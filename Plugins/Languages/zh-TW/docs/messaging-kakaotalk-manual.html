設定 KakaoTalk 訊息服務

先決條件

若要透過 KakaoTalk 傳送訊息，您需要在 developers.kakao.com（Kakao Developers）上建立一個應用程式。 KakaoTalk 是韓國最主要的通訊軟體。Klacks 的串接使用 Kakao 開發者 API（「傳送訊息給好友」）。

Kakao 開發者 API 的重要限制：

  • 此串接僅適用於傳送訊息 — 不支援接收。
  • 存取權杖效期很短（約 6 小時），必須在 Klacks 之外更新後重新填入。
  • 訊息只能傳送給已與該應用程式建立 Kakao「好友」關係並同意接收訊息的 使用者。
  • 若要在韓國進行正式的商業訊息傳送（AlimTalk）， 需要透過經授權的代理商申請商業頻道 — 本項串接 不涵蓋此項功能，它使用的是開發者 API。

步驟 1 — 設定 Kakao Developers 應用程式

  1. 在 developers.kakao.com 建立一個應用程式。
  2. 為此應用程式啟用 Kakao Login。
  3. 開放 talk_message 與 friends 這兩個 Scope。
  4. 透過 Kakao Login 的 OAuth 流程取得 存取權杖（以其名義傳送的使用者必須同意這些 Scope）。

提示：請將存取權杖視為密碼一樣妥善保管。 不要公開分享，並安全地儲存它。

步驟 2 — 在 Klacks 中設定 KakaoTalk

  1. 前往設定 → 訊息服務提供者。
  2. 點擊新增。
  3. 依照以下方式填寫欄位：
欄位說明範例
名稱內部使用的唯一名稱kakaotalk-main
顯示名稱將顯示於介面中KakaoTalk
提供者類型選擇 KakaoTalkKakaoTalk
存取權杖透過 OAuth 流程取得的權杖kakao-access-token...
已啟用開啟/關閉此提供者是
  1. 點擊儲存。
  2. 透過提供者清單中的測試按鈕測試連線。

重要：存取權杖約6 小時後會過期。 Klacks 不會自動更新它 — 您必須在外部（透過 Kakao 的 重新整理權杖流程）更新它，並重新填入 Klacks。

步驟 3 — 透過聊天機器人（Klacksy）傳送訊息

一旦 KakaoTalk 提供者設定完成並啟用，聊天機器人 Klacksy 便可 傳送訊息。您不需要知道 ID — 只需 使用員工或客戶的姓名即可： 

「傳送訊息給王小明：您的預約時間是明天下午 2 點。」
「傳一則訊息給陳小華：班次已經調換。」
「通知李大同，他星期一的班次取消了。」

Klacksy 會自動尋找收件人所登記的識別碼，並 使用已設定的 KakaoTalk 提供者傳送。整個傳送過程對您而言完全透明 — 您只需輸入姓名，其餘交給 Klacksy 處理。

先決條件：收件人必須在 Klacks 中登記來自 Kakao Friends API 的好友 UUID（於地址 → 聯絡資料中設定）。 收件人必須已與該應用程式建立 Kakao「好友」關係 — 無法 傳送給其他使用者。

傳入訊息

KakaoTalk 串接不支援接收訊息 — 對已傳送訊息的回覆 不會傳送給 Klacks。因此，訊息收件匣不會顯示 此提供者的任何傳入訊息。

疑難排解

問題可能原因解決方式
連線測試失敗 存取權杖已過期（效期約 6 小時） 請透過 Kakao 的 OAuth 流程更新權杖，並重新填入
訊息無法送達 收件人並非該應用程式的 Kakao「好友」 收件人必須透過 Kakao Login 與該應用程式建立連結，並同意該 Scope
