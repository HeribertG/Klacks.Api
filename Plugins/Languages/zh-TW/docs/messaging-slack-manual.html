設定 Slack

先決條件

若要透過 Slack 與 Klacks 傳送及接收訊息，您需要一個 Slack 工作區以及一個具有相應權限的 Slack 應用程式。Klacks 傳送訊息時使用 Slack Web API，接收訊息時則使用 Events API。

提示：免費版的 Slack 方案即足以完成串接。 Slack 應用程式可在 api.slack.com 建立，且完全免費。

步驟 1 — 建立 Slack 應用程式

  1. 開啟 api.slack.com/apps，點擊Create New App。
  2. 選擇From scratch，並設定一個名稱（例如 Klacks Bot）。
  3. 選擇要安裝此應用程式的工作區。
  4. 前往 OAuth & Permissions，並新增以下Bot Token Scopes：
    • chat:write — 用於向頻道傳送訊息
    • im:write — 用於向使用者傳送私訊
  5. 點擊 Install to Workspace 並確認權限。
  6. 記下 Bot User OAuth Token（以 xoxb- 開頭）。
  7. 前往 Basic Information，並記下 Signing Secret。

步驟 2 — 在 Klacks 中設定 Slack

  1. 前往設定 → 訊息服務提供者。
  2. 點擊新增。
  3. 依照以下方式填寫欄位：
欄位說明範例
名稱內部使用的唯一名稱slack-main
顯示名稱將顯示於介面中Slack
提供者類型選擇 SlackSlack
機器人權杖Bot User OAuth Token（以 xoxb- 開頭）xoxb-1234567890-abcdef...
簽章密鑰來自 Basic Information 的 Signing Secret — 用於驗證傳入事件的簽章a1b2c3d4e5f6...
預設頻道沒有指定收件人時使用的備用頻道#general
Webhook 網址系統會自動填入 — 此網址將於步驟 4 中作為 Request URL 登記於 Slackhttps://example.com/api/messaging/webhook/slack
已啟用開啟/關閉此提供者是
  1. 點擊儲存。
  2. 透過提供者清單中的測試按鈕測試連線。

步驟 3 — 透過聊天機器人（Klacksy）傳送訊息

一旦 Slack 提供者設定完成並啟用，聊天機器人 Klacksy 便可 透過 Slack 傳送訊息。請使用員工姓名或 頻道名稱： 

「傳送訊息給王小明：您的預約時間是明天下午 2 點。」
「傳一則訊息給陳小華：班次已經調換。」
「在 #team-updates 發布：下週的班表已經完成。」

收件人可以是頻道 ID（例如 C0123456789）或 使用者 ID（例如 U0123456789）— 若為使用者 ID，則會傳送 私訊。若未指定收件人，則會使用已設定的預設頻道。 整個傳送過程對您而言完全透明 — 您只需輸入姓名，其餘交給 Klacksy 處理。

先決條件：Slack 使用者必須與對應的 Klacks 聯絡人建立關聯（於地址 → 聯絡資料中設定）。若要傳送頻道訊息， 則必須先將機器人邀請至該頻道（/invite @Klacks Bot）。

步驟 4 — 接收傳入訊息（Events API）

若要在 Klacks 中顯示傳入的 Slack 訊息，必須設定 Slack 應用程式的 Events API。請務必先在 Klacks 中儲存並啟用此提供者，再 輸入 Request URL — Slack 會立即以一個 Challenge 請求驗證該網址， 而 Klacks 會自動回應此請求。

  1. 在 api.slack.com/apps 開啟您的 Slack 應用程式，並前往 Event Subscriptions。
  2. 啟用 Enable Events，並將 Klacks 中顯示的 Webhook 網址 輸入為 Request URL： 
    https://{您的網域}/api/messaging/webhook/slack
  3. 在 Subscribe to bot events 下訂閱事件 message.im（私訊）與 message.channels（頻道訊息）。
  4. 儲存變更，並在系統提示時重新於工作區中安裝該應用程式。
  5. 傳入的訊息現在會即時顯示於訊息收件匣中。 Klacks 會使用已登記的簽章密鑰驗證每個請求的簽章。

疑難排解

問題可能原因解決方式
連線測試失敗 機器人權杖無效或已被撤銷 請在 OAuth & Permissions 中檢查權杖，並重新安裝應用程式
錯誤 channel_not_found 或 not_in_channel 機器人未加入該頻道 將機器人邀請至頻道（/invite），或檢查頻道 ID
沒有收件人的訊息傳送失敗 未設定預設頻道 在提供者設定中輸入一個預設頻道
Request URL 驗證失敗 提供者尚未在 Klacks 中儲存/啟用，或簽章密鑰錯誤 請先在 Klacks 中儲存並啟用此提供者，並檢查簽章密鑰
收不到傳入訊息 尚未訂閱機器人事件 在 Event Subscriptions 中訂閱 message.im 與 message.channels
