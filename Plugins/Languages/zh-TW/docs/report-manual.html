報表設計工具手冊

報表結構

一份報表包含三個區域：

  • 頁首 – 列印在每一頁的上方
  • 本文 – 包含資料表格
  • 頁尾 – 列印在每一頁的下方

每個區域都可以在報表編輯器的設計索引標籤中進行編輯。

頁首區域

頁首有三個區域：左側、中間和右側。

每個區域可以包含：

  • 欄位 – 自動填入的資料庫欄位
  • 自由文字 – 手動輸入的文字
  • 圖片 – 例如公司標誌（透過圖片管理員上傳）

可以透過工具列新增或移除列。

本文表格

本文包含一個或多個表格。

動作說明
新增欄透過+符號或從欄位清單拖放
欄寬拖曳欄位邊緣進行調整
欄位順序透過拖放移動
移除欄在欄位編輯器中透過刪除符號

每個表格都與一個資料集（DataSet）關聯（例如工作計畫、地址）。

合併欄位（Merged Fields）

合併欄位允許在單一欄中進行多個資料繫結。

  • 在欄位編輯器中按一下新增欄位，即可在相同欄中新增更多欄位
  • 數值會上下排列或以分隔符號顯示
  • 分隔符號可在欄位對話方塊中設定（例如逗號、空格、換行）

表格頁尾

每個表格下方都可以顯示頁尾。

  • SUM 欄位：數值欄可以自動加總
  • 標籤：加總的標籤可以顯示或隱藏
  • 透過欄位編輯器中的頁尾索引標籤啟用

自由文字列

自由文字列可以插入在資料表格之前或之後。

屬性說明
位置可選擇資料之前或資料之後
內容任意文字，例如備註、條件或簽名欄位
樣式可設定字型、大小和對齊方式

格式設定

每個儲存格和每段自由文字都可以個別設定格式：

選項說明
字型可選擇儲存格的字型
字型大小以點（pt）為單位的大小
粗體／斜體／底線透過B／I／U按鈕
文字顏色可自由選擇顏色
對齊方式靠左、置中或靠右

儲存格框線

每個儲存格的框線都可以個別設定。

屬性選項
邊線上、右、下、左（個別或全部）
線條樣式細、中、粗、虛線、雙線
線條顏色可自由選擇

框線在欄位編輯器的框線下設定。

頁面設定

在一般索引標籤中可以調整列印設定：

  • 方向：直向（Portrait）或橫向（Landscape）
  • 紙張大小：A4、A3、B4 (JIS)、B5 (JIS) 或 Letter
  • 頁面邊界：上、右、下、左，單位為公釐

顯示選項（設計工具）

在設計索引標籤中，當資料來源為工作計畫（Schedule）時，還有其他選項可用：

  • 合併每日的項目：同一天的多個項目會合併為一行
  • 顯示完整期間：顯示期間內的所有日期，即使沒有項目

資料來源

報表可用的資料來源：

資料來源說明
工作計畫（Schedule）班次和工作時間
地址（清單）所有地址的表格
地址（詳細）單一地址
缺勤缺勤總覽
班次（Shifts）班次表格
群組群組總覽
容器範本容器報表的範本

資料來源在「資料來源」索引標籤中選擇，並決定可用的欄位。

參數

執行報表時會詢問參數。其數值可用於列篩選和公式中，並可進一步限制資料來源的查詢。參數在參數索引標籤中建立。

欄位說明
索引鍵技術名稱。必須以字母開頭，且只能包含字母、數字和底線。每個報表中必須唯一。
名稱執行時顯示的標籤。
類型文字、數字、日期、是／否或選項。
預設值執行時若未輸入任何值，則使用此值。
選項值僅限「選項」類型：允許的值，以逗號分隔。
影響範圍決定是否將該值額外傳遞給資料來源。
必填欄位若無此值，報表無法執行。

篩選和公式中的參數

每個參數在指令碼中皆以索引鍵加上前綴 param_ 的形式使用 — 例如索引鍵 region 會變成 param_region。此前綴可防止參數遮蔽同名的列值。目前的名稱會顯示在每個參數下方。

數值會在評估前轉換為所選的類型：

  • 數字：作為數字；無效的輸入會變成 0
  • 是／否：當值為 1、true、wahr 或 yes 時為真，否則為假
  • 文字、日期、選項：作為文字

將參數繫結至資料來源

透過影響範圍，參數可以進一步限制實際載入的資料：

設定效果
僅篩選和公式該值僅在指令碼中使用（預設）。
查詢的群組該值取代載入資料的群組。
查詢的人員該值取代載入資料的人員。
查詢的開始日期該值取代期間的開始日期。
查詢的結束日期該值取代期間的結束日期。

繫結的日期值必須以 YYYY-MM-DD 或 DD.MM.YYYY 格式輸入。其他格式的值會被忽略，以免查詢在不知不覺中變成空白。空值則保持原始設定不變。
