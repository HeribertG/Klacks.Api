設定 Threema Gateway

先決條件

若要透過 Threema 傳送訊息，您需要一個 Threema Gateway 帳戶。Threema 是瑞士的服務提供者， 在瑞士廣泛使用，且注重隱私保護（依循瑞士 DSG 資料保護法）。

重要：Threema 串接僅適用於傳送訊息。 接收傳入訊息需要使用該閘道的端對端模式， 目前並不支援。傳送訊息需要付費 — 每則傳送的訊息 都會消耗點數（Credits）。

步驟 1 — 建立 Threema Gateway 帳戶

  1. 在 gateway.threema.ch 註冊。
  2. 申請一個基本模式的 Gateway ID （例如 *MYGATEWAY）。此 ID 一律以星號（*）開頭， 且必須經 Threema 核准。
  3. 購買點數 — 沒有餘額便無法傳送訊息。
  4. 記下 Gateway 儀表板中的 API 密鑰。

提示：請將 API 密鑰視為密碼一樣妥善保管。 不要公開分享，並安全地儲存它。

步驟 2 — 在 Klacks 中設定 Threema

  1. 前往設定 → 訊息服務提供者。
  2. 點擊新增。
  3. 依照以下方式填寫欄位：
欄位說明範例
名稱內部使用的唯一名稱threema-gateway
顯示名稱將顯示於介面中Threema
提供者類型選擇 ThreemaThreema
Gateway ID您的 Threema Gateway ID（基本模式，以 * 開頭）*MYGATEWAY
API 密鑰來自 Gateway 儀表板的 API 密鑰a1b2c3d4e5...
已啟用開啟/關閉此提供者是
  1. 點擊儲存。
  2. 透過提供者清單中的測試按鈕測試連線。 測試會透過該閘道的點數查詢功能檢查憑證是否正確。

步驟 3 — 透過聊天機器人（Klacksy）傳送訊息

一旦 Threema 提供者設定完成並啟用，聊天機器人 Klacksy 便可 傳送訊息。您不需要知道 Threema ID — 只需 使用員工或客戶的姓名即可： 

「傳送訊息給王小明：您的預約時間是明天下午 2 點。」
「傳一則訊息給陳小華：班次已經調換。」
「通知李大同，他星期一的班次取消了。」

Klacksy 會自動尋找收件人所登記的 Threema ID，並 使用已設定的 Threema 提供者傳送。整個傳送過程對您而言完全透明 — 您只需輸入姓名，其餘交給 Klacksy 處理。

先決條件：收件人必須在 Klacks 中登記8 位數的 Threema ID （於地址 → 聯絡資料中設定）。員工可以在其 Threema 應用程式的「我的個人資料」中找到自己的 Threema ID。

傳入訊息

Threema 串接不支援接收訊息 — 對已傳送訊息的回覆 不會傳送給 Klacks。接收訊息需要使用 Threema Gateway 的端對端模式；而 Klacks 的串接使用的是基本模式。 因此，訊息收件匣不會顯示此提供者的任何傳入訊息。

疑難排解

問題可能原因解決方式
連線測試失敗 Gateway ID 或 API 密鑰錯誤 請在 gateway.threema.ch 的 Gateway 儀表板中檢查憑證
訊息無法送達 Threema ID 錯誤或不存在 請檢查 8 位數的 Threema ID 是否正確登記
傳送失敗 點數已用盡 請在 Threema Gateway 中加值點數
找不到收件人 尚未登記 Threema ID 請在地址 → 聯絡資料中輸入 Threema ID
Gateway ID 無法運作 ID 尚未核准 請等待 Threema 核准（可於儀表板查看狀態）
