設定 SMS 提供者

先決條件

若要透過 Klacks 傳送 SMS 簡訊，您需要一個 Twilio 帳戶或相容於 Twilio 的 SMS 閘道服務。Klacks 使用 Twilio REST API（Messages 端點，搭配 Basic 驗證方式）。

重要：SMS 串接僅適用於傳送簡訊。 Klacks 不會接收傳入的 SMS。

步驟 1 — 設定 Twilio 帳戶

  1. 在 twilio.com 註冊，並驗證您的 電話號碼與電子郵件地址。
  2. 開啟 Twilio Console。在儀表板的 Account Info 下可找到所需的兩項憑證：
    • Account SID — 以 AC 開頭
    • Auth Token — 點擊「顯示」查看
  3. 在Phone Numbers → Buy a number 中 購買一個寄件號碼（需支援 SMS）。 此號碼會作為傳出 SMS 的寄件者顯示。
  4. 測試帳戶：使用免費試用帳戶時，SMS 只能發送給事先 驗證過的號碼，且訊息中會包含試用提示。

提示：請將 Auth Token 視為密碼一樣妥善保管。 不要公開分享，並安全地儲存它。

步驟 2 — 在 Klacks 中設定 SMS 提供者

  1. 前往設定 → 訊息服務提供者。
  2. 點擊新增。
  3. 依照以下方式填寫欄位：
欄位說明範例
名稱內部使用的唯一名稱sms-twilio
顯示名稱將顯示於介面中SMS (Twilio)
提供者類型選擇 SMSSMS
帳戶 SID來自 Twilio Console 的 Account SIDACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
驗證權杖來自 Twilio Console 的 Auth Tokena1b2c3d4e5f6...
寄件號碼您購買的電話號碼，需為國際格式+41791234567
閘道網址（選填）僅用於相容 Twilio 的替代閘道服務 — 若使用 Twilio 則留空https://api.twilio.com
已啟用開啟/關閉此提供者是
  1. 點擊儲存。
  2. 透過提供者清單中的測試按鈕測試連線。

關於閘道網址的提示：若使用 Twilio，請將此欄位留空 — Klacks 會自動使用 https://api.twilio.com。只有在使用相容 Twilio API 的替代閘道服務時，才需要填寫此網址。

步驟 3 — 透過聊天機器人（Klacksy）傳送訊息

一旦 SMS 提供者設定完成並啟用，聊天機器人 Klacksy 便可 傳送簡訊。您不需要知道電話號碼 — 只需 使用員工或客戶的姓名即可： 

「傳送簡訊給王小明：您的預約時間是明天下午 2 點。」
「傳一則簡訊給陳小華：班次已經調換。」
「用簡訊通知李大同，他星期一的班次取消了。」

Klacksy 會自動尋找收件人所登記的行動電話號碼，並 使用已設定的 SMS 提供者傳送。整個傳送過程對您而言完全透明 — 您只需輸入姓名，其餘交給 Klacksy 處理。

先決條件：收件人必須在 Klacks 中登記行動電話號碼 （於地址 → 聯絡資料中設定），且需為國際格式（例如 +41791234567）。

傳入訊息

SMS 串接不支援接收訊息 — 對已傳送簡訊的回覆 不會傳送給 Klacks。因此，訊息收件匣不會顯示 此提供者的任何傳入訊息。

疑難排解

問題可能原因解決方式
連線測試失敗 Account SID 或 Auth Token 錯誤 請在 Twilio Console 的儀表板中檢查這兩項數值
SMS 無法送達 寄件號碼不支援 SMS 或尚未啟用 請在 Twilio Console 的 Phone Numbers 中檢查該號碼
收件人收不到簡訊（試用帳戶） 收件人號碼未經驗證 在 Twilio Console 中驗證該號碼，或改用付費帳戶
收件人收不到簡訊 電話號碼不是國際格式 使用 +{國碼}{號碼} 格式（例如 +41791234567）
錯誤「Permission to send an SMS has not been enabled」 目標國家未在地理權限中啟用 在 Twilio Console 的 Messaging → Geographic Permissions 中啟用該國家
帳戶餘額用盡 按使用量計費的預算已耗盡 在 Twilio Console 中加值餘額
