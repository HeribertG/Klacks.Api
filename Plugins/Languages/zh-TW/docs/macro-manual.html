巨集指令碼手冊

簡介

使用巨集編輯器，您可以建立用於計算工作、僱用類型等的指令碼。

使用範例：

  • 根據僱用率精確計算假期和兵役時間
  • 計算夜班、週末和節假日的加班費
  • 靈活應對新的需求

注意：指令碼直譯器執行在安全的沙箱環境中，無法存取檔案系統或網路。 無法執行惡意程式碼。

功能與類別

除了名稱與指令碼內容之外，巨集清單中的每個巨集還有兩個透過編輯器中的下拉選單設定的屬性： 類別與功能。兩者皆為純粹的中繼資料——它們獨立於指令碼之外，不會影響其運算結果，而是用於控制 Klacks 如何自動找到並指派合適的巨集。

類別

類別會將巨集歸類到某個業務應用範圍：

類別用途
未指定無特定應用範圍（新巨集的預設值）
班次一般班次的加班費計算（夜班、週末、節假日加班費）
休假假期時數計算
病假病假時數計算
意外事故意外事故時數計算
研習（支薪）支薪研習/培訓時間
研習（不支薪）不支薪研習/培訓時間

「班次」類別具有特殊角色：新建立的班次會自動指派此類別的標準巨集（參見下方「功能」）。 已存在的班次則永遠不會因此被事後變更。

功能：自訂、標準、標準（疊加）

功能用於分類巨集在其類別中所扮演的角色：

功能意義
自訂沒有特殊角色的自由巨集，每個類別可有任意數量。
標準該類別的標準巨集——會自動指派給新建立的班次。每個類別最多只能有一個巨集具有此功能。
標準（疊加）具有疊加式加班費邏輯的替代標準巨集（見下文）。同樣每個類別最多一個，可與「標準」巨集並存。

重要：功能本身不進行任何運算——它只是一個標籤。加班費究竟採用「取最高者」 （只計算適用的最高加班率）還是「疊加」（將所有適用的加班率加總）方式計算，是由指令碼本身決定的。 系統內建的兩個「班次」類別巨集，以相同的基本結構展示了這種差異：

  • 「AllShift」（功能：標準）——針對每個時段找出最高的適用加班費 （夜班/WE1/WE2/WE3/節假日），僅採用此一項。
  • 「AllShiftAdditive」（功能：標準（疊加））——分別獨立計算夜班、 週末與節假日加班費，並將其加總。

新建班次時自動指派這兩者中的哪一個，由一項安裝層級的設定（「疊加」或「取最高者」）控制。 之後每個班次都可隨時手動切換所使用的巨集——因此混合運作是可行的。

唯一性：若您嘗試將同一類別的第二個巨集也儲存為「標準」或「標準（疊加）」，編輯器會阻止儲存， 並顯示已被指派的巨集名稱。請先將該巨集的功能改為「自訂」。

不建議手動修改「AllShift」/「AllShiftAdditive」。 這兩個巨集是自動套用國家與行業特定調整的機制：只要保持不變，Klacks 就會自動讓它們與您所在國家 或行業適用的規則保持同步。若您手動編輯其中之一，該巨集自此即視為客戶自訂——日後針對此巨集的 自動國家/行業更新將不再默默套用，而是會因衝突而失敗，直到您手動解決差異為止。如果您需要自訂的 加班費邏輯，請改為建立一個功能為「自訂」的新巨集，並將其指定給相關的班次。

變數和常數

所有變數和常數均為無類型。

CONST PI = 3.1415
DIM a, b, c
IMPORT betrag, rabatt

匯入變數（IMPORT）

這些變數從 Work、Contract、CalendarSelection 中產生：

變數類型說明
hourDecimal工作時數（來自 Work）
fromhourString ("HH:MM")開始時間，例如 "08:30"——可用 TimeToHours() 轉換為十進位小時
untilhourString ("HH:MM")結束時間，例如 "17:00"
weekdayInteger星期幾 ISO-8601（1=週一、2=週二、3=週三、4=週四、5=週五、6=週六、7=週日）

we2rateDecimal可設定的第 2 個週末日（例如週日）的加班率
we3rateDecimal可設定的第 3 個週末日的加班率
nightstartString ("HH:MM")合約/設定中夜間時段的開始時間，例如 "23:00"
nightendString ("HH:MM")夜間時段的結束時間，例如 "06:00"
guaranteedhoursDecimal合約中的月度保障工時

weekendday2Integer第 2 個設定的週末日的 ISO 星期代碼
weekendday3Integer第 3 個設定的週末日的 ISO 星期代碼

注意：先前的變數 sarate/sorate（固定的週六/週日加班率） 已由三個與國家無關的 we1rate/we2rate/we3rate 取代， 它們與 weekendday1-3 搭配，可對應任意的週末日（例如以週五/週六取代週六/週日）。

控制結構

重要： ENDIF、ENDFUNCTION、ENDSUB 等關鍵字 必須連寫（請勿寫成 END IF 等分開的形式）。

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "大"
ELSEIF x > 5 THEN
    OUTPUT 1, "中"
ELSE
    OUTPUT 1, "小"
ENDIF

單行 IF

IF x > 10 THEN OUTPUT 1, "大" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "週末"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "工作日"
    CASE ELSE
        OUTPUT 1, "未知"
END SELECT

FOR-NEXT 迴圈

FOR i = 1 TO 10
    summe += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

DO-LOOP 迴圈

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

函式和程序

重要： 函式（FUNCTION）和程序（SUB）必須在首次呼叫之前定義。 直譯器從上到下讀取程式碼。函式或程序只有在其定義被處理後才能使用。

SUB（無傳回值的程序）

SUB berechne(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION（有傳回值的函式）

FUNCTION verdoppeln(x)
    verdoppeln = x * 2
ENDFUNCTION

DIM ergebnis
ergebnis = verdoppeln(21)
OUTPUT 1, ergebnis

傳回值（OUTPUT）

OUTPUT typ, wert

typ 與 wert 是以逗號分隔的兩個運算式；兩者皆為選填（省略時預設為 0 與 ""）。一個巨集可以包含任意數量的 OUTPUT 列——每一列都會 產生各自的傳回值。Klacks 僅會處理以下類型：

類型意義
1主要結果（時數或總金額）——即使數值為 0 也會被採用
10夜班加班費
11週末日 1 的加班費（例如週六）
12週末日 2 的加班費（例如週日）
13週末日 3 的加班費（第三個可設定的週末日）
14節假日加班費

數值為 0 的加班費列（類型 10-14）會被忽略——因此巨集不需要為每種加班費類型都輸出一列， 只需針對實際產生的加班費輸出即可。無法解讀為數字的值將被跳過。

儲存時，巨集必定會被編譯，並以中性測試值試行執行一次。語法錯誤與執行期錯誤（例如括號不成對或 懸空的運算式）都會可靠地顯示出來，而不會悄悄產生一個無法運作的巨集。

範例：加班費計算（「AllShift」）

系統內建的「班次」類別標準巨集。計算夜班、節假日以及三個可設定週末日的加班費，正確處理跨越午夜的 班次（分段計算），並針對每個時段套用最高的適用加班率（取最高者）。 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

說明

  • 分段計算： 跨越午夜的班次（例：22:00-06:00）會被分為兩段處理（至午夜／自午夜起），每段各有自己的星期/節假日標記
  • SegBonusForType： 針對一個時段與特定加班費類型（10-14），在考慮夜班、節假日與週末加班費的情況下計算加班金額
  • WE1/WE2/WE3 取代週六/週日： weekendday1-3 讓週末日可設定（並非每個國家都以週六/週日作為週末）
  • 每段取最高加班率： NRate/DRate 分別找出夜間時數與日間時數適用的最高加班率——取最高者，不疊加
  • HolidayNextDay： 考慮次日是否為節假日（對跨越午夜的夜班很重要）
  • 多個 OUTPUT 列： 第 1 列提供總金額，第 10-14 列提供各項加班金額（參見「傳回值」章節）

疊加變體（「AllShiftAdditive」）

同一類別的標準（疊加）巨集擁有相同的 IMPORT 列與相同的整體結構——唯一不同的是 SegBonusForType：不再採用最高加班率，而是針對每種加班費類型獨立計算是否適用，並在 最後將所有符合的金額加總（不再是取最高者）： 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

舉例來說，若夜班同時又遇上節假日，在「AllShift」中只會取兩者較高的加班率，而在「AllShiftAdditive」 中則會同時獲得夜班與節假日加班費。指令碼其餘部分（分段計算、加總、OUTPUT 列） 與上方的「AllShift」完全相同。
