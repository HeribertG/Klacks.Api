設定 Telegram 機器人

先決條件

若要透過 Klacks 傳送與接收 Telegram 訊息，您需要一個 Telegram 機器人。機器人可透過官方的 BotFather 建立，且完全免費。

步驟 1 — 建立 Telegram 機器人

  1. 開啟 Telegram，搜尋 @BotFather。
  2. 與 BotFather 開始對話，並傳送指令 /newbot。
  3. 為您的機器人設定一個名稱（例如 Klacks 通知）。
  4. 為機器人設定一個使用者名稱（必須以 bot 結尾，例如 klacks_notify_bot）。
  5. BotFather 會提供您一組機器人權杖。請複製此權杖 — 下一步會需要用到。

提示：請將機器人權杖視為密碼一樣妥善保管。 不要公開分享，並安全地儲存它。

步驟 2 — 在 Klacks 中設定機器人

  1. 前往設定 → 訊息服務提供者。
  2. 點擊新增。
  3. 依照以下方式填寫欄位：
欄位說明範例
名稱內部使用的唯一名稱telegram-bot
顯示名稱將顯示於介面中Telegram
提供者類型選擇 TelegramTelegram
機器人權杖來自 BotFather 的權杖123456:ABC-DEF1234ghIkl-zyx57W2v...
Webhook 網址用於接收訊息的網址（見步驟 4）https://example.com/api/messaging/webhook/telegram
已啟用開啟/關閉此提供者是
  1. 點擊儲存。
  2. 透過提供者清單中的測試按鈕測試連線。

步驟 3 — 透過聊天機器人（Klacksy）傳送訊息

一旦 Telegram 機器人設定完成並啟用，聊天機器人 Klacksy 便可 傳送訊息。您不需要知道對話 ID — 只需 使用員工或客戶的姓名即可： 

「傳送訊息給王小明：您的預約時間是明天下午 2 點。」
「傳一則訊息給陳小華：班次已經調換。」
「通知李大同，他星期一的班次取消了。」

Klacksy 會自動尋找收件人所登記的 Telegram 使用者名稱，並 使用已設定的機器人傳送。整個傳送過程對您而言完全透明 — 您只需輸入姓名，其餘交給 Klacksy 處理。

先決條件：收件人必須在 Klacks 中登記其 Telegram 使用者名稱 （於地址 → 聯絡資料中設定）。

步驟 4 — 接收傳入訊息（Webhook）

若要在 Klacks 中顯示傳入的 Telegram 訊息，必須設定一個 Webhook。

  1. 請確認您的 Klacks 執行個體可透過 HTTPS 公開存取。
  2. 在提供者設定中輸入以下 Webhook 網址： 
    https://{您的網域}/api/messaging/webhook/telegram
  3. 一旦此提供者儲存並啟用，Klacks 會自動向 Telegram 註冊 Webhook。
  4. 傳入的訊息現在會即時顯示於訊息收件匣中。

疑難排解

問題可能原因解決方式
連線測試失敗 機器人權杖無效 使用 /mybots 向 BotFather 查詢確認權杖
訊息無法送達 收件人尚未啟動該機器人 收件人必須在 Telegram 中開啟該機器人並傳送 /start
找不到收件人 尚未登記 Telegram 使用者名稱 請在地址 → 聯絡資料中輸入 Telegram 使用者名稱
收不到傳入訊息 Webhook 網址無法連線 請確認您的網域可透過 HTTPS 連線，且網址正確
Webhook 註冊失敗 沒有有效的 SSL 憑證 Telegram 需要有效的 SSL 憑證（不可為自簽憑證）
