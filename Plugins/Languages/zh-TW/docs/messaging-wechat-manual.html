設定 WeChat 訊息服務

先決條件

若要透過 WeChat 傳送訊息，您需要在 mp.weixin.qq.com 上申請一個服務號（Service Account） 類型的 WeChat 官方帳號。WeChat 是中國最主要的通訊軟體。

重要：WeChat 串接僅適用於傳送訊息。 此外，WeChat 平台還有以下限制：

  • 客服訊息只能傳送給在最近 48 小時內 與該帳號互動過的關注者。
  • 對於中國境外的企業，官方帳號的 驗證門檻很高（需要中國商業文件等）；請務必 務實規劃這一點。

步驟 1 — 設定 WeChat 官方帳號

  1. 在 mp.weixin.qq.com 申請一個 服務號，並完成驗證流程。
  2. 開啟 Settings → Basic Configuration，並 記下 AppID 與 AppSecret。
  3. 維護伺服器 IP 白名單：輸入您 Klacks 伺服器的 公開 IP 位址。若未輸入此項，WeChat 將拒絕 Klacks 的權杖請求。

提示：請將 AppSecret 視為密碼一樣妥善保管。 不要公開分享，並安全地儲存它。

步驟 2 — 在 Klacks 中設定 WeChat

  1. 前往設定 → 訊息服務提供者。
  2. 點擊新增。
  3. 依照以下方式填寫欄位：

名稱內部使用的唯一名稱wechat-main
顯示名稱將顯示於介面中WeChat
提供者類型選擇 WeChatWeChat
App ID來自 Settings → Basic Configuration 的 AppIDwx1234567890abcdef
App Secret來自 Settings → Basic Configuration 的 AppSecretabc123def456...
已啟用開啟/關閉此提供者是

  2. 透過提供者清單中的測試按鈕測試連線。

提示：Klacks 會自動從 WeChat 取得存取權杖並 快取起來 — 您不需要手動維護權杖。

步驟 3 — 透過聊天機器人（Klacksy）傳送訊息

一旦 WeChat 提供者設定完成並啟用，聊天機器人 Klacksy 便可 傳送訊息。您不需要知道 OpenID — 只需 使用員工或客戶的姓名即可： 

「傳送訊息給王小明：您的預約時間是明天下午 2 點。」
「傳一則訊息給陳小華：班次已經調換。」
「通知李大同，他星期一的班次取消了。」

Klacksy 會自動尋找收件人所登記的 OpenID，並 使用已設定的 WeChat 提供者傳送。整個傳送過程對您而言完全透明 — 您只需輸入姓名，其餘交給 Klacksy 處理。

先決條件：收件人必須在 Klacks 中登記其關注者 OpenID（於地址 → 聯絡資料中設定）。收件人 必須關注該官方帳號，並在最近 48 小時內 與其互動過 — 否則 WeChat 會以錯誤 「response out of time limit」拒絕傳送（此錯誤會顯示於訊息記錄中）。

傳入訊息

WeChat 串接不支援接收訊息 — 對已傳送訊息的回覆 不會傳送給 Klacks。因此，訊息收件匣不會顯示 此提供者的任何傳入訊息。

疑難排解

問題可能原因解決方式
連線測試失敗 App ID 或 App Secret 錯誤 請在 Settings → Basic Configuration 中檢查這兩項數值
權杖取得被拒絕 Klacks 伺服器 IP 不在白名單中 請將 Klacks 伺服器的公開 IP 加入伺服器 IP 白名單
錯誤「response out of time limit」 48 小時時限已過 該關注者必須再次與官方帳號互動（例如傳送一則訊息）
找不到收件人 尚未登記 OpenID 請在地址 → 聯絡資料中輸入該關注者的 OpenID
因權限問題傳送被拒絕 帳號類型或驗證不足 客服訊息需要已驗證的服務號
