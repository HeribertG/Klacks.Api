公式欄位手冊

基本語法

每個公式欄位都以 output 指令輸出結果：

output 1, <運算式>

第一個參數 1 是訊息類型，必須永遠是 1。第二個參數則是要輸出的值。

簡單範例：

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " 筆記錄"

可用的變數

可用的變數列在變數分頁中，您可以在那裡為其填入測試值。依報表類型不同，可用的變數也不同：

報表類型表格頁尾
工作計畫totalRows, totalHours, totalSurcharges, totalWorkDays
缺勤totalRows, totalValue
地址totalRows
群組totalRows

運算子

運算子說明範例
+加法totalHours + 2
-減法totalRows - 1
*乘法totalValue * 1.5
/除法totalHours / 8
^次方2 ^ 10
\整數除法10 \ 3 → 3
MOD取模（餘數）10 MOD 3 → 1
&文字串接"Total: " & totalRows

內建函式

型別轉換

函式說明
CStr(x)將數字轉換為文字
CInt(x)轉換為整數
CDbl(x)轉換為小數

數學

函式說明
Abs(x)絕對值
Round(x, n)四捨五入至小數點後 n 位
Int(x)無條件捨去為整數
Sqr(x)平方根
Sgn(x)正負號（-1、0、1）

文字

函式說明
Len(s)文字長度
Left(s, n)從左側取 n 個字元
Right(s, n)從右側取 n 個字元
Mid(s, pos, n)從位置 pos 開始取 n 個字元
UCase(s)轉換為大寫
LCase(s)轉換為小寫
Trim(s)移除頭尾空白字元
Replace(s, alt, neu)取代文字

條件邏輯

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "許多筆記錄"
ELSEIF totalRows > 0 THEN
    output 1, "少量記錄"
ELSE
    output 1, "沒有記錄"
ENDIF

單行 IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF（簡短形式）

output 1, IIF(totalRows > 0, "OK", "空")

變數與迴圈

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

實用範例

記錄筆數加文字說明

output 1, CStr(totalRows) & " 筆記錄"

四捨五入的數值（1 位小數）

output 1, CStr(Round(totalValue, 1))

時數以 h:mm 格式顯示

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

條件式輸出

IF totalRows = 0 THEN
    output 1, "沒有缺勤記錄"
ELSE
    output 1, CStr(totalRows) & " 筆缺勤記錄（總計：" & CStr(totalValue) & "）"
ENDIF

計算平均值

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " 小時/天"
ELSE
    output 1, "-"
ENDIF
提示：指令碼直譯器在安全的沙盒環境中執行，無法存取檔案系統或網路。
