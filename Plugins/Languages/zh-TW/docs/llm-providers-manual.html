搜尋 LLM 提供者 — 使用說明

此功能的用途是什麼？

此檢視畫面會為你建議尚未加入清單中的 LLM 提供者，並讓你一鍵加入所選項目。 如此一來，你就不必手動輸入名稱與基礎網址。系統只會建議 相容於 OpenAI API 的提供者 — 也就是與你已設定的提供者相同類型的服務。

表格欄位說明

提供者名稱

提供者的顯示名稱（例如「OpenRouter」、「xAI (Grok)」）。

基礎網址

與此提供者通訊時使用的 API 位址（例如 https://api.x.ai/v1/）。之後建立時會直接使用此網址。

來源

說明此建議來自何處：

  • 目錄 — 來自事先建立且經過驗證的知名提供者清單。 這些基礎網址已經過驗證，因此值得信賴。
  • 網路 — 透過網路搜尋找到並自動解析。這些 項目只有在設定中已設定網路搜尋功能時才會出現。 它們很有幫助，但若有疑慮，建議先簡單檢查一下基礎網址。

可達性

在顯示之前，每個建議都會即時測試（呼叫 /models 端點）：

  • 可連線 — API 有回應，提供者可正常運作。
  • 可連線（需要金鑰） — API 存在，但需要 API 金鑰。表示位址正確。
  • 無法連線 — 此位址沒有回應。這類項目 無法被選取。

新增提供者

勾選一個或多個提供者，然後點擊下方的 「新增所選項目」。所選的提供者將會 以停用且不含 API 金鑰的狀態建立。已存在的提供者 則不會被建議。

新增後的下一步

新加入的提供者尚未啟用。請在清單中開啟它，輸入 API 金鑰並將其啟用。之後它的運作方式 就會與你其他的提供者相同。個別模型的維護仍需 透過模型管理功能分開進行。
