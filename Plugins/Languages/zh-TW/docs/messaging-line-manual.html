設定 LINE 訊息服務

先決條件

若要透過 LINE 傳送與接收訊息，您需要在 LINE Developers Console 中建立一個 LINE 官方帳號，並搭配 Messaging API 頻道。LINE 在日本、台灣與泰國特別普及。

提示：依 LINE 方案不同，推播訊息可能有每月配額 （免費方案有限制）。請查看您官方帳號方案的 最新條款。

步驟 1 — 建立 LINE 官方帳號與 Messaging API 頻道

  1. 建立一個 LINE 官方帳號 （透過 LINE Official Account Manager）。
  2. 開啟 LINE Developers Console（developers.line.biz），並 建立一個 Messaging API 頻道，或將您的 官方帳號與 Messaging API 建立關聯。
  3. 在 Messaging API 分頁中發行一組長效的 頻道存取權杖（Issue）。
  4. 記下 Basic Settings 分頁中的 頻道密鑰。

提示：請將頻道存取權杖與頻道密鑰視為密碼一樣妥善保管。 不要公開分享，並安全地儲存它們。

步驟 2 — 在 Klacks 中設定 LINE

  1. 前往設定 → 訊息服務提供者。
  2. 點擊新增。
  3. 依照以下方式填寫欄位：
欄位說明範例
名稱內部使用的唯一名稱line-bot
顯示名稱將顯示於介面中LINE
提供者類型選擇 LINELINE
頻道存取權杖來自 Messaging API 分頁的長效權杖eyJhbGciOi...
頻道密鑰來自 Basic Settings 的密鑰abc123def456...
Webhook 網址系統會自動填入您 Klacks 執行個體的網址（無法編輯）https://example.com/api/messaging/webhook/line
已啟用開啟/關閉此提供者是
  1. 點擊儲存。
  2. 透過提供者清單中的測試按鈕測試連線。

步驟 3 — 透過聊天機器人（Klacksy）傳送訊息

一旦 LINE 提供者設定完成並啟用，聊天機器人 Klacksy 便可 傳送訊息。您不需要知道 LINE 使用者 ID — 只需 使用員工或客戶的姓名即可： 

「傳送訊息給王小明：您的預約時間是明天下午 2 點。」
「傳一則訊息給陳小華：班次已經調換。」
「通知李大同，他星期一的班次取消了。」

Klacksy 會自動尋找收件人所登記的 LINE 使用者 ID，並 使用已設定的 LINE 提供者傳送。整個傳送過程對您而言完全透明 — 您只需輸入姓名，其餘交給 Klacksy 處理。

先決條件：收件人必須在 Klacks 中登記LINE 使用者 ID （以 U 開頭）（於地址 → 聯絡資料中設定）。 此使用者 ID 會透過傳入訊息取得（可在訊息收件匣中看到）— 收件人必須先將您的官方帳號加為好友，並向其 傳送一則訊息。

步驟 4 — 接收傳入訊息（Webhook）

若要在 Klacks 中顯示傳入的 LINE 訊息，必須在 LINE Developers Console 中手動輸入 Webhook 網址。

  1. 從提供者設定中複製 Klacks 顯示的 Webhook 網址： 
    https://{您的網域}/api/messaging/webhook/line
  2. 在 LINE Developers Console 的 Messaging API → Webhook settings 中將此網址 輸入為 Webhook URL。
  3. 啟用選項 「Use webhook」。
  4. 請確認您的 Klacks 執行個體可透過 HTTPS 公開存取。
  5. 傳入的訊息現在會即時顯示於訊息收件匣中。

疑難排解

問題可能原因解決方式
連線測試失敗 頻道存取權杖無效 請在 LINE Developers Console 中發行一組新的權杖
訊息無法送達 收件人尚未將官方帳號加為好友，或已封鎖 收件人必須在 LINE 中將此帳號加為好友
傳送失敗 每月推播配額已用盡 請在 LINE Official Account Manager 中檢查您方案的配額
找不到收件人 尚未登記 LINE 使用者 ID 請將訊息收件匣中的使用者 ID 登記到地址 → 聯絡資料
收不到傳入訊息 Webhook 網址未輸入，或「Use webhook」未啟用 請檢查 LINE Developers Console 中的 Webhook settings
