個人存取權杖手冊

什麼是個人存取權杖？

個人存取權杖（PAT）是長效的 API 金鑰，讓外部工具與 服務可以安全存取 Klacks — 不需要使用者名稱與密碼。

常見應用情境：

  • MCP（Model Context Protocol） — 讓像 Claude Desktop 這樣的 AI 助理直接存取 Klacksy 技能
  • 自動化指令碼與 CI/CD 流水線
  • 外部監控與整合工具

安全性概念

Klacks 絕不會儲存明文權杖。建立完成後，資料庫中僅會 儲存該權杖的 SHA-256 雜湊值。權杖本身 只會在建立完成後顯示一次，之後 便無法再次取得。

提示：請在建立後立即記下或複製此權杖。若遺失， 必須建立新權杖並撤銷舊的權杖。

建立權杖

逐步操作

  • 前往設定 → 個人存取權杖
  • 點擊建立新權杖
  • 輸入一個有意義的名稱（例如 Claude Desktop 或 CI-Pipeline）
  • 選擇所需的有效期限（1–730 天，預設：365 天）
  • 點擊建立
  • 立即複製顯示出來的權杖 — 它只會顯示一次

權杖格式

klacks_pat_<隨機字串>

每個權杖都以前綴 klacks_pat_ 開頭，後面接著一段 加密安全的隨機字串。

有效期限

期限建議用途
1–30 天短期測試與開發
90–180 天需定期輪換的 CI/CD 流水線
365 天（預設）長期整合（例如 Claude Desktop）
730 天長期系統整合

使用權杖

HTTP 標頭中的 Bearer 權杖

權杖會以 Bearer 權杖的形式，於每個 API 請求的 Authorization 標頭中傳送：

Authorization: Bearer klacks_pat_...

在 Claude Desktop 中設定 MCP

MCP 端點（/mcp）讓像 Claude Desktop 這樣的 AI 助理可以直接 存取所有 Klacksy 技能 — 查詢員工資料、安排班次、 管理群組等等。

在 Claude Desktop 應用程式中設定（claude_desktop_config.json）：

{
  "mcpServers": {
    "klacks": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-fetch",
        "https://<您的-klacks-網域>/mcp"
      ],
      "env": {
        "AUTHORIZATION": "Bearer klacks_pat_..."
      }
    }
  }
}

請將 <您的-klacks-網域> 替換為您 Klacks 安裝環境的地址， 並將 klacks_pat_... 替換為您所建立的權杖。

直接呼叫 API（curl）

curl -H "Authorization: Bearer klacks_pat_..." \
     https://<您的-klacks-網域>/api/clients

管理與安全

權杖總覽

在設定 → 個人存取權杖下，您可以看到所有權杖的 名稱、建立日期、到期日期及最後使用時間。 明文權杖絕不會在此檢視中顯示。

撤銷權杖

您可以隨時撤銷權杖。撤銷後，所有使用該權杖的請求 都會立即被拒絕。請在以下情況立即撤銷權杖：

  • 權杖不慎外流
  • 某個裝置或服務不再使用
  • 您發現可疑活動

到期

過期的權杖會被自動拒絕。Klacks 會在總覽中顯示 未來 30 天內即將到期的權杖，讓您能及時建立 新的權杖。

安全性建議

  • 每個服務或工具使用各自獨立的權杖
  • 選擇有意義的名稱，以便清楚識別各個權杖
  • 絕不將明文權杖儲存在版本控制系統中
  • 定期輪換權杖，尤其是在 CI/CD 場景中
  • 一旦懷疑遭到濫用，立即撤銷權杖

每個權杖都與您的使用者帳號綁定，並擁有與您帳號 相同的權限。請以對待密碼同樣的謹慎態度 對待這些權杖。
