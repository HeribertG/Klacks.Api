設定 Viber 機器人

先決條件

若要透過 Viber 傳送與接收訊息，您需要一個 Viber 機器人，可透過 Viber 合作夥伴入口網站建立。 Viber 在東歐與中東地區特別受歡迎。

提示：Viber 已將機器人使用商業化 — 依國家與 訊息量不同，可能適用付費方案。請至 partners.viber.com 查看最新條款。

步驟 1 — 建立 Viber 機器人

  1. 在 partners.viber.com 註冊。
  2. 在合作夥伴入口網站中建立一個新的機器人。
  3. 記下機器人儀表板中的 Auth Token。
  4. 設定一個寄件者名稱（例如 Klacks Bot）。

步驟 2 — 在 Klacks 中設定 Viber

  1. 前往設定 → 訊息服務提供者。
  2. 點擊新增。
  3. 依照以下方式填寫欄位：
欄位說明範例
名稱內部使用的唯一名稱viber-bot
顯示名稱將顯示於介面中Viber
提供者類型選擇 ViberViber
Auth Token來自機器人儀表板的 Auth Token4a5e6f7g8h9i...
寄件者名稱將顯示給收件人看到的名稱Klacks Bot
Webhook 網址系統會自動填入您 Klacks 執行個體的網址（無法編輯）https://example.com/api/messaging/webhook/viber
已啟用開啟/關閉此提供者是
  1. 點擊儲存。Klacks 會在此時自動向 Viber 註冊 Webhook（set_webhook）。
  2. 透過提供者清單中的測試按鈕測試連線。

重要：顯示的 Webhook 網址必須可透過 HTTPS 公開存取 — 否則儲存時 Webhook 註冊 會失敗。

步驟 3 — 透過聊天機器人（Klacksy）傳送訊息

一旦 Viber 提供者設定完成並啟用，聊天機器人 Klacksy 便可 傳送訊息。您不需要知道 Viber 使用者 ID — 只需 使用員工或客戶的姓名即可： 

「傳送訊息給王小明：您的預約時間是明天下午 2 點。」
「傳一則訊息給陳小華：班次已經調換。」
「通知李大同，他星期一的班次取消了。」

Klacksy 會自動尋找收件人所登記的 Viber 使用者 ID，並 使用已設定的 Viber 提供者傳送。整個傳送過程對您而言完全透明 — 您只需輸入姓名，其餘交給 Klacksy 處理。

重要：Viber 機器人只能對已訂閱該機器人 （已與機器人開始 1:1 對話）的使用者傳送訊息。因此收件人必須 先向機器人傳送一則訊息。其Viber 使用者 ID 會透過該傳入訊息取得（可在訊息收件匣中看到），並 登記到收件人的地址 → 聯絡資料中。

步驟 4 — 接收傳入訊息

傳入的 Viber 訊息會透過儲存時註冊的 Webhook 自動接收 — 不需要額外設定。

  1. 使用者在 Viber 中搜尋此機器人並傳送訊息給它。
  2. 此訊息會即時顯示於訊息收件匣中。
  3. 將寄件者的 Viber 使用者 ID 填入該員工的聯絡資料中， 以便 Klacksy 日後可以直接向其傳送訊息。

疑難排解

問題可能原因解決方式
連線測試失敗 Auth Token 錯誤 請在 partners.viber.com 的機器人儀表板中檢查此權杖
儲存時 Webhook 註冊失敗 Klacks 執行個體無法透過 HTTPS 公開存取 請確認 Webhook 網址可公開存取，且具備有效的 SSL 憑證
訊息無法送達 收件人尚未訂閱該機器人 收件人必須先在 Viber 中向機器人傳送訊息
找不到收件人 尚未登記 Viber 使用者 ID 請將訊息收件匣中的使用者 ID 登記到地址 → 聯絡資料
收不到傳入訊息 Webhook 尚未註冊 請重新儲存此提供者，讓 Klacks 重新註冊 Webhook
