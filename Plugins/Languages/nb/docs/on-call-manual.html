Bakvakt- og hjemmevaktordning

Disse innstillingene fastsetter om bakvakt og hjemmevakt registreres, og hvor stor andel av tiden som telles som arbeidstid. De gjelder som standard for hele bedriften for nyplanlagte tjenester.

Bakvaktordning aktivert

Slår hele bakvakt-logikken på eller av. Er alternativet deaktivert, ignoreres de øvrige feltene, og tilstedevakt og hjemmevakt telles ikke separat.

  • Standard: deaktivert.

Tilstedevakt telles som (%)

Andel av den aktive tilstedeværelsestiden på stedet som regnes som ordinær arbeidstid.

  • Verdiområde: 0 til 100 prosent.
  • Standard: 100 (tilstedevakt telles fullt ut som arbeidstid).

Hjemmevakt telles som (%)

Andel av den rene hjemmevakttiden (tilkallingsvakt uten aktivt oppdrag) som regnes som arbeidstid.

  • Verdiområde: 0 til 100 prosent.
  • Standard: 0 (hjemmevakt telles ikke som arbeidstid).

Regn med i periodegrenser

Fastsetter om den medregnede bakvakt- og hjemmevakttiden inngår i periodegrensene (f.eks. månedlige eller årlige makstimer).

  • Aktiv: medregnet tid belaster periodegrensene.
  • Standard: deaktivert.
