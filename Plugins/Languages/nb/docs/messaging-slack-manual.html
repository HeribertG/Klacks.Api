Sette opp Slack

Forutsetninger

For å sende og motta meldinger via Slack med Klacks, trenger du en Slack-arbeidsområde (workspace) og en Slack-app med de nødvendige tillatelsene. Klacks bruker Slack Web API for utsending og Events API for mottak.

Merk: Den gratis Slack-planen er tilstrekkelig for tilkoblingen. Slack-apper opprettes på api.slack.com og er gratis.

Trinn 1 — Opprett en Slack-app

  1. Åpne api.slack.com/apps og klikk på Create New App.
  2. Velg From scratch og gi appen et navn (f.eks. Klacks Bot).
  3. Velg arbeidsområdet appen skal installeres i.
  4. Naviger til OAuth & Permissions og legg til følgende Bot Token Scopes:
    • chat:write — for å sende meldinger til kanaler
    • im:write — for å sende direktemeldinger til brukere
  5. Klikk på Install to Workspace og bekreft tillatelsene.
  6. Noter deg Bot User OAuth Token (begynner med xoxb-).
  7. Naviger til Basic Information og noter deg Signing Secret.

Trinn 3 — Sende meldinger via chatboten (Klacksy)

Så snart Slack-leverandøren er konfigurert og aktivert, kan chatboten Klacksy sende meldinger via Slack. Bruk navnet på medarbeideren eller et kanalnavn: 

"Send en melding til Max Muster: Avtalen din er i morgen kl. 14:00."
"Send Anna Beispiel en melding: Skiftet er byttet."
"Post i #team-updates: Vaktplanene for neste uke er klare."

Som mottaker brukes en Channel-ID (f.eks. C0123456789) eller en User-ID (f.eks. U0123456789) — med en User-ID sendes det en direktemelding. Hvis ingen mottaker er angitt, brukes den konfigurerte standardkanalen. Utsendingen er helt transparent for deg — du jobber med navn, Klacksy tar seg av resten.

Forutsetning: Slack-brukeren må være koblet til den tilhørende Klacks-kontakten (under Adresse → Kontaktdata). For kanalmeldinger må boten være invitert inn i den aktuelle kanalen (/invite @Klacks Bot).

Trinn 4 — Motta innkommende meldinger (Events API)

For å vise innkommende Slack-meldinger i Klacks, må Events API for Slack-appen konfigureres. Lagre og aktiver leverandøren i Klacks før du angir Request-URL-en — Slack kontrollerer URL-en umiddelbart med en Challenge-forespørsel, som Klacks besvarer automatisk.

  1. Åpne Slack-appen din på api.slack.com/apps og naviger til Event Subscriptions.
  2. Aktiver Enable Events og angi som Request URL webhook-URL-en som vises i Klacks: 
    https://{ditt-domene}/api/messaging/webhook/slack
  3. Abonner under Subscribe to bot events på hendelsene message.im (direktemeldinger) og message.channels (kanalmeldinger).
  4. Lagre endringene og installer appen på nytt i arbeidsområdet når du blir bedt om det.
  5. Innkommende meldinger vises nå i sanntid i meldingsinnboksen. Klacks kontrollerer signaturen til hver forespørsel med det lagrede signing-secretet.

Feilsøking

ProblemMulig årsakLøsning
Tilkoblingstesten mislykkes Bot-token ugyldig eller tilbakekalt Kontroller tokenet under OAuth & Permissions og installer appen på nytt
Feil channel_not_found eller not_in_channel Boten er ikke lagt til i kanalen Inviter boten inn i kanalen (/invite) eller kontroller Channel-ID-en
Melding uten mottaker mislykkes Ingen standardkanal konfigurert Angi en standardkanal i leverandørinnstillingene
Verifisering av Request-URL mislykkes Leverandøren er ikke lagret/aktivert i Klacks, eller signing-secretet er feil Lagre og aktiver leverandøren i Klacks først, og kontroller signing-secretet
Innkommende meldinger mangler Bot-hendelser er ikke abonnert på Abonner på message.im og message.channels under Event Subscriptions
