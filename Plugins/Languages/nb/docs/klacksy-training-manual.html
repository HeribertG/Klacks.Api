Klacksy trening - veiledning

Hva er treningsverktøyet?

Treningsverktøyet styrer navigasjonen på siden for chatboten Klacksy. Når en bruker sier eller skriver "Klacksy, vis meg adressene", navigerer Klacksy til riktig side og ruller til det tilhørende avsnittet.

For at dette skal fungere, trenger Klacksy for hvert anker på en side en liste med synonymer på hvert språk (f.eks. "adresser", "kunder", "kontakter" for målet addresses).

Fanen "Mål"

Liste over alle anker funnet i frontend (HTML-attributtene data-klacksy-target). Statusfilter:

  • pending: Anker finnes, men har ennå ingen synonymer
  • generated: Synonymer er generert automatisk, trenger kontroll
  • reviewed: Synonymer godkjent av en administrator
  • needs-review: Merket for ny kontroll

Å klikke på et mål åpner synonym-editoren nedenfor. Der kan synonymer legges til, slettes og godkjennes med "Lagre som kontrollert".

Fanen "Tilbakemeldinger"

Viser brukerinndata som Klacksy ikke kunne tolke (ingen passende synonym funnet). Ut fra denne listen kan man se hvilke synonymer som fortsatt mangler.

Fanen "Metrikker"

Oversikt over alle mål etter status. Hjelper med å følge treningsfremdriften.

Byggerørledning (CLI)

Når maler har fått nye data-klacksy-target-ankere, må manifestet og de innledende synonymene regenereres. Følgende kommandoer kjører også automatisk i CI og i Husky pre-commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Skann maler → navigation-targets.json med alle ankere
npm run scan:targets

# 2a. Generer innledende synonymer (alle 4 kjerne + 22 plugin-lokaliseringer, ~2,5 t)
npm run generate:synonyms

# 2b. Bare kjerne-lokaliseringer (de/en/fr/it) — raskt, ca. 9 min
npm run generate:synonyms -- --core-only

# 2c. Bare fylle inn manglende plugin-lokaliseringer — ca. 45 min
npm run generate:synonyms -- --plugins-only

# 3. Sjekk konsistens for vekkeord
npm run wake-word-lint

Viktig: Ved npm run må -- stå der, slik at alternativene videreformidles til skriptet. Uten -- svelger npm flagget, og skriptet kjører i standardmodus.

Alternativ uten npm: npx tsx tools/generate-synonyms.ts --core-only.

API-nøkkel

LLM-API-nøkkelen slås opp i denne rekkefølgen:

  1. Miljøvariabelen SYNONYM_LLM_API_KEY
  2. DB-tabellen llm_providers (leverandør deepseek, is_enabled = true) — automatisk via psql-kall
  3. Ellers feilmelding

Standardleverandør er DeepSeek. Annen leverandør via SYNONYM_LLM_PROVIDER_ID=anthropic (eller en annen konfigurert LLM-leverandør i innstillingene).

Trinn 1 - scan:targets

Gjennomsøker alle Angular-maler etter attributtene data-klacksy-target og genererer manifestet Application/Skills/Definitions/navigation-targets.json. Hvert nytt anker vises deretter i fanen "Mål" med status pending.

Trinn 2 - generate:synonyms

Genererer innledende synonymer for hvert nytt anker ut fra data-klacksy-label-key og kategorien. Status deretter: generated (må kontrolleres av administrator).

Skriptet skriver manifest-sjekkpunkter hver 5. mål, slik at et avbrudd ikke mister allerede genererte data.

Trinn 3 - wake-word-lint

Sjekker konsistensen til vekkeord-varianten (Hallo Klacksy / Hey Klacksy / ...) på tvers av alle språk. Hindrer at synonymer overskriver vekkeordet.

Talemodus

Mikrofonikonet i chatten aktiverer talemodus. Så snart den er aktiv:

  • Mikrofonen lytter kontinuerlig og transkriberer fortløpende
  • Ved kort stillhet → den hittil transkriberte teksten sendes automatisk

Viktig: Så snart du begynner å skrive i tekstfeltet, avsluttes talemodus automatisk — ellers ville mikrofonen overskrive den skrevne teksten med sine egne transkripsjoner og sende den for tidlig.

Typisk treningsløkke

  1. Legg til anker i malen: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Start API på nytt (cachen leses inn på nytt ved oppstart)
  4. Åpne fanen "Mål" → nye mål vises med status generated
  5. Kontroller/supplér synonymer → "Lagre som kontrollert" → status reviewed
  6. Test med Klacksy, f.eks. "Klacksy, vis meg adressene"
  7. Hvis Klacksy ikke finner treff → fanen "Tilbakemeldinger" → legg til manglende synonym
  8. Overvåk fanen "Metrikker" til alt er reviewed
