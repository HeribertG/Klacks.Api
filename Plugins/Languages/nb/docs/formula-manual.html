Formelfelt-håndbok

Grunnleggende syntaks

Hvert formelfelt gir ut resultatet med kommandoen output:

output 1, <uttrykk>

Den første parameteren 1 er meldingstypen og må alltid være 1. Den andre parameteren er verdien som skal gis ut.

Enkle eksempler:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " oppføringer"

Tilgjengelige variabler

De tilgjengelige variablene er oppført i fanen Variabler og kan gis testverdier der. Avhengig av rapporttypen er ulike variabler tilgjengelige:

Betinget logikk

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "mange oppføringer"
ELSEIF totalRows > 0 THEN
    output 1, "få oppføringer"
ELSE
    output 1, "ingen oppføringer"
ENDIF

Enlinjes IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (kortform)

output 1, IIF(totalRows > 0, "OK", "Tom")

Variabler og løkker

DIM i, sum
sum = 0
FOR i = 1 TO totalRows
    sum = sum + 1
NEXT
output 1, CStr(sum)

Praktiske eksempler

Antall oppføringer med tekst

output 1, CStr(totalRows) & " oppføringer"

Avrundet verdi (1 desimal)

output 1, CStr(Round(totalValue, 1))

Timer som t:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "t " & CStr(m) & "min"

Betinget utdata

IF totalRows = 0 THEN
    output 1, "Ingen fravær"
ELSE
    output 1, CStr(totalRows) & " fravær (Total: " & CStr(totalValue) & ")"
ENDIF

Beregne gjennomsnitt

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " t/dag"
ELSE
    output 1, "-"
ENDIF
