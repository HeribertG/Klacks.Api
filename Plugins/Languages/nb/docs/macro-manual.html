Håndbok for makroskript

Introduksjon

Makroeditoren gjør det mulig å skrive skript som brukes som beregningsgrunnlag for tjenester, arbeidsaktiviteter osv.

Brukseksempler:

  • Nøyaktig timeberegning for ferie eller militærtjeneste basert på stillingsprosent
  • Beregning av tillegg for nattarbeid, helger og helligdager
  • Fleksibel tilpasning til nye krav

Merk: Skripttolken kjører i et sikkert sandkassemiljø uten tilgang til filsystemet eller nettverket. Det er ikke mulig å kjøre ondsinnet kode.

Funksjon og kategori

Utover navn og skript-innhold har hver makro i makrolisten to andre egenskaper, som settes via nedtrekksmenyer i editoren: Kategori og Funksjon. Begge er rene metadata – de ligger utenfor skriptet og endrer ikke beregningen, men styrer hvordan Klacks automatisk finner og tildeler riktig makro.

Kategori

Kategorien knytter en makro til et bestemt fagområde:

KategoriBruk
Ikke tildeltIngen spesiell bruksområde (standard for nye makroer)
VaktTilleggsberegning for ordinære vakter (natt-, helge-, helligdagstillegg)
FerieTimeberegning for ferie
SykdomTimeberegning for sykdom
UlykkeTimeberegning for ulykke
Kurs (betalt)Betalt kurs-/opplæringstid
Kurs (ubetalt)Ubetalt kurs-/opplæringstid

Kategorien Vakt har en spesiell rolle: Nyopprettede vakter får automatisk tildelt standardmakroen for denne kategorien (se "Funksjon" nedenfor). Allerede eksisterende vakter blir aldri endret i etterkant.

Funksjon: Egendefinert, Standard, Standard (additiv)

Funksjonen klassifiserer rollen til en makro innenfor kategorien:

FunksjonBetydning
EgendefinertFri makro uten spesiell rolle. Vilkårlig mange per kategori mulig.
StandardStandardmakroen for denne kategorien – tildeles automatisk til nye vakter. Høyst ÉN makro per kategori kan ha denne funksjonen.
Standard (additiv)Alternativ standardmakro med additiv tilleggslogikk (se nedenfor). Også høyst én per kategori, i tillegg til "Standard"-makroen.

Viktig: Funksjonen alene beregner ingenting – den er en etikett. Om tillegg beregnes «highest-wins» (kun den høyeste gjeldende satsen teller) eller additivt (alle gjeldende satser summeres), avgjøres av selve skriptet. De to medfølgende «Vakt»-kategori-makroene viser forskjellen på samme grunnstruktur:

  • "AllShift" (Funksjon: Standard) – finner for hvert tidssegment det høyeste gjeldende tillegget (natt/WE1/WE2/WE3/helligdag) og bruker kun dette.
  • "AllShiftAdditive" (Funksjon: Standard (additiv)) – beregner natt-, helge- og helligdagstillegg uavhengig av hverandre og summerer dem.

Hvilken av de to som automatisk tildeles ved opprettelse av en ny vakt, styres av en installasjonsomfattende innstilling («additiv» eller «høyeste sats vinner»). Per vakt kan makroen deretter når som helst byttes manuelt – en blandet drift er altså mulig.

Entydighet: Forsøker du å lagre en annen makro i samme kategori også som "Standard" eller "Standard (additiv)", blokkerer editoren lagringen og oppgir navnet på makroen som allerede er tildelt. Sett dennes funksjon først til "Egendefinert".

Manuelle endringer i "AllShift"/"AllShiftAdditive" frarådes. Disse to makroene er mekanismen som land- og bransjespesifikke tilpasninger spilles inn gjennom automatisk: Så lenge du lar dem stå uendret, holder Klacks dem automatisk synkronisert med reglene som passer for ditt land og din bransje. Redigerer du en av dem manuelt, regnes den fra da av som kundeeid – fremtidige automatiske land-/bransje-oppdateringer for denne makroen blir da ikke lenger overtatt stille, men feiler med en konflikt inntil du løser avviket manuelt. Trenger du egen tilleggslogikk, opprett i stedet en ny makro med funksjon "Egendefinert" og tildel den målrettet til de berørte vaktene.

Kontrollstrukturer

Viktig: Nøkkelord som ENDIF, ENDFUNCTION, ENDSUB må skrives som ett ord (ikke END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "stor"
ELSEIF x > 5 THEN
    OUTPUT 1, "middels"
ELSE
    OUTPUT 1, "liten"
ENDIF

IF på én linje

IF x > 10 THEN OUTPUT 1, "stor" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Helg"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Hverdag"
    CASE ELSE
        OUTPUT 1, "Ukjent"
END SELECT

FOR-NEXT-løkke

FOR i = 1 TO 10
    sum += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

DO-LOOP-løkke

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Funksjoner og prosedyrer

Viktig: Funksjoner (FUNCTION) og prosedyrer (SUB) må defineres før det første kallet. Tolken leser koden fra topp til bunn: en funksjon eller prosedyre er først kjent etter at definisjonen er behandlet.

SUB (prosedyre uten returverdi)

SUB beregn(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (funksjon med returverdi)

FUNCTION doble(x)
    doble = x * 2
ENDFUNCTION

DIM resultat
resultat = doble(21)
OUTPUT 1, resultat

Returnering av verdier (OUTPUT)

OUTPUT type, verdi

type og verdi er to uttrykk atskilt med komma; begge er valgfrie (standard 0 hhv. "" hvis utelatt). En makro kan inneholde vilkårlig mange OUTPUT-linjer – hver genererer en egen returverdi. Klacks evaluerer bare følgende typer:

TypeBetydning
1Hovedresultat (timer hhv. totalbeløp) – tas med også ved verdi 0
10Nattillegg
11Tillegg for helgedag 1 (f.eks. lørdag)
12Tillegg for helgedag 2 (f.eks. søndag)
13Tillegg for helgedag 3 (tredje konfigurerbare helgedag)
14Helligdagstillegg

Tilleggslinjer (type 10-14) med verdi 0 ignoreres – en makro trenger altså ikke å skrive ut en egen linje for hver tilleggstype, kun for tillegg som faktisk gjelder. Verdier som ikke kan tolkes som tall, hoppes over.

Ved lagring blir makroen alltid kompilert og kjørt én gang prøvevis med nøytrale testverdier. Syntaks- og kjøretidsfeil (f.eks. ubalanserte parenteser eller et hengende uttrykk) vises da pålitelig i stedet for stille å føre til en funksjonsløs makro.

Eksempel: Tilleggsberegning ("AllShift")

Den medfølgende standardmakroen for kategorien "Vakt". Beregner tillegg for natt, helligdag og de tre konfigurerbare helgedagene med korrekt håndtering av vakter som krysser midnatt (segmentdeling), og bruker den høyeste gjeldende satsen per segment (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Forklaring

  • Segmentdeling: For vakter som krysser midnatt (f.eks. 22:00-06:00) deles vakten i to segmenter (frem til midnatt / fra midnatt), hver med sitt eget ukedag-/helligdagsflagg
  • SegBonusForType: Beregner tillegget for et segment og en bestemt tilleggstype (10-14) med hensyn til natt-, helligdags- og helgetillegg
  • WE1/WE2/WE3 i stedet for lørdag/søndag: weekendday1-3 gjør helgedagene konfigurerbare (ikke alle land har lørdag/søndag som helg)
  • Høyeste tillegg per segment: NRate/DRate finner henholdsvis den høyeste gjeldende satsen for natt- og dagtimer – highest-wins, ingen stabling
  • HolidayNextDay: Tar hensyn til om neste dag er en helligdag (viktig for nattevakter over midnatt)
  • Flere OUTPUT-linjer: Linje 1 gir totalsummen, linjene 10-14 gir de enkelte tilleggsbeløpene (se avsnittet "Returnering av verdier")

Den additive varianten ("AllShiftAdditive")

Standard-(additiv)-makroen i samme kategori har identiske IMPORT-linjer og samme rammestruktur – kun SegBonusForType er forskjellig: i stedet for den høyeste satsen beregnes det uavhengig for hver tilleggstype om den gjelder, og alle gjeldende beløp summeres til slutt (ikke lenger highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Faller en nattevakt f.eks. også på en helligdag, får den med "AllShift" kun den høyere av de to satsene, mens den med "AllShiftAdditive" derimot får natt- og helligdagstillegg samlet. Resten av skriptet (segmentdeling, summering, OUTPUT-linjer) er identisk med "AllShift" ovenfor.
