LLM-palveluntarjoajien haku — Ohje

Mihin tätä toimintoa käytetään?

Tämä näkymä ehdottaa sinulle LLM-palveluntarjoajia, joita ei vielä ole listallasi, ja lisää valitut yhdellä napsautuksella. Näin sinun ei tarvitse kirjoittaa nimeä ja perus-URL:ää käsin. Ehdolle tulevat yksinomaan OpenAI-yhteensopivat API-palveluntarjoajat — siis juuri sellaiset palvelut, joita jo käyttöön otetut palveluntarjoajasi käyttävät.

Taulukon sarakkeet

Palveluntarjoajan nimi

Palveluntarjoajan näyttönimi (esim. "OpenRouter", "xAI (Grok)").

Perus-URL

API-osoite, jonka kautta palveluntarjoajan kanssa kommunikoidaan (esim. https://api.x.ai/v1/). Juuri tätä URL-osoitetta käytetään myöhemmin luontivaiheessa.

Lähde

Ilmaisee, mistä ehdotus on peräisin:

  • Luettelo — kiinteästi tallennetusta, tarkistetusta luettelosta tunnettuja palveluntarjoajia. Perus-URL:t on varmennettu ja siten luotettavia.
  • Web — löydetty internet-haulla ja arvioitu automaattisesti. Nämä merkinnät näkyvät vain, jos verkkohaku on määritetty asetuksissa. Ne ovat hyödyllisiä, mutta epäselvissä tapauksissa perus-URL kannattaa tarkistaa lyhyesti.

Tavoitettavuus

Ennen näyttämistä jokainen ehdotus testataan reaaliaikaisesti (kutsutaan /models-päätepistettä):

  • Tavoitettavissa — API vastaa, palveluntarjoaja toimii.
  • Tavoitettavissa (avain tarvitaan) — API on olemassa, mutta vaatii API-avaimen. Osoite on siis oikein.
  • Ei tavoitettavissa — osoite ei vastaa. Tällaisia merkintöjä ei voi valita.

Palveluntarjoajan lisääminen

Merkitse valintaruutu yhden tai useamman palveluntarjoajan kohdalle ja napsauta alla "Lisää valinta". Valitut palveluntarjoajat luodaan poistettuina käytöstä ja ilman API-avainta. Jo olemassa olevia palveluntarjoajia ei edes ehdoteta.

Seuraavat vaiheet lisäämisen jälkeen

Vasta lisätty palveluntarjoaja ei ole vielä aktiivinen. Avaa se listalta, syötä API-avain ja aktivoi se. Sen jälkeen se toimii aivan kuten muutkin palveluntarjoajasi. Palveluntarjoajan yksittäisiä malleja hallinnoit edelleen erikseen mallien hallinnan kautta.
