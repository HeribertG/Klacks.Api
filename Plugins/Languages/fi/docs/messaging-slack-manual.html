Slackin käyttöönotto

Edellytykset

Lähettääksesi ja vastaanottaaksesi viestejä Slackin kautta Klacksilla tarvitset Slack-työtilan ja Slack-sovelluksen, jolla on tarvittavat käyttöoikeudet. Klacks käyttää Slack Web API:a lähetykseen ja Events API:a vastaanottoon.

Huomio: Ilmainen Slack-tilaustyyppi riittää liitäntään. Slack-sovellukset luodaan osoitteessa api.slack.com ja ovat maksuttomia.

Vaihe 1 — Slack-sovelluksen luonti

  1. Avaa api.slack.com/apps ja napsauta Create New App.
  2. Valitse From scratch ja anna nimi (esim. Klacks Bot).
  3. Valitse työtila, johon sovellus asennetaan.
  4. Siirry kohtaan OAuth & Permissions ja lisää seuraavat Bot Token Scopes:
    • chat:write — viestien lähettämiseen kanaville
    • im:write — suorien viestien lähettämiseen käyttäjille
  5. Napsauta Install to Workspace ja vahvista käyttöoikeudet.
  6. Merkitse muistiin Bot User OAuth Token (alkaa merkeillä xoxb-).
  7. Siirry kohtaan Basic Information ja merkitse muistiin Signing Secret.

Vaihe 2 — Slackin määrittäminen Klacksissa

  1. Siirry kohtaan Asetukset → Viestintäpalveluntarjoajat.
  2. Napsauta Lisää.
  3. Täytä kentät seuraavasti:

Vaihe 3 — Viestien lähetys chatbotin (Klacksy) kautta

Kun Slack-palveluntarjoaja on määritetty ja aktivoitu, chatbot Klacksy voi lähettää viestejä Slackin kautta. Käytä työntekijän nimeä tai kanavan nimeä: 

"Lähetä viesti Max Musterille: Tapaamisesi on huomenna klo 14:00."
"Lähetä Anna Beispielille viesti: Vuoro on vaihdettu."
"Julkaise kanavalle #team-updates: Ensi viikon työvuorolistat ovat valmiit."

Vastaanottajana toimii kanava-ID (esim. C0123456789) tai käyttäjä-ID (esim. U0123456789) — käyttäjä-ID:llä lähetetään suora viesti. Jos vastaanottajaa ei ole määritetty, käytetään määritettyä oletuskanavaa. Lähetys on sinulle täysin läpinäkyvä — työskentelet nimillä, Klacksy hoitaa loput.

Edellytys: Slack-käyttäjä on liitettävä vastaavaan Klacks-yhteystietoon (kohdassa Osoite → Yhteystiedot). Kanavaviestejä varten botti on kutsuttava kyseiseen kanavaan (/invite @Klacks Bot).

Vaihe 4 — Saapuvien viestien vastaanotto (Events API)

Jotta saapuvat Slack-viestit näkyvät Klacksissa, Slack-sovelluksen Events API on määritettävä. Tallenna ja aktivoi palveluntarjoaja Klacksissa ennen kuin syötät Request-URL:n — Slack tarkistaa osoitteen välittömästi Challenge-pyynnöllä, johon Klacks vastaa automaattisesti.

  1. Avaa Slack-sovelluksesi osoitteessa api.slack.com/apps ja siirry kohtaan Event Subscriptions.
  2. Aktivoi Enable Events ja syötä Request URL -kenttään Klacksissa näytetty webhook-osoite: 
    https://{ihre-domain}/api/messaging/webhook/slack
  3. Tilaa kohdassa Subscribe to bot events tapahtumat message.im (suorat viestit) ja message.channels (kanavaviestit).
  4. Tallenna muutokset ja asenna sovellus pyydettäessä uudelleen työtilaan.
  5. Saapuvat viestit näkyvät nyt reaaliajassa viestintäpalvelun saapuvat-kansiossa. Klacks tarkistaa tällöin jokaisen pyynnön allekirjoituksen tallennetulla Signing-secretillä.
