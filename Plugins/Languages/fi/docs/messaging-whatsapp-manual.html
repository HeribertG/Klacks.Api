WhatsAppin käyttöönotto

Edellytykset

Lähettääksesi ja vastaanottaaksesi viestejä WhatsAppin kautta Klacksilla tarvitset Meta-kehittäjätilin ja Meta-sovelluksen, jossa WhatsApp-tuote on aktivoitu. Klacks käyttää lähetykseen Meta-yritysalustan WhatsApp Cloud API:a ja vastaanottoon Meta-webhookeja.

Huomio: Käyttöönotosta ja testaamisesta ei aiheudu kustannuksia. Sovellusta luotaessa Meta tarjoaa automaattisesti maksuttoman testipuhelinnumeron.

Tärkeää — lähettäjänumero ei ole yksityinen numerosi. Puhelinnumeroa, joka on jo käytössä tavallisessa WhatsApp-sovelluksessa, ei voi rekisteröidä Cloud API:lle, eikä rekisteröityä numeroa voi enää käyttää WhatsApp Messenger -sovelluksessa. Käytä siksi Metan tarjoamaa testinumeroa tai omaa, ainoastaan liiketoimintakäyttöön tarkoitettua numeroa. Matkapuhelimesi yksityinen WhatsApp toimii testauksessa vastaanottajana — ei lähettäjänä.

Vaihe 1 — Meta-sovelluksen luonti

  1. Avaa developers.facebook.com/apps ja napsauta Create app.
  2. Valitse käyttötapaukseksi Other ja sovellustyypiksi Business.
  3. Napsauta hallintapaneelissa tuotteen WhatsApp kohdalla Set up. Samalla luodaan ja rekisteröidään automaattisesti testipuhelinnumero.
  4. Siirry vasemmasta navigaatiosta kohtaan WhatsApp → API Setup.
  5. Merkitse muistiin Phone number ID ja luo käyttöoikeustunnus kohdasta Generate access token.
  6. Merkitse muistiin kohdasta App settings → Basic tieto App Secret — sitä tarvitaan saapuvien viestien allekirjoituksen tarkistukseen.

Huomaa — kaksi samankaltaista tunnusta: API-Setup-paneelissa Phone number ID ja WhatsApp Business Account ID ovat suoraan allekkain. Klacks tarvitsee tunnuksen Phone number ID. Väärällä tunnuksella yhteystesti ilmoittaa silti onnistumisesta, mutta jokainen lähetys epäonnistuu.

Huomaa — tokenin voimassaoloaika: Kohdasta Generate access token luotu token on tilapäinen testitoken ja vanhenee lyhyen ajan kuluttua. Jatkuvaa käyttöä varten luo Meta Business Managerissa pysyvä token järjestelmäkäyttäjän kautta.

Vaihe 2 — Vastaanottajanumeron hyväksyntä

Testinumerolla saa lähettää vain etukäteen hyväksytyille vastaanottajille. Lisää API Setup -paneelissa kohdassa To → Manage phone number list oma WhatsApp-numerosi. Meta lähettää tähän numeroon vahvistuskoodin, joka sinun on syötettävä.

Ilman tätä vaihetta Meta hylkää jokaisen lähetyksen kyseiseen numeroon. Kun otat myöhemmin käyttöön oman, vahvistetun yritysnumeron, hyväksyntää ei enää tarvita.

Vaihe 4 — 24 tunnin ikkuna

WhatsApp eroaa tässä olennaisesti Telegramista tai Slackista. Vapaita tekstiviestejä yritys saa lähettää vain niin kauan kuin asiakaspalveluikkuna on auki. Tämän ikkunan avaa vastaanottaja lähettämällä viestin WhatsApp-numeroosi. Ikkuna pysyy auki 24 tuntia ja pitenee jokaisesta vastaanottajan uudesta viestistä.

Tämän ikkunan ulkopuolella Meta sallii ainoastaan etukäteen hyväksytyt viestipohjat. Klacks lähettää tällä hetkellä ainoastaan vapaita tekstiviestejä, joten se ei voi avata keskustelua oma-aloitteisesti.

Mitä tämä tarkoittaa sinulle: Pyydä työntekijöitäsi lähettämään kerran viesti Klacksin WhatsApp-numeroon. Sen jälkeen lähettäminen on mahdollista 24 tunnin ajan, ja jokainen vastaus pidentää ikkunaa. Jos ikkuna on kiinni, lähetys ilmoittaa virheestä — kyseessä ei ole määritysongelma vaan WhatsAppin sääntö.

Jos sinun on tavoitettava työntekijöitä tästä ikkunasta riippumatta, paremmat palveluntarjoajat ovat Telegram tai Signal — niissä tätä rajoitusta ei ole.

Vaihe 5 — Viestien lähetys chatbotin (Klacksy) kautta

Kun WhatsApp-palveluntarjoaja on määritetty ja aktivoitu, chatbot Klacksy voi lähettää viestejä WhatsAppin kautta. Käytä työntekijän nimeä: 

"Lähetä viesti Max Musterille: Tapaamisesi on huomenna klo 14:00."
"Lähetä Anna Beispielille viesti: Vuoro on vaihdettu."

Vastaanottajana toimii puhelinnumero kansainvälisessä muodossa ilman alkunollaa ja ilman plusmerkkiä (esim. 41791234567 numerolle 079 123 45 67). Lähetys on sinulle täysin läpinäkyvä — työskentelet nimillä, Klacksy hoitaa loput.

Edellytys: WhatsApp-numero on liitettävä vastaavaan Klacks-yhteystietoon (kohdassa Osoite → Yhteystiedot), ja vaiheen 4 24 tunnin ikkunan on oltava auki.

Vaihe 6 — Saapuvien viestien vastaanotto (webhookit)

Jotta saapuvat WhatsApp-viestit näkyvät Klacksissa, Meta-sovelluksen webhook on määritettävä. Tallenna ja aktivoi palveluntarjoaja Klacksissa ennen kuin syötät Callback-osoitteen — Meta tarkistaa osoitteen välittömästi vahvistuspyynnöllä, johon Klacks vastaa automaattisesti Verify-tokenin perusteella.

  1. Avaa Meta-sovelluksesi ja siirry kohtaan WhatsApp → Configuration.
  2. Napsauta kohdassa Webhook painiketta Edit ja syötä:
    • Callback URL: Klacksissa näytetty webhook-osoite 
      https://{verkkotunnuksesi}/api/messaging/webhook/whatsapp
    • Verify token: täsmälleen sama arvo, jonka syötit vaiheessa 3 kenttään Verify-token
  3. Napsauta Verify and save.
  4. Tilaa kohdassa Webhook fields kenttä messages.
  5. Saapuvat viestit näkyvät nyt reaaliajassa viestintäpalvelun saapuvat-kansiossa. Klacks tarkistaa tällöin jokaisen pyynnön allekirjoituksen (X-Hub-Signature-256) tallennetulla App-secretillä.

Callback-osoitteen on oltava tavoitettavissa ulkopuolelta HTTPS-yhteydellä. Jos asennus on yrityksen sisäverkossa ilman julkista osoitetta, lähettäminen toimii, mutta viestejä ei voi vastaanottaa.
