Signal-viestinnän käyttöönotto

Edellytykset

Lähettääksesi Signal-viestejä Klacksin kautta tarvitset itse ylläpidetyn signal-cli-rest-api-instanssin. Kyseessä on avoimen lähdekoodin projekti, joka tekee Signalista käytettävän REST-rajapinnan kautta.

  • Dockerin on oltava asennettuna palvelimelle
  • Puhelinnumero, joka rekisteröidään Signaliin (suositellaan omistettua numeroa)
  • Docker-image: bbernhard/signal-cli-rest-api

Tärkeää: Signal-liitäntä on suunniteltu vain lähetykseen. Saapuvia Signal-viestejä ei vastaanoteta Klacksissa.

Vaihe 1 — signal-cli-rest-apin käyttöönotto

  1. Käynnistä kontti Dockerilla: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Liitä Signal-numerosi QR-linkkimenetelmällä: Avaa selaimessa 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    ja skannaa näytetty QR-koodi Signal-sovelluksella puhelimessa, johon numero on rekisteröity (Asetukset → Linkitetyt laitteet → Linkitä laite). Kontti liitetään näin toissijaiseksi laitteeksi.
  3. Vaihtoehtoisesti voit rekisteröidä numeron itsenäisesti rajapinnan kautta — lisätietoja löydät projektin dokumentaatiosta.
  4. Testaa rajapinta terveystarkastuksella: 
    curl http://localhost:8080/v1/about

Huomio: Lisätietoja määrityksestä löydät signal-cli-rest-api-dokumentaatiosta.

Vaihe 3 — Viestien lähetys chatbotin (Klacksy) kautta

Kun Signal-palveluntarjoaja on määritetty ja aktivoitu, chatbot Klacksy voi lähettää viestejä. Sinun ei tarvitse tietää puhelinnumeroita — käytä yksinkertaisesti työntekijän tai asiakkaan nimeä: 

"Lähetä viesti Max Musterille: Tapaamisesi on huomenna klo 14:00."
"Lähetä Anna Beispielille Signal-viesti: Vuoro on vaihdettu."
"Ilmoita Peter Müllerille, että hänen vuoronsa maanantaina peruuntuu."

Klacksy hakee automaattisesti vastaanottajalle tallennetun matkapuhelinnumeron ja käyttää määritettyä Signal-palveluntarjoajaa. Lähetys on sinulle täysin läpinäkyvä — työskentelet nimillä, Klacksy hoitaa loput.

Edellytys: Vastaanottajalle on tallennettava matkapuhelinnumero Klacksiin (kohdassa Osoite → Yhteystiedot) kansainvälisessä muodossa (esim. +41791234567). Myös joukkoviesteissä Signal-lähetys käyttää tallennettua matkapuhelinnumeroa.

Saapuvat viestit

Signal-liitäntä ei tue vastaanottoa — vastauksia lähetettyihin viesteihin ei välitetä Klacksiin. Viestintäpalvelun saapuvat-kansio ei siksi näytä saapuvia viestejä tälle palveluntarjoajalle.
