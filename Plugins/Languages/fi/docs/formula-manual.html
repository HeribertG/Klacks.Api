Kaavakentän käyttöopas

Perussyntaksi

Jokainen kaavakenttä tulostaa tuloksen output-komennolla:

output 1, <lauseke>

Ensimmäinen parametri 1 on viestityyppi ja sen on aina oltava 1. Toinen parametri on tulostettava arvo.

Yksinkertaisia esimerkkejä:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " riviä"

Käytettävissä olevat muuttujat

Käytettävissä olevat muuttujat on lueteltu Muuttujat-välilehdellä, jossa niille voi myös asettaa testiarvoja. Raporttityypistä riippuen käytettävissä on erilaisia muuttujia:

Ehdollinen logiikka

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "paljon rivejä"
ELSEIF totalRows > 0 THEN
    output 1, "muutama rivi"
ELSE
    output 1, "ei rivejä"
ENDIF

Yksirivinen IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (lyhyt muoto)

output 1, IIF(totalRows > 0, "OK", "Tyhjä")

Muuttujat ja silmukat

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Käytännön esimerkkejä

Rivien määrä tekstin kanssa

output 1, CStr(totalRows) & " riviä"

Pyöristetty arvo (1 desimaali)

output 1, CStr(Round(totalValue, 1))

Tunnit muodossa h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Ehdollinen tulostus

IF totalRows = 0 THEN
    output 1, "Ei poissaoloja"
ELSE
    output 1, CStr(totalRows) & " poissaoloa (yhteensä: " & CStr(totalValue) & ")"
ENDIF

Keskiarvon laskeminen

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/päivä"
ELSE
    output 1, "-"
ENDIF
Huomautus: Skriptitulkki toimii suojatussa hiekkalaatikossa ilman pääsyä tiedostojärjestelmään tai verkkoon.
