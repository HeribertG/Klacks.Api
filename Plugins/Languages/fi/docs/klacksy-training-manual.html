Klacksy-koulutus - käyttöohje

Mikä on koulutustyökalu?

Koulutustyökalu ohjaa chatbot Klacksyn sivunsisäistä navigointia. Kun käyttäjä sanoo tai kirjoittaa "Klacksy, näytä minulle osoitteet", Klacksy siirtyy oikealle sivulle ja vierittää näkymän oikeaan kohtaan.

Jotta tämä toimisi, Klacksy tarvitsee jokaiselle sivun ankkurille listan synonyymeja jokaisella kielellä (esim. "Osoitteet", "Asiakkaat", "Kontaktit" kohteelle addresses).

Välilehti "Kohteet"

Luettelo kaikista frontendista löydetyistä ankkureista (HTML-attribuutit data-klacksy-target). Tila-suodattimet:

  • pending: Ankkuri on olemassa, mutta synonyymeja ei vielä ole
  • generated: Synonyymit on generoitu automaattisesti, ne vaativat tarkistuksen
  • reviewed: Synonyymit hyväksytty pääkäyttäjän toimesta
  • needs-review: Merkitty uudelleentarkistusta varten

Kohteen napsauttaminen avaa synonyymieditorin sen alapuolella. Siellä voidaan lisätä ja poistaa synonyymeja sekä hyväksyä ne painikkeella "Tallenna tarkistettuna".

Välilehti "Palautteet"

Näyttää käyttäjän syötteet, joita Klacksy ei pystynyt kohdistamaan (sopivaa synonyymia ei löytynyt). Tämän listan avulla voidaan huomata, mitkä synonyymit vielä puuttuvat.

Välilehti "Mittarit"

Yleiskatsaus kaikkiin kohteisiin tilan mukaan. Auttaa seuraamaan koulutuksen edistymistä.

Build-putki (CLI)

Kun malleihin (templates) on lisätty uusia data-klacksy-target-ankkureita, manifesti ja alkuperäiset synonyymit täytyy generoida uudelleen. Seuraavat komennot ajetaan myös automaattisesti CI:ssä ja Husky-pre-commitissa: 

cd C:\SourceCode\Klacks.Ui

# 1. Skannaa mallit → navigation-targets.json kaikkine ankkureineen
npm run scan:targets

# 2a. Generoi alkuperäiset synonyymit (kaikki 4 ydinkieltä + 22 plugin-kieltä, ~2,5 h)
npm run generate:synonyms

# 2b. Vain ydinkielet (de/en/fr/it) — nopea, n. 9 min
npm run generate:synonyms -- --core-only

# 2c. Täydennä vain puuttuvat plugin-kielet — n. 45 min
npm run generate:synonyms -- --plugins-only

# 3. Tarkista herätyssanan (wake-word) yhdenmukaisuus
npm run wake-word-lint

Tärkeää: npm run-komennossa täytyy olla --, jotta valitsimet välitetään skriptille. Ilman --:aa npm nielaisee lipun (flag) ja skripti ajetaan oletustilassa.

Vaihtoehto ilman npm:ää: npx tsx tools/generate-synonyms.ts --core-only.

API-avain

LLM-API-avainta etsitään seuraavassa järjestyksessä:

  1. Ympäristömuuttuja SYNONYM_LLM_API_KEY
  2. Tietokantataulu llm_providers (palveluntarjoaja deepseek, is_enabled = true) — automaattisesti psql-kutsun kautta
  3. Muutoin virheilmoitus

Oletuspalveluntarjoaja on DeepSeek. Toinen palveluntarjoaja asetuksella SYNONYM_LLM_PROVIDER_ID=anthropic (tai jokin muu asetuksiin määritetty LLM-palveluntarjoaja).

Vaihe 1 - scan:targets

Käy läpi kaikki Angular-mallit ja etsii data-klacksy-target-attribuutit, ja luo manifestin Application/Skills/Definitions/navigation-targets.json. Jokainen uusi ankkuri ilmestyy tämän jälkeen välilehdelle "Kohteet" tilassa pending.

Vaihe 2 - generate:synonyms

Luo jokaiselle uudelle ankkurille alustavat synonyymit data-klacksy-label-key-arvon ja kategorian perusteella. Tila tämän jälkeen: generated (pääkäyttäjän on tarkistettava).

Skripti kirjoittaa manifestin tarkistuspisteitä (checkpoints) 5 kohteen välein, jotta keskeytys ei hukkaa jo generoitua dataa.

Vaihe 3 - wake-word-lint

Tarkistaa herätyssanan (Hei Klacksy / Hey Klacksy / ...) muunnelman yhdenmukaisuuden kaikkien kielten kesken. Estää synonyymejä korvaamasta herätyssanaa.

Ääni-tila (Voice-Mode)

Mikrofonikuvake chatissa aktivoi ääni-tilan. Kun se on aktiivinen:

  • Mikrofoni kuuntelee jatkuvasti ja litteroi puhetta
  • Lyhyen hiljaisuuden jälkeen → tähänastinen litterointi lähetetään automaattisesti

Tärkeää: Heti kun alat kirjoittaa tekstikenttään, ääni-tila päättyy automaattisesti — muuten mikrofoni korvaisi kirjoittamasi tekstin omilla litteroinneillaan ja lähettäisi viestin ennenaikaisesti.

Tyypillinen koulutuskierto

  1. Lisää ankkuri malliin: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Käynnistä API uudelleen (välimuisti luetaan uudelleen käynnistyksen yhteydessä)
  4. Avaa välilehti "Kohteet" → uudet kohteet ilmestyvät tilassa generated
  5. Tarkista/täydennä synonyymit → "Tallenna tarkistettuna" → tila reviewed
  6. Testaa Klacksyn kanssa, esim. "Klacksy, näytä minulle osoitteet"
  7. Jos Klacksy ei tunnista → välilehti "Palautteet" → lisää puuttuva synonyymi
  8. Seuraa välilehteä "Mittarit", kunnes kaikki on tilassa reviewed
