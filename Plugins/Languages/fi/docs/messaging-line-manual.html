LINE-viestinnän käyttöönotto

Edellytykset

Lähettääksesi ja vastaanottaaksesi viestejä LINEn kautta tarvitset LINE Official Account -tilin, jolla on Messaging API -kanava LINE Developers Consolessa. LINE on erityisen suosittu Japanissa, Taiwanissa ja Thaimaassa.

Huomio: Push-viesteillä on LINE-tilaustyypistä riippuen kuukausittainen kiintiö (ilmainen tilaustyyppi on rajoitettu). Tarkista Official Account -tilaustyyppisi voimassa olevat ehdot.

Vaihe 1 — LINE Official Account -tilin ja Messaging API -kanavan luonti

  1. Luo LINE Official Account -tili (LINE Official Account Managerin kautta).
  2. Avaa LINE Developers Console (developers.line.biz) ja luo Messaging API -kanava tai liitä Official Account -tilisi Messaging API:iin.
  3. Anna Messaging API -välilehdellä pitkäikäinen Channel-access-token (Issue).
  4. Merkitse muistiin Channel-secret välilehdeltä Basic Settings.

Huomio: Käsittele channel-access-tokenia ja channel-secretiä kuten salasanoja. Älä jaa niitä julkisesti ja säilytä ne turvallisesti.

  2. Napsauta Lisää.

Vaihe 3 — Viestien lähetys chatbotin (Klacksy) kautta

Kun LINE-palveluntarjoaja on määritetty ja aktivoitu, chatbot Klacksy voi lähettää viestejä. Sinun ei tarvitse tietää LINE-käyttäjätunnuksia — käytä yksinkertaisesti työntekijän tai asiakkaan nimeä: 

"Lähetä viesti Max Musterille: Tapaamisesi on huomenna klo 14:00."
"Lähetä Anna Beispielille viesti: Vuoro on vaihdettu."
"Ilmoita Peter Müllerille, että hänen vuoronsa maanantaina peruuntuu."

Klacksy hakee automaattisesti vastaanottajalle tallennetun LINE-käyttäjätunnuksen ja käyttää määritettyä LINE-palveluntarjoajaa. Lähetys on sinulle täysin läpinäkyvä — työskentelet nimillä, Klacksy hoitaa loput.

Edellytys: Vastaanottajalle on tallennettava LINE-käyttäjätunnus (alkaa kirjaimella U…) Klacksiin (kohdassa Osoite → Yhteystiedot). Käyttäjätunnus tulee tietoon saapuvien viestien kautta (näkyvissä viestintäpalvelun saapuvat-kansiossa) — tätä varten vastaanottajan on täytynyt lisätä Official Account -tilisi ystäväkseen ja lähettää sille viesti.

Vaihe 4 — Saapuvien viestien vastaanotto (webhook)

Jotta saapuvat LINE-viestit näkyvät Klacksissa, webhook-osoite on syötettävä manuaalisesti LINE Developers Consoleen.

  1. Kopioi Klacksissa näytetty webhook-osoite palveluntarjoaja-asetuksista: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. Syötä tämä osoite LINE Developers Consolessa kohtaan Messaging API → Webhook settings kentäksi Webhook URL.
  3. Aktivoi asetus „Use webhook".
  4. Varmista, että Klacks-instanssisi on julkisesti tavoitettavissa HTTPS:n kautta.
  5. Saapuvat viestit näkyvät nyt reaaliajassa viestintäpalvelun saapuvat-kansiossa.
