设置 KakaoTalk 消息

前提条件

要通过KakaoTalk发送消息，您需要在 developers.kakao.com（Kakao Developers）上拥有一个应用。KakaoTalk是 韩国占主导地位的通讯应用。Klacks对接使用Kakao开发者API （"向好友发送消息"）。

Kakao开发者API的重要限制：

  • 该对接仅设计用于发送 — 不支持接收。
  • 访问令牌生命周期短（约6小时），必须在 Klacks之外续期并重新保存。
  • 消息只能发送给已作为 该应用的Kakao"好友"并同意接收消息的用户。
  • 对于韩国的正式商用消息（AlimTalk），需要通过授权 代理商开通商用渠道 — 本对接不涵盖此项， 本对接使用的是开发者API。

步骤1 — 设置 Kakao Developers 应用

  1. 在developers.kakao.com上创建一个应用。
  2. 为该应用启用Kakao登录。
  3. 开通talk_message和friends作用域。
  4. 通过Kakao登录的OAuth流程获取访问令牌 （以其名义发送消息的用户必须同意这些作用域）。

提示：请像对待密码一样对待访问令牌。 不要公开分享，并妥善保存。

步骤2 — 在 Klacks 中配置 KakaoTalk

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称kakaotalk-main
显示名称会在界面中显示KakaoTalk
提供商类型选择KakaoTalkKakaoTalk
访问令牌通过OAuth流程获取的令牌kakao-access-token...
已启用启用/禁用该提供商是
  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。

重要提示：访问令牌大约6小时后过期。 Klacks不会自动续期 — 您必须在外部（通过Kakao的 刷新令牌流程）续期，并在Klacks中重新保存。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦KakaoTalk提供商配置并启用，聊天机器人Klacksy就可以 发送消息。您不需要知道任何ID — 只需 使用员工或客户的姓名： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条消息：班次已经调换了。"
"通知李大同，他周一的班次取消了。"

Klacksy会自动查找已保存的收件人标识，并 使用已配置的KakaoTalk提供商。发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：收件人必须在Klacks中保存来自Kakao好友API的 好友UUID（在地址 → 联系数据下）。 收件人必须作为Kakao"好友"与该应用连接 — 无法向其他用户 发送消息。

传入消息

KakaoTalk对接不支持接收 — 对已发送消息的回复 不会传输到Klacks。因此消息收件箱不会为该 提供商显示任何传入消息。

故障排除

问题可能原因解决方法
连接测试失败 访问令牌已过期（有效期约6小时） 通过Kakao OAuth流程续期令牌并重新保存
消息未送达 收件人不是该应用的Kakao"好友" 收件人必须通过Kakao登录与该应用建立连接并同意该作用域
找不到收件人 未保存好友UUID 通过好友API获取UUID并在地址 → 联系数据下填写
发送因权限错误被拒绝 talk_message或friends作用域未开通 在developers.kakao.com上检查该应用的作用域设置
无法进行正式的批量发送 开发者API不涵盖AlimTalk 在韩国进行商用消息发送需要通过授权代理商开通商用渠道
