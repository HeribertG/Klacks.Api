设置 SMS 提供商

前提条件

要通过Klacks发送SMS消息，您需要一个Twilio 账户，或一个兼容Twilio的SMS网关。Klacks使用 Twilio REST API（带有基本身份验证的Messages端点）。

重要提示：SMS对接仅设计用于发送。 Klacks不接收传入的SMS。

步骤1 — 设置 Twilio 账户

  1. 在twilio.com上注册，并验证您的 电话号码和电子邮件地址。
  2. 打开Twilio Console。在仪表盘的 Account Info下可以找到所需的两项凭据：
    • Account SID — 以AC开头
    • Auth Token — 点击"显示"
  3. 在Phone Numbers → Buy a number下 购买一个发件人号码（支持SMS）。 该号码将作为发件人显示在发出的SMS中。
  4. 测试账户：使用免费试用账户时，SMS只能发送到 预先验证过的号码，并会附带试用提示。

提示：请像对待密码一样对待Auth Token。 不要公开分享，并妥善保存。

步骤2 — 在 Klacks 中配置 SMS 提供商

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称sms-twilio
显示名称会在界面中显示SMS (Twilio)
提供商类型选择SMSSMS
Account SID来自Twilio Console的Account SIDACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Auth Token来自Twilio Console的Auth Tokena1b2c3d4e5f6...
发件人号码您购买的电话号码（国际格式）+41791234567
网关URL（可选）仅适用于兼容Twilio的替代网关 — 使用Twilio时留空https://api.twilio.com
已启用启用/禁用该提供商是
  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。

关于网关URL的提示：如果您使用Twilio，请将该字段留空 — Klacks会自动使用https://api.twilio.com。仅当您使用 具有兼容Twilio的API的替代网关时，才需要填写URL。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦SMS提供商配置并启用，聊天机器人Klacksy就可以 发送消息。您不需要知道电话号码 — 只需 使用员工或客户的姓名： 

"给王小明发一条短信：您的预约是明天下午2点。"
"给陈小华发一条短信：班次已经调换了。"
"通过短信通知李大同，他周一的班次取消了。"

Klacksy会自动查找已保存的收件人手机号码，并 使用已配置的SMS提供商。发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：收件人必须在Klacks中保存手机号码 （在地址 → 联系数据下），采用国际格式（例如：+41791234567）。

传入消息

SMS对接不支持接收 — 对已发送SMS的回复 不会传输到Klacks。因此消息收件箱不会为该 提供商显示任何传入消息。

故障排除

问题可能原因解决方法
连接测试失败 Account SID或Auth Token有误 在Twilio Console的仪表盘上检查这两个值
短信未送达 发件人号码不支持SMS或未开通 在Twilio Console的Phone Numbers下检查该号码
收件人未收到短信（试用账户） 收件人号码未验证 在Twilio Console中验证该号码，或升级到付费账户
收件人未收到短信 电话号码不是国际格式 使用格式+{国家区号}{号码}（例如：+41791234567）
错误"Permission to send an SMS has not been enabled" 目标国家在地理权限中未开通 在Twilio Console的Messaging → Geographic Permissions下启用该国家
账户余额已用尽 按量付费预算已耗尽 在Twilio Console中充值
