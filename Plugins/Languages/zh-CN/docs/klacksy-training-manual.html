Klacksy 训练 - 使用说明

什么是训练工具？

训练工具控制着聊天机器人Klacksy的页内导航。当用户说 "Klacksy 给我看看地址"时，Klacksy会导航到相应的页面 并滚动到相应的区域。

为了让这一切正常工作，Klacksy需要为页面上的每个锚点在每种语言中 提供一份同义词列表（例如："地址"、"客户"、"联系人" 对应目标addresses）。

"目标"选项卡

显示在前端中找到的所有锚点列表（HTML属性data-klacksy-target）。 状态筛选：

  • pending（待处理）：锚点存在，但尚无同义词
  • generated（已生成）：同义词已自动生成，需要审核
  • reviewed（已审核）：同义词已由管理员批准
  • needs-review（需要审核）：已标记为需要重新审核

点击一个目标会打开下方的同义词编辑器。在那里可以 添加、删除同义词，并通过"保存为已审核"进行批准。

"反馈"选项卡

显示Klacksy无法匹配的用户输入（未找到匹配的 同义词）。通过此列表可以识别哪些同义词仍然缺失。

"指标"选项卡

按状态显示所有目标的概览。有助于跟踪训练进度。

构建流水线（CLI）

如果模板获得了新的data-klacksy-target锚点，则必须 重新生成清单和初始同义词。以下命令也会在CI和Husky 预提交钩子中自动运行： 

cd C:\SourceCode\Klacks.Ui

# 1. 扫描模板 → 生成包含所有锚点的 navigation-targets.json
npm run scan:targets

# 2a. 生成初始同义词（全部4种核心语言 + 22种插件语言，约2.5小时）
npm run generate:synonyms

# 2b. 仅核心语言（de/en/fr/it）— 快速，约9分钟
npm run generate:synonyms -- --core-only

# 2c. 仅补充缺失的插件语言 — 约45分钟
npm run generate:synonyms -- --plugins-only

# 3. 检查唤醒词一致性
npm run wake-word-lint

重要提示：使用npm run时必须加上--，以便 选项传递给脚本。如果没有--，npm会吞掉该标志， 脚本会以默认模式运行。

不使用npm的替代方式：npx tsx tools/generate-synonyms.ts --core-only。

API密钥

LLM API密钥会按以下顺序查找：

  1. 环境变量SYNONYM_LLM_API_KEY
  2. 数据库表llm_providers（提供商deepseek， is_enabled = true）— 通过psql调用自动获取
  3. 否则报错

默认提供商为DeepSeek。可通过 SYNONYM_LLM_PROVIDER_ID=anthropic使用其他提供商（或设置中 已配置的其他LLM提供商）。

步骤1 - scan:targets

搜索所有Angular模板中的data-klacksy-target属性，并 生成清单Application/Skills/Definitions/navigation-targets.json。 之后每个新锚点都会在"目标"选项卡中以pending状态出现。

步骤2 - generate:synonyms

根据data-klacksy-label-key和类别为每个新锚点 生成初始同义词。之后状态为：generated（需管理员审核）。

脚本每处理5个目标就会写入一次清单检查点，因此中断不会 丢失已生成的数据。

步骤3 - wake-word-lint

检查所有语言中唤醒词变体（Hallo Klacksy / Hey Klacksy / ...）的 一致性。防止同义词覆盖唤醒词。

语音模式

聊天中的麦克风图标可激活语音模式。一旦激活：

  • 麦克风持续聆听并连续转录
  • 短暂静默后 → 自动发送迄今为止的转录内容

重要提示：一旦你开始在文本框中输入，语音模式会 自动结束 — 否则麦克风会用自己的转录内容 覆盖你输入的文本并提前发送。

典型的训练循环

  1. 在模板中补充锚点： 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. 重启API（缓存会在启动时重新读取）
  4. 打开"目标"选项卡 → 新目标会以generated状态出现
  5. 检查/补充同义词 → "保存为已审核" → 状态变为reviewed
  6. 用Klacksy测试，例如："Klacksy 给我看看地址"
  7. 如果Klacksy无法匹配 → "反馈"选项卡 → 补充缺失的同义词
  8. 监控"指标"选项卡，直到全部为reviewed
