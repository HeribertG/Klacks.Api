设置 Threema Gateway

前提条件

要通过Threema发送消息，您需要一个Threema Gateway 账户。Threema是一家瑞士提供商，在瑞士广泛使用，并且 注重隐私保护（瑞士数据保护法DSG）。

重要提示：Threema对接仅设计用于发送。 接收传入消息需要该网关的端到端模式， 本对接不支持此功能。发送是收费的 — 每条已发送的消息 都会消耗点数（Credits）。

步骤1 — 创建 Threema Gateway 账户

  1. 在gateway.threema.ch上注册。
  2. 申请一个基础模式的Gateway ID （例如：*MYGATEWAY）。此ID始终以星号（*）开头， 并且必须由Threema批准。
  3. 购买点数（Credits） — 没有余额将无法发送消息。
  4. 记下Gateway仪表盘上的API密钥。

提示：请像对待密码一样对待API密钥。 不要公开分享，并妥善保存。

步骤2 — 在 Klacks 中配置 Threema

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称threema-gateway
显示名称会在界面中显示Threema
提供商类型选择ThreemaThreema
Gateway ID您的Threema Gateway ID（基础模式，以*开头）*MYGATEWAY
API密钥来自Gateway仪表盘的API密钥a1b2c3d4e5...
已启用启用/禁用该提供商是
  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。 此测试通过网关的点数查询来验证凭据。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦Threema提供商配置并启用，聊天机器人Klacksy就可以 发送消息。您不需要知道Threema ID — 只需 使用员工或客户的姓名： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条消息：班次已经调换了。"
"通知李大同，他周一的班次取消了。"

Klacksy会自动查找已保存的收件人Threema ID，并 使用已配置的Threema提供商。发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：收件人必须在Klacks中保存 8位Threema ID（在地址 → 联系数据下）。员工可以在 其Threema应用的"我的资料"下找到自己的Threema ID。

传入消息

Threema对接不支持接收 — 对已发送消息的回复 不会传输到Klacks。接收功能需要Threema Gateway的 端到端模式；Klacks对接使用的是基础模式。 因此消息收件箱不会为该提供商显示任何传入消息。

故障排除

问题可能原因解决方法
连接测试失败 Gateway ID或API密钥有误 在gateway.threema.ch的Gateway仪表盘上检查凭据
消息未送达 Threema ID有误或不存在 检查8位Threema ID是否正确保存
发送失败 点数已用尽 在Threema Gateway中充值点数
找不到收件人 未保存Threema ID 在地址 → 联系数据下填写Threema ID
Gateway ID无法使用 该ID尚未获得批准 等待Threema批准（状态可在仪表盘中查看）
