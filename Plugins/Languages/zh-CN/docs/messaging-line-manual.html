设置 LINE 消息

前提条件

要通过LINE发送和接收消息，您需要在LINE Developers Console中 拥有一个带有Messaging API频道的LINE官方账号。 LINE在日本、台湾和泰国特别流行。

提示：推送消息根据LINE套餐不同有每月配额限制 （免费套餐有限制）。请检查您的官方账号套餐的最新条款。

步骤1 — 创建 LINE 官方账号和 Messaging API 频道

  1. 创建一个LINE官方账号 （通过LINE Official Account Manager）。
  2. 打开LINE Developers Console（developers.line.biz）并 创建一个Messaging API频道，或将您的 官方账号与Messaging API关联。
  3. 在Messaging API选项卡中签发一个长期有效的 频道访问令牌（Issue）。
  4. 记下Basic Settings选项卡中的 频道密钥。

提示：请像对待密码一样对待频道访问令牌和频道密钥。 不要公开分享，并妥善保存。

步骤2 — 在 Klacks 中配置 LINE

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称line-bot
显示名称会在界面中显示LINE
提供商类型选择LINELINE
频道访问令牌来自Messaging API选项卡的长期令牌eyJhbGciOi...
频道密钥来自Basic Settings的密钥abc123def456...
Webhook URL会自动填入您Klacks实例的URL（不可编辑）https://example.com/api/messaging/webhook/line
已启用启用/禁用该提供商是
  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦LINE提供商配置并启用，聊天机器人Klacksy就可以 发送消息。您不需要知道LINE用户ID — 只需 使用员工或客户的姓名： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条消息：班次已经调换了。"
"通知李大同，他周一的班次取消了。"

Klacksy会自动查找已保存的收件人LINE用户ID，并 使用已配置的LINE提供商。发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：收件人必须在Klacks中保存LINE用户ID （以U…开头）（在地址 → 联系数据下）。 用户ID会通过传入消息获知（在消息收件箱中可见）—— 收件人必须先将您的官方账号添加为好友并向其发送过 一条消息。

步骤4 — 接收传入消息（Webhook）

要在Klacks中显示传入的LINE消息，必须 手动在LINE Developers Console中输入Webhook URL。

  1. 从提供商设置中复制Klacks显示的Webhook URL： 
    https://{您的域名}/api/messaging/webhook/line
  2. 在LINE Developers Console的 Messaging API → Webhook settings下， 将此URL填入Webhook URL。
  3. 启用选项"Use webhook"。
  4. 确保您的Klacks实例可以通过HTTPS公开访问。
  5. 传入的消息现在会实时显示在消息收件箱中。

故障排除

问题可能原因解决方法
连接测试失败 频道访问令牌无效 在LINE Developers Console中签发一个新令牌
消息未送达 收件人未将官方账号添加为好友或已将其屏蔽 收件人必须在LINE中将该账号添加为好友
发送失败 每月推送配额已用尽 在LINE Official Account Manager中检查您套餐的配额
找不到收件人 未保存LINE用户ID 将消息收件箱中的用户ID填入地址 → 联系数据
缺少传入消息 未填写Webhook URL或"Use webhook"未启用 检查LINE Developers Console中的Webhook settings
