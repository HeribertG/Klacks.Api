设置 Zalo 消息

前提条件

要通过Zalo发送消息，您需要在oa.zalo.me上拥有一个 Zalo官方账号（OA），以及在 developers.zalo.me上拥有一个应用。Zalo是越南 领先的通讯应用。

重要提示：Zalo对接仅设计用于发送。 此外还有以下Zalo平台限制：

  • 访问令牌大约25小时后过期，必须在 Klacks之外续期并重新保存。
  • 消息只能发送给之前已与该官方账号 互动过的用户（互动窗口期）。

步骤1 — 设置 Zalo 官方账号和应用

  1. 在oa.zalo.me上创建一个官方账号。
  2. 在developers.zalo.me上创建一个应用。
  3. 将该官方账号与该应用关联。
  4. 通过Zalo Developer控制台的OAuth流程 获取一个访问令牌。

提示：请像对待密码一样对待访问令牌。 不要公开分享，并妥善保存。

步骤2 — 在 Klacks 中配置 Zalo

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称zalo-oa
显示名称会在界面中显示Zalo
提供商类型选择ZaloZalo
访问令牌通过OAuth流程获取的令牌zalo-oa-access-token...
OA ID您官方账号的ID（仅供参考，用于识别）987654321...
已启用启用/禁用该提供商是
  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。

重要提示：访问令牌大约25小时后过期。 Klacks不会自动续期 — 您必须通过Zalo的 刷新令牌流程在外部续期，并在Klacks中重新保存。请注意： 刷新令牌是一次性使用的 — 每次续期都会 生成一对新的令牌。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦Zalo提供商配置并启用，聊天机器人Klacksy就可以 发送消息。您不需要知道Zalo用户ID — 只需 使用员工或客户的姓名： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条消息：班次已经调换了。"
"通知李大同，他周一的班次取消了。"

Klacksy会自动查找已保存的收件人Zalo用户ID，并 使用已配置的Zalo提供商。发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：收件人必须在Klacks中保存 Zalo用户ID（在地址 → 联系数据下）。收件人必须 之前与该官方账号互动过（例如关注该OA或向其发送过一条 消息）— 超出互动窗口期后Zalo会拒绝发送。

传入消息

Zalo对接不支持接收 — 对已发送消息的回复 不会传输到Klacks。因此消息收件箱不会为该 提供商显示任何传入消息。

故障排除

问题可能原因解决方法
连接测试失败 访问令牌已过期（有效期约25小时） 通过刷新令牌流程续期该令牌并重新保存
消息未送达 用户未与该官方账号互动过 收件人必须关注该OA或向其发送一条消息
找不到收件人 未保存Zalo用户ID 在地址 → 联系数据下填写用户ID
令牌续期失败 刷新令牌已被使用过（一次性使用） 在Zalo Developer控制台中重新走一遍OAuth流程
发送因权限错误被拒绝 OA未与该应用关联 在developers.zalo.me上检查应用与官方账号之间的关联
