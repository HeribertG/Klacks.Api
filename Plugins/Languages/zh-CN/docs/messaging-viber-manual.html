设置 Viber 机器人

前提条件

要通过Viber发送和接收消息，您需要一个 Viber机器人，可通过Viber Partner Portal创建。 Viber在东欧和中东地区尤其受欢迎。

提示：Viber已将机器人使用商业化 — 根据国家和 消息量的不同，可能适用收费模式。请在 partners.viber.com上查看最新条款。

步骤1 — 创建 Viber 机器人

  1. 在partners.viber.com上注册。
  2. 在Partner Portal中创建一个新的机器人。
  3. 记下机器人仪表盘上的Auth Token。
  4. 设定一个发件人名称（例如：Klacks Bot）。

步骤2 — 在 Klacks 中配置 Viber

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称viber-bot
显示名称会在界面中显示Viber
提供商类型选择ViberViber
Auth Token来自机器人仪表盘的Auth Token4a5e6f7g8h9i...
发件人名称收件人看到的名称Klacks Bot
Webhook URL会自动填入您Klacks实例的URL（不可编辑）https://example.com/api/messaging/webhook/viber
已启用启用/禁用该提供商是
  1. 点击保存。此时Klacks会自动在Viber处 注册该Webhook（set_webhook）。
  2. 通过提供商列表中的测试按钮测试连接。

重要提示：所显示的Webhook URL必须可以通过 HTTPS公开访问 — 否则保存时Webhook注册 将会失败。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦Viber提供商配置并启用，聊天机器人Klacksy就可以 发送消息。您不需要知道Viber用户ID — 只需 使用员工或客户的姓名： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条消息：班次已经调换了。"
"通知李大同，他周一的班次取消了。"

Klacksy会自动查找已保存的收件人Viber用户ID，并 使用已配置的Viber提供商。发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

重要提示：Viber机器人只能向已订阅 该机器人的用户发送消息（已与机器人开始一对一聊天）。因此收件人 必须先向机器人发送一条消息。其Viber用户ID 会通过传入消息获知（在消息收件箱中可见）， 并需保存在收件人的地址 → 联系数据下。

步骤4 — 接收传入消息

传入的Viber消息会通过保存时自动注册的 Webhook自动接收 — 无需其他配置。

  1. 用户在Viber中搜索该机器人并向其发送一条消息。
  2. 该消息会实时显示在消息收件箱中。
  3. 将发件人的Viber用户ID填入该员工的联系数据中， 以便Klacksy今后可以直接给他发消息。
