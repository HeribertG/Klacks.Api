宏脚本手册

简介

使用宏编辑器，您可以创建用于计算工作、雇佣类型等的脚本。

使用示例：

  • 根据雇佣率精确计算假期和兵役时间
  • 计算夜班、周末和节假日的加班费
  • 灵活应对新的需求

注意：脚本解释器运行在安全的沙箱环境中，无法访问文件系统或网络。 无法执行恶意代码。

功能与类别

除了名称和脚本内容外，宏列表中的每个宏还有两个额外属性，这两个属性通过编辑器中的下拉菜单设置： 类别和功能。两者都是纯元数据——它们独立于脚本本身，不会影响脚本的计算逻辑，而是控制 Klacks 如何自动查找并分配合适的宏。

类别

类别将宏归入某个业务应用领域：

类别用途
未分配无特定应用领域（新建宏的默认值）
班次常规班次的加班费计算（夜班、周末、节假日加班费）
休假假期工时计算
疾病病假工时计算
事故事故假工时计算
培训（带薪）带薪培训/研修时间
培训（无薪）无薪培训/研修时间

类别班次具有特殊作用：新建的班次会自动分配该类别下的标准宏（见下文"功能"）。 已存在的班次不会因此被事后更改。

功能：自定义、标准、标准（叠加）

功能对宏在其类别中的角色进行分类：

功能含义
自定义没有特殊角色的自由宏。每个类别下可以有任意数量。
标准该类别的标准宏——会自动分配给新建的班次。每个类别最多只能有一个宏具有此功能。
标准（叠加）具有叠加加班费逻辑（见下文）的备用标准宏。同样每个类别最多一个，可与"标准"宏并存。

重要：功能本身不进行任何计算——它只是一个标签。加班费是按"取最高者" （只有适用的最高费率生效）还是按叠加方式（所有适用的费率相加）计算，由脚本本身决定。 随附的两个类别为"班次"的宏在相同的基本结构上展示了这一区别：

  • "AllShift"（功能：标准）——针对每个时间段确定其中最高的适用加班费 （夜班/WE1/WE2/WE3/节假日），并仅使用该费率。
  • "AllShiftAdditive"（功能：标准（叠加））——分别独立计算夜班、周末和节假日 加班费，并将它们相加。

新建班次时自动分配这两者中的哪一个，由一项全局安装设置控制（"叠加"或"取最高费率"）。 之后可随时为单个班次手动切换宏——因此可以混合使用。

唯一性：如果您尝试将同一类别的第二个宏也保存为"标准"或"标准（叠加）"，编辑器将阻止保存， 并提示已分配的宏名称。请先将该宏的功能设置为"自定义"。

不建议手动修改"AllShift"/"AllShiftAdditive"。 这两个宏是自动引入国家和行业特定调整的机制：只要保持不变，Klacks 就会自动使其与适用于您所在 国家或行业的规则保持同步。如果手动编辑其中之一，该宏从此被视为客户自有——针对该宏的未来自动 国家/行业更新将不再静默应用，而是失败并提示冲突，直到您手动解决差异为止。如果您需要自定义 加班费逻辑，请改为新建一个功能为"自定义"的宏，并将其专门分配给受影响的班次。

控制结构

重要： ENDIF、ENDFUNCTION、ENDSUB 等关键字 必须连写（请勿写成 END IF 等分开的形式）。

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "大"
ELSEIF x > 5 THEN
    OUTPUT 1, "中"
ELSE
    OUTPUT 1, "小"
ENDIF

单行 IF

IF x > 10 THEN OUTPUT 1, "大" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "周末"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "工作日"
    CASE ELSE
        OUTPUT 1, "未知"
END SELECT

FOR-NEXT 循环

FOR i = 1 TO 10
    summe += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

DO-LOOP 循环

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

函数和过程

重要： 函数（FUNCTION）和过程（SUB）必须在首次调用之前定义。 解释器从上到下读取代码。函数或过程只有在其定义被处理后才能使用。

SUB（无返回值的过程）

SUB berechne(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION（有返回值的函数）

FUNCTION verdoppeln(x)
    verdoppeln = x * 2
ENDFUNCTION

DIM ergebnis
ergebnis = verdoppeln(21)
OUTPUT 1, ergebnis

返回值 (OUTPUT)

OUTPUT typ, wert

typ 和 wert 是用逗号分隔的两个表达式；两者都是可选的（省略时默认分别 为 0 和 ""）。一个宏可以包含任意数量的 OUTPUT 行——每一行 都会产生一个独立的返回值。Klacks 只会解析以下类型：

类型含义
1主要结果（工时或总金额）——即使值为 0 也会被采用
10夜班加班费
11周末日 1 加班费（例如周六）
12周末日 2 加班费（例如周日）
13周末日 3 加班费（第三个可配置的周末日）
14节假日加班费

值为 0 的加班费行（类型 10-14）会被忽略——因此宏不必为每种加班费类型都输出一行， 只需为实际产生的加班费输出即可。无法解析为数字的值将被跳过。

保存时，宏必须先编译，并使用中性测试值试运行一次。语法错误和运行时错误（例如括号不匹配 或悬空表达式）会在此时被可靠地报告出来，而不是悄悄变成一个不起作用的宏。

示例：加班费计算（"AllShift"）

这是随附的类别为"班次"的标准宏。计算夜班、节假日以及三个可配置周末日的加班费，正确处理跨越 午夜的班次（分段计算），并对每个时间段应用最高的适用费率（取最高者）。 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

说明

  • 分段计算： 跨越午夜的班次（例如 22:00-06:00）会被分为两段处理（截至午夜/从午夜开始），每段都有自己的星期几/节假日标记
  • SegBonusForType： 针对某个时间段和特定加班费类型（10-14）计算加班金额，同时考虑夜班、节假日和周末加班费
  • WE1/WE2/WE3 而非周六/周日： weekendday1-3 使周末日可配置（并非每个国家都以周六/周日作为周末）
  • 每段最高加班费： NRate/DRate 分别确定夜间时段和日间时段适用的最高费率——取最高者，不叠加
  • HolidayNextDay： 考虑次日是否为节假日（对跨越午夜的夜班很重要）
  • 多个 OUTPUT 行： 第 1 行给出总金额，第 10-14 行给出各项加班费金额（参见"返回值"一节）

叠加版本（"AllShiftAdditive"）

同一类别下的标准（叠加）宏具有相同的 IMPORT 行和相同的整体结构——只有 SegBonusForType 不同：不再取最高费率，而是针对每种加班费类型独立判断是否 适用，并在最后将所有适用的金额相加（不再取最高者）： 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

例如，如果一个夜班同时又恰逢节假日，在"AllShift"中它只会获得两者中较高的一个费率，而在 "AllShiftAdditive"中则会同时获得夜班加班费和节假日加班费。脚本的其余部分（分段计算、 求和、OUTPUT 行）与上面的"AllShift"完全相同。
