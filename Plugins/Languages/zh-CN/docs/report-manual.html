报表设计器手册

报表结构

报表由三个区域组成：

  • 页眉 – 打印在每页顶部
  • 主体 – 包含数据表
  • 页脚 – 打印在每页底部

每个区域都可以在报表编辑器的设计选项卡中进行编辑。

页眉区域

页眉有三个区域：左侧、中间和右侧。

每个区域可以包含：

  • 字段 – 自动填充的数据库字段
  • 自由文本 – 手动输入的文本
  • 图片 – 例如公司徽标（通过图片管理器上传）

可以通过工具栏添加或删除行。

主体表格

主体包含一个或多个表格。

操作说明
添加列通过+符号或从字段列表拖放
列宽通过拖动列边缘进行调整
列顺序通过拖放移动
删除列在列编辑器中通过删除符号

每个表格都与一个数据集（例如工作计划、地址）关联。

合并字段

合并字段允许在单个列中进行多个数据绑定。

  • 在列编辑器中点击添加字段，向同一列添加更多字段
  • 这些值将上下排列或使用分隔符显示
  • 分隔符可在字段对话框中配置（例如逗号、空格、换行）

表格页脚

每个表格下方可以显示页脚。

  • 求和字段：数字列可以自动求和
  • 标签：可以显示或隐藏合计的标签
  • 通过列编辑器中的页脚选项卡激活

自由文本行

可以在数据表之前或之后插入自由文本行。

属性说明
位置可选择数据之前或数据之后
内容任意文本，例如提示、条件或签名栏
样式可配置字体、大小和对齐方式

格式设置

每个单元格和自由文本都可以单独格式化：

选项说明
字体可为单元格选择字体
字号以磅（pt）为单位的大小
粗体 / 斜体 / 下划线通过B / I / U按钮
文本颜色可自由选择的颜色
对齐方式左对齐、居中或右对齐

单元格边框

每个单元格的边框线都可以单独配置。

属性选项
边上、右、下、左（单独或全部）
线型细、中、粗、虚线、双线
线条颜色可自由选择

边框在列编辑器中的边框下设置。

页面设置

在常规选项卡中可以调整打印设置：

  • 方向：纵向或横向
  • 纸张大小：A4、A3、B4 (JIS)、B5 (JIS) 或 Letter
  • 页边距：上、右、下、左，以毫米为单位

显示选项（设计器）

在设计选项卡中，对于数据源工作计划，可以使用其他选项：

  • 合并每日条目：同一天的多条记录将合并为一行
  • 显示完整周期：显示周期的所有天数，即使没有记录

数据源

可用于报表的数据源：

数据源说明
工作计划班次和工作时间
地址（列表）所有地址作为表格
地址（详情）单个地址
缺勤缺勤概览
班次班次表
组组概览
容器模板容器报表的模板

数据源在“数据源”选项卡中选择，并决定可用的字段。

参数

参数在报表执行时被查询。它们的值可用于行过滤器和公式，并且还可以限制数据源的查询。它们在参数选项卡中创建。

字段含义
键技术名称。必须以字母开头，并且只能包含字母、数字和下划线。每个报表中唯一。
名称执行时显示的标签。
类型文本、数字、日期、是/否或选择。
默认值执行时未输入任何内容时使用的值。
选择值仅适用于“选择”类型：允许的值，以逗号分隔。
作用于确定该值是否额外传递给数据源。
必填字段没有该值，报表无法执行。

过滤器和公式中的参数

每个参数在脚本中都可以通过带有前缀 param_ 的键使用 — 例如，键 region 变为 param_region。该前缀防止参数遮蔽同名的行值。当前名称显示在每个参数下方。

该值在评估之前会转换为所选类型：

  • 数字：作为数字；无效输入将变为 0
  • 是/否：当值为 1、true、wahr 或 yes 时为真，否则为假
  • 文本、日期、选择：作为文本

将参数绑定到数据源

通过作用于，参数可以额外限制实际加载哪些数据：

设置效果
仅过滤器和公式该值仅在脚本中使用（默认）。
查询的组该值替换为其加载数据的组。
查询的人员该值替换为其加载数据的人员。
查询的开始日期该值替换时间段的开始。
查询的结束日期该值替换时间段的结束。

绑定的日期值必须输入为 YYYY-MM-DD 或 DD.MM.YYYY。其他格式的值将被忽略，以免查询在不知不觉中保持为空。空值将保持原始设置不变。
