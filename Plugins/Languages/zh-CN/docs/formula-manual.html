公式字段手册

基本语法

每个公式字段使用output命令输出结果：

output 1, <表达式>

第一个参数1是消息类型，必须始终为1。第二个参数是要输出的值。

简单示例：

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " 条记录"

可用变量

可用变量列在变量选项卡中，可在那里为其赋测试值。根据报表类型不同，可用的变量也不同：

报表类型表格页脚
工作计划totalRows、totalHours、totalSurcharges、totalWorkDays
缺勤totalRows、totalValue
地址totalRows
分组totalRows

条件逻辑

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "记录较多"
ELSEIF totalRows > 0 THEN
    output 1, "记录较少"
ELSE
    output 1, "没有记录"
ENDIF

单行IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF（简写形式）

output 1, IIF(totalRows > 0, "OK", "空")

变量与循环

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

实用示例

带文本的记录数

output 1, CStr(totalRows) & " 条记录"

四舍五入的值（1位小数）

output 1, CStr(Round(totalValue, 1))

小时表示为 h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

条件输出

IF totalRows = 0 THEN
    output 1, "没有缺勤记录"
ELSE
    output 1, CStr(totalRows) & " 条缺勤记录（总计：" & CStr(totalValue) & "）"
ENDIF

计算平均值

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " 小时/天"
ELSE
    output 1, "-"
ENDIF
