设置 WhatsApp

前提条件

要使用Klacks通过WhatsApp发送和接收消息，您需要一个 Meta开发者账号，以及一个已启用WhatsApp产品的Meta应用。Klacks使用 Meta Business平台的WhatsApp Cloud API发送消息，使用Meta Webhooks接收消息。

提示：设置和测试均不产生费用。创建应用时， Meta会自动免费提供一个测试电话号码。

重要 — 发件号码不是您的私人号码。 已在普通WhatsApp应用中使用的电话号码无法注册到Cloud API，而已注册的号码也无法再用于 WhatsApp Messenger。因此请使用Meta提供的测试号码，或使用一个仅用于业务的自有号码。 您手机上的私人WhatsApp在测试时充当收件人 — 而不是发件人。

步骤1 — 创建 Meta 应用

  1. 打开developers.facebook.com/apps并点击Create app。
  2. 用例选择Other，应用类型选择Business。
  3. 在Dashboard中，在WhatsApp产品处点击Set up。 此时会自动生成并注册一个测试电话号码。
  4. 在左侧导航中切换到WhatsApp → API Setup。
  5. 记下Phone number ID，并通过Generate access token生成一个访问令牌。
  6. 在App settings → Basic下记下 App Secret — 验证传入消息的签名时需要用到它。

注意 — 两个相似的ID：在API Setup面板中，Phone number ID和 WhatsApp Business Account ID紧挨着上下排列。Klacks需要的是 Phone number ID。填错ID时连接测试仍会报告成功，但每次发送都会失败。

注意 — 令牌有效期：通过Generate access token生成的 令牌是临时测试令牌，很短时间后就会过期。若要长期运行， 请在Meta Business Manager中通过一个系统用户生成永久令牌。

步骤2 — 为收件号码开通权限

测试号码只能向事先开通权限的收件人发送消息。请在API Setup面板中的 To → Manage phone number list下添加您的WhatsApp号码。 Meta会向该号码发送一个确认码，您必须输入该确认码。

没有这一步，Meta会拒绝发往该号码的任何消息。以后当您使用自己的、已验证的企业号码时， 就不再需要开通权限。

步骤3 — 在 Klacks 中配置 WhatsApp

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：

  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。

步骤4 — 24小时窗口

在这一点上，WhatsApp与Telegram或Slack有根本区别。企业只有在客服窗口处于 打开状态时，才可以发送自由文本消息。该窗口由收件人打开，即由他主动给您的WhatsApp 号码发消息。窗口会保持打开24小时，收件人每发送一条新消息都会延长该窗口。

在此窗口之外，Meta仅允许使用事先获批的消息模板。Klacks目前仅发送自由文本 消息，因此无法主动发起会话。

这对您意味着什么：请让您的员工先向Klacks的WhatsApp号码发送一次消息。 此后即可在24小时内发送消息，并且每一次回复都会延长该窗口。如果窗口已关闭，发送会报错 — 这不是配置问题，而是WhatsApp的规定。

如果您必须不受该窗口限制地联系员工，那么Telegram或Signal 是更合适的提供商 — 它们没有这项限制。

步骤5 — 通过聊天机器人（Klacksy）发送消息

一旦WhatsApp提供商配置并启用，聊天机器人Klacksy就可以 通过WhatsApp发送消息。请使用员工姓名： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条消息：班次已经调换了。"

作为收件人使用国际格式的电话号码，不带前导零、不带加号 （例如：41791234567对应079 123 45 67）。 发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：该WhatsApp号码必须与相应的 Klacks联系人关联（在地址 → 联系数据下），并且步骤4中的24小时窗口必须处于打开状态。

步骤6 — 接收传入消息（Webhooks）

要在Klacks中显示传入的WhatsApp消息，必须配置Meta应用的Webhook。 请在填写Callback URL之前先在Klacks中保存并启用该提供商 — Meta会立即通过一次验证请求检查该URL，Klacks会根据验证令牌自动回应该请求。

  1. 打开您的Meta应用，并导航到WhatsApp → Configuration。
  2. 在Webhook处点击Edit并填入：
    • Callback URL：Klacks中显示的Webhook URL 
      https://{您的域名}/api/messaging/webhook/whatsapp
    • Verify token：与您在步骤3的验证令牌字段中 填写的完全相同的值
  3. 点击Verify and save。
  4. 在Webhook fields下订阅字段messages。
  5. 传入的消息现在会实时显示在消息收件箱中。 Klacks会使用已保存的应用密钥检查每个请求的签名（X-Hub-Signature-256）。

Callback URL必须能从外部通过HTTPS访问。如果安装在没有公网地址的企业内网中， 发送功能可用，但无法接收消息。
