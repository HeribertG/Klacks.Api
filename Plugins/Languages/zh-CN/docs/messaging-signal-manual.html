设置 Signal 消息

前提条件

要通过Klacks发送Signal消息，您需要一个自托管的 signal-cli-rest-api实例。这是一个开源项目， 通过REST接口提供对Signal的访问。

  • 服务器上必须安装Docker
  • 一个将在Signal上注册的电话号码（推荐使用专用号码）
  • Docker镜像：bbernhard/signal-cli-rest-api

重要提示：Signal对接仅设计用于发送。 Klacks不接收传入的Signal消息。

步骤1 — 设置 signal-cli-rest-api

  1. 使用Docker启动容器： 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. 通过二维码链接方式关联您的Signal号码： 在浏览器中打开 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    并使用注册了该号码的手机上的Signal应用扫描显示的二维码 （设置 → 已关联的设备 → 关联设备）。 这样容器就会作为第二设备关联上。
  3. 您也可以选择通过API自行注册该号码 — 详情请参见该项目的文档。
  4. 使用健康检查测试该API： 
    curl http://localhost:8080/v1/about

提示：更多配置详情请参见 signal-cli-rest-api文档。

步骤2 — 在 Klacks 中配置 Signal

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称signal-main
显示名称会在界面中显示Signal
提供商类型选择SignalSignal
Signal号码已注册的电话号码（国际格式）+41791234567
Signal-CLI API URLsignal-cli-rest-api容器的URL。如果容器与Klacks运行在同一服务器上，此处可填写http://localhost:8080。http://localhost:8080
已启用启用/禁用该提供商是
  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。 此测试会检查所提供的号码是否已在容器中注册。

提示：Klacks通过容器的POST /v2/send端点发送消息。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦Signal提供商配置并启用，聊天机器人Klacksy就可以 发送消息。您不需要知道电话号码 — 只需 使用员工或客户的姓名： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条Signal消息：班次已经调换了。"
"通知李大同，他周一的班次取消了。"

Klacksy会自动查找已保存的收件人手机号码，并 使用已配置的Signal提供商。发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：收件人必须在Klacks中保存手机号码 （在地址 → 联系数据下），采用国际格式（例如：+41791234567）。 即使是群发消息，Signal发送也会使用已保存的手机号码。

传入消息

Signal对接不支持接收 — 对已发送消息的回复 不会传输到Klacks。因此消息收件箱不会为该 提供商显示任何传入消息。

故障排除

问题可能原因解决方法
连接测试失败 容器不可达 检查Docker容器是否在运行（docker ps）以及API URL是否正确
连接测试失败 号码未在容器中注册 重新通过二维码链接方式进行关联
消息未送达 收件人未使用Signal或号码有误 确保收件人已安装Signal，且号码以+{国家区号}{号码}格式保存
关联丢失 设备在Signal应用中被解除关联 通过二维码链接重新关联容器
容器无法启动 端口8080已被占用 使用其他端口：-p 9090:8080，并在Klacks中相应调整API URL
