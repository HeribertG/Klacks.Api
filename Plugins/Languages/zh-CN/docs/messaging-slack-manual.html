设置 Slack

前提条件

要使用Klacks通过Slack发送和接收消息，您需要一个 Slack工作区，以及一个具有相应权限的Slack应用。Klacks使用 Slack Web API发送消息，使用Events API接收消息。

提示：免费版Slack套餐足以支持该对接。 Slack应用在api.slack.com上创建，且免费。

步骤1 — 创建 Slack 应用

  1. 打开api.slack.com/apps并点击Create New App。
  2. 选择From scratch，并指定一个名称（例如：Klacks Bot）。
  3. 选择要安装该应用的工作区。
  4. 导航到OAuth & Permissions，并添加以下Bot Token Scopes：
    • chat:write — 用于向频道发送消息
    • im:write — 用于向用户发送私信
  5. 点击Install to Workspace并确认权限。
  6. 记下Bot User OAuth Token（以xoxb-开头）。
  7. 导航到Basic Information并记下Signing Secret。

步骤2 — 在 Klacks 中配置 Slack

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称slack-main
显示名称会在界面中显示Slack
提供商类型选择SlackSlack
Bot令牌Bot User OAuth Token（以xoxb-开头）xoxb-1234567890-abcdef...
签名密钥来自Basic Information的Signing Secret — 用于验证传入事件的签名a1b2c3d4e5f6...
默认频道没有指定收件人时消息的备用频道#general
Webhook URL会自动填写 — 请在步骤4中将此URL作为Request URL填入Slackhttps://example.com/api/messaging/webhook/slack
已启用启用/禁用该提供商是
  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦Slack提供商配置并启用，聊天机器人Klacksy就可以 通过Slack发送消息。请使用员工姓名或 频道名称： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条消息：班次已经调换了。"
"在#team-updates中发布：下周的排班计划已完成。"

作为收件人可以使用频道ID（例如：C0123456789）或 用户ID（例如：U0123456789）— 使用用户ID时会 发送私信。如果未指定收件人，则使用已配置的默认频道。 发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：Slack用户必须与相应的 Klacks联系人关联（在地址 → 联系数据下）。对于频道消息， 机器人必须被邀请到相应频道（/invite @Klacks Bot）。

步骤4 — 接收传入消息（Events API）

要在Klacks中显示传入的Slack消息，必须配置Slack应用的Events API。 请在填写Request URL之前先在Klacks中保存并启用该提供商 — Slack会立即通过一次质询请求验证该URL， Klacks会自动回应该请求。

  1. 在api.slack.com/apps上打开您的Slack应用，并导航到 Event Subscriptions。
  2. 启用Enable Events，并将Klacks显示的Webhook URL填入 Request URL： 
    https://{您的域名}/api/messaging/webhook/slack
  3. 在Subscribe to bot events下订阅事件 message.im（私信）和message.channels（频道消息）。
  4. 保存更改，并在系统提示时重新在工作区中安装该应用。
  5. 传入的消息现在会实时显示在消息收件箱中。 Klacks会使用已保存的Signing Secret检查每个请求的签名。

故障排除

问题可能原因解决方法
连接测试失败 Bot令牌无效或已被撤销 在OAuth & Permissions下检查该令牌并重新安装该应用
错误channel_not_found或not_in_channel 机器人未被添加到该频道 将机器人邀请到该频道（/invite）或检查频道ID
无收件人的消息发送失败 未配置默认频道 在提供商设置中填写一个默认频道
Request URL验证失败 提供商在Klacks中未保存/未启用，或Signing Secret有误 先在Klacks中保存并启用该提供商，并检查Signing Secret
缺少传入消息 未订阅Bot事件 在Event Subscriptions下订阅message.im和message.channels
