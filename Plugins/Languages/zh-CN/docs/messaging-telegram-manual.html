设置 Telegram 机器人

前提条件

要通过Klacks发送和接收Telegram消息，您需要一个 Telegram机器人。机器人通过官方BotFather创建，且免费。

步骤1 — 创建 Telegram 机器人

  1. 打开Telegram并搜索@BotFather。
  2. 与BotFather开始对话，并发送命令/newbot。
  3. 为您的机器人指定一个名称（例如：Klacks 通知）。
  4. 为机器人指定一个用户名（必须以bot结尾，例如：klacks_notify_bot）。
  5. BotFather会为您提供一个Bot Token。复制此令牌 — 下一步需要用到它。

提示：请像对待密码一样对待Bot Token。 不要公开分享，并妥善保存。

步骤2 — 在 Klacks 中配置机器人

  1. 导航到设置 → 消息提供商。
  2. 点击添加。
  3. 按如下方式填写字段：
字段说明示例
名称内部唯一名称telegram-bot
显示名称会在界面中显示Telegram
提供商类型选择TelegramTelegram
Bot Token来自BotFather的令牌123456:ABC-DEF1234ghIkl-zyx57W2v...
Webhook URL接收消息的URL（参见步骤4）https://example.com/api/messaging/webhook/telegram
已启用启用/禁用该提供商是
  1. 点击保存。
  2. 通过提供商列表中的测试按钮测试连接。

步骤3 — 通过聊天机器人（Klacksy）发送消息

一旦Telegram机器人配置并启用，聊天机器人Klacksy就可以 发送消息。您不需要知道Chat ID — 只需 使用员工或客户的姓名： 

"给王小明发一条消息：您的预约是明天下午2点。"
"给陈小华发一条消息：班次已经调换了。"
"通知李大同，他周一的班次取消了。"

Klacksy会自动查找已保存的收件人Telegram用户名，并 使用已配置的机器人。发送过程对您来说完全透明 — 您只需处理姓名，其余的由Klacksy负责。

前提条件：收件人必须在Klacks中保存Telegram用户名 （在地址 → 联系数据下）。

步骤4 — 接收传入消息（Webhook）

要在Klacks中显示传入的Telegram消息，必须配置一个Webhook。

  1. 确保您的Klacks实例可以通过HTTPS公开访问。
  2. 在提供商设置中输入以下Webhook URL： 
    https://{您的域名}/api/messaging/webhook/telegram
  3. 一旦提供商被保存并启用，Klacks会自动在Telegram中注册该Webhook。
  4. 传入的消息现在会实时显示在消息收件箱中。

故障排除

问题可能原因解决方法
连接测试失败 Bot Token无效 使用/mybots在BotFather处检查令牌
消息未送达 收件人未启动该机器人 收件人必须在Telegram中打开该机器人并发送/start
找不到收件人 未保存Telegram用户名 在地址 → 联系数据下填写Telegram用户名
缺少传入消息 Webhook URL不可达 检查您的域名是否可通过HTTPS访问，以及URL是否正确
Webhook注册失败 没有有效的SSL证书 Telegram要求提供有效的SSL证书（非自签名）
