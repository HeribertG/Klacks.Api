إعداد Slack

المتطلبات الأساسية

لإرسال واستقبال رسائل عبر Slack باستخدام Klacks، تحتاجون إلى مساحة عمل Slack وتطبيق Slack بالصلاحيات المناسبة. يستخدم Klacks Slack Web API للإرسال وEvents API للاستقبال.

ملاحظة: خطة Slack المجانية كافية لهذا الاتصال. تُنشأ تطبيقات Slack على api.slack.com وهي مجانية.

الخطوة 1 — إنشاء تطبيق Slack

  1. افتحوا api.slack.com/apps وانقروا على Create New App.
  2. اختاروا From scratch وأدخلوا اسمًا (مثال: Klacks Bot).
  3. اختاروا مساحة العمل التي سيُثبَّت فيها التطبيق.
  4. انتقلوا إلى OAuth & Permissions وأضيفوا نطاقات Bot Token Scopes التالية:
    • chat:write — لإرسال الرسائل إلى القنوات
    • im:write — لإرسال رسائل مباشرة إلى المستخدمين
  5. انقروا على Install to Workspace وأكّدوا الصلاحيات.
  6. احتفظوا بـ Bot User OAuth Token (يبدأ بـ xoxb-).
  7. انتقلوا إلى Basic Information واحتفظوا بـ Signing Secret.

الخطوة 2 — إعداد Slack في Klacks

  1. انتقلوا إلى الإعدادات → مزودو المراسلة.
  2. انقروا على إضافة.
  3. املؤوا الحقول كما يلي:

الخطوة 3 — إرسال الرسائل عبر روبوت الدردشة (Klacksy)

بمجرد إعداد مزوّد Slack وتفعيله، يمكن لروبوت الدردشة Klacksy إرسال الرسائل عبر Slack. استخدموا اسم الموظف أو اسم قناة: 

"أرسل رسالة إلى ماكس موستر: موعدك غدًا الساعة 14:00."
"أرسل لأنا بايشبيل رسالة: تم تبديل المناوبة."
"انشر في #team-updates: جداول المناوبات للأسبوع القادم جاهزة."

يُستخدم كمستلم معرّف قناة (Channel-ID) (مثال C0123456789) أو معرّف مستخدم (User-ID) (مثال U0123456789) — عند استخدام معرّف مستخدم تُرسَل رسالة مباشرة. إذا لم يُحدَّد مستلم، تُستخدم القناة الافتراضية المُعدَّة. الإرسال شفاف تمامًا بالنسبة لكم — تعملون بالأسماء، ويتولى Klacksy الباقي.

الشرط المسبق: يجب ربط مستخدم Slack بجهة الاتصال المقابلة في Klacks (تحت العنوان → بيانات الاتصال). لرسائل القنوات يجب دعوة البوت إلى القناة المعنية (/invite @Klacks Bot).

الخطوة 4 — استقبال الرسائل الواردة (Events API)

لعرض رسائل Slack الواردة في Klacks، يجب إعداد Events API لتطبيق Slack. احفظوا وفعّلوا المزوّد في Klacks قبل إدخال رابط الطلب (Request-URL) — يتحقق Slack من الرابط فورًا عبر طلب تحدٍّ (Challenge) يرد عليه Klacks تلقائيًا.

  1. افتحوا تطبيق Slack الخاص بكم على api.slack.com/apps وانتقلوا إلى Event Subscriptions.
  2. فعّلوا Enable Events وأدخلوا كـ Request URL رابط Webhook المعروض في Klacks: 
    https://{نطاقكم}/api/messaging/webhook/slack
  3. اشتركوا تحت Subscribe to bot events في الأحداث message.im (رسائل مباشرة) وmessage.channels (رسائل القنوات).
  4. احفظوا التغييرات وأعيدوا تثبيت التطبيق في مساحة العمل عند الطلب.
  5. تظهر الآن الرسائل الواردة في الوقت الفعلي في صندوق وارد المراسلة. يتحقق Klacks من توقيع كل طلب باستخدام Signing-Secret المُخزَّن.
