تدريب Klacksy - الدليل

ما هي أداة التدريب؟

تتحكم أداة التدريب في التنقل داخل الصفحة لروبوت المحادثة Klacksy. عندما يقول المستخدم أو يكتب "Klacksy، أرني العناوين"، ينتقل Klacksy إلى الصفحة المناسبة ويقوم بالتمرير إلى القسم المطابق.

لكي يعمل هذا، يحتاج Klacksy لكل مرساة (anchor) في الصفحة إلى قائمة من المرادفات بكل لغة (مثلاً "العناوين"، "الزبائن"، "جهات الاتصال" للهدف addresses).

علامة التبويب "الأهداف"

قائمة بجميع المراسي الموجودة في الواجهة الأمامية (سمات HTML data-klacksy-target). مرشحات الحالة:

  • pending: المرساة موجودة، لكن لا توجد مرادفات بعد
  • generated: تم توليد المرادفات تلقائياً، بحاجة إلى مراجعة
  • reviewed: تمت الموافقة على المرادفات من قبل مسؤول
  • needs-review: مُعلَّم لإعادة المراجعة

النقر على هدف يفتح محرر المرادفات أدناه. هناك يمكن إضافة المرادفات وحذفها والموافقة عليها عبر "حفظ كمُراجَع".

علامة التبويب "الملاحظات"

تعرض مدخلات المستخدمين التي لم يتمكن Klacksy من مطابقتها (لم يُعثر على مرادف مناسب). بالاستناد إلى هذه القائمة يمكن معرفة المرادفات التي لا تزال ناقصة.

علامة التبويب "المقاييس"

نظرة عامة على جميع الأهداف حسب الحالة. تساعد على متابعة تقدّم التدريب.

خط أنابيب البناء (CLI)

عند حصول القوالب على مراسي data-klacksy-target جديدة، يجب إعادة توليد البيان (Manifest) والمرادفات الأولية. تعمل الأوامر التالية أيضاً بشكل تلقائي في CI وفي Husky-Pre-Commit: 

cd C:\SourceCode\Klacks.Ui

# 1. فحص القوالب → navigation-targets.json مع جميع المراسي
npm run scan:targets

# 2a. توليد المرادفات الأولية (جميع اللغات الأساسية الـ4 + 22 لغة إضافية للـPlugins، ~2.5 ساعة)
npm run generate:synonyms

# 2b. اللغات الأساسية فقط (de/en/fr/it) — سريع، حوالي 9 دقائق
npm run generate:synonyms -- --core-only

# 2c. تعبئة اللغات الناقصة الخاصة بالـPlugins فقط — حوالي 45 دقيقة
npm run generate:synonyms -- --plugins-only

# 3. فحص اتساق كلمة التنبيه (Wake-Word)
npm run wake-word-lint

مهم: عند استخدام npm run يجب إضافة -- حتى يتم تمرير الخيارات إلى النص البرمجي. بدون -- يقوم npm بابتلاع العلامة (flag) ويعمل النص البرمجي بالوضع الافتراضي.

بديل بدون npm: npx tsx tools/generate-synonyms.ts --core-only.

مفتاح API

يتم البحث عن مفتاح API الخاص بنموذج اللغة (LLM) بالترتيب التالي:

  1. متغير البيئة SYNONYM_LLM_API_KEY
  2. جدول قاعدة البيانات llm_providers (المزوّد deepseek، is_enabled = true) — تلقائياً عبر استدعاء psql
  3. وإلا، تظهر رسالة خطأ

المزوّد الافتراضي هو DeepSeek. يمكن استخدام مزوّد آخر عبر SYNONYM_LLM_PROVIDER_ID=anthropic (أو أي مزوّد LLM آخر مُهيَّأ في الإعدادات).

الخطوة 1 - scan:targets

يقوم بفحص جميع قوالب Angular بحثاً عن سمات data-klacksy-target وينشئ البيان (Manifest) Application/Skills/Definitions/navigation-targets.json. تظهر كل مرساة جديدة بعد ذلك في علامة التبويب "الأهداف" بحالة pending.

الخطوة 2 - generate:synonyms

ينشئ لكل مرساة جديدة مرادفات أولية من data-klacksy-label-key والفئة. الحالة بعد ذلك: generated (يجب أن تتم مراجعتها من قبل المسؤول).

يقوم النص البرمجي بكتابة نقاط تحقق (Checkpoints) للبيان كل 5 أهداف، بحيث لا يفقد أي انقطاع البيانات المُولَّدة مسبقاً.

الخطوة 3 - wake-word-lint

يتحقق من اتساق نسخة كلمة التنبيه (Hallo Klacksy / Hey Klacksy / ...) عبر جميع اللغات. يمنع أن تقوم المرادفات بالكتابة فوق كلمة التنبيه.

وضع الصوت (Voice-Mode)

رمز الميكروفون في المحادثة يقوم بتفعيل وضع الصوت. بمجرد التفعيل:

  • يستمع الميكروفون باستمرار، ويقوم بالنسخ الصوتي بشكل متواصل
  • عند حدوث صمت قصير → يتم الإرسال التلقائي للنسخة الصوتية الحالية

مهم: بمجرد أن تبدأ بالكتابة في حقل النص، يتم إنهاء وضع الصوت تلقائياً — وإلا فسيقوم الميكروفون بالكتابة فوق النص الذي تكتبه بنسخه الصوتية الخاصة به وإرساله قبل الأوان.

حلقة التدريب النموذجية

  1. إضافة مرساة في القالب: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. إعادة تشغيل الـAPI (تتم إعادة قراءة الذاكرة المؤقتة عند البدء)
  4. فتح علامة التبويب "الأهداف" → تظهر الأهداف الجديدة بحالة generated
  5. مراجعة/إكمال المرادفات → "حفظ كمُراجَع" → الحالة reviewed
  6. الاختبار مع Klacksy، مثلاً "Klacksy، أرني العناوين"
  7. إذا لم تنجح المطابقة → علامة التبويب "الملاحظات" → إضافة المرادف الناقص
  8. متابعة علامة التبويب "المقاييس" حتى تصبح جميع الحالات reviewed
