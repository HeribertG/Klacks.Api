إعداد المراسلة عبر LINE

المتطلبات الأساسية

لإرسال واستقبال الرسائل عبر LINE، تحتاجون إلى حساب LINE رسمي (LINE Official Account) مع قناة Messaging API في لوحة LINE Developers Console. ينتشر LINE بشكل خاص في اليابان وتايوان وتايلاند.

ملاحظة: تخضع الرسائل الفورية (Push) لحصة شهرية حسب باقة LINE (الباقة المجانية محدودة). تحققوا من الشروط الحالية لباقة حسابكم الرسمي.

الخطوة 1 — إنشاء حساب LINE رسمي وقناة Messaging API

  1. أنشئوا حساب LINE رسمي (LINE Official Account) (عبر LINE Official Account Manager).
  2. افتحوا LINE Developers Console (developers.line.biz) و أنشئوا قناة Messaging API، أو اربطوا حسابكم الرسمي بواجهة برمجة تطبيقات المراسلة.
  3. أصدروا في تبويب Messaging API رمز وصول قناة (Channel-Access-Token) طويل الأجل (Issue).
  4. دوّنوا سر القناة (Channel-Secret) من تبويب Basic Settings.

ملاحظة: تعاملوا مع رمز وصول القناة وسر القناة كما تتعاملون مع كلمات المرور. لا تشاركوهما علنًا واحفظوهما بأمان.

الخطوة 3 — إرسال الرسائل عبر روبوت المحادثة (Klacksy)

بمجرد تهيئة وتفعيل مزوّد LINE، يمكن لروبوت المحادثة Klacksy إرسال الرسائل. لستم بحاجة إلى معرفة معرّفات مستخدمي LINE — ما عليكم سوى استخدام اسم الموظف أو العميل: 

"أرسل رسالة إلى Max Muster: موعدك غدًا الساعة 14:00."
"أرسل إلى Anna Beispiel رسالة: تم تبديل المناوبة."
"أخبر Peter Müller أن مناوبته يوم الاثنين ملغاة."

يبحث Klacksy تلقائيًا عن معرّف مستخدم LINE المخزَّن للمستلِم ويستخدم مزوّد LINE المُهيَّأ. عملية الإرسال شفافة تمامًا بالنسبة لكم — أنتم تعملون بالأسماء، ويتولى Klacksy الباقي.

شرط أساسي: يجب أن يكون معرّف مستخدم LINE (يبدأ بالحرف U…) مُخزَّنًا في Klacks لدى المستلِم (ضمن العنوان → بيانات الاتصال). يصبح معرّف المستخدم معروفًا عبر الرسائل الواردة (يظهر في صندوق وارد المراسلة) — ولهذا يجب أن يكون المستلِم قد أضاف حسابكم الرسمي كصديق وأرسل إليه رسالة.

الخطوة 4 — استقبال الرسائل الواردة (Webhook)

لعرض رسائل LINE الواردة في Klacks، يجب إدخال رابط Webhook يدويًا في LINE Developers Console.

  1. انسخوا رابط Webhook المعروض في Klacks من إعدادات المزوّد: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. أدخلوا هذا الرابط في LINE Developers Console ضمن Messaging API → Webhook settings كـ Webhook URL.
  3. فعّلوا خيار „Use webhook".
  4. تأكدوا من أن نسخة Klacks الخاصة بكم متاحة للعموم عبر HTTPS.
  5. ستظهر الرسائل الواردة الآن في الوقت الفعلي في صندوق وارد المراسلة.
