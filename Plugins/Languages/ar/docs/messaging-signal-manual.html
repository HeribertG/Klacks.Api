إعداد المراسلة عبر Signal

المتطلبات الأساسية

لإرسال رسائل Signal عبر Klacks، تحتاجون إلى نسخة مستضافة ذاتيًا من signal-cli-rest-api. وهو مشروع مفتوح المصدر يتيح الوصول إلى Signal عبر واجهة REST.

  • يجب تثبيت Docker على الخادم
  • رقم هاتف مسجَّل لدى Signal (يُنصح برقم مخصَّص)
  • صورة Docker: bbernhard/signal-cli-rest-api

هام: اتصال Signal مُصمَّم للإرسال فقط. لا يتم استقبال رسائل Signal الواردة في Klacks.

الخطوة 1 — إعداد signal-cli-rest-api

  1. ابدأوا الحاوية باستخدام Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. اربطوا رقم Signal الخاص بكم عبر إجراء رابط رمز QR: افتحوا في المتصفح 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    وامسحوا رمز QR المعروض باستخدام تطبيق Signal على الهاتف الذي سُجِّل فيه الرقم (الإعدادات → الأجهزة المرتبطة → ربط جهاز). بذلك تُربط الحاوية كجهاز ثانٍ.
  3. بدلًا من ذلك، يمكنكم تسجيل الرقم بأنفسكم عبر الـ API — التفاصيل موجودة في وثائق المشروع.
  4. اختبروا الـ API بفحص صحة: 
    curl http://localhost:8080/v1/about

ملاحظة: مزيد من تفاصيل الإعداد موجودة في وثائق signal-cli-rest-api.

الخطوة 3 — إرسال الرسائل عبر روبوت الدردشة (Klacksy)

بمجرد إعداد مزوّد Signal وتفعيله، يمكن لروبوت الدردشة Klacksy إرسال الرسائل. لا حاجة لمعرفة أرقام الهواتف — استخدموا ببساطة اسم الموظف أو العميل: 

"أرسل رسالة إلى ماكس موستر: موعدك غدًا الساعة 14:00."
"أرسل لأنا بايشبيل رسالة Signal: تم تبديل المناوبة."
"أخطر بيتر مولر بأن مناوبته يوم الاثنين ملغاة."

يبحث Klacksy تلقائيًا عن رقم الهاتف المحمول المسجَّل للمستلم ويستخدم مزوّد Signal المُعد. الإرسال شفاف تمامًا بالنسبة لكم — تعملون بالأسماء، ويتولى Klacksy الباقي.

الشرط المسبق: يجب أن يكون رقم هاتف محمول مسجَّلًا في Klacks لدى المستلم (تحت العنوان → بيانات الاتصال)، بالصيغة الدولية (مثال +41791234567). حتى في رسائل البث الجماعي، يعتمد إرسال Signal على رقم الهاتف المحمول المسجَّل.

الرسائل الواردة

لا يدعم اتصال Signal الاستقبال — الردود على الرسائل المُرسَلة لا تُنقل إلى Klacks. لذلك لا يعرض صندوق وارد المراسلة لهذا المزوّد أي رسائل واردة.
