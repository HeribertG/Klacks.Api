دليل حقل الصيغة

الصياغة الأساسية

يقوم كل حقل صيغة بإخراج النتيجة باستخدام الأمر output:

output 1, <تعبير>

المعامل الأول 1 هو نوع الرسالة ويجب أن يكون دائماً 1. المعامل الثاني هو القيمة المراد إخراجها.

أمثلة بسيطة:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " إدخالات"

المتغيرات المتاحة

المتغيرات المتاحة مدرجة في علامة التبويب المتغيرات ويمكن تعيين قيم اختبار لها هناك. حسب نوع التقرير، تتوفر متغيرات مختلفة:

نوع التقريرتذييل الجدول
خطة العملtotalRows, totalHours, totalSurcharges, totalWorkDays
الغياباتtotalRows, totalValue
العناوينtotalRows
المجموعاتtotalRows

العاملالوصفمثال
+الجمعtotalHours + 2
-الطرحtotalRows - 1
*الضربtotalValue * 1.5
/القسمةtotalHours / 8
^الأس2 ^ 10

الدوال المدمجة

تحويل الأنواع

الدالةالوصف

CInt(x)تحويل إلى عدد صحيح
CDbl(x)تحويل إلى عدد عشري

الرياضيات

الدالةالوصف

المنطق الشرطي

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "إدخالات كثيرة"
ELSEIF totalRows > 0 THEN
    output 1, "إدخالات قليلة"
ELSE
    output 1, "لا توجد إدخالات"
ENDIF

IF من سطر واحد

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (الصيغة المختصرة)

output 1, IIF(totalRows > 0, "OK", "فارغ")

المتغيرات والحلقات

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

أمثلة عملية

عدد الإدخالات مع نص

output 1, CStr(totalRows) & " إدخالات"

قيمة مقرَّبة (منزلة عشرية واحدة)

output 1, CStr(Round(totalValue, 1))

الساعات بصيغة h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

إخراج شرطي

IF totalRows = 0 THEN
    output 1, "لا توجد غيابات"
ELSE
    output 1, CStr(totalRows) & " غيابات (المجموع: " & CStr(totalValue) & ")"
ENDIF

حساب المتوسط
