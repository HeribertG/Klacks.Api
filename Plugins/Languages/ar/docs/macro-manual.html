دليل برمجة الماكرو (Scripting)

مقدمة

يتيح محرر الماكرو كتابة نصوص برمجية تُستخدم كأساس للحساب للخدمات والأنشطة العملية وغيرها.

أمثلة على الاستخدام:

  • حساب الساعات الدقيق للعطل أو الخدمة العسكرية وفقاً لدرجة التوظيف
  • حساب علاوات العمل الليلي وعطلات نهاية الأسبوع وأيام العطل الرسمية
  • التكيف المرن مع المتطلبات الجديدة

ملاحظة: يعمل مفسر النصوص البرمجية في بيئة معزولة آمنة (sandbox) دون الوصول إلى نظام الملفات أو الشبكة. لا يمكن تنفيذ أي تعليمات برمجية خبيثة.

الوظيفة والفئة

إضافة إلى الاسم ومحتوى النص البرمجي، يحتوي كل ماكرو في قائمة الماكرو على خاصيتين إضافيتين يتم تعيينهما عبر قوائم منسدلة في المحرر: الفئة والوظيفة. كلتاهما بيانات وصفية بحتة – فهما خارج النص البرمجي ولا تؤثران على حسابه، بل تتحكمان في كيفية عثور Klacks تلقائياً على الماكرو المناسب وتعيينه.

الفئة

تُسند الفئة الماكرو إلى مجال تطبيق مهني معيّن:

الفئةالاستخدام
غير محددلا يوجد مجال تطبيق خاص (افتراضي للماكرو الجديد)
دوامحساب العلاوات للخدمات المعتادة (علاوة ليلية، نهاية أسبوع، عطلة رسمية)
إجازةحساب الساعات للإجازات
مرضحساب الساعات للمرض
حادثحساب الساعات للحادث
ورشة عمل (مدفوعة)وقت ورشة عمل/تدريب مدفوع
ورشة عمل (غير مدفوعة)وقت ورشة عمل/تدريب غير مدفوع

لفئة دوام دور خاص: تحصل الخدمات المنشأة حديثاً تلقائياً على الماكرو الافتراضي لهذه الفئة (انظر "الوظيفة" أدناه). أما الخدمات الموجودة مسبقاً فلا يتم تعديلها لاحقاً أبداً بهذه الطريقة.

الوظيفة: مخصص، افتراضي، افتراضي (تراكمي)

تصنف الوظيفة دور الماكرو ضمن فئته:

الوظيفةالمعنى
مخصصماكرو حر بدون دور خاص. يمكن وجود عدد غير محدود منها لكل فئة.
افتراضيالماكرو الافتراضي لهذه الفئة – يُسند تلقائياً للخدمات الجديدة. لا يجوز لأكثر من ماكرو واحد لكل فئة أن يحمل هذه الوظيفة.
افتراضي (تراكمي)ماكرو افتراضي بديل بمنطق علاوات تراكمي (انظر أدناه). يمكن وجوده أيضاً بحد أقصى واحد لكل فئة، إلى جانب ماكرو "افتراضي".

مهم: الوظيفة وحدها لا تحسب شيئاً – إنها مجرد تسمية (Label). أما كون العلاوات تُحسب بمنطق "الأعلى يفوز" (يُحتسب فقط أعلى معدل قابل للتطبيق) أو بمنطق تراكمي (تُجمع كل المعدلات المنطبقة) فهذا يقرره النص البرمجي نفسه. يوضح الماكروان المرفقان لفئة "دوام" هذا الفرق باستخدام نفس البنية الأساسية:

  • "AllShift" (الوظيفة: افتراضي) – يحدد لكل مقطع زمني أعلى علاوة قابلة للتطبيق (ليلية/WE1/WE2/WE3/عطلة رسمية) ويستخدم هذه العلاوة فقط.
  • "AllShiftAdditive" (الوظيفة: افتراضي (تراكمي)) – يحسب علاوة الليل ونهاية الأسبوع والعطلة الرسمية بشكل مستقل عن بعضها ثم يجمعها.

يتحكم إعداد على مستوى التثبيت بأكمله ("تراكمي" أو "الأعلى يفوز") في أي من الاثنين يُسند تلقائياً عند إنشاء خدمة جديدة. ويمكن بعد ذلك تغيير الماكرو يدوياً لكل خدمة في أي وقت – أي أن التشغيل المختلط ممكن.

التفرد: إذا حاولتم حفظ ماكرو ثانٍ من نفس الفئة أيضاً بوصفه "افتراضي" أو "افتراضي (تراكمي)"، يمنع المحرر الحفظ ويذكر اسم الماكرو المُسند مسبقاً. عيّنوا وظيفة ذلك الماكرو أولاً إلى "مخصص".

يُنصح بعدم إجراء تعديلات يدوية على "AllShift"/"AllShiftAdditive". هذان الماكروان هما الآلية التي يتم من خلالها إدخال التعديلات الخاصة بالبلد والقطاع تلقائياً: طالما تركتموهما دون تغيير، يحافظ Klacks على مزامنتهما تلقائياً مع القواعد المناسبة لبلدكم أو قطاعكم. أما إذا عدّلتم أحدهما يدوياً، فيُعتبر من تلك اللحظة ملكاً خاصاً بالعميل – ولن تُطبَّق تحديثات البلد/القطاع التلقائية المستقبلية لهذا الماكرو بصمت، بل ستفشل مع تعارض إلى أن تحلّوا الاختلاف يدوياً. إذا احتجتم إلى منطق علاوات خاص بكم، أنشئوا بدلاً من ذلك ماكرو جديداً بوظيفة "مخصص" وأسندوه تحديداً إلى الخدمات المعنية.

الدوال والإجراءات

مهم: يجب تعريف الدوال (FUNCTION) والإجراءات (SUB) قبل استدعائها لأول مرة. يقرأ المفسر الشيفرة من الأعلى إلى الأسفل: لا تكون الدالة أو الإجراء معروفاً إلا بعد معالجة تعريفه.

SUB (إجراء بدون قيمة إرجاع)

SUB calcular(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (دالة بقيمة إرجاع)

FUNCTION duplicar(x)
    duplicar = x * 2
ENDFUNCTION

DIM resultado
resultado = duplicar(21)
OUTPUT 1, resultado

إرجاع القيم (OUTPUT)

OUTPUT النوع, القيمة

النوع والقيمة هما تعبيران مفصولان بفاصلة؛ وكلاهما اختياري (القيمة الافتراضية 0 أو "" عند حذفهما). يجوز أن يحتوي الماكرو على أي عدد من أسطر OUTPUT – ينتج كل سطر منها قيمة إرجاع مستقلة. لا يقيّم Klacks سوى الأنواع التالية:

النوعالمعنى
1النتيجة الرئيسية (الساعات أو المبلغ الإجمالي) – تُعتمد حتى عند القيمة 0
10علاوة العمل الليلي
11علاوة يوم نهاية الأسبوع 1 (مثلاً السبت)
12علاوة يوم نهاية الأسبوع 2 (مثلاً الأحد)
13علاوة يوم نهاية الأسبوع 3 (يوم نهاية الأسبوع الثالث القابل للتهيئة)
14علاوة العطلة الرسمية

يتم تجاهل أسطر العلاوات (النوع 10-14) ذات القيمة 0 – أي أن الماكرو لا يحتاج إلى إخراج سطر مستقل لكل نوع علاوة، بل فقط للعلاوات المستحقة فعلياً. تُتجاوَز القيم التي لا يمكن تفسيرها كأرقام.

عند الحفظ، يتم تجميع (compile) الماكرو إلزامياً وتنفيذه مرة واحدة تجريبياً بقيم اختبار محايدة. يتم بذلك عرض أخطاء الصياغة والتنفيذ (مثل الأقواس غير المتوازنة أو تعبير معلّق) بشكل موثوق بدلاً من أن يؤدي الأمر بصمت إلى ماكرو معطّل الوظيفة.

مثال: حساب العلاوات ("AllShift")

الماكرو الافتراضي المرفق لفئة "دوام". يحسب علاوات لليل والعطلة الرسمية وأيام نهاية الأسبوع الثلاثة القابلة للتهيئة مع معالجة صحيحة للمناوبات التي تعبر منتصف الليل (تقسيم إلى مقاطع)، ويطبق لكل مقطع أعلى معدل قابل للتطبيق (الأعلى يفوز). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

الشرح

  • التقسيم إلى مقاطع (Segment-Splitting): بالنسبة للمناوبات التي تعبر منتصف الليل (مثلاً 22:00-06:00)، يتم تقسيم المناوبة إلى مقطعين (حتى منتصف الليل / من منتصف الليل)، لكل منهما يوم أسبوع/علم عطلة رسمية خاص به
  • SegBonusForType: تحسب علاوة مقطع واحد لنوع علاوة معيّن (10-14) مع مراعاة علاوات الليل والعطلة الرسمية ونهاية الأسبوع
  • WE1/WE2/WE3 بدلاً من السبت/الأحد: يجعل weekendday1-3 أيام نهاية الأسبوع قابلة للتهيئة (ليس لكل بلد السبت والأحد عطلة نهاية الأسبوع)
  • أعلى علاوة لكل مقطع: يحدد NRate/DRate أعلى معدل قابل للتطبيق لساعات الليل أو النهار على التوالي – الأعلى يفوز، بدون تراكم
  • HolidayNextDay: يأخذ في الحسبان ما إذا كان اليوم التالي عطلة رسمية (مهم للمناوبات الليلية العابرة لمنتصف الليل)
  • عدة أسطر OUTPUT: يقدّم السطر 1 المجموع الإجمالي، بينما تقدّم الأسطر 10-14 مبالغ العلاوات الفردية (انظر قسم "إرجاع القيم")

النسخة التراكمية ("AllShiftAdditive")

يحتوي الماكرو الافتراضي (التراكمي) لنفس الفئة على أسطر IMPORT مطابقة ونفس البنية العامة – الفرق الوحيد في SegBonusForType: فبدلاً من أعلى معدل، يُحسب لكل نوع علاوة بشكل مستقل ما إذا كان ينطبق، وتُجمع في النهاية كل المبالغ المنطبقة (لم يعد هناك "الأعلى يفوز"): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

إذا صادفت مناوبة ليلية مثلاً عطلة رسمية أيضاً، فإنها تحصل في "AllShift" على الأعلى فقط من المعدلين، بينما تحصل في "AllShiftAdditive" على علاوة الليل وعلاوة العطلة الرسمية معاً. باقي النص البرمجي (التقسيم إلى مقاطع، الجمع، أسطر OUTPUT) مطابق لـ"AllShift" أعلاه.
