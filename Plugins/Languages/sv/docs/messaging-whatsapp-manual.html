Konfigurera WhatsApp

Förutsättningar

För att skicka och ta emot meddelanden via WhatsApp med Klacks behöver du ett Meta-utvecklarkonto och en Meta-app med aktiverad WhatsApp-produkt. Klacks använder WhatsApp Cloud API från Meta Business-plattformen för utskick och Meta-webhooks för mottagande.

Obs: Konfigurationen och testningen är kostnadsfria. När appen skapas tillhandahåller Meta automatiskt ett kostnadsfritt testtelefonnummer.

Viktigt — avsändarnumret är inte ditt privata nummer. Ett telefonnummer som redan används i den vanliga WhatsApp-appen kan inte registreras för Cloud API, och ett registrerat nummer går inte längre att använda med WhatsApp Messenger. Använd därför testnumret som Meta tillhandahåller eller ett eget nummer som uteslutande används i affärssyfte. Ditt privata WhatsApp på mobiltelefonen fungerar som mottagare vid testning — inte som avsändare.

Steg 1 — Skapa en Meta-app

  1. Öppna developers.facebook.com/apps och klicka på Create app.
  2. Välj Other som användningsfall och Business som apptyp.
  3. Klicka i instrumentpanelen på Set up vid produkten WhatsApp. Därvid skapas och registreras automatiskt ett testtelefonnummer.
  4. Gå i den vänstra navigeringen till WhatsApp → API Setup.
  5. Notera Phone number ID och skapa en åtkomsttoken via Generate access token.
  6. Notera under App settings → Basic värdet App Secret — det behövs för signaturkontrollen av inkommande meddelanden.

Observera — två liknande ID:n: I API Setup-panelen står Phone number ID och WhatsApp Business Account ID direkt under varandra. Klacks behöver Phone number ID. Med fel ID rapporterar anslutningstestet ändå framgång, men varje utskick misslyckas.

Observera — tokens giltighetstid: Den token som skapas via Generate access token är en tillfällig testtoken och upphör att gälla efter kort tid. För kontinuerlig drift skapar du en permanent token i Meta Business Manager via en systemanvändare.

Steg 2 — Godkänn mottagarnumret

Testnumret får endast skicka till mottagare som godkänts i förväg. Lägg till ditt WhatsApp-nummer i panelen API Setup under To → Manage phone number list. Meta skickar en bekräftelsekod till detta nummer, som du måste ange.

Utan detta steg avvisar Meta varje utskick till detta nummer. Så snart du senare använder ett eget, verifierat företagsnummer bortfaller godkännandet.

Steg 4 — 24-timmarsfönstret

Här skiljer sig WhatsApp i grunden från Telegram eller Slack. Ett företag får endast skicka fria textmeddelanden så länge ett kundtjänstfönster är öppet. Detta fönster öppnas av mottagaren, genom att denne skriver till ditt WhatsApp-nummer. Det förblir öppet i 24 timmar och förlängs med varje ytterligare meddelande från mottagaren.

Utanför detta fönster tillåter Meta uteslutande i förväg godkända meddelandemallar. Klacks skickar för närvarande uteslutande fria textmeddelanden och kan därmed inte inleda en konversation på eget initiativ.

Vad det innebär för dig: Be dina medarbetare att en gång skicka ett meddelande till Klacks WhatsApp-nummer. Därefter är utskick möjligt i 24 timmar, och varje svar förlänger fönstret. Är fönstret stängt rapporterar utskicket ett fel — det är inte ett konfigurationsproblem utan en regel från WhatsApp.

Om du måste nå medarbetare oberoende av detta fönster är Telegram eller Signal de bättre leverantörerna — där finns inte denna begränsning.

Steg 5 — Skicka meddelanden via chatboten (Klacksy)

Så snart WhatsApp-leverantören är konfigurerad och aktiverad kan chatboten Klacksy skicka meddelanden via WhatsApp. Använd namnet på medarbetaren: 

"Skicka ett meddelande till Max Muster: Ditt möte är imorgon kl. 14:00."
"Skicka ett meddelande till Anna Exempel: Skiftet har bytts."

Som mottagare används telefonnumret i internationellt format utan inledande nolla och utan plustecken (t.ex. 41791234567 för 079 123 45 67). Utskicket är helt transparent för dig — du arbetar med namn, Klacksy sköter resten.

Förutsättning: WhatsApp-numret måste vara kopplat till motsvarande Klacks-kontakt (under Adress → Kontaktuppgifter), och 24-timmarsfönstret från steg 4 måste vara öppet.

Steg 6 — Ta emot inkommande meddelanden (webhooks)

För att inkommande WhatsApp-meddelanden ska visas i Klacks måste Meta-appens webhook konfigureras. Spara och aktivera leverantören i Klacks innan du anger Callback-URL:en — Meta kontrollerar URL:en direkt med en verifieringsförfrågan, som Klacks besvarar automatiskt med hjälp av verifieringstoken.

  1. Öppna din Meta-app och navigera till WhatsApp → Configuration.
  2. Klicka på Edit vid Webhook och ange:
    • Callback URL: den webhook-URL som visas i Klacks 
      https://{din-domän}/api/messaging/webhook/whatsapp
    • Verify token: exakt samma värde som du angav i steg 3 i fältet Verifieringstoken
  3. Klicka på Verify and save.
  4. Prenumerera under Webhook fields på fältet messages.
  5. Inkommande meddelanden visas nu i realtid i meddelandeinkorgen. Klacks kontrollerar därvid signaturen för varje begäran (X-Hub-Signature-256) med den lagrade app-hemligheten.

Callback-URL:en måste vara åtkomlig utifrån via HTTPS. Vid en installation i företagsnätet utan publik adress fungerar utskicket, men inga meddelanden kan tas emot.
