Klacksy-träning – handledning

Vad är träningsverktyget?

Träningsverktyget styr chatboten Klacksys navigering inom sidan. När en användare säger eller skriver "Klacksy visa mig adresserna" navigerar Klacksy till rätt sida och skrollar till motsvarande avsnitt.

För att detta ska fungera behöver Klacksy för varje ankare på en sida en lista med synonymer på varje språk (t.ex. "adresser", "kunder", "kontakter" för målet addresses).

Fliken "Mål"

Lista över alla ankare som hittats i frontend (HTML-attributet data-klacksy-target). Statusfilter:

  • pending: Ankaret finns, men har ännu inga synonymer
  • generated: Synonymer har genererats automatiskt, behöver granskas
  • reviewed: Synonymer godkända av en administratör
  • needs-review: Markerad för förnyad granskning

Klick på ett mål öppnar synonymredigeraren nedanför. Där kan synonymer läggas till, tas bort och godkännas med "Spara som granskad".

Fliken "Återkopplingar"

Visar användarinmatningar som Klacksy inte kunde matcha (ingen passande synonym hittades). Utifrån denna lista kan man se vilka synonymer som fortfarande saknas.

Fliken "Mätvärden"

Översikt över alla mål efter status. Hjälper till att följa upp träningens framsteg.

Byggpipeline (CLI)

När mallar har fått nya data-klacksy-target-ankare måste manifestet och de initiala synonymerna genereras på nytt. Följande kommandon körs även automatiskt i CI och i Husky pre-commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Skanna mallar → navigation-targets.json med alla ankare
npm run scan:targets

# 2a. Generera initiala synonymer (alla 4 kärn- + 22 plugin-lokaler, ~2,5 tim)
npm run generate:synonyms

# 2b. Endast kärnlokaler (de/en/fr/it) — snabbt, ca 9 min
npm run generate:synonyms -- --core-only

# 2c. Endast fylla i saknade plugin-lokaler — ca 45 min
npm run generate:synonyms -- --plugins-only

# 3. Kontrollera väckningsordskonsistens
npm run wake-word-lint

Viktigt: Vid npm run måste -- anges så att alternativen skickas vidare till skriptet. Utan -- sväljer npm flaggan och skriptet körs i standardläge.

Alternativ utan npm: npx tsx tools/generate-synonyms.ts --core-only.

API-nyckel

LLM-API-nyckeln söks i denna ordning:

  1. Miljövariabeln SYNONYM_LLM_API_KEY
  2. Databastabellen llm_providers (leverantör deepseek, is_enabled = true) — automatiskt via ett psql-anrop
  3. Annars felmeddelande

Standardleverantör är DeepSeek. Annan leverantör via SYNONYM_LLM_PROVIDER_ID=anthropic (eller en annan konfigurerad LLM-leverantör i inställningarna).

Steg 1 – scan:targets

Genomsöker alla Angular-mallar efter data-klacksy-target-attribut och skapar manifestet Application/Skills/Definitions/navigation-targets.json. Varje nytt ankare visas därefter i fliken "Mål" med status pending.

Steg 2 – generate:synonyms

Skapar initiala synonymer för varje nytt ankare utifrån data-klacksy-label-key och kategorin. Status därefter: generated (måste granskas av en administratör).

Skriptet skriver manifest-kontrollpunkter var 5:e mål, så att ett avbrott inte förlorar redan genererade data.

Steg 3 – wake-word-lint

Kontrollerar konsistensen hos väckningsordsvarianten (Hallo Klacksy / Hej Klacksy / ...) över alla språk. Förhindrar att synonymer skriver över väckningsordet.

Röstläge

Mikrofonsymbolen i chatten aktiverar röstläget. Så fort det är aktivt:

  • Mikrofonen lyssnar kontinuerligt och transkriberar
  • Vid kort tystnad → den hittills gjorda transkriptionen skickas automatiskt

Viktigt: Så fort du börjar skriva i textfältet avslutas röstläget automatiskt — annars skulle mikrofonen skriva över din inskrivna text med sina egna transkriptioner och skicka den i förtid.

Typisk träningsloop

  1. Lägg till ankare i mallen: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Starta om API:et (cachen läses in på nytt vid start)
  4. Öppna fliken "Mål" → nya mål visas med status generated
  5. Granska/komplettera synonymer → "Spara som granskad" → status reviewed
  6. Testa med Klacksy, t.ex. "Klacksy visa mig adresserna"
  7. Om Klacksy inte matchar → fliken "Återkopplingar" → komplettera med saknad synonym
  8. Övervaka fliken "Mätvärden" tills allt är reviewed
