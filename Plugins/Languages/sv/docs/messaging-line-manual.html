Konfigurera LINE-meddelanden

Förutsättningar

För att skicka och ta emot meddelanden via LINE behöver du ett LINE Official Account med en Messaging API-kanal i LINE Developers Console. LINE är särskilt utbrett i Japan, Taiwan och Thailand.

Obs: Push-meddelanden har en månatlig kvot beroende på LINE-plan (den kostnadsfria planen är begränsad). Kontrollera de aktuella villkoren för ditt Official Account-abonnemang.

Steg 1 — Skapa LINE Official Account och Messaging API-kanal

  1. Skapa ett LINE Official Account (via LINE Official Account Manager).
  2. Öppna LINE Developers Console (developers.line.biz) och skapa en Messaging API-kanal respektive koppla ditt Official Account till Messaging API:et.
  3. Utfärda en långlivad kanal-access-token (Issue) på fliken Messaging API.
  4. Notera kanalhemligheten (Channel Secret) på fliken Basic Settings.

Obs: Behandla kanal-access-token och kanalhemligheten som lösenord. Dela dem inte offentligt och lagra dem säkert.

Steg 3 — Skicka meddelanden via chatboten (Klacksy)

Så snart LINE-leverantören är konfigurerad och aktiverad kan chatboten Klacksy skicka meddelanden. Du behöver inte känna till några LINE-användar-ID:n — använd bara namnet på medarbetaren eller klienten: 

"Skicka ett meddelande till Max Muster: Ditt möte är imorgon kl. 14:00."
"Skicka ett meddelande till Anna Exempel: Skiftet har bytts."
"Meddela Peter Müller att hans pass på måndag är inställt."

Klacksy söker automatiskt upp mottagarens lagrade LINE-användar-ID och använder den konfigurerade LINE-leverantören. Utskicket är helt transparent för dig — du arbetar med namn, Klacksy sköter resten.

Förutsättning: Mottagaren måste ha ett LINE-användar-ID (börjar med U…) lagrat i Klacks (under Adress → Kontaktuppgifter). Användar-ID:t blir känt via inkommande meddelanden (synligt i meddelandeinkorgen) — mottagaren måste då ha lagt till ditt Official Account som vän och skickat ett meddelande till det.

Steg 4 — Ta emot inkommande meddelanden (webhook)

För att inkommande LINE-meddelanden ska visas i Klacks måste webhook-URL:en läggas till manuellt i LINE Developers Console.

  1. Kopiera den webhook-URL som visas i Klacks från leverantörsinställningarna: 
    https://{din-domän}/api/messaging/webhook/line
  2. Ange denna URL i LINE Developers Console under Messaging API → Webhook settings som Webhook URL.
  3. Aktivera alternativet „Use webhook".
  4. Se till att din Klacks-instans är offentligt nåbar via HTTPS.
  5. Inkommande meddelanden visas nu i realtid i meddelandeinkorgen.

Felsökning

ProblemMöjlig orsakLösning
Anslutningstestet misslyckas Kanal-access-token ogiltig Utfärda en ny token i LINE Developers Console
Meddelandet levereras inte Mottagaren har inte lagt till Official Account som vän eller har blockerat det Mottagaren måste lägga till kontot som vän i LINE
Utskicket misslyckas Månatlig push-kvot uttömd Kontrollera kvoten för din plan i LINE Official Account Manager
Mottagaren hittas inte LINE-användar-ID inte lagrat Ange användar-ID:t från meddelandeinkorgen under Adress → Kontaktuppgifter
Inkommande meddelanden saknas Webhook-URL inte angiven eller „Use webhook" inaktiverat Kontrollera webhook-inställningarna i LINE Developers Console
