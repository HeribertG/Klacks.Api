Jour- och beredskapstjänst

Dessa inställningar avgör om jour- och beredskapstjänst registreras och till vilken andel den utförda tiden räknas som arbetstid. De gäller som företagsövergripande grundinställning för nyplanerade tjänster.

Jour/beredskap aktiverad

Slår på eller av hela jour-/beredskapslogiken. Om alternativet är inaktiverat ignoreras övriga fält och jour- respektive beredskapstid räknas inte separat.

  • Standard: inaktiverad.

Jour räknas som (%)

Andel av den aktiva jourtiden på plats som räknas som ordinarie arbetstid.

  • Värdeintervall: 0 till 100 procent.
  • Standard: 100 (jourtid räknas fullt ut som arbetstid).

Beredskap räknas som (%)

Andel av den rena beredskapstiden (tillgänglighet utan aktiv insats) som räknas som arbetstid.

  • Värdeintervall: 0 till 100 procent.
  • Standard: 0 (beredskap räknas inte som arbetstid).

Inkludera i periodgränser

Anger om den tillgodoräknade jour- och beredskapstiden räknas in i periodgränserna (t.ex. maximala månads- eller årstimmar).

  • Aktivt: tillgodoräknad tid belastar periodgränserna.
  • Standard: inaktiverad.
