Konfigurera SMS-leverantör

Förutsättningar

För att skicka SMS-meddelanden via Klacks behöver du ett konto hos Twilio eller en Twilio-kompatibel SMS-gateway. Klacks använder Twilios REST-API (Messages-ändpunkten med Basic-autentisering).

Viktigt: SMS-anslutningen är utformad endast för utskick. Inkommande SMS tas inte emot i Klacks.

Steg 1 — Konfigurera Twilio-konto

  1. Registrera dig på twilio.com och verifiera ditt telefonnummer och din e-postadress.
  2. Öppna Twilio Console. På dashboarden hittar du under Account Info de två nödvändiga behörighetsuppgifterna:
    • Account SID — börjar med AC
    • Auth Token — klicka på „Visa"
  3. Skaffa ett avsändarnummer under Phone Numbers → Buy a number (SMS-kapabelt). Detta nummer visas som avsändare vid utgående SMS.
  4. Testkonton: Med ett kostnadsfritt testkonto kan SMS bara skickas till tidigare verifierade nummer och innehåller en testkontonotis.

Obs: Behandla Auth Token som ett lösenord. Dela det inte offentligt och lagra det säkert.

Steg 2 — Konfigurera SMS-leverantör i Klacks

  1. Navigera till Inställningar → Meddelandeleverantörer.
  2. Klicka på Lägg till.
  3. Fyll i fälten enligt följande:
FältBeskrivningExempel
NamnInternt unikt namnsms-twilio
VisningsnamnVisas i gränssnittetSMS (Twilio)
LeverantörstypVälj SMSSMS
Account-SIDAccount SID från Twilio ConsoleACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Auth-tokenAuth Token från Twilio Consolea1b2c3d4e5f6...
AvsändarnummerDitt köpta telefonnummer i internationellt format+41791234567
Gateway-URL (valfritt)Endast för Twilio-kompatibla alternativa gateways — lämna tomt vid Twiliohttps://api.twilio.com
AktiveradSlår på/av leverantörenJa
  1. Klicka på Spara.
  2. Testa anslutningen med knappen Test i leverantörslistan.

Obs om Gateway-URL: Lämna fältet tomt om du använder Twilio — Klacks använder då automatiskt https://api.twilio.com. Ange endast en URL om du använder en alternativ gateway med Twilio-kompatibelt API.

Steg 3 — Skicka meddelanden via chatboten (Klacksy)

Så snart SMS-leverantören är konfigurerad och aktiverad kan chatboten Klacksy skicka meddelanden. Du behöver inte känna till några telefonnummer — använd bara namnet på medarbetaren eller klienten: 

"Skicka ett SMS till Max Muster: Ditt möte är imorgon kl. 14:00."
"Skicka ett SMS till Anna Exempel: Skiftet har bytts."
"Meddela Peter Müller via SMS att hans pass på måndag är inställt."

Klacksy söker automatiskt upp mottagarens lagrade mobilnummer och använder den konfigurerade SMS-leverantören. Utskicket är helt transparent för dig — du arbetar med namn, Klacksy sköter resten.

Förutsättning: Mottagaren måste ha ett mobilnummer lagrat i Klacks (under Adress → Kontaktuppgifter), i internationellt format (t.ex. +41791234567).

Inkommande meddelanden

SMS-anslutningen stödjer inte mottagande — svar på skickade SMS överförs inte till Klacks. Meddelandeinkorgen visar därför inga inkommande meddelanden för denna leverantör.

Felsökning

ProblemMöjlig orsakLösning
Anslutningstestet misslyckas Account-SID eller Auth-token fel Kontrollera båda värdena på dashboarden i Twilio Console
SMS levereras inte Avsändarnumret är inte SMS-kapabelt eller inte aktiverat Kontrollera numret under Phone Numbers i Twilio Console
Mottagaren får inget SMS (testkonto) Mottagarnumret är inte verifierat Verifiera numret i Twilio Console eller uppgradera till ett betalkonto
Mottagaren får inget SMS Telefonnumret är inte i internationellt format Använd formatet +{landskod}{nummer} (t.ex. +41791234567)
Felet „Permission to send an SMS has not been enabled" Målland inte aktiverat i geo-behörigheterna Aktivera landet under Messaging → Geographic Permissions i Twilio Console
Kontosaldo slut Pay-per-use-budget uttömd Fyll på saldo i Twilio Console
