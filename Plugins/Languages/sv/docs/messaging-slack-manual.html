Konfigurera Slack

Förutsättningar

För att skicka och ta emot meddelanden via Slack med Klacks behöver du en Slack-arbetsyta och en Slack-app med lämpliga behörigheter. Klacks använder Slack Web API för utskick och Events API för mottagande.

Obs: Den kostnadsfria Slack-planen räcker för anslutningen. Slack-appar skapas på api.slack.com och är kostnadsfria.

Steg 1 — Skapa en Slack-app

  1. Öppna api.slack.com/apps och klicka på Create New App.
  2. Välj From scratch och ange ett namn (t.ex. Klacks Bot).
  3. Välj den arbetsyta där appen ska installeras.
  4. Navigera till OAuth & Permissions och lägg till följande Bot Token Scopes:
    • chat:write — för att skicka meddelanden till kanaler
    • im:write — för att skicka direktmeddelanden till användare
  5. Klicka på Install to Workspace och bekräfta behörigheterna.
  6. Notera Bot User OAuth Token (börjar med xoxb-).
  7. Navigera till Basic Information och notera Signing Secret.

Steg 2 — Konfigurera Slack i Klacks

  1. Navigera till Inställningar → Meddelandeleverantörer.
  2. Klicka på Lägg till.
  3. Fyll i fälten enligt följande:

Steg 3 — Skicka meddelanden via chatboten (Klacksy)

Så snart Slack-leverantören är konfigurerad och aktiverad kan chatboten Klacksy skicka meddelanden via Slack. Använd namnet på medarbetaren eller ett kanalnamn: 

"Skicka ett meddelande till Max Muster: Ditt möte är imorgon kl. 14:00."
"Skicka ett meddelande till Anna Exempel: Skiftet har bytts."
"Publicera i #team-updates: Schemana för nästa vecka är klara."

Som mottagare används ett kanal-ID (t.ex. C0123456789) eller ett användar-ID (t.ex. U0123456789) — vid ett användar-ID skickas ett direktmeddelande. Om ingen mottagare anges används den konfigurerade standardkanalen. Utskicket är helt transparent för dig — du arbetar med namn, Klacksy sköter resten.

Förutsättning: Slack-användaren måste vara kopplad till motsvarande Klacks-kontakt (under Adress → Kontaktuppgifter). För kanalmeddelanden måste boten vara inbjuden till respektive kanal (/invite @Klacks Bot).

Steg 4 — Ta emot inkommande meddelanden (Events API)

För att inkommande Slack-meddelanden ska visas i Klacks måste Slack-appens Events API konfigureras. Spara och aktivera leverantören i Klacks innan du anger Request-URL:en — Slack kontrollerar URL:en direkt med en Challenge-förfrågan, som Klacks besvarar automatiskt.

  1. Öppna din Slack-app på api.slack.com/apps och navigera till Event Subscriptions.
  2. Aktivera Enable Events och ange den webhook-URL som visas i Klacks som Request URL: 
    https://{din-domän}/api/messaging/webhook/slack
  3. Prenumerera under Subscribe to bot events på händelserna message.im (direktmeddelanden) och message.channels (kanalmeddelanden).
  4. Spara ändringarna och installera appen på nytt i arbetsytan när du uppmanas till det.
  5. Inkommande meddelanden visas nu i realtid i meddelandeinkorgen. Klacks kontrollerar därvid signaturen för varje begäran med den lagrade signeringshemligheten.

Felsökning

ProblemMöjlig orsakLösning
Anslutningstestet misslyckas Bot-token ogiltig eller återkallad Kontrollera token under OAuth & Permissions och installera appen på nytt
Felet channel_not_found eller not_in_channel Boten är inte tillagd i kanalen Bjud in boten till kanalen (/invite) eller kontrollera kanal-ID:t
Meddelande utan mottagare misslyckas Ingen standardkanal konfigurerad Ange en standardkanal i leverantörsinställningarna
Verifiering av Request-URL misslyckas Leverantören är inte sparad/aktiverad i Klacks eller signeringshemligheten är fel Spara och aktivera leverantören i Klacks först och kontrollera signeringshemligheten
Inkommande meddelanden saknas Bot-händelser inte prenumererade Prenumerera på message.im och message.channels under Event Subscriptions
