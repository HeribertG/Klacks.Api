Handbok för makroskript

Inledning

Makroredigeraren gör det möjligt att skriva skript som används som beräkningsunderlag för tjänster, arbetsaktiviteter m.m.

Användningsexempel:

  • Exakt timberäkning för semester eller militärtjänst baserat på sysselsättningsgrad
  • Beräkning av tillägg för nattarbete, helger och helgdagar
  • Flexibel anpassning till nya krav

Obs: Skripttolken körs i en säker sandlådemiljö utan åtkomst till filsystemet eller nätverket. Det är inte möjligt att köra skadlig kod.

Funktion och kategori

Förutom namn och skriptinnehåll har varje makro i makrolistan ytterligare två egenskaper som ställs in via rullgardinsmenyer i redigeraren: Kategori och Funktion. Båda är rena metadata – de ligger utanför skriptet och påverkar inte dess beräkning, utan styr hur Klacks automatiskt hittar och tilldelar rätt makro.

Kategori

Kategorin knyter ett makro till ett visst fackligt användningsområde:

KategoriAnvändning
Ej tilldeladInget särskilt användningsområde (standard för nya makron)
PassTilläggsberäkning för ordinarie pass (natt-, veckoslut- och helgdagstillägg)
SemesterTimberäkning för semester
SjukdomTimberäkning för sjukdom
OlycksfallTimberäkning för olycksfall
Workshop (betald)Betald workshop-/utbildningstid
Workshop (obetald)Obetald workshop-/utbildningstid

Kategorin Pass har en särskild roll: Nyskapade pass tilldelas automatiskt standardmakrot för denna kategori (se "Funktion" nedan). Redan befintliga pass ändras aldrig i efterhand av detta.

Funktion: Anpassad, Standard, Standard (additiv)

Funktionen klassificerar ett makros roll inom sin kategori:

FunktionBetydelse
AnpassadFritt makro utan särskild roll. Valfritt antal per kategori möjligt.
StandardStandardmakrot för denna kategori – tilldelas automatiskt nya pass. Högst ETT makro per kategori får ha denna funktion.
Standard (additiv)Alternativt standardmakro med additiv tilläggslogik (se nedan). Även detta högst ett per kategori, kan finnas utöver "Standard"-makrot.

Viktigt: Funktionen beräknar ingenting i sig själv – den är en etikett. Om tillägg beräknas enligt "högsta vinner" (endast det högsta tillämpliga tillägget räknas) eller additivt (alla tillämpliga tillägg summeras) avgörs av skriptet självt. De två medföljande kategori-"Pass"-makrona visar skillnaden med samma grundstruktur:

  • "AllShift" (Funktion: Standard) – räknar per tidssegment ut det högsta tillämpliga tillägget (natt/WE1/WE2/WE3/helgdag) och använder bara detta.
  • "AllShiftAdditive" (Funktion: Standard (additiv)) – beräknar natt-, veckoslut- och helgdagstillägg oberoende av varandra och summerar dem.

Vilket av de två som tilldelas automatiskt när ett nytt pass skapas styrs av en installationsomfattande inställning ("additiv" eller "högsta satsen vinner"). Per pass går makrot därefter att byta manuellt när som helst – blandad drift är alltså möjlig.

Entydighet: Försöker du spara ytterligare ett makro i samma kategori också som "Standard" eller "Standard (additiv)", blockerar redigeraren sparningen och anger namnet på det makro som redan har tilldelningen. Sätt dess funktion till "Anpassad" först.

Manuella ändringar av "AllShift"/"AllShiftAdditive" avråds. Dessa två makron är mekanismen genom vilken land- och branschspecifika anpassningar förs in automatiskt: Så länge du låter dem vara oförändrade håller Klacks dem automatiskt synkroniserade med reglerna för ditt land respektive din bransch. Redigerar du ett av dem manuellt räknas det från och med då som kundanpassat – framtida automatiska land-/bransch- uppdateringar för detta makro tas då inte längre emot tyst, utan misslyckas med en konflikt tills du löser avvikelsen manuellt. Behöver du en egen tilläggslogik, skapa istället ett nytt makro med funktionen "Anpassad" och tilldela det specifikt till de berörda passen.

Funktioner och procedurer

Viktigt: Funktioner (FUNCTION) och procedurer (SUB) måste definieras före det första anropet. Tolken läser koden uppifrån och ner: en funktion eller procedur är först känd efter att dess definition har bearbetats.

SUB (procedur utan returvärde)

SUB beräkna(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (funktion med returvärde)

FUNCTION fördubbla(x)
    fördubbla = x * 2
ENDFUNCTION

DIM resultat
resultat = fördubbla(21)
OUTPUT 1, resultat

Returnera värden (OUTPUT)

OUTPUT typ, värde

typ och värde är två uttryck åtskilda med kommatecken; båda är valfria (standard 0 respektive "" om de utelämnas). Ett makro får innehålla hur många OUTPUT-rader som helst – varje rad ger ett eget returvärde. Klacks utvärderar därvid endast följande typer:

TypBetydelse
1Huvudresultat (timmar respektive totalbelopp) – tas med även vid värdet 0
10Nattillägg
11Tillägg för veckoslutsdag 1 (t.ex. lördag)
12Tillägg för veckoslutsdag 2 (t.ex. söndag)
13Tillägg för veckoslutsdag 3 (tredje konfigurerbara veckoslutsdagen)
14Helgdagstillägg

Tilläggsrader (typ 10-14) med värdet 0 ignoreras – ett makro behöver alltså inte mata ut en egen rad för varje tilläggstyp, utan bara för tillägg som faktiskt uppstår. Värden som inte kan tolkas som tal hoppas över.

Vid sparande kompileras makrot alltid och körs en gång som test med neutrala testvärden. Syntax- och körtidsfel (t.ex. obalanserade parenteser eller ett hängande uttryck) visas då tillförlitligt istället för att tyst leda till ett makro som inte fungerar.

Exempel: Tilläggsberäkning ("AllShift")

Det medföljande standardmakrot för kategorin "Pass". Beräknar tillägg för natt, helgdag och de tre konfigurerbara veckoslutsdagarna med korrekt hantering av skift över midnatt (segmentindelning) och tillämpar per segment den högsta tillämpliga satsen (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Förklaring

  • Segmentindelning: För skift som passerar midnatt (t.ex. 22:00-06:00) delas skiftet i två segment (fram till midnatt / från midnatt), vart och ett med egen veckodag/helgdagsflagga
  • SegBonusForType: Beräknar tillägget för ett segment och en viss tilläggstyp (10-14) med hänsyn till natt-, helgdags- och veckoslutstillägg
  • WE1/WE2/WE3 istället för lö/sö: weekendday1-3 gör veckoslutsdagarna konfigurerbara (inte alla länder har lördag/söndag som helg)
  • Högsta tillägg per segment: NRate/DRate tar fram den högsta tillämpliga satsen för natt- respektive dagtimmar – highest-wins, ingen stapling
  • HolidayNextDay: Tar hänsyn till om nästa dag är en helgdag (viktigt för nattskift som passerar midnatt)
  • Flera OUTPUT-rader: Rad 1 ger totalsumman, raderna 10-14 ger de enskilda tilläggsbeloppen (se avsnittet "Returnera värden")

Den additiva varianten ("AllShiftAdditive")

Standard-(additiv)-makrot i samma kategori har identiska IMPORT-rader och samma ramstruktur – endast SegBonusForType skiljer sig: istället för den högsta satsen beräknas för varje tilläggstyp oberoende om den gäller, och alla tillämpliga belopp summeras i slutet (ingen highest-wins längre): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Om ett nattskift t.ex. dessutom infaller på en helgdag får det med "AllShift" bara den högre av de två satserna, medan det med "AllShiftAdditive" istället får natt- och helgdagstillägg tillsammans. Resten av skriptet (segmentindelning, summering, OUTPUT-rader) är identiskt med "AllShift" ovan.
