Övertid

Dessa inställningar avgör från när mertid räknas som övertid och med vilket tillägg den ersätts. Över tre nivåer kan trappade tillägg avbildas. Värdena gäller företagsövergripande som grundinställning.

Beräkningsbasis

Referensperiod som nivåernas timtrösklar prövas mot.

  • Dagligen: övertid beräknas per arbetsdag.
  • Veckovis: övertid beräknas per vecka.

Tilläggsläge

Bestämmer hur nivåernas tilläggsvärde tolkas.

  • Multiplikator: faktor på timlönen. Tillägget anges som procentvärde (t.ex. betyder 25 % faktor 1,25, dvs. 25 % påslag).
  • Fast belopp per timme: ett fast belopp per övertidstimme istället för en procentuell faktor.

Nivå 1 till 3

Varje nivå består av ett timtröskelvärde och ett tillägg. Nivån träder in så snart de utförda timmarna överskrider tröskelvärdet inom den valda referensperioden. Högre nivåer avbildar ytterligare trösklar för högre tillägg.

  • Efter timmar: tröskelvärde i timmar från vilket nivån gäller.
  • Tillägg (%): tilläggets storlek för denna nivå, angivet som procentvärde.
  • Lämna icke behövda nivåer tomma; de tillämpas då inte.
