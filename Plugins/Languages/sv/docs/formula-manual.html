Handbok för formelfält

Grundläggande syntax

Varje formelfält skriver ut sitt resultat med kommandot output:

output 1, <uttryck>

Den första parametern 1 är meddelandetypen och måste alltid vara 1. Den andra parametern är värdet som ska skrivas ut.

Enkla exempel:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " poster"

Tillgängliga variabler

De tillgängliga variablerna listas under fliken Variabler och kan där fyllas i med testvärden. Beroende på rapporttyp finns olika variabler tillgängliga:

Villkorlig logik

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "många poster"
ELSEIF totalRows > 0 THEN
    output 1, "få poster"
ELSE
    output 1, "inga poster"
ENDIF

IF på en rad

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (kortform)

output 1, IIF(totalRows > 0, "OK", "Tom")

Variabler och loopar

DIM i, summa
summa = 0
FOR i = 1 TO totalRows
    summa = summa + 1
NEXT
output 1, CStr(summa)

Praktiska exempel

Antal poster med text

output 1, CStr(totalRows) & " poster"

Avrundat värde (1 decimal)

output 1, CStr(Round(totalValue, 1))

Timmar som h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Villkorlig utskrift

IF totalRows = 0 THEN
    output 1, "Ingen frånvaro"
ELSE
    output 1, CStr(totalRows) & " frånvaroposter (Totalt: " & CStr(totalValue) & ")"
ENDIF

Beräkna genomsnitt

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/dag"
ELSE
    output 1, "-"
ENDIF
Obs: Skripttolken körs i en säker sandlåda utan åtkomst till filsystemet eller nätverket.
