Konfigurera Signal-meddelanden

Förutsättningar

För att skicka Signal-meddelanden via Klacks behöver du en självhostad instans av signal-cli-rest-api. Det är ett open source-projekt som gör Signal tillgängligt via ett REST-gränssnitt.

  • Docker måste vara installerat på servern
  • Ett telefonnummer som registreras hos Signal (dedikerat nummer rekommenderas)
  • Docker-avbildningen: bbernhard/signal-cli-rest-api

Viktigt: Signal-anslutningen är utformad endast för utskick. Inkommande Signal-meddelanden tas inte emot i Klacks.

Steg 1 — Konfigurera signal-cli-rest-api

  1. Starta containern med Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Koppla ditt Signal-nummer via QR-länkförfarandet: Öppna i webbläsaren 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    och skanna den visade QR-koden med Signal-appen på telefonen där numret är registrerat (Inställningar → Kopplade enheter → Koppla enhet). Containern kopplas därmed som en sekundär enhet.
  3. Alternativt kan du registrera numret på egen hand via API:et — detaljer finns i projektets dokumentation.
  4. Testa API:et med en hälsokontroll: 
    curl http://localhost:8080/v1/about

Obs: Fler detaljer om konfigurationen finns i signal-cli-rest-api-dokumentationen.

Steg 2 — Konfigurera Signal i Klacks

  1. Navigera till Inställningar → Meddelandeleverantörer.
  2. Klicka på Lägg till.
  3. Fyll i fälten enligt följande:
FältBeskrivningExempel
NamnInternt unikt namnsignal-main
VisningsnamnVisas i gränssnittetSignal
LeverantörstypVälj SignalSignal
Signal-nummerDet registrerade telefonnumret i internationellt format+41791234567
Signal-CLI API-URLURL till signal-cli-rest-api-containern. Om containern körs på samma server som Klacks kan http://localhost:8080 anges här.http://localhost:8080
AktiveradSlår på/av leverantörenJa
  1. Klicka på Spara.
  2. Testa anslutningen med knappen Test i leverantörslistan. Testet kontrollerar om det angivna numret är registrerat i containern.

Obs: Klacks skickar meddelanden via ändpunkten POST /v2/send i containern.

Steg 3 — Skicka meddelanden via chatboten (Klacksy)

Så snart Signal-leverantören är konfigurerad och aktiverad kan chatboten Klacksy skicka meddelanden. Du behöver inte känna till några telefonnummer — använd bara namnet på medarbetaren eller klienten: 

"Skicka ett meddelande till Max Muster: Ditt möte är imorgon kl. 14:00."
"Skicka ett Signal-meddelande till Anna Exempel: Skiftet har bytts."
"Meddela Peter Müller att hans pass på måndag är inställt."

Klacksy söker automatiskt upp mottagarens lagrade mobilnummer och använder den konfigurerade Signal-leverantören. Utskicket är helt transparent för dig — du arbetar med namn, Klacksy sköter resten.

Förutsättning: Mottagaren måste ha ett mobilnummer lagrat i Klacks (under Adress → Kontaktuppgifter), i internationellt format (t.ex. +41791234567). Även för broadcast-meddelanden använder Signal-utskicket det lagrade mobilnumret.

Inkommande meddelanden

Signal-anslutningen stödjer inte mottagande — svar på skickade meddelanden överförs inte till Klacks. Meddelandeinkorgen visar därför inga inkommande meddelanden för denna leverantör.

Felsökning

ProblemMöjlig orsakLösning
Anslutningstestet misslyckas Containern är inte nåbar Kontrollera om Docker-containern körs (docker ps) och att API-URL:en är korrekt
Anslutningstestet misslyckas Numret är inte registrerat i containern Upprepa kopplingen via QR-länkförfarandet
Meddelandet levereras inte Mottagaren använder inte Signal eller numret är fel Se till att mottagaren har Signal installerat och att numret är lagrat i formatet +{landskod}{nummer}
Kopplingen har gått förlorad Enheten kopplades bort i Signal-appen Koppla containern på nytt via QR-länken
Containern startar inte Port 8080 redan upptagen Använd en annan port: -p 9090:8080 och anpassa API-URL:en i Klacks
