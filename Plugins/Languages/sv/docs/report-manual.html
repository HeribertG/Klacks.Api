Handbok för Report Designer

Rapportstruktur

En rapport består av tre delar:

  • Rubrik – skrivs ut högst upp på varje sida
  • Brödtext – innehåller datatabellerna
  • Sidfot – skrivs ut längst ner på varje sida

Varje del kan redigeras via fliken Design i rapportredigeraren.

Sidhuvud

Sidhuvudet har tre zoner: vänster, mitten och höger.

Varje zon kan innehålla:

  • Fält – databasfält som fylls i automatiskt
  • Fritext – manuellt inmatad text
  • Bilder – t.ex. en företagslogotyp (laddas upp via bildhanteraren)

Rader kan läggas till eller tas bort via verktygsfältet.

Huvudtabeller

Huvudtexten innehåller en eller flera tabeller.

ÅtgärdBeskrivning
Lägg till kolumnVia +-symbolen eller genom att dra och släppa från fältlistan
KolumnbreddJustera genom att dra i kolumnkanten
KolumnordningFlytta med dra och släpp
Ta bort kolumnI kolumnredigeraren med hjälp av raderingsikonen

Varje tabell är kopplad till ett DataSet (t.ex. arbetsplan, adresser).

Slå ihop fält (Merged Fields)

Merged Fields möjliggör flera datakopplingar i en enda kolumn.

  • Klicka på Lägg till fält i kolumnredigeraren för att lägga till ytterligare fält i samma kolumn
  • Värdena visas under varandra eller med en avgränsare
  • Avgränsaren kan konfigureras i fältdialogrutan (t.ex. kommatecken, mellanslag, radbrytning)

Tabellens fotrad

En fotrad kan visas under varje tabell.

  • SUM-fält: Numeriska kolumner kan summeras automatiskt
  • Etikett: Summans etikett kan visas eller döljas
  • Aktiveras via kolumnredigeraren under fliken ”Fotrad”

Fritt textfält

Fritt textfält kan infogas före eller efter datatabellerna.

EgenskapBeskrivning
PositionKan väljas före eller efter data
InnehållValfri text, t.ex. anvisningar, villkor eller signaturfält
UtformningTeckensnitt, storlek och justering kan konfigureras

Varje cell och varje fritextfält kan formateras individuellt:

Cellramar

Ramlinjerna kan konfigureras individuellt för varje cell.

EgenskapAlternativ
SidorÖvre, högra, nedre, vänstra (enskilt eller alla)
LinjestilTunn, medel, tjock, streckad, dubbel

Ramarna ställs in under Ramar i kolumnredigeraren.

Sidinställningar

På fliken Allmänt kan utskriftsinställningarna anpassas:

  • Orientering: Stående (Portrait) eller liggande (Landscape)
  • Pappersstorlek: A4, A3, B4 (JIS), B5 (JIS) eller Letter
  • Sidmarginaler: Övre, högra, nedre, vänstra i mm

Visningsalternativ (Designer)

I fliken Design finns ytterligare alternativ tillgängliga för datakällan Arbetsplan (Schedule):

  • Sammanfatta poster per dag: Flera poster på samma dag sammanfattas i en rad
  • Visa hela perioden: Alla dagar i perioden visas, även om det inte finns några poster

Parametrar

Parametrar efterfrågas när en rapport körs. Deras värden finns tillgängliga i radfilter och formler och kan dessutom begränsa sökningen i datakällan. De skapas på fliken Parametrar.

FältBetydelse
NyckelTekniskt namn. Måste börja med en bokstav och får endast innehålla bokstäver, siffror och understreck. Unikt för varje rapport.
BenämningText som visas när rapporten körs.
TypText, siffra, datum, ja/nej eller val.
StandardvärdeAnvänds om inget matas in vid körning.
ValsvärdenEndast för typen «Välj»: de tillåtna värdena, åtskilda med kommatecken.
PåverkarAnger om värdet dessutom ska överföras till datakällan.
Obligatoriskt fältRapporten kan inte köras utan ett värde.

Parametrar i filter och formler

Varje parameter finns i skriptet under nyckeln med prefixet param_ — från nyckeln region blir alltså param_region. Prefixet förhindrar att en parameter döljer ett radvärde med samma namn. Det aktuella namnet visas under varje parameter.

Värdet omvandlas till den valda typen innan det utvärderas:

  • Tal: som tal; en ogiltig inmatning blir 0
  • Ja/Nej: sant vid 1, true, wahr eller yes, annars falskt
  • Text, datum, val: som text

Koppla parametrar till datakällan

Via ”Påverkar” begränsar en parameter ytterligare vilka data som överhuvudtaget laddas:

InställningEffekt
Endast filter och formlerVärdet används uteslutande i skriptet (standard).
Frågans gruppVärdet ersätter den grupp för vilken data laddas.
Person i fråganVärdet ersätter den person för vilken data laddas.
Frågans startdatumVärdet ersätter periodens startdatum.
Sökningens slutdatumVärdet ersätter periodens slutdatum.

Datumvärden måste anges i formatet ÅÅÅÅ-MM-DD eller DD.MM.ÅÅÅÅ. Ett värde i annat format ignoreras för att undvika att sökningen obemärkt förblir tom. Ett tomt värde innebär att den ursprungliga inställningen förblir oförändrad.
