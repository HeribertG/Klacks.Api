Odpoczynek wyrównawczy

Te ustawienia sterują odpoczynkiem wyrównawczym: jeśli ustawowy minimalny czas odpoczynku między dwoma dyżurami nie zostanie zachowany, brakujący odpoczynek musi zostać nadrobiony jako odpoczynek wyrównawczy w określonym terminie. Wartości obowiązują jako domyślne dla całej firmy.

Odpoczynek wyrównawczy aktywny

Włącza lub wyłącza sprawdzanie odpoczynku wyrównawczego. Jeśli opcja jest wyłączona, termin i automatyczne planowanie nie są stosowane.

  • Domyślnie: wyłączony.

Termin (dni)

Liczba dni, w ciągu których odpoczynek wyrównawczy musi zostać przyznany po niezachowaniu minimalnego czasu odpoczynku.

  • Wartość całkowita od 0 wzwyż.
  • Przykład: 14 oznacza, że odpoczynek wyrównawczy musi nastąpić w ciągu dwóch tygodni.

Planowanie automatyczne

Określa, czy system samodzielnie planuje należny odpoczynek wyrównawczy w grafiku. Jeśli opcja jest wyłączona, tylko sygnalizowany jest brakujący odpoczynek wyrównawczy.

  • Domyślnie: wyłączony.

Pochodzenie standardowego czasu odpoczynku

Próg standardowego czasu odpoczynku, po którego przekroczeniu wyzwalany jest odpoczynek wyrównawczy, jest wyprowadzany z minimalnej przerwy w domyślnych ustawieniach planowania (reguły planowania / wartości domyślne) i można go tam edytować; nie jest on zarządzany na tej karcie. Zmiana minimalnej przerwy tam wpływa również na odpoczynek wyrównawczy.
