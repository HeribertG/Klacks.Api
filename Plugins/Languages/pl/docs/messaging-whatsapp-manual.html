Konfiguracja WhatsApp

Wymagania wstępne

Aby wysyłać i odbierać wiadomości przez WhatsApp z Klacks, potrzebujesz konta dewelopera Meta i aplikacji Meta z aktywnym produktem WhatsApp. Klacks używa WhatsApp Cloud API platformy Meta Business do wysyłania i webhooków Meta do odbierania.

Uwaga: konfiguracja i testy nie wiążą się z żadnymi kosztami. Podczas tworzenia aplikacji Meta automatycznie udostępnia bezpłatny testowy numer telefonu.

Ważne — numer nadawcy to nie Twój prywatny numer. Numeru telefonu, który jest już używany w zwykłej aplikacji WhatsApp, nie można zarejestrować dla Cloud API, a zarejestrowanego numeru nie da się już używać w WhatsApp Messenger. Dlatego użyj numeru testowego udostępnionego przez Meta albo własnego numeru wykorzystywanego wyłącznie służbowo. Twój prywatny WhatsApp w telefonie służy jako odbiorca do testów — nie jako nadawca.

Krok 1 — utwórz aplikację Meta

  1. Otwórz developers.facebook.com/apps i kliknij Create app.
  2. Wybierz jako przypadek użycia Other, a jako typ aplikacji Business.
  3. W panelu kliknij przy produkcie WhatsApp na Set up. Zostanie przy tym automatycznie utworzony i zarejestrowany testowy numer telefonu.
  4. Przejdź w nawigacji po lewej stronie do WhatsApp → API Setup.
  5. Zapisz Phone number ID i wygeneruj token dostępu przez Generate access token.
  6. Zapisz w App settings → Basic wartość App Secret — jest potrzebna do weryfikacji podpisu wiadomości przychodzących.

Uwaga — dwa podobne identyfikatory: W panelu API Setup Phone number ID i WhatsApp Business Account ID znajdują się bezpośrednio jeden pod drugim. Klacks potrzebuje Phone number ID. Przy błędnym identyfikatorze test połączenia i tak zgłasza sukces, ale każda wysyłka się nie powiedzie.

Uwaga — czas życia tokena: Token utworzony przez Generate access token jest tymczasowym tokenem testowym i wygasa po krótkim czasie. Do pracy ciągłej utwórz w Meta Business Manager token stały przy użyciu użytkownika systemowego.

Krok 2 — odblokuj numer odbiorcy

Numer testowy może wysyłać tylko do wcześniej odblokowanych odbiorców. Dodaj w panelu API Setup pod To → Manage phone number list swój numer WhatsApp. Meta wyśle na ten numer kod potwierdzający, który musisz wprowadzić.

Bez tego kroku Meta odrzuci każdą wysyłkę na ten numer. Gdy później zaczniesz używać własnego, zweryfikowanego numeru firmowego, odblokowanie nie będzie już potrzebne.

Krok 4 — okno 24 godzin

WhatsApp różni się tu zasadniczo od Telegrama czy Slacka. Dowolne wiadomości tekstowe firma może wysyłać tylko dopóki otwarte jest okno obsługi klienta. To okno otwiera odbiorca, pisząc na Twój numer WhatsApp. Pozostaje ono otwarte przez 24 godziny i przedłuża się z każdą kolejną wiadomością odbiorcy.

Poza tym oknem Meta dopuszcza wyłącznie wcześniej zatwierdzone szablony wiadomości. Klacks wysyła obecnie wyłącznie dowolne wiadomości tekstowe i tym samym nie może samodzielnie rozpocząć konwersacji.

Co to dla Ciebie oznacza: Poproś jednorazowo swoich pracowników o wysłanie wiadomości na numer WhatsApp Klacks. Potem wysyłka jest możliwa przez 24 godziny, a każda odpowiedź przedłuża okno. Gdy okno jest zamknięte, wysyłka zgłasza błąd — to nie jest problem konfiguracji, lecz wymóg WhatsAppa.

Jeśli musisz docierać do pracowników niezależnie od tego okna, lepszymi dostawcami są Telegram lub Signal — tam takie ograniczenie nie występuje.

Krok 5 — Wysyłanie wiadomości przez chatbota (Klacksy)

Gdy dostawca WhatsApp jest skonfigurowany i aktywowany, chatbot Klacksy może wysyłać wiadomości przez WhatsApp. Użyj imienia i nazwiska pracownika: 

"Wyślij wiadomość do Jana Kowalskiego: Twoje spotkanie jest jutro o 14:00."
"Wyślij Annie Nowak wiadomość: Zmiana została zamieniona."

Jako odbiorca służy numer telefonu w formacie międzynarodowym bez wiodącego zera i bez znaku plus (np. 41791234567 dla 079 123 45 67). Wysyłka jest dla Ciebie całkowicie przezroczysta — Ty pracujesz z imionami, Klacksy zajmuje się resztą.

Wymaganie: numer WhatsApp musi być powiązany z odpowiednim kontaktem Klacks (pod Adres → Dane kontaktowe), a okno 24 godzin z kroku 4 musi być otwarte.

Krok 6 — odbieranie wiadomości przychodzących (webhooki)

Aby wyświetlić przychodzące wiadomości WhatsApp w Klacks, trzeba skonfigurować webhook aplikacji Meta. Zapisz i aktywuj dostawcę w Klacks, zanim wprowadzisz Callback URL — Meta natychmiast sprawdza URL zapytaniem weryfikacyjnym, na które Klacks odpowiada automatycznie na podstawie Verify Token.

  1. Otwórz swoją aplikację Meta i przejdź do WhatsApp → Configuration.
  2. Kliknij przy Webhook na Edit i wprowadź:
    • Callback URL: wyświetlony w Klacks URL webhooka 
      https://{twoja-domena}/api/messaging/webhook/whatsapp
    • Verify token: dokładnie tę samą wartość, którą wprowadziłeś w kroku 3 w polu Verify Token
  3. Kliknij Verify and save.
  4. Zasubskrybuj pod Webhook fields pole messages.
  5. Wiadomości przychodzące pojawiają się teraz w czasie rzeczywistym w skrzynce odbiorczej wiadomości. Klacks sprawdza przy tym podpis każdego zapytania (X-Hub-Signature-256) zapisanym App Secret.

Callback URL musi być osiągalny z zewnątrz przez HTTPS. Przy instalacji w sieci firmowej bez publicznego adresu wysyłka działa, ale nie można odbierać wiadomości.
