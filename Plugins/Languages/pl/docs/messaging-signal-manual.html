Konfiguracja Signal

Wymagania wstępne

Aby wysyłać wiadomości Signal przez Klacks, potrzebujesz samodzielnie hostowanej instancji signal-cli-rest-api. Jest to projekt open-source, który udostępnia Signal przez interfejs REST.

  • Docker musi być zainstalowany na serwerze
  • Numer telefonu, który zostanie zarejestrowany w Signal (zalecany dedykowany numer)
  • Obraz Docker: bbernhard/signal-cli-rest-api

Ważne: integracja Signal jest zaprojektowana tylko do wysyłania. Przychodzące wiadomości Signal nie są odbierane w Klacks.

Krok 1 — skonfiguruj signal-cli-rest-api

  1. Uruchom kontener przez Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Połącz swój numer Signal metodą linku QR: otwórz w przeglądarce 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    i zeskanuj wyświetlony kod QR aplikacją Signal na telefonie, na którym numer jest zarejestrowany (Ustawienia → Powiązane urządzenia → Powiąż urządzenie). Kontener zostaje w ten sposób powiązany jako urządzenie dodatkowe.
  3. Alternatywnie możesz samodzielnie zarejestrować numer przez API — szczegóły znajdziesz w dokumentacji projektu.
  4. Przetestuj API kontrolą stanu: 
    curl http://localhost:8080/v1/about

Uwaga: więcej szczegółów dotyczących konfiguracji znajdziesz w dokumentacji signal-cli-rest-api.

Krok 2 — Skonfiguruj Signal w Klacks

  1. Przejdź do Ustawienia → Dostawcy wiadomości.
  2. Kliknij Dodaj.
  3. Wypełnij pola w następujący sposób:
PoleOpisPrzykład
NazwaWewnętrzna unikalna nazwasignal-main
Nazwa wyświetlanaWyświetlana w interfejsieSignal
Typ dostawcyWybierz SignalSignal
Numer SignalZarejestrowany numer telefonu w formacie międzynarodowym+41791234567
URL API Signal-CLIURL kontenera signal-cli-rest-api. Jeśli kontener działa na tym samym serwerze co Klacks, może tu być http://localhost:8080.http://localhost:8080
AktywnyWłącza/wyłącza dostawcęTak
  1. Kliknij Zapisz.
  2. Przetestuj połączenie przyciskiem Test na liście dostawców. Test sprawdza, czy podany numer jest zarejestrowany w kontenerze.

Uwaga: Klacks wysyła wiadomości przez punkt końcowy POST /v2/send kontenera.

Krok 3 — Wysyłanie wiadomości przez chatbota (Klacksy)

Gdy dostawca Signal jest skonfigurowany i aktywowany, chatbot Klacksy może wysyłać wiadomości. Nie musisz znać numerów telefonów — po prostu użyj imienia i nazwiska pracownika lub klienta: 

"Wyślij wiadomość do Jana Kowalskiego: Twoje spotkanie jest jutro o 14:00."
"Wyślij Annie Nowak wiadomość Signal: Zmiana została zamieniona."
"Powiadom Piotra Wiśniewskiego, że jego dyżur w poniedziałek odpada."

Klacksy automatycznie wyszukuje zapisany numer komórkowy odbiorcy i używa skonfigurowanego dostawcy Signal. Wysyłka jest dla Ciebie całkowicie przezroczysta — Ty pracujesz z imionami, Klacksy zajmuje się resztą.

Wymaganie: u odbiorcy musi być zapisany numer komórkowy w Klacks (pod Adres → Dane kontaktowe), w formacie międzynarodowym (np. +41791234567). Również przy wiadomościach rozgłoszeniowych wysyłka Signal opiera się na zapisanym numerze komórkowym.

Wiadomości przychodzące

Integracja Signal nie obsługuje odbioru — odpowiedzi na wysłane wiadomości nie są przekazywane do Klacks. Skrzynka odbiorcza wiadomości nie pokazuje zatem dla tego dostawcy żadnych wiadomości przychodzących.

Rozwiązywanie problemów

ProblemMożliwa przyczynaRozwiązanie
Test połączenia nie powiódł się Kontener niedostępny Sprawdź, czy kontener Docker działa (docker ps) i czy URL API jest poprawny
Test połączenia nie powiódł się Numer niezarejestrowany w kontenerze Powtórz powiązanie metodą linku QR
Wiadomość nie jest dostarczana Odbiorca nie używa Signal lub numer jest nieprawidłowy Upewnij się, że odbiorca ma zainstalowany Signal, a numer jest zapisany w formacie +{numer kierunkowy kraju}{numer}
Powiązanie utracone Urządzenie zostało odłączone w aplikacji Signal Powiąż kontener ponownie przez link QR
Kontener się nie uruchamia Port 8080 już zajęty Użyj innego portu: -p 9090:8080 i dostosuj URL API w Klacks
