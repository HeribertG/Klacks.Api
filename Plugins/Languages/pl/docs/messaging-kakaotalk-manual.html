Konfiguracja KakaoTalk

Wymagania wstępne

Aby wysyłać wiadomości przez KakaoTalk, potrzebujesz aplikacji na developers.kakao.com (Kakao Developers). KakaoTalk jest dominującym komunikatorem w Korei Południowej. Integracja z Klacks korzysta z Kakao Developer API („wysyłanie wiadomości do znajomych").

Ważne ograniczenia Kakao Developer API:

  • Integracja jest zaprojektowana tylko do wysyłania — bez odbioru.
  • Token dostępu jest krótkotrwały (ok. 6 godzin) i musi być odnawiany i ponownie wprowadzany poza Klacks.
  • Wiadomości można wysyłać tylko do użytkowników, którzy są połączeni jako „znajomi" Kakao aplikacji i wyrazili zgodę na otrzymywanie wiadomości.
  • Do produkcyjnych wiadomości biznesowych (AlimTalk) w Korei wymagany jest kanał biznesowy przez autoryzowane agencje — ta integracja tego nie obejmuje, korzysta z Developer API.

Krok 1 — Skonfiguruj aplikację Kakao Developers

  1. Utwórz aplikację na developers.kakao.com.
  2. Aktywuj Kakao Login dla aplikacji.
  3. Odblokuj zakresy talk_message i friends.
  4. Uzyskaj token dostępu przez przepływ OAuth Kakao Login (użytkownik, w którego imieniu jest wysyłana wiadomość, musi wyrazić zgodę na zakresy).

Uwaga: traktuj token dostępu jak hasło. Nie udostępniaj go publicznie i przechowuj bezpiecznie.

Krok 2 — Skonfiguruj KakaoTalk w Klacks

  1. Przejdź do Ustawienia → Dostawcy wiadomości.
  2. Kliknij Dodaj.
  3. Wypełnij pola w następujący sposób:
PoleOpisPrzykład
NazwaWewnętrzna unikalna nazwakakaotalk-main
Nazwa wyświetlanaWyświetlana w interfejsieKakaoTalk
Typ dostawcyWybierz KakaoTalkKakaoTalk
Token dostępuToken uzyskany przez przepływ OAuthkakao-access-token...
AktywnyWłącza/wyłącza dostawcęTak
  1. Kliknij Zapisz.
  2. Przetestuj połączenie przyciskiem Test na liście dostawców.

Ważne: token dostępu wygasa po ok. 6 godzinach. Klacks nie odnawia go automatycznie — musisz odnowić go zewnętrznie (przepływ refresh token Kakao) i ponownie wprowadzić w Klacks.

Krok 3 — Wysyłanie wiadomości przez chatbota (Klacksy)

Gdy dostawca KakaoTalk jest skonfigurowany i aktywowany, chatbot Klacksy może wysyłać wiadomości. Nie musisz znać żadnych ID — po prostu użyj imienia i nazwiska pracownika lub klienta: 

"Wyślij wiadomość do Jana Kowalskiego: Twoje spotkanie jest jutro o 14:00."
"Wyślij Annie Nowak wiadomość: Zmiana została zamieniona."
"Powiadom Piotra Wiśniewskiego, że jego dyżur w poniedziałek odpada."

Klacksy automatycznie wyszukuje zapisany identyfikator odbiorcy i używa skonfigurowanego dostawcy KakaoTalk. Wysyłka jest dla Ciebie całkowicie przezroczysta — Ty pracujesz z imionami, Klacksy zajmuje się resztą.

Wymaganie: u odbiorcy musi być zapisany Friend-UUID z Kakao Friends API w Klacks (pod Adres → Dane kontaktowe). Odbiorca musi być połączony z aplikacją jako „znajomy" Kakao — do innych użytkowników wysyłka nie jest możliwa.

Wiadomości przychodzące

Integracja KakaoTalk nie obsługuje odbioru — odpowiedzi na wysłane wiadomości nie są przekazywane do Klacks. Skrzynka odbiorcza wiadomości nie pokazuje zatem dla tego dostawcy żadnych wiadomości przychodzących.
