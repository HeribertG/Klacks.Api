Konfiguracja Slack

Wymagania wstępne

Aby wysyłać i odbierać wiadomości przez Slack z Klacks, potrzebujesz przestrzeni roboczej Slack i aplikacji Slack z odpowiednimi uprawnieniami. Klacks używa Slack Web API do wysyłania i Events API do odbierania.

Uwaga: darmowy plan Slack wystarcza do integracji. Aplikacje Slack tworzy się na api.slack.com i są darmowe.

Krok 1 — utwórz aplikację Slack

  1. Otwórz api.slack.com/apps i kliknij Create New App.
  2. Wybierz From scratch i nadaj nazwę (np. Klacks Bot).
  3. Wybierz przestrzeń roboczą, w której ma zostać zainstalowana aplikacja.
  4. Przejdź do OAuth & Permissions i dodaj następujące Bot Token Scopes:
    • chat:write — do wysyłania wiadomości na kanały
    • im:write — do wysyłania wiadomości bezpośrednich do użytkowników
  5. Kliknij Install to Workspace i potwierdź uprawnienia.
  6. Zapisz Bot User OAuth Token (zaczyna się od xoxb-).
  7. Przejdź do Basic Information i zapisz Signing Secret.

Krok 2 — Skonfiguruj Slack w Klacks

  1. Przejdź do Ustawienia → Dostawcy wiadomości.
  2. Kliknij Dodaj.
  3. Wypełnij pola w następujący sposób:

Krok 3 — Wysyłanie wiadomości przez chatbota (Klacksy)

Gdy dostawca Slack jest skonfigurowany i aktywowany, chatbot Klacksy może wysyłać wiadomości przez Slack. Użyj imienia i nazwiska pracownika lub nazwy kanału: 

"Wyślij wiadomość do Jana Kowalskiego: Twoje spotkanie jest jutro o 14:00."
"Wyślij Annie Nowak wiadomość: Zmiana została zamieniona."
"Opublikuj w #team-updates: Plany dyżurów na przyszły tydzień są gotowe."

Jako odbiorca służy ID kanału (np. C0123456789) lub ID użytkownika (np. U0123456789) — przy ID użytkownika wysyłana jest wiadomość bezpośrednia. Jeśli nie podano odbiorcy, używany jest skonfigurowany kanał domyślny. Wysyłka jest dla Ciebie całkowicie przezroczysta — Ty pracujesz z imionami, Klacksy zajmuje się resztą.

Wymaganie: użytkownik Slack musi być powiązany z odpowiednim kontaktem Klacks (pod Adres → Dane kontaktowe). Do wiadomości kanałowych bot musi być zaproszony do odpowiedniego kanału (/invite @Klacks Bot).

Krok 4 — odbieranie wiadomości przychodzących (Events API)

Aby wyświetlić przychodzące wiadomości Slack w Klacks, trzeba skonfigurować Events API aplikacji Slack. Zapisz i aktywuj dostawcę w Klacks, zanim wprowadzisz Request URL — Slack natychmiast sprawdza URL zapytaniem challenge, na które Klacks odpowiada automatycznie.

  1. Otwórz swoją aplikację Slack na api.slack.com/apps i przejdź do Event Subscriptions.
  2. Aktywuj Enable Events i jako Request URL wprowadź wyświetlony w Klacks URL webhooka: 
    https://{twoja-domena}/api/messaging/webhook/slack
  3. Subskrybuj pod Subscribe to bot events zdarzenia message.im (wiadomości bezpośrednie) i message.channels (wiadomości kanałowe).
  4. Zapisz zmiany i ponownie zainstaluj aplikację w przestrzeni roboczej, jeśli zostaniesz o to poproszony.
  5. Wiadomości przychodzące pojawiają się teraz w czasie rzeczywistym w skrzynce odbiorczej wiadomości. Klacks sprawdza przy tym podpis każdego zapytania zapisanym Signing Secret.
