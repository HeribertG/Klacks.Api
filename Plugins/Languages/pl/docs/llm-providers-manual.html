Szukaj dostawców LLM — instrukcja

Do czego służy ta funkcja?

Ten widok proponuje Ci dostawców LLM, których nie masz jeszcze na swojej liście, i dodaje wybranych jednym kliknięciem. Dzięki temu nie musisz ręcznie wpisywać nazwy i podstawowego URL. Proponowani są wyłącznie dostawcy API kompatybilni z OpenAI — czyli dokładnie ten rodzaj usług, z jakich korzystają już Twoi skonfigurowani dostawcy.

Kolumny tabeli

Nazwa dostawcy

Nazwa wyświetlana dostawcy (np. „OpenRouter", „xAI (Grok)").

Podstawowy URL

Adres API, przez który następuje komunikacja z dostawcą (np. https://api.x.ai/v1/). Dokładnie ten URL zostanie później użyty podczas tworzenia.

Źródło

Wskazuje, skąd pochodzi propozycja:

  • Katalog — z na stałe zapisanej, sprawdzonej listy znanych dostawców. Podstawowe URL-e są zweryfikowane i dzięki temu wiarygodne.
  • Sieć — znalezione przez wyszukiwanie internetowe i automatycznie ocenione. Te wpisy pojawiają się tylko wtedy, gdy wyszukiwanie internetowe jest skonfigurowane w ustawieniach. Są pomocne, ale w razie wątpliwości warto krótko sprawdzić podstawowy URL.

Dostępność

Przed wyświetleniem każda propozycja jest testowana na żywo (wywołanie punktu końcowego /models):

  • Dostępny — API odpowiada, dostawca działa.
  • Dostępny (wymaga klucza) — API istnieje, ale wymaga klucza API. Adres jest więc poprawny.
  • Niedostępny — adres nie odpowiada. Takich wpisów nie można wybrać.

Dodawanie dostawcy

Zaznacz jednego lub kilku dostawców i kliknij poniżej „Dodaj wybór". Wybrani dostawcy zostają utworzeni jako dezaktywowani i bez klucza API. Już istniejący dostawcy nie są w ogóle proponowani.

Kolejne kroki po dodaniu

Nowo dodany dostawca nie jest jeszcze aktywny. Otwórz go na liście, wprowadź klucz API i aktywuj go. Następnie działa dokładnie tak jak pozostali Twoi dostawcy. Poszczególne modele dostawcy zarządzasz nadal osobno przez zarządzanie modelami.
