Konfiguracja Zalo

Wymagania wstępne

Aby wysyłać wiadomości przez Zalo, potrzebujesz Zalo Official Account (OA) na oa.zalo.me oraz aplikacji na developers.zalo.me. Zalo jest wiodącym komunikatorem w Wietnamie.

Ważne: integracja Zalo jest zaprojektowana tylko do wysyłania. Ponadto obowiązują ograniczenia platformy Zalo:

  • Token dostępu wygasa po ok. 25 godzinach i musi być odnawiany i ponownie wprowadzany poza Klacks.
  • Wiadomości można wysyłać tylko do użytkowników, którzy wcześniej mieli interakcję z Official Account (okno interakcji).

Krok 1 — skonfiguruj Zalo Official Account i aplikację

  1. Utwórz Official Account na oa.zalo.me.
  2. Utwórz aplikację na developers.zalo.me.
  3. Połącz Official Account z aplikacją.
  4. Uzyskaj token dostępu przez przepływ OAuth konsoli Zalo Developer.

Uwaga: traktuj token dostępu jak hasło. Nie udostępniaj go publicznie i przechowuj bezpiecznie.

Krok 2 — Skonfiguruj Zalo w Klacks

  1. Przejdź do Ustawienia → Dostawcy wiadomości.
  2. Kliknij Dodaj.
  3. Wypełnij pola w następujący sposób:
PoleOpisPrzykład
NazwaWewnętrzna unikalna nazwazalo-oa
Nazwa wyświetlanaWyświetlana w interfejsieZalo
Typ dostawcyWybierz ZaloZalo
Token dostępuToken uzyskany przez przepływ OAuthzalo-oa-access-token...
OA-IDID Twojego Official Account (informacyjne, służy do przypisania)987654321...
AktywnyWłącza/wyłącza dostawcęTak
  1. Kliknij Zapisz.
  2. Przetestuj połączenie przyciskiem Test na liście dostawców.

Ważne: token dostępu wygasa po ok. 25 godzinach. Klacks nie odnawia go automatycznie — musisz odnowić go zewnętrznie przez przepływ refresh token Zalo i ponownie wprowadzić w Klacks. Uwaga: refresh token jest jednorazowy — każde odnowienie dostarcza nową parę tokenów.

Krok 3 — Wysyłanie wiadomości przez chatbota (Klacksy)

Gdy dostawca Zalo jest skonfigurowany i aktywowany, chatbot Klacksy może wysyłać wiadomości. Nie musisz znać ID użytkowników Zalo — po prostu użyj imienia i nazwiska pracownika lub klienta: 

"Wyślij wiadomość do Jana Kowalskiego: Twoje spotkanie jest jutro o 14:00."
"Wyślij Annie Nowak wiadomość: Zmiana została zamieniona."
"Powiadom Piotra Wiśniewskiego, że jego dyżur w poniedziałek odpada."

Klacksy automatycznie wyszukuje zapisane ID użytkownika Zalo odbiorcy i używa skonfigurowanego dostawcy Zalo. Wysyłka jest dla Ciebie całkowicie przezroczysta — Ty pracujesz z imionami, Klacksy zajmuje się resztą.

Wymaganie: u odbiorcy musi być zapisane ID użytkownika Zalo w Klacks (pod Adres → Dane kontaktowe). Odbiorca musi wcześniej mieć interakcję z Official Account (np. obserwować OA lub wysłać mu wiadomość) — poza oknem interakcji Zalo odrzuca wysyłkę.

Wiadomości przychodzące

Integracja Zalo nie obsługuje odbioru — odpowiedzi na wysłane wiadomości nie są przekazywane do Klacks. Skrzynka odbiorcza wiadomości nie pokazuje zatem dla tego dostawcy żadnych wiadomości przychodzących.
