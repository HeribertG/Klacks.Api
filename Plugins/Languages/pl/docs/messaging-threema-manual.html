Konfiguracja Threema Gateway

Wymagania wstępne

Aby wysyłać wiadomości przez Threema, potrzebujesz konta w Threema Gateway. Threema jest szwajcarskim dostawcą, szeroko rozpowszechnionym w Szwajcarii i przyjaznym dla ochrony danych (szwajcarska DSG).

Ważne: integracja Threema jest zaprojektowana tylko do wysyłania. Odbiór wiadomości przychodzących wymagałby trybu end-to-end bramki i nie jest obsługiwany. Wysyłka jest płatna — każda wysłana wiadomość zużywa kredyty.

Krok 1 — utwórz konto Threema Gateway

  1. Zarejestruj się na gateway.threema.ch.
  2. Wystąp o Gateway-ID w trybie podstawowym (Basic) (np. *MYGATEWAY). Zaczyna się ono zawsze od gwiazdki (*) i musi zostać zatwierdzone przez Threema.
  3. Kup kredyty — bez środków nie można wysyłać wiadomości.
  4. Zapisz API Secret z pulpitu Gateway.

Uwaga: traktuj API Secret jak hasło. Nie udostępniaj go publicznie i przechowuj bezpiecznie.

Krok 2 — Skonfiguruj Threema w Klacks

  1. Przejdź do Ustawienia → Dostawcy wiadomości.
  2. Kliknij Dodaj.
  3. Wypełnij pola w następujący sposób:

  2. Przetestuj połączenie przyciskiem Test na liście dostawców. Test sprawdza dane dostępowe przez zapytanie o kredyty w bramce.

Krok 3 — Wysyłanie wiadomości przez chatbota (Klacksy)

Gdy dostawca Threema jest skonfigurowany i aktywowany, chatbot Klacksy może wysyłać wiadomości. Nie musisz znać ID Threema — po prostu użyj imienia i nazwiska pracownika lub klienta: 

"Wyślij wiadomość do Jana Kowalskiego: Twoje spotkanie jest jutro o 14:00."
"Wyślij Annie Nowak wiadomość: Zmiana została zamieniona."
"Powiadom Piotra Wiśniewskiego, że jego dyżur w poniedziałek odpada."

Klacksy automatycznie wyszukuje zapisane ID Threema odbiorcy i używa skonfigurowanego dostawcy Threema. Wysyłka jest dla Ciebie całkowicie przezroczysta — Ty pracujesz z imionami, Klacksy zajmuje się resztą.

Wymaganie: u odbiorcy musi być zapisane 8-znakowe ID Threema w Klacks (pod Adres → Dane kontaktowe). ID Threema znajduje pracownik w swojej aplikacji Threema pod „Mój profil".

Wiadomości przychodzące

Integracja Threema nie obsługuje odbioru — odpowiedzi na wysłane wiadomości nie są przekazywane do Klacks. Odbiór wymagałby trybu end-to-end bramki Threema; integracja Klacks korzysta z trybu Basic. Skrzynka odbiorcza wiadomości nie pokazuje zatem dla tego dostawcy żadnych wiadomości przychodzących.
