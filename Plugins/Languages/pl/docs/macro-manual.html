Podręcznik skryptów makr

Wprowadzenie

Edytor makr umożliwia pisanie skryptów, które służą jako podstawa obliczeniowa dla usług, czynności roboczych itp.

Przykłady zastosowania:

  • Dokładne obliczanie godzin urlopu lub służby wojskowej na podstawie wymiaru zatrudnienia
  • Obliczanie dodatków za pracę nocną, weekendy i dni świąteczne
  • Elastyczne dostosowanie do nowych wymagań

Uwaga: Interpreter skryptów działa w bezpiecznym środowisku piaskownicy bez dostępu do systemu plików ani sieci. Wykonanie złośliwego kodu nie jest możliwe.

Funkcja i kategoria

Oprócz nazwy i zawartości skryptu każde makro na liście makr ma dwie dodatkowe właściwości, ustawiane za pomocą list rozwijanych w edytorze: Kategorię i Funkcję. Obie są czystymi metadanymi – znajdują się poza skryptem i nie zmieniają jego obliczeń, lecz sterują tym, jak Klacks automatycznie znajduje i przypisuje odpowiednie makro.

Kategoria Dyżur odgrywa szczególną rolę: nowo utworzone dyżury automatycznie otrzymują przypisane makro standardowe tej kategorii (patrz "Funkcja" poniżej). Istniejące już dyżury nigdy nie są przy tym zmieniane retroaktywnie.

Funkcja: Niestandardowa, Standardowa, Standardowa (addytywna)

Funkcja klasyfikuje rolę makra w obrębie jego kategorii:

FunkcjaZnaczenie
NiestandardowaDowolne makro bez szczególnej roli. Możliwa dowolna liczba na kategorię.
StandardowaStandardowe makro tej kategorii – jest automatycznie przypisywane nowym dyżurom. Co najwyżej JEDNO makro na kategorię może mieć tę funkcję.
Standardowa (addytywna)Alternatywne makro standardowe z addytywną logiką dodatków (patrz niżej). Również co najwyżej jedno na kategorię, możliwe dodatkowo obok makra "Standardowa".

Ważne: Sama funkcja niczego nie oblicza – jest to etykieta. To, czy dodatki są obliczane według zasady "highest-wins" (liczy się tylko najwyższa obowiązująca stawka) czy addytywnie (wszystkie obowiązujące stawki są sumowane), decyduje sam skrypt. Dwa dostarczone makra kategorii "Dyżur" pokazują tę różnicę na tej samej podstawowej strukturze:

  • "AllShift" (funkcja: Standardowa) – dla każdego segmentu czasu ustala najwyższy obowiązujący dodatek (nocny/WE1/WE2/WE3/świąteczny) i stosuje tylko ten jeden.
  • "AllShiftAdditive" (funkcja: Standardowa (addytywna)) – oblicza dodatek nocny, weekendowy i świąteczny niezależnie od siebie i sumuje je.

Które z tych dwóch makr jest automatycznie przypisywane przy tworzeniu nowego dyżuru, kontroluje ustawienie obowiązujące dla całej instalacji ("addytywne" lub "wygrywa najwyższa stawka"). Dla każdego dyżuru z osobna można później ręcznie zmienić makro – możliwa jest więc eksploatacja mieszana.

Jednoznaczność: Jeśli spróbujesz zapisać drugie makro tej samej kategorii również jako "Standardowa" lub "Standardowa (addytywna)", edytor zablokuje zapis i poda nazwę już przypisanego makra. Najpierw ustaw jego funkcję na "Niestandardowa".

Odradza się ręczne zmiany w "AllShift"/"AllShiftAdditive". Te dwa makra są mechanizmem, za pomocą którego automatycznie wgrywane są dostosowania specyficzne dla kraju i branży: dopóki pozostawisz je niezmienione, Klacks automatycznie synchronizuje je z regułami odpowiednimi dla Twojego kraju lub branży. Jeśli edytujesz jedno z nich ręcznie, od tego momentu uznawane jest ono za dostosowane przez klienta – przyszłe automatyczne aktualizacje kraju/branży dla tego makra nie będą już przejmowane po cichu, lecz zakończą się konfliktem, dopóki ręcznie nie rozwiążesz rozbieżności. Jeśli potrzebujesz własnej logiki dodatków, utwórz zamiast tego nowe makro z funkcją "Niestandardowa" i przypisz je celowo do odpowiednich dyżurów.

Struktury sterujące

Ważne: Słowa kluczowe takie jak ENDIF, ENDFUNCTION, ENDSUB muszą być pisane łącznie (nie END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "duży"
ELSEIF x > 5 THEN
    OUTPUT 1, "średni"
ELSE
    OUTPUT 1, "mały"
ENDIF

IF w jednej linii

IF x > 10 THEN OUTPUT 1, "duży" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Weekend"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Dzień roboczy"
    CASE ELSE
        OUTPUT 1, "Nieznany"
END SELECT

Pętla FOR-NEXT

FOR i = 1 TO 10
    suma += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Pętla DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Funkcje i procedury

Ważne: Funkcje (FUNCTION) i procedury (SUB) muszą być zdefiniowane przed pierwszym wywołaniem. Interpreter czyta kod od góry do dołu: funkcja lub procedura jest znana dopiero po przetworzeniu jej definicji.

SUB (procedura bez wartości zwracanej)

SUB oblicz(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (funkcja z wartością zwracaną)

FUNCTION podwoj(x)
    podwoj = x * 2
ENDFUNCTION

DIM wynik
wynik = podwoj(21)
OUTPUT 1, wynik

Zwracanie wartości (OUTPUT)

OUTPUT typ, wartość

typ i wartość to dwa wyrażenia oddzielone przecinkiem; oba są opcjonalne (domyślnie 0 lub "", jeśli pominięte). Makro może zawierać dowolną liczbę linii OUTPUT – każda generuje własną wartość zwracaną. Klacks uwzględnia przy tym tylko następujące typy:

TypZnaczenie
1Wynik główny (godziny lub kwota całkowita) – jest przejmowany również przy wartości 0
10Dodatek nocny
11Dodatek za dzień weekendowy 1 (np. sobota)
12Dodatek za dzień weekendowy 2 (np. niedziela)
13Dodatek za dzień weekendowy 3 (trzeci konfigurowalny dzień weekendowy)
14Dodatek świąteczny

Linie dodatków (typ 10-14) z wartością 0 są ignorowane – makro nie musi więc wypisywać osobnej linii dla każdego typu dodatku, lecz tylko dla faktycznie występujących dodatków. Wartości, których nie można zinterpretować jako liczby, są pomijane.

Podczas zapisywania makro jest obowiązkowo kompilowane i raz próbnie wykonywane z neutralnymi wartościami testowymi. Błędy składni i wykonania (np. niezbalansowane nawiasy lub zawieszone wyrażenie) są przy tym niezawodnie wyświetlane, zamiast po cichu prowadzić do niedziałającego makra.

Przykład: obliczanie dodatków ("AllShift")

Dostarczone standardowe makro kategorii "Dyżur". Oblicza dodatki za pracę nocną, dzień świąteczny i trzy konfigurowalne dni weekendowe z prawidłową obsługą zmian przekraczających północ (podział na segmenty) i stosuje dla każdego segmentu najwyższą obowiązującą stawkę (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Wyjaśnienie

  • Podział na segmenty: Dla zmian przekraczających północ (np. 22:00-06:00) zmiana jest dzielona na dwa segmenty (do północy / od północy), każdy z własną flagą dnia tygodnia/święta
  • SegBonusForType: Oblicza dodatek dla segmentu i określonego typu dodatku (10-14) z uwzględnieniem dodatków nocnych, świątecznych i weekendowych
  • WE1/WE2/WE3 zamiast So/Nd: weekendday1-3 czynią dni weekendowe konfigurowalnymi (nie każdy kraj ma sobotę/niedzielę jako weekend)
  • Najwyższy dodatek na segment: NRate/DRate ustalają odpowiednio najwyższą obowiązującą stawkę dla godzin nocnych i dziennych – highest-wins, bez sumowania
  • HolidayNextDay: Uwzględnia, czy następny dzień jest dniem świątecznym (ważne dla zmian nocnych przekraczających północ)
  • Wiele linii OUTPUT: Linia 1 zwraca sumę całkowitą, linie 10-14 zwracają poszczególne kwoty dodatków (patrz sekcja "Zwracanie wartości")

Wariant addytywny ("AllShiftAdditive")

Standardowe makro (addytywne) tej samej kategorii ma identyczne linie IMPORT i tę samą strukturę ramową – różni się jedynie SegBonusForType: zamiast najwyższej stawki dla każdego typu dodatku niezależnie obliczane jest, czy ma on zastosowanie, a wszystkie obowiązujące kwoty są na końcu sumowane (nie ma już highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Jeśli zmiana nocna przypada np. dodatkowo na dzień świąteczny, w "AllShift" otrzymuje ona tylko wyższą z obu stawek, natomiast w "AllShiftAdditive" dodatek nocny i świąteczny łącznie. Reszta skryptu (podział na segmenty, sumowanie, linie OUTPUT) jest identyczna jak w "AllShift" powyżej.
