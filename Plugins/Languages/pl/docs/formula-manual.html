Instrukcja pola formuły

Podstawowa składnia

Każde pole formuły wypisuje wynik za pomocą polecenia output:

output 1, <wyrażenie>

Pierwszy parametr 1 to typ komunikatu i zawsze musi wynosić 1. Drugi parametr to wartość do wypisania.

Proste przykłady:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " wpisów"

Dostępne zmienne

Dostępne zmienne są wymienione na karcie Zmienne i można tam przypisać im wartości testowe. W zależności od typu raportu dostępne są różne zmienne:

Logika warunkowa

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "dużo wpisów"
ELSEIF totalRows > 0 THEN
    output 1, "mało wpisów"
ELSE
    output 1, "brak wpisów"
ENDIF

Jednowierszowe IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (skrócona forma)

output 1, IIF(totalRows > 0, "OK", "Puste")

Zmienne i pętle

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Przykłady praktyczne

Liczba wpisów z tekstem

output 1, CStr(totalRows) & " wpisów"

Zaokrąglona wartość (1 miejsce)

output 1, CStr(Round(totalValue, 1))

Godziny jako h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Wynik warunkowy

IF totalRows = 0 THEN
    output 1, "Brak nieobecności"
ELSE
    output 1, CStr(totalRows) & " nieobecności (suma: " & CStr(totalValue) & ")"
ENDIF

Obliczanie średniej

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/dzień"
ELSE
    output 1, "-"
ENDIF
