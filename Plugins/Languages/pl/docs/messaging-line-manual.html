Konfiguracja LINE

Wymagania wstępne

Aby wysyłać i odbierać wiadomości przez LINE, potrzebujesz LINE Official Account z kanałem Messaging API w konsoli LINE Developers. LINE jest szczególnie rozpowszechnione w Japonii, na Tajwanie i w Tajlandii.

Uwaga: wiadomości push mają, w zależności od taryfy LINE, miesięczny limit (darmowy plan jest ograniczony). Sprawdź aktualne warunki swojego planu Official Account.

Krok 1 — utwórz LINE Official Account i kanał Messaging API

  1. Utwórz LINE Official Account (przez LINE Official Account Manager).
  2. Otwórz konsolę LINE Developers (developers.line.biz) i utwórz kanał Messaging API lub połącz swoje konto Official Account z Messaging API.
  3. Na karcie Messaging API wystaw długotrwały Channel Access Token (Issue).
  4. Zapisz Channel Secret z karty Basic Settings.

Uwaga: traktuj Channel Access Token i Channel Secret jak hasła. Nie udostępniaj ich publicznie i przechowuj bezpiecznie.

Krok 3 — Wysyłanie wiadomości przez chatbota (Klacksy)

Gdy dostawca LINE jest skonfigurowany i aktywowany, chatbot Klacksy może wysyłać wiadomości. Nie musisz znać ID użytkowników LINE — po prostu użyj imienia i nazwiska pracownika lub klienta: 

"Wyślij wiadomość do Jana Kowalskiego: Twoje spotkanie jest jutro o 14:00."
"Wyślij Annie Nowak wiadomość: Zmiana została zamieniona."
"Powiadom Piotra Wiśniewskiego, że jego dyżur w poniedziałek odpada."

Klacksy automatycznie wyszukuje zapisane ID użytkownika LINE odbiorcy i używa skonfigurowanego dostawcy LINE. Wysyłka jest dla Ciebie całkowicie przezroczysta — Ty pracujesz z imionami, Klacksy zajmuje się resztą.

Wymaganie: u odbiorcy musi być zapisane ID użytkownika LINE (zaczyna się od U…) w Klacks (pod Adres → Dane kontaktowe). ID użytkownika staje się znane przez wiadomości przychodzące (widoczne w skrzynce odbiorczej wiadomości) — odbiorca musi w tym celu dodać Twoje konto Official Account jako znajomego i wysłać mu wiadomość.

Krok 4 — odbieranie wiadomości przychodzących (webhook)

Aby wyświetlić przychodzące wiadomości LINE w Klacks, URL webhooka musi zostać wprowadzony ręcznie w konsoli LINE Developers.

  1. Skopiuj wyświetlony w Klacks URL webhooka z ustawień dostawcy: 
    https://{twoja-domena}/api/messaging/webhook/line
  2. Wprowadź ten URL w konsoli LINE Developers pod Messaging API → Webhook settings jako Webhook URL.
  3. Aktywuj opcję „Use webhook".
  4. Upewnij się, że Twoja instancja Klacks jest publicznie dostępna przez HTTPS.
  5. Wiadomości przychodzące pojawiają się teraz w czasie rzeczywistym w skrzynce odbiorczej wiadomości.
