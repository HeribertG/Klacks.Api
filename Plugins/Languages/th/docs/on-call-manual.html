เวรเรียกและเวรสำรอง

การตั้งค่านี้กำหนดว่าจะบันทึกเวรเรียกและเวรสำรองหรือไม่ และเวลาที่ปฏิบัติหน้าที่นั้น จะนับเป็นเวลาทำงานในสัดส่วนเท่าใด การตั้งค่านี้มีผลเป็นค่าเริ่มต้นทั่วทั้งบริษัท สำหรับเวรที่วางแผนขึ้นใหม่

เปิดใช้งานเวรเรียก

เปิดหรือปิดตรรกะเวรเรียกทั้งหมด หากปิดใช้งานตัวเลือกนี้ ฟิลด์ที่เหลือจะถูกละเว้น และเวลาเวรประจำการรวมถึงเวรสำรองจะไม่ถูกนับแยกต่างหาก

  • ค่าเริ่มต้น: ปิดใช้งาน

เวรประจำการนับเป็น (%)

สัดส่วนของเวลาประจำการที่ปฏิบัติงานอยู่ ณ สถานที่จริง ซึ่งจะถูกนับเป็นเวลาทำงานตามปกติ

  • ช่วงค่า: 0 ถึง 100 เปอร์เซ็นต์
  • ค่าเริ่มต้น: 100 (เวลาประจำการนับเป็นเวลาทำงานเต็มจำนวน)

เวรสำรองนับเป็น (%)

สัดส่วนของเวลาเวรสำรองล้วน (พร้อมรับเรียกโดยไม่มีการปฏิบัติงานจริง) ซึ่งจะถูกนับเป็น เวลาทำงาน

  • ช่วงค่า: 0 ถึง 100 เปอร์เซ็นต์
  • ค่าเริ่มต้น: 0 (เวรสำรองไม่นับเป็นเวลาทำงาน)

รวมในขีดจำกัดช่วงเวลา

กำหนดว่าเวลาเวรเรียกและเวรสำรองที่นับแล้วจะถูกรวมเข้าในขีดจำกัดช่วงเวลา (เช่น ชั่วโมงสูงสุดรายเดือนหรือรายปี) หรือไม่

  • เปิดใช้งาน: เวลาที่นับแล้วจะถูกนำไปหักลบกับขีดจำกัดช่วงเวลา
  • ค่าเริ่มต้น: ปิดใช้งาน
