ตั้งค่า Slack

ข้อกำหนดเบื้องต้น

ในการส่งและรับข้อความผ่าน Slack ด้วย Klacks คุณต้องมี Slack-Workspace และ Slack-App ที่มีสิทธิ์ที่จำเป็น Klacks ใช้ Slack Web API สำหรับการส่ง และ Events API สำหรับการรับ

หมายเหตุ: แพ็กเกจ Slack ฟรีก็เพียงพอสำหรับการเชื่อมต่อนี้ Slack-App สามารถสร้างได้ที่ api.slack.com โดยไม่มีค่าใช้จ่าย

ขั้นตอนที่ 1 — สร้าง Slack-App

  1. เปิด api.slack.com/apps และคลิก Create New App
  2. เลือก From scratch และตั้งชื่อ (เช่น Klacks Bot)
  3. เลือก Workspace ที่จะติดตั้ง App นี้
  4. ไปที่ OAuth & Permissions และเพิ่ม Bot Token Scopes ต่อไปนี้:
    • chat:write — สำหรับส่งข้อความไปยังช่องทาง
    • im:write — สำหรับส่งข้อความส่วนตัวถึงผู้ใช้
  5. คลิก Install to Workspace และยืนยันสิทธิ์การใช้งาน
  6. จดบันทึก Bot User OAuth Token (ขึ้นต้นด้วย xoxb-)
  7. ไปที่ Basic Information และจดบันทึก Signing Secret

ขั้นตอนที่ 2 — ตั้งค่า Slack ใน Klacks

  1. ไปที่ การตั้งค่า → ผู้ให้บริการส่งข้อความ
  2. คลิก เพิ่ม
  3. กรอกข้อมูลในช่องต่างๆ ดังนี้

ขั้นตอนที่ 3 — ส่งข้อความผ่านแชทบอท (Klacksy)

เมื่อตั้งค่าและเปิดใช้งานผู้ให้บริการ Slack แล้ว แชทบอท Klacksy สามารถส่งข้อความผ่าน Slack ได้ โดยใช้ชื่อพนักงานหรือ ชื่อช่องทาง: 

"ส่งข้อความถึงสมชาย ใจดี: ท่านมีนัดหมายพรุ่งนี้เวลา 14:00 น."
"ส่งข้อความถึงสมหญิง รักดี: กะงานได้ถูกสลับแล้ว"
"โพสต์ใน #team-updates: ตารางเวรสำหรับสัปดาห์หน้าเสร็จเรียบร้อยแล้ว"

ผู้รับสามารถระบุได้ด้วย Channel-ID (เช่น C0123456789) หรือ User-ID (เช่น U0123456789) — หากใช้ User-ID จะเป็นการส่งข้อความส่วนตัว หากไม่ระบุผู้รับ จะใช้ ช่องทางเริ่มต้น ที่ตั้งค่าไว้ กระบวนการส่งทั้งหมดโปร่งใสสำหรับคุณ — คุณเพียงระบุชื่อ ส่วนที่เหลือ Klacksy จะจัดการให้

ข้อกำหนด: ผู้ใช้ Slack ต้องเชื่อมโยงกับผู้ติดต่อ ที่สอดคล้องกันใน Klacks (ที่เมนู ที่อยู่ → ข้อมูลติดต่อ) สำหรับข้อความในช่องทาง ต้องเชิญบอทเข้าช่องทางนั้นๆ ก่อน (/invite @Klacks Bot)

ขั้นตอนที่ 4 — รับข้อความขาเข้า (Events API)

เพื่อให้ข้อความ Slack ขาเข้าแสดงใน Klacks ต้องตั้งค่า Events API ของ Slack-App กรุณาบันทึกและเปิดใช้งานผู้ให้บริการใน Klacks ก่อน ที่จะ ใส่ Request-URL — Slack จะตรวจสอบ URL ทันทีด้วยคำขอ Challenge ซึ่ง Klacks จะตอบกลับโดยอัตโนมัติ

  1. เปิด Slack-App ของคุณที่ api.slack.com/apps และไปที่ Event Subscriptions
  2. เปิดใช้งาน Enable Events และใส่ Webhook-URL ที่แสดงใน Klacks เป็น Request URL: 
    https://{ihre-domain}/api/messaging/webhook/slack
  3. ที่ Subscribe to bot events ให้สมัครรับ Events message.im (ข้อความส่วนตัว) และ message.channels (ข้อความในช่องทาง)
  4. บันทึกการเปลี่ยนแปลง และติดตั้ง App ใน Workspace ใหม่อีกครั้งเมื่อได้รับการแจ้งเตือน
  5. ข้อความขาเข้าจะปรากฏแบบเรียลไทม์ใน Messaging-Inbox โดย Klacks จะตรวจสอบลายเซ็นของทุกคำขอด้วย Signing-Secret ที่บันทึกไว้

การแก้ไขปัญหา

ปัญหาสาเหตุที่เป็นไปได้วิธีแก้ไข
การทดสอบการเชื่อมต่อล้มเหลว Bot-Token ไม่ถูกต้องหรือถูกเพิกถอน ตรวจสอบโทเคนที่ OAuth & Permissions และติดตั้ง App ใหม่
ข้อผิดพลาด channel_not_found หรือ not_in_channel ยังไม่ได้เพิ่มบอทเข้าช่องทาง เชิญบอทเข้าช่องทาง (/invite) หรือตรวจสอบ Channel-ID
ข้อความที่ไม่มีผู้รับส่งไม่สำเร็จ ยังไม่ได้ตั้งค่าช่องทางเริ่มต้น ใส่ช่องทางเริ่มต้นในการตั้งค่าผู้ให้บริการ
การยืนยัน Request-URL ล้มเหลว ผู้ให้บริการยังไม่ได้บันทึก/เปิดใช้งานใน Klacks หรือ Signing-Secret ไม่ถูกต้อง บันทึกและเปิดใช้งานผู้ให้บริการใน Klacks ก่อน แล้วตรวจสอบ Signing-Secret
ไม่มีข้อความขาเข้า ยังไม่ได้สมัครรับ Bot-Events สมัครรับ message.im และ message.channels ที่ Event Subscriptions
