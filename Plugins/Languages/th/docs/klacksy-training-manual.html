คู่มือการฝึกฝน Klacksy

เครื่องมือฝึกฝนคืออะไร?

เครื่องมือฝึกฝนควบคุมการนำทางภายในหน้าเว็บของแชทบอท Klacksy เมื่อผู้ใช้พูดหรือพิมพ์ว่า "Klacksy แสดงที่อยู่ให้หน่อย" Klacksy จะนำทางไปยังหน้าที่เหมาะสม และเลื่อนไปยังส่วนที่เกี่ยวข้อง

เพื่อให้ทำงานได้ Klacksy ต้องมีรายการ คำพ้องความหมาย สำหรับจุดยึด (anchor) แต่ละจุดบนหน้าเว็บ ในทุกภาษา (เช่น "ที่อยู่", "ลูกค้า", "ผู้ติดต่อ" สำหรับเป้าหมาย addresses)

แท็บ "เป้าหมาย"

รายการจุดยึดทั้งหมดที่พบในฟรอนต์เอนด์ (แอตทริบิวต์ HTML data-klacksy-target) ตัวกรองสถานะ:

  • pending: จุดยึดมีอยู่แล้ว แต่ยังไม่มีคำพ้องความหมาย
  • generated: คำพ้องความหมายถูกสร้างขึ้นโดยอัตโนมัติ ต้องได้รับการตรวจสอบ
  • reviewed: คำพ้องความหมายได้รับการอนุมัติจากผู้ดูแลระบบแล้ว
  • needs-review: ถูกทำเครื่องหมายให้ตรวจสอบซ้ำอีกครั้ง

การคลิกเป้าหมายจะเปิดตัวแก้ไขคำพ้องความหมายด้านล่าง ที่นั่นสามารถเพิ่ม ลบ และอนุมัติคำพ้องความหมายผ่านปุ่ม "บันทึกเป็นตรวจสอบแล้ว" ได้

แท็บ "ข้อเสนอแนะ"

แสดงข้อความที่ผู้ใช้ป้อนซึ่ง Klacksy ไม่สามารถจับคู่ได้ (ไม่พบคำพ้องความหมายที่ตรงกัน) จากรายการนี้จะสามารถระบุได้ว่ายังขาดคำพ้องความหมายใดบ้าง

แท็บ "ตัวชี้วัด"

ภาพรวมของเป้าหมายทั้งหมดจำแนกตามสถานะ ช่วยติดตามความคืบหน้าของการฝึกฝน

Build-Pipeline (CLI)

หากเทมเพลตได้รับจุดยึด data-klacksy-target ใหม่ จะต้องสร้าง manifest และคำพ้องความหมายเริ่มต้นขึ้นใหม่ คำสั่งต่อไปนี้ยังทำงานโดยอัตโนมัติใน CI และใน Husky-Pre-Commit ด้วย: 

cd C:\SourceCode\Klacks.Ui

# 1. Templates scannen → navigation-targets.json mit allen Anchors
npm run scan:targets

# 2a. Initial-Synonyme generieren (alle 4 Core + 22 Plugin-Locales, ~2.5 h)
npm run generate:synonyms

# 2b. Nur Core-Locales (de/en/fr/it) — schnell, ca. 9 min
npm run generate:synonyms -- --core-only

# 2c. Nur fehlende Plugin-Locales nachfuellen — ca. 45 min
npm run generate:synonyms -- --plugins-only

# 3. Wake-Word-Konsistenz pruefen
npm run wake-word-lint

สำคัญ: เมื่อใช้ npm run ต้องมี -- เพื่อให้ตัวเลือกถูกส่งต่อไปยังสคริปต์ หากไม่มี -- npm จะกลืนแฟล็กนั้นไป และสคริปต์จะทำงานในโหมดมาตรฐานแทน

ทางเลือกอื่นโดยไม่ใช้ npm: npx tsx tools/generate-synonyms.ts --core-only

API-Key

LLM-API-Key จะถูกค้นหาตามลำดับดังนี้:

  1. ตัวแปรสภาพแวดล้อม SYNONYM_LLM_API_KEY
  2. ตาราง DB llm_providers (ผู้ให้บริการ deepseek, is_enabled = true) — อัตโนมัติผ่านการเรียก psql
  3. หากไม่พบ จะแสดงข้อความแจ้งข้อผิดพลาด

ผู้ให้บริการเริ่มต้นคือ DeepSeek สามารถเปลี่ยนผู้ให้บริการอื่นได้ผ่าน SYNONYM_LLM_PROVIDER_ID=anthropic (หรือผู้ให้บริการ LLM อื่นที่ตั้งค่าไว้แล้ว ในการตั้งค่า)

ขั้นตอนที่ 1 - scan:targets

ค้นหาแอตทริบิวต์ data-klacksy-target ในเทมเพลต Angular ทั้งหมด และสร้าง manifest Application/Skills/Definitions/navigation-targets.json จุดยึดใหม่แต่ละจุดจะปรากฏหลังจากนั้นในแท็บ "เป้าหมาย" ด้วยสถานะ pending

ขั้นตอนที่ 2 - generate:synonyms

สร้างคำพ้องความหมายเริ่มต้นสำหรับจุดยึดใหม่แต่ละจุดจาก data-klacksy-label-key และหมวดหมู่ สถานะหลังจากนั้น: generated (ต้องได้รับการตรวจสอบโดยผู้ดูแลระบบ)

สคริปต์จะเขียนจุดตรวจสอบ (checkpoint) ของ manifest ทุก 5 เป้าหมาย เพื่อไม่ให้ข้อมูล ที่สร้างไว้แล้วสูญหายหากมีการหยุดชะงัก

ขั้นตอนที่ 3 - wake-word-lint

ตรวจสอบความสอดคล้องของรูปแบบ Wake-Word (Hallo Klacksy / Hey Klacksy / ...) ในทุกภาษา ป้องกันไม่ให้คำพ้องความหมายเขียนทับ Wake-Word

โหมดเสียง (Voice-Mode)

สัญลักษณ์ไมโครโฟนในหน้าแชทจะเปิดใช้งานโหมดเสียง เมื่อเปิดใช้งานแล้ว:

  • ไมโครโฟนจะรับฟังและถอดเสียงเป็นข้อความอย่างต่อเนื่อง
  • เมื่อมีความเงียบสั้น ๆ → ระบบจะส่งข้อความที่ถอดเสียงไว้จนถึงตอนนั้นโดยอัตโนมัติ

สำคัญ: ทันทีที่คุณเริ่มพิมพ์ในช่องข้อความ โหมดเสียงจะถูกปิดโดยอัตโนมัติ — มิฉะนั้นไมโครโฟนจะเขียนทับข้อความที่คุณพิมพ์ด้วยข้อความที่ถอดเสียงเอง และส่งออกไปก่อนเวลาอันควร

ขั้นตอนการฝึกฝนโดยทั่วไป

  1. เพิ่มจุดยึดในเทมเพลต: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. รีสตาร์ท API (แคชจะถูกอ่านใหม่ตอนเริ่มต้น)
  4. เปิดแท็บ "เป้าหมาย" → เป้าหมายใหม่จะปรากฏพร้อมสถานะ generated
  5. ตรวจสอบ/เพิ่มคำพ้องความหมาย → "บันทึกเป็นตรวจสอบแล้ว" → สถานะ reviewed
  6. ทดสอบกับ Klacksy เช่น "Klacksy แสดงที่อยู่ให้หน่อย"
  7. หาก Klacksy ไม่สามารถจับคู่ได้ → แท็บ "ข้อเสนอแนะ" → เพิ่มคำพ้องความหมายที่ขาดหายไป
  8. ติดตามแท็บ "ตัวชี้วัด" จนกว่าทุกอย่างจะมีสถานะ reviewed
