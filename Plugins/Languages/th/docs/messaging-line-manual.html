ตั้งค่าการส่งข้อความผ่าน LINE

ข้อกำหนดเบื้องต้น

ในการส่งและรับข้อความผ่าน LINE คุณต้องมี LINE Official Account ที่มี Messaging-API-Channel ใน LINE Developers Console โดย LINE เป็นที่นิยมอย่างมากในญี่ปุ่น ไต้หวัน และไทย

หมายเหตุ: การส่ง Push-Message มีโควตารายเดือนขึ้นอยู่กับแพ็กเกจ LINE ของคุณ (แพ็กเกจฟรีมีข้อจำกัด) กรุณาตรวจสอบเงื่อนไขปัจจุบันของแพ็กเกจ Official Account ของคุณ

ขั้นตอนที่ 1 — สร้าง LINE Official Account และ Messaging-API-Channel

  1. สร้าง LINE Official Account (ผ่าน LINE Official Account Manager)
  2. เปิด LINE Developers Console (developers.line.biz) และ สร้าง Messaging-API-Channel หรือเชื่อมต่อ Official Account ของคุณกับ Messaging API
  3. ออก Channel-Access-Token แบบระยะยาว (Issue) ในแท็บ Messaging API
  4. จดบันทึก Channel-Secret จากแท็บ Basic Settings

หมายเหตุ: ให้ปฏิบัติต่อ Channel-Access-Token และ Channel-Secret เหมือนรหัสผ่าน ห้ามเปิดเผยต่อสาธารณะและเก็บรักษาอย่างปลอดภัย

ขั้นตอนที่ 2 — ตั้งค่า LINE ใน Klacks

  2. คลิก เพิ่ม
  3. กรอกข้อมูลในช่องต่างๆ ดังนี้

ขั้นตอนที่ 3 — ส่งข้อความผ่านแชทบอท (Klacksy)

เมื่อตั้งค่าและเปิดใช้งานผู้ให้บริการ LINE แล้ว แชทบอท Klacksy สามารถส่งข้อความได้ทันที คุณไม่จำเป็นต้องทราบ LINE-User-ID — เพียงระบุชื่อพนักงานหรือลูกค้า: 

"ส่งข้อความถึงสมชาย ใจดี: ท่านมีนัดหมายพรุ่งนี้เวลา 14:00 น."
"ส่งข้อความถึงสมหญิง รักดี: กะงานได้ถูกสลับแล้ว"
"แจ้งประเสริฐ มั่นคงว่ากะงานวันจันทร์ถูกยกเลิก"

Klacksy จะค้นหา LINE-User-ID ของผู้รับที่บันทึกไว้โดยอัตโนมัติ และ ใช้ผู้ให้บริการ LINE ที่ตั้งค่าไว้ กระบวนการส่งทั้งหมดโปร่งใสสำหรับคุณ — คุณเพียงระบุชื่อ ส่วนที่เหลือ Klacksy จะจัดการให้

ข้อกำหนด: ผู้รับต้องมี LINE-User-ID (ขึ้นต้นด้วย U…) บันทึกไว้ใน Klacks (ที่เมนู ที่อยู่ → ข้อมูลติดต่อ) User-ID จะทราบได้จากข้อความที่ส่งเข้ามา (มองเห็นได้ใน Messaging-Inbox) — ผู้รับต้องเพิ่ม Official Account ของคุณเป็นเพื่อนและ ส่งข้อความมาก่อน

ขั้นตอนที่ 4 — รับข้อความขาเข้า (Webhook)

เพื่อให้ข้อความ LINE ขาเข้าแสดงใน Klacks ต้องตั้งค่า Webhook-URL ด้วยตนเอง ใน LINE Developers Console

  1. คัดลอก Webhook-URL ที่แสดงใน Klacks จาก การตั้งค่าผู้ให้บริการ: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. ใส่ URL นี้ใน LINE Developers Console ที่ Messaging API → Webhook settings ในช่อง Webhook URL
  3. เปิดใช้งานตัวเลือก „Use webhook"
  4. ตรวจสอบว่าอินสแตนซ์ Klacks ของคุณสามารถเข้าถึงได้ผ่าน HTTPS จากภายนอก
  5. ข้อความขาเข้าจะปรากฏแบบเรียลไทม์ใน Messaging-Inbox

การแก้ไขปัญหา

ปัญหาสาเหตุที่เป็นไปได้วิธีแก้ไข
การทดสอบการเชื่อมต่อล้มเหลว Channel-Access-Token ไม่ถูกต้อง ออกโทเคนใหม่ใน LINE Developers Console
ไม่สามารถส่งข้อความได้ ผู้รับยังไม่ได้เพิ่ม Official Account เป็นเพื่อน หรือได้บล็อกไว้ ผู้รับต้องเพิ่มบัญชีเป็นเพื่อนใน LINE
การส่งล้มเหลว โควตา Push รายเดือนหมดลง ตรวจสอบโควตาของแพ็กเกจคุณใน LINE Official Account Manager
ไม่พบผู้รับ ยังไม่ได้บันทึก LINE-User-ID ใส่ User-ID จาก Messaging-Inbox ที่เมนู ที่อยู่ → ข้อมูลติดต่อ
ไม่มีข้อความขาเข้า ยังไม่ได้ใส่ Webhook-URL หรือปิดใช้งาน „Use webhook" ตรวจสอบ Webhook settings ใน LINE Developers Console
