ค้นหาผู้ให้บริการ LLM — คู่มือการใช้งาน

ฟังก์ชันนี้ใช้ทำอะไร?

มุมมองนี้จะแนะนำผู้ให้บริการ LLM ที่คุณยังไม่มีในรายการของคุณ และเพิ่มผู้ให้บริการที่เลือก ด้วยการคลิกเพียงครั้งเดียว คุณจึงไม่ต้องกรอกชื่อและ Base-URL ด้วยตนเอง ระบบจะแนะนำเฉพาะ ผู้ให้บริการ API ที่เข้ากันได้กับ OpenAI เท่านั้น — ซึ่งเป็นประเภทของบริการ เดียวกับที่ผู้ให้บริการที่คุณตั้งค่าไว้แล้วใช้งานอยู่

คอลัมน์ต่าง ๆ ของตาราง

ชื่อผู้ให้บริการ

ชื่อที่แสดงของผู้ให้บริการ (เช่น "OpenRouter", "xAI (Grok)")

Base URL

ที่อยู่ API ที่ใช้ในการสื่อสารกับผู้ให้บริการ (เช่น https://api.x.ai/v1/) URL นี้จะถูกใช้ในภายหลังตอนสร้างรายการ

แหล่งที่มา

ระบุว่าคำแนะนำนี้ มาจากที่ใด:

  • แคตตาล็อก — จากรายการผู้ให้บริการที่รู้จักและตรวจสอบแล้ว ซึ่งจัดเก็บไว้ตายตัว Base-URL ได้รับการยืนยันแล้ว จึงเชื่อถือได้
  • เว็บ — พบผ่านการค้นหาทางอินเทอร์เน็ตและวิเคราะห์โดยอัตโนมัติ รายการเหล่านี้จะปรากฏก็ต่อเมื่อมีการตั้งค่าการค้นหาเว็บไว้ในการตั้งค่าเท่านั้น ข้อมูลเหล่านี้มีประโยชน์ แต่หากไม่แน่ใจ ควรตรวจสอบ Base-URL สักเล็กน้อย

ความพร้อมใช้งาน

ก่อนแสดงผล คำแนะนำแต่ละรายการจะถูกทดสอบแบบสด (เรียก endpoint /models):

  • พร้อมใช้งาน — API ตอบสนอง ผู้ให้บริการทำงานได้ปกติ
  • พร้อมใช้งาน (ต้องมี Key) — API มีอยู่จริง แต่ต้องใช้ API-Key ในการเข้าถึง แสดงว่าที่อยู่ถูกต้อง
  • ไม่พร้อมใช้งาน — ที่อยู่ไม่ตอบสนอง รายการเหล่านี้จะไม่สามารถเลือกได้

การเพิ่มผู้ให้บริการ

ทำเครื่องหมายถูกที่ผู้ให้บริการหนึ่งรายการหรือมากกว่า แล้วคลิกที่ "เพิ่มรายการที่เลือก" ด้านล่าง ผู้ให้บริการที่เลือกจะถูกสร้างขึ้นในสถานะ ปิดใช้งานและไม่มี API-Key ผู้ให้บริการที่มีอยู่แล้วจะไม่ถูกแนะนำอีก

ขั้นตอนถัดไปหลังจากเพิ่มแล้ว

ผู้ให้บริการที่เพิ่งเพิ่มเข้ามาใหม่ยังไม่เปิดใช้งาน เปิดรายการนั้นขึ้นมา กรอก API-Key และเปิดใช้งาน หลังจากนั้นผู้ให้บริการจะทำงาน เหมือนกับผู้ให้บริการรายอื่นของคุณทุกประการ ส่วนโมเดลแต่ละตัวของผู้ให้บริการนั้น คุณยังคงต้องจัดการแยกต่างหากผ่านการจัดการโมเดล
