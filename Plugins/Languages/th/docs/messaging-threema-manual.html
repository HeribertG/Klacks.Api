ตั้งค่า Threema Gateway

ข้อกำหนดเบื้องต้น

ในการส่งข้อความผ่าน Threema คุณต้องมีบัญชีกับ Threema Gateway Threema เป็นผู้ให้บริการสัญชาติสวิส ที่ได้รับความนิยมอย่างแพร่หลายในสวิตเซอร์แลนด์และเป็นมิตรกับความเป็นส่วนตัว (ตามกฎหมายคุ้มครองข้อมูลส่วนบุคคลของสวิส DSG)

สำคัญ: การเชื่อมต่อ Threema ออกแบบมา สำหรับการส่งเท่านั้น การรับข้อความขาเข้าจะต้องใช้โหมด End-to-End ของ Gateway ซึ่ง ไม่รองรับ การส่งข้อความมีค่าใช้จ่าย — ทุกข้อความที่ส่ง จะใช้ Credits

ขั้นตอนที่ 1 — สร้างบัญชี Threema Gateway

  1. ลงทะเบียนที่ gateway.threema.ch
  2. ขอรับ Gateway-ID ในโหมด Basic (เช่น *MYGATEWAY) ซึ่งจะขึ้นต้นด้วยเครื่องหมายดอกจันเสมอ (*) และต้องได้รับการอนุมัติจาก Threema
  3. ซื้อ Credits — หากไม่มียอดเครดิตจะไม่สามารถส่งข้อความได้
  4. จดบันทึก API-Secret จากแดชบอร์ดของ Gateway

หมายเหตุ: ควรเก็บรักษา API-Secret เสมือนรหัสผ่าน อย่าเปิดเผยต่อสาธารณะและจัดเก็บไว้อย่างปลอดภัย

ขั้นตอนที่ 2 — ตั้งค่า Threema ใน Klacks

  2. คลิก เพิ่ม
  3. กรอกข้อมูลในช่องต่างๆ ดังนี้

ขั้นตอนที่ 3 — ส่งข้อความผ่านแชทบอท (Klacksy)

เมื่อตั้งค่าและเปิดใช้งานผู้ให้บริการ Threema แล้ว แชทบอท Klacksy สามารถส่งข้อความได้ทันที คุณไม่จำเป็นต้องทราบ Threema-ID — เพียงระบุชื่อพนักงานหรือลูกค้า: 

"ส่งข้อความถึงสมชาย ใจดี: ท่านมีนัดหมายพรุ่งนี้เวลา 14:00 น."
"ส่งข้อความถึงสมหญิง รักดี: กะงานได้ถูกสลับแล้ว"
"แจ้งประเสริฐ มั่นคงว่ากะงานวันจันทร์ถูกยกเลิก"

Klacksy จะค้นหา Threema-ID ของผู้รับที่บันทึกไว้โดยอัตโนมัติ และ ใช้ผู้ให้บริการ Threema ที่ตั้งค่าไว้ กระบวนการส่งทั้งหมดโปร่งใสสำหรับคุณ — คุณเพียงระบุชื่อ ส่วนที่เหลือ Klacksy จะจัดการให้

ข้อกำหนด: ผู้รับต้องมี Threema-ID 8 หลัก บันทึกไว้ใน Klacks (ที่เมนู ที่อยู่ → ข้อมูลติดต่อ) พนักงานสามารถดู Threema-ID ของตนได้ในแอป Threema ที่เมนู "โปรไฟล์ของฉัน"

ข้อความขาเข้า

การเชื่อมต่อ Threema ไม่รองรับการรับข้อความ — การตอบกลับข้อความที่ส่งไป จะ ไม่ ถูกส่งเข้ามาที่ Klacks การรับข้อความจะต้องใช้โหมด End-to-End ของ Threema Gateway ในขณะที่การเชื่อมต่อของ Klacks ใช้โหมด Basic ดังนั้น Messaging-Inbox จะไม่แสดงข้อความขาเข้าสำหรับผู้ให้บริการนี้

การแก้ไขปัญหา

ปัญหาสาเหตุที่เป็นไปได้วิธีแก้ไข
การทดสอบการเชื่อมต่อล้มเหลว Gateway-ID หรือ API-Secret ไม่ถูกต้อง ตรวจสอบข้อมูลการเข้าใช้งานในแดชบอร์ดของ Gateway ที่ gateway.threema.ch
ไม่สามารถส่งข้อความได้ Threema-ID ไม่ถูกต้องหรือไม่มีอยู่ ตรวจสอบว่า Threema-ID 8 หลักถูกบันทึกไว้อย่างถูกต้อง
การส่งล้มเหลว Credits หมด เติม Credits ใน Threema Gateway
ไม่พบผู้รับ ไม่ได้บันทึก Threema-ID ไว้ กรอก Threema-ID ที่เมนู ที่อยู่ → ข้อมูลติดต่อ
Gateway-ID ใช้งานไม่ได้ ID ยังไม่ได้รับการอนุมัติ รอการอนุมัติจาก Threema (ตรวจสอบสถานะในแดชบอร์ด)
