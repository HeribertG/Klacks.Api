ตั้งค่าการส่งข้อความผ่าน Signal

ข้อกำหนดเบื้องต้น

ในการส่งข้อความ Signal ผ่าน Klacks คุณต้องมีอินสแตนซ์ที่โฮสต์เอง ของ signal-cli-rest-api ซึ่งเป็นโปรเจกต์ โอเพนซอร์สที่เปิดให้เข้าถึง Signal ผ่านอินเทอร์เฟซ REST

  • ต้องติดตั้ง Docker บนเซิร์ฟเวอร์
  • หมายเลขโทรศัพท์ ที่จะลงทะเบียนกับ Signal (แนะนำให้ใช้หมายเลขเฉพาะ)
  • Docker-Image: bbernhard/signal-cli-rest-api

สำคัญ: การเชื่อมต่อ Signal ออกแบบมา สำหรับการส่งเท่านั้น Klacks จะไม่รับข้อความ Signal ขาเข้า

ขั้นตอนที่ 1 — ตั้งค่า signal-cli-rest-api

  1. เริ่มคอนเทนเนอร์ด้วย Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. เชื่อมโยงหมายเลข Signal ของคุณผ่าน วิธี QR-Link: เปิดในเบราว์เซอร์ 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    และสแกน QR-Code ที่แสดงด้วยแอป Signal บนโทรศัพท์ที่ ลงทะเบียนหมายเลขไว้ (การตั้งค่า → อุปกรณ์ที่เชื่อมต่อ → เชื่อมต่ออุปกรณ์) คอนเทนเนอร์จะถูกเชื่อมโยงเป็นอุปกรณ์ที่สอง
  3. อีกทางเลือกหนึ่งคือลงทะเบียนหมายเลขด้วยตนเองผ่าน API — รายละเอียดดูได้ในเอกสารประกอบของโปรเจกต์
  4. ทดสอบ API ด้วย Healthcheck: 
    curl http://localhost:8080/v1/about

หมายเหตุ: ดูรายละเอียดเพิ่มเติมเกี่ยวกับการตั้งค่าได้ที่ เอกสาร signal-cli-rest-api

ขั้นตอนที่ 2 — ตั้งค่า Signal ใน Klacks

  1. ไปที่ การตั้งค่า → ผู้ให้บริการส่งข้อความ
  2. คลิก เพิ่ม
  3. กรอกข้อมูลในช่องต่างๆ ดังนี้

ขั้นตอนที่ 3 — ส่งข้อความผ่านแชทบอท (Klacksy)

เมื่อตั้งค่าและเปิดใช้งานผู้ให้บริการ Signal แล้ว แชทบอท Klacksy สามารถส่งข้อความได้ทันที คุณไม่จำเป็นต้องทราบหมายเลขโทรศัพท์ — เพียงระบุชื่อพนักงานหรือลูกค้า: 

"ส่งข้อความถึงสมชาย ใจดี: ท่านมีนัดหมายพรุ่งนี้เวลา 14:00 น."
"ส่งข้อความ Signal ถึงสมหญิง รักดี: กะงานได้ถูกสลับแล้ว"
"แจ้งประเสริฐ มั่นคงว่ากะงานวันจันทร์ถูกยกเลิก"

Klacksy จะค้นหาหมายเลขมือถือของผู้รับที่บันทึกไว้โดยอัตโนมัติ และ ใช้ผู้ให้บริการ Signal ที่ตั้งค่าไว้ กระบวนการส่งทั้งหมดโปร่งใสสำหรับคุณ — คุณเพียงระบุชื่อ ส่วนที่เหลือ Klacksy จะจัดการให้

ข้อกำหนด: ผู้รับต้องมีหมายเลขมือถือบันทึกไว้ใน Klacks (ที่เมนู ที่อยู่ → ข้อมูลติดต่อ) ในรูปแบบสากล (เช่น +41791234567) แม้แต่การส่งข้อความแบบ Broadcast ก็ยังใช้หมายเลขมือถือที่บันทึกไว้เช่นกัน

ข้อความขาเข้า

การเชื่อมต่อ Signal ไม่รองรับการรับข้อความ — การตอบกลับข้อความที่ส่งไป จะ ไม่ ถูกส่งเข้ามาที่ Klacks ดังนั้น Messaging-Inbox จะไม่แสดงข้อความขาเข้าสำหรับผู้ให้บริการนี้

การแก้ไขปัญหา

ปัญหาสาเหตุที่เป็นไปได้วิธีแก้ไข
การทดสอบการเชื่อมต่อล้มเหลว ไม่สามารถเข้าถึงคอนเทนเนอร์ได้ ตรวจสอบว่าคอนเทนเนอร์ Docker กำลังทำงานอยู่ (docker ps) และ API-URL ถูกต้องหรือไม่
การทดสอบการเชื่อมต่อล้มเหลว หมายเลขยังไม่ได้ลงทะเบียนในคอนเทนเนอร์ ทำการเชื่อมโยงซ้ำผ่านวิธี QR-Link
ไม่สามารถส่งข้อความได้ ผู้รับไม่ได้ใช้ Signal หรือหมายเลขไม่ถูกต้อง ตรวจสอบว่าผู้รับติดตั้ง Signal แล้ว และหมายเลขถูกบันทึกในรูปแบบ +{รหัสประเทศ}{หมายเลข}
การเชื่อมโยงหลุด อุปกรณ์ถูกยกเลิกการเชื่อมต่อในแอป Signal เชื่อมโยงคอนเทนเนอร์ใหม่ผ่าน QR-Link
คอนเทนเนอร์ไม่เริ่มทำงาน พอร์ต 8080 ถูกใช้งานอยู่แล้ว ใช้พอร์ตอื่นแทน: -p 9090:8080 และปรับ API-URL ใน Klacks ให้สอดคล้องกัน
