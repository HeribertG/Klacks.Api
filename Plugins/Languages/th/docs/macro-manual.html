คู่มือมาโครสคริปต์

บทนำ

ตัวแก้ไขมาโครช่วยให้คุณสร้างสคริปต์ที่ใช้เป็นพื้นฐานการคำนวณสำหรับงาน รูปแบบการจ้างงาน ฯลฯ

ตัวอย่างการใช้งาน:

  • การคำนวณเวลาพักร้อนและราชการทหารที่แม่นยำตามอัตราการจ้างงาน
  • การคำนวณค่าล่วงเวลาสำหรับกะกลางคืน วันหยุดสุดสัปดาห์ และวันหยุดราชการ
  • การปรับตัวอย่างยืดหยุ่นตามข้อกำหนดใหม่

หมายเหตุ: ตัวแปลสคริปต์ทำงานในสภาพแวดล้อมแซนด์บ็อกซ์ที่ปลอดภัย ไม่สามารถเข้าถึงระบบไฟล์หรือเครือข่ายได้ ไม่สามารถรันโค้ดที่เป็นอันตรายได้

ฟังก์ชันและหมวดหมู่

นอกจากชื่อและเนื้อหาสคริปต์แล้ว มาโครแต่ละตัวในรายการมาโครยังมีคุณสมบัติอีกสองอย่างที่กำหนดผ่านเมนูแบบเลื่อนลงในตัวแก้ไข ได้แก่ หมวดหมู่ และ ฟังก์ชัน ทั้งสองอย่างเป็นเพียงข้อมูลเมทาดาทา – อยู่นอกเหนือจากสคริปต์ และไม่มีผลต่อการคำนวณ แต่ควบคุมว่า Klacks จะค้นหาและกำหนดมาโครที่เหมาะสมโดยอัตโนมัติอย่างไร

หมวดหมู่

หมวดหมู่กำหนดขอบเขตการใช้งานเชิงธุรกิจของมาโคร:

หมวดหมู่การใช้งาน
ไม่ได้กำหนดไม่มีขอบเขตการใช้งานพิเศษ (ค่าเริ่มต้นสำหรับมาโครใหม่)
กะการคำนวณค่าล่วงเวลาสำหรับกะปกติ (ค่าล่วงเวลากลางคืน วันหยุดสุดสัปดาห์ วันหยุดราชการ)
วันหยุดพักผ่อนการคำนวณชั่วโมงสำหรับวันหยุดพักร้อน
การเจ็บป่วยการคำนวณชั่วโมงสำหรับการเจ็บป่วย
อุบัติเหตุการคำนวณชั่วโมงสำหรับอุบัติเหตุ
เวิร์กชอป (มีค่าตอบแทน)เวลาเวิร์กชอป/ฝึกอบรมที่มีค่าตอบแทน
เวิร์กชอป (ไม่มีค่าตอบแทน)เวลาเวิร์กชอป/ฝึกอบรมที่ไม่มีค่าตอบแทน

หมวดหมู่ กะ มีบทบาทพิเศษ: กะที่สร้างขึ้นใหม่จะได้รับมาโครมาตรฐานของหมวดหมู่นี้โดยอัตโนมัติ (ดู "ฟังก์ชัน" ด้านล่าง) กะที่มีอยู่แล้วจะไม่ถูกเปลี่ยนแปลงย้อนหลังเด็ดขาด

ฟังก์ชัน: กำหนดเอง, มาตรฐาน, มาตรฐาน (แบบสะสม)

ฟังก์ชันจัดประเภทบทบาทของมาโครภายในหมวดหมู่ของมัน:

ฟังก์ชันความหมาย
กำหนดเองมาโครอิสระที่ไม่มีบทบาทพิเศษ สามารถมีได้หลายตัวต่อหมวดหมู่
มาตรฐานมาโครมาตรฐานของหมวดหมู่นี้ – จะถูกกำหนดให้กะใหม่โดยอัตโนมัติ มาโครในหมวดหมู่เดียวกันมีฟังก์ชันนี้ได้สูงสุดเพียง 1 ตัวเท่านั้น
มาตรฐาน (แบบสะสม)มาโครมาตรฐานทางเลือกที่ใช้ตรรกะการคำนวณค่าล่วงเวลาแบบสะสม (ดูด้านล่าง) มีได้สูงสุด 1 ตัวต่อหมวดหมู่เช่นกัน และสามารถมีอยู่ควบคู่กับมาโคร "มาตรฐาน" ได้

สำคัญ: ฟังก์ชันเพียงอย่างเดียวไม่มีผลต่อการคำนวณใดๆ – มันเป็นเพียงป้ายกำกับ ส่วนว่าค่าล่วงเวลาจะคำนวณแบบ "อัตราสูงสุดชนะ" (นับเฉพาะอัตราสูงสุดที่ใช้ได้) หรือแบบสะสม (รวมทุกอัตราที่เข้าเงื่อนไข) นั้นขึ้นอยู่กับ ตัวสคริปต์เอง มาโครหมวดหมู่ "กะ" สองตัวที่มาพร้อมระบบแสดงความแตกต่างนี้บนโครงสร้างพื้นฐานเดียวกัน:

  • "AllShift" (ฟังก์ชัน: มาตรฐาน) – หาค่าล่วงเวลาสูงสุดที่ใช้ได้ในแต่ละช่วงเวลา (กลางคืน/WE1/WE2/WE3/วันหยุดราชการ) และใช้เฉพาะค่านั้น
  • "AllShiftAdditive" (ฟังก์ชัน: มาตรฐาน (แบบสะสม)) – คำนวณค่าล่วงเวลากลางคืน วันหยุดสุดสัปดาห์ และวันหยุดราชการแยกจากกันโดยอิสระ แล้วนำมารวมกัน

การตั้งค่าระดับติดตั้งทั้งระบบ ("แบบสะสม" หรือ "อัตราสูงสุดชนะ") เป็นตัวควบคุมว่ามาโครใดจะถูกกำหนดโดยอัตโนมัติเมื่อสร้างกะใหม่ หลังจากนั้นสามารถเปลี่ยนมาโครของแต่ละกะด้วยตนเองได้ตลอดเวลา – จึงสามารถใช้งานแบบผสมกันได้

ความเป็นเอกลักษณ์: หากคุณพยายามบันทึกมาโครตัวที่สองในหมวดหมู่เดียวกันเป็น "มาตรฐาน" หรือ "มาตรฐาน (แบบสะสม)" ตัวแก้ไขจะปฏิเสธการบันทึกและแจ้งชื่อของมาโครที่ถูกกำหนดไว้แล้ว ให้เปลี่ยนฟังก์ชันของมาโครนั้นเป็น "กำหนดเอง" ก่อน

ไม่แนะนำให้แก้ไข "AllShift"/"AllShiftAdditive" ด้วยตนเอง มาโครทั้งสองตัวนี้เป็นกลไกที่ใช้นำการปรับปรุงเฉพาะประเทศและเฉพาะอุตสาหกรรมมาใช้โดยอัตโนมัติ ตราบใดที่คุณไม่แก้ไขมัน Klacks จะซิงค์มาโครให้ตรงกับกฎเกณฑ์ที่เหมาะสมกับประเทศหรืออุตสาหกรรมของคุณโดยอัตโนมัติ หากคุณแก้ไขตัวใดตัวหนึ่งด้วยตนเอง มาโครนั้นจะถือว่าเป็นมาโครเฉพาะของลูกค้าตั้งแต่นั้นเป็นต้นไป – การอัปเดตประเทศ/อุตสาหกรรมโดยอัตโนมัติในอนาคตสำหรับมาโครนี้จะ ไม่ถูกนำมาใช้แบบเงียบๆ อีกต่อไป แต่จะล้มเหลวพร้อมแจ้งความขัดแย้ง จนกว่าคุณจะแก้ไขความแตกต่างด้วยตนเอง หากคุณต้องการตรรกะการคำนวณค่าล่วงเวลาของคุณเอง ให้สร้างมาโครใหม่ที่มีฟังก์ชัน "กำหนดเอง" แทน และกำหนดมันให้กับกะที่เกี่ยวข้องโดยเฉพาะ

we1rateDecimalอัตราค่าล่วงเวลาสำหรับวันหยุดสุดสัปดาห์ที่กำหนดค่าได้ วันที่ 1 (เช่น วันเสาร์)
we2rateDecimalอัตราค่าล่วงเวลาสำหรับวันหยุดสุดสัปดาห์ที่กำหนดค่าได้ วันที่ 2 (เช่น วันอาทิตย์)
we3rateDecimalอัตราค่าล่วงเวลาสำหรับวันหยุดสุดสัปดาห์ที่กำหนดค่าได้ วันที่ 3

weekendday1Integerวันในสัปดาห์แบบ ISO ของวันหยุดสุดสัปดาห์ที่กำหนดค่าไว้ วันที่ 1 (0 = ไม่ได้กำหนดค่า)
weekendday2Integerวันในสัปดาห์แบบ ISO ของวันหยุดสุดสัปดาห์ที่กำหนดค่าไว้ วันที่ 2
weekendday3Integerวันในสัปดาห์แบบ ISO ของวันหยุดสุดสัปดาห์ที่กำหนดค่าไว้ วันที่ 3

ฟังก์ชันและโพรซีเจอร์

สำคัญ: ฟังก์ชัน (FUNCTION) และโพรซีเจอร์ (SUB) ต้องถูกกำหนดก่อนการเรียกใช้ครั้งแรก ตัวแปลจะอ่านโค้ดจากบนลงล่าง ฟังก์ชันหรือโพรซีเจอร์จะใช้งานได้หลังจากที่คำจำกัดความถูกประมวลผลแล้วเท่านั้น

SUB (โพรซีเจอร์ไม่มีค่าส่งกลับ)

SUB berechne(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (ฟังก์ชันมีค่าส่งกลับ)

FUNCTION verdoppeln(x)
    verdoppeln = x * 2
ENDFUNCTION

DIM ergebnis
ergebnis = verdoppeln(21)
OUTPUT 1, ergebnis

typ และ wert เป็นนิพจน์สองตัวที่คั่นด้วยจุลภาค ทั้งสองเป็นตัวเลือก (ค่าเริ่มต้นคือ 0 และ "" ตามลำดับ หากละไว้) มาโครหนึ่งตัวสามารถมีบรรทัด OUTPUT ได้หลายบรรทัดตามต้องการ – แต่ละบรรทัดจะสร้างค่าส่งกลับของตัวเอง Klacks จะประมวลผลเฉพาะประเภทต่อไปนี้เท่านั้น:

ประเภทความหมาย
1ผลลัพธ์หลัก (ชั่วโมงหรือยอดรวม) – จะถูกนำไปใช้แม้ค่าจะเป็น 0
10ค่าล่วงเวลากลางคืน
11ค่าล่วงเวลาสำหรับวันหยุดสุดสัปดาห์ที่ 1 (เช่น วันเสาร์)
12ค่าล่วงเวลาสำหรับวันหยุดสุดสัปดาห์ที่ 2 (เช่น วันอาทิตย์)
13ค่าล่วงเวลาสำหรับวันหยุดสุดสัปดาห์ที่ 3 (วันหยุดสุดสัปดาห์ที่กำหนดค่าได้ตัวที่สาม)
14ค่าล่วงเวลาวันหยุดราชการ

บรรทัดค่าล่วงเวลา (ประเภท 10-14) ที่มีค่าเป็น 0 จะถูกละเว้น – มาโครจึงไม่จำเป็นต้องส่งออกบรรทัดสำหรับค่าล่วงเวลาทุกประเภท แต่ส่งเฉพาะค่าล่วงเวลาที่เกิดขึ้นจริงเท่านั้น ค่าที่ไม่สามารถตีความเป็นตัวเลขได้จะถูกข้ามไป

เมื่อบันทึก มาโครจะถูกคอมไพล์และรันทดสอบหนึ่งครั้งด้วยค่าทดสอบที่เป็นกลางเสมอ ข้อผิดพลาดด้านไวยากรณ์และรันไทม์ (เช่น วงเล็บไม่สมดุลหรือนิพจน์ที่ค้าง) จะถูกแสดงอย่างน่าเชื่อถือ แทนที่จะทำให้มาโครใช้งานไม่ได้โดยไม่มีการแจ้งเตือน

ตัวอย่าง: การคำนวณค่าล่วงเวลา ("AllShift")

มาโครมาตรฐานของหมวดหมู่ "กะ" ที่มาพร้อมระบบ คำนวณค่าล่วงเวลาสำหรับกลางคืน วันหยุดราชการ และวันหยุดสุดสัปดาห์ ที่กำหนดค่าได้สามวัน โดยจัดการกะที่ข้ามเที่ยงคืนอย่างถูกต้อง (การแบ่งช่วง) และใช้อัตราสูงสุดที่ใช้ได้ในแต่ละช่วง (อัตราสูงสุดชนะ) 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

คำอธิบาย

  • การแบ่งช่วง: สำหรับกะที่ข้ามเที่ยงคืน (เช่น 22:00-06:00) กะจะถูกแบ่งเป็นสองช่วง (ก่อนเที่ยงคืน / หลังเที่ยงคืน) แต่ละช่วงมีวันในสัปดาห์/สถานะวันหยุดราชการของตัวเอง
  • SegBonusForType: คำนวณค่าล่วงเวลาสำหรับหนึ่งช่วงและประเภทค่าล่วงเวลาที่กำหนด (10-14) โดยพิจารณาค่าล่วงเวลากลางคืน วันหยุดราชการ และวันหยุดสุดสัปดาห์
  • WE1/WE2/WE3 แทนวันเสาร์/อาทิตย์: weekendday1-3 ทำให้วันหยุดสุดสัปดาห์กำหนดค่าได้ (ไม่ใช่ทุกประเทศที่ใช้วันเสาร์/อาทิตย์เป็นวันหยุดสุดสัปดาห์)
  • ค่าล่วงเวลาสูงสุดต่อช่วง: NRate/DRate หาอัตราสูงสุดที่ใช้ได้สำหรับ ชั่วโมงกลางคืนและกลางวันตามลำดับ – อัตราสูงสุดชนะ ไม่มีการซ้อนทับกัน
  • HolidayNextDay: พิจารณาว่าวันถัดไปเป็นวันหยุดราชการหรือไม่ (สำคัญสำหรับกะกลางคืนที่ข้ามเที่ยงคืน)
  • หลายบรรทัด OUTPUT: บรรทัด 1 ให้ผลรวมทั้งหมด บรรทัด 10-14 ให้ยอดค่าล่วงเวลาแต่ละประเภท (ดูหัวข้อ "ค่าส่งกลับ")

รูปแบบสะสม ("AllShiftAdditive")

มาโครมาตรฐาน (แบบสะสม) ของหมวดหมู่เดียวกันมีบรรทัด IMPORT และโครงสร้างเหมือนกันทุกประการ – มีเพียง SegBonusForType เท่านั้นที่แตกต่าง: แทนที่จะใช้อัตราสูงสุด แต่ละประเภทค่าล่วงเวลาจะถูกคำนวณแยกจากกันโดยอิสระ ว่าเข้าเงื่อนไขหรือไม่ แล้วนำยอดที่เข้าเงื่อนไขทั้งหมดมารวมกันในตอนท้าย (ไม่มีอัตราสูงสุดชนะอีกต่อไป): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

ตัวอย่างเช่น หากกะกลางคืนตรงกับวันหยุดราชการด้วย ใน "AllShift" จะได้รับเฉพาะอัตราที่สูงกว่าจากสองอัตรา ในขณะที่ "AllShiftAdditive" จะได้รับทั้งค่าล่วงเวลากลางคืน และ วันหยุดราชการรวมกัน ส่วนที่เหลือของสคริปต์ (การแบ่งช่วง การรวมยอด บรรทัด OUTPUT) เหมือนกับ "AllShift" ด้านบนทุกประการ
