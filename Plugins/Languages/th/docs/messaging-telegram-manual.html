ตั้งค่า Telegram Bot

ข้อกำหนดเบื้องต้น

หากต้องการส่งและรับข้อความ Telegram ผ่าน Klacks คุณต้องมี Telegram Bot บอทสามารถสร้างได้ผ่าน BotFather อย่างเป็นทางการ และไม่มีค่าใช้จ่าย

ขั้นตอนที่ 1 — สร้าง Telegram Bot

  1. เปิด Telegram แล้วค้นหา @BotFather
  2. เริ่มแชทกับ BotFather แล้วส่งคำสั่ง /newbot
  3. ตั้งชื่อให้กับบอทของคุณ (เช่น Klacks Benachrichtigungen)
  4. ตั้งชื่อผู้ใช้ให้กับบอท (ต้องลงท้ายด้วย bot เช่น klacks_notify_bot)
  5. BotFather จะให้ Bot Token แก่คุณ ให้คัดลอกโทเค็นนี้ไว้ — จะต้องใช้ในขั้นตอนถัดไป

หมายเหตุ: ให้ปฏิบัติต่อ Bot Token เหมือนรหัสผ่าน อย่าเปิดเผยต่อสาธารณะ และเก็บรักษาไว้อย่างปลอดภัย

ขั้นตอนที่ 2 — กำหนดค่าบอทใน Klacks

  2. คลิก เพิ่ม
  3. กรอกข้อมูลในช่องต่าง ๆ ดังนี้

ขั้นตอนที่ 3 — ส่งข้อความผ่านแชทบอท (Klacksy)

เมื่อกำหนดค่าและเปิดใช้งาน Telegram Bot แล้ว แชทบอท Klacksy สามารถส่งข้อความได้ทันที คุณไม่จำเป็นต้องทราบ Chat ID — เพียงใช้ชื่อของพนักงานหรือลูกค้าก็เพียงพอ: 

"ส่งข้อความถึง Max Muster: นัดหมายของคุณคือพรุ่งนี้เวลา 14:00 น."
"ส่งข้อความถึง Anna Beispiel: กะงานได้รับการสลับแล้ว"
"แจ้ง Peter Müller ว่าเวรของเขาในวันจันทร์ถูกยกเลิก"

Klacksy จะค้นหาชื่อผู้ใช้ Telegram ของผู้รับที่บันทึกไว้โดยอัตโนมัติ และ ใช้บอทที่กำหนดค่าไว้ กระบวนการส่งข้อความทั้งหมดโปร่งใสสำหรับคุณอย่างสมบูรณ์ — คุณเพียงใช้ชื่อ ส่วนที่เหลือ Klacksy จะจัดการให้

ข้อกำหนดเบื้องต้น: ผู้รับต้องมีการบันทึกชื่อผู้ใช้ Telegram ไว้ใน Klacks (ภายใต้ ที่อยู่ → ข้อมูลติดต่อ)

ขั้นตอนที่ 4 — รับข้อความขาเข้า (Webhook)

หากต้องการแสดงข้อความ Telegram ขาเข้าใน Klacks จะต้องกำหนดค่า Webhook

  1. ตรวจสอบให้แน่ใจว่าอินสแตนซ์ Klacks ของคุณสามารถเข้าถึงได้แบบสาธารณะผ่าน HTTPS
  2. ป้อน Webhook URL ต่อไปนี้ในการตั้งค่าผู้ให้บริการ: 
    https://{ihre-domain}/api/messaging/webhook/telegram
  3. Klacks จะลงทะเบียน Webhook กับ Telegram โดยอัตโนมัติทันทีที่ผู้ให้บริการถูกบันทึกและเปิดใช้งาน
  4. ข้อความขาเข้าจะปรากฏแบบเรียลไทม์ใน กล่องข้อความ (Messaging-Inbox)

การแก้ไขปัญหา

ปัญหาสาเหตุที่เป็นไปได้วิธีแก้ไข
การทดสอบการเชื่อมต่อล้มเหลว Bot Token ไม่ถูกต้อง ตรวจสอบโทเค็นกับ BotFather โดยใช้ /mybots
ข้อความไม่ถูกส่งถึงผู้รับ ผู้รับยังไม่ได้เริ่มใช้งานบอท ผู้รับต้องเปิดบอทใน Telegram และส่งคำสั่ง /start
ไม่พบผู้รับ ยังไม่ได้บันทึกชื่อผู้ใช้ Telegram ป้อนชื่อผู้ใช้ Telegram ภายใต้ ที่อยู่ → ข้อมูลติดต่อ
ไม่มีข้อความขาเข้า ไม่สามารถเข้าถึง Webhook URL ได้ ตรวจสอบว่าโดเมนของคุณสามารถเข้าถึงได้ผ่าน HTTPS และ URL ถูกต้อง
การลงทะเบียน Webhook ล้มเหลว ไม่มีใบรับรอง SSL ที่ถูกต้อง Telegram ต้องการใบรับรอง SSL ที่ถูกต้อง (ไม่ใช่แบบ self-signed)
