ตั้งค่า WhatsApp

ข้อกำหนดเบื้องต้น

ในการส่งและรับข้อความผ่าน WhatsApp ด้วย Klacks คุณต้องมี บัญชีนักพัฒนา Meta และ Meta-App ที่เปิดใช้งานผลิตภัณฑ์ WhatsApp แล้ว Klacks ใช้ WhatsApp Cloud API ของแพลตฟอร์ม Meta Business สำหรับการส่ง และ Meta-Webhooks สำหรับการรับ

หมายเหตุ: การตั้งค่าและการทดสอบไม่มีค่าใช้จ่าย เมื่อสร้าง App Meta จะจัดเตรียม หมายเลขโทรศัพท์ทดสอบ ให้โดยอัตโนมัติและไม่มีค่าใช้จ่าย

สำคัญ — หมายเลขผู้ส่งไม่ใช่หมายเลขส่วนตัวของคุณ หมายเลขโทรศัพท์ที่ใช้งานอยู่แล้วในแอป WhatsApp ปกติ ไม่สามารถลงทะเบียนกับ Cloud API ได้ และหมายเลขที่ลงทะเบียนแล้วจะไม่สามารถใช้กับ WhatsApp Messenger ได้อีกต่อไป ดังนั้นให้ใช้หมายเลขทดสอบที่ Meta จัดเตรียมไว้ หรือหมายเลขของคุณเองที่ใช้เพื่อธุรกิจเท่านั้น WhatsApp ส่วนตัวบนโทรศัพท์มือถือของคุณทำหน้าที่เป็น ผู้รับ สำหรับการทดสอบ — ไม่ใช่ผู้ส่ง

ขั้นตอนที่ 1 — สร้าง Meta-App

  1. เปิด developers.facebook.com/apps และคลิก Create app
  2. เลือกกรณีการใช้งานเป็น Other และประเภท App เป็น Business
  3. ในหน้า Dashboard ให้คลิก Set up ที่ผลิตภัณฑ์ WhatsApp ระบบจะสร้างและลงทะเบียนหมายเลขโทรศัพท์ทดสอบให้โดยอัตโนมัติ
  4. ไปที่เมนูด้านซ้าย WhatsApp → API Setup
  5. จดบันทึก Phone number ID และสร้างโทเคนการเข้าถึงผ่าน Generate access token
  6. จดบันทึกค่า App Secret ที่ App settings → Basic — ค่านี้จำเป็นสำหรับการตรวจสอบลายเซ็นของข้อความขาเข้า

ข้อควรระวัง — มีสอง ID ที่คล้ายกัน: ในแผง API Setup นั้น Phone number ID และ WhatsApp Business Account ID จะอยู่ในบรรทัดถัดกันพอดี Klacks ต้องใช้ Phone number ID หากใช้ ID ผิด การทดสอบการเชื่อมต่อจะยังรายงานว่าสำเร็จ แต่การส่งทุกครั้งจะล้มเหลว

ข้อควรระวัง — อายุของโทเคน: โทเคนที่สร้างผ่าน Generate access token เป็นโทเคนทดสอบชั่วคราวและจะหมดอายุในเวลาอันสั้น สำหรับการใช้งานถาวร ให้สร้างโทเคนถาวรใน Meta Business Manager ผ่านผู้ใช้ระบบ

ขั้นตอนที่ 2 — เปิดสิทธิ์หมายเลขผู้รับ

หมายเลขทดสอบสามารถส่งได้เฉพาะผู้รับที่เปิดสิทธิ์ไว้ล่วงหน้าเท่านั้น ให้เพิ่มหมายเลข WhatsApp ของคุณ ในแผง API Setup ที่ To → Manage phone number list Meta จะส่งรหัสยืนยันไปยังหมายเลขนี้ ซึ่งคุณต้องกรอกรหัสดังกล่าว

หากไม่ทำขั้นตอนนี้ Meta จะปฏิเสธการส่งทุกครั้งไปยังหมายเลขนี้ เมื่อคุณเปลี่ยนไปใช้หมายเลขธุรกิจ ของคุณเองที่ผ่านการยืนยันแล้ว ก็ไม่จำเป็นต้องเปิดสิทธิ์อีกต่อไป

ขั้นตอนที่ 4 — หน้าต่าง 24 ชั่วโมง

ในเรื่องนี้ WhatsApp แตกต่างจาก Telegram หรือ Slack อย่างสิ้นเชิง ธุรกิจสามารถส่งข้อความแบบอิสระได้ เฉพาะในขณะที่ หน้าต่างบริการลูกค้า ยังเปิดอยู่เท่านั้น หน้าต่างนี้จะเปิดโดย ผู้รับ เมื่อเขาส่งข้อความมายังหมายเลข WhatsApp ของคุณ หน้าต่างจะเปิดอยู่ 24 ชั่วโมง และจะขยายเวลาออกไปทุกครั้งที่ผู้รับส่งข้อความเพิ่มเติม

นอกช่วงหน้าต่างนี้ Meta อนุญาตเฉพาะ เทมเพลตข้อความ ที่ได้รับอนุมัติล่วงหน้าเท่านั้น ปัจจุบัน Klacks ส่งเฉพาะข้อความแบบอิสระเท่านั้น จึง ไม่สามารถเริ่มต้นการสนทนาด้วยตนเองได้

สิ่งนี้หมายความว่าอย่างไรสำหรับคุณ: ขอให้พนักงานของคุณส่งข้อความไปยังหมายเลข WhatsApp ของ Klacks หนึ่งครั้ง หลังจากนั้นจะสามารถส่งข้อความได้เป็นเวลา 24 ชั่วโมง และทุกการตอบกลับจะขยายเวลา ของหน้าต่างออกไป หากหน้าต่างปิดอยู่ การส่งจะรายงานข้อผิดพลาด — นี่ไม่ใช่ปัญหาการตั้งค่า แต่เป็นข้อกำหนดของ WhatsApp

หากคุณจำเป็นต้องติดต่อพนักงานโดยไม่ขึ้นกับหน้าต่างนี้ Telegram หรือ Signal เป็นผู้ให้บริการที่เหมาะสมกว่า — เพราะไม่มีข้อจำกัดนี้

ขั้นตอนที่ 5 — ส่งข้อความผ่านแชทบอท (Klacksy)

เมื่อตั้งค่าและเปิดใช้งานผู้ให้บริการ WhatsApp แล้ว แชทบอท Klacksy สามารถส่งข้อความผ่าน WhatsApp ได้ โดยใช้ชื่อพนักงาน: 

"ส่งข้อความถึงสมชาย ใจดี: ท่านมีนัดหมายพรุ่งนี้เวลา 14:00 น."
"ส่งข้อความถึงสมหญิง รักดี: กะงานได้ถูกสลับแล้ว"

ผู้รับจะระบุด้วย หมายเลขโทรศัพท์ ในรูปแบบสากล โดยไม่มีเลขศูนย์นำหน้า และไม่มีเครื่องหมายบวก (เช่น 41791234567 สำหรับ 079 123 45 67) กระบวนการส่งทั้งหมดโปร่งใสสำหรับคุณ — คุณเพียงระบุชื่อ ส่วนที่เหลือ Klacksy จะจัดการให้

ข้อกำหนด: หมายเลข WhatsApp ต้องเชื่อมโยงกับผู้ติดต่อ ที่สอดคล้องกันใน Klacks (ที่เมนู ที่อยู่ → ข้อมูลติดต่อ) และหน้าต่าง 24 ชั่วโมง จากขั้นตอนที่ 4 ต้องเปิดอยู่

ขั้นตอนที่ 6 — รับข้อความขาเข้า (Webhooks)

เพื่อให้ข้อความ WhatsApp ขาเข้าแสดงใน Klacks ต้องตั้งค่า Webhook ของ Meta-App กรุณาบันทึกและเปิดใช้งานผู้ให้บริการใน Klacks ก่อน ที่จะใส่ Callback-URL — Meta จะตรวจสอบ URL ทันทีด้วยคำขอยืนยัน ซึ่ง Klacks จะตอบกลับโดยอัตโนมัติด้วย Verify-Token

  1. เปิด Meta-App ของคุณ และไปที่ WhatsApp → Configuration
  2. ที่ Webhook ให้คลิก Edit แล้วกรอกข้อมูลดังนี้:
    • Callback URL: Webhook-URL ที่แสดงใน Klacks 
      https://{โดเมนของคุณ}/api/messaging/webhook/whatsapp
    • Verify token: ค่าเดียวกันทุกประการกับที่คุณกรอกไว้ในช่อง Verify-Token ในขั้นตอนที่ 3
  3. คลิก Verify and save
  4. ที่ Webhook fields ให้สมัครรับฟิลด์ messages
  5. ข้อความขาเข้าจะปรากฏแบบเรียลไทม์ใน Messaging-Inbox โดย Klacks จะตรวจสอบลายเซ็นของทุกคำขอ (X-Hub-Signature-256) ด้วย App-Secret ที่บันทึกไว้

Callback-URL ต้องเข้าถึงได้จากภายนอกผ่าน HTTPS ในกรณีที่ติดตั้งในเครือข่ายภายในองค์กร โดยไม่มีที่อยู่สาธารณะ การส่งจะยังใช้งานได้ แต่จะไม่สามารถรับข้อความได้

การแก้ไขปัญหา

ปัญหาสาเหตุที่เป็นไปได้วิธีแก้ไข
การทดสอบการเชื่อมต่อล้มเหลว Access-Token หมดอายุ โทเคนทดสอบชั่วคราวจะหมดอายุในเวลาอันสั้น — สร้างใหม่ในแผง API Setup หรือตั้งค่าโทเคนถาวร
การทดสอบการเชื่อมต่อสำเร็จ แต่การส่งล้มเหลวทุกครั้ง กรอก Business Account ID แทนรหัสหมายเลขโทรศัพท์ ใช้ Phone number ID จากแผง API Setup ไม่ใช่ WhatsApp Business Account ID
ข้อผิดพลาดที่อ้างถึง 24 ชั่วโมงหรือการติดต่อใหม่อีกครั้ง หน้าต่างบริการลูกค้าปิดอยู่ ผู้รับต้องส่งข้อความมายังหมายเลข WhatsApp ของคุณก่อน — ดูขั้นตอนที่ 4
การส่งไปยังหมายเลขหนึ่งล้มเหลว ยังไม่ได้เปิดสิทธิ์ผู้รับสำหรับหมายเลขทดสอบ เพิ่มหมายเลขที่ Manage phone number list และยืนยันด้วยรหัส
การยืนยัน Webhook ล้มเหลว Verify-Token ไม่ตรงกัน หรือผู้ให้บริการยังไม่ได้บันทึก/เปิดใช้งานใน Klacks บันทึกและเปิดใช้งานผู้ให้บริการใน Klacks ก่อน แล้วใส่ Verify-Token เดียวกันที่ Meta
ไม่มีข้อความขาเข้า ยังไม่ได้สมัครรับฟิลด์ Webhook messages หรือ App-Secret ไม่ถูกต้อง สมัครรับฟิลด์ messages ที่ Configuration และตรวจสอบ App-Secret
