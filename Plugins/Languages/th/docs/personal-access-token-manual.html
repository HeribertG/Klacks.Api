คู่มือ Personal Access Tokens

Personal Access Tokens คืออะไร?

Personal Access Tokens (PATs) คือคีย์ API ที่มีอายุการใช้งานยาวนาน ซึ่งช่วยให้เครื่องมือและบริการภายนอก เข้าถึง Klacks ได้อย่างปลอดภัย — โดยไม่ต้องใช้ชื่อผู้ใช้และรหัสผ่าน

กรณีการใช้งานทั่วไป:

  • MCP (Model Context Protocol) — ช่วยให้ผู้ช่วย AI เช่น Claude Desktop เข้าถึงทักษะของ Klacksy ได้โดยตรง
  • สคริปต์อัตโนมัติและ CI/CD Pipeline
  • เครื่องมือตรวจสอบและการเชื่อมต่อภายนอก

แนวคิดด้านความปลอดภัย

Klacks จะไม่เก็บโทเคนแบบข้อความธรรมดาเลย หลังจากสร้างโทเคนแล้ว จะมีการเก็บเฉพาะ SHA-256 Hash ของโทเคนไว้ในฐานข้อมูลเท่านั้น ตัวโทเคนจริงจะแสดง เพียงครั้งเดียวทันทีหลังจากสร้าง และหลังจากนั้นจะไม่สามารถเรียกดูได้อีก

หมายเหตุ: กรุณาจดบันทึกหรือคัดลอกโทเคนทันทีหลังจากสร้าง หากทำหาย ต้องสร้างโทเคนใหม่และเพิกถอนโทเคนเดิม

การสร้างโทเคน

ขั้นตอนทีละขั้น

  • ไปที่ การกำหนดค่า → Personal Access Tokens
  • คลิก สร้างโทเคนใหม่
  • ตั้งชื่อที่สื่อความหมายชัดเจน (เช่น Claude Desktop หรือ CI-Pipeline)
  • เลือกระยะเวลาที่ใช้ได้ที่ต้องการ (1–730 วัน ค่าเริ่มต้น: 365 วัน)
  • คลิก สร้าง
  • คัดลอกโทเคนที่แสดงทันที — จะแสดงเพียงครั้งเดียวเท่านั้น

รูปแบบโทเคน

klacks_pat_<สายอักขระแบบสุ่ม>

โทเคนแต่ละอันจะเริ่มต้นด้วยคำนำหน้า klacks_pat_ ตามด้วยสายอักขระแบบสุ่ม ที่มีความปลอดภัยทางการเข้ารหัส

ระยะเวลาที่ใช้ได้

ระยะเวลาการใช้งานที่แนะนำ
1–30 วันการทดสอบและการพัฒนาระยะสั้น
90–180 วันCI/CD Pipeline ที่มีการหมุนเวียนสม่ำเสมอ
365 วัน (ค่าเริ่มต้น)การเชื่อมต่อแบบถาวร (เช่น Claude Desktop)
730 วันการเชื่อมต่อระบบระยะยาว

การใช้งานโทเคน

Bearer Token ใน HTTP Header

โทเคนจะถูกส่งเป็น Bearer Token ใน Header Authorization ของทุกคำขอ API:

Authorization: Bearer klacks_pat_...

การตั้งค่า MCP กับ Claude Desktop

MCP Endpoint (/mcp) ช่วยให้ผู้ช่วย AI เช่น Claude Desktop เข้าถึงทักษะ ของ Klacksy ทั้งหมดได้โดยตรง — สอบถามข้อมูลพนักงาน วางแผนกะ จัดการกลุ่ม และอื่นๆ อีกมากมาย

การกำหนดค่าในแอป Claude Desktop (claude_desktop_config.json):

{
  "mcpServers": {
    "klacks": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-fetch",
        "https://<โดเมน-klacks-ของคุณ>/mcp"
      ],
      "env": {
        "AUTHORIZATION": "Bearer klacks_pat_..."
      }
    }
  }
}

แทนที่ <โดเมน-klacks-ของคุณ> ด้วยที่อยู่ของการติดตั้ง Klacks ของคุณ และ klacks_pat_... ด้วยโทเคนที่คุณสร้างไว้

คำขอ API โดยตรง (curl)

curl -H "Authorization: Bearer klacks_pat_..." \
     https://<โดเมน-klacks-ของคุณ>/api/clients

การจัดการและความปลอดภัย

ภาพรวมของโทเคน

ที่ การกำหนดค่า → Personal Access Tokens คุณจะเห็นโทเคนทั้งหมดของคุณ พร้อมชื่อ วันที่สร้าง วันหมดอายุ และการใช้งานล่าสุด โทเคนแบบข้อความธรรมดาจะไม่แสดงในมุมมองนี้เลย

การเพิกถอนโทเคน

สามารถเพิกถอนโทเคนได้ทุกเมื่อ หลังจากเพิกถอนแล้ว คำขอทั้งหมดที่ใช้โทเคนนี้ จะถูกปฏิเสธทันที กรุณาเพิกถอนโทเคนทันทีเมื่อ:

  • โทเคนถูกเปิดเผยโดยไม่ตั้งใจ
  • อุปกรณ์หรือบริการไม่ได้ใช้งานอีกต่อไป
  • คุณสังเกตเห็นกิจกรรมที่น่าสงสัย

วันหมดอายุ

โทเคนที่หมดอายุจะถูกปฏิเสธโดยอัตโนมัติ Klacks จะแสดงในภาพรวม โทเคนที่จะหมดอายุภายใน 30 วันข้างหน้า เพื่อให้คุณสร้างโทเคนใหม่ ได้ทันเวลา

เคล็ดลับด้านความปลอดภัย

  • ใช้โทเคนแยกต่างหากสำหรับแต่ละบริการหรือเครื่องมือ
  • เลือกชื่อที่สื่อความหมายชัดเจนเพื่อให้ระบุโทเคนได้ง่าย
  • ห้ามเก็บโทเคนแบบข้อความธรรมดาในระบบควบคุมเวอร์ชันเด็ดขาด
  • หมุนเวียนโทเคนอย่างสม่ำเสมอ โดยเฉพาะเมื่อใช้กับ CI/CD
  • เพิกถอนโทเคนทันทีหากสงสัยว่ามีการใช้งานในทางที่ผิด

โทเคนแต่ละอันผูกกับบัญชีผู้ใช้ของคุณและมีสิทธิ์เช่นเดียว กับบัญชีของคุณ กรุณาดูแลรักษาโทเคนด้วยความระมัดระวัง เช่นเดียวกับรหัสผ่านของคุณ
