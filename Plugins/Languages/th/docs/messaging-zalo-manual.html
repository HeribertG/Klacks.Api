ตั้งค่า Zalo Messaging

ข้อกำหนดเบื้องต้น

ในการส่งข้อความผ่าน Zalo คุณต้องมี Zalo Official Account (OA) บน oa.zalo.me รวมถึงแอปบน developers.zalo.me Zalo เป็นแอปพลิเคชันส่งข้อความชั้นนำในเวียดนาม

สำคัญ: การเชื่อมต่อ Zalo ออกแบบมา สำหรับการส่งเท่านั้น นอกจากนี้ยังมีข้อจำกัดของแพลตฟอร์ม Zalo ดังนี้:

  • Access Token จะหมดอายุหลังจาก ประมาณ 25 ชั่วโมง และต้องต่ออายุและบันทึกใหม่ นอกระบบ Klacks
  • สามารถส่งข้อความได้เฉพาะผู้ใช้ที่เคย โต้ตอบ กับ Official Account มาก่อนเท่านั้น (หน้าต่างการโต้ตอบ)

ขั้นตอนที่ 1 — ตั้งค่า Zalo Official Account และแอป

  1. สร้าง Official Account บน oa.zalo.me
  2. สร้าง แอป บน developers.zalo.me
  3. เชื่อมโยง Official Account เข้ากับแอป
  4. ขอรับ Access Token ผ่านขั้นตอน OAuth ของ คอนโซลนักพัฒนา Zalo

หมายเหตุ: ควรจัดการ Access Token เสมือนเป็นรหัสผ่าน ห้ามเผยแพร่ต่อสาธารณะและควรเก็บรักษาไว้อย่างปลอดภัย

ขั้นตอนที่ 2 — ตั้งค่า Zalo ใน Klacks

  1. ไปที่ การตั้งค่า → ผู้ให้บริการ Messaging
  2. คลิก เพิ่ม
  3. กรอกข้อมูลในช่องต่าง ๆ ดังนี้:
ช่องคำอธิบายตัวอย่าง
ชื่อชื่อภายในที่ไม่ซ้ำกันzalo-oa
ชื่อที่แสดงแสดงในส่วนติดต่อผู้ใช้Zalo
ประเภทผู้ให้บริการเลือก ZaloZalo
Access Tokenโทเค็นที่ได้รับผ่านขั้นตอน OAuthzalo-oa-access-token...
OA-IDรหัสของ Official Account ของคุณ (ใช้เพื่อการอ้างอิงเท่านั้น)987654321...
เปิดใช้งานเปิด/ปิดผู้ให้บริการใช่
  1. คลิก บันทึก
  2. ทดสอบการเชื่อมต่อผ่านปุ่ม ทดสอบ ในรายการผู้ให้บริการ

สำคัญ: Access Token จะหมดอายุหลังจาก ประมาณ 25 ชั่วโมง Klacks จะไม่ต่ออายุให้โดยอัตโนมัติ — คุณต้องต่ออายุจากภายนอกผ่าน ขั้นตอน Refresh Token ของ Zalo แล้วบันทึกลงใน Klacks ใหม่ โปรดทราบว่า: Refresh Token เป็น ใช้ได้ครั้งเดียว (single-use) — การต่ออายุแต่ละครั้งจะได้รับ โทเค็นคู่ใหม่

ขั้นตอนที่ 3 — ส่งข้อความผ่านแชทบอท (Klacksy)

เมื่อผู้ให้บริการ Zalo ได้รับการตั้งค่าและเปิดใช้งานแล้ว แชทบอท Klacksy จะสามารถ ส่งข้อความได้ คุณไม่จำเป็นต้องทราบ Zalo User ID — เพียงแค่ ใช้ชื่อของพนักงานหรือลูกค้า: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy จะค้นหา Zalo User ID ของผู้รับที่บันทึกไว้โดยอัตโนมัติ และ ใช้ผู้ให้บริการ Zalo ที่ตั้งค่าไว้ การส่งข้อความจะโปร่งใสอย่างสมบูรณ์สำหรับคุณ — คุณทำงานด้วยชื่อ ส่วน Klacksy จะจัดการที่เหลือให้เอง

ข้อกำหนด: ผู้รับต้องมีการบันทึก Zalo User ID ไว้ใน Klacks (ภายใต้ ที่อยู่ → ข้อมูลติดต่อ) ผู้รับต้อง เคยโต้ตอบกับ Official Account มาก่อน (เช่น ติดตาม OA หรือส่ง ข้อความถึง OA) — หากอยู่นอกหน้าต่างการโต้ตอบ Zalo จะปฏิเสธการส่งข้อความ

ข้อความขาเข้า

การเชื่อมต่อ Zalo ไม่รองรับการรับข้อความ — การตอบกลับข้อความที่ส่งไป จะไม่ถูกส่งเข้าสู่ Klacks ดังนั้นกล่องข้อความ Messaging จะไม่แสดง ข้อความขาเข้าสำหรับผู้ให้บริการรายนี้

การแก้ไขปัญหา

ปัญหาสาเหตุที่เป็นไปได้วิธีแก้ไข
การทดสอบการเชื่อมต่อล้มเหลว Access Token หมดอายุ (อายุการใช้งานประมาณ 25 ชั่วโมง) ต่ออายุโทเค็นผ่านขั้นตอน Refresh Token และบันทึกใหม่
ข้อความไม่ถูกส่งถึงผู้รับ ผู้ใช้ยังไม่เคยโต้ตอบกับ Official Account ผู้รับต้องติดตาม OA หรือส่งข้อความถึง OA ก่อน
ไม่พบผู้รับ ยังไม่ได้บันทึก Zalo User ID กรอก User ID ภายใต้ ที่อยู่ → ข้อมูลติดต่อ
การต่ออายุโทเค็นล้มเหลว Refresh Token ถูกใช้ไปแล้ว (ใช้ได้ครั้งเดียว) ดำเนินการตามขั้นตอน OAuth ในคอนโซลนักพัฒนา Zalo อีกครั้ง
การส่งถูกปฏิเสธเนื่องจากข้อผิดพลาดด้านสิทธิ์ OA ยังไม่ได้เชื่อมโยงกับแอป ตรวจสอบการเชื่อมโยงระหว่างแอปและ Official Account บน developers.zalo.me
