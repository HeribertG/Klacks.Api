คู่มือฟิลด์สูตรคำนวณ

ไวยากรณ์พื้นฐาน

ฟิลด์สูตรคำนวณแต่ละฟิลด์จะแสดงผลลัพธ์ด้วยคำสั่ง output:

output 1, <Ausdruck>

พารามิเตอร์แรก 1 คือประเภทข้อความ และต้องเป็น 1 เสมอ พารามิเตอร์ที่สองคือค่าที่จะแสดงผล

ตัวอย่างง่าย ๆ:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " Einträge"

ตัวแปรที่ใช้ได้

ตัวแปรที่ใช้ได้จะแสดงอยู่ในแท็บ ตัวแปร และสามารถกำหนดค่าทดสอบไว้ที่นั่นได้ ทั้งนี้ตัวแปรที่ใช้ได้จะแตกต่างกันไปตามประเภทของรายงาน:

ประเภทรายงานแถวสรุปท้ายตาราง
ตารางเวรทำงานtotalRows, totalHours, totalSurcharges, totalWorkDays
การขาดงานtotalRows, totalValue
ที่อยู่totalRows
กลุ่มtotalRows

ตัวดำเนินการ

ตัวดำเนินการคำอธิบายตัวอย่าง
+การบวกtotalHours + 2
-การลบtotalRows - 1
*การคูณtotalValue * 1.5
/การหารtotalHours / 8
^เลขยกกำลัง2 ^ 10
\การหารจำนวนเต็ม10 \ 3 → 3
MODโมดูโล (เศษที่เหลือ)10 MOD 3 → 1
&การต่อข้อความ"Total: " & totalRows

ฟังก์ชันในตัว

การแปลงชนิดข้อมูล

ฟังก์ชันคำอธิบาย
CStr(x)แปลงตัวเลขเป็นข้อความ
CInt(x)แปลงเป็นจำนวนเต็ม
CDbl(x)แปลงเป็นเลขทศนิยม

คณิตศาสตร์

ฟังก์ชันคำอธิบาย
Abs(x)ค่าสัมบูรณ์
Round(x, n)ปัดเศษให้เหลือ n ตำแหน่งทศนิยม
Int(x)ปัดเศษลงเป็นจำนวนเต็ม
Sqr(x)รากที่สอง
Sgn(x)เครื่องหมาย (-1, 0, 1)

ข้อความ

ฟังก์ชันคำอธิบาย
Len(s)ความยาวของข้อความ
Left(s, n)ตัวอักษร n ตัวจากด้านซ้าย
Right(s, n)ตัวอักษร n ตัวจากด้านขวา
Mid(s, pos, n)ตัวอักษร n ตัว เริ่มจากตำแหน่ง pos
UCase(s)แปลงเป็นตัวพิมพ์ใหญ่
LCase(s)แปลงเป็นตัวพิมพ์เล็ก
Trim(s)ลบช่องว่างที่ขอบข้อความ
Replace(s, alt, neu)แทนที่ข้อความ

ตรรกะแบบมีเงื่อนไข

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "viele Einträge"
ELSEIF totalRows > 0 THEN
    output 1, "wenige Einträge"
ELSE
    output 1, "keine Einträge"
ENDIF

IF บรรทัดเดียว

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (รูปแบบย่อ)

output 1, IIF(totalRows > 0, "OK", "Leer")

ตัวแปรและลูป

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

ตัวอย่างการใช้งานจริง

จำนวนรายการพร้อมข้อความ

output 1, CStr(totalRows) & " Einträge"

ค่าที่ปัดเศษ (1 ตำแหน่ง)

output 1, CStr(Round(totalValue, 1))

ชั่วโมงในรูปแบบ h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

การแสดงผลแบบมีเงื่อนไข

IF totalRows = 0 THEN
    output 1, "Keine Abwesenheiten"
ELSE
    output 1, CStr(totalRows) & " Abwesenheiten (Total: " & CStr(totalValue) & ")"
ENDIF

คำนวณค่าเฉลี่ย

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/Tag"
ELSE
    output 1, "-"
ENDIF
