ตั้งค่าผู้ให้บริการ SMS

ข้อกำหนดเบื้องต้น

ในการส่งข้อความ SMS ผ่าน Klacks คุณต้องมีบัญชีกับ Twilio หรือเกตเวย์ SMS ที่รองรับ Twilio Klacks ใช้ Twilio-REST-API (Messages-Endpoint พร้อม Basic-Authentication)

สำคัญ: การเชื่อมต่อ SMS ออกแบบมา สำหรับการส่งเท่านั้น Klacks จะไม่รับ SMS ขาเข้า

ขั้นตอนที่ 1 — ตั้งค่าบัญชี Twilio

  1. ลงทะเบียนที่ twilio.com และยืนยันหมายเลขโทรศัพท์ และที่อยู่อีเมลของคุณ
  2. เปิด Twilio Console ในหน้า Dashboard คุณจะพบ ข้อมูลการเข้าถึงสองอย่างที่จำเป็นภายใต้ Account Info:
    • Account SID — ขึ้นต้นด้วย AC
    • Auth Token — คลิก „แสดง" เพื่อแสดงค่า
  3. ซื้อ หมายเลขผู้ส่ง ที่ Phone Numbers → Buy a number (ต้องรองรับ SMS) หมายเลขนี้จะปรากฏเป็นผู้ส่งใน SMS ขาออก
  4. บัญชีทดลอง: บัญชี Trial ฟรีสามารถส่ง SMS ได้เฉพาะไปยังหมายเลข ที่ยืนยันไว้ล่วงหน้าเท่านั้น และจะมีข้อความแจ้งเตือน Trial แนบมาด้วย

หมายเหตุ: ให้ปฏิบัติต่อ Auth Token เหมือนรหัสผ่าน ห้ามเปิดเผยต่อสาธารณะและเก็บรักษาอย่างปลอดภัย

ขั้นตอนที่ 2 — ตั้งค่าผู้ให้บริการ SMS ใน Klacks

  1. ไปที่ การตั้งค่า → ผู้ให้บริการส่งข้อความ
  2. คลิก เพิ่ม
  3. กรอกข้อมูลในช่องต่างๆ ดังนี้

หมายเหตุเกี่ยวกับ Gateway-URL: เว้นช่องนี้ว่างไว้หากคุณใช้ Twilio — Klacks จะใช้ https://api.twilio.com โดยอัตโนมัติ กรอก URL เฉพาะ เมื่อคุณใช้เกตเวย์ทางเลือกที่มี API รองรับ Twilio เท่านั้น

ขั้นตอนที่ 3 — ส่งข้อความผ่านแชทบอท (Klacksy)

เมื่อตั้งค่าและเปิดใช้งานผู้ให้บริการ SMS แล้ว แชทบอท Klacksy สามารถส่งข้อความได้ทันที คุณไม่จำเป็นต้องทราบหมายเลขโทรศัพท์ — เพียงระบุชื่อพนักงานหรือลูกค้า: 

"ส่ง SMS ถึงสมชาย ใจดี: ท่านมีนัดหมายพรุ่งนี้เวลา 14:00 น."
"ส่ง SMS ถึงสมหญิง รักดี: กะงานได้ถูกสลับแล้ว"
"แจ้งประเสริฐ มั่นคงทาง SMS ว่ากะงานวันจันทร์ถูกยกเลิก"

Klacksy จะค้นหาหมายเลขมือถือของผู้รับที่บันทึกไว้โดยอัตโนมัติ และ ใช้ผู้ให้บริการ SMS ที่ตั้งค่าไว้ กระบวนการส่งทั้งหมดโปร่งใสสำหรับคุณ — คุณเพียงระบุชื่อ ส่วนที่เหลือ Klacksy จะจัดการให้

ข้อกำหนด: ผู้รับต้องมีหมายเลขมือถือบันทึกไว้ใน Klacks (ที่เมนู ที่อยู่ → ข้อมูลติดต่อ) ในรูปแบบสากล (เช่น +41791234567)

ข้อความขาเข้า

การเชื่อมต่อ SMS ไม่รองรับการรับข้อความ — การตอบกลับ SMS ที่ส่งไป จะ ไม่ ถูกส่งเข้ามาที่ Klacks ดังนั้น Messaging-Inbox จะไม่แสดงข้อความขาเข้าสำหรับผู้ให้บริการนี้

การทดสอบการเชื่อมต่อล้มเหลว Account-SID หรือ Auth-Token ไม่ถูกต้อง ตรวจสอบค่าทั้งสองในหน้า Dashboard ของ Twilio Console
SMS ไม่ถูกส่งถึง หมายเลขผู้ส่งไม่รองรับ SMS หรือยังไม่ได้เปิดใช้งาน ตรวจสอบหมายเลขที่ Phone Numbers ใน Twilio Console
ผู้รับไม่ได้รับ SMS (บัญชีทดลอง) หมายเลขผู้รับยังไม่ได้ยืนยัน ยืนยันหมายเลขใน Twilio Console หรือเปลี่ยนเป็นบัญชีแบบชำระเงิน
ผู้รับไม่ได้รับ SMS หมายเลขโทรศัพท์ไม่อยู่ในรูปแบบสากล ใช้รูปแบบ +{รหัสประเทศ}{หมายเลข} (เช่น +41791234567)
ข้อผิดพลาด „Permission to send an SMS has not been enabled" ยังไม่ได้เปิดใช้งานประเทศปลายทางใน Geo-Permissions เปิดใช้งานประเทศที่ Messaging → Geographic Permissions ใน Twilio Console
