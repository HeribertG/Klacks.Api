אימון Klacksy - הוראות שימוש

מהו כלי האימון?

כלי האימון שולט בניווט בתוך העמוד של הצ'אטבוט Klacksy. כאשר משתמש אומר או כותב "Klacksy תראה לי את הכתובות", Klacksy מנווט לעמוד המתאים וגולל אל הקטע הרלוונטי.

כדי שזה יעבוד, Klacksy זקוק לכל עוגן (anchor) בעמוד לרשימת נרדפים בכל שפה (למשל "כתובות", "לקוחות", "אנשי קשר" עבור היעד addresses).

כרטיסיית "יעדים"

רשימת כל העוגנים שנמצאו בממשק (תכונות HTML data-klacksy-target). מסנני סטטוס:

  • pending: העוגן קיים, אך עדיין אין נרדפים
  • generated: הנרדפים נוצרו אוטומטית, דורשים בדיקה
  • reviewed: הנרדפים אושרו על ידי מנהל מערכת
  • needs-review: מסומן לבדיקה חוזרת

לחיצה על יעד פותחת את עורך הנרדפים למטה. שם ניתן להוסיף נרדפים, למחוק אותם ולאשר אותם באמצעות "שמור כמאושר".

כרטיסיית "משובים"

מציגה קלטים של משתמשים ש-Klacksy לא הצליח להתאים (לא נמצא נרדף מתאים). על סמך רשימה זו ניתן לזהות אילו נרדפים עדיין חסרים.

כרטיסיית "מדדים"

סקירה כללית של כל היעדים לפי סטטוס. עוזרת לעקוב אחר התקדמות האימון.

שרשרת בנייה (CLI)

כאשר תבניות מקבלות עוגני data-klacksy-target חדשים, יש לחולל מחדש את המניפסט ואת הנרדפים ההתחלתיים. הפקודות הבאות פועלות גם אוטומטית ב-CI וב-Husky-Pre-Commit: 

cd C:\SourceCode\Klacks.Ui

# 1. סריקת תבניות → navigation-targets.json עם כל העוגנים
npm run scan:targets

# 2a. יצירת נרדפים התחלתיים (כל 4 שפות הליבה + 22 שפות תוסף, ~2.5 שעות)
npm run generate:synonyms

# 2b. שפות ליבה בלבד (de/en/fr/it) — מהיר, כ-9 דקות
npm run generate:synonyms -- --core-only

# 2c. השלמת שפות תוסף חסרות בלבד — כ-45 דקות
npm run generate:synonyms -- --plugins-only

# 3. בדיקת עקביות מילת ההפעלה (Wake-Word)
npm run wake-word-lint

חשוב: ב-npm run חובה להוסיף -- כדי שהאפשרויות יועברו לסקריפט. בלי -- npm בולע את הדגל (flag) והסקריפט פועל במצב ברירת המחדל.

חלופה ללא npm: npx tsx tools/generate-synonyms.ts --core-only.

מפתח API

מפתח ה-API של ה-LLM מחופש בסדר הבא:

  1. משתנה סביבה SYNONYM_LLM_API_KEY
  2. טבלת מסד הנתונים llm_providers (ספק deepseek, is_enabled = true) — אוטומטית באמצעות קריאת psql
  3. אחרת מוצגת הודעת שגיאה

ספק ברירת המחדל הוא DeepSeek. ניתן להשתמש בספק אחר באמצעות SYNONYM_LLM_PROVIDER_ID=anthropic (או כל ספק LLM אחר המוגדר בהגדרות).

שלב 1 - scan:targets

סורק את כל תבניות Angular לאיתור תכונות data-klacksy-target ויוצר את המניפסט Application/Skills/Definitions/navigation-targets.json. כל עוגן חדש מופיע לאחר מכן בכרטיסיית "יעדים" בסטטוס pending.

שלב 2 - generate:synonyms

יוצר עבור כל עוגן חדש נרדפים התחלתיים מתוך data-klacksy-label-key והקטגוריה. הסטטוס לאחר מכן: generated (חייב להיבדק על ידי מנהל מערכת).

הסקריפט כותב נקודות ביקורת (checkpoints) של המניפסט כל 5 יעדים, כך שהפסקה באמצע לא גורמת לאובדן נתונים שכבר נוצרו.

שלב 3 - wake-word-lint

בודק את עקביות גרסת מילת ההפעלה (Hallo Klacksy / Hey Klacksy / ...) בכל השפות. מונע מהנרדפים לדרוס את מילת ההפעלה.

מצב קול (Voice-Mode)

סמל המיקרופון בצ'אט מפעיל את מצב הקול. ברגע שהוא פעיל:

  • המיקרופון מאזין ברציפות ומתמלל באופן רציף
  • בעת שקט קצר → שליחה אוטומטית של התמלול הנוכחי

חשוב: ברגע שאתה מתחיל להקליד בשדה הטקסט, מצב הקול מסתיים אוטומטית — אחרת המיקרופון היה דורס את הטקסט שהקלדת בתמלולים משלו ושולח אותו בטרם עת.

מעגל אימון טיפוסי

  1. הוספת עוגן בתבנית: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. הפעלה מחדש של ה-API (המטמון נטען מחדש עם ההפעלה)
  4. פתיחת כרטיסיית "יעדים" → יעדים חדשים מופיעים בסטטוס generated
  5. בדיקת/השלמת נרדפים → "שמור כמאושר" → סטטוס reviewed
  6. בדיקה עם Klacksy, למשל "Klacksy תראה לי את הכתובות"
  7. אם Klacksy לא מתאים → כרטיסיית "משובים" → השלמת הנרדף החסר
  8. מעקב אחר כרטיסיית "מדדים" עד שהכול במצב reviewed
