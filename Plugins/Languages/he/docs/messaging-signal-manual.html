הגדרת הודעות Signal

דרישות מוקדמות

כדי לשלוח הודעות Signal דרך Klacks, נדרש מופע (instance) מתארח עצמאי (self-hosted) של signal-cli-rest-api. מדובר בפרויקט קוד פתוח שמנגיש את Signal באמצעות ממשק REST.

  • יש להתקין Docker בשרת
  • מספר טלפון שיירשם ב-Signal (מומלץ מספר ייעודי)
  • תמונת Docker (Docker image): bbernhard/signal-cli-rest-api

חשוב: החיבור ל-Signal מיועד לשליחה בלבד. הודעות Signal נכנסות אינן מתקבלות ב-Klacks.

שלב 1 — הגדרת signal-cli-rest-api

  1. הפעילו את הקונטיינר (container) באמצעות Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. קשרו את מספר ה-Signal שלכם באמצעות שיטת קישור קוד QR: פתחו בדפדפן את הכתובת 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    וסרקו את קוד ה-QR המוצג באמצעות אפליקציית Signal בטלפון שבו רשום המספר (הגדרות → מכשירים מקושרים → קישור מכשיר). הקונטיינר ייקשר בכך כמכשיר משני.
  3. לחלופין, ניתן לרשום את המספר באופן עצמאי דרך ה-API — פרטים נוספים ניתן למצוא בתיעוד הפרויקט.
  4. בדקו את ה-API באמצעות בדיקת תקינות (health check): 
    curl http://localhost:8080/v1/about

הערה: פרטים נוספים על התצורה ניתן למצוא ב תיעוד signal-cli-rest-api.

שלב 3 — שליחת הודעות דרך הצ'אטבוט (Klacksy)

לאחר שספק ה-Signal הוגדר והופעל, הצ'אטבוט Klacksy יכול לשלוח הודעות. אין צורך לדעת מספרי טלפון — פשוט השתמשו בשם העובד או הלקוח: 

"שלח הודעה למקס מוסטר: הפגישה שלך מחר בשעה 14:00."
"שלח לאנה בייספיל הודעת Signal: המשמרת הוחלפה."
"הודע לפטר מילר שהתורנות שלו ביום שני מבוטלת."

Klacksy מאתרת אוטומטית את מספר הנייד השמור של הנמען ומשתמשת בספק ה-Signal המוגדר. השליחה שקופה לחלוטין עבורכם — אתם עובדים עם שמות, ו-Klacksy דואגת לשאר.

דרישה: אצל הנמען חייב להיות שמור מספר נייד ב-Klacks (תחת כתובת → פרטי קשר), בפורמט בינלאומי (למשל +41791234567). גם בהודעות שידור (broadcast) השליחה דרך Signal מסתמכת על מספר הנייד השמור.

הודעות נכנסות

החיבור ל-Signal אינו תומך בקבלה — תגובות להודעות שנשלחו אינן מועברות ל-Klacks. לכן תיבת הדואר הנכנס של ההודעות אינה מציגה הודעות נכנסות עבור ספק זה.
