מדריך סקריפטים של מאקרו

מבוא

עורך המאקרו מאפשר לכתוב סקריפטים המשמשים כבסיס חישוב עבור שירותים, פעילויות עבודה וכו'.

דוגמאות שימוש:

  • חישוב מדויק של שעות לחופשה או שירות צבאי לפי דרגת התעסוקה
  • חישוב תוספות לעבודת לילה, סופי שבוע וימי חג
  • התאמה גמישה לדרישות חדשות

הערה: פרשן הסקריפטים רץ בסביבת sandbox מאובטחת ללא גישה למערכת הקבצים או לרשת. לא ניתן להריץ קוד זדוני.

פונקציה וקטגוריה

בנוסף לשם ולתוכן הסקריפט, לכל מאקרו ברשימת המאקרו יש שתי תכונות נוספות הנקבעות באמצעות תפריטים נפתחים בעורך: קטגוריה ופונקציה. שתיהן הן מטא-דאטה בלבד – הן נמצאות מחוץ לסקריפט ואינן משנות את חישובו, אלא קובעות כיצד Klacks מוצא ומשייך אוטומטית את המאקרו המתאים.

קטגוריה

הקטגוריה משייכת מאקרו לתחום יישום מקצועי:

קטגוריהשימוש
לא משויךאין תחום יישום מיוחד (ברירת מחדל למאקרו חדשים)
משמרתחישוב תוספות עבור משמרות רגילות (תוספת לילה, סוף שבוע, חג)
חופשהחישוב שעות לחופשה
מחלהחישוב שעות למחלה
תאונהחישוב שעות לתאונה
סדנה (בתשלום)זמן סדנה/הדרכה בתשלום
סדנה (ללא תשלום)זמן סדנה/הדרכה ללא תשלום

לקטגוריה משמרת יש תפקיד מיוחד: משמרות חדשות שנוצרות מקבלות אוטומטית את מאקרו ברירת המחדל של קטגוריה זו (ראו "פונקציה" למטה). משמרות קיימות לעולם אינן משתנות בדיעבד כתוצאה מכך.

פונקציה: מותאם אישית, ברירת מחדל, ברירת מחדל (מצטבר)

הפונקציה מסווגת את תפקידו של מאקרו בתוך הקטגוריה שלו:

פונקציהמשמעות
מותאם אישיתמאקרו חופשי ללא תפקיד מיוחד. ניתן ליצור כמה שרוצים לכל קטגוריה.
ברירת מחדלמאקרו ברירת המחדל של קטגוריה זו – משויך אוטומטית למשמרות חדשות. לכל היותר מאקרו אחד לכל קטגוריה יכול לשאת פונקציה זו.
ברירת מחדל (מצטבר)מאקרו ברירת מחדל חלופי עם לוגיקת תוספות מצטברת (ראו למטה). גם כאן לכל היותר אחד לכל קטגוריה, בנוסף למאקרו "ברירת מחדל".

חשוב: הפונקציה כשלעצמה אינה מחשבת דבר – היא תווית בלבד. האם התוספות מחושבות לפי "highest-wins" (רק התעריף הגבוה ביותר הישים נספר) או באופן מצטבר (כל התעריפים הישימים מסוכמים) – את זה קובע הסקריפט עצמו. שני מאקרו הקטגוריה "משמרת" המסופקים מראש מדגימים את ההבדל על אותו מבנה בסיסי:

  • "AllShift" (פונקציה: ברירת מחדל) – קובע לכל קטע זמן את התוספת הגבוהה ביותר הישימה (לילה/WE1/WE2/WE3/חג) ומשתמש רק בה.
  • "AllShiftAdditive" (פונקציה: ברירת מחדל (מצטבר)) – מחשב את תוספות הלילה, סוף השבוע והחג בנפרד זה מזה ומסכם אותן.

איזה מבין השניים משויך אוטומטית ביצירת משמרת חדשה, נקבע על ידי הגדרה כלל-מערכתית ("מצטבר" או "התעריף הגבוה ביותר מנצח"). לכל משמרת ניתן לאחר מכן להחליף את המאקרו ידנית בכל עת – כך שאפשרי גם תפעול מעורב.

ייחודיות: אם תנסו לשמור מאקרו שני מאותה קטגוריה גם כן כ"ברירת מחדל" או "ברירת מחדל (מצטבר)", העורך יחסום את השמירה ויציין את שם המאקרו שכבר משויך. הגדירו תחילה את הפונקציה שלו כ"מותאם אישית".

מומלץ להימנע משינויים ידניים ב-"AllShift"/"AllShiftAdditive". שני המאקרו הללו הם המנגנון שדרכו מוחדרות אוטומטית התאמות ספציפיות למדינה ולענף: כל עוד הם נשארים ללא שינוי, Klacks שומר אותם מסונכרנים אוטומטית עם הכללים המתאימים למדינה או לענף שלכם. אם תערכו ידנית אחד מהם, הוא ייחשב מרגע זה כמותאם ללקוח – עדכוני מדינה/ענף אוטומטיים עתידיים למאקרו זה לא ייקלטו יותר בשקט, אלא ייכשלו עם התנגשות עד שתפתרו את החריגה ידנית. אם דרושה לכם לוגיקת תוספות משלכם, צרו במקום זאת מאקרו חדש עם פונקציה "מותאם אישית" ושייכו אותו במפורש למשמרות הרלוונטיות.

פונקציות ופרוצדורות

חשוב: פונקציות (FUNCTION) ופרוצדורות (SUB) חייבות להיות מוגדרות לפני הקריאה הראשונה. הפרשן קורא את הקוד מלמעלה למטה: פונקציה או פרוצדורה ידועה רק אחרי שהגדרתה עובדה.

SUB (פרוצדורה ללא ערך החזרה)

SUB calcular(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (פונקציה עם ערך החזרה)

FUNCTION duplicar(x)
    duplicar = x * 2
ENDFUNCTION

DIM resultado
resultado = duplicar(21)
OUTPUT 1, resultado

החזרת ערכים (OUTPUT)

OUTPUT tipo, valor

tipo ו-valor הם שני ביטויים המופרדים בפסיק; שניהם אופציונליים (ברירת מחדל 0 או "", אם הושמטו). מאקרו יכול להכיל מספר בלתי מוגבל של שורות OUTPUT – כל אחת מייצרת ערך החזרה משלה. Klacks מעריך רק את הסוגים הבאים:

סוגמשמעות
1תוצאה ראשית (שעות או סכום כולל) – נקלטת גם בערך 0
10תוספת לילה
11תוספת עבור יום סוף שבוע 1 (למשל שבת)
12תוספת עבור יום סוף שבוע 2 (למשל ראשון)
13תוספת עבור יום סוף שבוע 3 (יום סוף שבוע שלישי הניתן להגדרה)
14תוספת חג

שורות תוספת (סוג 10-14) עם ערך 0 מתעלמות – כלומר מאקרו אינו חייב להוציא שורה נפרדת לכל סוג תוספת, אלא רק עבור תוספות שאכן חלות. ערכים שלא ניתן לפרש כמספר יידלגו.

בעת השמירה, המאקרו מהודר תמיד ומורץ פעם אחת לניסיון עם ערכי בדיקה נייטרליים. שגיאות תחביר וזמן ריצה (למשל סוגריים לא מאוזנים או ביטוי תלוי) מוצגות באופן אמין במקום להוביל בשקט למאקרו חסר פונקציונליות.

דוגמה: חישוב תוספות ("AllShift")

מאקרו ברירת המחדל המסופק מראש של הקטגוריה "משמרת". מחשב תוספות עבור לילה, חג ושלושת ימי סוף השבוע הניתנים להגדרה, עם טיפול נכון במשמרות שחוצות את חצות (חלוקה לקטעים), ומיישם לכל קטע את התעריף הגבוה ביותר הישים (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

הסבר

  • חלוקה לקטעים: עבור משמרות שחוצות את חצות (למשל, 22:00-06:00), המשמרת מחולקת לשני קטעים (עד חצות / החל מחצות), כל אחד עם דגל יום-בשבוע/חג משלו
  • SegBonusForType: מחשב את התוספת עבור קטע וסוג תוספת מסוים (10-14) תוך התחשבות בתוספות לילה, חג וסוף שבוע
  • WE1/WE2/WE3 במקום שבת/ראשון: weekendday1-3 הופכים את ימי סוף השבוע לניתנים להגדרה (לא בכל מדינה שבת/ראשון הם סוף השבוע)
  • התוספת הגבוהה ביותר לכל קטע: NRate/DRate קובעים בכל פעם את התעריף הגבוה ביותר הישים עבור שעות לילה או שעות יום – highest-wins, ללא צבירה
  • HolidayNextDay: מתחשב בכך שהיום הבא הוא חג (חשוב למשמרות לילה שחוצות את חצות)
  • מספר שורות OUTPUT: שורה 1 מספקת את הסכום הכולל, שורות 10-14 מספקות את סכומי התוספת הבודדים (ראו סעיף "החזרת ערכים")

הגרסה המצטברת ("AllShiftAdditive")

למאקרו ברירת המחדל (המצטבר) של אותה קטגוריה יש שורות IMPORT זהות ואותו מבנה מסגרת – רק SegBonusForType שונה: במקום התעריף הגבוה ביותר, מחושב עבור כל סוג תוספת בנפרד האם הוא חל, וכל הסכומים הרלוונטיים מסוכמים בסוף (אין עוד highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

אם משמרת לילה חלה למשל גם ביום חג, ב-"AllShift" היא מקבלת רק את התעריף הגבוה מבין השניים, ואילו ב-"AllShiftAdditive" היא מקבלת תוספת לילה וגם תוספת חג יחד. שאר הסקריפט (חלוקה לקטעים, סיכום, שורות OUTPUT) זהה ל-"AllShift" למעלה.
