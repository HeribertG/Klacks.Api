הגדרת WhatsApp

דרישות מוקדמות

כדי לשלוח ולקבל הודעות דרך WhatsApp באמצעות Klacks, דרושים לכם חשבון מפתחים של Meta ואפליקציית Meta שבה מוצר ה-WhatsApp מופעל. Klacks משתמשת ב-WhatsApp Cloud API של פלטפורמת Meta לעסקים לצורך השליחה וב-Webhooks של Meta לצורך הקבלה.

הערה: ההגדרה והבדיקה אינן כרוכות בעלות. בעת יצירת האפליקציה Meta מספקת אוטומטית מספר טלפון לבדיקה ללא תשלום.

חשוב — מספר השולח אינו המספר הפרטי שלכם. מספר טלפון שכבר נמצא בשימוש באפליקציית WhatsApp הרגילה אינו יכול להירשם ל-Cloud API, ומספר שנרשם אינו ניתן עוד לשימוש עם WhatsApp Messenger. לכן השתמשו במספר הבדיקה ש-Meta מספקת או במספר משלכם המשמש לצרכים עסקיים בלבד. ה-WhatsApp הפרטי שבטלפון הנייד שלכם משמש כנמען לצורך בדיקה — ולא כשולח.

שלב 1 — יצירת אפליקציית Meta

  1. פתחו את developers.facebook.com/apps ולחצו על Create app.
  2. בחרו כמקרה השימוש Other וכסוג האפליקציה Business.
  3. בלוח הבקרה לחצו אצל המוצר WhatsApp על Set up. בכך נוצר ונרשם אוטומטית מספר טלפון לבדיקה.
  4. עברו בסרגל הניווט השמאלי אל WhatsApp → API Setup.
  5. רשמו לעצמכם את Phone number ID וצרו אסימון גישה באמצעות Generate access token.
  6. רשמו לעצמכם תחת App settings → Basic את ה-App Secret — הוא נדרש לבדיקת החתימה של הודעות נכנסות.

שימו לב — שני מזהים דומים: בלוח ה-API Setup מופיעים Phone number ID ו-WhatsApp Business Account ID זה מתחת לזה. Klacks זקוקה ל-Phone number ID. עם המזהה השגוי בדיקת החיבור עדיין תדווח על הצלחה, אך כל שליחה תיכשל.

שימו לב — תוקף הטוקן: הטוקן שנוצר באמצעות Generate access token הוא טוקן בדיקה זמני והוא פג לאחר זמן קצר. להפעלה שוטפת צרו ב-Meta Business Manager טוקן קבוע באמצעות משתמש מערכת.

שלב 2 — אישור מספר הנמען

מספר הבדיקה רשאי לשלוח רק לנמענים שאושרו מראש. הוסיפו בלוח API Setup תחת To → Manage phone number list את מספר ה-WhatsApp שלכם. Meta שולחת קוד אימות למספר זה, ועליכם להזין אותו.

בלי שלב זה Meta דוחה כל שליחה למספר הזה. ברגע שתשתמשו בהמשך במספר עסקי מאומת משלכם, האישור אינו נדרש עוד.

שלב 4 — חלון 24 השעות

WhatsApp שונה כאן מהותית מ-Telegram או Slack. הודעות טקסט חופשיות מותר לעסק לשלוח רק כל עוד חלון שירות הלקוחות פתוח. את החלון הזה פותח הנמען, בכך שהוא כותב אל מספר ה-WhatsApp שלכם. החלון נשאר פתוח 24 שעות ומתארך עם כל הודעה נוספת של הנמען.

מחוץ לחלון זה Meta מתירה אך ורק תבניות הודעה שאושרו מראש. Klacks שולחת כרגע אך ורק הודעות טקסט חופשיות, ולכן היא אינה יכולה לפתוח שיחה ביוזמתה.

מה זה אומר עבורכם: בקשו מהעובדים שלכם לשלוח פעם אחת הודעה למספר ה-WhatsApp של Klacks. לאחר מכן השליחה אפשרית במשך 24 שעות, וכל תשובה מאריכה את החלון. אם החלון סגור, השליחה מדווחת על שגיאה — זו אינה בעיית הגדרה אלא כלל של WhatsApp.

אם עליכם להגיע לעובדים ללא תלות בחלון זה, Telegram או Signal הם הספקים המתאימים יותר — שם אין מגבלה זו.

שלב 5 — שליחת הודעות דרך הצ'אטבוט (Klacksy)

לאחר שספק ה-WhatsApp הוגדר והופעל, הצ'אטבוט Klacksy יכול לשלוח הודעות דרך WhatsApp. השתמשו בשם העובד: 

"שלח הודעה למקס מוסטר: הפגישה שלך מחר בשעה 14:00."
"שלח לאנה בייספיל הודעה: המשמרת הוחלפה."

כנמען משמש מספר הטלפון בפורמט בינלאומי ללא אפס מוביל וללא סימן פלוס (לדוגמה 41791234567 עבור 079 123 45 67). השליחה שקופה לחלוטין עבורכם — אתם עובדים עם שמות, ו-Klacksy דואג לשאר.

תנאי מוקדם: מספר ה-WhatsApp חייב להיות מקושר לאיש הקשר המתאים ב-Klacks (תחת כתובת → פרטי קשר), וחלון 24 השעות משלב 4 חייב להיות פתוח.

שלב 6 — קבלת הודעות נכנסות (Webhooks)

כדי להציג הודעות WhatsApp נכנסות ב-Klacks, יש להגדיר את ה-Webhook של אפליקציית ה-Meta. שמרו והפעילו את הספק ב-Klacks לפני שתזינו את כתובת ה-Callback — Meta בודקת את הכתובת מיד באמצעות בקשת אימות, ש-Klacks עונה עליה אוטומטית על סמך ה-Verify-Token.

  1. פתחו את אפליקציית ה-Meta שלכם ונווטו אל WhatsApp → Configuration.
  2. לחצו ליד Webhook על Edit והזינו:
    • Callback URL: כתובת ה-Webhook המוצגת ב-Klacks 
      https://{הדומיין-שלכם}/api/messaging/webhook/whatsapp
    • Verify token: בדיוק אותו ערך שהזנתם בשלב 3 בשדה Verify-Token
  3. לחצו על Verify and save.
  4. הירשמו תחת Webhook fields לשדה messages.
  5. הודעות נכנסות יופיעו כעת בזמן אמת בתיבת ההודעות הנכנסות. בד בבד Klacks בודקת את החתימה של כל בקשה (X-Hub-Signature-256) מול ה-App-Secret השמור.

כתובת ה-Callback חייבת להיות נגישה מבחוץ דרך HTTPS. בהתקנה ברשת הפנימית של החברה ללא כתובת ציבורית השליחה עובדת, אך לא ניתן לקבל הודעות.
