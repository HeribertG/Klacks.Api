הגדרת Slack

דרישות מוקדמות

כדי לשלוח ולקבל הודעות דרך Slack באמצעות Klacks, דרושים לכם workspace ב-Slack ואפליקציית Slack עם ההרשאות המתאימות. Klacks משתמשת ב-Slack Web API לצורך השליחה וב-Events API לצורך הקבלה.

הערה: התוכנית החינמית של Slack מספיקה לחיבור זה. אפליקציות Slack נוצרות באתר api.slack.com וללא עלות.

שלב 1 — יצירת אפליקציית Slack

  1. פתחו את api.slack.com/apps ולחצו על Create New App.
  2. בחרו From scratch והזינו שם (לדוגמה Klacks Bot).
  3. בחרו את ה-workspace שבו תותקן האפליקציה.
  4. נווטו אל OAuth & Permissions והוסיפו את Bot Token Scopes הבאים:
    • chat:write — לשליחת הודעות לערוצים
    • im:write — לשליחת הודעות ישירות למשתמשים
  5. לחצו על Install to Workspace ואשרו את ההרשאות.
  6. רשמו לעצמכם את Bot User OAuth Token (מתחיל ב-xoxb-).
  7. נווטו אל Basic Information ורשמו לעצמכם את Signing Secret.

  2. לחצו על הוספה.
  3. מלאו את השדות כך:

שלב 3 — שליחת הודעות דרך הצ'אטבוט (Klacksy)

לאחר שספק ה-Slack הוגדר והופעל, הצ'אטבוט Klacksy יכול לשלוח הודעות דרך Slack. השתמשו בשם העובד או בשם ערוץ: 

"שלח הודעה למקס מוסטר: הפגישה שלך מחר בשעה 14:00."
"שלח לאנה בייספיל הודעה: המשמרת הוחלפה."
"פרסם ב-#team-updates: לוחות העבודה לשבוע הבא מוכנים."

כנמען משמש Channel ID (לדוגמה C0123456789) או User ID (לדוגמה U0123456789) — עבור User ID תישלח הודעה ישירה. אם לא צוין נמען, ייעשה שימוש בערוץ ברירת המחדל המוגדר. השליחה שקופה לחלוטין עבורכם — אתם עובדים עם שמות, ו-Klacksy דואג לשאר.

תנאי מוקדם: משתמש ה-Slack חייב להיות מקושר לאיש הקשר המתאים ב-Klacks (תחת כתובת → פרטי קשר). לצורך הודעות בערוץ, על הבוט להיות מוזמן לערוץ הרלוונטי (/invite @Klacks Bot).

שלב 4 — קבלת הודעות נכנסות (Events API)

כדי להציג הודעות Slack נכנסות ב-Klacks, יש להגדיר את ה-Events API של אפליקציית ה-Slack. שמרו והפעילו את הספק ב-Klacks לפני שתזינו את ה-Request URL — Slack בודקת את הכתובת מיד באמצעות בקשת challenge, ש- Klacks עונה עליה אוטומטית.

  1. פתחו את אפליקציית ה-Slack שלכם באתר api.slack.com/apps ונווטו אל Event Subscriptions.
  2. הפעילו את Enable Events והזינו כ-Request URL את כתובת ה-Webhook המוצגת ב-Klacks: 
    https://{ihre-domain}/api/messaging/webhook/slack
  3. הירשמו תחת Subscribe to bot events לאירועים message.im (הודעות ישירות) ו-message.channels (הודעות ערוץ).
  4. שמרו את השינויים והתקינו את האפליקציה מחדש ב-workspace כשתתבקשו לכך.
  5. הודעות נכנסות יופיעו כעת בזמן אמת בתיבת ההודעות הנכנסות. בד בבד Klacks בודקת את החתימה של כל בקשה מול ה-Signing-Secret השמור.
