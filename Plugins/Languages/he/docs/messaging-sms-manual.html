הגדרת ספק SMS

דרישות מוקדמות

כדי לשלוח הודעות SMS דרך Klacks, נדרש חשבון אצל Twilio או שער SMS תואם-Twilio אחר. Klacks משתמשת ב- Twilio REST API (נקודת קצה Messages עם אימות Basic).

חשוב: חיבור ה-SMS מיועד לשליחה בלבד. הודעות SMS נכנסות אינן מתקבלות ב-Klacks.

שלב 1 — הקמת חשבון Twilio

  1. הירשמו באתר twilio.com ואמתו את מספר הטלפון וכתובת הדוא"ל שלכם.
  2. פתחו את Twilio Console. בלוח הבקרה תמצאו תחת Account Info את שני פרטי הגישה הנדרשים:
    • Account SID — מתחיל ב-AC
    • Auth Token — לחצו על "Anzeigen" (הצג)
  3. רכשו מספר שולח תחת Phone Numbers → Buy a number (עם תמיכה ב-SMS). מספר זה יופיע כשולח בהודעות SMS יוצאות.
  4. חשבונות ניסיון: עם חשבון Trial חינמי ניתן לשלוח הודעות SMS רק למספרים שאומתו מראש, וההודעות יכללו הערת ניסיון.

הערה: התייחסו ל-Auth Token כאל סיסמה. אל תשתפו אותו בפומבי ושמרו אותו במקום מאובטח.

שלב 2 — הגדרת ספק ה-SMS ב-Klacks

  1. נווטו אל הגדרות → ספקי הודעות.
  2. לחצו על הוספה.
  3. מלאו את השדות באופן הבא:

שלב 3 — שליחת הודעות דרך הצ'אטבוט (Klacksy)

לאחר שספק ה-SMS הוגדר והופעל, הצ'אטבוט Klacksy יכול לשלוח הודעות. אין צורך לדעת מספרי טלפון — פשוט השתמשו בשם העובד או הלקוח: 

"שלח הודעת SMS למקס מוסטר: הפגישה שלך מחר בשעה 14:00."
"שלח הודעת SMS לאנה בייספיל: המשמרת הוחלפה."
"הודע לפטר מילר באמצעות SMS שהתורנות שלו ביום שני מבוטלת."

Klacksy מאתרת אוטומטית את מספר הנייד השמור של הנמען ומשתמשת בספק ה-SMS המוגדר. השליחה שקופה לחלוטין עבורכם — אתם עובדים עם שמות, ו-Klacksy דואגת לשאר.

דרישה: אצל הנמען חייב להיות שמור מספר נייד ב-Klacks (תחת כתובת → פרטי קשר), בפורמט בינלאומי (למשל +41791234567).

הודעות נכנסות

חיבור ה-SMS אינו תומך בקבלה — תגובות להודעות SMS שנשלחו אינן מועברות ל-Klacks. תיבת הדואר הנכנס של ההודעות אינה מציגה אפוא הודעות נכנסות עבור ספק זה.
