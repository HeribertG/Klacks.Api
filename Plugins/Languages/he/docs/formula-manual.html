מדריך שדה נוסחה

תחביר בסיסי

כל שדה נוסחה מוציא את התוצאה באמצעות הפקודה output:

output 1, <ביטוי>

הפרמטר הראשון 1 הוא סוג ההודעה וחייב תמיד להיות 1. הפרמטר השני הוא הערך שיש להוציא.

דוגמאות פשוטות:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " רשומות"

משתנים זמינים

המשתנים הזמינים רשומים בכרטיסייה משתנים וניתן להקצות להם שם ערכי בדיקה. בהתאם לסוג הדוח, זמינים משתנים שונים:

סוג דוחשורת סיכום טבלה
תוכנית עבודהtotalRows, totalHours, totalSurcharges, totalWorkDays
היעדרויותtotalRows, totalValue
כתובותtotalRows
קבוצותtotalRows

אופרטורים

אופרטורתיאורדוגמה
+חיבורtotalHours + 2
-חיסורtotalRows - 1
*כפלtotalValue * 1.5
/חילוקtotalHours / 8
^חזקה2 ^ 10
\חילוק שלם10 \ 3 → 3
MODמודולו (שארית)10 MOD 3 → 1
&שרשור טקסט"סה״כ: " & totalRows

פונקציות מובנות

המרת סוגים

פונקציהתיאור
CStr(x)המרת מספר לטקסט
CInt(x)המרה למספר שלם
CDbl(x)המרה למספר עשרוני

מתמטיקה

פונקציהתיאור
Abs(x)ערך מוחלט
Round(x, n)עיגול ל-n ספרות עשרוניות
Int(x)עיגול כלפי מטה למספר שלם
Sqr(x)שורש ריבועי
Sgn(x)סימן (‎-1, 0, 1)

טקסט

פונקציהתיאור
Len(s)אורך הטקסט
Left(s, n)n תווים מהצד השמאלי
Right(s, n)n תווים מהצד הימני
Mid(s, pos, n)n תווים החל מהמיקום pos
UCase(s)המרה לאותיות גדולות
LCase(s)המרה לאותיות קטנות
Trim(s)הסרת רווחים בקצוות
Replace(s, alt, neu)החלפת טקסט

לוגיקה מותנית

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "הרבה רשומות"
ELSEIF totalRows > 0 THEN
    output 1, "מעט רשומות"
ELSE
    output 1, "אין רשומות"
ENDIF

IF בשורה אחת

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (צורה מקוצרת)

output 1, IIF(totalRows > 0, "OK", "ריק")

משתנים ולולאות

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

דוגמאות מעשיות

מספר רשומות עם טקסט

output 1, CStr(totalRows) & " רשומות"

ערך מעוגל (ספרה אחת)

output 1, CStr(Round(totalValue, 1))

שעות בפורמט h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

פלט מותנה

IF totalRows = 0 THEN
    output 1, "אין היעדרויות"
ELSE
    output 1, CStr(totalRows) & " היעדרויות (סה״כ: " & CStr(totalValue) & ")"
ENDIF

חישוב ממוצע

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " שעות/יום"
ELSE
    output 1, "-"
ENDIF
