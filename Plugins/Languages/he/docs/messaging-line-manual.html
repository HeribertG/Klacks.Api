הגדרת הודעות LINE

דרישות מוקדמות

כדי לשלוח ולקבל הודעות דרך LINE, נדרש לכם חשבון LINE Official Account עם ערוץ Messaging API ב-LINE Developers Console. LINE פופולרי במיוחד ביפן, בטייוואן ובתאילנד.

הערה: להודעות Push יש מכסה חודשית בהתאם לתוכנית ה-LINE שלכם (התוכנית החינמית מוגבלת). בדקו את התנאים העדכניים של תוכנית ה-Official Account שלכם.

שלב 1 — יצירת חשבון LINE Official Account וערוץ Messaging API

  1. צרו חשבון LINE Official Account (דרך LINE Official Account Manager).
  2. פתחו את LINE Developers Console (developers.line.biz) ו צרו ערוץ Messaging API או שייכו את חשבון ה-Official Account שלכם ל-Messaging API.
  3. בלשונית Messaging API הנפיקו Channel Access Token ארוך טווח (Issue).
  4. רשמו לעצמכם את Channel Secret מהלשונית Basic Settings.

הערה: התייחסו ל-Channel Access Token ול-Channel Secret כאל סיסמאות. אל תשתפו אותם בפומבי ושמרו אותם במקום מאובטח.

שלב 3 — שליחת הודעות דרך הצ'אטבוט (Klacksy)

לאחר שספק ה-LINE הוגדר והופעל, הצ'אטבוט Klacksy יכול לשלוח הודעות. אינכם צריכים לדעת מזהי משתמש של LINE — פשוט השתמשו בשם העובד או הלקוח: 

"שלח הודעה למקס מוסטר: הפגישה שלך מחר בשעה 14:00."
"שלח לאנה בייספיל הודעה: המשמרת הוחלפה."
"הודע לפטר מילר שהתורנות שלו ביום שני מבוטלת."

Klacksy מאתר אוטומטית את מזהה משתמש ה-LINE השמור של הנמען ומשתמש בספק ה-LINE המוגדר. תהליך השליחה שקוף לחלוטין עבורכם — אתם עובדים עם שמות, ו-Klacksy דואג לשאר.

דרישה: אצל הנמען חייב להיות שמור מזהה משתמש LINE (מתחיל ב-U…) ב-Klacks (תחת כתובת → פרטי קשר). מזהה המשתמש נודע דרך הודעה נכנסת (גלוי בתיבת הדואר הנכנס של ההודעות) — לשם כך על הנמען להוסיף את חשבון ה-Official Account שלכם כחבר ולשלוח לו הודעה.

שלב 4 — קבלת הודעות נכנסות (Webhook)

כדי להציג הודעות LINE נכנסות ב-Klacks, יש להזין את כתובת ה-Webhook ידנית ב-LINE Developers Console.

  1. העתיקו את כתובת ה-Webhook המוצגת ב-Klacks מתוך הגדרות הספק: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. הזינו כתובת זו ב-LINE Developers Console תחת Messaging API → Webhook settings כ- Webhook URL.
  3. הפעילו את האפשרות „Use webhook".
  4. ודאו שמופע ה-Klacks שלכם נגיש באופן ציבורי דרך HTTPS.
  5. הודעות נכנסות יופיעו כעת בזמן אמת בתיבת הדואר הנכנס של ההודעות.

פתרון בעיות

בעיהסיבה אפשריתפתרון
בדיקת החיבור נכשלת Channel Access Token לא תקין הנפיקו אסימון חדש ב-LINE Developers Console
ההודעה לא נמסרת הנמען לא הוסיף את חשבון ה-Official Account כחבר, או חסם אותו על הנמען להוסיף את החשבון כחבר ב-LINE
השליחה נכשלת המכסה החודשית של הודעות Push מוצתה בדקו את המכסה של התוכנית שלכם ב-LINE Official Account Manager
הנמען לא נמצא מזהה משתמש LINE אינו שמור הזינו את מזהה המשתמש מתיבת הדואר הנכנס תחת כתובת → פרטי קשר
הודעות נכנסות חסרות כתובת ה-Webhook לא הוזנה, או שהאפשרות „Use webhook" מבוטלת בדקו את הגדרות ה-Webhook ב-LINE Developers Console
