חיפוש ספקי LLM — הוראות שימוש

מה מטרת הפונקציה הזו?

תצוגה זו מציעה לך ספקי LLM שעדיין אינם ברשימתך, ומוסיפה את הספקים שנבחרו בלחיצה אחת. כך אינך צריך להזין את השם וכתובת ה-URL הבסיסית באופן ידני. מוצעים אך ורק ספקי API תואמי OpenAI — כלומר בדיוק אותו סוג שירותים שבו משתמשים גם הספקים שכבר הגדרת אצלך.

עמודות הטבלה

שם הספק

שם התצוגה של הספק (לדוגמה, "OpenRouter", "‎xAI (Grok)‎").

כתובת URL בסיסית

כתובת ה-API שדרכה מתקיימת התקשורת עם הספק (לדוגמה, https://api.x.ai/v1/). כתובת זו בדיוק תשמש בהמשך בעת היצירה.

מקור

מציין מהיכן מגיעה ההצעה:

  • קטלוג — מרשימה קבועה ומאומתת מראש של ספקים ידועים. כתובות ה-URL הבסיסיות מאומתות ולכן אמינות.
  • אינטרנט — נמצא באמצעות חיפוש באינטרנט ונותח אוטומטית. רשומות אלה מופיעות רק אם חיפוש האינטרנט מוגדר בהגדרות. הן מועילות, אך במקרה של ספק כדאי לבדוק בקצרה את כתובת ה-URL הבסיסית.

זמינות

לפני ההצגה, כל הצעה נבדקת בזמן אמת (קריאה לנקודת הקצה /models):

  • זמין — ה-API מגיב, הספק פועל.
  • זמין (נדרש מפתח) — ה-API קיים, אך דורש מפתח API. כלומר הכתובת נכונה.
  • לא זמין — הכתובת אינה מגיבה. רשומות מסוג זה אינן ניתנות לבחירה.

הוספת ספק

סמן ספק אחד או יותר ולחץ למטה על "הוסף את הנבחרים". הספקים שנבחרו ייווצרו במצב מושבת וללא מפתח API. ספקים שכבר קיימים כלל לא יוצעו.

הצעדים הבאים לאחר ההוספה

ספק שהתווסף זה עתה עדיין אינו פעיל. פתח אותו ברשימה, הזן את מפתח ה-API והפעל אותו. לאחר מכן הוא יפעל בדיוק כמו שאר הספקים שלך. את הדגמים (models) הבודדים של ספק ממשיכים לנהל בנפרד דרך ניהול הדגמים.
