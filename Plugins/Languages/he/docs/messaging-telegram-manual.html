הגדרת בוט Telegram

דרישות מוקדמות

כדי לשלוח ולקבל הודעות Telegram דרך Klacks, נדרש בוט Telegram. בוטים נוצרים דרך BotFather הרשמי, וללא עלות.

שלב 1 — יצירת בוט Telegram

  1. פתחו את Telegram וחפשו את @BotFather.
  2. התחילו שיחה עם ה-BotFather ושלחו את הפקודה /newbot.
  3. הזינו שם לבוט שלכם (למשל Klacks Benachrichtigungen).
  4. הזינו שם משתמש לבוט (חייב להסתיים ב-bot, למשל klacks_notify_bot).
  5. ה-BotFather יספק לכם Bot Token. העתיקו אסימון זה — הוא יידרש בשלב הבא.

הערה: התייחסו ל-Bot Token כאל סיסמה. אל תשתפו אותו בפומבי ושמרו אותו במקום מאובטח.

שלב 2 — הגדרת הבוט ב-Klacks

  1. נווטו אל הגדרות → ספקי הודעות.
  2. לחצו על הוספה.
  3. מלאו את השדות באופן הבא:

  2. בדקו את החיבור באמצעות כפתור בדיקה ברשימת הספקים.

שלב 3 — שליחת הודעות דרך הצ'אטבוט (Klacksy)

לאחר שבוט ה-Telegram הוגדר והופעל, הצ'אטבוט Klacksy יכול לשלוח הודעות. אין צורך לדעת מזהי צ'אט — פשוט השתמשו בשם העובד או הלקוח: 

"שלח הודעה למקס מוסטר: הפגישה שלך מחר בשעה 14:00."
"שלח לאנה בייספיל הודעה: המשמרת הוחלפה."
"הודע לפטר מילר שהתורנות שלו ביום שני מבוטלת."

Klacksy מאתרת אוטומטית את שם המשתמש השמור של הנמען ב-Telegram ומשתמשת בבוט המוגדר. השליחה שקופה לחלוטין עבורכם — אתם עובדים עם שמות, ו-Klacksy דואגת לשאר.

דרישה: אצל הנמען חייב להיות שמור שם משתמש Telegram ב-Klacks (תחת כתובת → פרטי קשר).

שלב 4 — קבלת הודעות נכנסות (Webhook)

כדי להציג הודעות Telegram נכנסות ב-Klacks, יש להגדיר Webhook.

  1. ודאו שמופע ה-Klacks שלכם נגיש באופן ציבורי דרך HTTPS.
  2. הזינו את כתובת ה-Webhook הבאה בהגדרות הספק: 
    https://{ihre-domain}/api/messaging/webhook/telegram
  3. Klacks תרשום את ה-Webhook אוטומטית ב-Telegram ברגע שהספק נשמר ומופעל.
  4. הודעות נכנסות יופיעו כעת בזמן אמת ב-תיבת הדואר הנכנס של ההודעות.
