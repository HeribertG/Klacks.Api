Menyediakan Threema Gateway

Prasyarat

Untuk menghantar mesej melalui Threema, anda memerlukan akaun di Threema Gateway. Threema ialah penyedia perkhidmatan dari Switzerland, digunakan secara meluas di Switzerland dan mesra privasi (DSG Switzerland).

Penting: Sambungan Threema direka hanya untuk penghantaran. Penerimaan mesej masuk memerlukan mod hujung-ke-hujung (end-to-end) gateway dan tidak disokong. Penghantaran dikenakan bayaran — setiap mesej yang dihantar menggunakan Kredit.

Langkah 1 — Membuat Akaun Threema Gateway

  1. Daftar di gateway.threema.ch.
  2. Mohon Gateway-ID dalam Mod Asas (Basic) (cth. *MYGATEWAY). ID ini sentiasa bermula dengan tanda bintang (*) dan mesti diluluskan oleh Threema.
  3. Beli Kredit — tanpa baki, mesej tidak dapat dihantar.
  4. Catatkan API-Secret daripada papan pemuka Gateway.

Nota: Layan API-Secret seperti kata laluan. Jangan kongsikannya secara terbuka dan simpan dengan selamat.

Langkah 2 — Mengkonfigurasi Threema dalam Klacks

  1. Navigasi ke Tetapan → Penyedia Pemesejan.
  2. Klik pada Tambah.

  2. Uji sambungan menggunakan butang Uji dalam senarai penyedia. Ujian ini menyemak kelayakan akses melalui pertanyaan kredit gateway.

Langkah 3 — Menghantar Mesej melalui Chatbot (Klacksy)

Sebaik sahaja penyedia Threema dikonfigurasi dan diaktifkan, chatbot Klacksy boleh menghantar mesej. Anda tidak perlu mengetahui ID Threema — cukup gunakan nama pekerja atau klien: 

"Hantar mesej kepada Max Muster: Temujanji anda esok pada jam 14:00."
"Hantar mesej kepada Anna Beispiel: Syif telah ditukar."
"Maklumkan Peter Müller bahawa tugasnya pada hari Isnin dibatalkan."

Klacksy secara automatik mencari ID Threema penerima yang telah disimpan dan menggunakan penyedia Threema yang dikonfigurasi. Penghantaran adalah sepenuhnya telus untuk anda — anda bekerja dengan nama, Klacksy menguruskan selebihnya.

Prasyarat: Penerima mesti mempunyai ID Threema 8 digit disimpan dalam Klacks (di bawah Alamat → Butiran Hubungan). Pekerja boleh menemui ID Threema dalam aplikasi Threema mereka di bawah „Profil Saya".

Mesej Masuk

Sambungan Threema tidak menyokong penerimaan — balasan kepada mesej yang dihantar tidak dipindahkan ke Klacks. Penerimaan memerlukan mod hujung-ke-hujung Threema Gateway; sambungan Klacks menggunakan Mod Asas. Oleh itu, peti masuk pemesejan tidak memaparkan sebarang mesej masuk untuk penyedia ini.
