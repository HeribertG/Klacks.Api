Manual Medan Formula

Sintaks Asas

Setiap medan formula mengeluarkan hasil dengan arahan output:

output 1, <Ungkapan>

Parameter pertama 1 ialah jenis mesej dan mesti sentiasa 1. Parameter kedua ialah nilai yang hendak dikeluarkan.

Contoh mudah:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " Entri"

Pemboleh Ubah Tersedia

Pemboleh ubah yang tersedia disenaraikan dalam tab Pemboleh Ubah dan boleh diberikan nilai ujian di sana. Bergantung pada jenis laporan, pemboleh ubah yang berbeza akan tersedia:

Fungsi Terbina Dalam

Penukaran Jenis

CDbl(x)Menukar kepada nombor perpuluhan

Matematik

FungsiPenerangan

Sgn(x)Tanda (-1, 0, 1)

Logik Bersyarat

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "banyak entri"
ELSEIF totalRows > 0 THEN
    output 1, "sedikit entri"
ELSE
    output 1, "tiada entri"
ENDIF

IF Satu Baris

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (Bentuk Ringkas)

output 1, IIF(totalRows > 0, "OK", "Kosong")

Pemboleh Ubah dan Gelung

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Contoh Praktikal

Bilangan Entri dengan Teks

output 1, CStr(totalRows) & " Entri"

Nilai Dibundarkan (1 Tempat Perpuluhan)

output 1, CStr(Round(totalValue, 1))

Jam sebagai h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Output Bersyarat

IF totalRows = 0 THEN
    output 1, "Tiada Ketidakhadiran"
ELSE
    output 1, CStr(totalRows) & " Ketidakhadiran (Jumlah: " & CStr(totalValue) & ")"
ENDIF

Mengira Purata

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/hari"
ELSE
    output 1, "-"
ENDIF
