Latihan Klacksy - Panduan

Apakah Alat Latihan Ini?

Alat Latihan mengawal navigasi dalam halaman bagi chatbot Klacksy. Apabila seorang pengguna menyebut atau menaip "Klacksy tunjukkan saya alamat", Klacksy akan menavigasi ke halaman yang sesuai dan menatal ke bahagian yang berkaitan.

Supaya ini berfungsi, Klacksy memerlukan senarai sinonim dalam setiap bahasa untuk setiap sauh pada sesuatu halaman (contohnya "Adressen", "Kunden", "Kontakte" untuk sasaran addresses).

Tab "Sasaran"

Senarai semua sauh yang ditemui dalam frontend (atribut HTML data-klacksy-target). Penapis Status:

  • pending: Sauh wujud, tetapi belum ada sinonim
  • generated: Sinonim telah dijana secara automatik, perlu disemak
  • reviewed: Sinonim telah diluluskan oleh pentadbir
  • needs-review: Ditandakan untuk semakan semula

Mengklik satu sasaran akan membuka editor sinonim di bawahnya. Di situ, sinonim boleh ditambah, dipadam dan diluluskan dengan butang "Simpan sebagai Disemak".

Tab "Maklum Balas"

Memaparkan input pengguna yang tidak dapat dipadankan oleh Klacksy (tiada sinonim yang sesuai ditemui). Berdasarkan senarai ini, dapat dikenal pasti sinonim mana yang masih tiada.

Tab "Metrik"

Gambaran keseluruhan semua sasaran mengikut status. Membantu untuk memantau kemajuan latihan.

Saluran Binaan (CLI)

Apabila templat mempunyai sauh data-klacksy-target yang baharu, manifes dan sinonim awal perlu dijana semula. Arahan-arahan berikut juga dijalankan secara automatik dalam CI dan dalam Husky pre-commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Templates scannen → navigation-targets.json mit allen Anchors
npm run scan:targets

# 2a. Initial-Synonyme generieren (alle 4 Core + 22 Plugin-Locales, ~2.5 h)
npm run generate:synonyms

# 2b. Nur Core-Locales (de/en/fr/it) — schnell, ca. 9 min
npm run generate:synonyms -- --core-only

# 2c. Nur fehlende Plugin-Locales nachfuellen — ca. 45 min
npm run generate:synonyms -- --plugins-only

# 3. Wake-Word-Konsistenz pruefen
npm run wake-word-lint

Penting: Untuk npm run, -- mesti dinyatakan supaya pilihan diteruskan kepada skrip. Tanpa --, npm akan menelan bendera tersebut dan skrip akan berjalan dalam mod lalai.

Alternatif tanpa npm: npx tsx tools/generate-synonyms.ts --core-only.

Kunci API

Kunci API LLM dicari mengikut turutan berikut:

  1. Pembolehubah persekitaran SYNONYM_LLM_API_KEY
  2. Jadual pangkalan data llm_providers (Penyedia deepseek, is_enabled = true) — secara automatik melalui panggilan psql
  3. Jika tidak, mesej ralat

Penyedia lalai ialah DeepSeek. Penyedia lain boleh digunakan melalui SYNONYM_LLM_PROVIDER_ID=anthropic (atau penyedia LLM lain yang telah disediakan dalam Tetapan).

Langkah 1 - scan:targets

Mengimbas semua templat Angular untuk atribut data-klacksy-target dan menjana manifes Application/Skills/Definitions/navigation-targets.json. Setiap sauh baharu akan muncul selepas itu dalam tab "Sasaran" dengan status pending.

Langkah 2 - generate:synonyms

Menjana sinonim awal untuk setiap sauh baharu daripada data-klacksy-label-key dan kategorinya. Status selepas itu: generated (perlu disemak oleh pentadbir).

Skrip ini menulis pusat semakan manifes setiap 5 sasaran, supaya sekiranya proses terhenti, data yang telah dijana tidak akan hilang.

Langkah 3 - wake-word-lint

Menyemak konsistensi varian kata pengaktif (Hallo Klacksy / Hey Klacksy / ...) merentasi semua bahasa. Mengelakkan sinonim daripada menggantikan kata pengaktif.

Mod Suara

Ikon mikrofon dalam chat mengaktifkan Mod Suara. Sebaik sahaja aktif:

  • Mikrofon mendengar secara berterusan dan mentranskrip secara berterusan
  • Apabila senyap sebentar → transkripsi setakat itu dihantar secara automatik

Penting: Sebaik sahaja anda mula menaip dalam medan teks, Mod Suara akan ditamatkan secara automatik — jika tidak, mikrofon akan menggantikan teks yang anda taip dengan transkripsinya sendiri dan menghantarnya sebelum sepatutnya.

Kitaran Latihan Biasa

  1. Tambah sauh dalam templat: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Mulakan semula API (cache akan dibaca semula semasa permulaan)
  4. Buka tab "Sasaran" → sasaran baharu muncul dengan status generated
  5. Semak/tambah sinonim → "Simpan sebagai Disemak" → status reviewed
  6. Uji dengan Klacksy, contohnya "Klacksy tunjukkan saya alamat"
  7. Jika Klacksy tidak dapat memadankan → tab "Maklum Balas" → tambah sinonim yang tiada
  8. Pantau tab "Metrik" sehingga semuanya berstatus reviewed
