Mencari Penyedia LLM — Panduan

Untuk apakah fungsi ini?

Paparan ini mencadangkan penyedia LLM yang belum terdapat dalam senarai anda, dan menambah pilihan yang dipilih dengan satu klik. Dengan ini anda tidak perlu memasukkan nama dan URL asas secara manual. Hanya penyedia API serasi OpenAI yang dicadangkan — iaitu jenis perkhidmatan yang sama seperti yang digunakan oleh penyedia yang telah anda sediakan.

Lajur dalam jadual

Nama Penyedia

Nama paparan penyedia (contohnya „OpenRouter", „xAI (Grok)").

URL Asas

Alamat API yang digunakan untuk berkomunikasi dengan penyedia (contohnya https://api.x.ai/v1/). URL inilah yang akan digunakan kemudian semasa penciptaan.

Sumber

Menunjukkan dari mana cadangan ini berasal:

  • Katalog — daripada senarai tetap yang telah disemak bagi penyedia yang dikenali. URL asasnya telah disahkan dan oleh itu boleh dipercayai.
  • Web — ditemui melalui carian internet dan dinilai secara automatik. Entri ini hanya muncul jika carian web telah dikonfigurasikan dalam tetapan. Ia berguna, tetapi jika ragu-ragu, anda harus menyemak URL asas secara ringkas.

Kebolehcapaian

Sebelum dipaparkan, setiap cadangan diuji secara langsung (panggilan kepada titik akhir /models):

  • Boleh dicapai — API bertindak balas, penyedia berfungsi.
  • Boleh dicapai (Kunci diperlukan) — API wujud, tetapi memerlukan kunci API. Ini bermakna alamatnya adalah betul.
  • Tidak boleh dicapai — alamat tidak bertindak balas. Entri sedemikian tidak boleh dipilih.

Menambah penyedia

Tandakan kotak semak pada satu atau lebih penyedia dan klik butang „Tambah Pilihan" di bawah. Penyedia yang dipilih akan dicipta dalam keadaan dinyahaktifkan dan tanpa kunci API. Penyedia yang telah wujud tidak akan dicadangkan langsung.

Langkah seterusnya selepas penambahan

Penyedia yang baru ditambah masih belum aktif. Buka penyedia tersebut dalam senarai, masukkan kunci API dan aktifkannya. Selepas itu, ia akan berfungsi sama seperti penyedia lain anda. Model-model individu bagi sesuatu penyedia tetap diuruskan secara berasingan melalui Pengurusan Model.
