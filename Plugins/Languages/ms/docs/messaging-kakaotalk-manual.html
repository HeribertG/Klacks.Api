Menyediakan Pemesejan KakaoTalk

Prasyarat

Untuk menghantar mesej melalui KakaoTalk, anda memerlukan satu aplikasi pada developers.kakao.com (Kakao Developers). KakaoTalk ialah aplikasi pemesejan yang mendominasi di Korea Selatan. Integrasi Klacks menggunakan API Kakao Developer ("Hantar Mesej kepada Rakan").

Batasan penting API Kakao Developer:

  • Integrasi ini direka hanya untuk penghantaran — bukan untuk penerimaan.
  • Access-Token bersifat berjangka pendek (lebih kurang 6 jam) dan mesti diperbaharui serta didaftarkan semula di luar Klacks.
  • Mesej hanya boleh dihantar kepada pengguna yang disambungkan sebagai "Rakan" Kakao bagi aplikasi dan telah bersetuju menerima mesej.
  • Untuk mesej perniagaan produktif (AlimTalk), satu saluran perniagaan melalui agensi yang diberi kuasa diperlukan di Korea — integrasi ini tidak merangkumi perkara tersebut kerana ia menggunakan API Developer.

Langkah 1 — Menyediakan Aplikasi Kakao Developers

  1. Cipta satu aplikasi pada developers.kakao.com.
  2. Aktifkan Kakao Login untuk aplikasi tersebut.
  3. Dayakan skop talk_message dan friends.
  4. Dapatkan satu Access-Token melalui aliran OAuth Kakao Login (pengguna yang bagi pihaknya mesej dihantar mesti bersetuju dengan skop tersebut).

Nota: Layan Access-Token seperti kata laluan. Jangan kongsikannya secara terbuka dan simpan dengan selamat.

Langkah 2 — Mengkonfigurasi KakaoTalk dalam Klacks

  1. Navigasi ke Tetapan → Pembekal Pemesejan.
  2. Klik pada Tambah.
  3. Isikan medan seperti berikut:

  1. Klik pada Simpan.
  2. Uji sambungan menggunakan butang Test dalam senarai pembekal.

Penting: Access-Token akan tamat tempoh selepas lebih kurang 6 jam. Klacks tidak memperbaharuinya secara automatik — anda perlu memperbaharuinya secara luaran (aliran Refresh-Token Kakao) dan mendaftarkannya semula dalam Klacks.

Langkah 3 — Menghantar Mesej melalui Chatbot (Klacksy)

Sebaik sahaja pembekal KakaoTalk dikonfigurasi dan diaktifkan, chatbot Klacksy boleh menghantar mesej. Anda tidak perlu mengetahui sebarang ID — cukup gunakan nama pekerja atau klien: 

"Hantar mesej kepada Max Muster: Temujanji anda esok pada pukul 14:00."
"Hantar mesej kepada Anna Beispiel: Syif telah ditukar."
"Maklumkan Peter Müller bahawa tugasnya pada hari Isnin dibatalkan."

Klacksy secara automatik mencari pengecam penerima yang telah didaftarkan dan menggunakan pembekal KakaoTalk yang dikonfigurasi. Proses penghantaran adalah telus sepenuhnya untuk anda — anda hanya perlu bekerja dengan nama, Klacksy akan menguruskan selebihnya.

Prasyarat: Friend-UUID daripada API Kakao Friends mesti didaftarkan dalam Klacks bagi penerima (di bawah Alamat → Butiran Hubungan). Penerima mesti disambungkan sebagai "Rakan" Kakao dengan aplikasi tersebut — mesej tidak boleh dihantar kepada pengguna lain.

Mesej Masuk

Integrasi KakaoTalk tidak menyokong penerimaan mesej — balasan kepada mesej yang dihantar tidak akan dihantar ke Klacks. Oleh itu, Peti Masuk Pemesejan tidak memaparkan sebarang mesej masuk untuk pembekal ini.
