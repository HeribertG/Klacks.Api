Menyediakan Pemesejan LINE

Prasyarat

Untuk menghantar dan menerima mesej melalui LINE, anda memerlukan LINE Official Account dengan Messaging-API-Channel dalam LINE Developers Console. LINE amat popular di Jepun, Taiwan dan Thailand.

Nota: Mesej push mempunyai kuota bulanan bergantung pada pelan LINE anda (pelan percuma adalah terhad). Semak syarat semasa pelan Official Account anda.

Langkah 1 — Membuat LINE Official Account dan Messaging-API-Channel

  1. Buat satu LINE Official Account (melalui LINE Official Account Manager).
  2. Buka LINE Developers Console (developers.line.biz) dan buat satu Messaging-API-Channel, atau pautkan Official Account anda dengan Messaging API.
  3. Dalam tab Messaging API, keluarkan (Issue) satu Channel-Access-Token yang tahan lama.
  4. Catatkan Channel-Secret daripada tab Basic Settings.

Nota: Layan Channel-Access-Token dan Channel-Secret seperti kata laluan. Jangan kongsikannya secara terbuka dan simpan dengan selamat.

Langkah 3 — Menghantar mesej melalui chatbot (Klacksy)

Sebaik sahaja pembekal LINE dikonfigurasi dan diaktifkan, chatbot Klacksy boleh menghantar mesej. Anda tidak perlu mengetahui LINE-User-ID — cukup gunakan nama pekerja atau klien: 

"Hantar mesej kepada Max Muster: Temujanji anda esok pada pukul 14:00."
"Hantar mesej kepada Anna Beispiel: Syif telah ditukar."
"Maklumkan kepada Peter Müller bahawa tugasnya pada hari Isnin dibatalkan."

Klacksy secara automatik mencari LINE-User-ID penerima yang telah didaftarkan dan menggunakan pembekal LINE yang dikonfigurasi. Penghantaran adalah sepenuhnya lutsinar untuk anda — anda bekerja dengan nama, Klacksy akan menguruskan selebihnya.

Prasyarat: LINE-User-ID penerima (bermula dengan U…) mesti didaftarkan dalam Klacks (di bawah Alamat → Data Hubungan). ID pengguna diketahui melalui mesej masuk (kelihatan dalam Peti Masuk Pemesejan) — untuk itu, penerima mesti menambah Official Account anda sebagai kawan dan menghantar mesej kepadanya.

Langkah 4 — Menerima mesej masuk (Webhook)

Untuk memaparkan mesej LINE masuk dalam Klacks, URL Webhook mesti dimasukkan secara manual dalam LINE Developers Console.

  1. Salin URL Webhook yang dipaparkan dalam Klacks daripada tetapan pembekal: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. Masukkan URL ini dalam LINE Developers Console di bawah Messaging API → Webhook settings sebagai Webhook URL.
  3. Aktifkan pilihan „Use webhook".
  4. Pastikan instans Klacks anda boleh diakses secara awam melalui HTTPS.
  5. Mesej masuk kini akan muncul secara masa nyata dalam Peti Masuk Pemesejan.
