Menyediakan Slack

Prasyarat

Untuk menghantar dan menerima mesej melalui Slack dengan Klacks, anda memerlukan ruang kerja Slack (Slack Workspace) dan aplikasi Slack dengan kebenaran yang sesuai. Klacks menggunakan Slack Web API untuk penghantaran dan Events API untuk penerimaan.

Nota: Pelan percuma Slack sudah mencukupi untuk penyambungan ini. Aplikasi Slack dicipta di api.slack.com dan adalah percuma.

Langkah 1 — Mencipta Aplikasi Slack

  1. Buka api.slack.com/apps dan klik Create New App.
  2. Pilih From scratch dan berikan nama (contohnya Klacks Bot).
  3. Pilih ruang kerja di mana aplikasi ini akan dipasang.
  4. Navigasi ke OAuth & Permissions dan tambahkan Bot Token Scopes berikut:
    • chat:write — untuk menghantar mesej ke saluran (channels)
    • im:write — untuk menghantar mesej terus (direct message) kepada pengguna
  5. Klik Install to Workspace dan sahkan kebenaran yang diperlukan.
  6. Catatkan Bot User OAuth Token (bermula dengan xoxb-).
  7. Navigasi ke Basic Information dan catatkan Signing Secret.

Langkah 2 — Mengkonfigurasi Slack dalam Klacks

  1. Navigasi ke Tetapan → Pembekal Pemesejan.
  2. Klik Tambah.
  3. Isikan medan seperti berikut:

Langkah 3 — Menghantar Mesej melalui Chatbot (Klacksy)

Sebaik sahaja pembekal Slack dikonfigurasi dan diaktifkan, chatbot Klacksy boleh menghantar mesej melalui Slack. Gunakan nama pekerja atau nama saluran: 

"Hantar mesej kepada Max Muster: Temujanji anda esok pada pukul 14:00."
"Hantar mesej kepada Anna Beispiel: Syif telah ditukar."
"Siarkan di #team-updates: Jadual kerja untuk minggu depan sudah siap."

Penerima boleh berupa Channel-ID (contohnya C0123456789) atau User-ID (contohnya U0123456789) — bagi User-ID, mesej terus akan dihantar. Jika tiada penerima dinyatakan, saluran lalai yang dikonfigurasi akan digunakan. Proses penghantaran adalah sepenuhnya telus bagi anda — anda hanya perlu menggunakan nama, dan Klacksy akan menguruskan selebihnya.

Prasyarat: Pengguna Slack mesti dipautkan dengan kenalan Klacks yang berkaitan (di bawah Alamat → Maklumat Hubungan). Untuk mesej saluran, bot mesti dijemput ke saluran berkenaan (/invite @Klacks Bot).

Langkah 4 — Menerima Mesej Masuk (Events API)

Untuk memaparkan mesej Slack yang masuk dalam Klacks, Events API bagi aplikasi Slack perlu dikonfigurasi. Simpan dan aktifkan pembekal dalam Klacks sebelum anda memasukkan Request URL — Slack akan menyemak URL tersebut serta-merta dengan permintaan cabaran, yang dijawab secara automatik oleh Klacks.

  1. Buka aplikasi Slack anda di api.slack.com/apps dan navigasi ke Event Subscriptions.
  2. Aktifkan Enable Events dan masukkan sebagai Request URL URL webhook yang dipaparkan dalam Klacks: 
    https://{ihre-domain}/api/messaging/webhook/slack
  3. Langgan di bawah Subscribe to bot events untuk events message.im (mesej terus) dan message.channels (mesej saluran).
  4. Simpan perubahan tersebut dan pasang semula aplikasi ke dalam ruang kerja apabila diminta.
  5. Mesej yang masuk kini akan dipaparkan secara masa nyata dalam Peti Masuk Pemesejan. Klacks turut menyemak tandatangan setiap permintaan menggunakan Signing Secret yang disimpan.
