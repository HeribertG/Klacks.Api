Εγχειρίδιο πεδίου τύπου

Βασική σύνταξη

Κάθε πεδίο τύπου εξάγει το αποτέλεσμα με την εντολή output:

output 1, <έκφραση>

Η πρώτη παράμετρος 1 είναι ο τύπος μηνύματος και πρέπει πάντα να είναι 1. Η δεύτερη παράμετρος είναι η τιμή προς εξαγωγή.

Απλά παραδείγματα:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " εγγραφές"

Οι διαθέσιμες μεταβλητές αναγράφονται στην καρτέλα Μεταβλητές και μπορούν εκεί να πάρουν δοκιμαστικές τιμές. Ανάλογα με τον τύπο αναφοράς είναι διαθέσιμες διαφορετικές μεταβλητές:

Λογική υπό συνθήκη

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "πολλές εγγραφές"
ELSEIF totalRows > 0 THEN
    output 1, "λίγες εγγραφές"
ELSE
    output 1, "καμία εγγραφή"
ENDIF

Μονογραμμικό IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (σύντομη μορφή)

output 1, IIF(totalRows > 0, "OK", "Κενό")

Μεταβλητές και βρόχοι

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Πρακτικά παραδείγματα

Αριθμός εγγραφών με κείμενο

output 1, CStr(totalRows) & " εγγραφές"

Στρογγυλοποιημένη τιμή (1 δεκαδικό)

output 1, CStr(Round(totalValue, 1))

Ώρες ως h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "ω " & CStr(m) & "λεπτά"

Εξαγωγή υπό συνθήκη

IF totalRows = 0 THEN
    output 1, "Καμία απουσία"
ELSE
    output 1, CStr(totalRows) & " απουσίες (Σύνολο: " & CStr(totalValue) & ")"
ENDIF

Υπολογισμός μέσου όρου

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " ω/ημέρα"
ELSE
    output 1, "-"
ENDIF
