Ρύθμιση μηνυμάτων LINE

Προϋποθέσεις

Για να στέλνετε και να λαμβάνετε μηνύματα μέσω LINE, χρειάζεστε έναν LINE Official Account με ένα κανάλι Messaging API στην κονσόλα LINE Developers. Το LINE είναι ιδιαίτερα διαδεδομένο στην Ιαπωνία, την Ταϊβάν και την Ταϊλάνδη.

Σημείωση: Τα push μηνύματα έχουν ανάλογα με το πρόγραμμα LINE μηνιαία ποσόστωση (το δωρεάν πρόγραμμα είναι περιορισμένο). Ελέγξτε τους τρέχοντες όρους του προγράμματος Official Account σας.

Βήμα 1 — Δημιουργία LINE Official Account και καναλιού Messaging API

  1. Δημιουργήστε έναν LINE Official Account (μέσω του LINE Official Account Manager).
  2. Ανοίξτε την κονσόλα LINE Developers (developers.line.biz) και δημιουργήστε ένα κανάλι Messaging API ή συνδέστε τον Official Account σας με το Messaging API.
  3. Εκδώστε στην καρτέλα Messaging API ένα μακράς διαρκείας Channel Access Token (Issue).
  4. Σημειώστε το Channel Secret από την καρτέλα Basic Settings.

Σημείωση: Χειριστείτε το Channel Access Token και το Channel Secret όπως κωδικούς πρόσβασης. Μην τα μοιράζεστε δημόσια και αποθηκεύστε τα με ασφάλεια.

Βήμα 2 — Διαμόρφωση του LINE στο Klacks

  1. Μεταβείτε στο Ρυθμίσεις → Πάροχοι μηνυμάτων.
  2. Κάντε κλικ στο Προσθήκη.
  3. Συμπληρώστε τα πεδία ως εξής:

Βήμα 3 — Αποστολή μηνυμάτων μέσω του chatbot (Klacksy)

Μόλις ο πάροχος LINE είναι διαμορφωμένος και ενεργοποιημένος, το chatbot Klacksy μπορεί να στέλνει μηνύματα. Δεν χρειάζεται να γνωρίζετε αναγνωριστικά χρήστη LINE — χρησιμοποιήστε απλώς το όνομα του εργαζομένου ή του πελάτη: 

"Στείλε ένα μήνυμα στον Max Muster: Το ραντεβού σας είναι αύριο στις 14:00."
"Στείλε στην Anna Beispiel ένα μήνυμα: Η βάρδια αντικαταστάθηκε."
"Ειδοποίησε τον Peter Müller ότι η υπηρεσία του τη Δευτέρα ακυρώνεται."

Ο Klacksy αναζητά αυτόματα το καταχωρημένο αναγνωριστικό χρήστη LINE του παραλήπτη και χρησιμοποιεί τον διαμορφωμένο πάροχο LINE. Η αποστολή είναι για εσάς πλήρως διαφανής — εργάζεστε με ονόματα, ο Klacksy αναλαμβάνει τα υπόλοιπα.

Προϋπόθεση: Ο παραλήπτης πρέπει να έχει καταχωρημένο το αναγνωριστικό χρήστη LINE (ξεκινά με U…) στο Klacks (στη Διεύθυνση → Στοιχεία επικοινωνίας). Το αναγνωριστικό χρήστη γίνεται γνωστό μέσω εισερχόμενων μηνυμάτων (ορατό στα εισερχόμενα μηνυμάτων) — ο παραλήπτης πρέπει γι' αυτό να έχει προσθέσει τον Official Account σας ως φίλο και να του έχει στείλει μήνυμα.

Βήμα 4 — Λήψη εισερχόμενων μηνυμάτων (Webhook)

Για να εμφανίζονται τα εισερχόμενα μηνύματα LINE στο Klacks, το URL webhook πρέπει να καταχωριστεί χειροκίνητα στην κονσόλα LINE Developers.

  1. Αντιγράψτε το URL webhook που εμφανίζεται στο Klacks από τις ρυθμίσεις παρόχου: 
    https://{το-domain-σας}/api/messaging/webhook/line
  2. Καταχωρίστε αυτό το URL στην κονσόλα LINE Developers στο Messaging API → Webhook settings ως Webhook URL.
  3. Ενεργοποιήστε την επιλογή «Use webhook».
  4. Βεβαιωθείτε ότι η εγκατάστασή σας Klacks είναι δημόσια προσβάσιμη μέσω HTTPS.
  5. Τα εισερχόμενα μηνύματα εμφανίζονται τώρα σε πραγματικό χρόνο στα Εισερχόμενα μηνυμάτων.
