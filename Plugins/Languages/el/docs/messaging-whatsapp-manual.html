Ρύθμιση WhatsApp

Προϋποθέσεις

Για να στέλνετε και να λαμβάνετε μηνύματα μέσω WhatsApp με το Klacks, χρειάζεστε έναν λογαριασμό προγραμματιστή Meta και μια εφαρμογή Meta με ενεργοποιημένο το προϊόν WhatsApp. Το Klacks χρησιμοποιεί το WhatsApp Cloud API της πλατφόρμας Meta Business για την αποστολή και τα webhooks της Meta για τη λήψη.

Σημείωση: Για τη ρύθμιση και τη δοκιμή δεν προκύπτει καμία χρέωση. Κατά τη δημιουργία της εφαρμογής η Meta παρέχει αυτόματα έναν δωρεάν δοκιμαστικό αριθμό τηλεφώνου.

Σημαντικό — ο αριθμός αποστολέα δεν είναι ο ιδιωτικός σας αριθμός. Ένας αριθμός τηλεφώνου που χρησιμοποιείται ήδη στην κανονική εφαρμογή WhatsApp δεν μπορεί να καταχωριστεί για το Cloud API, και ένας καταχωρισμένος αριθμός δεν μπορεί πλέον να χρησιμοποιηθεί με το WhatsApp Messenger. Χρησιμοποιήστε επομένως τον δοκιμαστικό αριθμό που παρέχει η Meta ή έναν δικό σας αριθμό αποκλειστικά επαγγελματικής χρήσης. Το ιδιωτικό σας WhatsApp στο κινητό τηλέφωνο χρησιμεύει ως παραλήπτης για τη δοκιμή — όχι ως αποστολέας.

Βήμα 1 — Δημιουργία εφαρμογής Meta

  1. Ανοίξτε το developers.facebook.com/apps και κάντε κλικ στο Create app.
  2. Επιλέξτε ως περίπτωση χρήσης Other και ως τύπο εφαρμογής Business.
  3. Στο dashboard κάντε κλικ στο Set up στο προϊόν WhatsApp. Με αυτόν τον τρόπο δημιουργείται και καταχωρίζεται αυτόματα ένας δοκιμαστικός αριθμός τηλεφώνου.
  4. Μεταβείτε στην αριστερή πλοήγηση στο WhatsApp → API Setup.
  5. Σημειώστε το Phone number ID και δημιουργήστε μέσω του Generate access token ένα token πρόσβασης.
  6. Σημειώστε στο App settings → Basic το App Secret — χρειάζεται για τον έλεγχο υπογραφής των εισερχόμενων μηνυμάτων.

Προσοχή — δύο παρόμοια ID: Στο πάνελ API Setup, το Phone number ID και το WhatsApp Business Account ID βρίσκονται ακριβώς το ένα κάτω από το άλλο. Το Klacks χρειάζεται το Phone number ID. Με λάθος ID η δοκιμή σύνδεσης αναφέρει παρ' όλα αυτά επιτυχία, αλλά κάθε αποστολή αποτυγχάνει.

Προσοχή — διάρκεια ισχύος του token: Το token που δημιουργείται μέσω του Generate access token είναι ένα προσωρινό δοκιμαστικό token και λήγει μετά από σύντομο χρονικό διάστημα. Για τη μόνιμη λειτουργία δημιουργήστε στο Meta Business Manager ένα μόνιμο token μέσω ενός χρήστη συστήματος.

Βήμα 2 — Έγκριση του αριθμού παραλήπτη

Ο δοκιμαστικός αριθμός επιτρέπεται να στέλνει μόνο σε παραλήπτες που έχουν εγκριθεί εκ των προτέρων. Προσθέστε στο πάνελ API Setup στο To → Manage phone number list τον αριθμό WhatsApp σας. Η Meta στέλνει έναν κωδικό επιβεβαίωσης σε αυτόν τον αριθμό, τον οποίο πρέπει να καταχωρίσετε.

Χωρίς αυτό το βήμα η Meta απορρίπτει κάθε αποστολή προς αυτόν τον αριθμό. Μόλις χρησιμοποιήσετε αργότερα έναν δικό σας, επαληθευμένο επαγγελματικό αριθμό, η έγκριση παύει να απαιτείται.

Βήμα 4 — Το παράθυρο των 24 ωρών

Εδώ το WhatsApp διαφέρει ριζικά από το Telegram ή το Slack. Μια επιχείρηση επιτρέπεται να στέλνει ελεύθερα μηνύματα κειμένου μόνο όσο είναι ανοιχτό ένα παράθυρο εξυπηρέτησης πελατών. Αυτό το παράθυρο το ανοίγει ο παραλήπτης, γράφοντας στον αριθμό WhatsApp σας. Παραμένει ανοιχτό για 24 ώρες και παρατείνεται με κάθε νέο μήνυμα του παραλήπτη.

Εκτός αυτού του παραθύρου η Meta επιτρέπει αποκλειστικά προεγκεκριμένα πρότυπα μηνυμάτων. Το Klacks αποστέλλει προς το παρόν αποκλειστικά ελεύθερα μηνύματα κειμένου και συνεπώς δεν μπορεί να ξεκινήσει από μόνο του καμία συνομιλία.

Τι σημαίνει αυτό για εσάς: Ζητήστε μία φορά από τους εργαζομένους σας να στείλουν ένα μήνυμα στον αριθμό WhatsApp του Klacks. Στη συνέχεια η αποστολή είναι δυνατή για 24 ώρες, και κάθε απάντηση παρατείνει το παράθυρο. Αν είναι κλειστό, η αποστολή αναφέρει σφάλμα — δεν πρόκειται για πρόβλημα διαμόρφωσης, αλλά για κανόνα του WhatsApp.

Αν πρέπει να προσεγγίζετε εργαζομένους ανεξάρτητα από αυτό το παράθυρο, το Telegram ή το Signal είναι οι καλύτεροι πάροχοι — εκεί δεν υπάρχει αυτός ο περιορισμός.

Βήμα 5 — Αποστολή μηνυμάτων μέσω του chatbot (Klacksy)

Μόλις ο πάροχος WhatsApp είναι διαμορφωμένος και ενεργοποιημένος, το chatbot Klacksy μπορεί να στέλνει μηνύματα μέσω WhatsApp. Χρησιμοποιήστε το όνομα του εργαζομένου: 

"Στείλε ένα μήνυμα στον Max Muster: Το ραντεβού σας είναι αύριο στις 14:00."
"Στείλε στην Anna Beispiel ένα μήνυμα: Η βάρδια αντικαταστάθηκε."

Ως παραλήπτης χρησιμεύει ο αριθμός τηλεφώνου σε διεθνή μορφή χωρίς αρχικό μηδέν και χωρίς το σύμβολο συν (π.χ. 41791234567 για 079 123 45 67). Η αποστολή είναι για εσάς πλήρως διαφανής — εργάζεστε με ονόματα, ο Klacksy αναλαμβάνει τα υπόλοιπα.

Προϋπόθεση: Ο αριθμός WhatsApp πρέπει να είναι συνδεδεμένος με την αντίστοιχη επαφή στο Klacks (στη Διεύθυνση → Στοιχεία επικοινωνίας) και το παράθυρο των 24 ωρών από το βήμα 4 πρέπει να είναι ανοιχτό.

Βήμα 6 — Λήψη εισερχόμενων μηνυμάτων (webhooks)

Για να εμφανίζονται τα εισερχόμενα μηνύματα WhatsApp στο Klacks, πρέπει να διαμορφωθεί το webhook της εφαρμογής Meta. Αποθηκεύστε και ενεργοποιήστε τον πάροχο στο Klacks, πριν καταχωρίσετε το Callback URL — η Meta ελέγχει αμέσως το URL με ένα αίτημα επαλήθευσης, στο οποίο το Klacks απαντά αυτόματα με βάση το Verify Token.

  1. Ανοίξτε την εφαρμογή Meta σας και μεταβείτε στο WhatsApp → Configuration.
  2. Κάντε κλικ στο Edit δίπλα στο Webhook και καταχωρίστε:
    • Callback URL: το URL webhook που εμφανίζεται στο Klacks 
      https://{το-domain-σας}/api/messaging/webhook/whatsapp
    • Verify token: ακριβώς την ίδια τιμή που καταχωρίσατε στο βήμα 3 στο πεδίο Verify Token
  3. Κάντε κλικ στο Verify and save.
  4. Εγγραφείτε στο Webhook fields στο πεδίο messages.
  5. Τα εισερχόμενα μηνύματα εμφανίζονται τώρα σε πραγματικό χρόνο στα Εισερχόμενα μηνυμάτων. Το Klacks ελέγχει την υπογραφή κάθε αιτήματος (X-Hub-Signature-256) με το καταχωρημένο App Secret.

Το Callback URL πρέπει να είναι προσβάσιμο από έξω μέσω HTTPS. Σε μια εγκατάσταση στο εταιρικό δίκτυο χωρίς δημόσια διεύθυνση η αποστολή λειτουργεί, αλλά δεν είναι δυνατή η λήψη μηνυμάτων.
