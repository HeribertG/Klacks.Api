Αναζήτηση παρόχων LLM — Οδηγίες

Σε τι χρησιμεύει αυτή η λειτουργία;

Αυτή η προβολή σου προτείνει παρόχους LLM που δεν έχεις ακόμη στη λίστα σου και προσθέτει τους επιλεγμένους με ένα κλικ. Έτσι δεν χρειάζεται να καταχωρίσεις χειροκίνητα το όνομα και το βασικό URL. Προτείνονται αποκλειστικά πάροχοι API συμβατοί με OpenAI — δηλαδή ακριβώς ο τύπος υπηρεσιών που χρησιμοποιούν και οι ήδη ρυθμισμένοι πάροχοί σου.

Οι στήλες του πίνακα

Όνομα παρόχου

Το εμφανιζόμενο όνομα του παρόχου (π.χ. «OpenRouter», «xAI (Grok)»).

Βασικό URL

Η διεύθυνση API μέσω της οποίας γίνεται η επικοινωνία με τον πάροχο (π.χ. https://api.x.ai/v1/). Ακριβώς αυτό το URL θα χρησιμοποιηθεί αργότερα κατά τη δημιουργία.

Πηγή

Υποδεικνύει από πού προέρχεται η πρόταση:

  • Κατάλογος — από μια καθορισμένη, ελεγμένη λίστα γνωστών παρόχων. Τα βασικά URL είναι επαληθευμένα και επομένως αξιόπιστα.
  • Web — βρέθηκε μέσω αναζήτησης στο διαδίκτυο και αξιολογήθηκε αυτόματα. Αυτές οι καταχωρίσεις εμφανίζονται μόνο όταν η αναζήτηση στο διαδίκτυο είναι διαμορφωμένη στις ρυθμίσεις. Είναι χρήσιμες, αλλά σε περίπτωση αμφιβολίας θα πρέπει να ελέγξεις σύντομα το βασικό URL.

Προσβασιμότητα

Πριν την εμφάνιση κάθε πρόταση δοκιμάζεται ζωντανά (κλήση του endpoint /models):

  • Προσβάσιμο — το API απαντά, ο πάροχος λειτουργεί.
  • Προσβάσιμο (απαιτείται κλειδί) — το API υπάρχει, αλλά απαιτεί κλειδί API. Η διεύθυνση είναι δηλαδή σωστή.
  • Μη προσβάσιμο — η διεύθυνση δεν απαντά. Τέτοιες καταχωρίσεις δεν μπορούν να επιλεγούν.

Προσθήκη παρόχου

Επίλεξε ένα ή περισσότερους παρόχους και κάνε κλικ παρακάτω στο «Προσθήκη επιλογής». Οι επιλεγμένοι πάροχοι δημιουργούνται απενεργοποιημένοι και χωρίς κλειδί API. Πάροχοι που υπάρχουν ήδη δεν προτείνονται καθόλου.

Επόμενα βήματα μετά την προσθήκη

Ένας νέος πάροχος δεν είναι ακόμη ενεργός. Άνοιξέ τον στη λίστα, καταχώρισε το κλειδί API και ενεργοποίησέ τον. Στη συνέχεια λειτουργεί ακριβώς όπως οι υπόλοιποι πάροχοί σου. Τα επιμέρους μοντέλα ενός παρόχου εξακολουθείς να τα διαχειρίζεσαι ξεχωριστά μέσω της διαχείρισης μοντέλων.
