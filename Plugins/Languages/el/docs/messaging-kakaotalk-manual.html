Ρύθμιση μηνυμάτων KakaoTalk

Προϋποθέσεις

Για να στέλνετε μηνύματα μέσω KakaoTalk, χρειάζεστε μια εφαρμογή στο developers.kakao.com (Kakao Developers). Το KakaoTalk είναι ο κυρίαρχος αγγελιοφόρος στη Νότια Κορέα. Η σύνδεση με το Klacks χρησιμοποιεί το API Kakao Developer («αποστολή μηνύματος σε φίλους»).

Σημαντικοί περιορισμοί του API Kakao Developer:

  • Η σύνδεση είναι σχεδιασμένη μόνο για αποστολή — καμία λήψη.
  • Το access token είναι βραχύβιο (περίπου 6 ώρες) και πρέπει να ανανεωθεί εκτός Klacks και να καταχωριστεί εκ νέου.
  • Μηνύματα μπορούν να σταλούν μόνο σε χρήστες που είναι συνδεδεμένοι ως «φίλοι» Kakao της εφαρμογής και έχουν συναινέσει στην αποστολή μηνυμάτων.
  • Για παραγωγικά επιχειρηματικά μηνύματα (AlimTalk) απαιτείται στην Κορέα ένα επιχειρηματικό κανάλι μέσω εξουσιοδοτημένων πρακτορείων — αυτό δεν καλύπτει αυτή η ενσωμάτωση, καθώς χρησιμοποιεί το API Developer.

Βήμα 1 — Ρύθμιση εφαρμογής Kakao Developers

  1. Δημιουργήστε μια εφαρμογή στο developers.kakao.com.
  2. Ενεργοποιήστε το Kakao Login για την εφαρμογή.
  3. Ενεργοποιήστε τα scopes talk_message και friends.
  4. Αποκτήστε ένα access token μέσω της ροής OAuth του Kakao Login (ο χρήστης, εξ ονόματος του οποίου γίνεται η αποστολή, πρέπει να συναινέσει στα scopes).

Σημείωση: Χειριστείτε το access token όπως έναν κωδικό πρόσβασης. Μην το μοιράζεστε δημόσια και αποθηκεύστε το με ασφάλεια.

Βήμα 2 — Διαμόρφωση του KakaoTalk στο Klacks

  1. Μεταβείτε στο Ρυθμίσεις → Πάροχοι μηνυμάτων.
  2. Κάντε κλικ στο Προσθήκη.
  3. Συμπληρώστε τα πεδία ως εξής:

ΌνομαΕσωτερικό μοναδικό όνομαkakaotalk-main
Εμφανιζόμενο όνομαΕμφανίζεται στη διεπαφήKakaoTalk
Τύπος παρόχουΕπιλέξτε KakaoTalkKakaoTalk
Access TokenΤο token που αποκτήθηκε μέσω της ροής OAuthkakao-access-token...
ΕνεργοποιημένοΕνεργοποιεί/απενεργοποιεί τον πάροχοΝαι
  1. Κάντε κλικ στο Αποθήκευση.
  2. Δοκιμάστε τη σύνδεση μέσω του κουμπιού Δοκιμή στη λίστα παρόχων.

Σημαντικό: Το access token λήγει μετά από περίπου 6 ώρες. Το Klacks δεν το ανανεώνει αυτόματα — πρέπει να το ανανεώσετε εξωτερικά (ροή refresh token του Kakao) και να το καταχωρίσετε εκ νέου στο Klacks.

Βήμα 3 — Αποστολή μηνυμάτων μέσω του chatbot (Klacksy)

Μόλις ο πάροχος KakaoTalk είναι διαμορφωμένος και ενεργοποιημένος, το chatbot Klacksy μπορεί να στέλνει μηνύματα. Δεν χρειάζεται να γνωρίζετε αναγνωριστικά — χρησιμοποιήστε απλώς το όνομα του εργαζομένου ή του πελάτη: 

"Στείλε ένα μήνυμα στον Max Muster: Το ραντεβού σας είναι αύριο στις 14:00."
"Στείλε στην Anna Beispiel ένα μήνυμα: Η βάρδια αντικαταστάθηκε."
"Ειδοποίησε τον Peter Müller ότι η υπηρεσία του τη Δευτέρα ακυρώνεται."

Ο Klacksy αναζητά αυτόματα το καταχωρημένο αναγνωριστικό του παραλήπτη και χρησιμοποιεί τον διαμορφωμένο πάροχο KakaoTalk. Η αποστολή είναι για εσάς πλήρως διαφανής — εργάζεστε με ονόματα, ο Klacksy αναλαμβάνει τα υπόλοιπα.

Προϋπόθεση: Ο παραλήπτης πρέπει να έχει καταχωρημένο το Friend UUID από το API Kakao Friends στο Klacks (στη Διεύθυνση → Στοιχεία επικοινωνίας). Ο παραλήπτης πρέπει να είναι συνδεδεμένος ως «φίλος» Kakao με την εφαρμογή — σε άλλους χρήστες δεν μπορεί να γίνει αποστολή.

Εισερχόμενα μηνύματα

Η σύνδεση KakaoTalk δεν υποστηρίζει λήψη — οι απαντήσεις σε απεσταλμένα μηνύματα δεν μεταφέρονται στο Klacks. Τα εισερχόμενα μηνυμάτων επομένως δεν εμφανίζουν εισερχόμενα μηνύματα για αυτόν τον πάροχο.
