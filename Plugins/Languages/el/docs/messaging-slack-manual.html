Ρύθμιση Slack

Προϋποθέσεις

Για να στέλνετε και να λαμβάνετε μηνύματα μέσω Slack με το Klacks, χρειάζεστε έναν χώρο εργασίας Slack και μια εφαρμογή Slack με τα κατάλληλα δικαιώματα. Το Klacks χρησιμοποιεί το Slack Web API για την αποστολή και το Events API για τη λήψη.

Σημείωση: Το δωρεάν πρόγραμμα Slack επαρκεί για τη σύνδεση. Οι εφαρμογές Slack δημιουργούνται στο api.slack.com και είναι δωρεάν.

Βήμα 1 — Δημιουργία εφαρμογής Slack

  1. Ανοίξτε το api.slack.com/apps και κάντε κλικ στο Create New App.
  2. Επιλέξτε From scratch και δώστε ένα όνομα (π.χ. Klacks Bot).
  3. Επιλέξτε τον χώρο εργασίας στον οποίο θα εγκατασταθεί η εφαρμογή.
  4. Μεταβείτε στο OAuth & Permissions και προσθέστε τα ακόλουθα Bot Token Scopes:
    • chat:write — για αποστολή μηνυμάτων σε κανάλια
    • im:write — για αποστολή άμεσων μηνυμάτων σε χρήστες
  5. Κάντε κλικ στο Install to Workspace και επιβεβαιώστε τα δικαιώματα.
  6. Σημειώστε το Bot User OAuth Token (ξεκινά με xoxb-).
  7. Μεταβείτε στο Basic Information και σημειώστε το Signing Secret.

Βήμα 2 — Διαμόρφωση του Slack στο Klacks

  1. Μεταβείτε στο Ρυθμίσεις → Πάροχοι μηνυμάτων.
  2. Κάντε κλικ στο Προσθήκη.
  3. Συμπληρώστε τα πεδία ως εξής:

Βήμα 3 — Αποστολή μηνυμάτων μέσω του chatbot (Klacksy)

Μόλις ο πάροχος Slack είναι διαμορφωμένος και ενεργοποιημένος, το chatbot Klacksy μπορεί να στέλνει μηνύματα μέσω Slack. Χρησιμοποιήστε το όνομα του εργαζομένου ή ένα όνομα καναλιού: 

"Στείλε ένα μήνυμα στον Max Muster: Το ραντεβού σας είναι αύριο στις 14:00."
"Στείλε στην Anna Beispiel ένα μήνυμα: Η βάρδια αντικαταστάθηκε."
"Δημοσίευσε στο #team-updates: Τα προγράμματα υπηρεσιών για την επόμενη εβδομάδα είναι έτοιμα."

Ως παραλήπτης χρησιμεύει ένα Channel ID (π.χ. C0123456789) ή ένα User ID (π.χ. U0123456789) — με User ID στέλνεται άμεσο μήνυμα. Αν δεν έχει οριστεί παραλήπτης, χρησιμοποιείται το διαμορφωμένο προεπιλεγμένο κανάλι. Η αποστολή είναι για εσάς πλήρως διαφανής — εργάζεστε με ονόματα, ο Klacksy αναλαμβάνει τα υπόλοιπα.

Προϋπόθεση: Ο χρήστης Slack πρέπει να είναι συνδεδεμένος με την αντίστοιχη επαφή στο Klacks (στη Διεύθυνση → Στοιχεία επικοινωνίας). Για μηνύματα καναλιού το bot πρέπει να είναι προσκεκλημένο στο αντίστοιχο κανάλι (/invite @Klacks Bot).

Βήμα 4 — Λήψη εισερχόμενων μηνυμάτων (Events API)

Για να εμφανίζονται τα εισερχόμενα μηνύματα Slack στο Klacks, πρέπει να διαμορφωθεί το Events API της εφαρμογής Slack. Αποθηκεύστε και ενεργοποιήστε τον πάροχο στο Klacks, πριν καταχωρίσετε το Request URL — το Slack ελέγχει αμέσως το URL με ένα αίτημα challenge, το οποίο το Klacks απαντά αυτόματα.

  1. Ανοίξτε την εφαρμογή Slack σας στο api.slack.com/apps και μεταβείτε στο Event Subscriptions.
  2. Ενεργοποιήστε το Enable Events και καταχωρίστε ως Request URL το URL webhook που εμφανίζεται στο Klacks: 
    https://{το-domain-σας}/api/messaging/webhook/slack
  3. Εγγραφείτε στο Subscribe to bot events στα events message.im (άμεσα μηνύματα) και message.channels (μηνύματα καναλιού).
  4. Αποθηκεύστε τις αλλαγές και εγκαταστήστε ξανά την εφαρμογή στον χώρο εργασίας όταν σας ζητηθεί.
  5. Τα εισερχόμενα μηνύματα εμφανίζονται τώρα σε πραγματικό χρόνο στα Εισερχόμενα μηνυμάτων. Το Klacks ελέγχει την υπογραφή κάθε αιτήματος με το καταχωρημένο Signing Secret.
