Ρύθμιση μηνυμάτων Signal

Προϋποθέσεις

Για να στέλνετε μηνύματα Signal μέσω του Klacks, χρειάζεστε ένα αυτόφιλοξενούμενο στιγμιότυπο του signal-cli-rest-api. Πρόκειται για ένα έργο ανοιχτού κώδικα, που καθιστά το Signal προσβάσιμο μέσω μιας διεπαφής REST.

  • Το Docker πρέπει να είναι εγκατεστημένο στον διακομιστή
  • Ένας αριθμός τηλεφώνου, που θα καταχωριστεί στο Signal (συνιστάται αποκλειστικός αριθμός)
  • Η εικόνα Docker: bbernhard/signal-cli-rest-api

Σημαντικό: Η σύνδεση Signal είναι σχεδιασμένη μόνο για αποστολή. Τα εισερχόμενα μηνύματα Signal δεν λαμβάνονται στο Klacks.

Βήμα 1 — Ρύθμιση του signal-cli-rest-api

  1. Ξεκινήστε το container με Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Συνδέστε τον αριθμό Signal σας μέσω της διαδικασίας συνδέσμου QR: Ανοίξτε στο πρόγραμμα περιήγησης 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    και σαρώστε τον εμφανιζόμενο κωδικό QR με την εφαρμογή Signal στο τηλέφωνο, στο οποίο είναι καταχωρημένος ο αριθμός (Ρυθμίσεις → Συνδεδεμένες συσκευές → Σύνδεση συσκευής). Το container συνδέεται έτσι ως δεύτερη συσκευή.
  3. Εναλλακτικά μπορείτε να καταχωρίσετε τον αριθμό αυτόνομα μέσω του API — λεπτομέρειες θα βρείτε στην τεκμηρίωση του έργου.
  4. Δοκιμάστε το API με έναν έλεγχο υγείας: 
    curl http://localhost:8080/v1/about

Σημείωση: Περισσότερες λεπτομέρειες για τη διαμόρφωση θα βρείτε στην τεκμηρίωση του signal-cli-rest-api.

Βήμα 2 — Διαμόρφωση του Signal στο Klacks

  1. Μεταβείτε στο Ρυθμίσεις → Πάροχοι μηνυμάτων.
  2. Κάντε κλικ στο Προσθήκη.
  3. Συμπληρώστε τα πεδία ως εξής:

  2. Δοκιμάστε τη σύνδεση μέσω του κουμπιού Δοκιμή στη λίστα παρόχων. Η δοκιμή ελέγχει αν ο δηλωμένος αριθμός είναι καταχωρημένος στο container.

Σημείωση: Το Klacks στέλνει μηνύματα μέσω του endpoint POST /v2/send του container.

Βήμα 3 — Αποστολή μηνυμάτων μέσω του chatbot (Klacksy)

Μόλις ο πάροχος Signal είναι διαμορφωμένος και ενεργοποιημένος, το chatbot Klacksy μπορεί να στέλνει μηνύματα. Δεν χρειάζεται να γνωρίζετε αριθμούς τηλεφώνου — χρησιμοποιήστε απλώς το όνομα του εργαζομένου ή του πελάτη: 

"Στείλε ένα μήνυμα στον Max Muster: Το ραντεβού σας είναι αύριο στις 14:00."
"Στείλε στην Anna Beispiel ένα μήνυμα Signal: Η βάρδια αντικαταστάθηκε."
"Ειδοποίησε τον Peter Müller ότι η υπηρεσία του τη Δευτέρα ακυρώνεται."

Ο Klacksy αναζητά αυτόματα τον καταχωρημένο αριθμό κινητού του παραλήπτη και χρησιμοποιεί τον διαμορφωμένο πάροχο Signal. Η αποστολή είναι για εσάς πλήρως διαφανής — εργάζεστε με ονόματα, ο Klacksy αναλαμβάνει τα υπόλοιπα.

Προϋπόθεση: Ο παραλήπτης πρέπει να έχει καταχωρημένο αριθμό κινητού στο Klacks (στη Διεύθυνση → Στοιχεία επικοινωνίας), σε διεθνή μορφή (π.χ. +41791234567). Ακόμη και σε μηνύματα broadcast η αποστολή Signal βασίζεται στον καταχωρημένο αριθμό κινητού.

Εισερχόμενα μηνύματα

Η σύνδεση Signal δεν υποστηρίζει λήψη — οι απαντήσεις σε απεσταλμένα μηνύματα δεν μεταφέρονται στο Klacks. Τα εισερχόμενα μηνυμάτων επομένως δεν εμφανίζουν εισερχόμενα μηνύματα για αυτόν τον πάροχο.
