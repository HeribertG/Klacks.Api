Ρύθμιση Threema Gateway

Προϋποθέσεις

Για να στέλνετε μηνύματα μέσω Threema, χρειάζεστε έναν λογαριασμό στο Threema Gateway. Το Threema είναι ελβετικός πάροχος, ευρέως διαδεδομένος στην Ελβετία και φιλικός προς την προστασία δεδομένων (ελβετικό DSG).

Σημαντικό: Η σύνδεση Threema είναι σχεδιασμένη μόνο για αποστολή. Η λήψη εισερχόμενων μηνυμάτων θα απαιτούσε τη λειτουργία end-to-end του gateway και δεν υποστηρίζεται. Η αποστολή είναι επί πληρωμή — κάθε απεσταλμένο μήνυμα καταναλώνει credits.

Βήμα 1 — Δημιουργία λογαριασμού Threema Gateway

  1. Εγγραφείτε στο gateway.threema.ch.
  2. Αιτηθείτε ένα Gateway ID σε λειτουργία Basic (π.χ. *MYGATEWAY). Αυτό ξεκινά πάντα με έναν αστερίσκο (*) και πρέπει να εγκριθεί από το Threema.
  3. Αγοράστε credits — χωρίς υπόλοιπο δεν μπορούν να σταλούν μηνύματα.
  4. Σημειώστε το API Secret από το dashboard του gateway.

Σημείωση: Χειριστείτε το API Secret όπως έναν κωδικό πρόσβασης. Μην το μοιράζεστε δημόσια και αποθηκεύστε το με ασφάλεια.

Βήμα 2 — Διαμόρφωση του Threema στο Klacks

  1. Μεταβείτε στο Ρυθμίσεις → Πάροχοι μηνυμάτων.
  2. Κάντε κλικ στο Προσθήκη.
  3. Συμπληρώστε τα πεδία ως εξής:

  1. Κάντε κλικ στο Αποθήκευση.
  2. Δοκιμάστε τη σύνδεση μέσω του κουμπιού Δοκιμή στη λίστα παρόχων. Η δοκιμή ελέγχει τα διαπιστευτήρια μέσω του ερωτήματος credits του gateway.

Βήμα 3 — Αποστολή μηνυμάτων μέσω του chatbot (Klacksy)

Μόλις ο πάροχος Threema είναι διαμορφωμένος και ενεργοποιημένος, το chatbot Klacksy μπορεί να στέλνει μηνύματα. Δεν χρειάζεται να γνωρίζετε αναγνωριστικά Threema — χρησιμοποιήστε απλώς το όνομα του εργαζομένου ή του πελάτη: 

"Στείλε ένα μήνυμα στον Max Muster: Το ραντεβού σας είναι αύριο στις 14:00."
"Στείλε στην Anna Beispiel ένα μήνυμα: Η βάρδια αντικαταστάθηκε."
"Ειδοποίησε τον Peter Müller ότι η υπηρεσία του τη Δευτέρα ακυρώνεται."

Ο Klacksy αναζητά αυτόματα το καταχωρημένο αναγνωριστικό Threema του παραλήπτη και χρησιμοποιεί τον διαμορφωμένο πάροχο Threema. Η αποστολή είναι για εσάς πλήρως διαφανής — εργάζεστε με ονόματα, ο Klacksy αναλαμβάνει τα υπόλοιπα.

Προϋπόθεση: Ο παραλήπτης πρέπει να έχει καταχωρημένο το 8-ψήφιο αναγνωριστικό Threema στο Klacks (στη Διεύθυνση → Στοιχεία επικοινωνίας). Το αναγνωριστικό Threema βρίσκει ο εργαζόμενος στην εφαρμογή Threema του στο «Το προφίλ μου».

Εισερχόμενα μηνύματα

Η σύνδεση Threema δεν υποστηρίζει λήψη — οι απαντήσεις σε απεσταλμένα μηνύματα δεν μεταφέρονται στο Klacks. Η λήψη θα απαιτούσε τη λειτουργία end-to-end του Threema Gateway· η σύνδεση με το Klacks χρησιμοποιεί τη λειτουργία Basic. Τα εισερχόμενα μηνυμάτων επομένως δεν εμφανίζουν εισερχόμενα μηνύματα για αυτόν τον πάροχο.
