Εκπαίδευση Klacksy - Οδηγίες

Τι είναι το εργαλείο εκπαίδευσης;

Το εργαλείο εκπαίδευσης ελέγχει την πλοήγηση εντός σελίδας του chatbot Klacksy. Όταν ένας χρήστης λέει ή γράφει "Klacksy δείξε μου τις διευθύνσεις", ο Klacksy πλοηγείται στην κατάλληλη σελίδα και κάνει κύλιση στην αντίστοιχη ενότητα.

Για να λειτουργήσει αυτό, ο Klacksy χρειάζεται για κάθε άγκυρα σε μια σελίδα μια λίστα συνωνύμων σε κάθε γλώσσα (π.χ. "Adressen", "Kunden", "Kontakte" για τον στόχο addresses).

Καρτέλα "Στόχοι"

Λίστα όλων των αγκυρών που βρέθηκαν στο frontend (χαρακτηριστικά HTML data-klacksy-target). Φίλτρα κατάστασης:

  • pending: Η άγκυρα υπάρχει, αλλά δεν υπάρχουν ακόμη συνώνυμα
  • generated: Τα συνώνυμα δημιουργήθηκαν αυτόματα, χρειάζονται έλεγχο
  • reviewed: Τα συνώνυμα εγκρίθηκαν από διαχειριστή
  • needs-review: Σημειωμένο για επανέλεγχο

Κάνοντας κλικ σε έναν στόχο ανοίγει ο επεξεργαστής συνωνύμων από κάτω. Εκεί μπορούν να προστεθούν, να διαγραφούν συνώνυμα και να εγκριθούν με "Αποθήκευση ως ελεγμένο".

Καρτέλα "Ανατροφοδοτήσεις"

Δείχνει εισαγωγές χρηστών που ο Klacksy δεν μπόρεσε να αντιστοιχίσει (δεν βρέθηκε κατάλληλο συνώνυμο). Από αυτή τη λίστα μπορεί να αναγνωριστεί ποια συνώνυμα λείπουν ακόμη.

Καρτέλα "Μετρήσεις"

Επισκόπηση όλων των στόχων ανά κατάσταση. Βοηθά στην παρακολούθηση της προόδου εκπαίδευσης.

Pipeline δημιουργίας (CLI)

Όταν τα templates αποκτήσουν νέες άγκυρες data-klacksy-target, πρέπει να αναδημιουργηθούν το manifest και τα αρχικά συνώνυμα. Οι παρακάτω εντολές εκτελούνται επίσης αυτόματα στο CI και στο Husky pre-commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Σάρωση templates → navigation-targets.json με όλες τις άγκυρες
npm run scan:targets

# 2a. Δημιουργία αρχικών συνωνύμων (όλες οι 4 βασικές + 22 γλώσσες πρόσθετων, ~2,5 ώ)
npm run generate:synonyms

# 2b. Μόνο βασικές γλώσσες (de/en/fr/it) — γρήγορο, περίπου 9 λεπτά
npm run generate:synonyms -- --core-only

# 2c. Συμπλήρωση μόνο των γλωσσών πρόσθετων που λείπουν — περίπου 45 λεπτά
npm run generate:synonyms -- --plugins-only

# 3. Έλεγχος συνέπειας λέξης αφύπνισης
npm run wake-word-lint

Σημαντικό: Στο npm run πρέπει να υπάρχει --, ώστε οι επιλογές να προωθηθούν στο script. Χωρίς το -- το npm καταπίνει τη σημαία και το script εκτελείται στην τυπική λειτουργία.

Εναλλακτικά χωρίς npm: npx tsx tools/generate-synonyms.ts --core-only.

Κλειδί API

Το κλειδί API του LLM αναζητείται με αυτή τη σειρά:

  1. Μεταβλητή περιβάλλοντος SYNONYM_LLM_API_KEY
  2. Πίνακας βάσης δεδομένων llm_providers (πάροχος deepseek, is_enabled = true) — αυτόματα μέσω κλήσης psql
  3. Αλλιώς μήνυμα σφάλματος

Ο προεπιλεγμένος πάροχος είναι ο DeepSeek. Άλλος πάροχος μέσω SYNONYM_LLM_PROVIDER_ID=anthropic (ή άλλος διαμορφωμένος πάροχος LLM στις ρυθμίσεις).

Βήμα 1 - scan:targets

Σαρώνει όλα τα templates Angular για χαρακτηριστικά data-klacksy-target και δημιουργεί το manifest Application/Skills/Definitions/navigation-targets.json. Κάθε νέα άγκυρα εμφανίζεται στη συνέχεια στην καρτέλα "Στόχοι" με κατάσταση pending.

Βήμα 2 - generate:synonyms

Δημιουργεί για κάθε νέα άγκυρα αρχικά συνώνυμα από το data-klacksy-label-key και την κατηγορία. Κατάσταση μετά: generated (πρέπει να ελεγχθεί από διαχειριστή).

Το script γράφει σημεία ελέγχου manifest κάθε 5 στόχους, ώστε μια διακοπή να μη χάνει ήδη δημιουργημένα δεδομένα.

Βήμα 3 - wake-word-lint

Ελέγχει τη συνέπεια της παραλλαγής της λέξης αφύπνισης (Hallo Klacksy / Hey Klacksy / ...) σε όλες τις γλώσσες. Αποτρέπει τα συνώνυμα να αντικαταστήσουν τη λέξη αφύπνισης.

Λειτουργία φωνής

Το εικονίδιο μικροφώνου στη συνομιλία ενεργοποιεί τη λειτουργία φωνής. Μόλις είναι ενεργή:

  • Το μικρόφωνο ακούει, μεταγράφει συνεχώς
  • Σε σύντομη σιωπή → αυτόματη αποστολή της μέχρι τώρα μεταγραφής

Σημαντικό: Μόλις αρχίσεις να πληκτρολογείς στο πεδίο κειμένου, η λειτουργία φωνής τερματίζεται αυτόματα — αλλιώς το μικρόφωνο θα αντικαθιστούσε το κείμενο που πληκτρολόγησες με δικές του μεταγραφές και θα το έστελνε πρόωρα.

Τυπικός κύκλος εκπαίδευσης

  1. Προσθήκη άγκυρας στο template: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Επανεκκίνηση API (η cache διαβάζεται ξανά κατά την εκκίνηση)
  4. Άνοιγμα καρτέλας "Στόχοι" → οι νέοι στόχοι εμφανίζονται με κατάσταση generated
  5. Έλεγχος/συμπλήρωση συνωνύμων → "Αποθήκευση ως ελεγμένο" → κατάσταση reviewed
  6. Δοκιμή με τον Klacksy, π.χ. "Klacksy δείξε μου τις διευθύνσεις"
  7. Αν ο Klacksy δεν αντιστοιχίσει → καρτέλα "Ανατροφοδοτήσεις" → συμπλήρωση του συνωνύμου που λείπει
  8. Παρακολούθηση καρτέλας "Μετρήσεις" μέχρι όλα να είναι reviewed
