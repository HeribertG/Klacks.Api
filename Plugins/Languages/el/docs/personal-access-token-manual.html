Εγχειρίδιο Personal Access Tokens

Τι είναι τα Personal Access Tokens;

Τα Personal Access Tokens (PATs) είναι μακράς διαρκείας κλειδιά API, που επιτρέπουν σε εξωτερικά εργαλεία και υπηρεσίες ασφαλή πρόσβαση στο Klacks — χωρίς όνομα χρήστη και κωδικό πρόσβασης.

Τυπικές περιπτώσεις χρήσης:

  • MCP (Model Context Protocol) — επιτρέπει σε βοηθούς ΤΝ όπως το Claude Desktop άμεση πρόσβαση στις δεξιότητες του Klacksy
  • Πράκτορες και βοηθοί ΤΝ που εργάζονται με το Klacks μέσω MCP

Έννοια ασφάλειας

Το Klacks δεν αποθηκεύει ποτέ το token σε απλό κείμενο. Μετά τη δημιουργία αποθηκεύεται στη βάση δεδομένων αποκλειστικά ένα SHA-256 hash του token. Το ίδιο το token εμφανίζεται μόνο μία φορά, αμέσως μετά τη δημιουργία, και μετά δεν μπορεί πλέον να ανακτηθεί.

Σημείωση: Σημειώστε ή αντιγράψτε το token αμέσως μετά τη δημιουργία. Σε περίπτωση απώλειας πρέπει να δημιουργηθεί νέο token και να ανακληθεί το παλιό.

Δημιουργία token

Βήμα προς βήμα

  • Μεταβείτε στο Διαμόρφωση → Personal Access Tokens
  • Κάντε κλικ στο Δημιουργία νέου token
  • Δώστε ένα περιγραφικό όνομα (π.χ. Claude Desktop ή Πράκτορας ΤΝ προγραμματισμός)
  • Επιλέξτε την επιθυμητή διάρκεια ισχύος (1–730 ημέρες, προεπιλογή: 365 ημέρες)
  • Κάντε κλικ στο Δημιουργία
  • Αντιγράψτε αμέσως το token που εμφανίζεται — εμφανίζεται μόνο μία φορά

Μορφή token

klacks_pat_<τυχαία ακολουθία χαρακτήρων>

Κάθε token ξεκινά με το πρόθεμα klacks_pat_ ακολουθούμενο από μια κρυπτογραφικά ασφαλή τυχαία ακολουθία χαρακτήρων.

Διάρκεια ισχύος

ΔιάρκειαΠροτεινόμενη χρήση
1–30 ημέρεςΒραχυπρόθεσμες δοκιμές και ανάπτυξη
90–180 ημέρεςΠράκτορες ΤΝ με τακτική εναλλαγή
365 ημέρες (προεπιλογή)Μόνιμες ενσωματώσεις (π.χ. Claude Desktop)
730 ημέρεςΜακροπρόθεσμες ενσωματώσεις συστημάτων

Λειτουργία πρόσβασης

Κατά τη δημιουργία ορίζετε τι επιτρέπεται να κάνει ένας εξωτερικός πράκτορας με το διακριτικό:

  • Μόνο ανάγνωση (προεπιλογή) — ο πράκτορας βλέπει και χρησιμοποιεί αποκλειστικά εργαλεία ανάγνωσης. Κάθε προσπάθεια αλλαγής δεδομένων απορρίπτεται.
  • Ανάγνωση και εγγραφή — ο πράκτορας μπορεί επιπλέον να αλλάζει δεδομένα χωρίς να εγκρίνει άνθρωπος κάθε μεμονωμένη αλλαγή. Επιλέξτε αυτή τη λειτουργία μόνο για πράκτορες στους οποίους εμπιστεύεστε αλλαγές.

Η λειτουργία εμφανίζεται στη λίστα διακριτικών και δεν μπορεί να αλλάξει εκ των υστέρων· αν χρειαστεί, δημιουργήστε νέο διακριτικό. Τα υπάρχοντα διακριτικά και όσα εκδίδονται μέσω σύνδεσης OAuth (π.χ. ενός συνδέσμου MCP) έχουν τη λειτουργία «Ανάγνωση και εγγραφή».

Χρήση του token

Bearer token στην κεφαλίδα HTTP

Το token μεταδίδεται ως Bearer token στην κεφαλίδα Authorization κάθε αιτήματος MCP προς το endpoint /mcp:

Authorization: Bearer klacks_pat_...

Διαμόρφωση MCP με το Claude Desktop

Το endpoint MCP (/mcp) επιτρέπει σε βοηθούς ΤΝ όπως το Claude Desktop άμεση πρόσβαση σε όλες τις δεξιότητες του Klacksy — αναζήτηση στοιχείων εργαζομένων, προγραμματισμό βαρδιών, διαχείριση ομάδων και πολλά άλλα.

Διαμόρφωση στην εφαρμογή Claude Desktop (claude_desktop_config.json):

{
  "mcpServers": {
    "klacks": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://<το-domain-σας-klacks>/mcp",
        "--header",
        "Authorization:${AUTH_HEADER}"
      ],
      "env": {
        "AUTH_HEADER": "Bearer klacks_pat_..."
      }
    }
  }
}

Αντικαταστήστε το <το-domain-σας-klacks> με τη διεύθυνση της εγκατάστασης Klacks και το klacks_pat_... με το token που δημιουργήσατε.

Σημείωση: Τα tokens λειτουργούν μόνο για την πρόσβαση MCP των πρακτόρων AI (endpoint /mcp). Το REST API του Klacks (π.χ. /api/clients) δεν τα δέχεται· απαιτεί το token σύνδεσης.

Διαχείριση και ασφάλεια

Επισκόπηση των tokens

Στο Διαμόρφωση → Personal Access Tokens βλέπετε όλα τα tokens σας με όνομα, ημερομηνία δημιουργίας, ημερομηνία λήξης και τελευταία χρήση. Το token σε απλό κείμενο δεν εμφανίζεται ποτέ σε αυτή την προβολή.

Ανάκληση token

Ένα token μπορεί να ανακληθεί ανά πάσα στιγμή. Μετά την ανάκληση, όλα τα αιτήματα με αυτό το token απορρίπτονται αμέσως. Ανακαλέστε τα tokens αμέσως όταν:

  • Το token διαρρεύσει κατά λάθος
  • Μια συσκευή ή υπηρεσία δεν χρησιμοποιείται πλέον
  • Παρατηρήσετε ύποπτη δραστηριότητα

Λήξη

Τα ληγμένα tokens απορρίπτονται αυτόματα. Το Klacks εμφανίζει στην επισκόπηση τα tokens που λήγουν τις επόμενες 30 ημέρες, ώστε να μπορείτε να δημιουργήσετε εγκαίρως νέα tokens.

Συμβουλές ασφάλειας

  • Χρησιμοποιήστε ξεχωριστό token για κάθε υπηρεσία ή εργαλείο
  • Επιλέξτε περιγραφικά ονόματα για σαφή αντιστοίχιση των tokens
  • Μην αποθηκεύετε ποτέ τα tokens σε απλό κείμενο σε συστήματα διαχείρισης εκδόσεων
  • Εναλλάσσετε τα tokens τακτικά
  • Ανακαλέστε αμέσως τα tokens σε περίπτωση υποψίας κατάχρησης

Κάθε token είναι συνδεδεμένο με τον λογαριασμό χρήστη σας. Μέσω MCP διαθέτει τα δικαιώματα του λογαριασμού σας, το πολύ όμως σε επίπεδο Supervisor: ακόμη και αν ο λογαριασμός σας είναι διαχειριστή, το token δεν έχει ποτέ δικαιώματα διαχειριστή. Επιπλέον, η λειτουργία πρόσβασης περιορίζει όσα μπορεί να κάνει ο πράκτορας: με «Μόνο ανάγνωση» χρησιμοποιεί αποκλειστικά λειτουργίες ανάγνωσης· με «Ανάγνωση και εγγραφή» πραγματοποιεί αλλαγές χωρίς περαιτέρω επιβεβαίωση. Χειριστείτε τα tokens με την ίδια προσοχή όπως τον κωδικό πρόσβασής σας.
