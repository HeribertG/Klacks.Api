Εγχειρίδιο σεναρίων μακροεντολών

Εισαγωγή

Ο επεξεργαστής μακροεντολών επιτρέπει τη συγγραφή σεναρίων που χρησιμοποιούνται ως βάση υπολογισμού για υπηρεσίες, εργασιακές δραστηριότητες κ.λπ.

Παραδείγματα χρήσης:

  • Ακριβής υπολογισμός ωρών για άδεια ή στρατιωτική θητεία βάσει ποσοστού απασχόλησης
  • Υπολογισμός προσαυξήσεων για νυχτερινή εργασία, σαββατοκύριακα και αργίες
  • Ευέλικτη προσαρμογή σε νέες απαιτήσεις

Σημείωση: Ο διερμηνέας σεναρίων εκτελείται σε ασφαλές περιβάλλον sandbox χωρίς πρόσβαση στο σύστημα αρχείων ή στο δίκτυο. Δεν είναι δυνατή η εκτέλεση κακόβουλου κώδικα.

Λειτουργία και Κατηγορία

Εκτός από το όνομα και το περιεχόμενο του σεναρίου, κάθε μακροεντολή στη λίστα μακροεντολών έχει δύο επιπλέον ιδιότητες, που ορίζονται μέσω αναπτυσσόμενων μενού στον επεξεργαστή: Κατηγορία και Λειτουργία. Και οι δύο είναι καθαρά μεταδεδομένα – βρίσκονται εκτός του σεναρίου και δεν μεταβάλλουν τον υπολογισμό του, αλλά καθορίζουν πώς το Klacks βρίσκει και αναθέτει αυτόματα τη σωστή μακροεντολή.

Κατηγορία

Η κατηγορία αντιστοιχίζει μια μακροεντολή σε έναν λειτουργικό τομέα εφαρμογής:

ΚατηγορίαΧρήση
Μη καθορισμένοΚανένας ιδιαίτερος τομέας εφαρμογής (προεπιλογή για νέες μακροεντολές)
ΥπηρεσίαΥπολογισμός προσαυξήσεων για τακτικές υπηρεσίες (νυχτερινή, σαββατοκύριακου, αργίας)
ΔιακοπέςΥπολογισμός ωρών για άδεια
ΑσθένειαΥπολογισμός ωρών για ασθένεια
ΑτύχημαΥπολογισμός ωρών για ατύχημα
Εργαστήριο (αμειβόμενο)Αμειβόμενος χρόνος εργαστηρίου/εκπαίδευσης
Εργαστήριο (μη αμειβόμενο)Μη αμειβόμενος χρόνος εργαστηρίου/εκπαίδευσης

Η κατηγορία Υπηρεσία έχει ιδιαίτερο ρόλο: Οι νέες υπηρεσίες που δημιουργούνται λαμβάνουν αυτόματα την τυπική μακροεντολή αυτής της κατηγορίας (βλ. "Λειτουργία" παρακάτω). Οι ήδη υπάρχουσες υπηρεσίες δεν τροποποιούνται ποτέ εκ των υστέρων.

Λειτουργία: Προσαρμοσμένο, Τυπικό, Τυπικό (προσθετικό)

Η λειτουργία ταξινομεί τον ρόλο μιας μακροεντολής εντός της κατηγορίας της:

ΛειτουργίαΣημασία
ΠροσαρμοσμένοΕλεύθερη μακροεντολή χωρίς ιδιαίτερο ρόλο. Επιτρέπονται όσες θέλετε ανά κατηγορία.
ΤυπικόΗ τυπική μακροεντολή αυτής της κατηγορίας – ανατίθεται αυτόματα σε νέες υπηρεσίες. Το πολύ ΜΙΑ μακροεντολή ανά κατηγορία μπορεί να φέρει αυτή τη λειτουργία.
Τυπικό (προσθετικό)Εναλλακτική τυπική μακροεντολή με προσθετική λογική προσαυξήσεων (βλ. παρακάτω). Επίσης το πολύ μία ανά κατηγορία, επιπλέον της μακροεντολής "Τυπικό".

Σημαντικό: Η λειτουργία από μόνη της δεν υπολογίζει τίποτα – είναι μια ετικέτα. Το αν οι προσαυξήσεις υπολογίζονται με λογική "ο υψηλότερος κερδίζει" (μετράει μόνο ο υψηλότερος ισχύων συντελεστής) ή προσθετικά (όλοι οι ισχύοντες συντελεστές αθροίζονται) καθορίζεται από το ίδιο το σενάριο. Οι δύο μακροεντολές κατηγορίας "Υπηρεσία" που παραδίδονται μαζί δείχνουν τη διαφορά πάνω στην ίδια βασική δομή:

  • "AllShift" (Λειτουργία: Τυπικό) – προσδιορίζει ανά χρονικό τμήμα την υψηλότερη ισχύουσα προσαύξηση (νυχτερινή/WE1/WE2/WE3/αργίας) και χρησιμοποιεί μόνο αυτήν.
  • "AllShiftAdditive" (Λειτουργία: Τυπικό (προσθετικό)) – υπολογίζει τη νυχτερινή, σαββατοκύριακου και αργίας προσαύξηση ανεξάρτητα η μία από την άλλη και τις αθροίζει.

Ποια από τις δύο ανατίθεται αυτόματα κατά τη δημιουργία μιας νέας υπηρεσίας καθορίζεται από μια ρύθμιση σε επίπεδο εγκατάστασης ("προσθετικό" ή "ο υψηλότερος συντελεστής κερδίζει"). Ανά υπηρεσία, η μακροεντολή μπορεί στη συνέχεια να αλλάξει χειροκίνητα ανά πάσα στιγμή – επομένως είναι δυνατή και η μικτή λειτουργία.

Μοναδικότητα: Αν προσπαθήσετε να αποθηκεύσετε και μια δεύτερη μακροεντολή της ίδιας κατηγορίας ως "Τυπικό" ή "Τυπικό (προσθετικό)", ο επεξεργαστής εμποδίζει την αποθήκευση και αναφέρει το όνομα της ήδη ανατεθειμένης μακροεντολής. Ορίστε πρώτα τη λειτουργία της σε "Προσαρμοσμένο".

Δεν συνιστώνται χειροκίνητες τροποποιήσεις στις "AllShift"/"AllShiftAdditive". Αυτές οι δύο μακροεντολές είναι ο μηχανισμός μέσω του οποίου εφαρμόζονται αυτόματα οι προσαρμογές ανά χώρα και κλάδο: Όσο τις αφήνετε αμετάβλητες, το Klacks τις διατηρεί αυτόματα συγχρονισμένες με τους κανόνες που ταιριάζουν στη χώρα ή τον κλάδο σας. Αν επεξεργαστείτε χειροκίνητα μία από τις δύο, από εκείνη τη στιγμή θεωρείται προσαρμοσμένη από τον πελάτη – μελλοντικές αυτόματες ενημερώσεις χώρας/κλάδου για αυτή τη μακροεντολή δεν θα εφαρμόζονται πλέον σιωπηρά, αλλά θα αποτυγχάνουν με σύγκρουση μέχρι να επιλύσετε χειροκίνητα τη διαφορά. Αν χρειάζεστε δική σας λογική προσαυξήσεων, δημιουργήστε αντ' αυτού μια νέα μακροεντολή με λειτουργία "Προσαρμοσμένο" και αναθέστε την συγκεκριμένα στις σχετικές υπηρεσίες.

Συναρτήσεις και διαδικασίες

Σημαντικό: Οι συναρτήσεις (FUNCTION) και οι διαδικασίες (SUB) πρέπει να ορίζονται πριν από την πρώτη κλήση. Ο διερμηνέας διαβάζει τον κώδικα από πάνω προς τα κάτω: μια συνάρτηση ή διαδικασία είναι γνωστή μόνο μετά την επεξεργασία του ορισμού της.

SUB (διαδικασία χωρίς τιμή επιστροφής)

SUB ypologise(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (συνάρτηση με τιμή επιστροφής)

FUNCTION diplasiazo(x)
    diplasiazo = x * 2
ENDFUNCTION

DIM apotelesma
apotelesma = diplasiazo(21)
OUTPUT 1, apotelesma

Επιστροφή τιμών (OUTPUT)

OUTPUT τύπος, τιμή

Τα τύπος και τιμή είναι δύο εκφράσεις χωρισμένες με κόμμα· και οι δύο είναι προαιρετικές (προεπιλογή 0 ή "" αντίστοιχα, αν παραλειφθούν). Μια μακροεντολή μπορεί να περιέχει όσες γραμμές OUTPUT θέλει – κάθε μία παράγει τη δική της τιμή επιστροφής. Το Klacks αξιολογεί όμως μόνο τους παρακάτω τύπους:

ΤύποςΣημασία
1Κύριο αποτέλεσμα (ώρες ή συνολικό ποσό) – λαμβάνεται υπόψη ακόμη και με τιμή 0
10Νυχτερινή προσαύξηση
11Προσαύξηση για ημέρα σαββατοκύριακου 1 (π.χ. Σάββατο)
12Προσαύξηση για ημέρα σαββατοκύριακου 2 (π.χ. Κυριακή)
13Προσαύξηση για ημέρα σαββατοκύριακου 3 (τρίτη ρυθμιζόμενη ημέρα σαββατοκύριακου)
14Προσαύξηση αργίας

Οι γραμμές προσαύξησης (τύπος 10-14) με τιμή 0 αγνοούνται – μια μακροεντολή δεν χρειάζεται δηλαδή να εκδίδει ξεχωριστή γραμμή για κάθε τύπο προσαύξησης, παρά μόνο για τις προσαυξήσεις που πράγματι ισχύουν. Τιμές που δεν μπορούν να ερμηνευθούν ως αριθμός παραλείπονται.

Κατά την αποθήκευση, η μακροεντολή μεταγλωττίζεται υποχρεωτικά και εκτελείται δοκιμαστικά μία φορά με ουδέτερες τιμές δοκιμής. Σφάλματα σύνταξης και εκτέλεσης (π.χ. μη ισορροπημένες παρενθέσεις ή μια εκκρεμής έκφραση) εμφανίζονται έτσι αξιόπιστα αντί να οδηγούν σιωπηρά σε μια μακροεντολή χωρίς λειτουργία.

Παράδειγμα: Υπολογισμός προσαυξήσεων ("AllShift")

Η τυπική μακροεντολή που παραδίδεται για την κατηγορία "Υπηρεσία". Υπολογίζει προσαυξήσεις για νυχτερινή εργασία, αργία και τις τρεις ρυθμιζόμενες ημέρες σαββατοκύριακου με σωστή διαχείριση βαρδιών που υπερβαίνουν τα μεσάνυχτα (τμηματοποίηση) και εφαρμόζει ανά τμήμα τον υψηλότερο ισχύοντα συντελεστή (ο υψηλότερος κερδίζει). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Επεξήγηση

  • Τμηματοποίηση: Για βάρδιες που υπερβαίνουν τα μεσάνυχτα (π.χ. 22:00-06:00), η βάρδια χωρίζεται σε δύο τμήματα (μέχρι τα μεσάνυχτα / από τα μεσάνυχτα), καθένα με τη δική του σημαία ημέρας εβδομάδας/αργίας
  • SegBonusForType: Υπολογίζει την προσαύξηση για ένα τμήμα και έναν συγκεκριμένο τύπο προσαύξησης (10-14) λαμβάνοντας υπόψη τις νυχτερινές, αργιών και σαββατοκύριακου προσαυξήσεις
  • WE1/WE2/WE3 αντί Σα/Κυ: Οι weekendday1-3 καθιστούν τις ημέρες σαββατοκύριακου ρυθμιζόμενες (δεν έχει κάθε χώρα Σάββατο/Κυριακή ως σαββατοκύριακο)
  • Υψηλότερη προσαύξηση ανά τμήμα: Οι NRate/DRate προσδιορίζουν αντίστοιχα τον υψηλότερο ισχύοντα συντελεστή για τις νυχτερινές ή τις ημερήσιες ώρες – ο υψηλότερος κερδίζει, χωρίς σώρευση
  • HolidayNextDay: Λαμβάνει υπόψη αν η επόμενη ημέρα είναι αργία (σημαντικό για νυχτερινές βάρδιες που υπερβαίνουν τα μεσάνυχτα)
  • Πολλαπλές γραμμές OUTPUT: Η γραμμή 1 δίνει το συνολικό άθροισμα, οι γραμμές 10-14 δίνουν τα επιμέρους ποσά προσαυξήσεων (βλ. ενότητα "Επιστροφή τιμών")

Η προσθετική παραλλαγή ("AllShiftAdditive")

Η μακροεντολή Τυπικό (προσθετικό) της ίδιας κατηγορίας έχει πανομοιότυπες γραμμές IMPORT και την ίδια βασική δομή – διαφέρει μόνο η SegBonusForType: αντί του υψηλότερου συντελεστή, υπολογίζεται ανεξάρτητα για κάθε τύπο προσαύξησης αν ισχύει, και όλα τα ισχύοντα ποσά αθροίζονται στο τέλος (δεν υπάρχει πια "ο υψηλότερος κερδίζει"): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Αν μια νυχτερινή βάρδια πέφτει π.χ. επιπλέον σε αργία, στην "AllShift" λαμβάνει μόνο τον υψηλότερο από τους δύο συντελεστές, ενώ στην "AllShiftAdditive" λαμβάνει νυχτερινή και προσαύξηση αργίας μαζί. Το υπόλοιπο του σεναρίου (τμηματοποίηση, άθροιση, γραμμές OUTPUT) είναι πανομοιότυπο με την "AllShift" παραπάνω.
