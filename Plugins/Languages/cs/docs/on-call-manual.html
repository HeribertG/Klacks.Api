Pohotovostní a záložní služba

Tato nastavení určují, zda se pohotovostní a záložní služby zaznamenávají a jakým podílem se při nich odsloužený čas počítá jako pracovní doba. Slouží jako výchozí nastavení pro celý podnik pro nově naplánované služby.

Pohotovostní služba aktivována

Zapíná nebo vypíná celou logiku pohotovostní služby. Je-li tato možnost deaktivována, ostatní pole se ignorují a prezenční ani pohotovostní čas se nepočítá samostatně.

  • Výchozí stav: deaktivováno.

Prezenční služba se počítá jako (%)

Podíl aktivní přítomnosti na místě, který se započítává jako běžná pracovní doba.

  • Rozsah hodnot: 0 až 100 procent.
  • Výchozí: 100 (prezenční čas se plně počítá jako pracovní doba).

Pohotovostní služba se počítá jako (%)

Podíl čisté pohotovostní služby (dosažitelnost bez aktivního nasazení), který se započítává jako pracovní doba.

  • Rozsah hodnot: 0 až 100 procent.
  • Výchozí: 0 (pohotovostní služba se nepočítá jako pracovní doba).

Zahrnout do limitů období

Určuje, zda se započítaný pohotovostní a záložní čas promítne do limitů období (např. maximální měsíční nebo roční hodiny).

  • Aktivní: započítaný čas se odečítá z limitů období.
  • Výchozí stav: deaktivováno.
