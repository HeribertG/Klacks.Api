Nastavení WhatsApp

Požadavky

Chcete-li odesílat a přijímat zprávy přes WhatsApp pomocí Klacks, potřebujete vývojářský účet Meta a aplikaci Meta s aktivovaným produktem WhatsApp. Klacks používá pro odesílání WhatsApp Cloud API platformy Meta Business a pro příjem Meta webhooky.

Poznámka: Za nastavení a testování se neplatí žádné poplatky. Při vytvoření aplikace poskytne Meta automaticky bezplatné testovací telefonní číslo.

Důležité — číslo odesílatele není vaše soukromé číslo. Telefonní číslo, které se již používá v běžné aplikaci WhatsApp, nelze registrovat pro Cloud API, a registrované číslo už nelze používat s WhatsApp Messenger. Použijte proto testovací číslo poskytnuté Metou nebo vlastní, výhradně firemně používané číslo. Váš soukromý WhatsApp v mobilním telefonu slouží jako příjemce pro testování — nikoli jako odesílatel.

Krok 1 — Vytvoření aplikace Meta

  1. Otevřete developers.facebook.com/apps a klikněte na Create app.
  2. Jako případ použití vyberte Other a jako typ aplikace Business.
  3. V dashboardu klikněte u produktu WhatsApp na Set up. Přitom se automaticky vytvoří a zaregistruje testovací telefonní číslo.
  4. V levé navigaci přejděte na WhatsApp → API Setup.
  5. Poznamenejte si Phone number ID a vytvořte přes Generate access token přístupový token.
  6. Poznamenejte si v App settings → Basic hodnotu App Secret — je potřeba pro ověření podpisu příchozích zpráv.

Pozor — dvě podobná ID: V panelu API Setup jsou Phone number ID a WhatsApp Business Account ID přímo pod sebou. Klacks potřebuje Phone number ID. S nesprávným ID hlásí test spojení přesto úspěch, ale každé odeslání selže.

Pozor — platnost tokenu: Token vytvořený přes Generate access token je dočasný testovací token a po krátké době vyprší. Pro trvalý provoz vytvořte v Meta Business Manageru trvalý token přes systémového uživatele.

Krok 2 — Povolení čísla příjemce

Testovací číslo smí odesílat pouze předem povoleným příjemcům. Přidejte v panelu API Setup pod To → Manage phone number list své číslo WhatsApp. Meta odešle na toto číslo potvrzovací kód, který musíte zadat.

Bez tohoto kroku Meta odmítne každé odeslání na toto číslo. Jakmile později použijete vlastní ověřené firemní číslo, povolení odpadá.

Krok 4 — 24hodinové okno

WhatsApp se zde zásadně liší od Telegramu nebo Slacku. Volné textové zprávy smí firma odesílat pouze tehdy, dokud je otevřené zákaznické okno. Toto okno otevírá příjemce tím, že napíše na vaše číslo WhatsApp. Zůstává otevřené 24 hodin a prodlužuje se s každou další zprávou příjemce.

Mimo toto okno povoluje Meta výhradně předem schválené šablony zpráv. Klacks odesílá v současnosti výhradně volné textové zprávy, a nemůže tak zahájit konverzaci sám od sebe.

Co to pro vás znamená: Požádejte jednorázově své zaměstnance, aby poslali zprávu na číslo WhatsApp Klacks. Poté je odesílání možné po dobu 24 hodin a každá odpověď okno prodlouží. Pokud je zavřené, ohlásí odeslání chybu — nejde o problém konfigurace, ale o pravidlo WhatsApp.

Pokud potřebujete zaměstnance zastihnout nezávisle na tomto okně, jsou lepšími poskytovateli Telegram nebo Signal — tam toto omezení neexistuje.

Krok 5 — Odesílání zpráv přes chatbota (Klacksy)

Jakmile je poskytovatel WhatsApp nakonfigurován a aktivován, může chatbot Klacksy odesílat zprávy přes WhatsApp. Použijte jméno zaměstnance: 

"Pošli zprávu Max Muster: Váš termín je zítra ve 14:00."
"Pošli Anna Beispiel zprávu: Směna byla vyměněna."

Jako příjemce slouží telefonní číslo v mezinárodním formátu bez úvodní nuly a bez znaménka plus (např. 41791234567 pro 079 123 45 67). Odesílání je pro vás zcela transparentní — vy pracujete se jmény, o zbytek se stará Klacksy.

Předpoklad: Číslo WhatsApp musí být propojeno s odpovídajícím kontaktem Klacks (v části Adresa → Kontaktní údaje) a 24hodinové okno z kroku 4 musí být otevřené.

Krok 6 — Příjem příchozích zpráv (webhooky)

Aby se příchozí zprávy WhatsApp zobrazovaly v Klacks, musí být nakonfigurován webhook aplikace Meta. Uložte a aktivujte poskytovatele v Klacks před zadáním Callback URL — Meta ověří URL okamžitě verifikačním požadavkem, na který Klacks automaticky odpoví pomocí verify tokenu.

  1. Otevřete svou aplikaci Meta a přejděte na WhatsApp → Configuration.
  2. Klikněte u Webhook na Edit a zadejte:
    • Callback URL: webhook URL zobrazenou v Klacks 
      https://{vaše-doména}/api/messaging/webhook/whatsapp
    • Verify token: přesně stejnou hodnotu, kterou jste zadali v kroku 3 do pole Verify token
  3. Klikněte na Verify and save.
  4. V části Webhook fields se přihlaste k odběru pole messages.
  5. Příchozí zprávy se nyní zobrazují v reálném čase v Messaging Inbox. Klacks přitom ověřuje podpis každého požadavku (X-Hub-Signature-256) pomocí uloženého App Secret.

Callback URL musí být zvenčí dostupná přes HTTPS. Při instalaci ve firemní síti bez veřejné adresy odesílání funguje, ale nelze přijímat žádné zprávy.
