Nastavení Threema Gateway

Požadavky

Chcete-li odesílat zprávy přes Threema, potřebujete účet u Threema Gateway. Threema je švýcarský poskytovatel, ve Švýcarsku je rozšířený a šetrný k ochraně osobních údajů (švýcarský DSG).

Důležité: Napojení na Threema je určeno pouze pro odesílání. Příjem příchozích zpráv by vyžadoval end-to-end režim brány a není podporován. Odesílání je zpoplatněné — každá odeslaná zpráva spotřebuje kredity.

Krok 1 — Vytvoření účtu Threema Gateway

  1. Zaregistrujte se na gateway.threema.ch.
  2. Požádejte o Gateway ID v základním režimu (např. *MYGATEWAY). Vždy začíná hvězdičkou (*) a musí být schváleno Threemou.
  3. Zakupte si kredity — bez kreditu nelze odesílat žádné zprávy.
  4. Poznamenejte si API Secret z dashboardu Gateway.

Poznámka: S API Secret zacházejte jako s heslem. Nesdílejte jej veřejně a ukládejte jej bezpečně.

Krok 2 — Konfigurace Threema v Klacks

  1. Přejděte na Nastavení → Poskytovatelé zpráv.
  2. Klikněte na Přidat.
  3. Vyplňte pole následovně:

  2. Otestujte spojení pomocí tlačítka Test v seznamu poskytovatelů. Test ověří přístupové údaje pomocí dotazu na stav kreditu Gateway.

Krok 3 — Odesílání zpráv přes chatbota (Klacksy)

Jakmile je poskytovatel Threema nakonfigurován a aktivován, může chatbot Klacksy odesílat zprávy. Nemusíte znát Threema ID — stačí použít jméno zaměstnance nebo klienta: 

"Pošli zprávu Max Muster: Váš termín je zítra ve 14:00."
"Pošli Anna Beispiel zprávu: Směna byla vyměněna."
"Informuj Peter Müller, že jeho směna v pondělí odpadá."

Klacksy automaticky vyhledá uložené Threema ID příjemce a použije nakonfigurovaného poskytovatele Threema. Odesílání je pro vás zcela transparentní — vy pracujete se jmény, o zbytek se stará Klacksy.

Předpoklad: U příjemce musí být v Klacks uloženo 8místné Threema ID (v části Adresa → Kontaktní údaje). Threema ID najde zaměstnanec ve své aplikaci Threema pod „Můj profil".

Příchozí zprávy

Napojení na Threema nepodporuje příjem zpráv — odpovědi na odeslané zprávy se do Klacks nepřenášejí. Příjem by vyžadoval end-to-end režim brány Threema; napojení Klacks používá základní režim. Messaging Inbox proto pro tohoto poskytovatele nezobrazuje žádné příchozí zprávy.
