Nastavení Signal Messaging

Požadavky

Chcete-li odesílat zprávy Signal přes Klacks, potřebujete vlastní hostovanou instanci signal-cli-rest-api. Jde o open-source projekt, který zpřístupňuje Signal prostřednictvím REST rozhraní.

  • Na serveru musí být nainstalován Docker
  • Telefonní číslo, které bude registrováno u Signal (doporučeno dedikované číslo)
  • Docker image: bbernhard/signal-cli-rest-api

Důležité: Napojení na Signal je určeno pouze pro odesílání. Příchozí zprávy Signal Klacks nepřijímá.

Krok 1 — Nastavení signal-cli-rest-api

  1. Spusťte kontejner pomocí Dockeru: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Propojte své číslo Signal pomocí QR-link postupu: Otevřete v prohlížeči 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    a naskenujte zobrazený QR kód aplikací Signal na telefonu, na kterém je číslo registrováno (Nastavení → Propojená zařízení → Propojit zařízení). Kontejner se tím propojí jako druhé zařízení.
  3. Alternativně můžete číslo zaregistrovat samostatně přes API — podrobnosti naleznete v dokumentaci projektu.
  4. Otestujte API pomocí healthchecku: 
    curl http://localhost:8080/v1/about

Poznámka: Další podrobnosti ke konfiguraci naleznete v dokumentaci signal-cli-rest-api.

Krok 2 — Konfigurace Signal v Klacks

  1. Přejděte na Nastavení → Poskytovatelé zpráv.
  2. Klikněte na Přidat.
  3. Vyplňte pole následovně:

  1. Klikněte na Uložit.
  2. Otestujte spojení pomocí tlačítka Test v seznamu poskytovatelů. Test ověří, zda je zadané číslo v kontejneru registrováno.

Poznámka: Klacks odesílá zprávy přes endpoint POST /v2/send kontejneru.

Krok 3 — Odesílání zpráv přes chatbota (Klacksy)

Jakmile je poskytovatel Signal nakonfigurován a aktivován, může chatbot Klacksy odesílat zprávy. Nemusíte znát telefonní čísla — stačí použít jméno zaměstnance nebo klienta: 

"Pošli zprávu Max Muster: Váš termín je zítra ve 14:00."
"Pošli Anna Beispiel zprávu Signal: Směna byla vyměněna."
"Informuj Peter Müller, že jeho směna v pondělí odpadá."

Klacksy automaticky vyhledá uložené mobilní číslo příjemce a použije nakonfigurovaného poskytovatele Signal. Odesílání je pro vás zcela transparentní — vy pracujete se jmény, o zbytek se stará Klacksy.

Předpoklad: U příjemce musí být v Klacks uloženo mobilní číslo (v části Adresa → Kontaktní údaje) v mezinárodním formátu (např. +41791234567). I u hromadných zpráv se odesílání Signal opírá o uložené mobilní číslo.

Příchozí zprávy

Napojení na Signal nepodporuje příjem zpráv — odpovědi na odeslané zprávy se do Klacks nepřenášejí. Messaging Inbox proto pro tohoto poskytovatele nezobrazuje žádné příchozí zprávy.
