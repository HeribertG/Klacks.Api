Nastavení Viber bota

Požadavky

Chcete-li odesílat a přijímat zprávy přes Viber, potřebujete Viber bota, kterého vytvoříte prostřednictvím Viber Partner portálu. Viber je zvlášť oblíbený ve východní Evropě a na Blízkém východě.

Poznámka: Viber zkomercionalizoval používání botů — podle země a objemu zpráv mohou platit zpoplatněné modely. Zkontrolujte aktuální podmínky na partners.viber.com.

Krok 1 — Vytvoření Viber bota

  1. Zaregistrujte se na partners.viber.com.
  2. Vytvořte nového bota v Partner portálu.
  3. Poznamenejte si Auth Token z dashboardu bota.
  4. Nastavte jméno odesílatele (např. Klacks Bot).

Krok 2 — Konfigurace Viber v Klacks

  1. Přejděte na Nastavení → Poskytovatelé zpráv.
  2. Klikněte na Přidat.
  3. Vyplňte pole následovně:
PolePopisPříklad
NázevInterní jedinečný názevviber-bot
Zobrazovaný názevZobrazuje se v uživatelském rozhraníViber
Typ poskytovateleVyberte ViberViber
Auth TokenAuth Token z dashboardu bota4a5e6f7g8h9i...
Jméno odesílateleJméno, které se zobrazí příjemciKlacks Bot
Webhook URLVyplní se automaticky adresou vaší instance Klacks (needitovatelné)https://example.com/api/messaging/webhook/viber
AktivovánoZapíná/vypíná poskytovateleAno
  1. Klikněte na Uložit. Klacks přitom automaticky zaregistruje webhook u Viberu (set_webhook).
  2. Otestujte spojení pomocí tlačítka Test v seznamu poskytovatelů.

Důležité: Zobrazená webhook URL musí být veřejně dostupná přes HTTPS — jinak registrace webhooku při ukládání selže.

Krok 3 — Odesílání zpráv přes chatbota (Klacksy)

Jakmile je poskytovatel Viber nakonfigurován a aktivován, může chatbot Klacksy odesílat zprávy. Nemusíte znát Viber User ID — stačí použít jméno zaměstnance nebo klienta: 

"Pošli zprávu Max Muster: Váš termín je zítra ve 14:00."
"Pošli Anna Beispiel zprávu: Směna byla vyměněna."
"Informuj Peter Müller, že jeho směna v pondělí odpadá."

Klacksy automaticky vyhledá uloženou Viber User ID příjemce a použije nakonfigurovaného poskytovatele Viber. Odesílání je pro vás zcela transparentní — vy pracujete se jmény, o zbytek se stará Klacksy.

Důležité: Boti Viber mohou psát pouze uživatelům, kteří bota odebírají (zahájili 1:1 chat s botem). Příjemce tedy musí botovi nejprve poslat zprávu. Jeho Viber User ID se tím zjistí z příchozí zprávy (viditelné v Messaging Inbox) a uloží se u příjemce v části Adresa → Kontaktní údaje.

Krok 4 — Příjem příchozích zpráv

Příchozí zprávy Viber se přijímají automaticky přes webhook zaregistrovaný při uložení — není potřeba žádná další konfigurace.

  1. Uživatel vyhledá bota ve Viberu a pošle mu zprávu.
  2. Zpráva se zobrazí v reálném čase v Messaging Inbox.
  3. Převezměte Viber User ID odesílatele do kontaktních údajů zaměstnance, aby mu Klacksy mohl v budoucnu psát přímo.
