Nastavení KakaoTalk Messaging

Požadavky

Chcete-li odesílat zprávy přes KakaoTalk, potřebujete aplikaci na developers.kakao.com (Kakao Developers). KakaoTalk je dominantní messenger v Jižní Koreji. Napojení Klacks využívá Kakao Developer API („odeslání zprávy přátelům").

Důležitá omezení Kakao Developer API:

  • Napojení je určeno pouze pro odesílání — bez příjmu.
  • Access token je krátkodobý (cca 6 hodin) a musí být obnoven a znovu uložen mimo Klacks.
  • Zprávy lze odesílat pouze uživatelům, kteří jsou s aplikací propojeni jako Kakao „přátelé" a odesílání zpráv odsouhlasili.
  • Pro produktivní firemní zprávy (AlimTalk) je v Koreji nutný firemní kanál přes autorizované agentury — to toto napojení nepokrývá, využívá Developer API.

Krok 1 — Nastavení aplikace Kakao Developers

  1. Vytvořte aplikaci na developers.kakao.com.
  2. Aktivujte Kakao Login pro aplikaci.
  3. Povolte scopy talk_message a friends.
  4. Získejte access token prostřednictvím OAuth flow Kakao Login (uživatel, jehož jménem se odesílá, musí scopy odsouhlasit).

Poznámka: S access tokenem zacházejte jako s heslem. Nesdílejte jej veřejně a ukládejte jej bezpečně.

Krok 2 — Konfigurace KakaoTalk v Klacks

  1. Přejděte na Nastavení → Poskytovatelé zpráv.
  2. Klikněte na Přidat.
  3. Vyplňte pole následovně:

  2. Otestujte spojení pomocí tlačítka Test v seznamu poskytovatelů.

Důležité: Access token vyprší přibližně po 6 hodinách. Klacks jej automaticky neobnovuje — musíte jej obnovit externě (přes refresh-token flow od Kakao) a znovu jej uložit v Klacks.

Krok 3 — Odesílání zpráv přes chatbota (Klacksy)

Jakmile je poskytovatel KakaoTalk nakonfigurován a aktivován, může chatbot Klacksy odesílat zprávy. Nemusíte znát žádná ID — stačí použít jméno zaměstnance nebo klienta: 

"Pošli zprávu Max Muster: Váš termín je zítra ve 14:00."
"Pošli Anna Beispiel zprávu: Směna byla vyměněna."
"Informuj Peter Müller, že jeho směna v pondělí odpadá."

Klacksy automaticky vyhledá uloženou identifikaci příjemce a použije nakonfigurovaného poskytovatele KakaoTalk. Odesílání je pro vás zcela transparentní — vy pracujete se jmény, o zbytek se stará Klacksy.

Předpoklad: U příjemce musí být v Klacks uloženo Friend UUID z Kakao Friends API (v části Adresa → Kontaktní údaje). Příjemce musí být s aplikací propojen jako Kakao „přítel" — jiným uživatelům nelze zprávu odeslat.

Příchozí zprávy

Napojení na KakaoTalk nepodporuje příjem zpráv — odpovědi na odeslané zprávy se do Klacks nepřenášejí. Messaging Inbox proto pro tohoto poskytovatele nezobrazuje žádné příchozí zprávy.
