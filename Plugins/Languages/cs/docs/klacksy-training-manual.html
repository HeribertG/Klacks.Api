Trénink Klacksy - návod

Co je nástroj pro trénink?

Nástroj pro trénink řídí navigaci chatbota Klacksy v rámci stránky. Když uživatel řekne nebo napíše "Klacksy, ukaž mi adresy", Klacksy přejde na příslušnou stránku a posune zobrazení na odpovídající část.

Aby to fungovalo, potřebuje Klacksy pro každou kotvu na stránce seznam synonym v každém jazyce (např. "adresy", "klienti", "kontakty" pro cíl addresses).

Karta "Cíle"

Seznam všech kotev nalezených ve frontendu (HTML atributy data-klacksy-target). Filtr podle stavu:

  • pending: kotva existuje, ale zatím bez synonym
  • generated: synonyma byla automaticky vygenerována, potřebují kontrolu
  • reviewed: synonyma schválená administrátorem
  • needs-review: označeno k opětovné kontrole

Kliknutím na cíl se otevře editor synonym níže. Tam lze synonyma přidávat, mazat a schválit tlačítkem "Uložit jako zkontrolováno".

Karta "Zpětné vazby"

Zobrazuje uživatelské vstupy, které Klacksy nedokázal přiřadit (nebylo nalezeno odpovídající synonymum). Podle tohoto seznamu lze rozpoznat, jaká synonyma ještě chybí.

Karta "Metriky"

Přehled všech cílů podle stavu. Pomáhá sledovat postup tréninku.

Build pipeline (CLI)

Když šablony získají nové kotvy data-klacksy-target, je nutné znovu vygenerovat manifest a počáteční synonyma. Následující příkazy běží také automaticky v CI a v Husky pre-commit háku: 

cd C:\SourceCode\Klacks.Ui

# 1. Prohledat šablony → navigation-targets.json se všemi kotvami
npm run scan:targets

# 2a. Vygenerovat počáteční synonyma (všechny 4 základní + 22 pluginových jazyků, ~2,5 h)
npm run generate:synonyms

# 2b. Pouze základní jazyky (de/en/fr/it) — rychlé, cca 9 min
npm run generate:synonyms -- --core-only

# 2c. Doplnit pouze chybějící pluginové jazyky — cca 45 min
npm run generate:synonyms -- --plugins-only

# 3. Zkontrolovat konzistenci probouzecího slova
npm run wake-word-lint

Důležité: U npm run musí být uvedeno --, aby se volby předaly skriptu. Bez -- npm tento příznak pohltí a skript poběží ve výchozím režimu.

Alternativa bez npm: npx tsx tools/generate-synonyms.ts --core-only.

Klíč API

Klíč API pro LLM se hledá v tomto pořadí:

  1. Proměnná prostředí SYNONYM_LLM_API_KEY
  2. Tabulka DB llm_providers (poskytovatel deepseek, is_enabled = true) — automaticky přes volání psql
  3. Jinak chybová zpráva

Výchozím poskytovatelem je DeepSeek. Jiného poskytovatele lze zadat pomocí SYNONYM_LLM_PROVIDER_ID=anthropic (nebo jiného nastaveného poskytovatele LLM v nastaveních).

Krok 1 - scan:targets

Prohledá všechny šablony Angular na atributy data-klacksy-target a vytvoří manifest Application/Skills/Definitions/navigation-targets.json. Každá nová kotva se poté zobrazí na kartě "Cíle" se stavem pending.

Krok 2 - generate:synonyms

Vygeneruje pro každou novou kotvu počáteční synonyma z data-klacksy-label-key a kategorie. Stav poté: generated (musí zkontrolovat administrátor).

Skript zapisuje kontrolní body manifestu po každých 5 cílech, takže přerušení neztratí již vygenerovaná data.

Krok 3 - wake-word-lint

Zkontroluje konzistenci varianty probouzecího slova (Ahoj Klacksy / Hej Klacksy / ...) ve všech jazycích. Zabraňuje tomu, aby synonyma přepsala probouzecí slovo.

Hlasový režim

Ikona mikrofonu v chatu aktivuje hlasový režim. Jakmile je aktivní:

  • Mikrofon naslouchá a průběžně přepisuje
  • Při krátkém tichu → automatické odeslání dosavadního přepisu

Důležité: Jakmile začnete psát do textového pole, hlasový režim se automaticky ukončí — jinak by mikrofon přepsal váš napsaný text vlastními přepisy a předčasně jej odeslal.

Typický trénovací cyklus

  1. Doplnit kotvu v šabloně: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Restartovat API (mezipaměť se při startu znovu načte)
  4. Otevřít kartu "Cíle" → nové cíle se zobrazí se stavem generated
  5. Zkontrolovat/doplnit synonyma → "Uložit jako zkontrolováno" → stav reviewed
  6. Otestovat s Klacksy, např. "Klacksy, ukaž mi adresy"
  7. Pokud Klacksy nenajde shodu → karta "Zpětné vazby" → doplnit chybějící synonymum
  8. Sledovat kartu "Metriky", dokud vše nemá stav reviewed
