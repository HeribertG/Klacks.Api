Nastavení LINE Messaging

Požadavky

Chcete-li odesílat a přijímat zprávy přes LINE, potřebujete LINE Official Account s Messaging API Channel v LINE Developers Console. LINE je zvlášť rozšířený v Japonsku, na Tchaj-wanu a v Thajsku.

Poznámka: Push zprávy mají podle tarifu LINE měsíční kvótu (bezplatný plán je omezený). Zkontrolujte aktuální podmínky svého plánu Official Account.

Krok 1 — Vytvoření LINE Official Account a Messaging API Channel

  1. Vytvořte LINE Official Account (prostřednictvím LINE Official Account Manager).
  2. Otevřete LINE Developers Console (developers.line.biz) a vytvořte Messaging API Channel, případně propojte svůj Official Account s Messaging API.
  3. Na kartě Messaging API vystavte dlouhodobý Channel Access Token (Issue).
  4. Poznamenejte si Channel Secret na kartě Basic Settings.

Poznámka: S Channel Access Tokenem a Channel Secretem zacházejte jako s hesly. Nesdílejte je veřejně a ukládejte je bezpečně.

Krok 2 — Konfigurace LINE v Klacks

  1. Přejděte na Nastavení → Poskytovatelé zpráv.
  2. Klikněte na Přidat.
  3. Vyplňte pole následovně:

Krok 3 — Odesílání zpráv přes chatbota (Klacksy)

Jakmile je poskytovatel LINE nakonfigurován a aktivován, může chatbot Klacksy odesílat zprávy. Nemusíte znát LINE User ID — stačí použít jméno zaměstnance nebo klienta: 

"Pošli zprávu Max Muster: Váš termín je zítra ve 14:00."
"Pošli Anna Beispiel zprávu: Směna byla vyměněna."
"Informuj Peter Müller, že jeho směna v pondělí odpadá."

Klacksy automaticky vyhledá uloženou LINE User ID příjemce a použije nakonfigurovaného poskytovatele LINE. Odesílání je pro vás zcela transparentní — vy pracujete se jmény, o zbytek se stará Klacksy.

Předpoklad: U příjemce musí být v Klacks uloženo LINE User ID (začíná na U…) (v části Adresa → Kontaktní údaje). User ID se zjistí z příchozí zprávy (viditelné v Messaging Inbox) — příjemce k tomu musí přidat váš Official Account jako přítele a poslat mu zprávu.

Krok 4 — Příjem příchozích zpráv (webhook)

Aby se příchozí zprávy z LINE zobrazovaly v Klacks, musí být webhook URL zadána ručně v LINE Developers Console.

  1. Zkopírujte webhook URL zobrazenou v Klacks z nastavení poskytovatele: 
    https://{vaše-doména}/api/messaging/webhook/line
  2. Zadejte tuto URL v LINE Developers Console pod Messaging API → Webhook settings jako Webhook URL.
  3. Aktivujte volbu „Use webhook".
  4. Ujistěte se, že vaše instance Klacks je veřejně dostupná přes HTTPS.
  5. Příchozí zprávy se nyní zobrazují v reálném čase v Messaging Inbox.
