Příručka pole vzorce

Základní syntaxe

Každé pole vzorce vydá výsledek příkazem output:

output 1, <výraz>

První parametr 1 je typ zprávy a musí být vždy 1. Druhý parametr je hodnota, která se má vypsat.

Jednoduché příklady:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " záznamů"

Dostupné proměnné

Dostupné proměnné jsou uvedeny na kartě Proměnné, kde je lze naplnit testovacími hodnotami. Podle typu sestavy jsou k dispozici různé proměnné:

Typ sestavyZápatí tabulky

AbsencetotalRows, totalValue

Podmíněná logika

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "mnoho záznamů"
ELSEIF totalRows > 0 THEN
    output 1, "málo záznamů"
ELSE
    output 1, "žádné záznamy"
ENDIF

IF na jednom řádku

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (zkrácený zápis)

output 1, IIF(totalRows > 0, "OK", "Prázdné")

Proměnné a smyčky

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Praktické příklady

Počet záznamů s textem

output 1, CStr(totalRows) & " záznamů"

Zaokrouhlená hodnota (1 desetinné místo)

output 1, CStr(Round(totalValue, 1))

Hodiny jako h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Podmíněný výstup

IF totalRows = 0 THEN
    output 1, "Žádné absence"
ELSE
    output 1, CStr(totalRows) & " absence (celkem: " & CStr(totalValue) & ")"
ENDIF

Výpočet průměru

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/den"
ELSE
    output 1, "-"
ENDIF
