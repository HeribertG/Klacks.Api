Vyhledávání poskytovatelů LLM — návod

K čemu slouží tato funkce?

Toto zobrazení vám navrhne poskytovatele LLM, které ještě nemáte ve svém seznamu, a vybrané jedním kliknutím přidá. Nemusíte tak ručně zadávat název ani základní URL adresu. Navrhováni jsou výhradně poskytovatelé s API kompatibilním s OpenAI — tedy přesně ten typ služeb, které využívají i vaši již nastavení poskytovatelé.

Sloupce tabulky

Název poskytovatele

Zobrazovaný název poskytovatele (např. „OpenRouter", „xAI (Grok)").

Základní URL

Adresa API, přes kterou probíhá komunikace s poskytovatelem (např. https://api.x.ai/v1/). Přesně tato URL se později použije při vytvoření.

Zdroj

Udává, odkud návrh pochází:

  • Katalog — z pevně uloženého, ověřeného seznamu známých poskytovatelů. Základní URL adresy jsou ověřené, a tedy spolehlivé.
  • Web — nalezeno internetovým vyhledáváním a automaticky vyhodnoceno. Tyto položky se zobrazují pouze v případě, že je v nastaveních nakonfigurováno webové vyhledávání. Jsou užitečné, ale v případě pochybností byste měli základní URL krátce zkontrolovat.

Dostupnost

Před zobrazením se každý návrh živě otestuje (volání koncového bodu /models):

  • Dostupný — API odpovídá, poskytovatel funguje.
  • Dostupný (vyžaduje klíč) — API je dostupné, ale vyžaduje klíč API. Adresa je tedy správná.
  • Nedostupný — adresa neodpovídá. Takové položky nelze vybrat.

Přidání poskytovatele

Zaškrtněte jednoho nebo více poskytovatelů a klikněte dole na „Přidat výběr". Vybraní poskytovatelé se vytvoří deaktivovaní a bez klíče API. Poskytovatelé, které již máte, se vůbec nenabízejí.

Další kroky po přidání

Nově přidaný poskytovatel ještě není aktivní. Otevřete jej v seznamu, zadejte klíč API a poskytovatele aktivujte. Poté funguje přesně jako vaši ostatní poskytovatelé. Jednotlivé modely poskytovatele nadále spravujete samostatně přes správu modelů.
