Nastavení Slack

Požadavky

Chcete-li odesílat a přijímat zprávy přes Slack pomocí Klacks, potřebujete Slack workspace a Slack aplikaci s odpovídajícími oprávněními. Klacks používá Slack Web API pro odesílání a Events API pro příjem.

Poznámka: Bezplatný plán Slack pro napojení postačuje. Slack aplikace se vytvářejí na api.slack.com a jsou zdarma.

Krok 1 — Vytvoření Slack aplikace

  1. Otevřete api.slack.com/apps a klikněte na Create New App.
  2. Vyberte From scratch a zadejte název (např. Klacks Bot).
  3. Vyberte workspace, do kterého má být aplikace nainstalována.
  4. Přejděte na OAuth & Permissions a přidejte tyto Bot Token Scopes:
    • chat:write — pro odesílání zpráv do kanálů
    • im:write — pro odesílání přímých zpráv uživatelům
  5. Klikněte na Install to Workspace a potvrďte oprávnění.
  6. Poznamenejte si Bot User OAuth Token (začíná na xoxb-).
  7. Přejděte na Basic Information a poznamenejte si Signing Secret.

Krok 2 — Konfigurace Slack v Klacks

  1. Přejděte na Nastavení → Poskytovatelé zpráv.
  2. Klikněte na Přidat.
  3. Vyplňte pole následovně:

Krok 3 — Odesílání zpráv přes chatbota (Klacksy)

Jakmile je poskytovatel Slack nakonfigurován a aktivován, může chatbot Klacksy odesílat zprávy přes Slack. Použijte jméno zaměstnance nebo název kanálu: 

"Pošli zprávu Max Muster: Váš termín je zítra ve 14:00."
"Pošli Anna Beispiel zprávu: Směna byla vyměněna."
"Napiš do #team-updates: Rozvrhy služeb na příští týden jsou hotové."

Jako příjemce slouží Channel ID (např. C0123456789) nebo User ID (např. U0123456789) — u User ID se odešle přímá zpráva. Není-li příjemce zadán, použije se nakonfigurovaný výchozí kanál. Odesílání je pro vás zcela transparentní — vy pracujete se jmény, o zbytek se stará Klacksy.

Předpoklad: Uživatel Slack musí být propojen s odpovídajícím kontaktem Klacks (v části Adresa → Kontaktní údaje). Pro zprávy do kanálu musí být bot do daného kanálu pozván (/invite @Klacks Bot).

Krok 4 — Příjem příchozích zpráv (Events API)

Aby se příchozí zprávy Slack zobrazovaly v Klacks, musí být nakonfigurováno Events API Slack aplikace. Uložte a aktivujte poskytovatele v Klacks před zadáním Request URL — Slack ověří URL okamžitě pomocí challenge požadavku, na který Klacks automaticky odpoví.

  1. Otevřete svou Slack aplikaci na api.slack.com/apps a přejděte na Event Subscriptions.
  2. Aktivujte Enable Events a jako Request URL zadejte webhook URL zobrazenou v Klacks: 
    https://{vaše-doména}/api/messaging/webhook/slack
  3. V části Subscribe to bot events se přihlaste k odběru eventů message.im (přímé zprávy) a message.channels (zprávy v kanálech).
  4. Uložte změny a na vyžádání nainstalujte aplikaci do workspace znovu.
  5. Příchozí zprávy se nyní zobrazují v reálném čase v Messaging Inbox. Klacks přitom ověřuje podpis každého požadavku pomocí uloženého Signing Secret.

Řešení problémů

ProblémMožná příčinaŘešení
Test spojení selže Bot token neplatný nebo odvolaný Zkontrolujte token v OAuth & Permissions a nainstalujte aplikaci znovu
Chyba channel_not_found nebo not_in_channel Bot není přidán do kanálu Pozvěte bota do kanálu (/invite) nebo zkontrolujte Channel ID
Zpráva bez příjemce selže Není nakonfigurován výchozí kanál Zadejte výchozí kanál v nastavení poskytovatele
Ověření Request URL selže Poskytovatel v Klacks není uložen/aktivován nebo je Signing Secret chybný Nejprve uložte a aktivujte poskytovatele v Klacks a zkontrolujte Signing Secret
Chybí příchozí zprávy Bot eventy nejsou odebírány Přihlaste se k odběru message.im a message.channels v Event Subscriptions
