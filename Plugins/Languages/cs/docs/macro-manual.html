Příručka skriptování maker

Úvod

Editor maker umožňuje psát skripty, které slouží jako výpočetní základ pro služby, pracovní činnosti atd.

Příklady použití:

  • Přesný výpočet hodin pro dovolenou nebo vojenskou službu podle úvazku
  • Výpočet příplatků za noční práci, víkendy a svátky
  • Flexibilní přizpůsobení novým požadavkům

Poznámka: Interpret skriptů běží v bezpečném sandboxovém prostředí bez přístupu k souborovému systému nebo síti. Spuštění škodlivého kódu není možné.

Funkce a kategorie

Kromě názvu a obsahu skriptu má každé makro v seznamu maker dvě další vlastnosti, které se nastavují pomocí rozevíracích seznamů (dropdown) v editoru: Kategorie a Funkce. Obě jsou čistě metadata – stojí mimo skript a nemění jeho výpočet, ale řídí, jak Klacks automaticky najde a přiřadí odpovídající makro.

Kategorie

Kategorie přiřazuje makro k určité věcné oblasti použití:

NemocVýpočet hodin pro nemoc

Kategorie Služba má zvláštní roli: nově vytvořeným službám se automaticky přiřadí výchozí makro této kategorie (viz "Funkce" níže). Již existující služby přitom nikdy nejsou dodatečně měněny.

Funkce: Uživatelské, Výchozí, Výchozí (aditivní)

Funkce klasifikuje roli makra v rámci jeho kategorie:

FunkceVýznam
UživatelskéVolné makro bez zvláštní role. V rámci kategorie jich může být libovolný počet.
VýchozíVýchozí makro této kategorie – automaticky se přiřazuje novým službám. Tuto funkci smí mít nejvýše JEDNO makro na kategorii.
Výchozí (aditivní)Alternativní výchozí makro s aditivní logikou příplatků (viz níže). Rovněž nejvýše jedno na kategorii, navíc k makru s funkcí "Výchozí".

Důležité: Funkce sama o sobě nic nepočítá – je to pouze štítek (label). Zda se příplatky počítají metodou "highest-wins" (počítá se jen nejvyšší platná sazba) nebo aditivně (všechny platné sazby se sečtou), rozhoduje samotný skript. Obě dodávaná makra kategorie "Služba" ukazují tento rozdíl na stejné základní struktuře:

  • "AllShift" (funkce: Výchozí) – pro každý časový segment určí nejvyšší platnou sazbu příplatku (noc/VE1/VE2/VE3/svátek) a použije jen tu.
  • "AllShiftAdditive" (funkce: Výchozí (aditivní)) – vypočítá noční, víkendový a sváteční příplatek nezávisle na sobě a sečte je.

Které z obou se automaticky přiřadí při vytvoření nové služby, řídí instalační nastavení ("aditivní" nebo "vyhrává nejvyšší sazba"). U jednotlivé služby lze makro kdykoli později ručně přepnout – smíšený provoz je tedy možný.

Jedinečnost: Pokud se pokusíte uložit i druhé makro téže kategorie jako "Výchozí" nebo "Výchozí (aditivní)", editor uložení zablokuje a uvede název již přiřazeného makra. Nejprve nastavte jeho funkci na "Uživatelské".

Ruční úpravy maker "AllShift"/"AllShiftAdditive" se nedoporučují. Tato dvě makra jsou mechanismus, kterým se automaticky zavádějí úpravy specifické pro danou zemi a obor: dokud je ponecháte beze změny, Klacks je automaticky udržuje synchronizovaná s pravidly platnými pro vaši zemi resp. obor. Upravíte-li některé z nich ručně, je od té chvíle považováno za zákaznické – budoucí automatické aktualizace pro danou zemi/obor se pro toto makro již nepřevezmou tiše, ale selžou s konfliktem, dokud odchylku ručně nevyřešíte. Potřebujete-li vlastní logiku příplatků, vytvořte místo toho nové makro s funkcí "Uživatelské" a přiřaďte ho cíleně dotčeným službám.

Funkce a procedury

Důležité: Funkce (FUNCTION) a procedury (SUB) musí být definovány před prvním voláním. Interpret čte kód shora dolů: funkce nebo procedura je známa až poté, co byla její definice zpracována.

SUB (procedura bez návratové hodnoty)

SUB vypocet(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (funkce s návratovou hodnotou)

FUNCTION zdvojnasob(x)
    zdvojnasob = x * 2
ENDFUNCTION

DIM vysledek
vysledek = zdvojnasob(21)
OUTPUT 1, vysledek

Vracení hodnot (OUTPUT)

OUTPUT typ, hodnota

typ a hodnota jsou dva výrazy oddělené čárkou; oba jsou volitelné (výchozí 0 resp. "", pokud jsou vynechány). Makro smí obsahovat libovolný počet řádků OUTPUT – každý vytvoří vlastní návratovou hodnotu. Klacks přitom vyhodnocuje pouze následující typy:

TypVýznam
1Hlavní výsledek (hodiny resp. celková částka) – převezme se i při hodnotě 0
10Noční příplatek
11Příplatek za víkendový den 1 (např. sobota)
12Příplatek za víkendový den 2 (např. neděle)
13Příplatek za víkendový den 3 (třetí konfigurovatelný víkendový den)
14Sváteční příplatek

Řádky s příplatky (typ 10-14) s hodnotou 0 se ignorují – makro tedy nemusí vypisovat vlastní řádek pro každý typ příplatku, ale jen pro skutečně vzniklé příplatky. Hodnoty, které nelze interpretovat jako číslo, se přeskočí.

Při uložení je makro povinně zkompilováno a jednou zkusmo spuštěno s neutrálními testovacími hodnotami. Syntaktické a běhové chyby (např. nevyvážené závorky nebo nedokončený výraz) se tak spolehlivě zobrazí, místo aby tiše vedly k nefunkčnímu makru.

Příklad: Výpočet příplatků ("AllShift")

Dodávané výchozí makro kategorie "Služba". Vypočítá příplatky za noční práci, svátky a tři konfigurovatelné víkendové dny se správným zpracováním směn přesahujících půlnoc (rozdělení na segmenty) a pro každý segment použije nejvyšší platnou sazbu (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Vysvětlení

  • Rozdělení na segmenty: Pro směny přesahující půlnoc (např. 22:00-06:00) se směna rozdělí na dva segmenty (do půlnoci / od půlnoci), každý s vlastním příznakem dne v týdnu/svátku
  • SegBonusForType: Vypočítá příplatek pro segment a určitý typ příplatku (10-14) s ohledem na noční, sváteční a víkendové příplatky
  • VE1/VE2/VE3 místo So/Ne: weekendday1-3 činí víkendové dny konfigurovatelnými (ne každá země má jako víkend sobotu/neděli)
  • Nejvyšší příplatek na segment: NRate/DRate určují vždy nejvyšší platnou sazbu pro noční resp. denní hodiny – highest-wins, žádné sčítání
  • HolidayNextDay: Zohledňuje, zda je následující den svátkem (důležité pro noční směny přesahující půlnoc)
  • Více řádků OUTPUT: Řádek 1 vrací celkový součet, řádky 10-14 vrací jednotlivé částky příplatků (viz oddíl "Vracení hodnot")

Aditivní varianta ("AllShiftAdditive")

Výchozí (aditivní) makro téže kategorie má identické řádky IMPORT a stejnou rámcovou strukturu – liší se jen SegBonusForType: místo nejvyšší sazby se pro každý typ příplatku počítá nezávisle, zda platí, a všechny platné částky se na konci sečtou (žádné highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Pokud noční směna připadne navíc na svátek, dostane u "AllShift" jen vyšší z obou sazeb, zatímco u "AllShiftAdditive" dostane noční i sváteční příplatek dohromady. Zbytek skriptu (rozdělení na segmenty, součet, řádky OUTPUT) je stejný jako u "AllShift" výše.
