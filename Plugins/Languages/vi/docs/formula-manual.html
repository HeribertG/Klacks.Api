Hướng dẫn trường công thức

Cú pháp cơ bản

Mỗi trường công thức xuất kết quả bằng lệnh output:

output 1, <biểu thức>

Tham số đầu tiên 1 là loại thông báo và luôn phải là 1. Tham số thứ hai là giá trị cần xuất ra.

Ví dụ đơn giản:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " mục"

Các biến khả dụng

Các biến khả dụng được liệt kê trong tab Biến số và có thể được gán giá trị thử nghiệm tại đó. Tùy theo loại báo cáo, các biến khác nhau sẽ khả dụng:

Loại báo cáoDòng chân bảng
Kế hoạch làm việctotalRows, totalHours, totalSurcharges, totalWorkDays
Vắng mặttotalRows, totalValue
Địa chỉtotalRows
NhómtotalRows

Toán tử

Toán tửMô tảVí dụ
+CộngtotalHours + 2
-TrừtotalRows - 1
*NhântotalValue * 1.5
/ChiatotalHours / 8
^Lũy thừa2 ^ 10
\Chia lấy số nguyên10 \ 3 → 3
MODModulo (phần dư)10 MOD 3 → 1

Các hàm có sẵn

Chuyển đổi kiểu dữ liệu

HàmMô tả
CStr(x)Chuyển số thành văn bản
CInt(x)Chuyển thành số nguyên
CDbl(x)Chuyển thành số thập phân

Toán học

HàmMô tả
Abs(x)Giá trị tuyệt đối
Round(x, n)Làm tròn đến n chữ số thập phân
Int(x)Làm tròn xuống thành số nguyên
Sqr(x)Căn bậc hai
Sgn(x)Dấu (-1, 0, 1)

Văn bản

HàmMô tả
Len(s)Độ dài văn bản
Left(s, n)n ký tự từ bên trái
Right(s, n)n ký tự từ bên phải
Mid(s, pos, n)n ký tự bắt đầu từ vị trí pos
UCase(s)Chuyển thành chữ hoa
LCase(s)Chuyển thành chữ thường
Trim(s)Loại bỏ khoảng trắng ở hai đầu
Replace(s, alt, neu)Thay thế văn bản

Logic điều kiện

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "nhiều mục"
ELSEIF totalRows > 0 THEN
    output 1, "ít mục"
ELSE
    output 1, "không có mục nào"
ENDIF

IF một dòng

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (dạng rút gọn)

output 1, IIF(totalRows > 0, "OK", "Trống")

Biến số và vòng lặp

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Ví dụ thực tế

Số lượng mục kèm văn bản

output 1, CStr(totalRows) & " mục"

Giá trị làm tròn (1 chữ số)

output 1, CStr(Round(totalValue, 1))

Giờ dưới dạng h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Xuất có điều kiện

IF totalRows = 0 THEN
    output 1, "Không có vắng mặt nào"
ELSE
    output 1, CStr(totalRows) & " vắng mặt (Tổng: " & CStr(totalValue) & ")"
ENDIF

Tính trung bình

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/ngày"
ELSE
    output 1, "-"
ENDIF
