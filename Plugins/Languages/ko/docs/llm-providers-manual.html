LLM 제공자 검색 - 안내서

이 기능은 무엇을 위한 것인가요?

이 화면은 아직 목록에 등록되지 않은 LLM 제공자를 추천해 주고, 선택한 항목을 클릭 한 번으로 추가할 수 있게 해 줍니다. 덕분에 이름과 기본 URL을 직접 입력할 필요가 없습니다. 오직 OpenAI 호환 API 제공자만 추천되며, 이는 이미 등록된 제공자들이 사용하는 것과 동일한 방식의 서비스입니다.

표의 열

제공자 이름

제공자의 표시 이름입니다(예: "OpenRouter", "xAI (Grok)").

기본 URL

제공자와 통신할 때 사용되는 API 주소입니다(예: https://api.x.ai/v1/). 등록 시에도 바로 이 URL이 그대로 사용됩니다.

출처

추천이 어디서 왔는지를 나타냅니다:

  • 카탈로그 — 미리 검증된 잘 알려진 제공자 목록에서 가져온 것입니다. 기본 URL이 검증되어 있어 신뢰할 수 있습니다.
  • 웹 — 인터넷 검색을 통해 찾아 자동으로 분석한 결과입니다. 이 항목들은 설정에서 웹 검색이 구성되어 있을 때만 나타납니다. 유용하긴 하지만, 확실하지 않은 경우 기본 URL을 한 번 확인하는 것이 좋습니다.

연결 상태

표시되기 전에 각 추천 항목은 실시간으로 테스트됩니다(/models 엔드포인트 호출):

  • 연결 가능 — API가 응답하며 제공자가 정상적으로 작동합니다.
  • 연결 가능 (키 필요) — API는 존재하지만 API 키를 요구합니다. 즉, 주소는 올바릅니다.
  • 연결 불가 — 해당 주소가 응답하지 않습니다. 이런 항목은 선택할 수 없습니다.

제공자 추가하기

하나 이상의 제공자에 체크 표시를 한 뒤 하단의 "선택 항목 추가"를 클릭하세요. 선택한 제공자는 비활성화 상태로, API 키 없이 등록됩니다. 이미 등록되어 있는 제공자는 애초에 추천 목록에 나타나지 않습니다.

추가 후 다음 단계

새로 추가된 제공자는 아직 활성화되지 않은 상태입니다. 목록에서 해당 제공자를 열어 API 키를 입력하고 활성화하세요. 그 이후에는 다른 제공자와 동일하게 작동합니다. 제공자별 개별 모델은 이후에도 모델 관리 화면에서 별도로 관리합니다.
