WhatsApp 설정

사전 준비

Klacks로 WhatsApp을 통해 메시지를 보내고 받으려면 Meta 개발자 계정과 WhatsApp 제품이 활성화된 Meta 앱이 필요합니다. Klacks는 전송에 Meta 비즈니스 플랫폼의 WhatsApp Cloud API를, 수신에 Meta 웹훅을 사용합니다.

참고: 설정과 테스트에는 비용이 발생하지 않습니다. 앱을 생성하면 Meta가 자동으로 무료 테스트 전화번호를 제공합니다.

중요 — 발신 번호는 개인 번호가 아닙니다. 일반 WhatsApp 앱에서 이미 사용 중인 전화번호는 Cloud API에 등록할 수 없으며, 등록된 번호는 더 이상 WhatsApp Messenger에서 사용할 수 없습니다. 따라서 Meta가 제공하는 테스트 번호 또는 업무 전용으로만 사용하는 자체 번호를 사용하세요. 휴대전화의 개인 WhatsApp은 테스트용 수신자로 사용하며, 발신자로는 사용하지 않습니다.

1단계 — Meta 앱 생성

  1. developers.facebook.com/apps를 열고 Create app을 클릭합니다.
  2. 사용 사례로 Other를, 앱 유형으로 Business를 선택합니다.
  3. 대시보드에서 WhatsApp 제품의 Set up을 클릭합니다. 이때 테스트 전화번호가 자동으로 생성되고 등록됩니다.
  4. 왼쪽 탐색 메뉴에서 WhatsApp → API Setup으로 이동합니다.
  5. Phone number ID를 확인하고 Generate access token으로 액세스 토큰을 생성합니다.
  6. App settings → Basic에서 App Secret을 확인합니다 — 수신 메시지의 서명 검증에 필요합니다.

주의 — 비슷한 두 개의 ID: API Setup 패널에는 Phone number ID와 WhatsApp Business Account ID가 바로 아래위로 나란히 표시됩니다. Klacks에 필요한 것은 Phone number ID입니다. 잘못된 ID를 입력해도 연결 테스트는 성공으로 표시되지만, 전송은 모두 실패합니다.

주의 — 토큰 유효 기간: Generate access token으로 생성한 토큰은 임시 테스트 토큰이며 짧은 시간 후에 만료됩니다. 상시 운영을 위해서는 Meta 비즈니스 관리자에서 시스템 사용자를 통해 영구 토큰을 생성하세요.

2단계 — 수신자 번호 승인

테스트 번호는 사전에 승인된 수신자에게만 전송할 수 있습니다. API Setup 패널의 To → Manage phone number list에서 본인의 WhatsApp 번호를 추가하세요. Meta가 해당 번호로 확인 코드를 보내며, 이를 입력해야 합니다.

이 단계를 거치지 않으면 Meta는 해당 번호로의 모든 전송을 거부합니다. 이후 인증된 자체 비즈니스 번호를 사용하게 되면 이 승인 절차는 더 이상 필요하지 않습니다.

  3. 다음과 같이 필드를 입력합니다:

4단계 — 24시간 창

이 점에서 WhatsApp은 Telegram이나 Slack과 근본적으로 다릅니다. 기업은 고객 서비스 창이 열려 있는 동안에만 자유 텍스트 메시지를 보낼 수 있습니다. 이 창은 수신자가 귀하의 WhatsApp 번호로 메시지를 보냄으로써 열립니다. 창은 24시간 동안 열려 있으며, 수신자가 메시지를 보낼 때마다 연장됩니다.

이 창 밖에서는 Meta가 사전에 승인된 메시지 템플릿만 허용합니다. Klacks는 현재 자유 텍스트 메시지만 전송하므로 스스로 대화를 시작할 수 없습니다.

이것이 의미하는 바: 직원들에게 Klacks의 WhatsApp 번호로 메시지를 한 번 보내달라고 요청하세요. 그 이후 24시간 동안 전송이 가능하며, 답장이 올 때마다 창이 연장됩니다. 창이 닫혀 있으면 전송 시 오류가 발생합니다 — 이는 구성 문제가 아니라 WhatsApp의 규정입니다.

이 창과 관계없이 직원에게 연락해야 한다면 Telegram 또는 Signal이 더 적합한 프로바이더입니다 — 그곳에는 이러한 제한이 없습니다.

5단계 — 챗봇(Klacksy)을 통한 메시지 전송

WhatsApp 프로바이더가 구성되고 활성화되면 챗봇 Klacksy가 WhatsApp을 통해 메시지를 보낼 수 있습니다. 직원의 이름을 사용하세요: 

"홍길동에게 메시지 보내기: 내일 오후 2시에 예약이 있습니다."
"김영희에게 메시지 보내기: 근무가 교대되었습니다."

수신자로는 앞자리 0과 더하기 기호를 뺀 국제 형식의 전화번호가 사용됩니다 (예: 079 123 45 67은 41791234567). 이 과정은 사용자에게 완전히 투명합니다 — 이름으로 작업하면 Klacksy가 나머지를 처리합니다.

전제 조건: WhatsApp 번호가 해당 Klacks 연락처에 연결되어 있어야 하며 (주소 → 연락처 정보), 4단계의 24시간 창이 열려 있어야 합니다.

6단계 — 수신 메시지 받기 (Webhook)

수신 WhatsApp 메시지를 Klacks에 표시하려면 Meta 앱의 Webhook을 구성해야 합니다. Callback URL을 입력하기 전에 Klacks에서 프로바이더를 저장하고 활성화하세요 — Meta는 즉시 확인 요청으로 URL을 검사하며, Klacks가 검증 토큰을 기준으로 자동으로 응답합니다.

  1. Meta 앱을 열고 WhatsApp → Configuration으로 이동합니다.
  2. Webhook에서 Edit를 클릭하고 다음을 입력합니다:
    • Callback URL: Klacks에 표시된 Webhook URL 
      https://{your-domain}/api/messaging/webhook/whatsapp
    • Verify token: 3단계에서 검증 토큰 필드에 입력한 값과 정확히 동일한 값
  3. Verify and save를 클릭합니다.
  4. Webhook fields에서 messages 필드를 구독합니다.
  5. 수신 메시지가 이제 메시징 수신함에 실시간으로 표시됩니다. 이때 Klacks는 저장된 App Secret으로 각 요청의 서명(X-Hub-Signature-256)을 검증합니다.

Callback URL은 외부에서 HTTPS로 접근할 수 있어야 합니다. 공개 주소가 없는 사내 네트워크에 설치한 경우 전송은 작동하지만, 메시지를 수신할 수는 없습니다.

문제 해결

문제가능한 원인해결 방법
연결 테스트 실패 액세스 토큰이 만료됨 임시 테스트 토큰은 짧은 시간 후 만료됩니다 — API Setup 패널에서 새로 생성하거나 영구 토큰을 설정하세요
연결 테스트는 성공하지만 전송이 모두 실패함 전화번호 ID 대신 비즈니스 계정 ID를 입력함 API Setup 패널에서 Phone number ID를 가져오세요. WhatsApp Business Account ID가 아닙니다
24시간 또는 재연락을 언급하는 오류 고객 서비스 창이 닫혀 있음 수신자가 먼저 귀하의 WhatsApp 번호로 메시지를 보내야 합니다 — 4단계를 참조하세요
특정 번호로의 전송 실패 테스트 번호에서 수신자가 승인되지 않음 Manage phone number list에서 번호를 추가하고 코드로 확인하세요
Webhook 검증 실패 검증 토큰이 일치하지 않거나 Klacks에서 프로바이더가 저장/활성화되지 않음 먼저 Klacks에서 프로바이더를 저장하고 활성화한 다음, Meta에 동일한 검증 토큰을 입력하세요
수신 메시지 누락 Webhook 필드 messages를 구독하지 않았거나 App Secret이 잘못됨 Configuration에서 messages 필드를 구독하고 App Secret을 확인하세요
