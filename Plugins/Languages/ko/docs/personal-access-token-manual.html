개인 액세스 토큰 매뉴얼

개인 액세스 토큰이란 무엇인가요?

개인 액세스 토큰(Personal Access Token, PAT)은 사용자 이름과 비밀번호 없이도 외부 도구와 서비스가 Klacks에 안전하게 접근할 수 있도록 해주는 장기 유효 API 키입니다.

대표적인 사용 사례:

  • MCP (Model Context Protocol) – Claude Desktop과 같은 AI 어시스턴트가 Klacksy 스킬에 직접 접근할 수 있도록 허용합니다
  • 자동화 스크립트 및 CI/CD 파이프라인
  • 외부 모니터링 및 연동 도구

보안 개념

Klacks는 평문 토큰을 절대 저장하지 않습니다. 토큰 생성 후에는 오직 토큰의 SHA-256 해시만 데이터베이스에 저장됩니다. 토큰 자체는 생성 직후 단 한 번만 표시되며, 이후에는 다시 조회할 수 없습니다.

참고: 토큰 생성 직후 즉시 기록하거나 복사해 두십시오. 분실 시에는 새 토큰을 생성하고 기존 토큰을 폐기해야 합니다.

토큰 생성

단계별 절차

  • 설정 → 개인 액세스 토큰으로 이동합니다
  • 새 토큰 만들기를 클릭합니다
  • 의미 있는 이름을 지정합니다 (예: Claude Desktop 또는 CI-Pipeline)
  • 원하는 유효 기간을 선택합니다 (1~730일, 기본값: 365일)
  • 생성을 클릭합니다
  • 표시된 토큰을 즉시 복사합니다 – 단 한 번만 표시됩니다

토큰 형식

klacks_pat_<random string>

모든 토큰은 접두사 klacks_pat_로 시작하며, 그 뒤에 암호학적으로 안전한 무작위 문자열이 이어집니다.

유효 기간

기간권장 용도
1~30일단기 테스트 및 개발
90~180일정기적으로 갱신되는 CI/CD 파이프라인
365일 (기본값)영구적인 연동 (예: Claude Desktop)
730일장기 시스템 연동

토큰 사용

HTTP 헤더의 Bearer 토큰

토큰은 모든 API 요청의 Authorization 헤더에 Bearer 토큰 형태로 전달됩니다:

Authorization: Bearer klacks_pat_...

Claude Desktop에서 MCP 설정하기

MCP 엔드포인트(/mcp)를 사용하면 Claude Desktop과 같은 AI 어시스턴트가 모든 Klacksy 스킬에 직접 접근할 수 있습니다 – 직원 데이터 조회, 근무 일정 계획, 그룹 관리 등 다양한 작업이 가능합니다.

Claude Desktop 앱 설정 (claude_desktop_config.json):

{
  "mcpServers": {
    "klacks": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-fetch",
        "https://<your-klacks-domain>/mcp"
      ],
      "env": {
        "AUTHORIZATION": "Bearer klacks_pat_..."
      }
    }
  }
}

<your-klacks-domain>을 사용 중인 Klacks 설치의 주소로, klacks_pat_...을 생성한 토큰으로 바꾸십시오.

직접 API 요청 (curl)

curl -H "Authorization: Bearer klacks_pat_..." \
     https://<your-klacks-domain>/api/clients

관리 및 보안

토큰 개요

설정 → 개인 액세스 토큰에서 모든 토큰의 이름, 생성일, 만료일, 마지막 사용 일시를 확인할 수 있습니다. 평문 토큰은 이 화면에서 절대 표시되지 않습니다.

토큰 폐기

토큰은 언제든지 폐기할 수 있습니다. 폐기 후에는 해당 토큰을 사용한 모든 요청이 즉시 거부됩니다. 다음의 경우 토큰을 즉시 폐기하십시오:

  • 토큰이 실수로 유출된 경우
  • 더 이상 사용하지 않는 기기나 서비스인 경우
  • 의심스러운 활동이 감지된 경우

만료

만료된 토큰은 자동으로 거부됩니다. Klacks는 개요 화면에서 앞으로 30일 이내에 만료될 토큰을 표시하여, 제때 새 토큰을 생성할 수 있도록 안내합니다.

보안 권장 사항

  • 서비스나 도구마다 별도의 토큰을 사용하십시오
  • 토큰을 명확히 구분할 수 있도록 의미 있는 이름을 사용하십시오
  • 토큰을 평문 상태로 버전 관리 시스템에 저장하지 마십시오
  • 특히 CI/CD 환경에서는 토큰을 정기적으로 교체하십시오
  • 오남용이 의심되면 즉시 토큰을 폐기하십시오

모든 토큰은 사용자 계정에 연결되어 있으며, 계정과 동일한 권한을 갖습니다. 토큰은 비밀번호와 동일한 수준으로 신중하게 관리하십시오.
