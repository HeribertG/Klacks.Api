제한 시간대 – 매뉴얼

제한 시간대란?

제한 시간대는 특정 시즌 동안 하루 중 특정 시간대에 근무를 계획하는 것을 금지합니다. 예를 들어 연중 특정 기간의 야간 계획 금지나 업종별 제한 시간을 구현하는 데 사용할 수 있습니다.

세부 설정

시즌 시작(월/일)

이 시간대가 적용되는 시즌의 시작을 월(1~12)과 일(1~31)로 지정합니다. 시즌은 달력 연도가 아니라 근무의 날짜를 기준으로 하며, 연도를 넘어갈 수 있습니다(아래 참조).

시즌 종료(월/일)

시즌의 종료를 월과 일로 지정합니다. 종료가 시작보다 앞서면(예: 11월 1일부터 2월 28일까지), 시즌은 연도를 넘어 적용됩니다.

일일 시간대 – 시작 / 종료

제한이 적용되는 하루 중 시간대를 시작 시각과 종료 시각(HH:mm)으로 지정합니다. 종료 시각이 시작 시각보다 이른 시간대(예: 22:00부터 06:00까지)는 자정을 넘어 적용됩니다.

적용 그룹 태그

제한을 특정 그룹(태그/식별자 기준)의 근무로 한정합니다. 필드를 비워두면 제한이 모든 근무에 적용됩니다.

가져온 규칙에 대한 중요 안내

  • 지역 설정(국가 프로필)에서 가져온 규칙은 지역 설정을 다시 가져올 때 복원됩니다. 따라서 이러한 행을 삭제해도 영구적이지 않습니다 – 다음 재가져오기 후 다시 나타납니다.
