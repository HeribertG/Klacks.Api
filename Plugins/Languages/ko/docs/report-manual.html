리포트 디자이너 매뉴얼

리포트 구조

리포트는 세 가지 영역으로 구성됩니다:

  • 헤더 – 각 페이지 상단에 인쇄됩니다
  • 본문 – 데이터 테이블을 포함합니다
  • 푸터 – 각 페이지 하단에 인쇄됩니다

각 영역은 리포트 편집기의 디자인 탭에서 편집할 수 있습니다.

헤더 영역

헤더에는 왼쪽, 가운데, 오른쪽의 세 영역이 있습니다.

각 영역에는 다음을 포함할 수 있습니다:

  • 필드 – 자동으로 채워지는 데이터베이스 필드
  • 자유 텍스트 – 수동으로 입력한 텍스트
  • 이미지 – 예: 회사 로고(이미지 관리자에서 업로드)

행은 도구 모음을 통해 추가하거나 제거할 수 있습니다.

본문 테이블

본문에는 하나 이상의 테이블이 포함됩니다.

작업설명
열 추가+ 기호 또는 필드 목록에서 끌어서 놓기를 통해
열 너비열 가장자리를 끌어서 조정
열 순서끌어서 놓기로 이동
열 제거열 편집기에서 삭제 기호를 통해

각 테이블은 데이터 세트(예: 근무 계획, 주소)와 연결됩니다.

필드 병합(병합된 필드)

병합된 필드는 단일 열에 여러 데이터 바인딩을 허용합니다.

  • 열 편집기에서 필드 추가를 클릭하여 같은 열에 추가 필드를 추가합니다
  • 값은 세로로 또는 구분 기호와 함께 표시됩니다
  • 구분 기호는 필드 대화 상자에서 구성할 수 있습니다(예: 쉼표, 공백, 줄 바꿈)

테이블 바닥글

각 테이블 아래에 바닥글을 표시할 수 있습니다.

  • 합계 필드: 숫자 열은 자동으로 합산될 수 있습니다
  • 레이블: 합계의 레이블을 표시하거나 숨길 수 있습니다
  • 바닥글 탭의 열 편집기를 통해 활성화합니다

자유 텍스트 행

자유 텍스트 행은 데이터 테이블 앞이나 뒤에 삽입할 수 있습니다.

속성설명
위치데이터 앞 또는 데이터 뒤 선택 가능
내용임의의 텍스트(예: 참고 사항, 조건 또는 서명란)
스타일글꼴, 크기 및 정렬 구성 가능

서식

각 셀과 자유 텍스트는 개별적으로 서식을 지정할 수 있습니다:

옵션설명
글꼴셀에 사용할 글꼴 선택
글꼴 크기포인트(pt) 단위의 크기

텍스트 색상자유롭게 선택 가능한 색상
정렬왼쪽, 가운데 또는 오른쪽

셀 테두리

각 셀의 테두리 선을 개별적으로 구성할 수 있습니다.

속성옵션
면위, 오른쪽, 아래, 왼쪽(개별 또는 모두)
선 스타일가는 선, 중간, 굵은 선, 점선, 이중선
선 색상자유롭게 선택 가능

테두리는 열 편집기의 테두리에서 설정합니다.

페이지 설정

일반 탭에서 인쇄 설정을 조정할 수 있습니다:

  • 방향: 세로(포트레이트) 또는 가로(랜드스케이프)
  • 용지 크기: A4, A3, B4 (JIS), B5 (JIS) 또는 Letter
  • 페이지 여백: 위, 오른쪽, 아래, 왼쪽(mm 단위)

표시 옵션(디자이너)

디자인 탭에서 데이터 소스 근무 계획(스케줄)에 대해 추가 옵션을 사용할 수 있습니다:

  • 일별 항목 요약: 같은 날의 여러 항목이 한 행으로 요약됩니다
  • 전체 기간 표시: 항목이 없어도 기간의 모든 날이 표시됩니다

매개변수

매개변수는 리포트 실행 시 요청됩니다. 해당 값은 행 필터와 수식에서 사용할 수 있으며 데이터 소스 쿼리를 추가로 제한할 수 있습니다. 매개변수 탭에서 생성합니다.

필드의미
키기술 이름. 문자로 시작해야 하며 문자, 숫자 및 밑줄만 포함할 수 있습니다. 리포트별로 고유합니다.
이름실행 시 표시되는 레이블입니다.
유형텍스트, 숫자, 날짜, 예/아니오 또는 선택.
기본값실행 시 아무것도 입력하지 않으면 사용됩니다.
선택 값«선택» 유형에만 해당: 쉼표로 구분된 허용 값.
적용 대상값이 데이터 소스에 추가로 전달되는지 여부를 결정합니다.
필수 필드값 없이는 리포트를 실행할 수 없습니다.

필터 및 수식의 매개변수

각 매개변수는 스크립트에서 param_ 접두사가 있는 키로 사용할 수 있습니다 — 키 region은 param_region이 됩니다. 이 접두사는 매개변수가 같은 이름의 행 값을 가리지 않도록 합니다. 현재 이름은 각 매개변수 아래에 표시됩니다.

값은 평가 전에 선택한 유형으로 변환됩니다:

  • 숫자: 숫자로; 잘못된 입력은 0이 됩니다
  • 예/아니오: 1, true, wahr 또는 yes이면 참이고, 그 외에는 거짓입니다
  • 텍스트, 날짜, 선택: 텍스트로

데이터 소스에 매개변수 바인딩

적용 대상을 통해 매개변수는 실제로 로드되는 데이터를 추가로 제한합니다:

설정효과
필터 및 수식에만값은 스크립트에서만 사용됩니다(기본값).
쿼리 그룹값이 데이터를 로드할 그룹을 대체합니다.
쿼리 직원값이 데이터를 로드할 직원을 대체합니다.
쿼리 시작 날짜값이 기간의 시작을 대체합니다.
쿼리 종료 날짜값이 기간의 끝을 대체합니다.

바인딩된 날짜 값은 YYYY-MM-DD 또는 DD.MM.YYYY 형식으로 입력해야 합니다. 다른 형식의 값은 쿼리가 눈에 띄지 않게 비어 있지 않도록 무시됩니다. 빈 값은 원래 설정을 변경하지 않습니다.
