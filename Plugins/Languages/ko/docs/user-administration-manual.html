사용자 관리 – 매뉴얼

사용자 관리란 무엇인가요?

여기서는 사람들이 Klacks에 로그인할 수 있게 해주는 로그인 계정 (시스템 사용자)을 관리합니다. 이는 직원 관리나 주소 관리와는 다릅니다 — 로그인 계정은 직원과 연결될 수도 있고, 연결되지 않을 수도 있습니다.

사용자 추가

  • + 사용자 추가 버튼을 누르면 입력 대화상자가 열립니다.
  • 이름과 성(각각 최소 2자 이상)을 입력하면 자동으로 사용자 이름 제안이 생성됩니다.
  • 이메일 주소는 필수이며 반드시 @ 기호를 포함해야 합니다.
  • 모든 필드가 유효하게 채워져야만 저장할 수 있습니다.
  • 계정을 생성할 때 비밀번호가 자동으로 생성됩니다. 해당 사용자가 직접 비밀번호를 설정할 수 있게 하려면, 이후 해당 사용자 행에서 비밀번호 재설정을 사용하세요.

권한: 감독자(Supervisor) & 관리자(Admin)

  • 감독자 – 주소, 그룹, 계약, 결근, 근무를 생성, 편집, 삭제할 수 있으며, 근무 일정에서 하루 또는 그룹 단위로 승인하거나 해당 승인을 다시 철회할 수 있습니다. 반면 개별 근무 시간의 단순 확인은 별도의 역할이 필요하지 않습니다.
  • 관리자 – 감독자가 할 수 있는 모든 작업에 더해, 모든 설정 (사용자 관리 자체 포함)에 접근할 수 있으며, 기간을 마감하고 다시 열 수 있고, 아이디 제공자(Identity Provider), 리포트, 캘린더 규칙과 같이 특별히 보호된 영역도 관리할 수 있습니다. 관리자 권한에는 감독자 권한이 자동으로 포함됩니다.
  • 권한 변경은 드롭다운을 전환하는 즉시 적용되며, 별도로 저장 버튼을 누를 필요가 없습니다.

사용자 편집

이름 행을 더블클릭하면 편집 대화상자가 열립니다. 여기서는 사용자 이름을 나중에 변경할 수 있습니다 — 신규 생성 시에는 단순히 제안 값으로만 표시되는 것과 다릅니다.

비밀번호 재설정

사용자 행에 있는 비밀번호 재설정 링크를 클릭하면, 등록된 이메일 주소로 메일이 전송되며 해당 사용자는 이를 통해 직접 새 비밀번호를 설정할 수 있습니다.

사용자 삭제

휴지통 버튼을 누르면 삭제 대화상자에서 확인 후 로그인 계정이 영구적으로 제거됩니다.

내 계정

현재 로그인한 사용자도 목록에 함께 표시되지만, 해당 행에서는 편집, 권한 변경, 삭제가 불가능합니다 — 이러한 작업은 자신의 행에서는 비활성화되어 있습니다.
