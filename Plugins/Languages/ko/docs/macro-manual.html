매크로 스크립팅 매뉴얼

소개

매크로 편집기를 사용하여 업무, 고용 형태 등의 계산 기반으로 사용되는 스크립트를 작성할 수 있습니다.

사용 예:

  • 고용률에 기반한 휴가 및 군복무 시간의 정확한 계산
  • 야간 근무, 주말, 공휴일 할증 수당 계산
  • 새로운 요구사항에 대한 유연한 대응

참고: 스크립트 인터프리터는 파일 시스템이나 네트워크에 접근할 수 없는 안전한 샌드박스 환경에서 동작합니다. 악성 코드를 실행할 수 없습니다.

함수와 카테고리

이름과 스크립트 내용 외에도, 매크로 목록의 각 매크로는 편집기의 드롭다운을 통해 설정되는 두 가지 속성을 추가로 가집니다: 카테고리와 함수. 둘 다 순수한 메타데이터입니다 – 스크립트 외부에 있으며 계산 자체를 변경하지 않고, Klacks가 적절한 매크로를 자동으로 찾아 할당하는 방식을 제어합니다.

카테고리

카테고리는 매크로를 특정 업무 영역에 할당합니다:

카테고리용도
미지정특별한 적용 영역 없음 (새 매크로의 기본값)
근무정규 근무에 대한 할증 계산 (야간, 주말, 공휴일 할증)
휴가휴가 시간 계산
질병질병 시간 계산
사고사고 시간 계산
워크숍 (유급)유급 워크숍/교육 시간
워크숍 (무급)무급 워크숍/교육 시간

근무 카테고리는 특별한 역할을 합니다: 새로 생성된 근무는 이 카테고리의 표준 매크로가 자동으로 할당됩니다 (아래 "함수" 참조). 기존 근무는 이때 절대 나중에 변경되지 않습니다.

함수: 사용자 정의, 표준, 표준 (가산형)

함수는 카테고리 내에서 매크로의 역할을 분류합니다:

함수의미
사용자 정의특별한 역할이 없는 자유 매크로. 카테고리당 얼마든지 존재할 수 있습니다.
표준이 카테고리의 표준 매크로 – 새 근무에 자동으로 할당됩니다. 카테고리당 최대 하나의 매크로만 이 함수를 가질 수 있습니다.
표준 (가산형)가산형 할증 로직을 가진 대체 표준 매크로 (아래 참조). 마찬가지로 카테고리당 하나만 가능하며, "표준" 매크로와 별도로 존재할 수 있습니다.

중요: 함수 자체는 아무것도 계산하지 않습니다 – 이는 하나의 레이블일 뿐입니다. 할증이 "최고 우선"(적용 가능한 최고 요율만 적용) 방식으로 계산되는지, 아니면 가산형(해당하는 모든 요율을 합산)으로 계산되는지는 스크립트 자체가 결정합니다. 함께 제공되는 두 개의 "근무" 카테고리 매크로는 동일한 기본 구조에서 그 차이를 보여줍니다:

  • "AllShift" (함수: 표준) – 시간 세그먼트별로 적용 가능한 최고 할증(야간/WE1/WE2/WE3/공휴일)을 산출하여 이것만 사용합니다.
  • "AllShiftAdditive" (함수: 표준 (가산형)) – 야간, 주말, 공휴일 할증을 서로 독립적으로 계산하여 합산합니다.

근무를 새로 생성할 때 둘 중 어느 것이 자동으로 할당되는지는 설치 전역 설정("가산형" 또는 "최고 요율 우선")이 제어합니다. 이후 근무별로 매크로를 언제든지 수동으로 전환할 수 있으므로 혼합 운영도 가능합니다.

유일성: 동일한 카테고리의 두 번째 매크로를 "표준" 또는 "표준 (가산형)"으로 저장하려고 하면 편집기가 저장을 차단하고 이미 할당된 매크로의 이름을 알려줍니다. 먼저 해당 매크로의 함수를 "사용자 정의"로 변경하십시오.

"AllShift"/"AllShiftAdditive"에 대한 수동 변경은 권장하지 않습니다. 이 두 매크로는 국가 및 업종별 조정이 자동으로 반영되는 메커니즘입니다: 이를 그대로 두는 한, Klacks는 해당 국가 또는 업종에 맞는 규칙과 자동으로 동기화된 상태를 유지합니다. 둘 중 하나를 수동으로 편집하면 그 시점부터 고객 고유 매크로로 간주되어 – 이후 이 매크로에 대한 자동 국가/업종 업데이트는 더 이상 자동으로 반영되지 않고, 사용자가 수동으로 차이를 해결할 때까지 충돌로 실패합니다. 별도의 할증 로직이 필요하면 대신 함수가 "사용자 정의"인 새 매크로를 만들어 해당 근무에 개별적으로 할당하십시오.

함수와 프로시저

중요: 함수(FUNCTION)와 프로시저(SUB)는 최초 호출보다 앞에 정의해야 합니다. 인터프리터는 코드를 위에서 아래로 읽습니다. 함수 또는 프로시저는 정의가 처리된 후에만 사용할 수 있습니다.

SUB (반환값 없는 프로시저)

SUB berechne(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (반환값 있는 함수)

FUNCTION verdoppeln(x)
    verdoppeln = x * 2
ENDFUNCTION

DIM ergebnis
ergebnis = verdoppeln(21)
OUTPUT 1, ergebnis

반환값 (OUTPUT)

OUTPUT typ, wert

typ과 wert는 쉼표로 구분된 두 개의 식입니다. 둘 다 선택 사항이며 생략 시 기본값은 각각 0과 ""입니다. 매크로는 원하는 만큼의 OUTPUT 줄을 포함할 수 있으며 – 각 줄은 하나의 반환값을 생성합니다. Klacks는 다음 타입만 평가합니다:

타입의미
1주 결과 (시간 또는 총액) – 값이 0이어도 반영됨
10야간 할증
11주말 요일 1 할증 (예: 토요일)
12주말 요일 2 할증 (예: 일요일)
13주말 요일 3 할증 (세 번째 설정 가능한 주말 요일)
14공휴일 할증

값이 0인 할증 줄(타입 10-14)은 무시됩니다 – 따라서 매크로가 모든 할증 타입에 대해 별도의 줄을 출력할 필요는 없으며, 실제로 발생하는 할증에 대해서만 출력하면 됩니다. 숫자로 해석할 수 없는 값은 건너뜁니다.

저장 시 매크로는 반드시 컴파일되고 중립적인 테스트 값으로 한 번 시험 실행됩니다. 구문 오류와 실행 오류(예: 괄호 불균형이나 미완성된 식)는 이때 확실하게 표시되며, 기능이 없는 매크로로 조용히 이어지지 않습니다.

예: 할증 수당 계산 ("AllShift")

함께 제공되는 "근무" 카테고리의 표준 매크로입니다. 자정을 넘는 교대근무를 올바르게 처리하며(세그먼트 분할) 야간, 공휴일, 그리고 설정 가능한 세 개의 주말 요일에 대한 할증을 계산하고, 세그먼트별로 적용 가능한 최고 요율을 적용합니다(최고 우선). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

설명

  • 세그먼트 분할: 자정을 넘는 교대근무(예: 22:00-06:00)의 경우 교대를 2개 세그먼트(자정까지 / 자정부터)로 분할하며, 각각 고유한 요일/공휴일 플래그를 가집니다
  • SegBonusForType: 야간, 공휴일, 주말 할증을 고려하여 세그먼트와 특정 할증 타입(10-14)에 대한 할증을 계산합니다
  • 토/일 대신 WE1/WE2/WE3: weekendday1-3은 주말 요일을 설정 가능하게 만듭니다(모든 국가가 토요일/일요일을 주말로 하지는 않습니다)
  • 세그먼트별 최고 할증: NRate/DRate는 야간 및 주간 시간에 각각 적용 가능한 최고 요율을 산출합니다 – 최고 우선, 중복 적용 없음
  • HolidayNextDay: 다음 날이 공휴일인지 고려합니다(자정을 넘는 야간 교대근무에 중요)
  • 여러 OUTPUT 줄: 1번 줄은 총합을 반환하고, 10-14번 줄은 개별 할증 금액을 반환합니다("반환값" 섹션 참조)

가산형 변형 ("AllShiftAdditive")

동일한 카테고리의 표준(가산형) 매크로는 동일한 IMPORT 줄과 동일한 전체 구조를 가집니다 – 다른 점은 SegBonusForType뿐입니다: 최고 요율 대신, 각 할증 타입이 해당하는지를 독립적으로 계산하며, 해당하는 모든 금액을 마지막에 합산합니다(더 이상 최고 우선이 아님): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

예를 들어 야간 교대근무가 동시에 공휴일에 해당하는 경우, "AllShift"에서는 둘 중 더 높은 요율만 적용되지만, "AllShiftAdditive"에서는 야간 할증과 공휴일 할증이 함께 적용됩니다. 스크립트의 나머지 부분(세그먼트 분할, 합산, OUTPUT 줄)은 위의 "AllShift"와 동일합니다.
