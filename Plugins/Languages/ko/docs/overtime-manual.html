초과근무

이 설정은 추가 근무가 언제부터 초과근무로 간주되는지와 어떤 할증률로 지급되는지를 결정합니다. 3단계를 통해 단계별 할증을 구현할 수 있습니다. 이 값은 회사 전체의 기본값으로 적용됩니다.

계산 기준

각 단계의 시간 임계값을 판단하는 기준 기간입니다.

  • 일별: 초과근무를 근무일 단위로 산정합니다.
  • 주별: 초과근무를 주 단위로 산정합니다.

할증 모드

단계별 할증 값을 어떻게 해석할지를 결정합니다.

  • 배율: 시급에 곱하는 계수입니다. 할증은 백분율로 입력합니다(예: 25%는 계수 1.25, 즉 25% 할증을 의미합니다).
  • 시간당 고정 금액: 백분율 계수 대신 초과근무 시간당 고정 금액을 적용합니다.

1~3단계

각 단계는 시간 임계값과 할증으로 구성됩니다. 선택한 기준 기간 내에 실제 근무 시간이 임계값을 초과하는 즉시 해당 단계가 적용됩니다. 상위 단계는 더 높은 할증을 위한 추가 임계값을 나타냅니다.

  • 시작 시간: 해당 단계가 적용되기 시작하는 시간 임계값입니다.
  • 할증(%): 해당 단계의 할증률이며 백분율로 입력합니다.
  • 사용하지 않는 단계는 비워두세요. 그러면 해당 단계는 적용되지 않습니다.
