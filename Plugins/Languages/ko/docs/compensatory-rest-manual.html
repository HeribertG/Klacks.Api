대체 휴식

이 설정은 대체 휴식을 제어합니다. 두 근무 사이의 법정 최소 휴식 시간이 충족되지 않으면, 부족한 휴식 시간을 일정 기간 내에 대체 휴식으로 보충해야 합니다. 이 값은 사업장 전체의 기본값으로 적용됩니다.

대체 휴식 활성화

대체 휴식 검사를 켜거나 끕니다. 옵션이 비활성화되면 기간이 적용되지 않습니다.

  • 기본값: 비활성화.

기간(일)

최소 휴식 시간 미달 후 대체 휴식이 제공되어야 하는 일수입니다.

  • 0 이상의 정수 값.
  • 예: 14는 대체 휴식이 2주 이내에 이루어져야 함을 의미합니다.

표준 휴식 시간 출처

대체 휴식을 유발하는 표준 휴식 시간의 임계값은 계획 규칙의 최소 휴게 시간 (계획 규칙 / 표준 값)에서 파생되며 해당 위치에서 편집할 수 있습니다. 이 카드에서는 관리되지 않습니다. 해당 위치에서 최소 휴게 시간을 변경하면 대체 휴식에도 영향을 미칩니다.
