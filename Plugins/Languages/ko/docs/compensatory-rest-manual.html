보상휴식

이 설정은 보상휴식을 제어합니다. 두 근무 사이의 법정 최소 휴식 시간이 충족되지 않으면, 부족한 휴식 시간을 기한 내에 보상휴식으로 보충해야 합니다. 이 값은 회사 전체의 기본값으로 적용됩니다.

보상휴식 활성화

보상휴식 검사를 켜거나 끕니다. 이 옵션을 비활성화하면 기한 및 자동 계획 기능이 적용되지 않습니다.

  • 기본값: 비활성화.

기한(일)

최소 휴식 시간 미달 이후 보상휴식이 부여되어야 하는 일수입니다.

  • 0 이상의 정수 값.
  • 예: 14는 보상휴식이 2주 이내에 이루어져야 함을 의미합니다.

자동 계획

시스템이 보상휴식이 필요한 시점을 근무표에 자동으로 반영할지 여부를 결정합니다. 이 옵션을 비활성화하면 부족한 보상휴식에 대한 안내만 표시됩니다.

  • 기본값: 비활성화.

표준 휴식 시간의 출처

보상휴식을 발생시키는 표준 휴식 시간의 임계값은 계획 기본 설정(계획 규칙 / 기본값)의 최소 휴식 시간에서 파생되며 해당 위치에서 수정할 수 있습니다. 이 카드에서는 관리되지 않습니다. 그곳에서 최소 휴식 시간을 변경하면 보상휴식에도 영향을 미칩니다.
