수식 필드 매뉴얼

기본 문법

모든 수식 필드는 output 명령으로 결과를 출력합니다:

output 1, <표현식>

첫 번째 매개변수 1은 메시지 유형이며 항상 1이어야 합니다. 두 번째 매개변수는 출력할 값입니다.

간단한 예:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " 건"

사용 가능한 변수

변수 탭에 사용 가능한 변수가 나열되어 있으며, 여기서 테스트 값을 지정할 수 있습니다. 리포트 유형에 따라 사용할 수 있는 변수가 다릅니다:

리포트 유형표 하단 합계 항목
근무 일정표totalRows, totalHours, totalSurcharges, totalWorkDays
부재totalRows, totalValue
주소totalRows
그룹totalRows

연산자

연산자설명예
+덧셈totalHours + 2
-뺄셈totalRows - 1
*곱셈totalValue * 1.5
/나눗셈totalHours / 8
^거듭제곱2 ^ 10
\정수 나눗셈10 \ 3 → 3
MOD나머지(모듈로)10 MOD 3 → 1
&문자열 연결"합계: " & totalRows

내장 함수

형 변환

함수설명
CStr(x)숫자를 텍스트로 변환
CInt(x)정수로 변환
CDbl(x)소수(실수)로 변환

수학

함수설명
Abs(x)절댓값
Round(x, n)소수점 n자리로 반올림
Int(x)정수로 내림
Sqr(x)제곱근
Sgn(x)부호(-1, 0, 1)

텍스트

함수설명
Len(s)텍스트 길이
Left(s, n)왼쪽에서 n글자
Right(s, n)오른쪽에서 n글자
Mid(s, pos, n)pos 위치부터 n글자
UCase(s)대문자로 변환
LCase(s)소문자로 변환
Trim(s)양 끝의 공백 제거
Replace(s, alt, neu)텍스트 치환

조건 로직

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "항목이 많습니다"
ELSEIF totalRows > 0 THEN
    output 1, "항목이 적습니다"
ELSE
    output 1, "항목이 없습니다"
ENDIF

한 줄 IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF(축약형)

output 1, IIF(totalRows > 0, "OK", "비어 있음")

변수와 반복문

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

실전 예제

텍스트와 함께 항목 수 출력

output 1, CStr(totalRows) & " 건"

반올림한 값(소수점 1자리)

output 1, CStr(Round(totalValue, 1))

시간을 h:mm 형식으로

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

조건부 출력

IF totalRows = 0 THEN
    output 1, "부재 기록 없음"
ELSE
    output 1, CStr(totalRows) & " 건의 부재 (합계: " & CStr(totalValue) & ")"
ENDIF

평균 계산

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/일"
ELSE
    output 1, "-"
ENDIF
참고: 스크립트 인터프리터는 파일 시스템이나 네트워크에 접근할 수 없는 안전한 샌드박스 환경에서 실행됩니다.
