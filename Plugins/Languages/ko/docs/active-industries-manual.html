활성 업종

Klacks는 다섯 개 업종(재가 돌봄, 의료, 보안, 시설관리, 물류)에 대한 템플릿 콘텐츠를 제공합니다. 이 카드는 이 중 어떤 업종이 귀사에서 활성 상태로 간주되는지를 제어합니다.

선택의 영향

활성 업종의 템플릿(예: 계획 규칙 템플릿, 자격 요건 템플릿)만 애플리케이션 전체의 선택 목록에 표시됩니다. 업종을 비활성화하면 이 목록들만 필터링됩니다.

  • 비활성화된 업종의 템플릿은 그대로 유지됩니다 — 삭제되지 않습니다.
  • 업종을 다시 활성화하면 해당 템플릿이 즉시 다시 표시됩니다.

기본값

이 설정을 한 번도 저장한 적이 없는 경우, 다섯 업종 모두 활성 상태입니다.

유효성 검사

최소 하나의 업종은 활성 상태로 유지되어야 합니다. 선택 항목이 비어 있으면 저장되지 않으며, 최소 하나의 업종이 다시 선택될 때까지 카드에 안내 문구가 표시됩니다.
