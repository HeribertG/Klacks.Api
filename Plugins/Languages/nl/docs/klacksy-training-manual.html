Handleiding Klacksy-training

Wat is de trainingstool?

De trainingstool stuurt de in-page-navigatie van de chatbot Klacksy aan. Wanneer een gebruiker "Klacksy, toon mij de adressen" zegt of typt, navigeert Klacksy naar de juiste pagina en scrollt naar het bijbehorende gedeelte.

Om dit te laten werken, heeft Klacksy voor elk anker op een pagina een lijst met synoniemen in elke taal nodig (bijv. "Adressen", "Klanten", "Contacten" voor het doel addresses).

Tabblad "Doelen"

Lijst van alle in de frontend gevonden ankers (HTML-attribuut data-klacksy-target). Statusfilter:

  • pending: anker bestaat, maar nog geen synoniemen
  • generated: synoniemen zijn automatisch gegenereerd, moeten worden gecontroleerd
  • reviewed: synoniemen zijn door een beheerder goedgekeurd
  • needs-review: gemarkeerd voor hercontrole

Door op een doel te klikken, wordt de synoniemeneditor daaronder geopend. Daar kunnen synoniemen worden toegevoegd, verwijderd en met "Als gecontroleerd opslaan" vrijgegeven.

Tabblad "Feedback"

Toont gebruikersinvoer die Klacksy niet kon toewijzen (geen passend synoniem gevonden). Aan de hand van deze lijst is te zien welke synoniemen nog ontbreken.

Tabblad "Metrieken"

Overzicht van alle doelen per status. Helpt om de voortgang van de training te volgen.

Build-pipeline (CLI)

Wanneer templates nieuwe data-klacksy-target-ankers hebben gekregen, moeten het manifest en de initiële synoniemen opnieuw worden gegenereerd. De volgende commando's lopen ook automatisch in CI en in de Husky-pre-commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Templates scannen → navigation-targets.json met alle anchors
npm run scan:targets

# 2a. Initiële synoniemen genereren (alle 4 core + 22 plugin-locales, ~2,5 u)
npm run generate:synonyms

# 2b. Alleen core-locales (de/en/fr/it) — snel, ca. 9 min
npm run generate:synonyms -- --core-only

# 2c. Alleen ontbrekende plugin-locales aanvullen — ca. 45 min
npm run generate:synonyms -- --plugins-only

# 3. Wake-word-consistentie controleren
npm run wake-word-lint

Belangrijk: Bij npm run moet -- staan, zodat de opties aan het script worden doorgegeven. Zonder -- slikt npm de vlag in en draait het script in de standaardmodus.

Alternatief zonder npm: npx tsx tools/generate-synonyms.ts --core-only.

API-sleutel

De LLM-API-sleutel wordt in deze volgorde gezocht:

  1. Omgevingsvariabele SYNONYM_LLM_API_KEY
  2. DB-tabel llm_providers (provider deepseek, is_enabled = true) — automatisch via psql-aanroep
  3. Anders foutmelding

Standaardprovider is DeepSeek. Andere provider via SYNONYM_LLM_PROVIDER_ID=anthropic (of een andere ingerichte LLM-provider in de instellingen).

Stap 1 - scan:targets

Doorzoekt alle Angular-templates op data-klacksy-target-attributen en genereert het manifest Application/Skills/Definitions/navigation-targets.json. Elk nieuw anker verschijnt daarna in het tabblad "Doelen" met status pending.

Stap 2 - generate:synonyms

Genereert voor elk nieuw anker initiële synoniemen uit de data-klacksy-label-key en de categorie. Status daarna: generated (moet door de beheerder gereviewd worden).

Het script schrijft om de 5 targets manifest-checkpoints weg, zodat een onderbreking geen reeds gegenereerde gegevens verliest.

Stap 3 - wake-word-lint

Controleert de consistentie van de wake-word-variant (Hallo Klacksy / Hey Klacksy / ...) over alle talen. Voorkomt dat synoniemen het wake-word overschrijven.

Voice-modus

Het microfoonpictogram in de chat activeert de voice-modus. Zodra actief:

  • Microfoon luistert mee en transcribeert continu
  • Bij korte stilte → automatisch versturen van de tot dan toe getranscribeerde tekst

Belangrijk: Zodra u in het tekstveld begint te typen, wordt de voice-modus automatisch beëindigd — anders zou de microfoon uw getypte tekst met eigen transcripties overschrijven en voortijdig versturen.

Typische trainingscyclus

  1. Anker in template toevoegen: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. API opnieuw starten (cache wordt bij het starten opnieuw ingelezen)
  4. Tabblad "Doelen" openen → nieuwe targets verschijnen met status generated
  5. Synoniemen controleren/aanvullen → "Als gecontroleerd opslaan" → status reviewed
  6. Testen met Klacksy, bijv. "Klacksy, toon mij de adressen"
  7. Indien Klacksy geen match vindt → tabblad "Feedback" → ontbrekend synoniem toevoegen
  8. Tabblad "Metrieken" bewaken totdat alles reviewed is
