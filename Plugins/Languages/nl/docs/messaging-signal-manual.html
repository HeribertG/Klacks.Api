Signal-messaging instellen

Vereisten

Om Signal-berichten via Klacks te verzenden, hebt u een zelfgehoste instantie van de signal-cli-rest-api nodig. Dit is een open-source-project dat Signal via een REST-interface toegankelijk maakt.

  • Docker moet op de server geïnstalleerd zijn
  • Een telefoonnummer dat bij Signal wordt geregistreerd (een toegewijd nummer wordt aanbevolen)
  • De Docker-image: bbernhard/signal-cli-rest-api

Belangrijk: de Signal-koppeling is uitsluitend voor het verzenden bedoeld. Inkomende Signal-berichten worden niet ontvangen in Klacks.

Stap 1 — signal-cli-rest-api instellen

  1. Start de container met Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Koppel uw Signal-nummer via de QR-linkmethode: open in de browser 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    en scan de weergegeven QR-code met de Signal-app op de telefoon waarop het nummer geregistreerd is (Instellingen → Gekoppelde apparaten → Apparaat koppelen). De container wordt daarmee als tweede apparaat gekoppeld.
  3. Als alternatief kunt u het nummer zelfstandig via de API registreren — details hierover vindt u in de documentatie van het project.
  4. Test de API met een healthcheck: 
    curl http://localhost:8080/v1/about

Opmerking: meer details over de configuratie vindt u in de signal-cli-rest-api-documentatie.

Stap 2 — Signal configureren in Klacks

  1. Navigeer naar Instellingen → Messaging-providers.
  2. Klik op Toevoegen.
  3. Vul de velden als volgt in:
VeldBeschrijvingVoorbeeld
NaamInterne unieke naamsignal-main
WeergavenaamWordt getoond in de interfaceSignal
ProvidertypeKies SignalSignal
Signal-nummerHet geregistreerde telefoonnummer in internationaal formaat+41791234567
Signal-CLI API-URLURL van de signal-cli-rest-api-container. Draait de container op dezelfde server als Klacks, dan mag hier http://localhost:8080 staan.http://localhost:8080
IngeschakeldSchakelt de provider in/uitJa
  1. Klik op Opslaan.
  2. Test de verbinding via de knop Test in de providerlijst. De test controleert of het opgegeven nummer in de container geregistreerd is.

Opmerking: Klacks verzendt berichten via het eindpunt POST /v2/send van de container.

Stap 3 — Berichten verzenden via de chatbot (Klacksy)

Zodra de Signal-provider geconfigureerd en ingeschakeld is, kan de chatbot Klacksy berichten verzenden. U hoeft geen telefoonnummers te kennen — gebruik gewoon de naam van de medewerker of cliënt: 

"Stuur Max Muster een bericht: uw afspraak is morgen om 14:00 uur."
"Stuur Anna Beispiel een Signal-bericht: de dienst is geruild."
"Informeer Peter Müller dat zijn dienst op maandag vervalt."

Klacksy zoekt automatisch het opgeslagen mobiele nummer van de ontvanger op en gebruikt de geconfigureerde Signal-provider. Het verzenden is voor u volledig transparant — u werkt met namen, Klacksy zorgt voor de rest.

Vereiste: bij de ontvanger moet een mobiel nummer in Klacks zijn vastgelegd (onder Adres → Contactgegevens), in internationaal formaat (bijv. +41791234567). Ook bij broadcastberichten valt het Signal-verzendproces terug op het vastgelegde mobiele nummer.

Inkomende berichten

De Signal-koppeling ondersteunt geen ontvangst — antwoorden op verzonden berichten worden niet naar Klacks overgedragen. De messaging-inbox toont voor deze provider daarom geen inkomende berichten.

Problemen oplossen

ProbleemMogelijke oorzaakOplossing
Verbindingstest mislukt Container niet bereikbaar Controleer of de Docker-container draait (docker ps) en of de API-URL correct is
Verbindingstest mislukt Nummer niet in de container geregistreerd Herhaal de koppeling via de QR-linkmethode
Bericht wordt niet afgeleverd Ontvanger gebruikt geen Signal of nummer onjuist Zorg ervoor dat de ontvanger Signal geïnstalleerd heeft en het nummer in het formaat +{landcode}{nummer} is vastgelegd
Koppeling verloren Apparaat werd in de Signal-app ontkoppeld Koppel de container opnieuw via de QR-link
Container start niet Poort 8080 al in gebruik Gebruik een andere poort: -p 9090:8080 en pas de API-URL in Klacks aan
