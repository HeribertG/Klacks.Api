Handleiding formulevelden

Basissyntaxis

Elk formuleveld geeft het resultaat weer met het output-commando:

output 1, <expressie>

De eerste parameter 1 is het berichttype en moet altijd 1 zijn. De tweede parameter is de uit te voeren waarde.

Eenvoudige voorbeelden:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " items"

Beschikbare variabelen

De beschikbare variabelen zijn te vinden op het tabblad Variabelen en kunnen daar van testwaarden worden voorzien. Afhankelijk van het reporttype zijn verschillende variabelen beschikbaar:

Voorwaardelijke logica

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "veel items"
ELSEIF totalRows > 0 THEN
    output 1, "weinig items"
ELSE
    output 1, "geen items"
ENDIF

IF op één regel

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (verkorte vorm)

output 1, IIF(totalRows > 0, "OK", "Leeg")

Variabelen en lussen

DIM i, som
som = 0
FOR i = 1 TO totalRows
    som = som + 1
NEXT
output 1, CStr(som)

Praktische voorbeelden

Aantal items met tekst

output 1, CStr(totalRows) & " items"

Afgerond getal (1 decimaal)

output 1, CStr(Round(totalValue, 1))

Uren als h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Voorwaardelijke uitvoer

IF totalRows = 0 THEN
    output 1, "Geen afwezigheden"
ELSE
    output 1, CStr(totalRows) & " afwezigheden (totaal: " & CStr(totalValue) & ")"
ENDIF

Gemiddelde berekenen

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " u/dag"
ELSE
    output 1, "-"
ENDIF
