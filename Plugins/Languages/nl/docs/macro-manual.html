Handleiding Macro-scripting

Inleiding

De macro-editor maakt het mogelijk scripts te schrijven die als berekeningsbasis dienen voor diensten, werkactiviteiten, enz.

Voorbeelden van gebruik:

  • Exacte urenberekening voor vakantie of militaire dienst op basis van het dienstverband
  • Berekening van toeslagen voor nachtwerk, weekenden en feestdagen
  • Flexibele aanpassing aan nieuwe vereisten

Opmerking: De scriptinterpreter draait in een veilige sandbox-omgeving zonder toegang tot het bestandssysteem of het netwerk. Het is niet mogelijk kwaadaardige code uit te voeren.

Functie en categorie

Naast naam en scriptinhoud heeft elke macro in de macrolijst twee andere eigenschappen, die via dropdowns in de editor worden ingesteld: Categorie en Functie. Beide zijn pure metadata – ze staan buiten het script en veranderen de berekening ervan niet, maar bepalen hoe Klacks automatisch de juiste macro vindt en toewijst.

Categorie

De categorie kent een macro toe aan een functioneel toepassingsgebied:

CategorieGebruik
Niet toegewezenGeen specifiek toepassingsgebied (standaard voor nieuwe macro's)
DienstToeslagberekening voor reguliere diensten (nacht-, weekend-, feestdagtoeslag)
VakantieUrenberekening voor vakantie
ZiekteUrenberekening voor ziekte
OngevalUrenberekening voor ongeval
Workshop (betaald)Betaalde workshop-/opleidingstijd
Workshop (onbetaald)Onbetaalde workshop-/opleidingstijd

De categorie Dienst heeft een bijzondere rol: nieuw aangemaakte diensten krijgen automatisch de standaardmacro van deze categorie toegewezen (zie "Functie" hieronder). Reeds bestaande diensten worden daarbij nooit achteraf gewijzigd.

Functie: aangepast, standaard, standaard (additief)

De functie classificeert de rol van een macro binnen zijn categorie:

FunctieBetekenis
AangepastVrije macro zonder bijzondere rol. Onbeperkt aantal per categorie mogelijk.
StandaardDe standaardmacro van deze categorie – wordt automatisch aan nieuwe diensten toegewezen. Ten hoogste ÉÉN macro per categorie mag deze functie dragen.
Standaard (additief)Alternatieve standaardmacro met additieve toeslaglogica (zie hieronder). Eveneens ten hoogste één per categorie, naast de "Standaard"-macro mogelijk.

Belangrijk: De functie berekent op zichzelf niets – het is een label. Of toeslagen "highest-wins" (alleen het hoogste geldende tarief telt) of additief (alle geldende tarieven worden opgeteld) worden berekend, bepaalt het script zelf. De twee meegeleverde categorie-"Dienst"-macro's tonen het verschil met dezelfde basisstructuur:

  • "AllShift" (Functie: Standaard) – bepaalt per tijdsegment de hoogste geldende toeslag (nacht/WE1/WE2/WE3/feestdag) en gebruikt alleen deze.
  • "AllShiftAdditive" (Functie: Standaard (additief)) – berekent nacht-, weekend- en feestdagtoeslag onafhankelijk van elkaar en telt ze op.

Welke van de twee automatisch wordt toegewezen bij het aanmaken van een nieuwe dienst, wordt bepaald door een installatiebrede instelling ("additief" of "hoogste tarief wint"). Per dienst kan de macro daarna op elk moment handmatig worden gewisseld – gemengd gebruik is dus mogelijk.

Uniciteit: probeert u een tweede macro van dezelfde categorie eveneens als "Standaard" of "Standaard (additief)" op te slaan, dan blokkeert de editor het opslaan en noemt de naam van de reeds toegewezen macro. Zet eerst de functie daarvan op "Aangepast".

Handmatige wijzigingen aan "AllShift"/"AllShiftAdditive" worden afgeraden. Deze twee macro's zijn het mechanisme waarmee land- en branchespecifieke aanpassingen automatisch worden doorgevoerd: zolang u ze ongewijzigd laat, houdt Klacks ze automatisch synchroon met de regels die passen bij uw land resp. uw branche. Bewerkt u een van beide handmatig, dan geldt deze vanaf dat moment als klanteigen – toekomstige automatische land-/ branche-updates voor deze macro worden dan niet meer stilzwijgend overgenomen, maar mislukken met een conflict totdat u de afwijking handmatig oplost. Heeft u een eigen toeslaglogica nodig, maak dan in plaats daarvan een nieuwe macro aan met functie "Aangepast" en wijs deze gericht toe aan de betreffende diensten.

Besturingsstructuren

Belangrijk: Sleutelwoorden zoals ENDIF, ENDFUNCTION, ENDSUB moeten aaneengeschreven worden (niet END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "groot"
ELSEIF x > 5 THEN
    OUTPUT 1, "middelgroot"
ELSE
    OUTPUT 1, "klein"
ENDIF

IF op één regel

IF x > 10 THEN OUTPUT 1, "groot" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Weekend"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Werkdag"
    CASE ELSE
        OUTPUT 1, "Onbekend"
END SELECT

FOR-NEXT-lus

FOR i = 1 TO 10
    som += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

DO-LOOP-lus

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Functies en procedures

Belangrijk: Functies (FUNCTION) en procedures (SUB) moeten vóór de eerste aanroep worden gedefinieerd. De interpreter leest de code van boven naar beneden: een functie of procedure is pas bekend nadat de definitie is verwerkt.

SUB (procedure zonder retourwaarde)

SUB berekenen(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (functie met retourwaarde)

FUNCTION verdubbelen(x)
    verdubbelen = x * 2
ENDFUNCTION

DIM resultaat
resultaat = verdubbelen(21)
OUTPUT 1, resultaat

Waarden retourneren (OUTPUT)

OUTPUT type, waarde

type en waarde zijn twee door een komma gescheiden expressies; beide zijn optioneel (standaard 0 resp. "", indien weggelaten). Een macro mag een willekeurig aantal OUTPUT-regels bevatten – elke regel genereert een eigen retourwaarde. Klacks evalueert daarbij alleen de volgende typen:

TypeBetekenis
1Hoofdresultaat (uren resp. totaalbedrag) – wordt ook bij waarde 0 overgenomen
10Nachttoeslag
11Toeslag voor weekenddag 1 (bijv. zaterdag)
12Toeslag voor weekenddag 2 (bijv. zondag)
13Toeslag voor weekenddag 3 (derde configureerbare weekenddag)
14Feestdagtoeslag

Toeslagregels (type 10-14) met waarde 0 worden genegeerd – een macro hoeft dus niet voor elk toeslagtype een eigen regel uit te voeren, maar alleen voor daadwerkelijk optredende toeslagen. Waarden die niet als getal kunnen worden geïnterpreteerd, worden overgeslagen.

Bij het opslaan wordt de macro verplicht gecompileerd en één keer proefondervindelijk uitgevoerd met neutrale testwaarden. Syntax- en runtimefouten (bijv. onbalans in haakjes of een hangende expressie) worden daarbij betrouwbaar getoond in plaats van stilzwijgend te leiden tot een functieloze macro.

Voorbeeld: Toeslagberekening ("AllShift")

De meegeleverde standaardmacro van de categorie "Dienst". Berekent toeslagen voor nachtwerk, feestdagen en de drie configureerbare weekenddagen met correcte behandeling van diensten die middernacht overschrijden (segmentdeling) en past per segment het hoogste geldende tarief toe (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Uitleg

  • Segmentdeling: Bij diensten die middernacht overschrijden (bijv. 22:00-06:00) wordt de dienst in twee segmenten opgedeeld (tot middernacht / vanaf middernacht), elk met een eigen weekdag-/feestdagvlag
  • SegBonusForType: Berekent de toeslag voor een segment en een bepaald toeslagtype (10-14) rekening houdend met nacht-, feestdag- en weekendtoeslagen
  • WE1/WE2/WE3 in plaats van Za/Zo: weekendday1-3 maken de weekenddagen configureerbaar (niet elk land heeft zaterdag/zondag als weekend)
  • Hoogste toeslag per segment: NRate/DRate bepalen telkens het hoogste geldende tarief voor nacht- resp. daguren – highest-wins, geen stapeling
  • HolidayNextDay: Houdt rekening met of de volgende dag een feestdag is (belangrijk voor nachtdiensten over middernacht)
  • Meerdere OUTPUT-regels: Regel 1 levert het totaalbedrag, regels 10-14 leveren de afzonderlijke toeslagbedragen (zie hoofdstuk "Waarden retourneren")

De additieve variant ("AllShiftAdditive")

Het standaard-(additief)-macro van dezelfde categorie heeft identieke IMPORT-regels en dezelfde raamstructuur – alleen SegBonusForType verschilt: in plaats van het hoogste tarief wordt voor elk toeslagtype onafhankelijk berekend of het van toepassing is, en alle geldende bedragen worden aan het einde opgeteld (geen highest-wins meer): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Valt een nachtdienst bijvoorbeeld ook op een feestdag, dan krijgt deze bij "AllShift" alleen het hoogste van de twee tarieven, bij "AllShiftAdditive" daarentegen nacht- en feestdagtoeslag samen. De rest van het script (segmentdeling, optelling, OUTPUT-regels) is identiek aan "AllShift" hierboven.
