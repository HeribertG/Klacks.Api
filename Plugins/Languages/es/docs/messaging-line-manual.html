Configurar la mensajería de LINE

Requisitos previos

Para enviar y recibir mensajes a través de LINE, necesita una LINE Official Account con un canal de la Messaging API en la LINE Developers Console. LINE está especialmente extendido en Japón, Taiwán y Tailandia.

Nota: los mensajes push tienen una cuota mensual según el plan de LINE (el plan gratuito está limitado). Consulte las condiciones actuales de su plan de Official Account.

Paso 1 — Crear la LINE Official Account y el canal de la Messaging API

  1. Cree una LINE Official Account (a través del LINE Official Account Manager).
  2. Abra la LINE Developers Console (developers.line.biz) y cree un canal de la Messaging API, o bien vincule su Official Account con la Messaging API.
  3. Emita un Channel Access Token de larga duración en la pestaña Messaging API (Issue).
  4. Anote el Channel Secret de la pestaña Basic Settings.

Nota: trate el Channel Access Token y el Channel Secret como contraseñas. No los comparta públicamente y guárdelos de forma segura.

Paso 2 — Configurar LINE en Klacks

  1. Navegue a Configuración → Proveedores de mensajería.
  2. Haga clic en Añadir.

Paso 3 — Enviar mensajes a través del chatbot (Klacksy)

Una vez configurado y activado el proveedor de LINE, el chatbot Klacksy puede enviar mensajes. No necesita conocer ningún ID de usuario de LINE: basta con usar el nombre del empleado o del cliente: 

"Envía un mensaje a Max Muster: su cita es mañana a las 14:00."
"Manda un mensaje a Anna Beispiel: el turno se ha intercambiado."
"Avisa a Peter Müller de que su servicio del lunes se cancela."

Klacksy busca automáticamente el ID de usuario de LINE registrado del destinatario y utiliza el proveedor de LINE configurado. El envío es completamente transparente para usted: usted trabaja con nombres, Klacksy se encarga del resto.

Requisito: el destinatario debe tener registrado el ID de usuario de LINE (comienza con U…) en Klacks (en Dirección → Datos de contacto). El ID de usuario se conoce a través de los mensajes entrantes (visible en la bandeja de entrada de mensajería); para ello el destinatario debe haber añadido su Official Account como amigo y haberle enviado un mensaje.

Paso 4 — Recibir mensajes entrantes (webhook)

Para mostrar los mensajes entrantes de LINE en Klacks, la URL del webhook debe introducirse manualmente en la LINE Developers Console.

  1. Copie la URL del webhook mostrada en Klacks desde la configuración del proveedor: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. Introduzca esta URL en la LINE Developers Console en Messaging API → Webhook settings como Webhook URL.
  3. Active la opción «Use webhook».
  4. Asegúrese de que su instancia de Klacks sea accesible públicamente por HTTPS.
  5. Los mensajes entrantes aparecerán ahora en tiempo real en la bandeja de entrada de mensajería.

Solución de problemas

ProblemaPosible causaSolución
La prueba de conexión falla Channel Access Token no válido Emita un nuevo token en la LINE Developers Console
El mensaje no se entrega El destinatario no ha añadido el Official Account como amigo o lo ha bloqueado El destinatario debe añadir la cuenta como amigo en LINE
El envío falla Cuota mensual de push agotada Revise la cuota de su plan en el LINE Official Account Manager
Destinatario no encontrado ID de usuario de LINE no registrado Introduzca el ID de usuario desde la bandeja de entrada de mensajería en Dirección → Datos de contacto
Faltan los mensajes entrantes URL del webhook no introducida o «Use webhook» desactivado Revise la configuración del webhook en la LINE Developers Console
