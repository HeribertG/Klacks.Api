Descanso compensatorio

Estos ajustes controlan el descanso compensatorio: si no se respeta el tiempo de descanso mínimo legal entre dos turnos, el descanso faltante debe recuperarse como descanso compensatorio dentro de un plazo. Los valores rigen como valor predeterminado para toda la empresa.

Activado

Activa o desactiva la comprobación del descanso compensatorio. Si la opción está desactivada, el plazo y la planificación automática no se aplican.

  • Predeterminado: desactivado.

Plazo (días)

Número de días dentro de los cuales debe concederse el descanso compensatorio tras no haberse respetado el tiempo de descanso mínimo.

  • Valor entero a partir de 0.
  • Ejemplo: 14 significa que el descanso compensatorio debe realizarse dentro de dos semanas.

Planificar automáticamente

Determina si el sistema planifica de forma autónoma el descanso compensatorio pendiente en el plan de turnos. Si la opción está desactivada, solo se indica el descanso compensatorio faltante.

  • Predeterminado: desactivado.

Origen del tiempo de descanso estándar

El umbral del tiempo de descanso estándar a partir del cual se activa un descanso compensatorio se deriva de la pausa mínima en los valores predeterminados de planificación (reglas de planificación / valores predeterminados) y se puede editar allí; no se gestiona en esta tarjeta. Si modifica la pausa mínima allí, esto también afecta al descanso compensatorio.
