Manual de Scripting de Macros

Introducción

El editor de macros permite escribir scripts que se utilizan como base de cálculo para servicios, actividades laborales, etc.

Ejemplos de uso:

  • Cálculo exacto de horas para vacaciones o servicio militar según el grado de ocupación
  • Cálculo de recargos por trabajo nocturno, fines de semana y días festivos
  • Adaptación flexible a nuevos requisitos

Nota: El intérprete de scripts se ejecuta en un entorno sandbox seguro sin acceso al sistema de archivos ni a la red. No es posible ejecutar código malicioso.

Función y categoría

Además del nombre y el contenido del script, cada macro en la lista de macros tiene dos propiedades adicionales, que se establecen mediante menús desplegables en el editor: Categoría y Función. Ambas son metadatos puros: están fuera del script y no modifican su cálculo, sino que controlan cómo Klacks encuentra y asigna automáticamente el macro adecuado.

Categoría

La categoría asigna un macro a un ámbito de aplicación específico:

CategoríaUso
Sin asignarSin ámbito de aplicación especial (valor predeterminado para macros nuevos)
TurnoCálculo de recargos para turnos regulares (recargo nocturno, de fin de semana, de festivo)
VacacionesCálculo de horas para vacaciones
EnfermedadCálculo de horas para enfermedad
AccidenteCálculo de horas para accidente
Taller (remunerado)Tiempo de taller/formación remunerado
Taller (no remunerado)Tiempo de taller/formación no remunerado

La categoría Turno tiene un papel especial: los turnos recién creados reciben automáticamente el macro estándar de esta categoría (véase "Función" más abajo). Los turnos ya existentes nunca se modifican posteriormente por este motivo.

Función: Personalizado, Estándar, Estándar (aditivo)

La función clasifica el papel de un macro dentro de su categoría:

FunciónSignificado
PersonalizadoMacro libre sin papel especial. Se permiten tantos como se desee por categoría.
EstándarEl macro estándar de esta categoría: se asigna automáticamente a los turnos nuevos. Como máximo UN macro por categoría puede tener esta función.
Estándar (aditivo)Macro estándar alternativo con lógica de recargo aditiva (véase más abajo). También como máximo uno por categoría, adicional al macro "Estándar".

Importante: La función por sí sola no calcula nada; es una etiqueta. Si los recargos se calculan según el principio "gana el más alto" (solo cuenta la tasa más alta aplicable) o de forma aditiva (se suman todas las tasas aplicables) lo decide el propio script. Los dos macros de categoría "Turno" incluidos de serie muestran la diferencia sobre la misma estructura base:

  • "AllShift" (Función: Estándar): determina, para cada segmento de tiempo, el recargo aplicable más alto (nocturno/WE1/WE2/WE3/festivo) y utiliza únicamente ese.
  • "AllShiftAdditive" (Función: Estándar (aditivo)): calcula el recargo nocturno, de fin de semana y de festivo de forma independiente entre sí y los suma.

Qué macro de los dos se asigna automáticamente al crear un turno nuevo lo controla un ajuste a nivel de instalación ("aditivo" o "gana la tasa más alta"). El macro de cada turno puede cambiarse manualmente en cualquier momento después, por lo que es posible un funcionamiento mixto.

Unicidad: si intenta guardar un segundo macro de la misma categoría también como "Estándar" o "Estándar (aditivo)", el editor bloqueará el guardado e indicará el nombre del macro ya asignado. Cambie primero su función a "Personalizado".

No se recomienda modificar manualmente "AllShift"/"AllShiftAdditive". Estos dos macros son el mecanismo mediante el cual se aplican automáticamente las adaptaciones específicas de cada país y sector: mientras los deje sin modificar, Klacks los mantiene sincronizados automáticamente con las reglas adecuadas para su país o sector. Si edita manualmente alguno de los dos, a partir de ese momento se considera propio del cliente: las futuras actualizaciones automáticas de país/sector para ese macro ya no se aplicarán silenciosamente, sino que fallarán con un conflicto hasta que resuelva manualmente la discrepancia. Si necesita una lógica de recargo propia, cree en su lugar un nuevo macro con función "Personalizado" y asígnelo específicamente a los turnos afectados.

Estructuras de control

Importante: Las palabras clave como ENDIF, ENDFUNCTION, ENDSUB deben escribirse juntas (no END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "grande"
ELSEIF x > 5 THEN
    OUTPUT 1, "mediano"
ELSE
    OUTPUT 1, "pequeño"
ENDIF

IF en una sola línea

IF x > 10 THEN OUTPUT 1, "grande" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Fin de semana"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Día laborable"
    CASE ELSE
        OUTPUT 1, "Desconocido"
END SELECT

Bucle FOR-NEXT

FOR i = 1 TO 10
    suma += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Bucle DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Funciones y procedimientos

Importante: Las funciones (FUNCTION) y los procedimientos (SUB) deben definirse antes de la primera llamada. El intérprete lee el código de arriba a abajo: una función o procedimiento solo es conocido después de que su definición haya sido procesada.

SUB (procedimiento sin valor de retorno)

SUB calcular(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (función con valor de retorno)

FUNCTION duplicar(x)
    duplicar = x * 2
ENDFUNCTION

DIM resultado
resultado = duplicar(21)
OUTPUT 1, resultado

Retorno de valores (OUTPUT)

OUTPUT tipo, valor

tipo y valor son dos expresiones separadas por una coma; ambas son opcionales (por defecto 0 y "" respectivamente, si se omiten). Un macro puede contener tantas líneas OUTPUT como se desee: cada una genera su propio valor de retorno. Klacks solo evalúa los siguientes tipos:

TipoSignificado
1Resultado principal (horas o importe total) – se aplica también con valor 0
10Recargo nocturno
11Recargo para el día de fin de semana 1 (p. ej., sábado)
12Recargo para el día de fin de semana 2 (p. ej., domingo)
13Recargo para el día de fin de semana 3 (tercer día de fin de semana configurable)
14Recargo por festivo

Las líneas de recargo (tipo 10-14) con valor 0 se ignoran: un macro no necesita generar una línea propia para cada tipo de recargo, sino solo para los recargos que realmente se apliquen. Los valores que no puedan interpretarse como número se omiten.

Al guardar, el macro se compila obligatoriamente y se ejecuta una vez de prueba con valores de prueba neutros. Los errores de sintaxis y de ejecución (p. ej., paréntesis desequilibrados o una expresión incompleta) se muestran de forma fiable en lugar de dar lugar silenciosamente a un macro sin función.

Ejemplo: Cálculo de recargos ("AllShift")

El macro estándar incluido de la categoría "Turno". Calcula recargos por trabajo nocturno, festivo y los tres días de fin de semana configurables con el tratamiento correcto de turnos que cruzan la medianoche (división en segmentos) y aplica por segmento la tasa más alta aplicable (gana el más alto). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Explicación

  • División en segmentos: en turnos que cruzan la medianoche (p. ej., 22:00-06:00), el turno se divide en dos segmentos (hasta medianoche / desde medianoche), cada uno con su propio indicador de día de la semana/festivo
  • SegBonusForType: calcula el recargo de un segmento para un tipo de recargo determinado (10-14) teniendo en cuenta los recargos nocturno, por festivo y de fin de semana
  • WE1/WE2/WE3 en lugar de Sá/Do: weekendday1-3 hacen que los días de fin de semana sean configurables (no todos los países tienen sábado/domingo como fin de semana)
  • Recargo más alto por segmento: NRate/DRate determinan respectivamente la tasa más alta aplicable para las horas nocturnas y diurnas: gana el más alto, sin acumulación
  • HolidayNextDay: tiene en cuenta si el día siguiente es festivo (importante para turnos nocturnos que cruzan la medianoche)
  • Varias líneas OUTPUT: la línea 1 entrega la suma total, las líneas 10-14 entregan los importes de recargo individuales (véase la sección "Retorno de valores")

La variante aditiva ("AllShiftAdditive")

El macro estándar (aditivo) de la misma categoría tiene líneas IMPORT idénticas y la misma estructura general; solo SegBonusForType es diferente: en lugar de la tasa más alta, se calcula de forma independiente para cada tipo de recargo si es aplicable, y todos los importes aplicables se suman al final (ya no hay "gana el más alto"): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Si, por ejemplo, un turno nocturno cae además en un día festivo, con "AllShift" solo recibe la tasa más alta de las dos, mientras que con "AllShiftAdditive" recibe el recargo nocturno y el recargo por festivo juntos. El resto del script (división en segmentos, suma, líneas OUTPUT) es idéntico al de "AllShift" anterior.
