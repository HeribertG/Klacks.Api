Manual del campo de fórmula

Sintaxis básica

Cada campo de fórmula devuelve el resultado con el comando output:

output 1, <expresión>

El primer parámetro 1 es el tipo de mensaje y siempre debe ser 1. El segundo parámetro es el valor a mostrar.

Ejemplos simples:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " entradas"

Variables disponibles

Las variables disponibles están listadas en la pestaña Variables y allí se les pueden asignar valores de prueba. Según el tipo de informe, están disponibles distintas variables:

Lógica condicional

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "muchas entradas"
ELSEIF totalRows > 0 THEN
    output 1, "pocas entradas"
ELSE
    output 1, "sin entradas"
ENDIF

IF en una línea

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (forma abreviada)

output 1, IIF(totalRows > 0, "OK", "Vacío")

Variables y bucles

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Ejemplos prácticos

Número de entradas con texto

output 1, CStr(totalRows) & " entradas"

Valor redondeado (1 decimal)

output 1, CStr(Round(totalValue, 1))

Horas como h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Salida condicional

IF totalRows = 0 THEN
    output 1, "Sin ausencias"
ELSE
    output 1, CStr(totalRows) & " ausencias (Total: " & CStr(totalValue) & ")"
ENDIF

Calcular el promedio

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/día"
ELSE
    output 1, "-"
ENDIF
