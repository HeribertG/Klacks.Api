Configurar la mensajería de KakaoTalk

Requisitos previos

Para enviar mensajes a través de KakaoTalk, necesita una app en developers.kakao.com (Kakao Developers). KakaoTalk es la aplicación de mensajería dominante en Corea del Sur. La integración de Klacks utiliza la API de Kakao Developers («Enviar mensaje a amigos»).

Limitaciones importantes de la API de Kakao Developers:

  • La integración está diseñada solo para el envío: no hay recepción.
  • El token de acceso es de corta duración (aprox. 6 horas) y debe renovarse fuera de Klacks y volver a introducirse.
  • Los mensajes solo pueden enviarse a usuarios que estén conectados como «amigos» de Kakao de la app y que hayan aceptado recibir mensajes.
  • Para mensajes de negocio en producción (AlimTalk) en Corea se requiere un canal empresarial a través de agencias autorizadas; esta integración no cubre eso, ya que utiliza la API de Developers.

Paso 1 — Configurar la app de Kakao Developers

  1. Cree una app en developers.kakao.com.
  2. Active Kakao Login para la app.
  3. Habilite los scopes talk_message y friends.
  4. Obtenga un token de acceso mediante el flujo OAuth de Kakao Login (el usuario en cuyo nombre se envía debe aceptar los scopes).

Nota: trate el token de acceso como una contraseña. No lo comparta públicamente y guárdelo de forma segura.

Paso 2 — Configurar KakaoTalk en Klacks

  1. Navegue a Configuración → Proveedores de mensajería.
  2. Haga clic en Añadir.
  3. Rellene los campos de la siguiente manera:

Importante: el token de acceso caduca después de aprox. 6 horas. Klacks no lo renueva automáticamente; debe renovarlo externamente (mediante el flujo de refresh token de Kakao) y volver a introducirlo en Klacks.

Paso 3 — Enviar mensajes a través del chatbot (Klacksy)

Una vez configurado y activado el proveedor de KakaoTalk, el chatbot Klacksy puede enviar mensajes. No necesita conocer ningún ID: basta con usar el nombre del empleado o del cliente: 

"Envía un mensaje a Max Muster: su cita es mañana a las 14:00."
"Manda un mensaje a Anna Beispiel: el turno se ha intercambiado."
"Avisa a Peter Müller de que su servicio del lunes se cancela."

Klacksy busca automáticamente el identificador registrado del destinatario y utiliza el proveedor de KakaoTalk configurado. El envío es completamente transparente para usted: usted trabaja con nombres, Klacksy se encarga del resto.

Requisito: el destinatario debe tener registrado el UUID de amigo de la API de Kakao Friends en Klacks (en Dirección → Datos de contacto). El destinatario debe estar conectado como «amigo» de Kakao con la app; no se puede enviar a otros usuarios.

Mensajes entrantes

La integración de KakaoTalk no admite la recepción: las respuestas a los mensajes enviados no se transmiten a Klacks. Por ello, la bandeja de entrada de mensajería no muestra mensajes entrantes para este proveedor.
