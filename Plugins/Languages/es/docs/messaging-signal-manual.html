Configurar la mensajería de Signal

Requisitos previos

Para enviar mensajes de Signal a través de Klacks, necesita una instancia autoalojada de la signal-cli-rest-api. Se trata de un proyecto de código abierto que hace que Signal sea accesible a través de una interfaz REST.

  • Docker debe estar instalado en el servidor
  • Un número de teléfono que se registrará en Signal (se recomienda un número dedicado)
  • La imagen de Docker: bbernhard/signal-cli-rest-api

Importante: la integración de Signal está diseñada solo para el envío. Los mensajes entrantes de Signal no se reciben en Klacks.

Paso 1 — Configurar signal-cli-rest-api

  1. Inicie el contenedor con Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Vincule su número de Signal mediante el procedimiento de enlace por código QR: abra en el navegador 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    y escanee el código QR mostrado con la app de Signal en el teléfono en el que está registrado el número (Configuración → Dispositivos vinculados → Vincular un dispositivo). De esta manera, el contenedor se vincula como dispositivo secundario.
  3. Alternativamente, puede registrar el número usted mismo a través de la API; encontrará más detalles en la documentación del proyecto.
  4. Pruebe la API con una comprobación de estado: 
    curl http://localhost:8080/v1/about

Nota: encontrará más detalles sobre la configuración en la documentación de signal-cli-rest-api.

Paso 2 — Configurar Signal en Klacks

  1. Navegue a Configuración → Proveedores de mensajería.
  2. Haga clic en Añadir.
  3. Rellene los campos de la siguiente manera:
CampoDescripciónEjemplo
NombreNombre interno únicosignal-main
Nombre para mostrarSe muestra en la interfazSignal
Tipo de proveedorSeleccione SignalSignal
Número de SignalEl número de teléfono registrado en formato internacional+41791234567
URL de la API de Signal-CLIURL del contenedor signal-cli-rest-api. Si el contenedor se ejecuta en el mismo servidor que Klacks, puede indicarse http://localhost:8080.http://localhost:8080
ActivadoActiva/desactiva el proveedorSí
  1. Haga clic en Guardar.
  2. Pruebe la conexión con el botón Probar en la lista de proveedores. La prueba comprueba si el número indicado está registrado en el contenedor.

Nota: Klacks envía los mensajes a través del endpoint POST /v2/send del contenedor.

Paso 3 — Enviar mensajes a través del chatbot (Klacksy)

Una vez configurado y activado el proveedor de Signal, el chatbot Klacksy puede enviar mensajes. No necesita conocer ningún número de teléfono: basta con usar el nombre del empleado o del cliente: 

"Envía un mensaje a Max Muster: su cita es mañana a las 14:00."
"Manda un mensaje de Signal a Anna Beispiel: el turno se ha intercambiado."
"Avisa a Peter Müller de que su servicio del lunes se cancela."

Klacksy busca automáticamente el número móvil registrado del destinatario y utiliza el proveedor de Signal configurado. El envío es completamente transparente para usted: usted trabaja con nombres, Klacksy se encarga del resto.

Requisito: el destinatario debe tener un número móvil registrado en Klacks (en Dirección → Datos de contacto), en formato internacional (por ejemplo, +41791234567). También en los mensajes de difusión, el envío por Signal recurre al número móvil registrado.

Mensajes entrantes

La integración de Signal no admite la recepción: las respuestas a los mensajes enviados no se transmiten a Klacks. Por ello, la bandeja de entrada de mensajería no muestra mensajes entrantes para este proveedor.

Solución de problemas

ProblemaPosible causaSolución
La prueba de conexión falla Contenedor inaccesible Compruebe si el contenedor de Docker está en ejecución (docker ps) y si la URL de la API es correcta
La prueba de conexión falla Número no registrado en el contenedor Repita la vinculación mediante el procedimiento de enlace por código QR
El mensaje no se entrega El destinatario no usa Signal o el número es incorrecto Asegúrese de que el destinatario tiene Signal instalado y de que el número está registrado en el formato +{prefijo del país}{número}
Se ha perdido la vinculación El dispositivo se desvinculó en la app de Signal Vuelva a vincular el contenedor mediante el enlace por código QR
El contenedor no arranca El puerto 8080 ya está en uso Utilice otro puerto: -p 9090:8080 y ajuste la URL de la API en Klacks
