Manual del Diseñador de informes

Estructura de los informes

Un informe consta de tres secciones:

  • Encabezado: se imprime en la parte superior de cada página
  • Cuerpo: contiene las tablas de datos
  • Pie de página: se imprime en la parte inferior de cada página

Cada sección se puede editar en la pestaña «Diseño» del editor de informes.

Sección de cabecera

El encabezado tiene tres zonas: izquierda, centro y derecha.

Cada zona puede contener:

  • Campos: campos de la base de datos que se rellenan automáticamente
  • Texto libre: texto introducido manualmente
  • Imágenes: por ejemplo, el logotipo de una empresa (que se sube a través del gestor de imágenes)

Las filas se pueden añadir o eliminar mediante la barra de herramientas.

Tablas del cuerpo

El cuerpo contiene una o varias tablas.

AcciónDescripción
Añadir columnaMediante el símbolo «+» o arrastrando y soltando desde la lista de campos
Ancho de columnaAjustar arrastrando el borde de la columna
Orden de las columnasMover mediante «arrastrar y soltar»
Eliminar columnaEn el editor de columnas, mediante el icono de eliminación

Cada tabla está vinculada a un conjunto de datos (por ejemplo, plan de trabajo, direcciones).

Combinar campos (Merged Fields)

Los campos combinados permiten varios enlaces de datos en una sola columna.

  • En el editor de columnas, haz clic en «Añadir campo» para añadir más campos a la misma columna
  • Los valores se muestran uno debajo de otro o con un separador
  • El separador se puede configurar en el cuadro de diálogo del campo (p. ej., coma, espacio, salto de línea)

Pie de página de la tabla

Se puede mostrar un pie de tabla debajo de cada tabla.

  • Campos SUM: las columnas numéricas se pueden sumar automáticamente
  • Etiqueta: la etiqueta de la suma se puede mostrar u ocultar
  • Se activa a través del editor de columnas en la pestaña «Pie de página»

Líneas de texto libre

Las líneas de texto libre se pueden insertar antes o después de las tablas de datos.

PropiedadDescripción
PosiciónSe puede elegir «Antes de los datos» o «Después de los datos»
ContenidoCualquier texto, p. ej., notas, condiciones o campos de firma
EstiloSe pueden configurar el tipo de letra, el tamaño y la alineación

Formato

Cada celda y cada campo de texto libre se pueden formatear de forma individual:

OpciónDescripción
Tipo de letraTipos de letra seleccionables para la celda
Tamaño de fuenteTamaño en puntos (pt)
Negrita / Cursiva / SubrayadoMediante los botones B / I / U
Color del textoColor a elegir libremente
AlineaciónA la izquierda, centrado o a la derecha

Bordes de las celdas

Las líneas del borde de cada celda se pueden configurar individualmente.

PropiedadOpciones
LadosArriba, derecha, abajo, izquierda (por separado o todas)
Estilo de líneaFino, medio, grueso, discontinuo, doble
Color de la líneaA elegir

Los marcos se configuran en el editor de columnas, en la sección «Marcos».

Configuración de la página

En la pestaña «General» se pueden ajustar las opciones de impresión:

  • Orientación: vertical (retrato) u horizontal (paisaje)
  • Tamaño del papel: A4, A3, B4 (JIS), B5 (JIS) o Carta
  • Márgenes: superior, derecho, inferior e izquierdo en mm

Opciones de presentación (Diseñador)

En la pestaña «Diseño», si la fuente de datos es un plan de trabajo (Schedule), hay opciones adicionales disponibles:

  • Agrupar entradas por día: las entradas múltiples del mismo día se agrupan en una sola línea
  • Mostrar el periodo completo: se muestran todos los días del periodo, aunque no haya entradas

La fuente de datos se selecciona en la pestaña «Fuente de datos» y determina los campos disponibles.

Parámetros

Los parámetros se solicitan al ejecutar un informe. Sus valores están disponibles en los filtros de fila y en las fórmulas, y además pueden limitar la consulta a la fuente de datos. Se crean en la pestaña «Parámetros».

CampoSignificado
ClaveNombre técnico. Debe comenzar por una letra y solo puede contener letras, números y guiones bajos. Único para cada informe.
DenominaciónTexto que se muestra al ejecutar el informe.
TipoTexto, número, fecha, Sí/No o selección.
Valor por defectoSe utiliza cuando no se introduce ningún valor al ejecutar la acción.
Valores de selecciónSolo para el tipo «Selección»: los valores permitidos, separados por comas.
Afecta aDetermina si el valor se transfiere además a la fuente de datos.
Campo obligatorioEl informe no se puede ejecutar sin un valor.

Parámetros en filtros y fórmulas

Cada parámetro está disponible en el script bajo la clave con el prefijo param_ — a partir de la clave region se convierte, por tanto, en param_region. El prefijo evita que un parámetro enmascare un valor de línea con el mismo nombre. El nombre actual se muestra debajo de cada parámetro.

El valor se convierte al tipo seleccionado antes de su evaluación:

  • Número: como número; una entrada no válida se convierte en 0
  • Sí/No: verdadero en el caso de 1, true, wahr o yes, en caso contrario, falso
  • Texto, fecha, selección: como texto

Vincular los parámetros a la fuente de datos

A través de «Afecta a», un parámetro limita además qué datos se cargan:

ConfiguraciónEfecto
solo filtros y fórmulasEl valor se utiliza exclusivamente en el script (predeterminado).
Grupo de la consultaEl valor sustituye al grupo para el que se cargan los datos.
Persona de la consultaEl valor sustituye a la persona para la que se cargan los datos.
Fecha de inicio de la consultaEste valor sustituye al inicio del periodo.
Fecha de finalización de la consultaEste valor sustituye al final del periodo.

Los valores de fecha fijos deben introducirse en el formato AAAA-MM-DD o DD.MM.AAAA. Se ignorará cualquier valor que no se ajuste a este formato, para evitar que la consulta quede vacía sin que se detecte. Un valor vacío mantiene la configuración original sin cambios.
