Configurar el bot de Telegram

Requisitos previos

Para enviar y recibir mensajes de Telegram a través de Klacks, necesita un bot de Telegram. Los bots se crean a través del oficial BotFather y son gratuitos.

Paso 1 — Crear el bot de Telegram

  1. Abra Telegram y busque @BotFather.
  2. Inicie un chat con BotFather y envíe el comando /newbot.
  3. Asigne un nombre a su bot (p. ej. Klacks Notificaciones).
  4. Asigne un nombre de usuario al bot (debe terminar en bot, p. ej. klacks_notify_bot).
  5. BotFather le entregará un token de bot. Copie este token — se necesitará en el siguiente paso.

Nota: trate el token del bot como una contraseña. No lo comparta públicamente y guárdelo de forma segura.

Paso 2 — Configurar el bot en Klacks

  1. Navegue a Configuración → Proveedores de mensajería.
  2. Haga clic en Añadir.
  3. Complete los campos de la siguiente manera:

  2. Pruebe la conexión mediante el botón Prueba en la lista de proveedores.

Paso 3 — Enviar mensajes a través del chatbot (Klacksy)

Una vez configurado y activado el bot de Telegram, el chatbot Klacksy puede enviar mensajes. No necesita conocer los ID de chat — simplemente utilice el nombre del empleado o del cliente: 

"Envía un mensaje a Max Muster: Su cita es mañana a las 14:00."
"Envía a Anna Beispiel un mensaje: El turno ha sido intercambiado."
"Notifica a Peter Müller que su servicio del lunes se cancela."

Klacksy busca automáticamente el nombre de usuario de Telegram registrado del destinatario y utiliza el bot configurado. El envío es completamente transparente para usted — usted trabaja con nombres, Klacksy se encarga del resto.

Requisito previo: el destinatario debe tener registrado un nombre de usuario de Telegram en Klacks (en Dirección → Datos de contacto).

Paso 4 — Recibir mensajes entrantes (webhook)

Para mostrar los mensajes entrantes de Telegram en Klacks, se debe configurar un webhook.

  1. Asegúrese de que su instancia de Klacks sea accesible públicamente a través de HTTPS.
  2. Introduzca la siguiente URL de webhook en la configuración del proveedor: 
    https://{su-dominio}/api/messaging/webhook/telegram
  3. Klacks registra el webhook automáticamente en Telegram en cuanto el proveedor se guarda y se activa.
  4. Los mensajes entrantes ahora aparecerán en tiempo real en la bandeja de entrada de mensajería.

Solución de problemas

ProblemaPosible causaSolución
La prueba de conexión falla Token de bot inválido Compruebe el token con BotFather usando /mybots
El mensaje no se entrega El destinatario no ha iniciado el bot El destinatario debe abrir el bot en Telegram y enviar /start
Destinatario no encontrado Nombre de usuario de Telegram no registrado Introduzca el nombre de usuario de Telegram en Dirección → Datos de contacto
Faltan mensajes entrantes URL del webhook no accesible Compruebe si su dominio es accesible por HTTPS y si la URL es correcta
El registro del webhook falla No hay un certificado SSL válido Telegram requiere un certificado SSL válido (no autofirmado)
