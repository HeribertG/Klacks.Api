Configurar la mensajería de Zalo

Requisitos previos

Para enviar mensajes a través de Zalo, necesita una Zalo Official Account (OA) en oa.zalo.me, así como una app en developers.zalo.me. Zalo es el mensajero líder en Vietnam.

Importante: la integración de Zalo está diseñada solo para el envío. Además, se aplican las siguientes restricciones de la plataforma Zalo:

  • El token de acceso caduca después de aproximadamente 25 horas y debe renovarse y registrarse de nuevo fuera de Klacks.
  • Los mensajes solo se pueden enviar a usuarios que previamente hayan interactuado con la Official Account (ventana de interacción).

Paso 1 — Configurar la Zalo Official Account y la app

  1. Cree una Official Account en oa.zalo.me.
  2. Cree una app en developers.zalo.me.
  3. Vincule la Official Account con la app.
  4. Obtenga un token de acceso mediante el flujo OAuth de la consola de desarrolladores de Zalo.

Nota: trate el token de acceso como una contraseña. No lo comparta públicamente y guárdelo de forma segura.

Paso 2 — Configurar Zalo en Klacks

  1. Navegue a Configuración → Proveedores de mensajería.
  2. Haga clic en Añadir.
  3. Complete los campos de la siguiente manera:

  1. Haga clic en Guardar.
  2. Pruebe la conexión mediante el botón Prueba en la lista de proveedores.

Importante: el token de acceso caduca después de aproximadamente 25 horas. Klacks no lo renueva automáticamente — debe renovarlo externamente mediante el flujo de refresh token de Zalo y registrarlo de nuevo en Klacks. Tenga en cuenta que el refresh token es de un solo uso — cada renovación entrega un nuevo par de tokens.

Paso 3 — Enviar mensajes a través del chatbot (Klacksy)

Una vez configurado y activado el proveedor de Zalo, el chatbot Klacksy puede enviar mensajes. No necesita conocer los ID de usuario de Zalo — simplemente utilice el nombre del empleado o del cliente: 

"Envía un mensaje a Max Muster: Su cita es mañana a las 14:00."
"Envía a Anna Beispiel un mensaje: El turno ha sido intercambiado."
"Notifica a Peter Müller que su servicio del lunes se cancela."

Klacksy busca automáticamente el ID de usuario de Zalo registrado del destinatario y utiliza el proveedor de Zalo configurado. El envío es completamente transparente para usted — usted trabaja con nombres, Klacksy se encarga del resto.

Requisito previo: el destinatario debe tener registrado en Klacks el ID de usuario de Zalo (en Dirección → Datos de contacto). El destinatario debe haber interactuado previamente con la Official Account (p. ej. siguiendo la OA o enviándole un mensaje) — fuera de la ventana de interacción, Zalo rechazará el envío.

Mensajes entrantes

La integración de Zalo no admite la recepción — las respuestas a los mensajes enviados no se transmiten a Klacks. Por ello, la bandeja de entrada de mensajería no muestra mensajes entrantes para este proveedor.
