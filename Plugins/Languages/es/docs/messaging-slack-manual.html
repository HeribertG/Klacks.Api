Configurar Slack

Requisitos previos

Para enviar y recibir mensajes a través de Slack con Klacks, necesita un workspace de Slack y una app de Slack con los permisos correspondientes. Klacks utiliza la Slack Web API para el envío y la Events API para la recepción.

Nota: el plan gratuito de Slack es suficiente para esta integración. Las apps de Slack se crean en api.slack.com y son gratuitas.

Paso 1 — Crear la app de Slack

  1. Abra api.slack.com/apps y haga clic en Create New App.
  2. Seleccione From scratch y asigne un nombre (por ejemplo, Klacks Bot).
  3. Seleccione el workspace en el que se instalará la app.
  4. Navegue a OAuth & Permissions y añada los siguientes Bot Token Scopes:
    • chat:write — para enviar mensajes a canales
    • im:write — para enviar mensajes directos a usuarios
  5. Haga clic en Install to Workspace y confirme los permisos.
  6. Anote el Bot User OAuth Token (comienza con xoxb-).
  7. Navegue a Basic Information y anote el Signing Secret.

Paso 2 — Configurar Slack en Klacks

  1. Navegue a Configuración → Proveedores de mensajería.
  2. Haga clic en Añadir.
  3. Rellene los campos de la siguiente manera:

Paso 3 — Enviar mensajes a través del chatbot (Klacksy)

Una vez configurado y activado el proveedor de Slack, el chatbot Klacksy puede enviar mensajes a través de Slack. Utilice el nombre del empleado o el nombre de un canal: 

"Envía un mensaje a Max Muster: su cita es mañana a las 14:00."
"Manda un mensaje a Anna Beispiel: el turno se ha intercambiado."
"Publica en #team-updates: los horarios de la próxima semana ya están listos."

Como destinatario sirve un Channel ID (por ejemplo, C0123456789) o un User ID (por ejemplo, U0123456789); con un User ID se envía un mensaje directo. Si no se indica ningún destinatario, se utiliza el canal predeterminado configurado. El envío es completamente transparente para usted: usted trabaja con nombres, Klacksy se encarga del resto.

Requisito: el usuario de Slack debe estar vinculado con el contacto correspondiente de Klacks (en Dirección → Datos de contacto). Para los mensajes de canal, el bot debe estar invitado al canal correspondiente (/invite @Klacks Bot).

Paso 4 — Recibir mensajes entrantes (Events API)

Para mostrar los mensajes entrantes de Slack en Klacks, debe configurarse la Events API de la app de Slack. Guarde y active el proveedor en Klacks antes de introducir la Request URL: Slack verifica la URL inmediatamente con una solicitud de challenge, que Klacks responde automáticamente.

  1. Abra su app de Slack en api.slack.com/apps y navegue a Event Subscriptions.
  2. Active Enable Events e introduzca como Request URL la URL del webhook mostrada en Klacks: 
    https://{ihre-domain}/api/messaging/webhook/slack
  3. Suscríbase en Subscribe to bot events a los eventos message.im (mensajes directos) y message.channels (mensajes de canal).
  4. Guarde los cambios y vuelva a instalar la app en el workspace cuando se le solicite.
  5. Los mensajes entrantes aparecerán ahora en tiempo real en la bandeja de entrada de mensajería. Klacks verifica la firma de cada solicitud con el Signing Secret registrado.

Solución de problemas

ProblemaPosible causaSolución
La prueba de conexión falla Token del bot no válido o revocado Revise el token en OAuth & Permissions y reinstale la app
Error channel_not_found o not_in_channel El bot no se ha añadido al canal Invite al bot al canal (/invite) o compruebe el Channel ID
Falla un mensaje sin destinatario No hay ningún canal predeterminado configurado Introduzca un canal predeterminado en la configuración del proveedor
Falla la verificación de la Request URL El proveedor no está guardado/activado en Klacks o el Signing Secret es incorrecto Guarde y active primero el proveedor en Klacks y revise el Signing Secret
Faltan los mensajes entrantes No se han suscrito los eventos del bot Suscríbase a message.im y message.channels en Event Subscriptions
