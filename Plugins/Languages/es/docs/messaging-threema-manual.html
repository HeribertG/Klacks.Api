Configurar Threema Gateway

Requisitos previos

Para enviar mensajes a través de Threema, necesita una cuenta en Threema Gateway. Threema es un proveedor suizo, muy extendido en Suiza y respetuoso con la privacidad (LPD suiza).

Importante: la integración de Threema está diseñada solo para el envío. La recepción de mensajes entrantes requeriría el modo de extremo a extremo del gateway y no está soportada. El envío tiene costo — cada mensaje enviado consume créditos.

Paso 1 — Crear una cuenta de Threema Gateway

  1. Regístrese en gateway.threema.ch.
  2. Solicite un ID de Gateway en modo Basic (p. ej. *MYGATEWAY). Este siempre comienza con un asterisco (*) y debe ser aprobado por Threema.
  3. Compre créditos — sin saldo no se pueden enviar mensajes.
  4. Anote el API-Secret del panel de control del gateway.

Nota: trate el API-Secret como una contraseña. No lo comparta públicamente y guárdelo de forma segura.

Paso 2 — Configurar Threema en Klacks

  1. Navegue a Configuración → Proveedores de mensajería.
  2. Haga clic en Añadir.
  3. Complete los campos de la siguiente manera:

Paso 3 — Enviar mensajes a través del chatbot (Klacksy)

Una vez configurado y activado el proveedor de Threema, el chatbot Klacksy puede enviar mensajes. No necesita conocer los ID de Threema — simplemente utilice el nombre del empleado o del cliente: 

"Envía un mensaje a Max Muster: Su cita es mañana a las 14:00."
"Envía a Anna Beispiel un mensaje: El turno ha sido intercambiado."
"Notifica a Peter Müller que su servicio del lunes se cancela."

Klacksy busca automáticamente el ID de Threema registrado del destinatario y utiliza el proveedor de Threema configurado. El envío es completamente transparente para usted — usted trabaja con nombres, Klacksy se encarga del resto.

Requisito previo: el destinatario debe tener registrado el ID de Threema de 8 caracteres en Klacks (en Dirección → Datos de contacto). El empleado puede encontrar su ID de Threema en su app de Threema en „Mi perfil".

Mensajes entrantes

La integración de Threema no admite la recepción — las respuestas a los mensajes enviados no se transmiten a Klacks. La recepción requeriría el modo de extremo a extremo del Threema Gateway; la integración de Klacks utiliza el modo Basic. Por ello, la bandeja de entrada de mensajería no muestra mensajes entrantes para este proveedor.
