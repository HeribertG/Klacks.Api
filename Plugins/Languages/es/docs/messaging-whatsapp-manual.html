Configurar WhatsApp

Requisitos previos

Para enviar y recibir mensajes a través de WhatsApp con Klacks, necesita una cuenta de desarrollador de Meta y una app de Meta con el producto WhatsApp activado. Klacks utiliza la WhatsApp Cloud API de la plataforma Meta Business para el envío y los webhooks de Meta para la recepción.

Nota: la configuración y las pruebas no generan ningún coste. Al crear la app, Meta proporciona automáticamente un número de teléfono de prueba gratuito.

Importante: el número del remitente no es su número privado. Un número de teléfono que ya se utiliza en la app normal de WhatsApp no puede registrarse para la Cloud API, y un número registrado ya no se puede utilizar con WhatsApp Messenger. Utilice por tanto el número de prueba proporcionado por Meta o un número propio de uso exclusivamente profesional. Su WhatsApp privado en el teléfono móvil sirve como destinatario para las pruebas, no como remitente.

Paso 1 — Crear la app de Meta

  1. Abra developers.facebook.com/apps y haga clic en Create app.
  2. Seleccione como caso de uso Other y como tipo de app Business.
  3. Haga clic en el panel, en el producto WhatsApp, en Set up. Con ello se genera y se registra automáticamente un número de teléfono de prueba.
  4. Cambie en la navegación izquierda a WhatsApp → API Setup.
  5. Anote el Phone number ID y genere un token de acceso mediante Generate access token.
  6. Anote en App settings → Basic el App Secret — se necesita para verificar la firma de los mensajes entrantes.

Atención — dos IDs parecidos: En el panel de API Setup, el Phone number ID y el WhatsApp Business Account ID aparecen directamente uno debajo del otro. Klacks necesita el Phone number ID. Con el ID incorrecto, la prueba de conexión indica igualmente éxito, pero todos los envíos fallan.

Atención — vigencia del token: El token generado mediante Generate access token es un token de prueba temporal y caduca al poco tiempo. Para el funcionamiento permanente, genere en el Meta Business Manager un token permanente a través de un usuario del sistema.

Paso 2 — Habilitar el número del destinatario

El número de prueba solo puede enviar a destinatarios habilitados previamente. Añada su número de WhatsApp en el panel API Setup, en To → Manage phone number list. Meta envía un código de confirmación a ese número, que usted debe introducir.

Sin este paso, Meta rechaza todos los envíos a ese número. En cuanto utilice más adelante un número de empresa propio y verificado, la habilitación deja de ser necesaria.

Paso 4 — La ventana de 24 horas

En este punto, WhatsApp se diferencia radicalmente de Telegram o Slack. Una empresa solo puede enviar mensajes de texto libres mientras esté abierta una ventana de atención al cliente. Esta ventana la abre el destinatario, escribiendo a su número de WhatsApp. Permanece abierta 24 horas y se prolonga con cada nuevo mensaje del destinatario.

Fuera de esa ventana, Meta solo permite plantillas de mensaje aprobadas previamente. Klacks envía actualmente solo mensajes de texto libres y por tanto no puede iniciar por sí mismo ninguna conversación.

Qué significa esto para usted: Pida una vez a sus empleados que envíen un mensaje al número de WhatsApp de Klacks. A partir de ese momento el envío es posible durante 24 horas, y cada respuesta prolonga la ventana. Si está cerrada, el envío devuelve un error: no se trata de un problema de configuración, sino de una norma de WhatsApp.

Si necesita llegar a sus empleados con independencia de esta ventana, Telegram o Signal son los mejores proveedores: allí no existe esta limitación.

Paso 5 — Enviar mensajes a través del chatbot (Klacksy)

Una vez configurado y activado el proveedor de WhatsApp, el chatbot Klacksy puede enviar mensajes a través de WhatsApp. Utilice el nombre del empleado: 

"Envía un mensaje a Max Muster: su cita es mañana a las 14:00."
"Manda un mensaje a Anna Beispiel: el turno se ha intercambiado."

Como destinatario sirve el número de teléfono en formato internacional sin cero inicial y sin el signo más (por ejemplo, 41791234567 para 079 123 45 67). El envío es completamente transparente para usted: usted trabaja con nombres, Klacksy se encarga del resto.

Requisito: el número de WhatsApp debe estar vinculado con el contacto de Klacks correspondiente (en Dirección → Datos de contacto), y la ventana de 24 horas del paso 4 debe estar abierta.

Paso 6 — Recibir mensajes entrantes (webhooks)

Para mostrar los mensajes entrantes de WhatsApp en Klacks, debe configurarse el webhook de la app de Meta. Guarde y active el proveedor en Klacks antes de introducir la Callback URL: Meta comprueba la URL inmediatamente con una solicitud de verificación que Klacks responde automáticamente mediante el token de verificación.

  1. Abra su app de Meta y navegue a WhatsApp → Configuration.
  2. Haga clic en Edit junto a Webhook e introduzca:
    • Callback URL: la URL del webhook mostrada en Klacks 
      https://{su-dominio}/api/messaging/webhook/whatsapp
    • Verify token: exactamente el mismo valor que introdujo en el paso 3 en el campo Token de verificación
  3. Haga clic en Verify and save.
  4. Suscríbase en Webhook fields al campo messages.
  5. Los mensajes entrantes aparecerán ahora en tiempo real en la bandeja de entrada de mensajería. Klacks verifica al hacerlo la firma de cada solicitud (X-Hub-Signature-256) con el App Secret registrado.

La Callback URL debe ser accesible desde el exterior a través de HTTPS. En una instalación en la red corporativa sin dirección pública, el envío funciona, pero no se pueden recibir mensajes.

ProblemaPosible causaSolución
La prueba de conexión falla Token de acceso caducado Los tokens de prueba temporales caducan al poco tiempo — genere uno nuevo en el panel de API Setup o configure un token permanente
La prueba de conexión es correcta, pero todos los envíos fallan Se ha introducido el ID de la cuenta de empresa en lugar del ID del número de teléfono Tome del panel de API Setup el Phone number ID, no el WhatsApp Business Account ID
Error con referencia a 24 horas o a un nuevo contacto La ventana de atención al cliente está cerrada El destinatario debe enviar primero un mensaje a su número de WhatsApp — véase el paso 4
El envío a un número concreto falla El destinatario no está habilitado en el número de prueba Añada el número en Manage phone number list y confírmelo con el código
La verificación del webhook falla El token de verificación no coincide o el proveedor no está guardado/activado en Klacks Guarde y active primero el proveedor en Klacks y, a continuación, introduzca el mismo token de verificación en Meta
Faltan los mensajes entrantes El campo de webhook messages no está suscrito o el App Secret es incorrecto Suscríbase al campo messages en Configuration y compruebe el App Secret
