Buscar proveedores LLM — Manual

¿Para qué sirve esta función?

Esta vista te propone proveedores LLM que aún no tienes en tu lista y añade los seleccionados con un solo clic. Así no tienes que introducir el nombre y la URL base a mano. Solo se proponen proveedores de API compatibles con OpenAI — es decir, exactamente el tipo de servicios que también utilizan los proveedores que ya tienes configurados.

Las columnas de la tabla

Nombre del proveedor

El nombre visible del proveedor (p. ej. «OpenRouter», «xAI (Grok)»).

URL base

La dirección de la API a través de la cual se comunica con el proveedor (p. ej. https://api.x.ai/v1/). Esta misma URL se utilizará después al crearlo.

Origen

Indica de dónde procede la propuesta:

  • Catálogo — de una lista fija y verificada de proveedores conocidos. Las URL base están comprobadas y, por tanto, son fiables.
  • Web — encontrado mediante búsqueda en internet y evaluado automáticamente. Estas entradas solo aparecen si la búsqueda web está configurada en los ajustes. Son útiles, pero en caso de duda conviene comprobar brevemente la URL base.

Disponibilidad

Antes de mostrarse, cada propuesta se comprueba en vivo (llamada al endpoint /models):

  • Disponible — la API responde, el proveedor funciona.
  • Disponible (requiere clave) — la API existe, pero requiere una clave de API. Por tanto, la dirección es correcta.
  • No disponible — la dirección no responde. Estas entradas no se pueden seleccionar.

Añadir proveedor

Marca uno o varios proveedores y haz clic abajo en «Añadir selección». Los proveedores elegidos se crean desactivados y sin clave de API. Los proveedores ya existentes directamente no se proponen.

Siguientes pasos tras añadir

Un proveedor recién añadido aún no está activo. Ábrelo en la lista, introduce la clave de API y actívalo. A partir de entonces funciona exactamente igual que tus demás proveedores. Los distintos modelos de un proveedor se siguen gestionando por separado desde la administración de modelos.
