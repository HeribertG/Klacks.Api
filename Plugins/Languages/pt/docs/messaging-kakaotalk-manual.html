Configurar mensagens KakaoTalk

Requisitos prévios

Para enviar mensagens através do KakaoTalk, precisa de uma aplicação em developers.kakao.com (Kakao Developers). O KakaoTalk é o messenger dominante na Coreia do Sul. A integração do Klacks utiliza a API Kakao Developer („Enviar mensagem a amigos").

Restrições importantes da API Kakao Developer:

  • A integração está concebida apenas para envio — sem receção.
  • O access token tem vida curta (cerca de 6 horas) e tem de ser renovado e voltado a guardar fora do Klacks.
  • As mensagens só podem ser enviadas a utilizadores que estejam ligados como „amigos" Kakao da aplicação e que tenham dado o seu consentimento ao envio de mensagens.
  • Para mensagens de negócio produtivas (AlimTalk) é necessário, na Coreia, um canal de negócio através de agências autorizadas — isto não é abrangido por esta integração, que utiliza a API Developer.

Passo 1 — Criar a aplicação Kakao Developers

  1. Crie uma aplicação em developers.kakao.com.
  2. Ative o Kakao Login para a aplicação.
  3. Ative os scopes talk_message e friends.
  4. Obtenha um access token através do fluxo OAuth do Kakao Login (o utilizador em cujo nome é enviado tem de aceitar os scopes).

Nota: Trate o access token como uma palavra-passe. Não o partilhe publicamente e guarde-o de forma segura.

Passo 2 — Configurar o KakaoTalk no Klacks

  1. Navegue até Definições → Fornecedores de mensagens.
  2. Clique em Adicionar.
  3. Preencha os campos da seguinte forma:
CampoDescriçãoExemplo
NomeNome interno únicokakaotalk-main
Nome de exibiçãoÉ apresentado na interfaceKakaoTalk
Tipo de fornecedorSelecione KakaoTalkKakaoTalk
Access TokenO token obtido através do fluxo OAuthkakao-access-token...
AtivadoLiga/desliga o fornecedorSim
  1. Clique em Guardar.
  2. Teste a ligação através do botão Testar na lista de fornecedores.

Importante: O access token expira ao fim de cerca de 6 horas. O Klacks não o renova automaticamente — tem de o renovar externamente (fluxo de refresh token da Kakao) e voltar a guardá-lo no Klacks.

Passo 3 — Enviar mensagens através do chatbot (Klacksy)

Assim que o fornecedor KakaoTalk estiver configurado e ativado, o chatbot Klacksy pode enviar mensagens. Não precisa de conhecer IDs — basta utilizar o nome do colaborador ou do cliente: 

"Envia uma mensagem ao Max Muster: A sua consulta é amanhã às 14:00."
"Manda uma mensagem à Anna Beispiel: O turno foi trocado."
"Avisa o Peter Müller de que o seu serviço de segunda-feira foi cancelado."

O Klacksy procura automaticamente o identificador guardado do destinatário e utiliza o fornecedor KakaoTalk configurado. O envio é totalmente transparente para si — trabalha com nomes, o Klacksy trata do resto.

Requisito: No destinatário tem de estar guardado o Friend UUID da API Kakao Friends no Klacks (em Morada → Dados de contacto). O destinatário tem de estar ligado à aplicação como „amigo" Kakao — não é possível enviar a outros utilizadores.

Mensagens de entrada

A integração com o KakaoTalk não suporta receção — as respostas a mensagens enviadas não são transmitidas ao Klacks. A caixa de entrada de mensagens não apresenta, por isso, mensagens de entrada para este fornecedor.

Resolução de problemas

ProblemaCausa possívelSolução
O teste de ligação falha Access token expirado (validade de cerca de 6 horas) Renove o token através do fluxo OAuth da Kakao e volte a guardá-lo
A mensagem não é entregue O destinatário não é „amigo" Kakao da aplicação O destinatário tem de se ligar à aplicação através do Kakao Login e aceitar o scope
Destinatário não encontrado Friend UUID não guardado Obtenha o UUID através da API Friends e introduza-o em Morada → Dados de contacto
Envio rejeitado com erro de permissão Scope talk_message ou friends não ativado Verifique as definições de scope da aplicação em developers.kakao.com
Envio em massa produtivo não é possível A API Developer não abrange o AlimTalk Para mensagens de negócio na Coreia é necessário um canal de negócio através de uma agência autorizada
