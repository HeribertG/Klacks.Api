Configurar o Slack

Requisitos prévios

Para enviar e receber mensagens através do Slack com o Klacks, precisa de um workspace Slack e de uma app Slack com as permissões correspondentes. O Klacks utiliza a Slack Web API para o envio e a Events API para a receção.

Nota: o plano gratuito do Slack é suficiente para a integração. As apps Slack são criadas em api.slack.com e são gratuitas.

Passo 1 — Criar a app Slack

  1. Abra api.slack.com/apps e clique em Create New App.
  2. Selecione From scratch e atribua um nome (p.ex. Klacks Bot).
  3. Selecione o workspace onde a app deve ser instalada.
  4. Navegue até OAuth & Permissions e adicione os seguintes Bot Token Scopes:
    • chat:write — para enviar mensagens para canais
    • im:write — para enviar mensagens diretas a utilizadores
  5. Clique em Install to Workspace e confirme as permissões.
  6. Anote o Bot User OAuth Token (começa por xoxb-).
  7. Navegue até Basic Information e anote o Signing Secret.

Passo 2 — Configurar o Slack no Klacks

  1. Navegue até Definições → Fornecedores de mensagens.
  2. Clique em Adicionar.
  3. Preencha os campos da seguinte forma:

Passo 3 — Enviar mensagens através do chatbot (Klacksy)

Assim que o fornecedor Slack estiver configurado e ativado, o chatbot Klacksy pode enviar mensagens através do Slack. Utilize o nome do colaborador ou um nome de canal: 

"Envia uma mensagem a Max Muster: O seu compromisso é amanhã às 14:00."
"Envia a Anna Beispiel uma mensagem: O turno foi trocado."
"Publica em #team-updates: Os horários de serviço da próxima semana estão prontos."

Como destinatário serve um ID de canal (p.ex. C0123456789) ou um ID de utilizador (p.ex. U0123456789) — com um ID de utilizador é enviada uma mensagem direta. Se não for indicado nenhum destinatário, é utilizado o canal padrão configurado. O envio é totalmente transparente para si — trabalha com nomes, o Klacksy trata do resto.

Pré-requisito: o utilizador Slack tem de estar associado ao respetivo contacto Klacks (em Morada → Dados de contacto). Para mensagens de canal, o bot tem de ser convidado para o respetivo canal (/invite @Klacks Bot).

Passo 4 — Receber mensagens de entrada (Events API)

Para que as mensagens Slack recebidas apareçam no Klacks, a Events API da app Slack tem de ser configurada. Guarde e ative o fornecedor no Klacks antes de introduzir o Request URL — o Slack verifica o URL de imediato com um pedido de desafio (challenge), ao qual o Klacks responde automaticamente.

  1. Abra a sua app Slack em api.slack.com/apps e navegue até Event Subscriptions.
  2. Ative Enable Events e introduza como Request URL o URL do webhook apresentado no Klacks: 
    https://{o-seu-dominio}/api/messaging/webhook/slack
  3. Subscreva em Subscribe to bot events os eventos message.im (mensagens diretas) e message.channels (mensagens de canal).
  4. Guarde as alterações e, se solicitado, reinstale a app no workspace.
  5. As mensagens recebidas passam agora a aparecer em tempo real na caixa de entrada de mensagens. O Klacks verifica a assinatura de cada pedido com o Signing Secret configurado.

Resolução de problemas

ProblemaCausa possívelSolução
O teste de ligação falha Bot-Token inválido ou revogado Verifique o token em OAuth & Permissions e reinstale a app
Erro channel_not_found ou not_in_channel Bot não adicionado ao canal Convide o bot para o canal (/invite) ou verifique o ID do canal
A mensagem sem destinatário falha Nenhum canal padrão configurado Introduza um canal padrão nas definições do fornecedor
A verificação do Request URL falha Fornecedor não guardado/ativado no Klacks ou Signing Secret incorreto Guarde e ative primeiro o fornecedor no Klacks e verifique o Signing Secret
Faltam mensagens de entrada Eventos do bot não subscritos Subscreva message.im e message.channels em Event Subscriptions
