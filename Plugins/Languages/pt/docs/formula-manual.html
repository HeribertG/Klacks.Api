Manual do campo de fórmula

Sintaxe básica

Cada campo de fórmula devolve o resultado com o comando output:

output 1, <expressão>

O primeiro parâmetro 1 é o tipo de mensagem e tem de ser sempre 1. O segundo parâmetro é o valor a apresentar.

Exemplos simples:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " registos"

Variáveis disponíveis

As variáveis disponíveis estão listadas no separador Variáveis, onde também podem ser preenchidas com valores de teste. Consoante o tipo de relatório, estão disponíveis variáveis diferentes:

Tipo de relatórioRodapé da tabela

AusênciastotalRows, totalValue
EndereçostotalRows

Lógica condicional

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "muitos registos"
ELSEIF totalRows > 0 THEN
    output 1, "poucos registos"
ELSE
    output 1, "nenhum registo"
ENDIF

IF numa linha

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (forma abreviada)

output 1, IIF(totalRows > 0, "OK", "Vazio")

Variáveis e ciclos

DIM i, soma
soma = 0
FOR i = 1 TO totalRows
    soma = soma + 1
NEXT
output 1, CStr(soma)

Exemplos práticos

Número de registos com texto

output 1, CStr(totalRows) & " registos"

Valor arredondado (1 casa decimal)

output 1, CStr(Round(totalValue, 1))

Horas em formato h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Saída condicional

IF totalRows = 0 THEN
    output 1, "Nenhuma ausência"
ELSE
    output 1, CStr(totalRows) & " ausências (Total: " & CStr(totalValue) & ")"
ENDIF

Calcular a média

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/dia"
ELSE
    output 1, "-"
ENDIF
Nota: o interpretador do script é executado numa sandbox segura, sem acesso ao sistema de ficheiros ou à rede.
