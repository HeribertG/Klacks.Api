Configurar o WhatsApp

Requisitos prévios

Para enviar e receber mensagens através do WhatsApp com o Klacks, precisa de uma conta de programador Meta e de uma app Meta com o produto WhatsApp ativado. O Klacks utiliza a WhatsApp Cloud API da plataforma Meta Business para o envio e webhooks da Meta para a receção.

Nota: a configuração e os testes não implicam quaisquer custos. Ao criar a app, a Meta disponibiliza automaticamente um número de telefone de teste gratuito.

Importante — o número do remetente não é o seu número privado. Um número de telefone que já esteja a ser utilizado na app WhatsApp normal não pode ser registado para a Cloud API, e um número registado deixa de poder ser utilizado com o WhatsApp Messenger. Por isso, utilize o número de teste disponibilizado pela Meta ou um número próprio, utilizado exclusivamente para fins profissionais. O seu WhatsApp privado no telemóvel serve de destinatário para os testes — não de remetente.

Passo 1 — Criar a app Meta

  1. Abra developers.facebook.com/apps e clique em Create app.
  2. Selecione Other como caso de utilização e Business como tipo de app.
  3. No dashboard, clique em Set up no produto WhatsApp. Nesse processo é gerado e registado automaticamente um número de telefone de teste.
  4. Na navegação à esquerda, mude para WhatsApp → API Setup.
  5. Anote o Phone number ID e gere um token de acesso através de Generate access token.
  6. Em App settings → Basic, anote o App Secret — é necessário para a verificação da assinatura das mensagens recebidas.

Atenção — dois IDs semelhantes: No painel API Setup, o Phone number ID e o WhatsApp Business Account ID aparecem diretamente um por baixo do outro. O Klacks precisa do Phone number ID. Com o ID errado, o teste de ligação indica mesmo assim sucesso, mas todos os envios falham.

Atenção — validade do token: O token gerado através de Generate access token é um token de teste temporário e expira ao fim de pouco tempo. Para funcionamento permanente, crie no Meta Business Manager um token permanente através de um utilizador de sistema.

Passo 2 — Autorizar o número do destinatário

O número de teste só pode enviar para destinatários previamente autorizados. Adicione no painel API Setup, em To → Manage phone number list, o seu número WhatsApp. A Meta envia um código de confirmação para esse número, que tem de introduzir.

Sem este passo, a Meta rejeita todos os envios para esse número. Assim que passar a utilizar um número de empresa próprio e verificado, a autorização deixa de ser necessária.

Passo 4 — A janela de 24 horas

Neste ponto, o WhatsApp distingue-se fundamentalmente do Telegram ou do Slack. Mensagens de texto livre só podem ser enviadas por uma empresa enquanto estiver aberta uma janela de apoio ao cliente. Essa janela é aberta pelo destinatário, ao escrever para o seu número WhatsApp. Ela permanece aberta durante 24 horas e prolonga-se com cada nova mensagem do destinatário.

Fora dessa janela, a Meta apenas permite modelos de mensagem previamente aprovados. O Klacks envia atualmente apenas mensagens de texto livre e, por isso, não pode iniciar uma conversa por sua própria iniciativa.

O que isto significa para si: Peça uma vez aos seus colaboradores que enviem uma mensagem para o número WhatsApp do Klacks. A partir daí, o envio é possível durante 24 horas, e cada resposta prolonga a janela. Se estiver fechada, o envio comunica um erro — não se trata de um problema de configuração, mas de uma regra do WhatsApp.

Se precisar de contactar os colaboradores independentemente desta janela, o Telegram ou o Signal são os melhores fornecedores — aí esta limitação não existe.

Passo 5 — Enviar mensagens através do chatbot (Klacksy)

Assim que o fornecedor WhatsApp estiver configurado e ativado, o chatbot Klacksy pode enviar mensagens através do WhatsApp. Utilize o nome do colaborador: 

"Envia uma mensagem a Max Muster: O seu compromisso é amanhã às 14:00."
"Envia a Anna Beispiel uma mensagem: O turno foi trocado."

Como destinatário serve o número de telefone em formato internacional, sem o zero inicial e sem o sinal de mais (p.ex. 41791234567 para 079 123 45 67). O envio é totalmente transparente para si — trabalha com nomes, o Klacksy trata do resto.

Pré-requisito: o número WhatsApp tem de estar associado ao respetivo contacto Klacks (em Morada → Dados de contacto) e a janela de 24 horas do passo 4 tem de estar aberta.

Passo 6 — Receber mensagens de entrada (webhooks)

Para que as mensagens WhatsApp recebidas apareçam no Klacks, o webhook da app Meta tem de ser configurado. Guarde e ative o fornecedor no Klacks antes de introduzir o Callback URL — a Meta verifica o URL de imediato com um pedido de verificação, ao qual o Klacks responde automaticamente com base no Verify-Token.

  1. Abra a sua app Meta e navegue até WhatsApp → Configuration.
  2. Em Webhook, clique em Edit e introduza:
    • Callback URL: o URL do webhook apresentado no Klacks 
      https://{o-seu-dominio}/api/messaging/webhook/whatsapp
    • Verify token: exatamente o mesmo valor que introduziu no passo 3 no campo Verify-Token
  3. Clique em Verify and save.
  4. Subscreva em Webhook fields o campo messages.
  5. As mensagens recebidas passam agora a aparecer em tempo real na caixa de entrada de mensagens. O Klacks verifica a assinatura de cada pedido (X-Hub-Signature-256) com o App-Secret configurado.

O Callback URL tem de estar acessível a partir do exterior através de HTTPS. Numa instalação na rede da empresa sem endereço público, o envio funciona, mas não é possível receber mensagens.

Resolução de problemas

ProblemaCausa possívelSolução
O teste de ligação falha Access-Token expirado Os tokens de teste temporários expiram ao fim de pouco tempo — gere um novo no painel API Setup ou configure um token permanente
O teste de ligação é bem-sucedido, mas todos os envios falham Introduzido o ID da conta empresarial em vez do ID do número de telefone Utilize o Phone number ID do painel API Setup, não o WhatsApp Business Account ID
Erro com indicação de 24 horas ou de novo contacto A janela de apoio ao cliente está fechada O destinatário tem primeiro de enviar uma mensagem para o seu número WhatsApp — ver passo 4
O envio para um determinado número falha Destinatário não autorizado no número de teste Adicione o número em Manage phone number list e confirme-o com o código
A verificação do webhook falha O Verify-Token não coincide ou o fornecedor não está guardado/ativado no Klacks Guarde e ative primeiro o fornecedor no Klacks e introduza depois o mesmo Verify-Token na Meta
Faltam mensagens de entrada Campo de webhook messages não subscrito ou App-Secret incorreto Subscreva em Configuration o campo messages e verifique o App-Secret
