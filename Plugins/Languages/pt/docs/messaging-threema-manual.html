Configurar o Threema Gateway

Requisitos

Para enviar mensagens através do Threema, precisa de uma conta no Threema Gateway. O Threema é um fornecedor suíço, muito utilizado na Suíça e respeitador da privacidade (Lei suíça de Proteção de Dados, DSG).

Importante: a integração com o Threema está concebida apenas para o envio. A receção de mensagens recebidas exigiria o modo de encriptação ponto-a-ponto do gateway e não é suportada. O envio é pago — cada mensagem enviada consome créditos.

Passo 1 — Criar uma conta no Threema Gateway

  1. Registe-se em gateway.threema.ch.
  2. Solicite um Gateway ID em modo básico (por exemplo, *MYGATEWAY). Este começa sempre com um asterisco (*) e tem de ser aprovado pelo Threema.
  3. Compre créditos — sem saldo não é possível enviar mensagens.
  4. Anote o API Secret do painel do gateway.

Nota: trate o API Secret como uma palavra-passe. Não o partilhe publicamente e guarde-o em local seguro.

Passo 2 — Configurar o Threema no Klacks

  1. Navegue até Definições → Fornecedores de mensagens.
  2. Clique em Adicionar.
  3. Preencha os campos da seguinte forma:

NomeNome interno únicothreema-gateway

Gateway IDO seu Threema Gateway ID (modo básico, começa com *)*MYGATEWAY

AtivadoLiga/desliga o fornecedorSim
  1. Clique em Guardar.
  2. Teste a ligação através do botão Testar na lista de fornecedores. O teste verifica as credenciais através da consulta de créditos do gateway.

Passo 3 — Enviar mensagens através do chatbot (Klacksy)

Assim que o fornecedor Threema estiver configurado e ativado, o chatbot Klacksy pode enviar mensagens. Não precisa de conhecer os IDs Threema — basta utilizar o nome do colaborador ou do cliente: 

"Envia uma mensagem ao Max Muster: A sua consulta é amanhã às 14:00."
"Manda uma mensagem à Anna Beispiel: O turno foi trocado."
"Avisa o Peter Müller de que o seu serviço de segunda-feira foi cancelado."

O Klacksy procura automaticamente o ID Threema registado do destinatário e utiliza o fornecedor Threema configurado. O envio é totalmente transparente para si — trabalha com nomes, o Klacksy trata do resto.

Requisito: o destinatário tem de ter o ID Threema de 8 caracteres registado no Klacks (em Endereço → Dados de contacto). O colaborador encontra o ID Threema na sua aplicação Threema em "O meu perfil".

Mensagens recebidas

A integração com o Threema não suporta receção — as respostas a mensagens enviadas não são transmitidas ao Klacks. A receção exigiria o modo de encriptação ponto-a-ponto do Threema Gateway; a integração do Klacks utiliza o modo básico. Por isso, a caixa de entrada de mensagens não mostra mensagens recebidas para este fornecedor.

Resolução de problemas

ProblemaCausa possívelSolução
O teste de ligação falha Gateway ID ou API Secret incorretos Verifique as credenciais no painel do gateway em gateway.threema.ch
A mensagem não é entregue ID Threema incorreto ou inexistente Verifique se o ID Threema de 8 caracteres está corretamente registado
O envio falha Créditos esgotados Recarregue os créditos no Threema Gateway
Destinatário não encontrado ID Threema não registado Introduza o ID Threema em Endereço → Dados de contacto
O Gateway ID não funciona ID ainda não aprovado Aguarde a aprovação pelo Threema (estado visível no painel)
