Configurar mensagens LINE

Requisitos prévios

Para enviar e receber mensagens através do LINE, precisa de uma LINE Official Account com um canal de API de Mensagens na LINE Developers Console. O LINE é particularmente popular no Japão, em Taiwan e na Tailândia.

Nota: Consoante o plano LINE, as mensagens push têm um limite mensal (o plano gratuito é limitado). Verifique as condições atuais do seu plano de Official Account.

Passo 1 — Criar a LINE Official Account e o canal de API de Mensagens

  1. Crie uma LINE Official Account (através do LINE Official Account Manager).
  2. Abra a LINE Developers Console (developers.line.biz) e crie um canal de API de Mensagens ou associe a sua Official Account à API de Mensagens.
  3. No separador Messaging API, emita um Channel Access Token de longa duração (Issue).
  4. Anote o Channel Secret no separador Basic Settings.

Nota: Trate o Channel Access Token e o Channel Secret como palavras-passe. Não os partilhe publicamente e guarde-os de forma segura.

Passo 2 — Configurar o LINE no Klacks

  2. Clique em Adicionar.

Passo 3 — Enviar mensagens através do chatbot (Klacksy)

Assim que o fornecedor LINE estiver configurado e ativado, o chatbot Klacksy pode enviar mensagens. Não precisa de conhecer os IDs de utilizador do LINE — basta utilizar o nome do colaborador ou do cliente: 

"Envia uma mensagem ao Max Muster: A sua consulta é amanhã às 14:00."
"Manda uma mensagem à Anna Beispiel: O turno foi trocado."
"Avisa o Peter Müller de que o seu serviço de segunda-feira foi cancelado."

O Klacksy procura automaticamente o ID de utilizador LINE guardado do destinatário e utiliza o fornecedor LINE configurado. O envio é totalmente transparente para si — trabalha com nomes, o Klacksy trata do resto.

Requisito: O ID de utilizador LINE (começa por U…) tem de estar guardado no Klacks para o destinatário (em Morada → Dados de contacto). O ID de utilizador é conhecido através das mensagens recebidas (visível na caixa de entrada de mensagens) — para isso, o destinatário tem de ter adicionado a sua Official Account como amigo e ter-lhe enviado uma mensagem.

Passo 4 — Receber mensagens de entrada (Webhook)

Para que as mensagens LINE recebidas apareçam no Klacks, o URL do webhook tem de ser introduzido manualmente na LINE Developers Console.

  1. Copie o URL do Webhook apresentado no Klacks a partir das definições do fornecedor: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. Introduza este URL na LINE Developers Console em Messaging API → Webhook settings como Webhook URL.
  3. Ative a opção „Use webhook".
  4. Certifique-se de que a sua instância Klacks está acessível publicamente via HTTPS.
  5. As mensagens recebidas passam agora a aparecer em tempo real na caixa de entrada de mensagens.

Resolução de problemas

ProblemaCausa possívelSolução
O teste de ligação falha Channel Access Token inválido Emita um novo token na LINE Developers Console
A mensagem não é entregue O destinatário não adicionou a Official Account como amigo ou bloqueou-a O destinatário tem de adicionar a conta como amigo no LINE
O envio falha Limite mensal de mensagens push esgotado Verifique o limite do seu plano no LINE Official Account Manager
Destinatário não encontrado ID de utilizador LINE não guardado Introduza o ID de utilizador da caixa de entrada de mensagens em Morada → Dados de contacto
Faltam mensagens de entrada URL do webhook não introduzido ou „Use webhook" desativado Verifique as Webhook settings na LINE Developers Console
