Pesquisar Fornecedores de LLM — Guia

Para que serve esta função?

Esta vista sugere fornecedores de LLM que ainda não tem na sua lista e adiciona os selecionados com um único clique. Assim, não precisa de introduzir manualmente o nome e o URL base. São sugeridos exclusivamente fornecedores de API compatíveis com o OpenAI — ou seja, exatamente o tipo de serviços que os fornecedores já configurados também utilizam.

As colunas da tabela

Nome do fornecedor

O nome de apresentação do fornecedor (por exemplo, "OpenRouter", "xAI (Grok)").

URL base

O endereço da API através do qual se comunica com o fornecedor (por exemplo, https://api.x.ai/v1/). É exatamente este URL que será utilizado mais tarde na criação.

Origem

Indica de onde provém a sugestão:

  • Catálogo — proveniente de uma lista fixa e verificada de fornecedores conhecidos. Os URLs base estão verificados e são, por isso, fiáveis.
  • Web — encontrado através de pesquisa na internet e avaliado automaticamente. Estas entradas só aparecem quando a pesquisa na Web estiver configurada nas definições. São úteis, mas em caso de dúvida deve verificar rapidamente o URL base.

Acessibilidade

Antes de ser apresentada, cada sugestão é testada em tempo real (chamada ao endpoint /models):

  • Acessível — a API responde, o fornecedor funciona.
  • Acessível (chave necessária) — a API existe, mas exige uma chave de API. O endereço está, portanto, correto.
  • Não acessível — o endereço não responde. Estas entradas não podem ser selecionadas.

Adicionar fornecedor

Assinale um ou mais fornecedores e clique em baixo em "Adicionar seleção". Os fornecedores escolhidos são criados desativados e sem chave de API. Os fornecedores já existentes nem sequer chegam a ser sugeridos.

Próximos passos após a adição

Um fornecedor recém-adicionado ainda não está ativo. Abra-o na lista, introduza a chave de API e ative-o. Depois disso, funciona exatamente como os restantes fornecedores. Os modelos individuais de um fornecedor continuam a ser geridos separadamente através da gestão de modelos.
