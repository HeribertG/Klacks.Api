Manual de scripting de macros

Introdução

Com o editor de macros pode criar scripts que servem de base de cálculo para trabalhos, tipos de emprego, entre outros.

Exemplos de uso:

  • Cálculo preciso de férias e serviço militar com base na taxa de emprego
  • Cálculo de suplementos para trabalho noturno, fins de semana e feriados
  • Adaptação flexível a novos requisitos

Nota: O interpretador de scripts funciona num ambiente sandbox seguro sem acesso ao sistema de ficheiros ou à rede. Não é possível executar código malicioso.

Função e categoria

Além do nome e do conteúdo do script, cada macro na lista de macros tem mais duas propriedades, definidas através de menus suspensos no editor: Categoria e Função. Ambas são puros metadados – ficam fora do script e não alteram o seu cálculo, mas controlam como o Klacks encontra e atribui automaticamente o macro adequado.

Categoria

A categoria atribui um macro a uma área de aplicação:

CategoriaUtilização
Não atribuídoNenhuma área de aplicação especial (padrão para novos macros)
TurnoCálculo de suplementos para turnos regulares (suplemento noturno, de fim de semana, de feriado)
FériasCálculo de horas para férias
DoençaCálculo de horas para doença
AcidenteCálculo de horas para acidente
Workshop (pago)Tempo de workshop/formação pago
Workshop (não pago)Tempo de workshop/formação não pago

A categoria Turno tem um papel especial: turnos recém-criados recebem automaticamente atribuído o macro padrão desta categoria (ver "Função" abaixo). Turnos já existentes nunca são alterados retroativamente por este mecanismo.

Função: Personalizado, Padrão, Padrão (aditivo)

A função classifica o papel de um macro dentro da sua categoria:

FunçãoSignificado
PersonalizadoMacro livre sem papel especial. Pode haver qualquer número por categoria.
PadrãoO macro padrão desta categoria – é atribuído automaticamente a novos turnos. No máximo UM macro por categoria pode ter esta função.
Padrão (aditivo)Macro padrão alternativo com lógica de suplemento aditiva (ver abaixo). Também no máximo um por categoria, adicionalmente possível ao macro "Padrão".

Importante: A função por si só não calcula nada – é uma etiqueta. Se os suplementos são calculados como "highest-wins" (conta apenas a taxa aplicável mais alta) ou de forma aditiva (todas as taxas aplicáveis são somadas) é decidido pelo próprio script. Os dois macros de categoria "Turno" fornecidos mostram a diferença com a mesma estrutura base:

  • "AllShift" (Função: Padrão) – determina, por segmento de tempo, o suplemento mais alto aplicável (noturno/WE1/WE2/WE3/feriado) e utiliza apenas esse.
  • "AllShiftAdditive" (Função: Padrão (aditivo)) – calcula o suplemento noturno, de fim de semana e de feriado de forma independente e soma-os.

Qual dos dois é atribuído automaticamente à criação de um novo turno é controlado por uma definição válida para toda a instalação ("aditivo" ou "a taxa mais alta vence"). Depois, o macro pode ser alterado manualmente a qualquer momento por turno – ou seja, é possível uma operação mista.

Unicidade: Se tentar guardar um segundo macro da mesma categoria também como "Padrão" ou "Padrão (aditivo)", o editor bloqueia o guardar e indica o nome do macro já atribuído. Defina primeiro a função deste último como "Personalizado".

Não é recomendado alterar manualmente "AllShift"/"AllShiftAdditive". Estes dois macros são o mecanismo através do qual as adaptações específicas de país e de setor são aplicadas automaticamente: enquanto os deixar inalterados, o Klacks mantém-os automaticamente sincronizados com as regras adequadas ao seu país ou setor. Se editar manualmente um dos dois, este passa a ser considerado personalizado a partir desse momento – futuras atualizações automáticas de país/setor para este macro deixam então de ser aplicadas silenciosamente, falhando antes com um conflito até resolver manualmente a divergência. Se precisar de uma lógica de suplemento própria, crie antes um novo macro com função "Personalizado" e atribua-o especificamente aos turnos afetados.

Estruturas de controlo

Importante: Palavras-chave como ENDIF, ENDFUNCTION, ENDSUB devem ser escritas sem espaço (não usar END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "grande"
ELSEIF x > 5 THEN
    OUTPUT 1, "médio"
ELSE
    OUTPUT 1, "pequeno"
ENDIF

IF numa linha

IF x > 10 THEN OUTPUT 1, "grande" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "fim de semana"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "dia útil"
    CASE ELSE
        OUTPUT 1, "desconhecido"
END SELECT

Ciclo FOR-NEXT

FOR i = 1 TO 10
    summe += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Ciclo DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Funções e procedimentos

Importante: Funções (FUNCTION) e procedimentos (SUB) devem ser definidos antes da primeira chamada. O interpretador lê o código de cima para baixo.

SUB (procedimento sem valor de retorno)

SUB calcular(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (função com valor de retorno)

FUNCTION duplicar(x)
    duplicar = x * 2
ENDFUNCTION

DIM resultado
resultado = duplicar(21)
OUTPUT 1, resultado

Valores de retorno (OUTPUT)

OUTPUT tipo, valor

tipo e valor são duas expressões separadas por vírgula; ambas são opcionais (padrão 0 ou "", se omitidas). Um macro pode conter qualquer número de linhas OUTPUT – cada uma produz o seu próprio valor de retorno. O Klacks avalia apenas os seguintes tipos:

TipoSignificado
1Resultado principal (horas ou montante total) – é assumido mesmo com valor 0
10Suplemento noturno
11Suplemento para o dia de fim de semana 1 (ex.: sábado)
12Suplemento para o dia de fim de semana 2 (ex.: domingo)
13Suplemento para o dia de fim de semana 3 (terceiro dia de fim de semana configurável)
14Suplemento de feriado

Linhas de suplemento (tipo 10-14) com valor 0 são ignoradas – ou seja, um macro não precisa de emitir uma linha própria para cada tipo de suplemento, apenas para os suplementos que realmente se aplicam. Valores que não possam ser interpretados como número são ignorados.

Ao guardar, o macro é obrigatoriamente compilado e executado uma vez experimentalmente com valores de teste neutros. Erros de sintaxe e de execução (ex.: parênteses não balanceados ou uma expressão pendente) são assim detetados de forma fiável, em vez de resultarem silenciosamente num macro sem função.

Exemplo: Cálculo de suplementos ("AllShift")

O macro padrão fornecido da categoria "Turno". Calcula suplementos para noite, feriado e os três dias de fim de semana configuráveis, com tratamento correto de turnos que atravessam a meia-noite (divisão em segmentos), aplicando por segmento a taxa mais alta aplicável (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Explicação

  • Divisão em segmentos: Turnos que atravessam a meia-noite (ex.: 22:00-06:00) são divididos em dois segmentos (até à meia-noite / a partir da meia-noite), cada um com o seu próprio indicador de dia da semana/feriado
  • SegBonusForType: Calcula o suplemento de um segmento para um determinado tipo de suplemento (10-14), considerando os suplementos noturno, de feriado e de fim de semana
  • WE1/WE2/WE3 em vez de sáb/dom: weekendday1-3 tornam os dias de fim de semana configuráveis (nem todos os países têm sábado/domingo como fim de semana)
  • Suplemento mais alto por segmento: NRate/DRate determinam, respetivamente, a taxa mais alta aplicável para horas noturnas e diurnas – highest-wins, sem acumulação
  • HolidayNextDay: Considera se o dia seguinte é feriado (importante para turnos noturnos que atravessam a meia-noite)
  • Várias linhas OUTPUT: A linha 1 fornece o total, as linhas 10-14 fornecem os montantes individuais de suplemento (ver secção "Valores de retorno")

A variante aditiva ("AllShiftAdditive")

O macro padrão (aditivo) da mesma categoria tem linhas IMPORT idênticas e a mesma estrutura geral – apenas SegBonusForType é diferente: em vez da taxa mais alta, calcula-se de forma independente para cada tipo de suplemento se este se aplica, e todos os montantes aplicáveis são somados no final (já não há highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Se, por exemplo, um turno noturno cair também num feriado, com "AllShift" recebe apenas a taxa mais alta das duas, enquanto com "AllShiftAdditive" recebe o suplemento noturno e o de feriado em conjunto. O resto do script (divisão em segmentos, soma, linhas OUTPUT) é idêntico ao de "AllShift" acima.
