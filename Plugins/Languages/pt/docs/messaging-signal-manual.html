Configurar mensagens Signal

Pré-requisitos

Para enviar mensagens Signal através do Klacks, precisa de uma instância auto-hospedada da signal-cli-rest-api. Trata-se de um projeto open source que disponibiliza o Signal através de uma interface REST.

  • O Docker tem de estar instalado no servidor
  • Um número de telefone que será registado no Signal (recomenda-se um número dedicado)
  • A imagem Docker: bbernhard/signal-cli-rest-api

Importante: a integração com o Signal está concebida apenas para o envio. As mensagens Signal recebidas não são recebidas no Klacks.

Passo 1 — Configurar o signal-cli-rest-api

  1. Inicie o contentor com o Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Associe o seu número Signal através do processo de ligação por código QR: abra no browser 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    e digitalize o código QR apresentado com a aplicação Signal no telemóvel onde o número está registado (Definições → Dispositivos associados → Associar dispositivo). O contentor fica assim associado como dispositivo secundário.
  3. Em alternativa, pode registar o número de forma autónoma através da API — encontrará mais detalhes na documentação do projeto.
  4. Teste a API com uma verificação de funcionamento (healthcheck): 
    curl http://localhost:8080/v1/about

Nota: mais detalhes sobre a configuração podem ser consultados na documentação do signal-cli-rest-api.

Passo 2 — Configurar o Signal no Klacks

  1. Navegue até Definições → Fornecedores de mensagens.
  2. Clique em Adicionar.
  3. Preencha os campos da seguinte forma:
CampoDescriçãoExemplo
NomeNome interno únicosignal-main
Nome de exibiçãoÉ apresentado na interfaceSignal
Tipo de fornecedorSelecione SignalSignal
Número SignalO número de telefone registado, em formato internacional+41791234567
URL da API Signal-CLIURL do contentor signal-cli-rest-api. Se o contentor for executado no mesmo servidor que o Klacks, pode aqui indicar-se http://localhost:8080.http://localhost:8080
AtivadoAtiva/desativa o fornecedorSim
  1. Clique em Guardar.
  2. Teste a ligação através do botão Testar na lista de fornecedores. O teste verifica se o número indicado está registado no contentor.

Nota: o Klacks envia as mensagens através do endpoint POST /v2/send do contentor.

Passo 3 — Enviar mensagens através do chatbot (Klacksy)

Assim que o fornecedor Signal estiver configurado e ativado, o chatbot Klacksy pode enviar mensagens. Não precisa de saber números de telefone — basta utilizar o nome do colaborador ou do cliente: 

"Envia uma mensagem a Max Muster: O seu compromisso é amanhã às 14:00."
"Envia a Anna Beispiel uma mensagem Signal: O turno foi trocado."
"Notifica Peter Müller de que o seu turno de segunda-feira foi cancelado."

O Klacksy procura automaticamente o número de telemóvel registado do destinatário e utiliza o fornecedor Signal configurado. O envio é totalmente transparente para si — trabalha com nomes, o Klacksy trata do resto.

Pré-requisito: o destinatário tem de ter um número de telemóvel registado no Klacks (em Morada → Dados de contacto), em formato internacional (por exemplo, +41791234567). Também nas mensagens de difusão (broadcast), o envio via Signal recorre ao número de telemóvel registado.

Mensagens recebidas

A integração com o Signal não suporta receção — as respostas a mensagens enviadas não são transmitidas ao Klacks. Por isso, a caixa de entrada de mensagens não apresenta mensagens recebidas para este fornecedor.

Resolução de problemas

ProblemaCausa possívelSolução
O teste de ligação falha O contentor não está acessível Verifique se o contentor Docker está em execução (docker ps) e se o URL da API está correto
O teste de ligação falha O número não está registado no contentor Repita a associação através do processo de código QR
A mensagem não é entregue O destinatário não utiliza o Signal ou o número está incorreto Certifique-se de que o destinatário tem o Signal instalado e de que o número está registado no formato +{indicativo do país}{número}
A associação foi perdida O dispositivo foi desassociado na aplicação Signal Volte a associar o contentor através do código QR
O contentor não arranca A porta 8080 já está em utilização Utilize outra porta: -p 9090:8080 e ajuste o URL da API no Klacks
