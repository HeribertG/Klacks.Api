KakaoTalkメッセージングの設定

前提条件

KakaoTalk経由でメッセージを送信するには、developers.kakao.com （Kakao Developers）上でアプリを作成する必要があります。KakaoTalkは韓国で 圧倒的なシェアを持つメッセンジャーです。Klacksとの連携はKakao Developer API （「フレンドへのメッセージ送信」）を使用します。

Kakao Developer APIの重要な制限事項：

  • この連携は送信専用です — 受信には対応していません。
  • アクセストークンは短命（有効期限は約6時間）であり、Klacksの 外部で更新し、再度登録する必要があります。
  • メッセージは、アプリのKakao「フレンド」として接続され、 メッセージ送信に同意したユーザーにのみ送信できます。
  • 本番用のビジネスメッセージ（AlimTalk）を利用するには、韓国では 認可された代理店を通じたビジネスチャンネルが必要です — この連携は それをカバーしていません。あくまでDeveloper APIを使用します。

ステップ1 — Kakao Developersアプリのセットアップ

  1. developers.kakao.comでアプリを作成します。
  2. アプリでKakaoログインを有効化します。
  3. talk_messageおよびfriendsスコープを許可します。
  4. Kakaoログインの OAuthフローを通じてアクセストークンを取得します （送信対象となるユーザー本人がスコープに同意する必要があります）。

注意：アクセストークンはパスワードと同様に扱ってください。 公開して共有せず、安全に保管してください。

ステップ2 — KlacksでKakaoTalkを設定する

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 以下のようにフィールドを入力します：
フィールド説明例
名前内部で使用する一意の名前kakaotalk-main
表示名画面上に表示される名前KakaoTalk
プロバイダータイプKakaoTalkを選択KakaoTalk
アクセストークンOAuthフローで取得したトークンkakao-access-token...
有効化プロバイダーの有効/無効を切り替えますはい
  1. 保存をクリックします。
  2. プロバイダー一覧のテストボタンで接続を確認します。

重要： アクセストークンは約6時間で失効します。 Klacksは自動更新を行わないため、外部（Kakaoのリフレッシュトークンフロー）で 更新し、Klacksに再度登録する必要があります。

ステップ3 — チャットボット（Klacksy）経由でメッセージを送信する

KakaoTalkプロバイダーが設定・有効化されると、チャットボットのKlacksyが メッセージを送信できるようになります。IDを知る必要はありません — 従業員またはクライアントの名前をそのまま使用するだけです： 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksyは受信者に登録されているIDを自動的に検索し、設定済みの KakaoTalkプロバイダーを使用します。送信処理はユーザーにとって完全に 透過的です — あなたは名前だけを扱い、残りはKlacksyが処理します。

前提条件： 受信者にはKakao Friends APIから取得した フレンドUUIDがKlacksに登録されている必要があります （住所 → 連絡先データの下）。受信者はKakao「フレンド」としてアプリと 接続されている必要があります — それ以外のユーザーには送信できません。

受信メッセージ

KakaoTalk連携は受信をサポートしていません — 送信したメッセージへの返信は Klacksに転送されません。そのため、メッセージングの受信トレイには このプロバイダーからの受信メッセージは表示されません。

トラブルシューティング

問題考えられる原因解決策
接続テストが失敗する アクセストークンの有効期限切れ（有効期限は約6時間） Kakao OAuthフローでトークンを更新し、再度登録してください
メッセージが配信されない 受信者がアプリのKakao「フレンド」になっていない 受信者はKakaoログインでアプリと接続し、スコープに同意する必要があります
受信者が見つからない フレンドUUIDが登録されていない Friends APIでUUIDを取得し、住所 → 連絡先データに入力してください
権限エラーで送信が拒否される talk_messageまたはfriendsスコープが許可されていない developers.kakao.comでアプリのスコープ設定を確認してください
本番環境での一斉送信ができない Developer APIはAlimTalkをカバーしていない 韓国でのビジネスメッセージには認可された代理店を通じたビジネスチャンネルが必要です
