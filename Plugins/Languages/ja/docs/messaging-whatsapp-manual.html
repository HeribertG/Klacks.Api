WhatsAppの設定

前提条件

Klacksを使ってWhatsApp経由でメッセージを送受信するには、Meta開発者アカウントと、 WhatsApp製品を有効にしたMetaアプリが必要です。Klacksは送信にMetaビジネスプラットフォームの WhatsApp Cloud APIを、受信にMetaのウェブフックを使用します。

注：設定とテストに費用はかかりません。アプリを作成すると、Metaが自動的に無料の テスト用電話番号を用意します。

重要 — 送信元番号はあなたの個人の番号ではありません。 通常のWhatsAppアプリですでに使用されている電話番号をCloud APIに登録することはできず、 登録済みの番号はWhatsApp Messengerでは使用できなくなります。そのため、Metaが提供する テスト用番号か、業務専用のご自身の番号を使用してください。携帯電話上の個人のWhatsAppは テスト時の受信者として使うものであり、送信元としては使用しません。

ステップ1 — Metaアプリの作成

  1. developers.facebook.com/appsを開き、Create appをクリックします。
  2. ユースケースとしてOtherを、アプリの種類としてBusinessを選択します。
  3. ダッシュボードで製品WhatsAppのSet upをクリックします。 その際、テスト用電話番号が自動的に生成・登録されます。
  4. 左側のナビゲーションでWhatsApp → API Setupに移動します。
  5. Phone number IDを控え、Generate access tokenから アクセストークンを生成します。
  6. App settings → Basicにある App Secretを控えておきます — 受信メッセージの署名検証に必要です。

注意 — 似た2つのID： API Setupパネルには Phone number IDとWhatsApp Business Account IDがすぐ 上下に並んで表示されます。Klacksが必要とするのはPhone number IDです。 誤ったIDを入力しても接続テストは成功と表示されますが、送信はすべて失敗します。

注意 — トークンの有効期間： Generate access tokenで生成した トークンは一時的なテスト用トークンで、短時間で失効します。継続運用には、 Metaビジネスマネージャでシステムユーザーを介して恒久トークンを作成してください。

ステップ2 — 受信者番号の許可登録

テスト用番号は、事前に許可登録された宛先にしか送信できません。 API SetupパネルのTo → Manage phone number listで、ご自身のWhatsApp番号を追加してください。 Metaがこの番号に確認コードを送信するので、それを入力します。

この手順を行わないと、Metaはこの番号への送信をすべて拒否します。後日、認証済みの 自社の番号を使用する場合は、この許可登録は不要になります。

ステップ4 — 24時間ウィンドウ

この点でWhatsAppはTelegramやSlackとは根本的に異なります。企業が自由なテキストメッセージを 送信できるのは、カスタマーサービスウィンドウが開いている間だけです。 このウィンドウを開くのは受信者であり、受信者があなたのWhatsApp番号宛にメッセージを 送ることで開きます。ウィンドウは24時間開いたままとなり、受信者からのメッセージが届くたびに 延長されます。

このウィンドウの外では、Metaは事前に承認されたメッセージテンプレートしか 許可しません。Klacksは現在、自由なテキストメッセージのみを送信するため、 自らの側から会話を開始することはできません。

これが意味すること： 従業員に一度だけ、KlacksのWhatsApp番号宛に メッセージを送るよう依頼してください。その後24時間は送信が可能になり、返信があるたびに ウィンドウが延長されます。ウィンドウが閉じている場合、送信はエラーになります — これは 設定の問題ではなく、WhatsAppの仕様です。

このウィンドウに左右されずに従業員へ連絡する必要がある場合は、Telegramや Signalのほうが適したプロバイダーです — これらにはこの制限がありません。

ステップ5 — チャットボット（Klacksy）経由でメッセージを送信する

WhatsAppプロバイダーの設定と有効化が完了すると、チャットボットのKlacksyが WhatsApp経由でメッセージを送信できるようになります。従業員名を使って指示してください。 

"Max Musterにメッセージを送信して：予定は明日14時です。"
"Anna Beispielにメッセージを送って：シフトが交代されました。"

宛先には、先頭のゼロとプラス記号を除いた国際形式の電話番号が使用されます （例：079 123 45 67なら41791234567）。 送信処理はユーザーには完全に見えない形で行われます — 名前を指定するだけで、残りはKlacksyが処理します。

前提条件： WhatsApp番号は対応するKlacksの連絡先と紐付けられている 必要があり（住所 → 連絡先情報の項目）、さらにステップ4の24時間ウィンドウが 開いている必要があります。

ステップ6 — 受信メッセージを受け取る（ウェブフック）

WhatsAppからの受信メッセージをKlacks上に表示するには、MetaアプリのWebhookを 設定する必要があります。Callback URLを登録する前に、Klacks側でプロバイダーを 保存・有効化してください — MetaはURLを即座に検証リクエストで確認し、Klacksが検証トークンに 基づいて自動的に応答します。

  1. Metaアプリを開き、WhatsApp → Configurationに移動します。
  2. WebhookのEditをクリックし、次を入力します。
    • Callback URL：Klacksに表示されているWebhook URL 
      https://{your-domain}/api/messaging/webhook/whatsapp
    • Verify token：ステップ3で検証トークンの項目に 入力したものとまったく同じ値
  3. Verify and saveをクリックします。
  4. Webhook fieldsでmessagesフィールドを購読します。
  5. 受信メッセージはリアルタイムでメッセージング受信箱に表示されるようになります。 その際、Klacksは登録済みのアプリシークレットを使って各リクエストの署名 （X-Hub-Signature-256）を検証します。

Callback URLは外部からHTTPSでアクセスできる必要があります。公開アドレスの ない社内ネットワークへのインストールでは、送信は動作しますが、メッセージを受信することは できません。
