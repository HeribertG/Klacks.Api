Zaloメッセージングの設定

前提条件

Zalo経由でメッセージを送信するには、oa.zalo.me上でZalo公式 アカウント（OA）を作成し、さらにdevelopers.zalo.me上でアプリを 作成する必要があります。Zaloはベトナムで最も利用されているメッセージングアプリです。

重要： Zalo連携は送信専用として設計されています。 さらに、Zaloプラットフォームには以下の制限があります。

  • アクセストークンは約25時間で失効するため、Klacksの外部で更新し、 再度登録する必要があります。
  • メッセージは、事前に公式アカウントとやり取りしたことのある ユーザーにのみ送信できます（インタラクションウィンドウ）。

ステップ1 — Zalo公式アカウントとアプリの設定

  1. oa.zalo.meで公式アカウントを作成します。
  2. developers.zalo.meでアプリを作成します。
  3. 公式アカウントとアプリを連携します。
  4. Zalo Developerコンソールの OAuthフローを使ってアクセストークンを 取得します。

注：アクセストークンはパスワードと同様に扱ってください。 公開せず、安全に保管してください。

ステップ2 — Klacks側でZaloを設定する

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 各項目を次のように入力します。
項目説明例
名前内部で使用する一意の名前zalo-oa
表示名画面上に表示される名称Zalo
プロバイダー種別Zaloを選択しますZalo
アクセストークンOAuthフローで取得したトークンzalo-oa-access-token...
OA ID公式アカウントのID（参考情報、識別用）987654321...
有効化プロバイダーの有効・無効を切り替えますはい
  1. 保存をクリックします。
  2. プロバイダー一覧のテストボタンで接続を確認します。

重要： アクセストークンは約25時間で失効します。 Klacksは自動的に更新を行いません — Zaloのリフレッシュトークンフローを使って外部で 更新し、Klacksに再度登録する必要があります。ご注意ください：リフレッシュトークンは 使い切り（single-use）です — 更新のたびに新しいトークンペアが 発行されます。

ステップ3 — チャットボット（Klacksy）経由でメッセージを送信する

Zaloプロバイダーの設定と有効化が完了すると、チャットボットのKlacksyが メッセージを送信できるようになります。Zaloユーザー IDを把握しておく必要はありません — 従業員またはクライアントの名前を使うだけです。 

「マックス・ムスターにメッセージを送って：ご予約は明日14時です。」
「アンナ・バイシュピールにメッセージを送信して：シフトが交換されました。」
「ペーター・ミュラーに、月曜日の勤務が休止になることを通知して。」

Klacksyは受信者の登録済みZaloユーザー IDを自動的に検索し、 設定されたZaloプロバイダーを使用します。送信処理はユーザーにとって完全に透過的です — 名前だけを扱えばよく、残りはKlacksyが処理します。

前提条件： 受信者には、Klacks上でZaloユーザー ID が登録されている必要があります（住所 → 連絡先情報の項目）。受信者は事前に 公式アカウントとやり取りしている必要があります（例：OAをフォローする、またはメッセージを 送信する）— インタラクションウィンドウの外では、Zaloは送信を拒否します。

受信メッセージについて

Zalo連携は受信をサポートしていません — 送信したメッセージへの返信はKlacksに 転送されません。そのため、このプロバイダーについては メッセージング受信箱に受信メッセージは表示されません。

トラブルシューティング

問題考えられる原因対処方法
接続テストが失敗する アクセストークンが失効している（有効期間は約25時間） リフレッシュトークンフローでトークンを更新し、再度登録してください
メッセージが配信されない ユーザーが公式アカウントとやり取りしていない 受信者にOAをフォローするか、メッセージを送信してもらってください
受信者が見つからない Zaloユーザー IDが登録されていない 住所 → 連絡先情報の項目にユーザーIDを入力してください
トークンの更新が失敗する リフレッシュトークンが既に使用されている（使い切り） Zalo Developerコンソールの OAuthフローを再度実行してください
権限エラーで送信が拒否される OAがアプリと連携されていない developers.zalo.meでアプリと公式アカウントの連携を確認してください
