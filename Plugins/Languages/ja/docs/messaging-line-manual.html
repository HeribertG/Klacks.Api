LINEメッセージングの設定

前提条件

LINEでメッセージを送受信するには、LINE Developersコンソールで Messaging APIチャネルを持つLINE公式アカウントが必要です。 LINEは特に日本、台湾、タイで広く普及しています。

注意：プッシュメッセージにはLINEのプランに応じて月間の配信数上限があります （無料プランには制限があります）。ご利用の公式アカウントプランの最新の条件をご確認ください。

ステップ1 — LINE公式アカウントとMessaging APIチャネルの作成

  1. LINE公式アカウントを作成します （LINE Official Account Managerから作成）。
  2. LINE Developersコンソール（developers.line.biz）を開き、 Messaging APIチャネルを作成するか、 公式アカウントをMessaging APIと連携させます。
  3. Messaging APIタブで長期利用可能な チャネルアクセストークンを発行（Issue）します。
  4. Basic Settingsタブからチャネルシークレットを 控えておきます。

注意：チャネルアクセストークンとチャネルシークレットはパスワードと同様に取り扱ってください。 外部に公開せず、安全に保管してください。

ステップ2 — KlacksでLINEを設定する

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 以下のように各項目を入力します。
項目説明例

プロバイダータイプLINEを選択しますLINE

チャネルシークレットBasic Settingsに表示されるシークレットabc123def456...
WebhookのURLKlacksインスタンスのURLが自動的に入力されます（編集不可）https://example.com/api/messaging/webhook/line

  1. 保存をクリックします。
  2. プロバイダー一覧のテストボタンで接続を確認します。

ステップ3 — チャットボット（Klacksy）経由でメッセージを送信する

LINEプロバイダーが設定・有効化されると、チャットボットのKlacksyがメッセージを 送信できるようになります。LINEのユーザーIDを把握している必要はありません。 従業員またはクライアントの名前を指定するだけです。 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksyは受信者に登録されているLINEユーザーIDを自動的に検索し、設定済みのLINE プロバイダーを使用します。送信処理はすべて内部で完結するため、あなたは名前を 入力するだけでよく、後の処理はKlacksyが行います。

前提条件：受信者のLINEユーザーID （Uで始まります）がKlacksに登録されている必要があります （住所 → 連絡先情報の下）。ユーザーIDは受信メッセージを通じて把握できます （メッセージング受信箱に表示されます）。そのためには、受信者が事前に貴社の 公式アカウントを友だち追加し、メッセージを送信している必要があります。

ステップ4 — 受信メッセージを受け取る（Webhook）

Klacksで受信LINEメッセージを表示するには、WebhookのURLを LINE Developersコンソールに手動で登録する必要があります。

  1. プロバイダー設定に表示されているKlacksのWebhookのURLを コピーします。 
    https://{ihre-domain}/api/messaging/webhook/line
  2. LINE DevelopersコンソールのMessaging API → Webhook settingsで、このURLを Webhook URLとして登録します。
  3. 「Use webhook」オプションを有効にします。
  4. KlacksインスタンスがHTTPS経由で外部から到達可能であることを確認します。
  5. これで受信メッセージがリアルタイムでメッセージング受信箱に 表示されるようになります。

トラブルシューティング

問題考えられる原因解決方法
接続テストが失敗する チャネルアクセストークンが無効 LINE Developersコンソールで新しいトークンを発行してください
メッセージが配信されない 受信者が公式アカウントを友だち追加していない、またはブロックしている 受信者にLINEでアカウントを友だち追加してもらってください
送信が失敗する 月間のプッシュ配信数上限に達している LINE Official Account Managerでプランの配信数上限を確認してください
受信者が見つからない LINEユーザーIDが未登録 メッセージング受信箱に表示されるユーザーIDを住所 → 連絡先情報に登録してください
受信メッセージが表示されない WebhookのURLが未登録、または「Use webhook」が無効 LINE Developersコンソールでウェブフック設定を確認してください
