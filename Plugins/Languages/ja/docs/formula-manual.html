数式フィールド マニュアル

基本構文

各数式フィールドは、outputコマンドで結果を出力します：

output 1, <式>

最初のパラメーター1はメッセージタイプであり、常に1でなければなりません。2番目のパラメーターは出力する値です。

簡単な例：

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & "件"

使用可能な変数

使用可能な変数は変数タブに一覧表示されており、そこでテスト値を設定できます。レポートタイプに応じて、利用できる変数が異なります：

レポートタイプテーブルフッター
勤務スケジュールtotalRows, totalHours, totalSurcharges, totalWorkDays
欠勤totalRows, totalValue
住所totalRows
グループtotalRows

演算子

演算子説明例
+加算totalHours + 2
-減算totalRows - 1
*乗算totalValue * 1.5
/除算totalHours / 8
^べき乗2 ^ 10
\整数除算10 \ 3 → 3
MOD剰余（余り）10 MOD 3 → 1
&文字列連結"合計: " & totalRows

組み込み関数

型変換

関数説明
CStr(x)数値を文字列に変換
CInt(x)整数に変換
CDbl(x)小数（Double）に変換

数学関数

関数説明
Abs(x)絶対値
Round(x, n)小数点以下n桁に四捨五入
Int(x)整数に切り捨て
Sqr(x)平方根
Sgn(x)符号（-1、0、1）

文字列関数

関数説明
Len(s)文字列の長さ
Left(s, n)左からn文字
Right(s, n)右からn文字
Mid(s, pos, n)位置posからn文字
UCase(s)大文字に変換
LCase(s)小文字に変換
Trim(s)前後の空白を除去
Replace(s, old, new)文字列を置換

条件分岐

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "件数が多い"
ELSEIF totalRows > 0 THEN
    output 1, "件数が少ない"
ELSE
    output 1, "件数なし"
ENDIF

1行IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF（短縮形）

output 1, IIF(totalRows > 0, "OK", "空")

変数とループ

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

実用例

件数のテキスト表示

output 1, CStr(totalRows) & "件"

丸めた値（小数点1桁）

output 1, CStr(Round(totalValue, 1))

時間をh:mm形式で表示

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

条件付き出力

IF totalRows = 0 THEN
    output 1, "欠勤なし"
ELSE
    output 1, CStr(totalRows) & "件の欠勤（合計：" & CStr(totalValue) & "）"
ENDIF

平均を計算

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/日"
ELSE
    output 1, "-"
ENDIF
注意：スクリプトインタープリターはファイルシステムやネットワークにアクセスできない安全なサンドボックス環境で動作します。
