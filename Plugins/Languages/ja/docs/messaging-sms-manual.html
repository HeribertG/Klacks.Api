SMSプロバイダーの設定

前提条件

Klacksを通じてSMSメッセージを送信するには、 TwilioまたはTwilio互換のSMSゲートウェイのアカウントが必要です。Klacksは Twilio REST API(Basic認証によるMessagesエンドポイント)を使用します。

重要: SMS連携は送信専用です。 受信SMSはKlacksでは受信されません。

手順1 — Twilioアカウントのセットアップ

  1. twilio.comで登録し、電話番号とメールアドレスを 確認してください。
  2. Twilio Consoleを開きます。ダッシュボードの Account Infoに、必要な2つの認証情報が表示されます:
    • Account SID — ACで始まります
    • Auth Token — 「表示」をクリックします
  3. Phone Numbers → Buy a numberで 送信元番号を購入してください(SMS対応であること)。 この番号が送信SMSの差出人として表示されます。
  4. テストアカウント: 無料のトライアルアカウントでは、事前に 確認済みの番号にのみSMSを送信でき、送信内容にはトライアル表示が含まれます。

注意: Auth Tokenはパスワードと同様に取り扱ってください。 公開せず、安全に保管してください。

手順2 — KlacksでSMSプロバイダーを設定する

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 以下のように各項目を入力します:
フィールド説明例
名前内部的な一意の名前sms-twilio
表示名画面に表示される名前SMS (Twilio)
プロバイダータイプSMSを選択しますSMS
Account SIDTwilio ConsoleのAccount SIDACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Auth TokenTwilio ConsoleのAuth Tokena1b2c3d4e5f6...
送信元番号購入した電話番号(国際形式)+41791234567
ゲートウェイURL(任意)Twilio互換の代替ゲートウェイ専用 — Twilioを使用する場合は空欄のままにしますhttps://api.twilio.com
有効プロバイダーの有効/無効を切り替えますはい
  1. 保存をクリックします。
  2. プロバイダー一覧のテストボタンで接続を確認します。

ゲートウェイURLについて: Twilioを使用する場合はこの項目を空欄のままにしてください — Klacksが自動的にhttps://api.twilio.comを使用します。Twilio互換APIを持つ 代替ゲートウェイを使用する場合にのみURLを入力してください。

手順3 — チャットボット(Klacksy)経由でメッセージを送信する

SMSプロバイダーが設定され有効化されると、チャットボットKlacksyが メッセージを送信できるようになります。電話番号を把握しておく必要はありません — 従業員またはクライアントの名前を使うだけです: 

「マックス・ムスターにSMSを送って: 予約は明日14時です。」
「アンナ・バイシュピールにSMSを送信して: シフトが交換されました。」
「ペーター・ミュラーにSMSで、月曜日の勤務が休止になることを通知して。」

Klacksyは受信者の登録済み携帯電話番号を自動的に検索し、 設定されたSMSプロバイダーを使用します。送信処理はユーザーにとって完全に透過的です — 名前だけを扱えばよく、残りはKlacksyが処理します。

前提条件: 受信者にはKlacks上で携帯電話番号が登録されている必要があります (住所 → 連絡先情報の下)、国際形式(例: +41791234567)で。

受信メッセージ

SMS連携は受信をサポートしていません — 送信したSMSへの返信は Klacksに転送されません。そのため、メッセージング受信ボックスには このプロバイダーからの受信メッセージは表示されません。

トラブルシューティング

問題考えられる原因解決策
接続テストが失敗する Account SIDまたはAuth Tokenが間違っている Twilio Consoleのダッシュボードで両方の値を確認してください
SMSが配信されない 送信元番号がSMS対応でないか、有効化されていない Twilio ConsoleのPhone Numbersで番号を確認してください
受信者がSMSを受け取れない(トライアルアカウント) 受信者の番号が確認されていない Twilio Consoleで番号を確認するか、有料アカウントに切り替えてください
受信者がSMSを受け取れない 電話番号が国際形式でない +{国番号}{番号}の形式を使用してください(例: +41791234567)
「Permission to send an SMS has not been enabled」というエラー 送信先の国がGeo Permissionsで有効化されていない Twilio ConsoleのMessaging → Geographic Permissionsでその国を有効化してください
アカウント残高が不足している 従量課金の予算が枯渇している Twilio Consoleで残高をチャージしてください
