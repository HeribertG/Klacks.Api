LLMプロバイダーの検索 — 操作ガイド

この機能は何のためにありますか？

この画面では、まだリストに登録していないLLMプロバイダーを提案し、選択したものをワンクリックで 追加できます。これにより、名称やベースURLを手入力する必要がなくなります。提案されるのは OpenAI互換のAPIプロバイダーのみです — つまり、すでに設定済みのプロバイダーと同じ種類のサービスです。

テーブルの各列

プロバイダー名

プロバイダーの表示名です（例：「OpenRouter」「xAI (Grok)」）。

ベースURL

プロバイダーとの通信に使用されるAPIアドレスです（例： https://api.x.ai/v1/）。このURLがそのまま登録時に使用されます。

ソース

提案がどこから来ているかを示します：

  • カタログ — 固定で登録された、検証済みの既知プロバイダー一覧から取得されたものです。 ベースURLは検証済みであり、信頼性があります。
  • Web — インターネット検索によって見つけられ、自動的に解析されたものです。 この項目は、設定でWeb検索が有効になっている場合にのみ表示されます。 有用ではありますが、念のためベースURLを一度確認することをお勧めします。

到達可能性

表示前に、各提案は実際に接続テストされます（/modelsエンドポイントの呼び出し）：

  • 到達可能 — APIが応答しており、プロバイダーは正常に機能します。
  • 到達可能（キーが必要） — APIは存在しますが、APIキーが必要です。 アドレス自体は正しいということです。
  • 到達不可 — アドレスが応答しません。これらの項目は選択できません。

プロバイダーの追加

1つまたは複数のプロバイダーにチェックを入れ、下部の 「選択項目を追加」をクリックしてください。選択したプロバイダーは 無効状態・APIキーなしで登録されます。既に登録済みのプロバイダーは、 そもそも提案されません。

追加後の次の手順

新しく追加されたプロバイダーは、まだ有効になっていません。リストからそのプロバイダーを開き、 APIキーを入力して有効化してください。その後は、 他のプロバイダーと全く同じように動作します。各プロバイダーの個別モデルについては、 引き続きモデル管理画面で別途管理してください。
