Threema Gatewayの設定

前提条件

Threema経由でメッセージを送信するには、 Threema Gatewayのアカウントが必要です。Threemaはスイスのプロバイダーで、 スイス国内で広く普及しており、データ保護に配慮しています(スイス連邦データ保護法DSG準拠)。

重要: Threema連携は送信専用です。 受信メッセージの受け取りにはGatewayのエンドツーエンドモードが必要となるため、 サポートされていません。送信には料金が発生し、送信するメッセージごとに クレジットを消費します。

手順1 — Threema Gatewayアカウントの作成

  1. gateway.threema.chで登録します。
  2. Basicモードのゲートウェイ IDを申請します (例: *MYGATEWAY)。このIDは必ずアスタリスク(*)で始まり、 Threema側の承認が必要です。
  3. クレジットを購入します — 残高がないとメッセージを送信できません。
  4. GatewayダッシュボードからAPI Secretを控えておきます。

注意: API Secretはパスワードと同様に取り扱ってください。 公開せず、安全に保管してください。

手順2 — KlacksでThreemaを設定する

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 以下のように各項目を入力します:

プロバイダータイプThreemaを選択しますThreema

API SecretGatewayダッシュボードのAPI Secreta1b2c3d4e5...

  1. 保存をクリックします。
  2. プロバイダー一覧のテストボタンで接続を確認します。 このテストではGatewayのクレジット照会APIを通じて認証情報を検証します。

手順3 — チャットボット(Klacksy)経由でメッセージを送信する

Threemaプロバイダーが設定され有効化されると、チャットボットKlacksyが メッセージを送信できるようになります。Threema IDを把握しておく必要はありません — 従業員またはクライアントの名前を使うだけです: 

「マックス・ムスターにメッセージを送って: 予約は明日14時です。」
「アンナ・バイシュピールにメッセージを送信して: シフトが交換されました。」
「ペーター・ミュラーに、月曜日の勤務が休止になることを通知して。」

Klacksyは受信者の登録済みThreema IDを自動的に検索し、 設定されたThreemaプロバイダーを使用します。送信処理はユーザーにとって完全に透過的です — 名前だけを扱えばよく、残りはKlacksyが処理します。

前提条件: 受信者には8桁のThreema IDが Klacks上で登録されている必要があります(住所 → 連絡先情報の下)。 Threema IDは従業員自身のThreemaアプリの「マイプロフィール」から確認できます。

受信メッセージ

Threema連携は受信をサポートしていません — 送信したメッセージへの返信は Klacksに転送されません。受信にはThreema Gatewayの エンドツーエンドモードが必要ですが、Klacks連携ではBasicモードを使用しています。 そのため、メッセージング受信ボックスにはこのプロバイダーからの受信メッセージは表示されません。
