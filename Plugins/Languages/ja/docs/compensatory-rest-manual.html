代替休憩

これらの設定は代替休憩を制御します。2つの勤務間の法定最低休憩時間が下回られた場合、不足した休憩時間は期限内に代替休憩として取り戻す必要があります。これらの値は事業所全体のデフォルトとして適用されます。

代替休憩を有効化

代替休憩チェックをオンまたはオフにします。このオプションが無効の場合、期限は適用されません。

  • 標準: 無効。

期限（日数）

最低休憩時間を下回った後、代替休憩が付与されなければならない日数。

  • 0 以上の整数値。
  • 例: 14 は、代替休憩が2週間以内に行われなければならないことを意味します。

標準休憩時間の由来

代替休憩が発生する基準となる標準休憩時間のしきい値は、計画設定の最小休憩時間（計画ルール / 標準値）から導出され、そこで編集可能です。このカードでは管理されません。そこでの最小休憩時間を変更すると、代替休憩にも影響します。
