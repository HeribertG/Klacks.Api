Signalメッセージングの設定

前提条件

Klacksを通じてSignalメッセージを送信するには、自己ホスト型の signal-cli-rest-apiインスタンスが必要です。これはSignalを REST インターフェース経由で利用可能にするオープンソースプロジェクトです。

  • サーバーにDockerがインストールされている必要があります
  • Signalに登録する電話番号（専用番号の使用を推奨）
  • Dockerイメージ：bbernhard/signal-cli-rest-api

重要：Signal連携は送信専用です。 受信したSignalメッセージはKlacksでは受け取れません。

ステップ1 — signal-cli-rest-apiの設定

  1. Dockerでコンテナを起動します： 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. QRコードリンク方式でSignal番号を連携します。 ブラウザで 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    を開き、表示されたQRコードを、番号が登録されている携帯電話のSignalアプリで スキャンしてください（設定 → 連携済みデバイス → デバイスを連携）。 これによりコンテナがセカンドデバイスとして連携されます。
  3. 代わりに、APIを使って番号を自分で登録することもできます — 詳細はプロジェクトのドキュメントを参照してください。
  4. ヘルスチェックでAPIをテストします： 
    curl http://localhost:8080/v1/about

注：設定に関する詳細は signal-cli-rest-apiのドキュメントを参照してください。

ステップ2 — KlacksでSignalを設定

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 以下のように各項目を入力します：
項目説明例
名前内部で使用する一意の名前signal-main
表示名画面上に表示される名前Signal
プロバイダータイプSignalを選択しますSignal
Signal番号国際形式で登録された電話番号+41791234567
Signal CLI API URLsignal-cli-rest-apiコンテナのURL。コンテナがKlacksと同じサーバー上で稼働している場合は、ここにhttp://localhost:8080を指定できます。http://localhost:8080
有効プロバイダーの有効／無効を切り替えますはい
  1. 保存をクリックします。
  2. プロバイダー一覧のテストボタンで接続を確認します。 このテストでは、指定した番号がコンテナに登録されているかを確認します。

注：KlacksはコンテナのPOST /v2/sendエンドポイント経由で メッセージを送信します。

ステップ3 — チャットボット（Klacksy）経由でメッセージを送信

Signalプロバイダーが設定・有効化されると、チャットボットのKlacksyが メッセージを送信できるようになります。電話番号を把握しておく必要はありません — 従業員またはクライアントの名前を指定するだけです： 

"Max Musterにメッセージを送信して：予定は明日14時です。"
"Anna Beispielにシグナルメッセージを送って：シフトが交代されました。"
"Peter Müllerに、月曜日の勤務がなくなったことを通知して。"

Klacksyは受信者に登録されている携帯電話番号を自動的に検索し、 設定済みのSignalプロバイダーを使用します。送信処理はすべて自動化されており — あなたは名前だけを扱い、残りはKlacksyが処理します。

前提条件：受信者にはKlacks上で携帯電話番号が登録されている必要があります （アドレス → 連絡先情報の下）、国際形式で（例：+41791234567）。 一斉配信メッセージの場合も、Signal送信は登録された携帯電話番号を使用します。

受信メッセージ

Signal連携は受信をサポートしていません — 送信したメッセージへの返信は Klacksには転送されません。そのため、メッセージング受信箱には このプロバイダーからの受信メッセージは表示されません。

トラブルシューティング

問題考えられる原因解決策
接続テストが失敗する コンテナに到達できない Dockerコンテナが稼働しているか（docker ps）、API URLが正しいかを確認してください
接続テストが失敗する 番号がコンテナに登録されていない QRコードリンク方式による連携をやり直してください
メッセージが配信されない 受信者がSignalを利用していない、または番号が誤っている 受信者がSignalをインストール済みであること、番号が+{国番号}{番号}形式で登録されていることを確認してください
連携が失われた Signalアプリ側でデバイスの連携が解除された QRコードリンクからコンテナを再連携してください
コンテナが起動しない ポート8080がすでに使用されている 別のポートを使用してください：-p 9090:8080、KlacksのAPI URLも合わせて変更してください
