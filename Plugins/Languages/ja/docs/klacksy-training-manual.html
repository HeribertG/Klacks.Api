Klacksyトレーニング - マニュアル

トレーニングツールとは？

トレーニングツールは、チャットボットKlacksyのページ内ナビゲーションを制御します。ユーザーが 「Klacksy、住所を見せて」のように話す、または入力すると、Klacksyは該当するページへ移動し、 対応するセクションまでスクロールします。

これを機能させるには、ページ上の各アンカーに対して、各言語における同義語の リストが必要です（例：ターゲットaddressesに対する「住所」「顧客」「連絡先」など）。

「ターゲット」タブ

フロントエンドで見つかったすべてのアンカー（HTML属性data-klacksy-target）の 一覧です。ステータスフィルター：

  • pending：アンカーは存在するが、まだ同義語がない
  • generated：同義語が自動生成され、確認が必要
  • reviewed：管理者によって同義語が承認済み
  • needs-review：再確認が必要としてマークされている

ターゲットをクリックすると、その下に同義語エディターが開きます。ここで同義語を追加・削除でき、 「確認済みとして保存」で承認できます。

「フィードバック」タブ

Klacksyが割り当てられなかったユーザー入力（該当する同義語が見つからなかった） を表示します。このリストから、まだ不足している同義語を把握できます。

「メトリクス」タブ

すべてのターゲットをステータス別に一覧表示します。トレーニングの進捗状況を把握するのに 役立ちます。

ビルドパイプライン（CLI）

テンプレートに新しいdata-klacksy-targetアンカーが追加された場合、マニフェストと 初期同義語を再生成する必要があります。以下のコマンドはCIおよびHuskyのpre-commitでも 自動的に実行されます。 

cd C:\SourceCode\Klacks.Ui

# 1. テンプレートをスキャン → すべてのアンカーを含むnavigation-targets.jsonを生成
npm run scan:targets

# 2a. 初期同義語を生成（コア4言語＋プラグイン22ロケール全て、約2.5時間）
npm run generate:synonyms

# 2b. コアロケールのみ（de/en/fr/it）— 高速、約9分
npm run generate:synonyms -- --core-only

# 2c. 不足しているプラグインロケールのみ追加生成 — 約45分
npm run generate:synonyms -- --plugins-only

# 3. ウェイクワードの整合性を確認
npm run wake-word-lint

重要：npm runの際には、オプションをスクリプトに渡すために --を付ける必要があります。--がないと、npmがそのフラグを無視して しまい、スクリプトは標準モードで実行されます。

npmを使わない代替方法：npx tsx tools/generate-synonyms.ts --core-only。

APIキー

LLM APIキーは以下の順序で検索されます：

  1. 環境変数SYNONYM_LLM_API_KEY
  2. DBテーブルllm_providers（プロバイダーdeepseek、 is_enabled = true）— psql呼び出しにより自動取得
  3. それ以外の場合はエラーメッセージ

標準プロバイダーはDeepSeekです。SYNONYM_LLM_PROVIDER_ID=anthropic （または設定内で構成された他のLLMプロバイダー）で変更可能です。

ステップ1 - scan:targets

すべてのAngularテンプレートをdata-klacksy-target属性について検索し、 マニフェストApplication/Skills/Definitions/navigation-targets.jsonを生成します。 新しいアンカーはその後、「ターゲット」タブにステータスpendingとして表示されます。

ステップ2 - generate:synonyms

各新規アンカーに対して、data-klacksy-label-keyとカテゴリーから初期同義語を 生成します。生成後のステータスはgeneratedとなり、管理者によるレビューが必要です。

このスクリプトは5ターゲットごとにマニフェストのチェックポイントを書き込むため、途中で 中断してもすでに生成されたデータが失われることはありません。

ステップ3 - wake-word-lint

すべての言語にわたってウェイクワードのバリエーション（Hallo Klacksy / Hey Klacksy など）の 整合性を確認します。同義語がウェイクワードを上書きしてしまうことを防ぎます。

音声モード

チャット内のマイクアイコンをクリックすると、音声モードが有効になります。有効化されると：

  • マイクが常時聞き取り、継続的に文字起こしを行う
  • 短い無音が続くと → それまでの文字起こし内容が自動的に送信される

重要：テキストフィールドへの入力を開始すると、音声モードは自動的に終了します。 そうしないと、マイクが入力したテキストを自身の文字起こしで上書きし、早期に送信してしまう ためです。

典型的なトレーニングループ

  1. テンプレートにアンカーを追加： 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. APIを再起動する（起動時にキャッシュが再読み込みされる）
  4. 「ターゲット」タブを開く → 新しいターゲットがステータスgeneratedで表示される
  5. 同義語を確認・追加する → 「確認済みとして保存」 → ステータスreviewed
  6. Klacksyでテストする、例：「Klacksy、住所を見せて」
  7. Klacksyがマッチしない場合 → 「フィードバック」タブ → 不足している同義語を追加する
  8. すべてがreviewedになるまで「メトリクス」タブを監視する
