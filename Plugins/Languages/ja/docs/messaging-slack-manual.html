Slackの設定

前提条件

Klacksを使ってSlack経由でメッセージを送受信するには、Slackワークスペースと、 適切な権限を持つSlackアプリが必要です。Klacksは送信にSlack Web APIを、 受信にEvents APIを使用します。

注：連携には無料のSlackプランで十分です。 Slackアプリはapi.slack.comで作成でき、無料です。

ステップ1 — Slackアプリの作成

  1. api.slack.com/appsを開き、Create New Appをクリックします。
  2. From scratchを選択し、名前を入力します（例：Klacks Bot）。
  3. アプリをインストールするワークスペースを選択します。
  4. OAuth & Permissionsに移動し、以下のBot Token Scopesを追加します。
    • chat:write — チャンネルへのメッセージ送信用
    • im:write — ユーザーへのダイレクトメッセージ送信用
  5. Install to Workspaceをクリックし、権限を承認します。
  6. Bot User OAuth Token（xoxb-で始まります）を控えておきます。
  7. Basic Informationに移動し、Signing Secretを控えておきます。

ステップ2 — Klacks側でSlackを設定する

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 各項目を次のように入力します。
項目説明例

表示名画面上に表示される名称Slack

  1. 保存をクリックします。
  2. プロバイダー一覧のテストボタンで接続を確認します。

ステップ3 — チャットボット（Klacksy）経由でメッセージを送信する

Slackプロバイダーの設定と有効化が完了すると、チャットボットのKlacksyが Slack経由でメッセージを送信できるようになります。従業員名またはチャンネル名を 使って指示してください。 

"Max Musterにメッセージを送信して：予定は明日14時です。"
"Anna Beispielにメッセージを送って：シフトが交代されました。"
"#team-updates に投稿して：来週のシフト表ができました。"

宛先にはチャンネルID（例：C0123456789）または ユーザーID（例：U0123456789）が使用されます — ユーザーIDを 指定した場合はダイレクトメッセージとして送信されます。宛先が指定されない場合は、設定済みの デフォルトチャンネルが使用されます。 送信処理はユーザーには完全に見えない形で行われます — 名前を指定するだけで、残りはKlacksyが処理します。

前提条件： Slackユーザーは対応するKlacksの連絡先と紐付けられている 必要があります（住所 → 連絡先情報の項目）。チャンネルへのメッセージ送信には、 該当チャンネルにボットを招待しておく必要があります（/invite @Klacks Bot）。

ステップ4 — 受信メッセージを受け取る（Events API）

Slackからの受信メッセージをKlacks上に表示するには、SlackアプリのEvents APIを 設定する必要があります。Request URLを登録する前に、Klacks側でプロバイダーを 保存・有効化してください — SlackはURL登録時に即座にチャレンジリクエストで検証を行い、 Klacksが自動的にこれに応答します。

  1. api.slack.com/appsでSlackアプリを開き、 Event Subscriptionsに移動します。
  2. Enable Eventsを有効にし、Request URLとして Klacksに表示されているWebhook URLを入力します。 
    https://{ihre-domain}/api/messaging/webhook/slack
  3. Subscribe to bot eventsの項目で、 message.im（ダイレクトメッセージ）とmessage.channels（チャンネルメッセージ）を購読します。
  4. 変更を保存し、指示が表示されたらワークスペースにアプリを再インストールします。
  5. 受信メッセージはリアルタイムでメッセージング受信箱に表示されるようになります。 その際、Klacksは登録済みの署名シークレットを使って各リクエストの署名を検証します。

トラブルシューティング

問題考えられる原因対処方法
接続テストが失敗する ボットトークンが無効または失効している OAuth & Permissionsでトークンを確認し、アプリを再インストールしてください
channel_not_foundまたはnot_in_channelエラーが出る ボットがチャンネルに追加されていない ボットをチャンネルに招待するか（/invite）、チャンネルIDを確認してください
宛先未指定のメッセージが失敗する デフォルトチャンネルが設定されていない プロバイダー設定でデフォルトチャンネルを入力してください
Request URLの検証が失敗する Klacks側でプロバイダーが保存・有効化されていない、または署名シークレットが誤っている まずKlacks側でプロバイダーを保存・有効化し、署名シークレットを確認してください
受信メッセージが表示されない ボットイベントが購読されていない Event Subscriptionsでmessage.imとmessage.channelsを購読してください
