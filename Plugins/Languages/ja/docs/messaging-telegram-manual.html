Telegram Bot の設定

前提条件

Klacks 経由で Telegram メッセージを送受信するには、 Telegram Bot が必要です。Bot は公式の BotFather を通じて作成でき、無料です。

手順1 — Telegram Bot を作成する

  1. Telegram を開き、@BotFather を検索します。
  2. BotFather とのチャットを開始し、コマンド /newbot を送信します。
  3. Bot の名前を設定します（例: Klacks Benachrichtigungen）。
  4. Bot のユーザー名を設定します（bot で終わる必要があります。例: klacks_notify_bot）。
  5. BotFather がBot Tokenを発行します。このトークンをコピーしてください — 次の手順で必要になります。

注意: Bot Token はパスワードと同様に扱ってください。 公開せず、安全に保管してください。

手順2 — Klacks で Bot を設定する

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 以下のように各項目を入力します。
項目説明例
名前内部で使用される一意の名前telegram-bot
表示名画面上に表示される名前Telegram
プロバイダータイプTelegram を選択しますTelegram
Bot TokenBotFather から取得したトークン123456:ABC-DEF1234ghIkl-zyx57W2v...
Webhook URL受信メッセージ用の URL（手順4を参照）https://example.com/api/messaging/webhook/telegram
有効プロバイダーの有効・無効を切り替えますはい
  1. 保存をクリックします。
  2. プロバイダー一覧のテストボタンから接続をテストします。

手順3 — チャットボット（Klacksy）経由でメッセージを送信する

Telegram Bot の設定と有効化が完了すると、チャットボット Klacksy が メッセージを送信できるようになります。チャット ID を知る必要はありません — 従業員またはクライアントの名前を指定するだけです。 

「マックス・ムスターにメッセージを送って: 予約は明日14時です。」
「アンナ・バイシュピールにメッセージを送信して: シフトが交換されました。」
「ペーター・ミュラーに、月曜日の勤務が休止になることを通知して。」

Klacksy は受信者に登録された Telegram ユーザー名を自動的に検索し、 設定済みの Bot を使用します。送信処理はすべて自動で行われます — あなたは名前だけを扱い、残りは Klacksy が処理します。

前提条件: 受信者には Klacks 上で Telegram ユーザー名が登録されている必要があります （アドレス → 連絡先情報の下）。

手順4 — 受信メッセージを受け取る（Webhook）

Klacks で Telegram の受信メッセージを表示するには、Webhook を設定する必要があります。

  1. Klacks インスタンスが HTTPS 経由で公開アクセス可能であることを確認してください。
  2. プロバイダー設定に以下の Webhook URL を入力します。 
    https://{ihre-domain}/api/messaging/webhook/telegram
  3. プロバイダーが保存され有効化されると、Klacks が Telegram に Webhook を自動的に登録します。
  4. 受信メッセージはリアルタイムでメッセージング受信箱に表示されます。

トラブルシューティング

問題考えられる原因解決方法
接続テストが失敗する Bot Token が無効 BotFather で /mybots を使ってトークンを確認してください
メッセージが配信されない 受信者が Bot を開始していない 受信者は Telegram で Bot を開き、/start を送信する必要があります
受信者が見つからない Telegram ユーザー名が登録されていない アドレス → 連絡先情報の下に Telegram ユーザー名を入力してください
受信メッセージが表示されない Webhook URL にアクセスできない ドメインが HTTPS でアクセス可能であること、URL が正しいことを確認してください
Webhook の登録が失敗する 有効な SSL 証明書がない Telegram は有効な SSL 証明書を要求します（自己署名証明書は不可）
