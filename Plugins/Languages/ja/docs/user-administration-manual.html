ユーザー管理 – マニュアル

ユーザー管理とは？

ここでは、Klacks にログインできる人を管理するログインアカウント （システムユーザー）を管理します。これは従業員管理や住所管理とは異なるものです — ログインアカウントは従業員と紐づけることができますが、必ずしも紐づける必要はありません。

ユーザーの追加

  • ＋ ユーザーを追加で入力ダイアログが開きます。
  • 姓と名（それぞれ2文字以上）を入力すると、自動的にユーザー名の候補が生成されます。
  • メールアドレスは必須で、＠記号を含む必要があります。
  • すべての項目が有効に入力されて初めて保存が可能になります。
  • パスワードは作成時に自動的に生成されます。本人がパスワードを設定できるようにするには、 作成後にその行のパスワードをリセットを使用してください。

権限：スーパーバイザー＆管理者

  • スーパーバイザー – 住所、グループ、契約、不在、シフトの作成・編集・削除、 および勤務表で特定の日やグループを承認したり、その承認を取り消したりする権限を 持ちます。個々の勤務時間の単なる確定には、これらの特別な権限は必要ありません。
  • 管理者 – スーパーバイザーができるすべての操作に加えて、すべての設定 （ユーザー管理自体も含む）へのアクセス、期間の締め処理および再オープン、さらに Identity Provider、レポート、カレンダールールなど特に保護された領域の管理も行えます。 管理者権限には、スーパーバイザー権限が自動的に含まれます。
  • 権限の変更は、ドロップダウンを切り替えた時点で即座に反映され、別途保存操作は 必要ありません。

ユーザーの編集

名前の行をダブルクリックすると編集ダイアログが開きます。そこではユーザー名を 後から変更できます — 新規作成時は候補として表示されるだけであるのとは異なります。

パスワードのリセット

ユーザーの行にあるパスワードをリセットリンクをクリックすると、 登録されているメールアドレス宛にメールが送信され、本人が新しいパスワードを 設定できるようになります。

ユーザーの削除

ゴミ箱ボタンをクリックし、削除ダイアログで確認すると、ログインアカウントが 完全に削除されます。

自分自身のアカウント

現在ログイン中のユーザーも一覧に表示されますが、そこでは編集、権限の変更、 削除を行うことはできません — これらの操作は自分自身の行に対しては 無効化されています。
