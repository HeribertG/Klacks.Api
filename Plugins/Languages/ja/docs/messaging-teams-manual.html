Microsoft Teams の設定

前提条件

Klacks から Microsoft Teams のチャネルへメッセージを送信するには、 Teams ライセンス付きの Microsoft 365 アカウントが必要です。連携は Teams ワークフロー（Power Automate）の受信 Webhook を介して行われます — Azure アプリの登録は不要であり、Bot サービスも不要です。

重要: Teams 連携は送信専用として設計されています。 すべてのメッセージはワークフローに設定された単一のチャネルに投稿されます — 個人への ダイレクトメッセージ（1:1 チャット）は不可能であり、Teams から Klacks への メッセージ受信も行われません。

手順1 — Webhook 付き Teams ワークフローの作成

  1. Microsoft Teams を開き、左側のサイドバー（または アプリ）から Workflows アプリを検索します。
  2. 新しいフローをクリックし、テンプレート 「Post to a channel when a webhook request is received」 （日本語:「Webhook 要求が受信されたときにチャネルに投稿する」）を選択します。 このテンプレートは make.powerautomate.com からも見つけられます。
  3. 求められたらサインインし、メッセージの投稿先となるチームと チャネルを選択します。
  4. フローの作成をクリックします。
  5. 生成されたHTTP URL（ https://prod-XX.westeurope.logic.azure.com/workflows/... で始まります）をコピーします。 この URL は一度しか表示されないため、安全に保管してください。

注意: Webhook URL はパスワードと同様に扱ってください。この URL を知っている人は 誰でもチャネルにメッセージを送信できます。

  1. 設定 → メッセージングプロバイダーに移動します。
  2. 追加をクリックします。
  3. 以下のように各項目を入力します。

  2. プロバイダー一覧のテストボタンから接続をテストします。 注意: このテストでは、設定済みのチャネルに実際に見える テストメッセージ（Klacks connection test）が送信されます。

手順3 — チャットボット（Klacksy）経由でメッセージを送信する

Teams プロバイダーの設定と有効化が完了すると、チャットボット Klacksy から Teams チャネルへメッセージを投稿できるようになります。 

"Teamsに投稿して：来週のシフト表ができました。"
"Teamsメッセージを送信して：チームミーティングは15時に始まります。"

メッセージは Adaptive Card としてワークフローに設定されたチャネルに投稿されます。 指定された宛先名は無視され、すべてのメッセージは同じチャネルに送信されます。 複数のチャネルを使い分けたい場合は、複数のワークフローと、それに対応する複数の Teams プロバイダーを Klacks 上に作成してください。

受信メッセージについて

ワークフロー Webhook は Teams 向けの純粋な送信チャネルであり、Teams 側での返信や メッセージが Klacks に転送されることはありません。そのため、 このプロバイダーについてはメッセージング受信箱に受信メッセージは表示されません。

トラブルシューティング

問題考えられる原因解決方法
接続テストが失敗する Webhook URL が誤っている、またはコピーが不完全 ワークフローから完全な HTTP URL（すべてのパラメーターを含む）を再度コピーしてください
送信時にエラー 401/403 が発生する ワークフロー URL が更新された、またはワークフローが再作成された ワークフローから最新の URL をコピーし、Klacks 側で更新してください
メッセージがチャネルに表示されない ワークフローが無効化されている、または実行に失敗している Workflows アプリまたは make.powerautomate.com でワークフローのステータスと実行履歴を確認してください
メッセージが違うチャネルに表示される ワークフローに別のチャネルが設定されている ワークフローを編集し、投稿アクションのチームとチャネルを修正してください
Klacks に受信メッセージが表示されない エラーではありません — ワークフロー方式は受信をサポートしていません 双方向のやり取りが必要な場合は、別のプロバイダー（例: Telegram や Slack）を使用してください
