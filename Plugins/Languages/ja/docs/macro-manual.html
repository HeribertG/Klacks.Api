マクロスクリプティング マニュアル

はじめに

マクロエディターを使用して、業務、雇用形態などの計算基盤として使用されるスクリプトを 作成することができます。

使用例：

  • 雇用率に基づいた休暇や軍務の時間の正確な計算
  • 夜間勤務、週末、祝日の割増賃金の計算
  • 新しい要件への柔軟な対応

注意：スクリプトインタープリターはファイルシステムやネットワークにアクセスできない 安全なサンドボックス環境で動作します。悪意のあるコードを実行することはできません。

機能とカテゴリー

マクロには、名前とスクリプト内容のほかに、エディターのドロップダウンで設定される2つのプロパティ、 カテゴリーと機能があります。どちらも純粋なメタデータであり、 スクリプトの外側にあってその計算内容を変更するものではなく、Klacksが適切なマクロを自動的に 見つけて割り当てる方法を制御します。

カテゴリー

カテゴリーはマクロを特定の業務領域に分類します：

カテゴリー用途
未割り当て特定の適用領域なし（新規マクロのデフォルト）
勤務通常勤務の割増賃金計算（夜間・週末・祝日割増）
休暇休暇の時間計算
病気病気の時間計算
事故事故の時間計算
研修（有給）有給の研修・トレーニング時間
研修（無給）無給の研修・トレーニング時間

カテゴリー「勤務」には特別な役割があります：新しく作成された勤務には、このカテゴリーの標準マクロが 自動的に割り当てられます（下記「機能」を参照）。既存の勤務が後から変更されることはありません。

機能：カスタム、標準、標準（加算）

機能はカテゴリー内でのマクロの役割を分類します：

機能意味
カスタム特別な役割を持たない自由なマクロ。カテゴリーごとに何個でも作成可能。
標準このカテゴリーの標準マクロ - 新しい勤務に自動的に割り当てられます。1カテゴリーにつき最大1個のマクロのみがこの機能を持てます。
標準（加算）加算的な割増ロジックを持つ代替の標準マクロ（下記参照）。こちらも1カテゴリーにつき最大1個、「標準」マクロとは別に設定可能です。

重要：機能そのものは何も計算しません - あくまでラベルです。割増賃金が 「最高額優先」（適用可能な最高の率のみが有効）で計算されるか、加算方式（該当するすべての率が 合算される）で計算されるかは、スクリプト自体が決定します。付属するカテゴリー「勤務」の 2つのマクロは、同じ基本構造の違いを示しています：

  • 「AllShift」（機能：標準）- 各時間セグメントについて最高の適用可能な 割増（夜間/WE1/WE2/WE3/祝日）を求め、これのみを使用します。
  • 「AllShiftAdditive」（機能：標準（加算））- 夜間、週末、祝日の割増をそれぞれ 独立して計算し、合算します。

勤務を新規作成する際にどちらが自動的に割り当てられるかは、インストール全体の設定 （「加算」または「最高額優先」）によって制御されます。その後は勤務ごとにいつでも手動で マクロを切り替えることができるため、混在運用も可能です。

一意性：同じカテゴリーの2つ目のマクロを「標準」または「標準（加算）」として保存しようとすると、 エディターは保存をブロックし、既に割り当てられているマクロの名前を表示します。まずそのマクロの 機能を「カスタム」に変更してください。

「AllShift」/「AllShiftAdditive」への手動変更は推奨されません。 この2つのマクロは、国別・業種別の調整が自動的に反映される仕組みです。変更しない限り、 Klacksはお使いの国・業種に合ったルールと自動的に同期させます。どちらかを手動で編集すると、 その時点でカスタム扱いとなり、以後この機能のマクロに対する国・業種の自動アップデートは サイレントには適用されなくなり、手動で差分を解決するまでコンフリクトとして失敗します。 独自の割増ロジックが必要な場合は、代わりに機能「カスタム」の新しいマクロを作成し、対象の勤務に 個別に割り当ててください。

関数とプロシージャ

重要： 関数（FUNCTION）とプロシージャ（SUB）は、最初の呼び出しより前に定義する必要があります。 インタープリターはコードを上から下へ読み込みます。関数またはプロシージャは、その定義が処理された後にのみ使用できます。

SUB（戻り値なしのプロシージャ）

SUB berechne(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION（戻り値ありの関数）

FUNCTION verdoppeln(x)
    verdoppeln = x * 2
ENDFUNCTION

DIM ergebnis
ergebnis = verdoppeln(21)
OUTPUT 1, ergebnis

戻り値（OUTPUT）

OUTPUT typ, wert

typとwertはカンマで区切られた2つの式で、どちらも省略可能です （省略時のデフォルトはそれぞれ0と""）。マクロには任意の数の OUTPUT行を含めることができ、それぞれが独自の戻り値を生成します。Klacksは 以下のタイプのみを評価します：

タイプ意味
1主結果（時間数または合計金額） - 値が0の場合も反映されます
10夜間割増
11週末日1の割増（例：土曜日）
12週末日2の割増（例：日曜日）
13週末日3の割増（3番目の設定可能な週末日）
14祝日割増

値が0の割増行（タイプ10〜14）は無視されます - つまりマクロはすべての割増タイプに ついて行を出力する必要はなく、実際に発生する割増についてのみ出力すれば十分です。数値として 解釈できない値はスキップされます。

保存時、マクロは必ずコンパイルされ、中立的なテスト値を使用して一度試験的に実行されます。 構文エラーおよび実行時エラー（例：括弧の不一致や不完全な式）は、機能しないマクロへと サイレントに陥ることなく、確実に表示されます。

例：割増賃金計算（「AllShift」）

付属のカテゴリー「勤務」の標準マクロです。深夜をまたぐシフトを正しく処理（セグメント分割）した うえで、夜間、祝日、および3つの設定可能な週末日の割増賃金を計算し、各セグメントに対して 最高の適用可能な率を適用します（highest-wins）。 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

説明

  • セグメント分割： 深夜をまたぐシフト（例：22:00-06:00）の場合、シフトは2つのセグメント（深夜0時まで／深夜0時から）に分割され、それぞれに固有の曜日・祝日フラグが設定されます
  • SegBonusForType： 夜間、祝日、週末の割増を考慮して、セグメントと特定の割増タイプ（10-14）に対する割増額を計算します
  • WE1/WE2/WE3（土日の代わりに）： weekendday1-3により週末日を設定可能にします（すべての国で土日が週末とは限らないため）
  • セグメントごとの最高割増： NRate/DRateは、それぞれ夜間時間・日中時間に適用可能な最高の率を求めます - highest-winsであり、積み上げ（スタッキング）はされません
  • HolidayNextDay： 翌日が祝日かどうかを考慮します（深夜をまたぐ夜間シフトにとって重要）
  • 複数のOUTPUT行： 1行目は合計額を返し、10-14行目は個々の割増額を返します（「戻り値」の章を参照）

加算版（「AllShiftAdditive」）

同じカテゴリーの標準（加算）マクロは、IMPORT行と全体構造が「AllShift」と同一です - 異なるのはSegBonusForTypeのみです：最高の率を求める代わりに、各割増タイプが 該当するかどうかを独立して計算し、該当するすべての金額を最後に合算します （highest-winsはもう適用されません）： 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

例えば夜間シフトがさらに祝日と重なった場合、「AllShift」では両方のうち高い方の率のみが 適用されますが、「AllShiftAdditive」では夜間割増と祝日割増の両方が加算されます。 スクリプトの残りの部分（セグメント分割、合算、OUTPUT行）は、上記の「AllShift」と 同一です。
