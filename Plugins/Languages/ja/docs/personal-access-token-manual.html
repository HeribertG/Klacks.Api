パーソナルアクセストークン マニュアル

パーソナルアクセストークンとは？

パーソナルアクセストークン（PAT）は、外部ツールやサービスが Klacks に安全にアクセスするための、 ユーザー名とパスワードを使わない長期有効な API キーです。

主な利用シーン：

  • MCP（Model Context Protocol） — Claude Desktop などの AI アシスタントが Klacksy スキルに直接アクセスできるようにします
  • MCP 経由で Klacks を利用する AI エージェントおよびアシスタント

セキュリティ設計

Klacks はトークンの平文を保存しません。作成後はデータベースに SHA-256 ハッシュのみが保存されます。トークン自体は作成直後に 一度だけ表示され、その後は二度と取得できません。

注：作成直後に必ずトークンをメモまたはコピーしてください。紛失した場合は、 新しいトークンを作成し、古いトークンを無効化する必要があります。

トークンの作成

手順

  • 設定 → パーソナルアクセストークンに移動します
  • 新しいトークンを作成をクリックします
  • わかりやすい名前を付けます（例：Claude Desktop や AI エージェント（計画））
  • 希望する有効期限を選択します（1〜730日、既定値：365日）
  • 作成をクリックします
  • 表示されたトークンを直ちにコピーしてください — 一度しか表示されません

トークン形式

klacks_pat_<ランダムな文字列>

各トークンは接頭辞 klacks_pat_ に続けて、暗号学的に安全な ランダム文字列で構成されます。

有効期限

期間推奨用途
1〜30日短期間のテストおよび開発
90〜180日定期的にローテーションする AI エージェント
365日（既定値）恒常的な連携（例：Claude Desktop）
730日長期的なシステム連携

アクセスモード

作成時に、外部エージェントがトークンで何をしてよいかを指定します。

  • 読み取り専用 （既定）— エージェントは読み取り用のツールだけを表示・使用できます。データを変更しようとする操作はすべて拒否されます。
  • 読み取りと書き込み — エージェントは、変更ごとに人が承認することなく、データを変更することもできます。変更を任せられるエージェントにのみ、このモードを選択してください。

モードはトークン一覧に表示され、後から変更することはできません。必要に応じて新しいトークンを作成してください。既存のトークンと、OAuth サインイン（MCP コネクタなど）で発行されたトークンのモードは「読み取りと書き込み」です。

トークンの使用

HTTP ヘッダーでの Bearer トークン

トークンは、/mcp エンドポイントへの各 MCP リクエストの Authorization ヘッダーに Bearer トークンとして渡します。

Authorization: Bearer klacks_pat_...

Claude Desktop での MCP 設定

MCP エンドポイント（/mcp）を使うと、Claude Desktop などの AI アシスタントが すべての Klacksy スキルに直接アクセスできます — 従業員データの照会、シフトの計画、 グループの管理など、さまざまな操作が可能です。

Claude Desktop アプリでの設定（claude_desktop_config.json）：

{
  "mcpServers": {
    "klacks": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://<your-klacks-domain>/mcp",
        "--header",
        "Authorization:${AUTH_HEADER}"
      ],
      "env": {
        "AUTH_HEADER": "Bearer klacks_pat_..."
      }
    }
  }
}

<your-klacks-domain> をお使いの Klacks インストールのアドレスに、 klacks_pat_... を作成したトークンに置き換えてください。

注意：トークンは AI エージェントの MCP アクセス（エンドポイント /mcp）でのみ使用できます。Klacks の REST API（例：/api/clients）では受け付けられず、ログイン用トークンが必要です。

管理とセキュリティ

トークン一覧

設定 → パーソナルアクセストークンでは、名前、作成日、有効期限、 最終使用日時とともに、すべてのトークンを確認できます。 このビューにトークンの平文が表示されることはありません。

トークンの無効化

トークンはいつでも無効化できます。無効化後は、そのトークンによるすべてのリクエストが 即座に拒否されます。次のような場合は直ちにトークンを無効化してください。

  • トークンが誤って漏洩した場合
  • デバイスやサービスを使用しなくなった場合
  • 不審な操作に気づいた場合

有効期限切れ

有効期限が切れたトークンは自動的に拒否されます。Klacks は一覧画面で、今後30日以内に 期限切れとなるトークンを表示し、事前に新しいトークンを作成できるようにします。

セキュリティに関する推奨事項

  • サービスやツールごとに個別のトークンを使用してください
  • トークンを一意に識別できるよう、わかりやすい名前を付けてください
  • トークンをバージョン管理システムに平文で保存しないでください
  • トークンを定期的にローテーションしてください
  • 不正使用の疑いがある場合は直ちにトークンを無効化してください

各トークンはご自身のユーザーアカウントに紐づいています。MCP 経由では、アカウントの権限がそのまま適用されますが、上限はスーパーバイザーレベルです。アカウントが管理者であっても、トークンに管理者権限が付与されることはありません。さらに、アクセスモードによってエージェントができることが制限されます。「読み取り専用」では読み取り機能のみを使用し、「読み取りと書き込み」では追加の確認なしに変更を実行します。パスワードと同様の注意を払って取り扱ってください。
