Menyiapkan Perpesanan Signal

Prasyarat

Untuk mengirim pesan Signal melalui Klacks, Anda memerlukan instans yang di-hosting sendiri dari signal-cli-rest-api. Ini adalah proyek open-source yang membuat Signal dapat diakses melalui antarmuka REST.

  • Docker harus terinstal di server
  • Sebuah nomor telepon yang akan didaftarkan di Signal (nomor khusus disarankan)
  • Image Docker: bbernhard/signal-cli-rest-api

Penting: Integrasi Signal dirancang hanya untuk pengiriman. Pesan Signal masuk tidak diterima di Klacks.

Langkah 1 — Menyiapkan signal-cli-rest-api

  1. Mulai kontainer dengan Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Kaitkan nomor Signal Anda melalui prosedur tautan QR: Buka di browser 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    dan pindai kode QR yang ditampilkan dengan aplikasi Signal di ponsel tempat nomor tersebut terdaftar (Pengaturan → Perangkat tertaut → Tautkan perangkat). Kontainer akan tertaut sebagai perangkat kedua.
  3. Sebagai alternatif, Anda dapat mendaftarkan nomor secara mandiri melalui API — detailnya dapat ditemukan dalam dokumentasi proyek.
  4. Uji API dengan pemeriksaan kesehatan: 
    curl http://localhost:8080/v1/about

Catatan: Detail lebih lanjut tentang konfigurasi dapat ditemukan dalam dokumentasi signal-cli-rest-api.

Langkah 2 — Mengonfigurasi Signal di Klacks

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.
  3. Isi bidang-bidang sebagai berikut:
BidangDeskripsiContoh
NamaNama unik internalsignal-main
Nama tampilanDitampilkan di antarmukaSignal
Tipe penyediaPilih SignalSignal
Nomor SignalNomor telepon terdaftar dalam format internasional+41791234567
URL API Signal-CLIURL kontainer signal-cli-rest-api. Jika kontainer berjalan di server yang sama dengan Klacks, di sini boleh diisi http://localhost:8080.http://localhost:8080
DiaktifkanMengaktifkan/menonaktifkan penyediaYa
  1. Klik Simpan.
  2. Uji koneksi melalui tombol Uji di daftar penyedia. Uji ini memeriksa apakah nomor yang diberikan terdaftar di kontainer.

Catatan: Klacks mengirim pesan melalui endpoint POST /v2/send dari kontainer.

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah penyedia Signal dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan. Anda tidak perlu mengetahui nomor telepon — cukup gunakan nama karyawan atau klien: 

"Kirim pesan ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel pesan Signal: Shift telah ditukar."
"Beri tahu Peter Müller bahwa dinasnya pada hari Senin dibatalkan."

Klacksy secara otomatis mencari nomor ponsel penerima yang tersimpan dan menggunakan penyedia Signal yang dikonfigurasi. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Prasyarat: Nomor ponsel harus tersimpan di Klacks untuk penerima (di bawah Alamat → Data kontak), dalam format internasional (misalnya: +41791234567). Bahkan untuk pesan broadcast, pengiriman Signal menggunakan nomor ponsel yang tersimpan.

Pesan masuk

Integrasi Signal tidak mendukung penerimaan — balasan atas pesan yang dikirim tidak diteruskan ke Klacks. Oleh karena itu, kotak masuk perpesanan tidak menampilkan pesan masuk untuk penyedia ini.

Pemecahan masalah

MasalahKemungkinan penyebabSolusi
Uji koneksi gagal Kontainer tidak dapat dijangkau Periksa apakah kontainer Docker berjalan (docker ps) dan apakah URL API benar
Uji koneksi gagal Nomor tidak terdaftar di kontainer Ulangi proses penautan melalui prosedur tautan QR
Pesan tidak terkirim Penerima tidak menggunakan Signal atau nomor salah Pastikan penerima telah menginstal Signal dan nomor tersimpan dalam format +{kode negara}{nomor}
Tautan hilang Perangkat dilepas tautannya di aplikasi Signal Tautkan kembali kontainer melalui tautan QR
Kontainer tidak dapat dimulai Port 8080 sudah digunakan Gunakan port lain: -p 9090:8080 dan sesuaikan URL API di Klacks
