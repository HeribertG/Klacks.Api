Menyiapkan Bot Viber

Prasyarat

Untuk mengirim dan menerima pesan melalui Viber, Anda memerlukan bot Viber, yang Anda buat melalui Viber Partner Portal. Viber sangat populer di Eropa Timur dan Timur Tengah.

Catatan: Viber telah mengomersialkan penggunaan bot — tergantung negara dan volume pesan, model berbayar mungkin berlaku. Periksa syarat dan ketentuan terkini di partners.viber.com.

Langkah 1 — Membuat bot Viber

  1. Daftar di partners.viber.com.
  2. Buat bot baru di Partner Portal.
  3. Catat Auth Token dari dashboard bot.
  4. Tetapkan nama pengirim (misalnya: Klacks Bot).

Langkah 2 — Mengonfigurasi Viber di Klacks

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.
  3. Isi bidang-bidang sebagai berikut:

  1. Klik Simpan. Klacks akan mendaftarkan webhook secara otomatis ke Viber (set_webhook).
  2. Uji koneksi melalui tombol Uji di daftar penyedia.

Penting: URL webhook yang ditampilkan harus dapat diakses secara publik melalui HTTPS — jika tidak, registrasi webhook akan gagal saat disimpan.

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah penyedia Viber dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan. Anda tidak perlu mengetahui Viber User ID — cukup gunakan nama karyawan atau klien: 

"Kirim pesan ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel pesan: Shift telah ditukar."
"Beri tahu Peter Müller bahwa dinasnya pada hari Senin dibatalkan."

Klacksy secara otomatis mencari Viber User ID penerima yang tersimpan dan menggunakan penyedia Viber yang dikonfigurasi. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Penting: Bot Viber hanya dapat mengirim pesan kepada pengguna yang telah berlangganan ke bot (memulai chat 1:1 dengan bot). Penerima harus mengirim pesan ke bot terlebih dahulu. Viber User ID-nya kemudian diketahui melalui pesan masuk (terlihat di kotak masuk perpesanan) dan disimpan pada penerima di bawah Alamat → Data kontak.

Langkah 4 — Menerima pesan masuk

Pesan Viber masuk diterima secara otomatis melalui webhook yang terdaftar saat penyimpanan — tidak diperlukan konfigurasi tambahan.

  1. Pengguna mencari bot di Viber dan mengirimkan pesan.
  2. Pesan muncul secara real-time di Kotak masuk perpesanan.
  3. Masukkan Viber User ID pengirim ke data kontak karyawan, agar Klacksy dapat langsung mengirim pesan kepadanya di masa depan.
