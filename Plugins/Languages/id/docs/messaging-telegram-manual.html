Menyiapkan Bot Telegram

Prasyarat

Untuk mengirim dan menerima pesan Telegram melalui Klacks, Anda memerlukan bot Telegram. Bot dibuat melalui BotFather resmi dan gratis.

Langkah 1 — Membuat bot Telegram

  1. Buka Telegram dan cari @BotFather.
  2. Mulai chat dengan BotFather dan kirim perintah /newbot.
  3. Berikan nama untuk bot Anda (misalnya: Klacks Benachrichtigungen).
  4. Berikan nama pengguna untuk bot (harus diakhiri dengan bot, misalnya: klacks_notify_bot).
  5. BotFather akan memberikan Anda Bot Token. Salin token ini — akan diperlukan pada langkah berikutnya.

Catatan: Perlakukan Bot Token seperti kata sandi. Jangan bagikan secara publik dan simpan dengan aman.

Langkah 2 — Mengonfigurasi bot di Klacks

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.
  3. Isi bidang-bidang sebagai berikut:
BidangDeskripsiContoh
NamaNama unik internaltelegram-bot
Nama tampilanDitampilkan di antarmukaTelegram
Tipe penyediaPilih TelegramTelegram
Bot TokenToken dari BotFather123456:ABC-DEF1234ghIkl-zyx57W2v...
URL webhookURL untuk pesan masuk (lihat langkah 4)https://example.com/api/messaging/webhook/telegram
DiaktifkanMengaktifkan/menonaktifkan penyediaYa
  1. Klik Simpan.
  2. Uji koneksi melalui tombol Uji di daftar penyedia.

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah bot Telegram dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan. Anda tidak perlu mengetahui chat ID — cukup gunakan nama karyawan atau klien: 

"Kirim pesan ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel pesan: Shift telah ditukar."
"Beri tahu Peter Müller bahwa dinasnya pada hari Senin dibatalkan."

Klacksy secara otomatis mencari nama pengguna Telegram penerima yang tersimpan dan menggunakan bot yang dikonfigurasi. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Prasyarat: Nama pengguna Telegram harus tersimpan di Klacks untuk penerima (di bawah Alamat → Data kontak).

Langkah 4 — Menerima pesan masuk (webhook)

Untuk menampilkan pesan Telegram masuk di Klacks, sebuah webhook harus dikonfigurasi.

  1. Pastikan instans Klacks Anda dapat diakses secara publik melalui HTTPS.
  2. Masukkan URL webhook berikut di pengaturan penyedia: 
    https://{domain-anda}/api/messaging/webhook/telegram
  3. Klacks mendaftarkan webhook secara otomatis ke Telegram, segera setelah penyedia disimpan dan diaktifkan.
  4. Pesan masuk sekarang akan muncul secara real-time di Kotak masuk perpesanan.

Pemecahan masalah

MasalahKemungkinan penyebabSolusi
Uji koneksi gagal Bot Token tidak valid Periksa token di BotFather dengan /mybots
Pesan tidak terkirim Penerima belum memulai bot Penerima harus membuka bot di Telegram dan mengirim /start
Penerima tidak ditemukan Nama pengguna Telegram belum tersimpan Masukkan nama pengguna Telegram di bawah Alamat → Data kontak
Pesan masuk tidak ada URL webhook tidak dapat dijangkau Periksa apakah domain Anda dapat diakses melalui HTTPS dan URL-nya benar
Registrasi webhook gagal Tidak ada sertifikat SSL yang valid Telegram memerlukan sertifikat SSL yang valid (bukan self-signed)
