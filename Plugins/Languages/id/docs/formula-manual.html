Panduan Bidang Formula

Sintaks dasar

Setiap bidang formula mengeluarkan hasilnya dengan perintah output:

output 1, <ekspresi>

Parameter pertama 1 adalah tipe pesan dan harus selalu 1. Parameter kedua adalah nilai yang akan dikeluarkan.

Contoh sederhana:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " entri"

Variabel yang tersedia

Variabel yang tersedia terdaftar di tab Variabel dan dapat diisi dengan nilai uji di sana. Tergantung pada jenis laporan, variabel yang tersedia berbeda-beda:

Fungsi bawaan

Konversi tipe

FungsiDeskripsi
CStr(x)Mengubah angka menjadi teks
CInt(x)Mengubah menjadi bilangan bulat
CDbl(x)Mengubah menjadi bilangan desimal

Sgn(x)Tanda (-1, 0, 1)

Logika kondisional

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "banyak entri"
ELSEIF totalRows > 0 THEN
    output 1, "sedikit entri"
ELSE
    output 1, "tidak ada entri"
ENDIF

IF satu baris

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (bentuk singkat)

output 1, IIF(totalRows > 0, "OK", "Kosong")

Variabel dan perulangan

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Contoh praktis

Jumlah entri dengan teks

output 1, CStr(totalRows) & " entri"

Nilai yang dibulatkan (1 desimal)

output 1, CStr(Round(totalValue, 1))

Jam sebagai j:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "j " & CStr(m) & "mnt"

Keluaran kondisional

IF totalRows = 0 THEN
    output 1, "Tidak ada ketidakhadiran"
ELSE
    output 1, CStr(totalRows) & " ketidakhadiran (Total: " & CStr(totalValue) & ")"
ENDIF

Menghitung rata-rata

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " j/hari"
ELSE
    output 1, "-"
ENDIF
