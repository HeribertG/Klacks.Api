Menyiapkan Slack

Prasyarat

Untuk mengirim dan menerima pesan melalui Slack dengan Klacks, Anda memerlukan workspace Slack dan sebuah aplikasi Slack dengan izin yang sesuai. Klacks menggunakan Slack Web API untuk pengiriman dan Events API untuk penerimaan.

Catatan: Paket Slack gratis sudah cukup untuk integrasi ini. Aplikasi Slack dibuat di api.slack.com dan gratis.

Langkah 1 — Membuat aplikasi Slack

  1. Buka api.slack.com/apps dan klik Create New App.
  2. Pilih From scratch dan berikan nama (misalnya: Klacks Bot).
  3. Pilih workspace tempat aplikasi akan diinstal.
  4. Navigasikan ke OAuth & Permissions dan tambahkan Bot Token Scopes berikut:
    • chat:write — untuk mengirim pesan ke kanal
    • im:write — untuk mengirim pesan langsung ke pengguna
  5. Klik Install to Workspace dan konfirmasikan izinnya.
  6. Catat Bot User OAuth Token (dimulai dengan xoxb-).
  7. Navigasikan ke Basic Information dan catat Signing Secret.

Langkah 2 — Mengonfigurasi Slack di Klacks

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.
  3. Isi bidang-bidang sebagai berikut:

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah penyedia Slack dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan melalui Slack. Gunakan nama karyawan atau nama kanal: 

"Kirim pesan ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel pesan: Shift telah ditukar."
"Posting di #team-updates: Jadwal dinas untuk minggu depan sudah selesai."

Sebagai penerima digunakan Channel ID (misalnya: C0123456789) atau User ID (misalnya: U0123456789) — untuk User ID, sebuah pesan langsung akan dikirim. Jika tidak ada penerima yang ditentukan, kanal standar yang dikonfigurasi akan digunakan. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Prasyarat: Pengguna Slack harus dikaitkan dengan kontak Klacks yang sesuai (di bawah Alamat → Data kontak). Untuk pesan kanal, bot harus diundang ke kanal terkait (/invite @Klacks Bot).

Langkah 4 — Menerima pesan masuk (Events API)

Untuk menampilkan pesan Slack masuk di Klacks, Events API dari aplikasi Slack harus dikonfigurasi. Simpan dan aktifkan penyedia di Klacks sebelum Anda memasukkan Request URL — Slack langsung memeriksa URL tersebut dengan permintaan challenge, yang dijawab secara otomatis oleh Klacks.

  1. Buka aplikasi Slack Anda di api.slack.com/apps dan navigasikan ke Event Subscriptions.
  2. Aktifkan Enable Events dan masukkan sebagai Request URL URL webhook yang ditampilkan di Klacks: 
    https://{domain-anda}/api/messaging/webhook/slack
  3. Berlangganan di bawah Subscribe to bot events untuk event message.im (pesan langsung) dan message.channels (pesan kanal).
  4. Simpan perubahan dan instal ulang aplikasi di workspace jika diminta.
  5. Pesan masuk sekarang akan muncul secara real-time di Kotak masuk perpesanan. Klacks memeriksa tanda tangan setiap permintaan dengan Signing Secret yang tersimpan.
