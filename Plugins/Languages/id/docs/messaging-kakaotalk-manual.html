Menyiapkan Perpesanan KakaoTalk

Prasyarat

Untuk mengirim pesan melalui KakaoTalk, Anda memerlukan aplikasi di developers.kakao.com (Kakao Developers). KakaoTalk adalah messenger dominan di Korea Selatan. Integrasi Klacks menggunakan Kakao Developer API ("Kirim pesan ke teman").

Batasan penting Kakao Developer API:

  • Integrasi ini dirancang hanya untuk pengiriman — tidak untuk menerima.
  • Access Token berumur pendek (sekitar 6 jam) dan harus diperbarui di luar Klacks dan dimasukkan ulang.
  • Pesan hanya dapat dikirim ke pengguna yang terhubung sebagai "teman" Kakao dari aplikasi dan telah menyetujui pengiriman pesan.
  • Untuk pesan bisnis produktif (AlimTalk), diperlukan kanal bisnis melalui agensi resmi di Korea — hal ini tidak tercakup oleh integrasi ini, yang menggunakan Developer API.

Langkah 1 — Menyiapkan aplikasi Kakao Developers

  1. Buat aplikasi di developers.kakao.com.
  2. Aktifkan Kakao Login untuk aplikasi.
  3. Aktifkan scope talk_message dan friends.
  4. Dapatkan Access Token melalui alur OAuth Kakao Login (pengguna atas nama siapa pesan dikirim harus menyetujui scope tersebut).

Catatan: Perlakukan Access Token seperti kata sandi. Jangan bagikan secara publik dan simpan dengan aman.

Langkah 2 — Mengonfigurasi KakaoTalk di Klacks

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.
  3. Isi bidang-bidang sebagai berikut:
BidangDeskripsiContoh
NamaNama unik internalkakaotalk-main
Nama tampilanDitampilkan di antarmukaKakaoTalk
Tipe penyediaPilih KakaoTalkKakaoTalk
Access TokenToken yang diperoleh melalui alur OAuthkakao-access-token...
DiaktifkanMengaktifkan/menonaktifkan penyediaYa
  1. Klik Simpan.
  2. Uji koneksi melalui tombol Uji di daftar penyedia.

Penting: Access Token kedaluwarsa setelah sekitar 6 jam. Klacks tidak memperbaruinya secara otomatis — Anda harus memperbaruinya secara eksternal (alur refresh token dari Kakao) dan memasukkannya ulang ke Klacks.

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah penyedia KakaoTalk dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan. Anda tidak perlu mengetahui ID apa pun — cukup gunakan nama karyawan atau klien: 

"Kirim pesan ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel pesan: Shift telah ditukar."
"Beri tahu Peter Müller bahwa dinasnya pada hari Senin dibatalkan."

Klacksy secara otomatis mencari identitas penerima yang tersimpan dan menggunakan penyedia KakaoTalk yang dikonfigurasi. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Prasyarat: Friend UUID dari Kakao Friends API harus tersimpan di Klacks untuk penerima (di bawah Alamat → Data kontak). Penerima harus terhubung sebagai "teman" Kakao dengan aplikasi — pengguna lain tidak dapat menerima pesan.

Pesan masuk

Integrasi KakaoTalk tidak mendukung penerimaan — balasan atas pesan yang dikirim tidak diteruskan ke Klacks. Oleh karena itu, kotak masuk perpesanan tidak menampilkan pesan masuk untuk penyedia ini.
