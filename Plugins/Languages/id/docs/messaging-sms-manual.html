Menyiapkan Penyedia SMS

Prasyarat

Untuk mengirim pesan SMS melalui Klacks, Anda memerlukan akun di Twilio atau gateway SMS yang kompatibel dengan Twilio. Klacks menggunakan Twilio REST API (endpoint Messages dengan autentikasi Basic).

Penting: Integrasi SMS dirancang hanya untuk pengiriman. SMS masuk tidak diterima di Klacks.

Langkah 1 — Menyiapkan akun Twilio

  1. Daftar di twilio.com dan verifikasi nomor telepon dan alamat email Anda.
  2. Buka Twilio Console. Di dashboard, di bawah Account Info, Anda menemukan dua kredensial yang diperlukan:
    • Account SID — dimulai dengan AC
    • Auth Token — klik "Tampilkan"
  3. Beli nomor pengirim di bawah Phone Numbers → Buy a number (yang mendukung SMS). Nomor ini akan muncul sebagai pengirim pada SMS keluar.
  4. Akun uji coba: Dengan akun trial gratis, SMS hanya dapat dikirim ke nomor yang sebelumnya sudah diverifikasi dan berisi catatan trial.

Catatan: Perlakukan Auth Token seperti kata sandi. Jangan bagikan secara publik dan simpan dengan aman.

Langkah 2 — Mengonfigurasi penyedia SMS di Klacks

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.
  3. Isi bidang-bidang sebagai berikut:

  2. Uji koneksi melalui tombol Uji di daftar penyedia.

Catatan tentang URL Gateway: Biarkan bidang ini kosong jika Anda menggunakan Twilio — Klacks kemudian secara otomatis menggunakan https://api.twilio.com. Isi URL hanya jika Anda menggunakan gateway alternatif dengan API yang kompatibel dengan Twilio.

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah penyedia SMS dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan. Anda tidak perlu mengetahui nomor telepon — cukup gunakan nama karyawan atau klien: 

"Kirim SMS ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel SMS: Shift telah ditukar."
"Beri tahu Peter Müller lewat SMS bahwa dinasnya pada hari Senin dibatalkan."

Klacksy secara otomatis mencari nomor ponsel penerima yang tersimpan dan menggunakan penyedia SMS yang dikonfigurasi. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Prasyarat: Nomor ponsel harus tersimpan di Klacks untuk penerima (di bawah Alamat → Data kontak), dalam format internasional (misalnya: +41791234567).

Pesan masuk

Integrasi SMS tidak mendukung penerimaan — balasan atas SMS yang dikirim tidak diteruskan ke Klacks. Oleh karena itu, kotak masuk perpesanan tidak menampilkan pesan masuk untuk penyedia ini.
