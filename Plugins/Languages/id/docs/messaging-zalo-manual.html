Menyiapkan Perpesanan Zalo

Prasyarat

Untuk mengirim pesan melalui Zalo, Anda memerlukan Zalo Official Account (OA) di oa.zalo.me serta aplikasi di developers.zalo.me. Zalo adalah messenger terkemuka di Vietnam.

Penting: Integrasi Zalo dirancang hanya untuk pengiriman. Selain itu, batasan platform Zalo berlaku:

  • Access Token kedaluwarsa setelah sekitar 25 jam dan harus diperbarui di luar Klacks dan dimasukkan ulang.
  • Pesan hanya dapat dikirim ke pengguna yang sebelumnya telah berinteraksi dengan Official Account (jendela interaksi).

Langkah 1 — Menyiapkan Zalo Official Account dan aplikasi

  1. Buat Official Account di oa.zalo.me.
  2. Buat aplikasi di developers.zalo.me.
  3. Kaitkan Official Account dengan aplikasi tersebut.
  4. Dapatkan Access Token melalui alur OAuth dari konsol Zalo Developer.

Catatan: Perlakukan Access Token seperti kata sandi. Jangan bagikan secara publik dan simpan dengan aman.

Langkah 2 — Mengonfigurasi Zalo di Klacks

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.
  3. Isi bidang-bidang sebagai berikut:
BidangDeskripsiContoh
NamaNama unik internalzalo-oa
Nama tampilanDitampilkan di antarmukaZalo
Tipe penyediaPilih ZaloZalo

DiaktifkanMengaktifkan/menonaktifkan penyediaYa
  1. Klik Simpan.
  2. Uji koneksi melalui tombol Uji di daftar penyedia.

Penting: Access Token kedaluwarsa setelah sekitar 25 jam. Klacks tidak memperbaruinya secara otomatis — Anda harus memperbaruinya secara eksternal melalui alur refresh token dari Zalo dan memasukkannya ulang ke Klacks. Perhatikan: refresh token bersifat sekali pakai — setiap pembaruan menghasilkan pasangan token baru.

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah penyedia Zalo dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan. Anda tidak perlu mengetahui Zalo User ID — cukup gunakan nama karyawan atau klien: 

"Kirim pesan ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel pesan: Shift telah ditukar."
"Beri tahu Peter Müller bahwa dinasnya pada hari Senin dibatalkan."

Klacksy secara otomatis mencari Zalo User ID penerima yang tersimpan dan menggunakan penyedia Zalo yang dikonfigurasi. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Prasyarat: Zalo User ID harus tersimpan di Klacks untuk penerima (di bawah Alamat → Data kontak). Penerima harus sebelumnya berinteraksi dengan Official Account (misalnya mengikuti OA atau mengirimnya pesan) — di luar jendela interaksi, Zalo akan menolak pengiriman.

Pesan masuk

Integrasi Zalo tidak mendukung penerimaan — balasan atas pesan yang dikirim tidak diteruskan ke Klacks. Oleh karena itu, kotak masuk perpesanan tidak menampilkan pesan masuk untuk penyedia ini.
