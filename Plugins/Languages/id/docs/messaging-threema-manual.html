Menyiapkan Threema Gateway

Prasyarat

Untuk mengirim pesan melalui Threema, Anda memerlukan akun di Threema Gateway. Threema adalah penyedia asal Swiss, banyak digunakan di Swiss dan ramah privasi (DSG Swiss).

Penting: Integrasi Threema dirancang hanya untuk pengiriman. Menerima pesan masuk memerlukan mode end-to-end dari gateway dan tidak didukung. Pengiriman berbayar — setiap pesan yang dikirim menggunakan Credits.

Langkah 1 — Membuat akun Threema Gateway

  1. Daftar di gateway.threema.ch.
  2. Ajukan Gateway ID dalam mode Basic (misalnya: *MYGATEWAY). ID ini selalu dimulai dengan tanda bintang (*) dan harus disetujui oleh Threema.
  3. Beli Credits — tanpa saldo, pesan tidak dapat dikirim.
  4. Catat API Secret dari dashboard Gateway.

Catatan: Perlakukan API Secret seperti kata sandi. Jangan bagikan secara publik dan simpan dengan aman.

Langkah 2 — Mengonfigurasi Threema di Klacks

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.
  3. Isi bidang-bidang sebagai berikut:

  1. Klik Simpan.
  2. Uji koneksi melalui tombol Uji di daftar penyedia. Uji ini memeriksa kredensial melalui pemeriksaan Credits gateway.

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah penyedia Threema dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan. Anda tidak perlu mengetahui Threema ID — cukup gunakan nama karyawan atau klien: 

"Kirim pesan ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel pesan: Shift telah ditukar."
"Beri tahu Peter Müller bahwa dinasnya pada hari Senin dibatalkan."

Klacksy secara otomatis mencari Threema ID penerima yang tersimpan dan menggunakan penyedia Threema yang dikonfigurasi. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Prasyarat: Threema ID 8 digit harus tersimpan di Klacks untuk penerima (di bawah Alamat → Data kontak). Karyawan dapat menemukan Threema ID mereka di aplikasi Threema di bawah "Profil Saya".

Pesan masuk

Integrasi Threema tidak mendukung penerimaan — balasan atas pesan yang dikirim tidak diteruskan ke Klacks. Penerimaan memerlukan mode end-to-end dari Threema Gateway; integrasi Klacks menggunakan mode Basic. Oleh karena itu, kotak masuk perpesanan tidak menampilkan pesan masuk untuk penyedia ini.
