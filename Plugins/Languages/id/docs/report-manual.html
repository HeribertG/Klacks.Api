Buku Panduan Report Designer

Struktur Report

Sebuah report terdiri dari tiga bagian:

  • Header – dicetak di bagian atas setiap halaman
  • Body – berisi tabel data
  • Footer – dicetak di bagian bawah setiap halaman

Setiap bagian dapat diedit melalui tab Desain di editor report.

Bagian Header

Header memiliki tiga zona: Kiri, Tengah, dan Kanan.

Setiap zona dapat berisi:

  • Kolom – kolom database yang diisi secara otomatis
  • Teks Bebas – teks yang dimasukkan secara manual
  • Gambar – misalnya logo perusahaan (unggah melalui pengelola gambar)

Baris dapat ditambahkan atau dihapus melalui toolbar.

Tabel Body

Body berisi satu atau beberapa tabel.

AksiDeskripsi
Tambahkan kolomMelalui simbol + atau dengan drag & drop dari daftar kolom
Lebar kolomSesuaikan dengan menyeret tepi kolom
Urutan kolomPindahkan dengan drag & drop
Hapus kolomDi editor kolom melalui ikon hapus

Setiap tabel terhubung dengan sebuah DataSet (misalnya jadwal kerja, alamat).

Menggabungkan Kolom (Merged Fields)

Merged Fields memungkinkan beberapa pengikatan data dalam satu kolom.

  • Klik Tambahkan kolom di editor kolom untuk menambahkan kolom lain ke kolom yang sama
  • Nilai ditampilkan secara vertikal atau dengan pemisah
  • Pemisah dapat dikonfigurasi di dialog kolom (misalnya koma, spasi, baris baru)

Footer Tabel

Di bawah setiap tabel, footer dapat ditampilkan.

  • Kolom SUM: Kolom numerik dapat dijumlahkan secara otomatis
  • Label: Label untuk jumlah dapat ditampilkan atau disembunyikan
  • Aktivasi melalui editor kolom di tab Footer

Baris Teks Bebas

Baris teks bebas dapat disisipkan sebelum atau sesudah tabel data.

PropertiDeskripsi

GayaJenis huruf, ukuran, dan perataan dapat dikonfigurasi

Format

Setiap sel dan setiap teks bebas dapat diformat secara individual:

OpsiDeskripsi

Ukuran hurufUkuran dalam poin (pt)
Tebal / Miring / Garis BawahMelalui tombol B / I / U
Warna teksWarna yang dapat dipilih secara bebas
PerataanKiri, Tengah, atau Kanan

Bingkai Sel

Untuk setiap sel, garis bingkai dapat dikonfigurasi secara individual.

PropertiOpsi
SisiAtas, Kanan, Bawah, Kiri (individu atau semua)
Gaya garisTipis, Sedang, Tebal, Putus-putus, Ganda
Warna garisDapat dipilih secara bebas

Bingkai diatur di editor kolom di bawah Bingkai.

Pengaturan Halaman

Di tab Umum, pengaturan pencetakan dapat disesuaikan:

  • Orientasi: Potret (Portrait) atau Lanskap (Landscape)
  • Ukuran kertas: A4, A3, B4 (JIS), B5 (JIS), atau Letter
  • Margin halaman: Atas, Kanan, Bawah, Kiri dalam mm

Opsi Tampilan (Designer)

Di tab Desain, untuk sumber data Jadwal Kerja (Schedule), tersedia opsi tambahan:

  • Gabungkan entri per hari: Beberapa entri pada hari yang sama digabungkan dalam satu baris
  • Tampilkan periode penuh: Semua hari dalam periode ditampilkan, meskipun tidak ada entri

Parameter

Parameter diminta saat menjalankan report. Nilainya tersedia dalam filter baris dan rumus, dan juga dapat membatasi kueri sumber data. Parameter dibuat di tab Parameter.

KolomArti
KunciNama teknis. Harus dimulai dengan huruf dan hanya boleh berisi huruf, angka, dan garis bawah. Unik untuk setiap report.
LabelLabel yang ditampilkan saat menjalankan.
TipeTeks, Angka, Tanggal, Ya/Tidak, atau Pilihan.
Nilai StandarDigunakan jika tidak ada input saat menjalankan.
Nilai PilihanHanya untuk tipe «Pilihan»: nilai yang diizinkan, dipisahkan dengan koma.
Berlaku padaMenentukan apakah nilai juga diteruskan ke sumber data.
Kolom WajibReport tidak dapat dijalankan tanpa nilai ini.

Parameter dalam Filter dan Rumus

Setiap parameter tersedia dalam skrip dengan kunci berawalan param_ — dari kunci region menjadi param_region. Awalan ini mencegah parameter menutupi nilai baris dengan nama yang sama. Nama saat ini ditampilkan di bawah setiap parameter.

Nilai dikonversi ke tipe yang dipilih sebelum dievaluasi:

  • Angka: sebagai angka; input yang tidak valid menjadi 0
  • Ya/Tidak: benar jika 1, true, wahr, atau yes, selain itu salah
  • Teks, Tanggal, Pilihan: sebagai teks

Mengikat Parameter ke Sumber Data

Melalui Berlaku pada, parameter juga membatasi data apa yang dimuat:

PengaturanEfek
hanya filter dan rumusNilai hanya digunakan dalam skrip (standar).
Grup kueriNilai menggantikan grup tempat data dimuat.
Orang kueriNilai menggantikan orang tempat data dimuat.
Tanggal mulai kueriNilai menggantikan awal periode.
Tanggal akhir kueriNilai menggantikan akhir periode.

Nilai tanggal yang terikat harus dimasukkan sebagai JJJJ-BB-TT atau TT.BB.JJJJ. Nilai dalam format lain akan diabaikan agar kueri tidak kosong tanpa disadari. Nilai kosong membiarkan pengaturan asli tidak berubah.
