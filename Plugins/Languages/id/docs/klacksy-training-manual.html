Pelatihan Klacksy - Panduan

Apa itu alat pelatihan ini?

Alat pelatihan ini mengendalikan navigasi dalam halaman dari chatbot Klacksy. Ketika pengguna mengatakan atau menulis "Klacksy tunjukkan alamat", Klacksy menavigasi ke halaman yang sesuai dan menggulir ke bagian yang relevan.

Agar ini berfungsi, Klacksy memerlukan daftar sinonim untuk setiap jangkar pada sebuah halaman dalam setiap bahasa (misalnya "Adressen", "Kunden", "Kontakte" untuk target addresses).

Tab "Target"

Daftar semua jangkar yang ditemukan di frontend (atribut HTML data-klacksy-target). Filter status:

  • pending: jangkar ada, tetapi belum ada sinonim
  • generated: sinonim telah dihasilkan secara otomatis, perlu diperiksa
  • reviewed: sinonim disetujui oleh admin
  • needs-review: ditandai untuk diperiksa ulang

Mengklik sebuah target membuka editor sinonim di bawahnya. Di sana sinonim dapat ditambahkan, dihapus, dan disetujui dengan "Simpan sebagai diperiksa".

Tab "Masukan"

Menampilkan input pengguna yang tidak dapat dicocokkan oleh Klacksy (tidak ada sinonim yang cocok ditemukan). Dari daftar ini dapat diketahui sinonim mana yang masih kurang.

Tab "Metrik"

Ikhtisar semua target berdasarkan status. Membantu melacak kemajuan pelatihan.

Pipeline build (CLI)

Jika templat mendapatkan jangkar data-klacksy-target baru, manifest dan sinonim awal harus diregenerasi. Perintah berikut juga berjalan secara otomatis di CI dan di Husky pre-commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Pindai templat → navigation-targets.json dengan semua anchor
npm run scan:targets

# 2a. Buat sinonim awal (semua 4 locale Core + 22 locale Plugin, ~2,5 jam)
npm run generate:synonyms

# 2b. Hanya locale Core (de/en/fr/it) — cepat, sekitar 9 menit
npm run generate:synonyms -- --core-only

# 2c. Hanya isi ulang locale Plugin yang hilang — sekitar 45 menit
npm run generate:synonyms -- --plugins-only

# 3. Periksa konsistensi wake-word
npm run wake-word-lint

Penting: Pada npm run, harus ada -- agar opsi diteruskan ke skrip. Tanpa --, npm akan menelan flag tersebut dan skrip berjalan dalam mode standar.

Alternatif tanpa npm: npx tsx tools/generate-synonyms.ts --core-only.

Kunci API

Kunci API LLM dicari dalam urutan berikut:

  1. Variabel lingkungan SYNONYM_LLM_API_KEY
  2. Tabel DB llm_providers (penyedia deepseek, is_enabled = true) — otomatis melalui pemanggilan psql
  3. Jika tidak ada, pesan kesalahan

Penyedia standar adalah DeepSeek. Penyedia lain melalui SYNONYM_LLM_PROVIDER_ID=anthropic (atau penyedia LLM lain yang telah dikonfigurasi di pengaturan).

Langkah 1 - scan:targets

Memindai semua templat Angular untuk atribut data-klacksy-target dan menghasilkan manifest Application/Skills/Definitions/navigation-targets.json. Setiap jangkar baru kemudian muncul di tab "Target" dengan status pending.

Langkah 2 - generate:synonyms

Menghasilkan sinonim awal untuk setiap jangkar baru dari data-klacksy-label-key dan kategori. Status setelahnya: generated (harus diperiksa oleh admin).

Skrip menulis checkpoint manifest setiap 5 target, sehingga jika terhenti, data yang sudah dihasilkan tidak hilang.

Langkah 3 - wake-word-lint

Memeriksa konsistensi varian wake-word (Hallo Klacksy / Hey Klacksy / ...) di semua bahasa. Mencegah sinonim menimpa wake-word.

Mode suara

Ikon mikrofon di chat mengaktifkan mode suara. Setelah aktif:

  • Mikrofon mendengarkan, mentranskripsikan secara terus-menerus
  • Pada keheningan singkat → pengiriman otomatis transkripsi yang ada

Penting: Segera setelah Anda mulai mengetik di bidang teks, mode suara akan otomatis berakhir — jika tidak, mikrofon akan menimpa teks yang Anda ketik dengan transkripsi sendiri dan mengirimnya sebelum waktunya.

Loop pelatihan tipikal

  1. Tambahkan jangkar dalam templat: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Mulai ulang API (cache dibaca ulang saat startup)
  4. Buka tab "Target" → target baru muncul dengan status generated
  5. Periksa/lengkapi sinonim → "Simpan sebagai diperiksa" → status reviewed
  6. Uji dengan Klacksy, misalnya "Klacksy tunjukkan alamat"
  7. Jika Klacksy tidak cocok → tab "Masukan" → lengkapi sinonim yang hilang
  8. Pantau tab "Metrik" hingga semuanya reviewed
