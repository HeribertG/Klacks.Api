Panduan Skrip Makro

Pendahuluan

Dengan editor makro, Anda dapat membuat skrip yang digunakan sebagai dasar perhitungan untuk pekerjaan, jenis kontrak kerja, dan lainnya.

Contoh penggunaan:

  • Perhitungan akurat waktu cuti dan dinas militer berdasarkan tingkat pekerjaan
  • Perhitungan upah lembur untuk kerja malam, akhir pekan, dan hari libur
  • Penyesuaian fleksibel terhadap persyaratan baru

Catatan: Interpreter skrip berjalan di lingkungan sandbox yang aman tanpa akses ke sistem file atau jaringan. Kode berbahaya tidak dapat dijalankan.

Fungsi dan Kategori

Selain nama dan isi skrip, setiap makro dalam daftar makro memiliki dua properti tambahan yang diatur melalui dropdown di editor: Kategori dan Peran. Keduanya murni metadata – berada di luar skrip dan tidak mengubah perhitungannya, melainkan mengatur bagaimana Klacks menemukan dan menetapkan makro yang sesuai secara otomatis.

Kategori

Kategori mengelompokkan makro ke dalam area penggunaan tertentu:

KategoriPenggunaan
Tidak ditetapkanTidak ada area penggunaan khusus (default untuk makro baru)
DinasPerhitungan tunjangan untuk dinas reguler (tunjangan malam, akhir pekan, hari libur)
CutiPerhitungan jam untuk cuti
SakitPerhitungan jam untuk sakit
KecelakaanPerhitungan jam untuk kecelakaan
Lokakarya (dibayar)Waktu lokakarya/pelatihan yang dibayar
Lokakarya (tidak dibayar)Waktu lokakarya/pelatihan yang tidak dibayar

Kategori Dinas memiliki peran khusus: dinas yang baru dibuat secara otomatis mendapatkan makro standar dari kategori ini (lihat "Peran" di bawah). Dinas yang sudah ada tidak pernah diubah secara retroaktif.

Peran: Kustom, Standar, Standar (Aditif)

Peran mengklasifikasikan posisi suatu makro di dalam kategorinya:

PeranArti
KustomMakro bebas tanpa peran khusus. Boleh ada berapa pun per kategori.
StandarMakro standar untuk kategori ini – ditetapkan secara otomatis ke dinas baru. Maksimal SATU makro per kategori boleh memiliki peran ini.
Standar (Aditif)Makro standar alternatif dengan logika tunjangan aditif (lihat di bawah). Juga maksimal satu per kategori, dapat ada di samping makro "Standar".

Penting: Peran itu sendiri tidak menghitung apa pun – ia hanyalah label. Apakah tunjangan dihitung dengan cara "highest-wins" (hanya tarif tertinggi yang berlaku dihitung) atau aditif (semua tarif yang berlaku dijumlahkan) ditentukan oleh skrip itu sendiri. Kedua makro kategori "Dinas" bawaan menunjukkan perbedaan ini pada struktur dasar yang sama:

  • "AllShift" (Peran: Standar) – untuk setiap segmen waktu menentukan tunjangan tertinggi yang berlaku (Malam/WE1/WE2/WE3/Hari libur) dan hanya menggunakan itu.
  • "AllShiftAdditive" (Peran: Standar (Aditif)) – menghitung tunjangan malam, akhir pekan, dan hari libur secara independen satu sama lain lalu menjumlahkannya.

Makro mana dari keduanya yang secara otomatis ditetapkan saat dinas baru dibuat diatur oleh pengaturan tingkat instalasi ("aditif" atau "tarif tertinggi menang"). Setelah itu, makro untuk setiap dinas dapat diganti secara manual kapan saja – sehingga penggunaan campuran dimungkinkan.

Keunikan: Jika Anda mencoba menyimpan makro kedua dari kategori yang sama juga sebagai "Standar" atau "Standar (Aditif)", editor akan memblokir penyimpanan dan menyebutkan nama makro yang sudah ditetapkan. Ubah dulu peran makro tersebut menjadi "Kustom".

Perubahan manual pada "AllShift"/"AllShiftAdditive" tidak disarankan. Kedua makro ini adalah mekanisme di mana penyesuaian khusus negara dan industri disisipkan secara otomatis: selama Anda tidak mengubahnya, Klacks akan menjaganya tetap sinkron secara otomatis dengan aturan yang sesuai untuk negara atau industri Anda. Jika Anda mengedit salah satunya secara manual, sejak saat itu makro tersebut dianggap milik pelanggan – pembaruan negara/industri otomatis di masa depan untuk makro ini tidak lagi diterapkan secara diam-diam, melainkan gagal dengan konflik hingga Anda menyelesaikan perbedaannya secara manual. Jika Anda memerlukan logika tunjangan sendiri, buat makro baru dengan peran "Kustom" dan tetapkan secara khusus ke dinas yang bersangkutan.

Struktur Kontrol

Penting: Kata kunci seperti ENDIF, ENDFUNCTION, ENDSUB harus ditulis menyatu (jangan ditulis terpisah seperti END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "Besar"
ELSEIF x > 5 THEN
    OUTPUT 1, "Sedang"
ELSE
    OUTPUT 1, "Kecil"
ENDIF

IF Satu Baris

IF x > 10 THEN OUTPUT 1, "Besar" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Akhir pekan"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Hari kerja"
    CASE ELSE
        OUTPUT 1, "Tidak diketahui"
END SELECT

Loop FOR-NEXT

FOR i = 1 TO 10
    summe += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Loop DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Fungsi dan Prosedur

Penting: Fungsi (FUNCTION) dan prosedur (SUB) harus didefinisikan sebelum pemanggilan pertama. Interpreter membaca kode dari atas ke bawah. Fungsi atau prosedur hanya dapat digunakan setelah definisinya diproses.

SUB (Prosedur tanpa nilai kembali)

SUB hitung(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (Fungsi dengan nilai kembali)

FUNCTION gandakan(x)
    gandakan = x * 2
ENDFUNCTION

DIM hasil
hasil = gandakan(21)
OUTPUT 1, hasil

Nilai Kembali (OUTPUT)

OUTPUT tipe, nilai

tipe dan nilai adalah dua ekspresi yang dipisahkan koma; keduanya opsional (default 0 atau "", jika dihilangkan). Satu makro boleh berisi baris OUTPUT sebanyak apa pun – setiap baris menghasilkan nilai kembali sendiri. Klacks hanya mengevaluasi tipe-tipe berikut:

TipeArti
1Hasil utama (jam atau jumlah total) – tetap diambil meskipun nilainya 0
10Tunjangan malam
11Tunjangan untuk hari akhir pekan 1 (misalnya Sabtu)
12Tunjangan untuk hari akhir pekan 2 (misalnya Minggu)
13Tunjangan untuk hari akhir pekan 3 (hari akhir pekan ketiga yang dapat dikonfigurasi)
14Tunjangan hari libur

Baris tunjangan (tipe 10-14) dengan nilai 0 diabaikan – jadi makro tidak perlu mengeluarkan baris tersendiri untuk setiap jenis tunjangan, cukup untuk tunjangan yang benar-benar berlaku. Nilai yang tidak dapat diinterpretasikan sebagai angka akan dilewati.

Saat disimpan, makro wajib dikompilasi dan dijalankan sekali secara percobaan dengan nilai uji netral. Kesalahan sintaks dan runtime (misalnya tanda kurung yang tidak seimbang atau ekspresi yang menggantung) akan ditampilkan secara andal, alih-alih diam-diam menghasilkan makro yang tidak berfungsi.

Contoh: Perhitungan Upah Lembur ("AllShift")

Makro standar bawaan untuk kategori "Dinas". Menghitung tunjangan untuk malam, hari libur, dan tiga hari akhir pekan yang dapat dikonfigurasi dengan penanganan yang benar untuk shift yang melewati tengah malam (pembagian segmen), dan menerapkan tarif tertinggi yang berlaku per segmen (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Penjelasan

  • Pembagian segmen: Untuk shift yang melewati tengah malam (misalnya 22:00-06:00), shift dibagi menjadi dua segmen (sampai tengah malam / mulai tengah malam), masing-masing dengan flag hari/hari libur sendiri
  • SegBonusForType: Menghitung tunjangan untuk satu segmen dan satu jenis tunjangan tertentu (10-14) dengan mempertimbangkan tunjangan malam, hari libur, dan akhir pekan
  • WE1/WE2/WE3 menggantikan Sab/Min: weekendday1-3 membuat hari akhir pekan dapat dikonfigurasi (tidak semua negara memiliki Sabtu/Minggu sebagai akhir pekan)
  • Tunjangan tertinggi per segmen: NRate/DRate masing-masing menentukan tarif tertinggi yang berlaku untuk jam malam dan jam siang – highest-wins, tanpa penumpukan
  • HolidayNextDay: Mempertimbangkan apakah hari berikutnya adalah hari libur (penting untuk shift malam yang melewati tengah malam)
  • Beberapa baris OUTPUT: baris 1 memberikan jumlah total, baris 10-14 memberikan jumlah tunjangan masing-masing (lihat bagian "Nilai Kembali")

Varian aditif ("AllShiftAdditive")

Makro standar (aditif) dari kategori yang sama memiliki baris IMPORT yang identik dan struktur kerangka yang sama – hanya SegBonusForType yang berbeda: alih-alih tarif tertinggi, untuk setiap jenis tunjangan dihitung secara independen apakah tunjangan itu berlaku, dan semua jumlah yang berlaku dijumlahkan di akhir (tidak ada lagi highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Jika misalnya shift malam juga jatuh pada hari libur, dengan "AllShift" ia hanya mendapatkan tarif yang lebih tinggi dari keduanya, sedangkan dengan "AllShiftAdditive" ia mendapatkan tunjangan malam dan hari libur sekaligus. Sisa skrip (pembagian segmen, penjumlahan, baris OUTPUT) identik dengan "AllShift" di atas.
