Menyiapkan Perpesanan LINE

Prasyarat

Untuk mengirim dan menerima pesan melalui LINE, Anda memerlukan LINE Official Account dengan Messaging API Channel di LINE Developers Console. LINE sangat populer di Jepang, Taiwan, dan Thailand.

Catatan: Pesan push memiliki kuota bulanan tergantung paket LINE (paket gratis terbatas). Periksa syarat dan ketentuan terkini dari paket Official Account Anda.

Langkah 1 — Membuat LINE Official Account dan Messaging API Channel

  1. Buat LINE Official Account (melalui LINE Official Account Manager).
  2. Buka LINE Developers Console (developers.line.biz) dan buat Messaging API Channel atau kaitkan Official Account Anda dengan Messaging API.
  3. Terbitkan Channel Access Token berumur panjang di tab Messaging API (Issue).
  4. Catat Channel Secret dari tab Basic Settings.

Catatan: Perlakukan Channel Access Token dan Channel Secret seperti kata sandi. Jangan bagikan secara publik dan simpan dengan aman.

  1. Navigasikan ke Pengaturan → Penyedia perpesanan.
  2. Klik Tambah.

Langkah 3 — Mengirim pesan melalui chatbot (Klacksy)

Setelah penyedia LINE dikonfigurasi dan diaktifkan, chatbot Klacksy dapat mengirim pesan. Anda tidak perlu mengetahui LINE User ID — cukup gunakan nama karyawan atau klien: 

"Kirim pesan ke Max Muster: Janji temu Anda besok pukul 14:00."
"Kirimkan Anna Beispiel pesan: Shift telah ditukar."
"Beri tahu Peter Müller bahwa dinasnya pada hari Senin dibatalkan."

Klacksy secara otomatis mencari LINE User ID penerima yang tersimpan dan menggunakan penyedia LINE yang dikonfigurasi. Pengiriman sepenuhnya transparan bagi Anda — Anda bekerja dengan nama, Klacksy mengurus sisanya.

Prasyarat: LINE User ID (dimulai dengan U…) harus tersimpan di Klacks untuk penerima (di bawah Alamat → Data kontak). User ID diketahui melalui pesan masuk (terlihat di kotak masuk perpesanan) — untuk itu penerima harus menambahkan Official Account Anda sebagai teman dan mengirim pesan kepadanya.

Langkah 4 — Menerima pesan masuk (webhook)

Untuk menampilkan pesan LINE masuk di Klacks, URL webhook harus dimasukkan secara manual di LINE Developers Console.

  1. Salin URL webhook yang ditampilkan di Klacks dari pengaturan penyedia: 
    https://{domain-anda}/api/messaging/webhook/line
  2. Masukkan URL ini di LINE Developers Console di bawah Messaging API → Webhook settings sebagai Webhook URL.
  3. Aktifkan opsi "Use webhook".
  4. Pastikan instans Klacks Anda dapat diakses secara publik melalui HTTPS.
  5. Pesan masuk sekarang akan muncul secara real-time di Kotak masuk perpesanan.
