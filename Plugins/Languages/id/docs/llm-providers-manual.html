Cari Penyedia LLM — Panduan

Untuk apa fungsi ini?

Tampilan ini mengusulkan penyedia LLM yang belum ada dalam daftar Anda, dan menambahkan yang dipilih dengan satu klik. Dengan begitu Anda tidak perlu memasukkan nama dan URL dasar secara manual. Hanya penyedia API yang kompatibel dengan OpenAI yang diusulkan — yaitu jenis layanan yang sama seperti yang digunakan oleh penyedia Anda yang sudah ada.

Kolom-kolom tabel

Nama Penyedia

Nama tampilan penyedia (misalnya: "OpenRouter", "xAI (Grok)").

URL Dasar

Alamat API tempat komunikasi dengan penyedia dilakukan (misalnya: https://api.x.ai/v1/). URL inilah yang akan digunakan nanti saat pembuatan.

Sumber

Menunjukkan dari mana usulan tersebut berasal:

  • Katalog — dari daftar tetap yang telah diperiksa berisi penyedia yang dikenal. URL dasar telah diverifikasi dan karenanya dapat diandalkan.
  • Web — ditemukan melalui pencarian internet dan dievaluasi secara otomatis. Entri ini hanya muncul jika pencarian web telah dikonfigurasi di pengaturan. Entri ini bermanfaat, tetapi jika ragu Anda sebaiknya memeriksa sebentar URL dasarnya.

Keterjangkauan

Sebelum ditampilkan, setiap usulan diuji secara langsung (memanggil endpoint /models):

  • Dapat dijangkau — API merespons, penyedia berfungsi.
  • Dapat dijangkau (kunci diperlukan) — API ada, tetapi memerlukan kunci API. Jadi alamatnya benar.
  • Tidak dapat dijangkau — alamat tidak merespons. Entri semacam ini tidak dapat dipilih.

Menambahkan penyedia

Beri tanda centang pada satu atau beberapa penyedia dan klik "Tambahkan pilihan" di bawah. Penyedia yang dipilih akan dibuat dinonaktifkan dan tanpa kunci API. Penyedia yang sudah ada tidak akan diusulkan sama sekali.

Langkah selanjutnya setelah menambahkan

Penyedia yang baru ditambahkan belum aktif. Buka di daftar, masukkan kunci API, dan aktifkan. Setelah itu ia bekerja persis seperti penyedia Anda yang lain. Model-model individual dari sebuah penyedia tetap Anda kelola secara terpisah melalui manajemen model.
