Formelfelt manual

Grundsyntaks

Hvert formelfelt udgiver resultatet med kommandoen output:

output 1, <udtryk>

Den første parameter 1 er meddelelsestypen og skal altid være 1. Den anden parameter er den værdi, der skal udgives.

Simple eksempler:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " poster"

Tilgængelige variabler

De tilgængelige variabler er anført under fanen Variabler og kan der udfyldes med testværdier. Afhængigt af rapporttypen er forskellige variabler tilgængelige:

Betinget logik

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "mange poster"
ELSEIF totalRows > 0 THEN
    output 1, "få poster"
ELSE
    output 1, "ingen poster"
ENDIF

Enkeltlinjet IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (kortform)

output 1, IIF(totalRows > 0, "OK", "Tom")

Variabler og løkker

DIM i, sum
sum = 0
FOR i = 1 TO totalRows
    sum = sum + 1
NEXT
output 1, CStr(sum)

Praktiske eksempler

Antal poster med tekst

output 1, CStr(totalRows) & " poster"

Afrundet værdi (1 decimal)

output 1, CStr(Round(totalValue, 1))

Timer som t:mm

DIM t, m
t = Int(totalHours)
m = Round((totalHours - t) * 60, 0)
output 1, CStr(t) & "t " & CStr(m) & "min"

Betinget udskrift

IF totalRows = 0 THEN
    output 1, "Intet fravær"
ELSE
    output 1, CStr(totalRows) & " fravær (total: " & CStr(totalValue) & ")"
ENDIF

Beregn gennemsnit

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " t/dag"
ELSE
    output 1, "-"
ENDIF
