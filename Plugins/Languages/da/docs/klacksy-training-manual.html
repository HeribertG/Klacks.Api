Klacksy træning - vejledning

Hvad er trænings-værktøjet?

Trænings-værktøjet styrer chatbotten Klacksys navigation på siden. Når en bruger siger eller skriver "Klacksy vis mig adresserne", navigerer Klacksy til den passende side og scroller til det tilsvarende afsnit.

For at dette skal fungere, har Klacksy brug for en liste af synonymer på hvert sprog for hvert anker på en side (f.eks. "adresser", "kunder", "kontakter" for målet addresses).

Fanen "Mål"

Liste over alle ankre, der er fundet i frontend'en (HTML-attributter data-klacksy-target). Statusfilter:

  • pending: Ankeret findes, men endnu ingen synonymer
  • generated: Synonymer er genereret automatisk, kræver gennemgang
  • reviewed: Synonymer godkendt af en administrator
  • needs-review: Markeret til fornyet gennemgang

Klik på et mål åbner synonym-editoren nedenfor. Der kan synonymer tilføjes, slettes og godkendes med "Gem som gennemgået".

Fanen "Tilbagemeldinger"

Viser brugerinput, som Klacksy ikke kunne matche (intet passende synonym fundet). Ud fra denne liste kan man se, hvilke synonymer der stadig mangler.

Fanen "Målinger"

Oversigt over alle mål efter status. Hjælper med at følge træningsfremskridtet.

Build-pipeline (CLI)

Når skabeloner har fået nye data-klacksy-target-ankre, skal manifestet og de indledende synonymer genereres på ny. Følgende kommandoer kører også automatisk i CI og i Husky-pre-commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Scan skabeloner → navigation-targets.json med alle ankre
npm run scan:targets

# 2a. Generér indledende synonymer (alle 4 kerne + 22 plugin-lokaler, ~2,5 t)
npm run generate:synonyms

# 2b. Kun kerne-lokaler (de/en/fr/it) — hurtigt, ca. 9 min
npm run generate:synonyms -- --core-only

# 2c. Efterfyld kun manglende plugin-lokaler — ca. 45 min
npm run generate:synonyms -- --plugins-only

# 3. Kontrollér wake-word-konsistens
npm run wake-word-lint

Vigtigt: Ved npm run skal -- stå der, for at indstillingerne videregives til scriptet. Uden -- sluger npm flagget, og scriptet kører i standardtilstand.

Alternativ uden npm: npx tsx tools/generate-synonyms.ts --core-only.

API-nøgle

LLM-API-nøglen søges i denne rækkefølge:

  1. Miljøvariabel SYNONYM_LLM_API_KEY
  2. DB-tabel llm_providers (udbyder deepseek, is_enabled = true) — automatisk via psql-kald
  3. Ellers fejlmeddelelse

Standardudbyder er DeepSeek. Anden udbyder via SYNONYM_LLM_PROVIDER_ID=anthropic (eller en anden opsat LLM-udbyder i indstillingerne).

Trin 1 - scan:targets

Gennemsøger alle Angular-skabeloner for data-klacksy-target-attributter og genererer manifestet Application/Skills/Definitions/navigation-targets.json. Hvert nyt anker vises derefter i fanen "Mål" med status pending.

Trin 2 - generate:synonyms

Genererer indledende synonymer for hvert nyt anker ud fra data-klacksy-label-key og kategorien. Status derefter: generated (skal gennemgås af administrator).

Scriptet skriver manifest-checkpoints hver 5. mål, så en afbrydelse ikke mister allerede genererede data.

Trin 3 - wake-word-lint

Kontrollerer konsistensen af wake-word-varianten (Hej Klacksy / Hallo Klacksy / ...) på tværs af alle sprog. Forhindrer, at synonymer overskriver wake-word'et.

Talemodus

Mikrofonsymbolet i chatten aktiverer talemodus. Så snart den er aktiv:

  • Mikrofonen lytter med og transskriberer løbende
  • Ved kort stilhed → automatisk afsendelse af den hidtidige transskription

Vigtigt: Så snart du begynder at skrive i tekstfeltet, afsluttes talemodus automatisk — ellers ville mikrofonen overskrive din indtastede tekst med sine egne transskriptioner og sende for tidligt.

Typisk træningsforløb

  1. Tilføj anker i skabelon: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Genstart API'et (cachen genindlæses ved start)
  4. Åbn fanen "Mål" → nye mål vises med status generated
  5. Gennemgå/tilføj synonymer → "Gem som gennemgået" → status reviewed
  6. Test med Klacksy, f.eks. "Klacksy vis mig adresserne"
  7. Hvis Klacksy ikke matcher → fanen "Tilbagemeldinger" → tilføj manglende synonym
  8. Overvåg fanen "Målinger", indtil alt er reviewed
