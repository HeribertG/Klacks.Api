Opsæt Signal-beskeder

Forudsætninger

For at sende Signal-beskeder via Klacks skal du have en selv-hostet instans af signal-cli-rest-api. Dette er et open source-projekt, der gør Signal tilgængeligt via et REST-interface.

  • Docker skal være installeret på serveren
  • Et telefonnummer, der registreres hos Signal (dedikeret nummer anbefales)
  • Docker-imaget: bbernhard/signal-cli-rest-api

Vigtigt: Signal-integrationen er kun beregnet til afsendelse. Indgående Signal-beskeder modtages ikke i Klacks.

Trin 1 — Opsæt signal-cli-rest-api

  1. Start containeren med Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Forbind dit Signal-nummer via QR-link-metoden: Åbn i browseren 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    og scan den viste QR-kode med Signal-appen på telefonen, hvor nummeret er registreret (Indstillinger → Koblede enheder → Kobl enhed). Containeren forbindes dermed som en sekundær enhed.
  3. Alternativt kan du selv registrere nummeret via API'et — detaljer herom findes i projektets dokumentation.
  4. Test API'et med et helbredstjek: 
    curl http://localhost:8080/v1/about

Bemærk: Yderligere detaljer om konfiguration findes i signal-cli-rest-api-dokumentationen.

Trin 2 — Konfigurér Signal i Klacks

  1. Naviger til Indstillinger → Beskedudbydere.
  2. Klik på Tilføj.
  3. Udfyld felterne som følger:

AktiveretSlår udbyderen til/fraJa
  1. Klik på Gem.
  2. Test forbindelsen via Test-knappen i udbyderlisten. Testen kontrollerer, om det angivne nummer er registreret i containeren.

Bemærk: Klacks sender beskeder via endpointet POST /v2/send i containeren.

Trin 3 — Send beskeder via chatbotten (Klacksy)

Så snart Signal-udbyderen er konfigureret og aktiveret, kan chatbotten Klacksy sende beskeder. Du behøver ikke kende telefonnumre — brug blot navnet på medarbejderen eller klienten: 

"Send en besked til Max Muster: Din aftale er i morgen kl. 14:00."
"Send Anna Beispiel en Signal-besked: Vagten er blevet byttet."
"Giv Peter Müller besked om, at hans vagt mandag bortfalder."

Klacksy finder automatisk modtagerens registrerede mobilnummer og bruger den konfigurerede Signal-udbyder. Afsendelsen er fuldt gennemsigtig for dig — du arbejder med navne, Klacksy tager sig af resten.

Forudsætning: Modtageren skal have et mobilnummer registreret i Klacks (under Adresse → Kontaktdata), i internationalt format (f.eks. +41791234567). Også ved broadcast-beskeder bruger Signal-afsendelsen det registrerede mobilnummer.

Indgående beskeder

Signal-integrationen understøtter ikke modtagelse — svar på sendte beskeder overføres ikke til Klacks. Beskedindbakken viser derfor ingen indgående beskeder for denne udbyder.

Fejlfinding

ProblemMulig årsagLøsning
Forbindelsestest mislykkes Container ikke tilgængelig Kontrollér, om Docker-containeren kører (docker ps), og om API-URL'en er korrekt
Forbindelsestest mislykkes Nummer ikke registreret i containeren Gentag forbindelsen via QR-link-metoden
Besked leveres ikke Modtageren bruger ikke Signal, eller nummeret er forkert Sørg for, at modtageren har installeret Signal, og at nummeret er registreret i formatet +{landekode}{nummer}
Forbindelse mistet Enheden blev afkoblet i Signal-appen Forbind containeren igen via QR-linket
Container starter ikke Port 8080 allerede optaget Brug en anden port: -p 9090:8080, og tilpas API-URL'en i Klacks
