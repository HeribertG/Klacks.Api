Tilkaldevagt og rådighedsvagt

Disse indstillinger fastlægger, om tilkalde- og rådighedsvagter registreres, og med hvilken andel den derved udførte tid tæller som arbejdstid. De fungerer som virksomhedsdækkende standard for nyplanlagte vagter.

Tilkaldevagt aktiveret

Slår hele tilkaldevagt-logikken til eller fra. Er indstillingen deaktiveret, ignoreres de øvrige felter, og tilstedeværelses- samt rådighedstid tæller ikke særskilt.

  • Standard: deaktiveret.

Tilstedeværelsesvagt tæller som (%)

Andel af den aktive tilstedeværelsestid på stedet, der medregnes som ordinær arbejdstid.

  • Værdiområde: 0 til 100 procent.
  • Standard: 100 (tilstedeværelsestid tæller fuldt ud som arbejdstid).

Rådighedsvagt tæller som (%)

Andel af den rene rådighedstid (tilkaldevagt uden aktiv indsats), der medregnes som arbejdstid.

  • Værdiområde: 0 til 100 procent.
  • Standard: 0 (rådighedstid tæller ikke som arbejdstid).

Medregn i periodegrænser

Fastlægger, om den medregnede tilkalde- og rådighedstid indgår i periodegrænserne (f.eks. maks. timer pr. måned eller år).

  • Aktiv: medregnet tid belaster periodegrænserne.
  • Standard: deaktiveret.
