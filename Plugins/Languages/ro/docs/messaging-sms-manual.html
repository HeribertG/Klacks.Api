Configurarea furnizorului de SMS

Cerințe preliminare

Pentru a trimite mesaje SMS prin Klacks, aveți nevoie de un cont la Twilio sau la un gateway SMS compatibil cu Twilio. Klacks utilizează API-ul REST Twilio (endpoint-ul Messages cu autentificare Basic).

Important: Conexiunea SMS este concepută doar pentru trimitere. Mesajele SMS primite nu sunt recepționate în Klacks.

Pasul 1 — Configurarea contului Twilio

  1. Înregistrați-vă pe twilio.com și verificați-vă numărul de telefon și adresa de e-mail.
  2. Deschideți Twilio Console. Pe tabloul de bord găsiți sub Account Info cele două date de acces necesare:
    • Account SID — începe cu AC
    • Auth Token — faceți clic pe „Afișare"
  3. Achiziționați un număr expeditor la Phone Numbers → Buy a number (compatibil SMS). Acest număr apare ca expeditor la SMS-urile trimise.
  4. Conturi de test: Cu un cont trial gratuit, SMS-urile pot fi trimise doar către numere verificate în prealabil și conțin o notă de trial.

Notă: Tratați Auth Token-ul ca pe o parolă. Nu îl distribuiți public și păstrați-l în siguranță.

Pasul 2 — Configurarea furnizorului SMS în Klacks

  1. Navigați la Setări → Furnizori de mesagerie.
  2. Faceți clic pe Adăugare.
  3. Completați câmpurile după cum urmează:

Notă privind URL-ul gateway: Lăsați câmpul gol dacă folosiți Twilio — Klacks va utiliza automat https://api.twilio.com. Introduceți un URL doar dacă folosiți un gateway alternativ cu API compatibil Twilio.

Pasul 3 — Trimiterea mesajelor prin chatbotul (Klacksy)

Odată ce furnizorul SMS este configurat și activat, chatbotul Klacksy poate trimite mesaje. Nu trebuie să cunoașteți numere de telefon — folosiți pur și simplu numele angajatului sau al clientului: 

"Trimite un SMS lui Max Muster: programarea dumneavoastră este mâine la ora 14:00."
"Trimite-i Anei Beispiel un SMS: tura a fost schimbată."
"Anunță-l pe Peter Müller prin SMS că schimbul său de luni este anulat."

Klacksy caută automat numărul de mobil înregistrat al destinatarului și folosește furnizorul SMS configurat. Trimiterea este complet transparentă pentru dvs. — lucrați cu nume, Klacksy se ocupă de restul.

Cerință: Destinatarul trebuie să aibă un număr de mobil înregistrat în Klacks (la Adresă → Date de contact), în format internațional (de ex. +41791234567).

Mesaje primite

Conexiunea SMS nu acceptă recepția — răspunsurile la SMS-urile trimise nu sunt transmise către Klacks. Prin urmare, inbox-ul de mesagerie nu afișează mesaje primite pentru acest furnizor.
