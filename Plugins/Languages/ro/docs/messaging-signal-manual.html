Configurarea mesageriei Signal

Cerințe preliminare

Pentru a trimite mesaje Signal prin Klacks, aveți nevoie de o instanță găzduită propriu a signal-cli-rest-api. Este vorba despre un proiect open-source care face Signal accesibil printr-o interfață REST.

  • Docker trebuie să fie instalat pe server
  • Un număr de telefon care va fi înregistrat la Signal (se recomandă un număr dedicat)
  • Imaginea Docker: bbernhard/signal-cli-rest-api

Important: Integrarea Signal este concepută doar pentru trimitere. Mesajele Signal primite nu sunt recepționate în Klacks.

Pasul 1 — Configurarea signal-cli-rest-api

  1. Porniți containerul cu Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Conectați numărul dvs. Signal prin procedura de link QR: Deschideți în browser 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    și scanați codul QR afișat cu aplicația Signal de pe telefonul pe care este înregistrat numărul (Setări → Dispozitive asociate → Asociere dispozitiv). Containerul este astfel conectat ca dispozitiv secundar.
  3. Alternativ, puteți înregistra numărul independent prin API — detalii găsiți în documentația proiectului.
  4. Testați API-ul cu o verificare de sănătate (healthcheck): 
    curl http://localhost:8080/v1/about

Notă: Găsiți mai multe detalii despre configurare în documentația signal-cli-rest-api.

Pasul 2 — Configurarea Signal în Klacks

  1. Navigați la Setări → Furnizori de mesagerie.
  2. Faceți clic pe Adăugare.
  3. Completați câmpurile după cum urmează:

  1. Faceți clic pe Salvare.
  2. Testați conexiunea folosind butonul Test din lista de furnizori. Testul verifică dacă numărul indicat este înregistrat în container.

Notă: Klacks trimite mesajele prin endpoint-ul POST /v2/send al containerului.

Pasul 3 — Trimiterea mesajelor prin chatbot (Klacksy)

Odată ce furnizorul Signal este configurat și activat, chatbot-ul Klacksy poate trimite mesaje. Nu trebuie să cunoașteți niciun număr de telefon — folosiți pur și simplu numele angajatului sau al clientului: 

"Trimite un mesaj lui Max Muster: programarea dumneavoastră este mâine la ora 14:00."
"Trimite-i Anei Beispiel un mesaj Signal: tura a fost schimbată."
"Anunță-l pe Peter Müller că schimbul său de luni este anulat."

Klacksy caută automat numărul de mobil salvat al destinatarului și utilizează furnizorul Signal configurat. Trimiterea este complet transparentă pentru dvs. — lucrați cu nume, Klacksy se ocupă de rest.

Cerință preliminară: La destinatar trebuie să fie salvat un număr de mobil în Klacks (la Adresă → Date de contact), în format internațional (de ex. +41791234567). Și pentru mesajele de tip broadcast, trimiterea prin Signal se bazează pe numărul de mobil salvat.

Mesaje primite

Integrarea Signal nu suportă primirea — răspunsurile la mesajele trimise nu sunt transmise către Klacks. Prin urmare, mesageria de tip inbox nu afișează niciun mesaj primit pentru acest furnizor.
