Ce este instrumentul de antrenare?

Instrumentul de antrenare controlează navigarea in-page a chatbot-ului Klacksy. Când un utilizator spune sau scrie "Klacksy arată-mi adresele", Klacksy navighează la pagina potrivită și derulează până la secțiunea corespunzătoare.

Pentru ca acest lucru să funcționeze, Klacksy are nevoie, pentru fiecare ancoră de pe o pagină, de o listă de sinonime în fiecare limbă (de ex. "Adrese", "Clienți", "Contacte" pentru ținta addresses).

Tab-ul „Ținte"

Lista tuturor ancorelor găsite în frontend (atribute HTML data-klacksy-target). Filtre de stare:

  • pending: ancora există, dar nu are încă sinonime
  • generated: sinonimele au fost generate automat, necesită verificare
  • reviewed: sinonime aprobate de un administrator
  • needs-review: marcat pentru o nouă verificare

Apăsarea pe o țintă deschide editorul de sinonime de dedesubt. Acolo se pot adăuga sau șterge sinonime și se pot aproba cu „Salvează ca verificat".

Tab-ul „Feedback-uri"

Arată intrările utilizatorilor pe care Klacksy nu le-a putut asocia (nu s-a găsit niciun sinonim potrivit). Pe baza acestei liste se poate identifica ce sinonime lipsesc încă.

Tab-ul „Metrici"

Prezentare de ansamblu a tuturor țintelor după stare. Ajută la urmărirea progresului antrenării.

Pipeline de build (CLI)

Dacă șabloanele au primit noi ancore data-klacksy-target, manifestul și sinonimele inițiale trebuie regenerate. Următoarele comenzi rulează, de asemenea, automat în CI și în Husky pre-commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Scanează șabloanele → navigation-targets.json cu toate ancorele
npm run scan:targets

# 2a. Generează sinonimele inițiale (toate cele 4 Core + 22 locale de plugin, ~2.5 h)
npm run generate:synonyms

# 2b. Doar locale Core (de/en/fr/it) — rapid, cca. 9 min
npm run generate:synonyms -- --core-only

# 2c. Completează doar locale de plugin lipsă — cca. 45 min
npm run generate:synonyms -- --plugins-only

# 3. Verifică consistența wake-word-ului
npm run wake-word-lint

Important: La npm run trebuie să existe --, pentru ca opțiunile să fie transmise mai departe scriptului. Fără --, npm înghite flag-ul, iar scriptul rulează în modul standard.

Alternativă fără npm: npx tsx tools/generate-synonyms.ts --core-only.

Cheie API

Cheia API pentru LLM este căutată în această ordine:

  1. Variabila de mediu SYNONYM_LLM_API_KEY
  2. Tabelul din baza de date llm_providers (provider deepseek, is_enabled = true) — automat, printr-un apel psql
  3. Altfel, mesaj de eroare

Provider-ul implicit este DeepSeek. Un alt provider poate fi folosit prin SYNONYM_LLM_PROVIDER_ID=anthropic (sau orice alt provider LLM configurat în setări).

Pasul 1 - scan:targets

Caută în toate șabloanele Angular atributele data-klacksy-target și generează manifestul Application/Skills/Definitions/navigation-targets.json. Fiecare ancoră nouă apare apoi în tab-ul „Ținte" cu starea pending.

Pasul 2 - generate:synonyms

Generează, pentru fiecare ancoră nouă, sinonime inițiale pornind de la data-klacksy-label-key și categorie. Starea rezultată: generated (trebuie verificată de un administrator).

Scriptul scrie puncte de control ale manifestului la fiecare 5 ținte, astfel încât o întrerupere nu pierde datele deja generate.

Pasul 3 - wake-word-lint

Verifică consistența variantei wake-word-ului (Salut Klacksy / Hei Klacksy / ...) în toate limbile. Împiedică sinonimele să suprascrie wake-word-ul.

Mod vocal

Pictograma microfonului din chat activează modul vocal. Odată activ:

  • microfonul ascultă continuu și transcrie
  • la o scurtă pauză de tăcere → trimiterea automată a transcrierii de până atunci

Important: De îndată ce începi să tastezi în câmpul de text, modul vocal este oprit automat — altfel microfonul ar suprascrie textul tastat cu propriile transcrieri și l-ar trimite prematur.

Ciclul tipic de antrenare

  1. Adaugă ancora în șablon: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Repornește API-ul (cache-ul este reîncărcat la pornire)
  4. Deschide tab-ul „Ținte" → noile ținte apar cu starea generated
  5. Verifică/completează sinonimele → „Salvează ca verificat" → starea reviewed
  6. Testează cu Klacksy, de ex. "Klacksy arată-mi adresele"
  7. Dacă Klacksy nu găsește potrivirea → tab-ul „Feedback-uri" → completează sinonimul lipsă
  8. Monitorizează tab-ul „Metrici" până când totul este reviewed
