Configurarea bot-ului Telegram

Cerințe preliminare

Pentru a trimite și primi mesaje Telegram prin Klacks, aveți nevoie de un bot Telegram. Bot-urile sunt create prin intermediul oficial BotFather și sunt gratuite.

Pasul 1 — Crearea unui bot Telegram

  1. Deschideți Telegram și căutați @BotFather.
  2. Începeți o conversație cu BotFather și trimiteți comanda /newbot.
  3. Alegeți un nume pentru bot-ul dvs. (de ex. Klacks Benachrichtigungen).
  4. Alegeți un nume de utilizator pentru bot (trebuie să se termine în bot, de ex. klacks_notify_bot).
  5. BotFather vă va oferi un Bot Token. Copiați acest token — va fi necesar la pasul următor.

Notă: Tratați Bot Token-ul ca pe o parolă. Nu îl distribuiți public și păstrați-l în siguranță.

Pasul 2 — Configurarea bot-ului în Klacks

  1. Navigați la Setări → Furnizori de mesagerie.
  2. Faceți clic pe Adăugare.
  3. Completați câmpurile după cum urmează:
CâmpDescriereExemplu
NumeNume intern unictelegram-bot
Nume afișatEste afișat în interfațăTelegram
Tip furnizorSelectați TelegramTelegram
Bot TokenToken-ul primit de la BotFather123456:ABC-DEF1234ghIkl-zyx57W2v...
URL webhookURL pentru mesajele primite (vezi pasul 4)https://example.com/api/messaging/webhook/telegram
ActivatActivează/dezactivează furnizorulDa
  1. Faceți clic pe Salvare.
  2. Testați conexiunea folosind butonul Test din lista de furnizori.

Pasul 3 — Trimiterea mesajelor prin chatbotul (Klacksy)

Odată ce bot-ul Telegram este configurat și activat, chatbotul Klacksy poate trimite mesaje. Nu trebuie să cunoașteți ID-uri de chat — folosiți pur și simplu numele angajatului sau al clientului: 

"Trimite un mesaj lui Max Muster: programarea dumneavoastră este mâine la ora 14:00."
"Trimite-i Anei Beispiel un mesaj: tura a fost schimbată."
"Anunță-l pe Peter Müller că schimbul său de luni este anulat."

Klacksy caută automat numele de utilizator Telegram înregistrat al destinatarului și folosește bot-ul configurat. Trimiterea este complet transparentă pentru dvs. — lucrați cu nume, Klacksy se ocupă de restul.

Cerință: Destinatarul trebuie să aibă un nume de utilizator Telegram înregistrat în Klacks (la Adresă → Date de contact).

Pasul 4 — Recepționarea mesajelor primite (webhook)

Pentru a afișa mesajele Telegram primite în Klacks, trebuie configurat un webhook.

  1. Asigurați-vă că instanța dvs. Klacks este accesibilă public prin HTTPS.
  2. Introduceți următorul URL webhook în setările furnizorului: 
    https://{ihre-domain}/api/messaging/webhook/telegram
  3. Klacks înregistrează automat webhook-ul la Telegram de îndată ce furnizorul este salvat și activat.
  4. Mesajele primite apar acum în timp real în inbox-ul de mesagerie.

Depanare

ProblemăCauză posibilăSoluție
Testul de conexiune eșuează Bot Token invalid Verificați token-ul la BotFather cu /mybots
Mesajul nu este livrat Destinatarul nu a pornit bot-ul Destinatarul trebuie să deschidă bot-ul în Telegram și să trimită /start
Destinatarul nu a fost găsit Numele de utilizator Telegram nu este înregistrat Introduceți numele de utilizator Telegram la Adresă → Date de contact
Lipsesc mesajele primite URL-ul webhook-ului nu este accesibil Verificați dacă domeniul dvs. este accesibil prin HTTPS și dacă URL-ul este corect
Înregistrarea webhook-ului a eșuat Nu există un certificat SSL valid Telegram necesită un certificat SSL valid (nu autosemnat)
