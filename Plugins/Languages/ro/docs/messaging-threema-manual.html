Configurarea Threema Gateway

Cerințe preliminare

Pentru a trimite mesaje prin Threema, aveți nevoie de un cont la Threema Gateway. Threema este un furnizor elvețian, foarte răspândit în Elveția și orientat spre protecția datelor (Legea elvețiană privind protecția datelor, DSG).

Important: Conexiunea Threema este concepută doar pentru trimitere. Recepția mesajelor primite ar necesita modul end-to-end al gateway-ului și nu este acceptată. Trimiterea este cu plată — fiecare mesaj trimis consumă credite.

Pasul 1 — Crearea unui cont Threema Gateway

  1. Înregistrați-vă pe gateway.threema.ch.
  2. Solicitați un ID de gateway în mod Basic (de ex. *MYGATEWAY). Acesta începe întotdeauna cu o steluță (*) și trebuie aprobat de Threema.
  3. Achiziționați credite — fără sold, nu pot fi trimise mesaje.
  4. Notați-vă API Secret-ul din tabloul de bord al gateway-ului.

Notă: Tratați API Secret-ul ca pe o parolă. Nu îl distribuiți public și păstrați-l în siguranță.

Pasul 2 — Configurarea Threema în Klacks

  1. Navigați la Setări → Furnizori de mesagerie.
  2. Faceți clic pe Adăugare.
  3. Completați câmpurile după cum urmează:

  1. Faceți clic pe Salvare.
  2. Testați conexiunea folosind butonul Test din lista de furnizori. Testul verifică datele de acces prin interogarea creditelor gateway-ului.

Pasul 3 — Trimiterea mesajelor prin chatbotul (Klacksy)

Odată ce furnizorul Threema este configurat și activat, chatbotul Klacksy poate trimite mesaje. Nu trebuie să cunoașteți ID-uri Threema — folosiți pur și simplu numele angajatului sau al clientului: 

"Trimite un mesaj lui Max Muster: programarea dumneavoastră este mâine la ora 14:00."
"Trimite-i Anei Beispiel un mesaj: tura a fost schimbată."
"Anunță-l pe Peter Müller că schimbul său de luni este anulat."

Klacksy caută automat ID-ul Threema înregistrat al destinatarului și folosește furnizorul Threema configurat. Trimiterea este complet transparentă pentru dvs. — lucrați cu nume, Klacksy se ocupă de restul.

Cerință: Destinatarul trebuie să aibă ID-ul Threema din 8 caractere înregistrat în Klacks (la Adresă → Date de contact). Angajatul găsește ID-ul Threema în aplicația sa Threema, la „Profilul meu".

Mesaje primite

Conexiunea Threema nu acceptă recepția — răspunsurile la mesajele trimise nu sunt transmise către Klacks. Recepția ar necesita modul end-to-end al Threema Gateway; conexiunea Klacks utilizează modul Basic. Prin urmare, inbox-ul de mesagerie nu afișează mesaje primite pentru acest furnizor.
