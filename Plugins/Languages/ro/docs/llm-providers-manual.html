Căutare provideri LLM — Ghid

La ce servește această funcție?

Această vizualizare îți sugerează provideri LLM pe care încă nu îi ai în lista ta și adaugă cu un singur clic pe cei selectați. Astfel nu trebuie să introduci manual numele și URL-ul de bază. Sunt sugerați exclusiv provideri API compatibili OpenAI — adică exact tipul de servicii folosite și de providerii tăi deja configurați.

Coloanele tabelului

Nume furnizor

Numele afișat al providerului (de ex. „OpenRouter", „xAI (Grok)").

URL de bază

Adresa API prin care se comunică cu providerul (de ex. https://api.x.ai/v1/). Exact acest URL va fi folosit ulterior la crearea providerului.

Sursă

Indică de unde provine sugestia:

  • Catalog — dintr-o listă predefinită și verificată de provideri cunoscuți. URL-urile de bază sunt verificate și, prin urmare, fiabile.
  • Web — găsit printr-o căutare pe internet și evaluat automat. Aceste intrări apar doar dacă în setări este configurată căutarea pe web. Sunt utile, dar în caz de dubiu ar trebui să verifici pe scurt URL-ul de bază.

Accesibilitate

Înainte de afișare, fiecare sugestie este testată în timp real (apelul endpoint-ului /models):

  • Accesibil — API-ul răspunde, providerul funcționează.
  • Accesibil (necesită cheie) — API-ul există, dar solicită o cheie API. Deci adresa este corectă.
  • Inaccesibil — adresa nu răspunde. Astfel de intrări nu pot fi selectate.

Adăugarea unui provider

Bifează unul sau mai mulți provideri și apasă mai jos pe „Adaugă selecția". Providerii selectați sunt creați dezactivați și fără cheie API. Providerii deja existenți nici măcar nu sunt sugerați.

Pașii următori după adăugare

Un provider nou adăugat nu este încă activ. Deschide-l în listă, introdu cheia API și activează-l. După aceea funcționează exact ca ceilalți provideri ai tăi. Modelele individuale ale unui provider se administrează în continuare separat, prin gestionarea modelelor.
