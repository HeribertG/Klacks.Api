Manual câmp formulă

Sintaxă de bază

Fiecare câmp de formulă emite rezultatul cu comanda output:

output 1, <expresie>

Primul parametru 1 este tipul mesajului și trebuie să fie întotdeauna 1. Al doilea parametru este valoarea de emis.

Exemple simple:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " intrări"

Logică condițională

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "multe intrări"
ELSEIF totalRows > 0 THEN
    output 1, "puține intrări"
ELSE
    output 1, "nicio intrare"
ENDIF

IF pe o singură linie

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (formă scurtă)

output 1, IIF(totalRows > 0, "OK", "Gol")

Variabile și bucle

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Exemple practice

Numărul de intrări cu text

output 1, CStr(totalRows) & " intrări"

Valoare rotunjită (1 zecimală)

output 1, CStr(Round(totalValue, 1))

Ore ca h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Emitere condiționată

IF totalRows = 0 THEN
    output 1, "Nicio absență"
ELSE
    output 1, CStr(totalRows) & " absențe (Total: " & CStr(totalValue) & ")"
ENDIF

Calcularea mediei

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/zi"
ELSE
    output 1, "-"
ENDIF
