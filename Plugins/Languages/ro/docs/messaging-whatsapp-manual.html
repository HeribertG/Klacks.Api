Configurarea WhatsApp

Cerințe preliminare

Pentru a trimite și primi mesaje prin WhatsApp cu Klacks, aveți nevoie de un cont de dezvoltator Meta și de o aplicație Meta cu produsul WhatsApp activat. Klacks utilizează WhatsApp Cloud API a platformei Meta Business pentru trimitere și Meta-Webhooks pentru primire.

Notă: Configurarea și testarea nu implică niciun cost. La crearea aplicației, Meta pune automat la dispoziție un număr de telefon de test gratuit.

Important — numărul expeditorului nu este numărul dumneavoastră privat. Un număr de telefon care este deja utilizat în aplicația WhatsApp obișnuită nu poate fi înregistrat pentru Cloud API, iar un număr înregistrat nu mai poate fi folosit cu WhatsApp Messenger. Folosiți de aceea numărul de test pus la dispoziție de Meta sau un număr propriu, utilizat exclusiv în scopuri profesionale. WhatsApp-ul dumneavoastră privat de pe telefonul mobil servește drept destinatar pentru testare — nu ca expeditor.

Pasul 1 — Crearea aplicației Meta

  1. Deschideți developers.facebook.com/apps și faceți clic pe Create app.
  2. Selectați ca scenariu de utilizare Other și ca tip de aplicație Business.
  3. În Dashboard, faceți clic la produsul WhatsApp pe Set up. Astfel se generează și se înregistrează automat un număr de telefon de test.
  4. Treceți în navigarea din stânga la WhatsApp → API Setup.
  5. Notați Phone number ID și generați un token de acces prin Generate access token.
  6. Notați la App settings → Basic valoarea App Secret — este necesară pentru verificarea semnăturii mesajelor primite.

Atenție — două ID-uri asemănătoare: În panoul API Setup, Phone number ID și WhatsApp Business Account ID sunt afișate direct una sub alta. Klacks are nevoie de Phone number ID. Cu ID-ul greșit, testul de conexiune raportează totuși succes, dar orice trimitere eșuează.

Atenție — durata de valabilitate a token-ului: Token-ul generat prin Generate access token este un token de test temporar și expiră după scurt timp. Pentru utilizarea permanentă, generați în Meta Business Manager un token permanent printr-un utilizator de sistem.

Pasul 2 — Autorizarea numărului destinatarului

Numărul de test poate trimite numai către destinatari autorizați în prealabil. Adăugați numărul dumneavoastră de WhatsApp în panoul API Setup, la To → Manage phone number list. Meta trimite un cod de confirmare la acest număr, pe care trebuie să îl introduceți.

Fără acest pas, Meta respinge orice trimitere către acest număr. Din momentul în care veți folosi un număr de firmă propriu și verificat, autorizarea nu mai este necesară.

Pasul 4 — Fereastra de 24 de ore

WhatsApp se deosebește aici fundamental de Telegram sau Slack. O firmă poate trimite mesaje text libere numai atât timp cât o fereastră de servicii pentru clienți este deschisă. Această fereastră este deschisă de destinatar, prin faptul că acesta scrie numărului dumneavoastră de WhatsApp. Ea rămâne deschisă 24 de ore și se prelungește cu fiecare mesaj suplimentar al destinatarului.

În afara acestei ferestre, Meta permite exclusiv șabloane de mesaje aprobate în prealabil. Klacks trimite în prezent exclusiv mesaje text libere și, prin urmare, nu poate deschide o conversație din proprie inițiativă.

Ce înseamnă acest lucru pentru dumneavoastră: Rugați-vă angajații o singură dată să trimită un mesaj către numărul de WhatsApp al Klacks. După aceea, trimiterea este posibilă timp de 24 de ore, iar fiecare răspuns prelungește fereastra. Dacă aceasta este închisă, trimiterea raportează o eroare — nu este o problemă de configurare, ci o regulă impusă de WhatsApp.

Dacă trebuie să vă contactați angajații independent de această fereastră, Telegram sau Signal sunt furnizorii mai potriviți — acolo nu există această restricție.

Pasul 5 — Trimiterea mesajelor prin chatbot (Klacksy)

Odată ce furnizorul WhatsApp este configurat și activat, chatbot-ul Klacksy poate trimite mesaje prin WhatsApp. Folosiți numele angajatului: 

"Trimite un mesaj lui Max Muster: programarea dumneavoastră este mâine la ora 14:00."
"Trimite-i Anei Beispiel un mesaj: tura a fost schimbată."

Ca destinatar servește numărul de telefon în format internațional, fără zero inițial și fără semnul plus (de ex. 41791234567 pentru 079 123 45 67). Trimiterea este complet transparentă pentru dvs. — lucrați cu nume, Klacksy se ocupă de rest.

Cerință preliminară: Numărul de WhatsApp trebuie să fie asociat cu contactul Klacks corespunzător (la Adresă → Date de contact), iar fereastra de 24 de ore de la pasul 4 trebuie să fie deschisă.

Pasul 6 — Primirea mesajelor primite (Webhooks)

Pentru a afișa mesajele WhatsApp primite în Klacks, trebuie configurat webhook-ul aplicației Meta. Salvați și activați furnizorul în Klacks înainte de a introduce Callback-URL — Meta verifică imediat URL-ul cu o cerere de verificare, la care Klacks răspunde automat pe baza Verify-Token-ului.

  1. Deschideți aplicația dvs. Meta și navigați la WhatsApp → Configuration.
  2. Faceți clic la Webhook pe Edit și introduceți:
    • Callback URL: URL-ul Webhook afișat în Klacks 
      https://{domeniul-dvs}/api/messaging/webhook/whatsapp
    • Verify token: exact aceeași valoare pe care ați introdus-o la pasul 3 în câmpul Verify-Token
  3. Faceți clic pe Verify and save.
  4. Abonați-vă la Webhook fields la câmpul messages.
  5. Mesajele primite apar acum în timp real în mesageria de tip inbox. Klacks verifică astfel semnătura fiecărei cereri (X-Hub-Signature-256) cu App-Secret-ul salvat.

Callback-URL trebuie să fie accesibil din exterior prin HTTPS. În cazul unei instalări în rețeaua internă a firmei, fără adresă publică, trimiterea funcționează, dar nu pot fi primite mesaje.
