Manual Scripting Macro

Introducere

Cu editorul de macrocomenzi puteți crea scripturi utilizate ca bază de calcul pentru muncă, tipuri de angajare și altele.

Exemple de utilizare:

  • Calcul precis al timpului de vacanță și serviciu militar pe baza ratei de angajare
  • Calcul sporuri pentru muncă de noapte, weekend și sărbători
  • Adaptare flexibilă la cerințe noi

Notă: Interpretorul de scripturi funcționează într-un mediu sandbox securizat fără acces la sistemul de fișiere sau rețea. Nu poate executa cod malițios.

Funcție și categorie

Pe lângă nume și conținutul scriptului, fiecare macro din lista de macrocomenzi are încă două proprietăți, setate prin liste derulante în editor: Categorie și Funcție. Ambele sunt metadate pure – se află în afara scriptului și nu îi modifică calculul, ci controlează modul în care Klacks găsește și atribuie automat macro-ul potrivit.

Categorie

Categoria asociază un macro unui domeniu de aplicare:

CategorieUtilizare
NeatribuitNiciun domeniu de aplicare special (implicit pentru macrocomenzi noi)
TurăCalcul sporuri pentru ture regulate (spor de noapte, weekend, sărbători)
ConcediuCalcul ore pentru concediu
BoalăCalcul ore pentru boală
AccidentCalcul ore pentru accident
Workshop (plătit)Timp de workshop/instruire plătit
Workshop (neplătit)Timp de workshop/instruire neplătit

Categoria Tură are un rol special: turele nou create primesc automat macro-ul standard al acestei categorii (vezi „Funcție" mai jos). Turele deja existente nu sunt niciodată modificate ulterior în acest proces.

Funcție: Personalizat, Standard, Standard (aditiv)

Funcția clasifică rolul unui macro în cadrul categoriei sale:

FuncțieSemnificație
PersonalizatMacro liber, fără rol special. Pot exista oricâte pe categorie.
StandardMacro-ul standard al acestei categorii – este atribuit automat turelor noi. Cel mult UN macro pe categorie poate avea această funcție.
Standard (aditiv)Macro standard alternativ cu logică de sporuri aditivă (vezi mai jos). De asemenea cel mult unul pe categorie, posibil pe lângă macro-ul „Standard".

Important: Funcția singură nu calculează nimic – este o etichetă. Dacă sporurile sunt calculate „highest-wins" (contează doar cel mai mare spor aplicabil) sau aditiv (toate sporurile aplicabile se însumează) decide scriptul însuși. Cele două macrocomenzi „Tură" livrate implicit arată diferența pe aceeași structură de bază:

  • „AllShift" (Funcție: Standard) – determină pentru fiecare segment de timp cel mai mare spor aplicabil (noapte/WE1/WE2/WE3/sărbătoare) și îl folosește doar pe acesta.
  • „AllShiftAdditive" (Funcție: Standard (aditiv)) – calculează sporul de noapte, weekend și sărbătoare independent unul de celălalt și le însumează.

Care dintre cele două este atribuit automat la crearea unei ture noi este controlat de o setare la nivel de instalare („aditiv" sau „cel mai mare spor câștigă"). Ulterior, macro-ul poate fi schimbat manual în orice moment per tură – deci este posibilă și o utilizare mixtă.

Unicitate: Dacă încercați să salvați un al doilea macro din aceeași categorie tot ca „Standard" sau „Standard (aditiv)", editorul blochează salvarea și indică numele macro-ului deja atribuit. Setați mai întâi funcția acestuia pe „Personalizat".

Modificările manuale ale „AllShift"/"AllShiftAdditive" nu sunt recomandate. Aceste două macrocomenzi sunt mecanismul prin care se aplică automat actualizările specifice țării și sectorului de activitate: atât timp cât rămân nemodificate, Klacks le menține automat sincronizate cu regulile potrivite pentru țara, respectiv sectorul dvs. Dacă editați manual unul dintre ele, de atunci încolo este considerat personalizat de client – viitoarele actualizări automate de țară/sector pentru acest macro nu mai sunt aplicate silențios, ci eșuează cu un conflict până când rezolvați manual diferența. Dacă aveți nevoie de o logică proprie de sporuri, creați în schimb un macro nou cu funcția „Personalizat" și atribuiți-l punctual turelor vizate.

Structuri de control

Important: Cuvintele cheie precum ENDIF, ENDFUNCTION, ENDSUB trebuie scrise fără spațiu (nu END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "mare"
ELSEIF x > 5 THEN
    OUTPUT 1, "mediu"
ELSE
    OUTPUT 1, "mic"
ENDIF

IF pe o singură linie

IF x > 10 THEN OUTPUT 1, "mare" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Weekend"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Zi lucrătoare"
    CASE ELSE
        OUTPUT 1, "Necunoscut"
END SELECT

Buclă FOR-NEXT

FOR i = 1 TO 10
    summe += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Buclă DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Funcții și proceduri

Important: Funcțiile (FUNCTION) și procedurile (SUB) trebuie definite înaintea primului apel. Interpretorul citește codul de sus în jos. O funcție sau procedură poate fi utilizată doar după ce definiția sa a fost procesată.

SUB (procedură fără valoare returnată)

SUB berechne(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (funcție cu valoare returnată)

FUNCTION verdoppeln(x)
    verdoppeln = x * 2
ENDFUNCTION

DIM ergebnis
ergebnis = verdoppeln(21)
OUTPUT 1, ergebnis

Valori returnate (OUTPUT)

OUTPUT tip, valoare

tip și valoare sunt două expresii separate prin virgulă; ambele sunt opționale (implicit 0, respectiv "", dacă sunt omise). Un macro poate conține oricâte linii OUTPUT – fiecare generează o valoare returnată proprie. Klacks evaluează însă doar următoarele tipuri:

TipSemnificație
1Rezultat principal (ore, respectiv sumă totală) – este preluat și la valoarea 0
10Spor de noapte
11Spor pentru ziua de weekend 1 (ex.: sâmbătă)
12Spor pentru ziua de weekend 2 (ex.: duminică)
13Spor pentru ziua de weekend 3 (a treia zi de weekend configurabilă)
14Spor de sărbătoare

Liniile de spor (tip 10-14) cu valoarea 0 sunt ignorate – un macro nu trebuie deci să genereze o linie proprie pentru fiecare tip de spor, ci doar pentru sporurile care apar efectiv. Valorile care nu pot fi interpretate ca număr sunt omise.

La salvare, macro-ul este compilat obligatoriu și executat o dată, cu titlu de probă, cu valori de test neutre. Erorile de sintaxă și de execuție (de ex. paranteze neechilibrate sau o expresie neterminată) sunt astfel semnalate în mod fiabil, în loc să conducă în tăcere la un macro nefuncțional.

Exemplu: Calcul sporuri („AllShift")

Macro-ul standard livrat implicit pentru categoria „Tură". Calculează sporuri pentru noapte, sărbătoare și cele trei zile de weekend configurabile, cu tratarea corectă a turelor care depășesc miezul nopții (segmentare) și aplică pentru fiecare segment cel mai mare spor aplicabil (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Explicație

  • Segmentare: La turele care depășesc miezul nopții (ex.: 22:00-06:00), tura este împărțită în două segmente (până la miezul nopții / de la miezul nopții), fiecare cu propriul indicator de zi a săptămânii/sărbătoare
  • SegBonusForType: Calculează sporul pentru un segment și un anumit tip de spor (10-14), ținând cont de sporurile de noapte, sărbătoare și weekend
  • WE1/WE2/WE3 în loc de Sâ/Du: weekendday1-3 fac zilele de weekend configurabile (nu orice țară are sâmbăta/duminica drept weekend)
  • Cel mai mare spor per segment: NRate/DRate determină de fiecare dată cel mai mare spor aplicabil pentru orele de noapte, respectiv de zi – highest-wins, fără cumulare
  • HolidayNextDay: Ține cont dacă ziua următoare este sărbătoare (important pentru turele de noapte care depășesc miezul nopții)
  • Mai multe linii OUTPUT: linia 1 furnizează suma totală, liniile 10-14 furnizează sumele individuale ale sporurilor (vezi secțiunea „Valori returnate")

Varianta aditivă („AllShiftAdditive")

Macro-ul Standard (aditiv) al aceleiași categorii are linii IMPORT identice și aceeași structură generală – doar SegBonusForType diferă: în loc de cel mai mare spor, pentru fiecare tip de spor se calculează independent dacă se aplică, iar toate sumele aplicabile sunt însumate la final (nu mai există highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Dacă o tură de noapte cade, de exemplu, și într-o zi de sărbătoare, la „AllShift" primește doar sporul mai mare dintre cele două, în timp ce la „AllShiftAdditive" primește sporul de noapte și cel de sărbătoare împreună. Restul scriptului (segmentare, însumare, liniile OUTPUT) este identic cu „AllShift" de mai sus.
