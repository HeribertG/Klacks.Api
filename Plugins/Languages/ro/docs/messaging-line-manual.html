Configurarea mesageriei LINE

Cerințe preliminare

Pentru a trimite și primi mesaje prin LINE, aveți nevoie de un LINE Official Account cu un Messaging-API-Channel în LINE Developers Console. LINE este deosebit de răspândit în Japonia, Taiwan și Thailanda.

Notă: Mesajele push au un contingent lunar în funcție de planul LINE (planul gratuit este limitat). Verificați condițiile actuale ale planului dvs. Official Account.

Pasul 1 — Crearea LINE Official Account și a Messaging-API-Channel

  1. Creați un LINE Official Account (prin LINE Official Account Manager).
  2. Deschideți LINE Developers Console (developers.line.biz) și creați un Messaging-API-Channel, respectiv conectați-vă contul Official cu API-ul Messaging.
  3. Emiteți în tab-ul Messaging API un Channel-Access-Token de lungă durată (Issue).
  4. Notați Channel-Secret-ul din tab-ul Basic Settings.

Notă: Tratați Channel-Access-Token-ul și Channel-Secret-ul ca pe niște parole. Nu le distribuiți public și stocați-le în siguranță.

Pasul 3 — Trimiterea mesajelor prin chatbot (Klacksy)

Odată ce furnizorul LINE este configurat și activat, chatbot-ul Klacksy poate trimite mesaje. Nu trebuie să cunoașteți niciun ID de utilizator LINE — folosiți pur și simplu numele angajatului sau al clientului: 

"Trimite un mesaj lui Max Muster: programarea dumneavoastră este mâine la ora 14:00."
"Trimite-i Anei Beispiel un mesaj: tura a fost schimbată."
"Anunță-l pe Peter Müller că schimbul său de luni este anulat."

Klacksy caută automat ID-ul de utilizator LINE salvat al destinatarului și utilizează furnizorul LINE configurat. Trimiterea este complet transparentă pentru dvs. — lucrați cu nume, Klacksy se ocupă de rest.

Cerință preliminară: La destinatar trebuie să fie salvat ID-ul de utilizator LINE (începe cu U…) în Klacks (la Adresă → Date de contact). ID-ul de utilizator devine cunoscut prin mesajele primite (vizibil în mesageria de tip inbox) — în acest scop, destinatarul trebuie să fi adăugat contul dvs. Official ca prieten și să-i fi trimis un mesaj.

Pasul 4 — Primirea mesajelor primite (Webhook)

Pentru a afișa mesajele LINE primite în Klacks, URL-ul webhook trebuie introdus manual în LINE Developers Console.

  1. Copiați URL-ul Webhook afișat în Klacks din setările furnizorului: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. Introduceți acest URL în LINE Developers Console la Messaging API → Webhook settings drept Webhook URL.
  3. Activați opțiunea „Use webhook".
  4. Asigurați-vă că instanța dvs. Klacks este accesibilă public prin HTTPS.
  5. Mesajele primite apar acum în timp real în mesageria de tip inbox.
