Configurarea Slack

Cerințe preliminare

Pentru a trimite și primi mesaje prin Slack cu Klacks, aveți nevoie de un workspace Slack și de o aplicație Slack cu permisiunile corespunzătoare. Klacks utilizează Slack Web API pentru trimitere și Events API pentru primire.

Notă: Planul gratuit Slack este suficient pentru integrare. Aplicațiile Slack se creează pe api.slack.com și sunt gratuite.

Pasul 1 — Crearea aplicației Slack

  1. Deschideți api.slack.com/apps și faceți clic pe Create New App.
  2. Selectați From scratch și dați un nume aplicației (de ex. Klacks Bot).
  3. Selectați workspace-ul în care va fi instalată aplicația.
  4. Navigați la OAuth & Permissions și adăugați următoarele Bot Token Scopes:
    • chat:write — pentru trimiterea de mesaje în canale
    • im:write — pentru trimiterea de mesaje directe către utilizatori
  5. Faceți clic pe Install to Workspace și confirmați permisiunile.
  6. Notați Bot User OAuth Token (începe cu xoxb-).
  7. Navigați la Basic Information și notați Signing Secret.

Pasul 2 — Configurarea Slack în Klacks

  1. Navigați la Setări → Furnizori de mesagerie.
  2. Faceți clic pe Adăugare.
  3. Completați câmpurile după cum urmează:

Pasul 3 — Trimiterea mesajelor prin chatbot (Klacksy)

Odată ce furnizorul Slack este configurat și activat, chatbot-ul Klacksy poate trimite mesaje prin Slack. Folosiți numele angajatului sau un nume de canal: 

"Trimite un mesaj lui Max Muster: programarea dumneavoastră este mâine la ora 14:00."
"Trimite-i Anei Beispiel un mesaj: tura a fost schimbată."
"Postează în #team-updates: Planurile de tură pentru săptămâna viitoare sunt gata."

Ca destinatar servește un Channel-ID (de ex. C0123456789) sau un User-ID (de ex. U0123456789) — în cazul unui User-ID se trimite un mesaj direct. Dacă nu este indicat niciun destinatar, se utilizează canalul implicit configurat. Trimiterea este complet transparentă pentru dvs. — lucrați cu nume, Klacksy se ocupă de rest.

Cerință preliminară: Utilizatorul Slack trebuie să fie asociat cu contactul Klacks corespunzător (la Adresă → Date de contact). Pentru mesajele de canal, botul trebuie să fie invitat în canalul respectiv (/invite @Klacks Bot).

Pasul 4 — Primirea mesajelor primite (Events API)

Pentru a afișa mesajele Slack primite în Klacks, trebuie configurat Events API al aplicației Slack. Salvați și activați furnizorul în Klacks înainte de a introduce Request-URL — Slack verifică imediat URL-ul cu o cerere de tip Challenge, la care Klacks răspunde automat.

  1. Deschideți aplicația dvs. Slack pe api.slack.com/apps și navigați la Event Subscriptions.
  2. Activați Enable Events și introduceți ca Request URL URL-ul Webhook afișat în Klacks: 
    https://{ihre-domain}/api/messaging/webhook/slack
  3. Abonați-vă la Subscribe to bot events la evenimentele message.im (mesaje directe) și message.channels (mesaje de canal).
  4. Salvați modificările și instalați din nou aplicația în workspace atunci când vi se solicită.
  5. Mesajele primite apar acum în timp real în mesageria de tip inbox. Klacks verifică astfel semnătura fiecărei cereri cu Signing-Secret-ul salvat.

Depanare

ProblemăCauză posibilăSoluție

Verificarea Request-URL eșuează Furnizorul nu este salvat/activat în Klacks sau Signing-Secret-ul este greșit Salvați și activați mai întâi furnizorul în Klacks și verificați Signing-Secret-ul
Lipsesc mesajele primite Evenimentele botului nu sunt abonate Abonați-vă la message.im și message.channels la Event Subscriptions
